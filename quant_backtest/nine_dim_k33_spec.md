# 九维警报池规则定稿（K33）

| 项 | 值 |
|---|---|
| 版本 | K33（V3 结构重定位） |
| 定稿日期 | 2026-10-02 |
| 状态 | **正式定稿**（证据链：k33_grid_report.md，5479 样本离线网格验证） |
| 前版 | 买入池 ≥90（已退役，见 §8） |

## 1. 规则总纲

九维总分语义反转：**高分 = 拥挤警报（回避位），非买入信号**。

依据：总分与前向收益单调负相关（thinned r20：lt65 -9.2% → 65-75 段负 → ≥75 -27.9% → ≥85 -71.5%，胜率 25%→9%→0%），高分构成（动量+机构+情绪+资金）为拥挤度代理（与 K27 图谱拥挤度判例同构）。任何分段**均不构成买入信号**。

## 2. 分段定义（band）

| band | 分数区间 | 语义 |
|---|---|---|
| `alert2` | ≥85 | 强警报：两仪 2 年 4 样本全亏（r20 均值 -71.5%，左尾 p5 -85.9%） |
| `alert` | 75-85 | 警报：thinned 胜率 9%，r20 均值 -18.8% |
| `mid` | 60-75 | 无信号段（观察池方案经离线网格否决，见 §5） |
| `low` | <60 | 基准段（负收益但为大盘属性，超额解释见报告③） |
| `na` | 无分 | 未完整评分（cov < MIN_COV=0.75） |

## 3. 入池规则

- **条件**：`band ∈ (alert, alert2) 且 full（cov ≥ 0.75）`，即总分 ≥ ALERT_TH=75 的满评样本
- **池类型**：`pool_type: "alert"`（警报池=回避名单，非买入名单）
- **幂等键**：`(code, trade_date)`，同票同日不重复入池
- **落盘**：`data/nine_dim_history.jsonl`，行字段含 score/cov/band/pool_type/entry_px/first_seen
- **节奏**：每日 06:40 NineDimScan（粗筛 → 满评 → 入池）；≥75 为罕见拥挤位，**低频累积属预期**（两仪 2 年 thinned 仅 23 样本），不因入池少调整阈值

## 4. 验证方向（影子观察）

警报有效性的判据方向已翻转：

- **预期**：入池票后续 r20 为**负**（超额亦负）= 警报有效
- **失效**：入池票 r20 系统性转正且超额为正 → 触发复评（§7）
- **观察口径**：n≥30（thinned）后方可下结论；n<10 期间仅记录不评判
- **退出跟踪**：入池后按 update_perf 通用逻辑跟踪（读 code/dt/entry_px，池类型无破坏）

## 5. 观察池否决记录（定稿边界）

65-75 中分段「底部环境正用」方案经离线网格否决，**不再复议**（除非 §7 触发）：

1. 2024 段 70% 胜率系 n=10 小样本误导；2025/2026 同段全面转负（17%/-9.8%、18%/-23.8%）
2. 60-65+低波（win 67%）经超额检验拆穿为 **beta 非 alpha**（超额 +0.1pp 近零，r5 胜率 37%）
3. 阈值敏感性单调（≥70 -18.9% → ≥75 -27.9% → ≥80 -39.3% → ≥85 -71.5%），75 为收益/样本量平衡点

## 7. 复评触发条件

任一触发即重跑网格验证报告并重开规则评审：

1. 结构修订（V4+：因子群权重/构成调整）——**复核铁律**：≥75 段负向单调性不劣化方可定稿
2. 警报池影子战绩失效（§4 失效判据，n≥30 thinned 口径）
3. 样本外新入池票累计 n≥30 时做一次中期对照（预期 vs 实际）

## 8. 退役记录

- `BUY_TH=90` 买入池：V3 复评两仪 2 年仅 1 票（可达性无意义）且该票 r20 -34%，2026-10-02（K33）退役。常量保留仅作历史参照展示，任何代码不得再以 ≥90 作为买入条件。
- 门户历史战绩表中 V2 时代买入池行标注「买入(旧)」，不与警报池混算。
