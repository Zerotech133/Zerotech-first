## 1. 口径红线（引用任何数字前必须对齐）

1. **成本 30bp 往返**：`config.json` → `trade.by_market.CN`（`cost_bps=12`、`slippage_bps=3` 均为单边，`2×(12+3)/10000`）。`backtest.py:133` 的 `turnover*(cost_bps+slippage_bps)/10000` **正确，不得改成 `/2`**。
2. **主持有期 hold10**（hold5 在 18.5bp 处即归零，30bp 下净负 −11.5bp；hold10 仍有 +24.3bp）。
3. **审计窗口固定 `20251015~20261014`**，不切全窗口：全窗口会让多维增量符号翻转（W1 +0.0985pp → W2 −0.1637pp → W3 −0.0908pp，Q 检验 p=0.005），且检测 +0.0815pp 需 ≈28.5 年数据，本地上限约 490 天。
4. **阈值 75/50 保持不动**：四种缺维补法的放宽量跨 `+6.25/+1.69/0/−3.25`，**符号相反、方向不可识别**；"缺维期放宽 6.25 分"是补 jev=50 的假设，不是恒等式（产线归一等价于补 `jev=S3`，放宽 0）。覆盖率边界 22.64%（最坏 μ=0 时 7.84%）。
5. **PIT 红线**：qfq 系指标为追溯调整，回测禁用；一律 hfq 或 bfq+adj_factor。既有池 2025 年中以前为前复权（同股收益链安全、跨股价格不可比）→ 见 §5 路径 B。
6. **增量归属**：环境闸门（关闸 +0.30%→−0.01%、DD −40%→−91%）与 `tech≥75` 门槛是仅有两个可押组件；多维二次排序（+0.083/−0.090/−0.052pp，p=0.31~0.54）与 C1 连续化 **不押**。对外禁止引用"多维有 +0.0815pp 增量"。
7. **基线校验**：`python _qpzm_audit_20261105/t7_lock/verify_baseline.py`（快检 1.5s）/ `--rerun`（~486s，19 字段逐值）。基线 = 引擎 8 文件 md5 + A 股数据两级指纹；**引擎文件任何改动（包括只加注释）都必须重冻，且不碰 data 指纹**。v2 基线数值：hold5 +0.1237% / hold10 +0.6320% / hold20 +0.3768%（三重修复后，比旧值低 2.9~3.3bp，掩码修复占 85%）。
8. **当前校验状态（2026-11-07）**：快检 `verdict=FAIL`，但**仅 data 四项不一致**——`data/ashare` 在 11-06 16:05 收盘刷新后由 5688→5689 个 parquet（新增 1 只上市/复牌票）、抽样文件内容均追加 11-06 一根 bar；引擎 8 文件全部 OK（注释补丁后引擎指纹已重冻 `f6782e33…`）。**这是数据漂移，不是代码失效**：审计窗口固定 `20251015~20261014`，窗口外新增 bar 不改变窗口内结果；2026-11-07 完整 `--rerun` 已实证 **19 字段逐值 0 差异（284.5s）**，产物 `_qpzm_audit_20261105/t7_lock/_verify_20261107_notes.json`。不得为"让校验变绿"而手改 data 指纹。A2 五窗口全量复跑时一并重冻数据指纹并出 v3 锁。

## 5. 验收判据（六条，任何改造必须全过）

1. **五窗口稳健性**：3m/6m/12m/24m/36m 中 ≥4/5 窗收益不恶化；回撤不恶化 >2pp。
2. **双成本**：30bp 与 50bp 均不翻转结论；给出盈亏平衡成本。
3. **组合层裁判**：收益/回撤以 `portfolio_sim.py` 真净值为准，禁止引用引擎虚拟净值；满仓折算口径须并列报告。
4. **PIT 红线**：新因子不得引入未来信息；qfq 系禁用。
5. **beta 判据（修订版）**：仅用于**新因子/新排序键**，差分形式「相对基线相关性变化 ≤±0.05 且回撤不恶化」；sizing 层不适用（只重分配同一篮子的钱）。原「beta 相关 <0.3」在本策略族全灭（基线 0.385~0.550），作废。
6. **审计工程流程**：改动前断言锚点 `count==1`、改动后断言新串存在；引擎改动必重冻基线锁并 `verify_baseline.py` 复核；备份链 `.bak-YYYYMMDD-*` 齐备；多代理并行遵守 `_qpzm_rd_20261106/AGENTS.md` 互斥协议。
