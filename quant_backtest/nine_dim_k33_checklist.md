# K33 警报池 · V4 复评触发检查清单

> 依据：[nine_dim_k33_spec.md](file:///e:/老田的AI助手/quant_backtest/nine_dim_k33_spec.md) §7。
> 性质：操作 SOP。三类触发——A 事件强制（结构修订）/ B 例行监测（影子战绩）/ C 里程碑（样本外 n≥30）。
> 任何一项判据失败 → 停止定稿流程，转 §D 失败处置。

## A. 结构修订触发（V4+，事件强制，不可跳过）

> 触发事件：因子群权重、构成、阈值（MIN_COV/粗筛条件）任何调整。

- [ ] **A1 落码核对**：`nine_dim.py` 常量区与评分函数 diff 确认，记录修订点清单
- [ ] **A2 全量回放**：`nine_dim_backtest.py` 51 锚点重跑（缓存命中段自动跳过；rc/fc 段最慢约 25 分钟/段，输出重定向 `C:\Temp\*.log`）
- [ ] **A3 网格报告重跑**：`python k33_grid_report.py`，生成新版 `k33_grid_report.md`（旧版另存勿覆盖）
- [ ] **A4 核心判据（复核铁律）**：新版报告 thinned r20——
  - ① ≥75 段均值 < 0（负向存在）
  - ② 分段单调性保持：<60 → 65-75 → 75-85 → ≥85 均值逐段递减
  - ③ ≥75 段均值不劣于 -10%（负向大幅衰减即可疑，转人工评审）
  - V3 基线参照：≥75 n=23 / 9% / -27.9%；≥85 n=4 / 0% / -71.5%
- [ ] **A5 阈值敏感性**：报告④节 ≥70/75/80/85 单调递减保持
- [ ] **A6 超额检验**：报告③节 ≥75 段超额仍为负（负向非 beta）
- [ ] **A7 观察池边界**：65-75 / 60-65 各环境层仍无可复制正信号（否则重开观察池评审）

## B. 影子战绩失效监测（例行，每周一次人工跑）

> 触发事件：例行监测。数据源：`data/nine_dim_history.jsonl`（pool_type=alert 行）。

- [ ] **B1 样本量核对**：入池总行数；同票 20 交易日去重后等效 n
- [ ] **B2 前置门槛**：thinned n < 30 → 仅记录不评判，本节通过（低频累积属预期，勿因入池少调整 ALERT_TH）
- [ ] **B3 有效判据（n≥30）**：入池票 r20 均值 < 0 **且** 超额均值 < 0 → 警报有效，继续观察
- [ ] **B4 失效判据（n≥30）**：r20 均值 > 0 **且** 超额均值 > 0（系统性转正）→ **触发复评**，按 A 全链重跑

## C. 中期对照（里程碑，样本外累计 n≥30 时一次性）

> 触发事件：警报池样本外（K33 定稿后入池）thinned 累计 n 首达 30。

- [ ] **C1 对照**：样本外 r20 实际均值 vs 离线预期 -27.9%
- [ ] **C2 一致区间**：均值落在 [-50%, -5%] 且胜率 < 40% → 预期一致
- [ ] **C3 超界处置**：均值 > 0（含超额 > 0）→ 转流程 B4；均值 < -50% 或胜率 ≥ 40% → 记录异常并人工分析（勿自动改规则）

## D. 失败处置与归档（任一判据失败时）

1. **停止**：V4 修订不得定稿 / 警报池标记「观察中-存疑」
2. **处置**：结构问题回滚至上一定稿版本；数据问题（如未来函数/除权污染）先修回放引擎再重跑
3. **归档**：INTEL_RD_PLAN 追加决策记录（触发项、判据数值、处置结论）
4. **重开**：规则评审须按 K33 同标准重新走「离线网格 → 报告 → 定稿」三件套
