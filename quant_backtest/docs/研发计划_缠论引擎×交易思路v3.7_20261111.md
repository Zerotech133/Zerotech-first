## 一、任务清单（对齐 Sprint 条目化风格）

### T1 · 三买×缩量交叉验证（R1，本周首发）—— ✅ 已完成 2026-11-11，**假设被拒绝，未过门**
- **结果**（reports/vr_bucket_3buy_20261111.json，脚本 vr_bucket_3buy.py）：
  - 全窗 1,436 条 3买（20251013-20261012）：vr 四桶 20 日超额（vs 全市场等权）：
    `<0.7: −119bp (t=−2.11)` / `0.7-1.0: −165bp (t=−3.53)` / `1.0-1.5: −62bp (t=−0.92)` / `>1.5: −209bp (t=−1.77)`
  - **无单调性**；最优桶是 1.0-1.5（温和量），缩量桶 <0.7 反而显著为负
  - 市值分层复核：小/大两半均非单调（秩 [2,1,3,0] / [1,0,2,3]）——不是市值代理
  - 近窗 118 条（尾部剔除 163 后）方向翻转（<0.7 最优 +19bp），样本太小当噪声
  - 附带发现：3买 事件整体跑输全市场等权约 −150bp/20日，与「1买>2买>3买」既有结论一致
- **裁定**：验收门四条全不过 → **T2 不触发**，评分口径不动。证据入档。
- **口径注记**：本检验的缩量 = 信号日量比（当日额/20日均额）；PPT「量能最低价最低」若指回踩腿量能与离开腿对比（腿级量能），属另一口径，如需可做 v2。另：报告 JSON 里 bench_n_days_median=1 是全日期联合轴（1993-2026）的中位数，事件日实际市场宽度 ~5,200 只，基准健康。
