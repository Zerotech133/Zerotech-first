## 一、三问直答

### 1. 抓取线和播种线是不是多线程的？——是，双实例并行运转中
| 线 | 实例 | 状态（23:08 实测） |
|---|---|---|
| 抓取·播种 | A 实例（seed 20000 队列）+ 夜班轮 B（seed 30000，22:41 自动拉起） | 双实例并行，奇偶队列分片，游标文件各自独立（--cursor-file） |
| 抓取·深挖 | xq_backfill_auto.py 每小时兜底（含 45 分钟自愈锁 + done 自动停） | 正常 |
| 治理·分类 | **w1（偶数段）+ w2（奇数段）** 双实例 | 各 500 条并行消费，分片互斥实证；已升级 --worker-id/--segment/--order 三参数（commit 0ca1a732） |
| 治理·automation | 追平轮=autoA/segment A、日轮=daily worker、探针让路 | 全部 worker 化，裸实例撞车已根治 |

**封顶结论**：Ollama par=2 决定分类并发上限=2，实测合并增益 ~1.2x（长文 KV 显存压力吃掉理论 1.53x 的一部分），2 实例是最优解，加第三实例必触发 60s 超时熔断。

### 2. 所有的数据是一个标准吗？——不是。三个标准化缺口（全部实测实锤）
1. **标的词形混杂**：tickers 列混装港股 5 位码（702 次）/A股 6 位码（298）/中文指数（129）/基金类目（123），门户 top_codes 榜单语义被污染。行业实践（实体归一化 NER+ticker 映射）正是补这个。
2. **标签口径漂移**：三代 prompt 并存且分布系统性偏移——广告识别率 v1.2-re 3% vs v1.3 **9%**（3 倍差）、宏观 2% vs 5%。v1.3-rule 是纯规则通道（100% 广告）。跨版本统计情绪分布必须分层或重标，否则回测信号失真。
3. **schema 语义陷阱**：xq_status.target 是 `/{user}/{status_id}` 路径而非股票代码（_manifest.json 未标注）；source 是自由文本（雪球/Android/iPhone/公告…12 种）。

**附加重大发现**：_manifest 七子源中**行情系四源（quote_snap/kline_d/capital_flow/northbound）全部 403「IP Blacklisted」degraded**，hot/comment failed——雪球行情域整域拉黑（与既有判例一致），意味着「帖子情绪 × 行情数据」的回测闭环右侧断供，需要行情数据替代源（akshare/tushare/免费行情 API）。

### 3. Hermes 在系统里做了什么？能否胜任驻场治理？——已做：只读问答+任务触发的驻场底座；能胜任，且零新增基建即可启动
**Hermes 现状画像**（侦察实证）：
- 生产基 `hermes-webui-next`（8787 在跑，PID 19392，30 分钟守护保活）；引擎=Nous Research 开源 Hermes Agent；模型=本地 qwen3.6:35b-a3b（22G MoE）
- 记忆纯自有：SQLite state.db（FTS5 全文）+ SOUL.md 人格纪律 + USER.md 用户事实 + profiles 隔离——不依赖 Redis/Qdrant/PG
- **与雪球线的真实集成**：4 个 stdio MCP（stock-data 24 工具、stock-intel-readonly、playwright、om-metadata），stock-data 全部经 8791 仪表盘转发到 210 表数仓；lineage_breaks/lineage_trace 血缘查询、trigger_task 任务触发、dataops_query 数据运维问答——**E2E 已验证**（数据池 7 子模块/206 表/188 done）
- **SOUL.md 已预写治理问答工具纪律**（「血缘断链→lineage_breaks、采集任务→scheduled_tasks」）——驻场定位已有预演
- cron 引擎齐全但 jobs.json 空载；playwright 浏览器面可用（token 获取/页面核对）

**三个瓶颈**（能胜任，但要在计划里解掉）：① 35b 工具调用 JSON 抖动史（K-STOCK-428）② 8791 仪表盘当前没跑→stock-data MCP 会 503（单点依赖）③ 无舆情语义层专用工具（分类覆盖率/口径漂移/队列健康都是我这边脚本，Hermes 看不到）。

## 二、开源社区实践对照 → 八条启示

| # | 社区实践 | 对我们的映射 |
|---|---|---|
| 1 | 编排模式：Coordinator-Worker（中心协调+专业工人）是数据管线最稳拓扑 | 我们已在用（主会话协调+w1/w2 工人+automation 外骨骼），方向正确，无需引入 LangGraph 等重框架——**Hermes 自有引擎+MCP 即原生 Coordinator 面** |
| 2 | 金融情绪管线标准流：采集→清洗/去重/**实体归一化**→评分（relevance gating）→recency 加权聚合→信号→监控 | 我们的管线缺实体归一化（缺口 1）和 relevance gating（闲聊/广告混入信号池） |
| 3 | GPT 类零样本标注 82-88% 准确率；域内微调（FinBERT 类）提升 10-15% | qwen3.5:9b 零样本可用；中期用已标 4k 样本做 LoRA 微调或规则增强（v1.3-rule 已是雏形） |
| 4 | 监控治理：模型漂移/覆盖率缺口/信号衰减/源可信度加权/bot 过滤 | 数据健康复盘 automation（07:40）已建雏形，需增：口径漂移探针（已实测出 3%→9%）、源加权 |
| 5 | 情绪+动量相关性仅 0.22，组合 Sharpe 1.52；新闻情绪 1-3 天定价、社媒 1-5 天 | 雪球社媒情绪定位=**反向指标/短窗信号**（1-5 天），回测设计按此窗口 |
| 6 | 高影响信号必须 human-in-the-loop；版本控制标注数据保证可复现 | prompt_version 已落库 ✓；升级：口径漂移超阈值时阻塞下线 |
| 7 | 多 regime 回测（平静/波动市情绪行为不同） | 近期线 2024-2026 数据是 regime 多样性的关键（呼应 M-H3 缺口） |
| 8 | AgentPrune：冗余通信剪枝省 72.8% token | 多实例间零直连（经主会话中转）+ probe 让路，已是低通信形态 ✓ |
