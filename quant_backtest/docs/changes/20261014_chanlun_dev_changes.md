## W3-4 背驰阈值扫描：影子背驰标注"标签启用门槛"论证（20261014）

### 一、背景与目的

`chanlun_signal.py` 存量影子标注（仅标注不拦截）：P5 盘整背驰、P6-a MACD 背驰、
P6-b 正宗盘整背驰、P6-c 趋势背驰、P8 量能共振、P2 K线形态、P9 MA200 regime。
设计意图为"可成交口径评估达标后才启用过滤"，但一直未系统评估。本次按 v1.1 计划
对最有代表性的 **P6-a MACD 背驰（1买）** 与 **P5 盘整背驰（3买）** 做阈值网格扫描，
产出启用门槛建议。P6-b 与 P5 共享 3买样本且口径相近（同用 BEICHI_RATIO），
P6-c 为结构性判据无连续阈值，均不在本次网格（后续攒样本再议）。

### 三、口径（与 v6c2/v7 同源）

- 新文件 `chanlun_beichi_grid.py`，**只读产线**（chanlun_signal / chanlun_macd 仅 import 调用），
  信号事件直接复用 `_v7_stream_cache.json` 的 seen-ever 新鲜买点流（219 个：1买=75、
  2买=72、3买=72；信号事件与阈值无关，无需重算产线信号流），每事件在检出日以
  tail(250) bars（与 v6c/v7 run_day 完全一致）补算标注原料。总耗时 1.4s。
- 股票池 76 只（poc_adapter_chanlun_20261012，同 v6c2）；窗口 20231010→20261012；
  use_hfq=true（kfac 后复权）；前向收益 = T+1 开盘买 → 持 5/10/20 交易日收盘卖，
  双边成本 15bps。
- 对照口径：同一事件集内「有背驰标注 vs 无标注(=False)」子集均值收益差；
  标注 None（窗口内无同向前序笔等无法判定）不计入任一子集、单独计数
  （P6-a conf2 档有 12 个事件无法判定，占 1买 的 16%）。
- **启用门槛判据**：半年度两段（交易日中点 20250410 分割）收益差同向且 |差|≥1pp
  → 该档值得启用为过滤器；另加最小样本护栏（两段各 ≥5 个标注样本，否则判
  "样本不足维持仅标注"）。
- **产线口径一致性校验**（参数化标签在 r=1.0/n=1 处必须复现产线字段）：
  P6-a vs 产线 mbei **75/75 全对齐**；P5 vs 产线 bei **72/72 全对齐**。

### 六、启用门槛建议（明确结论）

1. **P6-a MACD 背驰（1买）：全部 6 档均不建议启用为过滤器，维持仅标注。**
   - conf1（产线现行口径）三档持有期 diff 在 H1/H2 两段方向不一致（H1 ≈0 或负、
     H2 正），分年 2023 反向大负——不满足"两段同向 ≥1pp"。
   - conf2 档 H5/H10 形式性通过（两段同向 ≥1pp），但 H2 标注样本仅 1 个，
     触发最小样本护栏（n≥5），统计上不可信，不作为启用依据；且 conf2 的
     H20 diff 全部大负（−3.7~−6.1pp），长持有期方向反转，进一步排除。
   - 待攒样本：conf2 档挂账，H2 段标注样本攒到 ≥5 后复评。
2. **P5 盘整背驰（3买）：全部 3 档均不建议启用为正向过滤器，维持仅标注。**
   - 额外发现：**产线现行 1.0 档在 H20 反向显著**（有背驰子集比无背驰子集
     差 3.2pp，两段同负 −3.51/−3.02，样本 49/6 达标）。即"回踩弱于离开笔"
     的 3买 并非更好的 3买。挂账观察：若后续样本维持同向，可考虑反向用法
     （P5 背驰 3买 降权/排除），启用前需以滚动样本复评。
3. 通用结论：当前 1买/3买 年事件量各 ~25 个，任何背驰过滤档位在半年度分割下
   样本量先天不足；**在信号量翻倍之前，所有背驰类标签一律维持"仅标注不拦截"**，
   启用门槛以本节判据（两段同向 ≥1pp + 两段各 n≥5）为准。
