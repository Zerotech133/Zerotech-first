## 一、实时线（战术情报支撑）

**目标**：当下舆情流 → 当日打标 → 情报分析可即时消费。

### 1.1 调度节奏（三班倒，全部走计划任务/automation）

| 时点 | 任务 | 产出 |
|---|---|---|
| 17:40 | XueqiuSync（行情/结构化面） | parquet 快照 |
| 17:50 | GubaCrawl（股吧舆情） | 股吧帖 |
| **18:00** | **XueqiuCrawl（雪球主采集，当日增量）** | xq_status 当日新帖 |
| **18:30** | **分类日轮（automation a68b8ed1）** | 当日帖打标入库 |
| 19:00 起 | 情报消费端读派生表 | 当日情报全量可用 |

**盘中提频预案（本周观察后启用）**：首跑稳定 3 天后，增开 11:35（午盘）+ 15:15（收盘）两个低预算轮（各 ≤200 条），分类日轮改 3 次/日。触发条件：18:00 轮连续 3 日 exit=0 且 token 零熔断。

### 1.2 情报消费端（缺口 → 本周补齐）

分类数据目前「落库即止」，消费端缺三件：
1. **情报日报生成器**（P1，1-2 天）：每日 19:00 读当日打标数据 → 产出 `event_type × sentiment × ticker` 汇总 + 异动信号（如某 ticker bearish 突增）→ 落门户/推 A0A。
2. **R3 拦截-舆情一致性核对**（P2，需 2-4 周积累）：实时舆情与 RiskGuard R3 事件风险拦截做时间对齐核对（历史侧已证零重叠不可行，未来生产期可做）。
3. ✅ **api_perf 门户出口**（10-18 提前落地）：`GET /api/xq/intel?date=YYYY-MM-DD` 读 automation_runs/xq_report 日报投影（latest 缺省），portal/api_xq_intel.py 只读 mixin（0c5af48a+984ad951），fail-visible 观测态 + 非法参数 400，旧端点回归无损。

### 1.3 实时线风险与对策

- **token 过期**：主 token + 备用匿名双池，18:10 automation 验收兜底
- **反爬提频红线**：提频以「低预算+错峰」为前提，触发 403 熔断自动回退单日轮
- **Ollama 抢队**：分类轮自带连续失败熔断让路，追平轮错峰补

## 二、历史线（回测数据支撑）

**目标**：把 2015-2023 历史舆情尽量抓全 → 舆情因子有效性研究 → 回测/RiskGuard 校准依据。

### 2.1 存量盘点（本日侦察结论）

- 存量 14212 条 = 2017-02 ~ 2023-11（timeline 线性深翻产物，翻到低产区停轮）
- **号段-时间映射已实锤**（探针 v0.2）：分类流游标是 feed 序号空间（~20 万+档，跨类目共享），与帖子 status_id（1.48 亿档）是两套体系；锚点：**30000→2015-03 / 60000→2017-05 / 150000→2018-04 / 250000→2020-03**
- **2015-2017 区段（3 万-6 万档）是从未挖过的处女地**；2018-2023 存量密度中等
- 旧区段每页产出 5-11 条（归档抽稀）但不重叠可净增，估算 ~1000 条/小时/轮

### 2.2 扩容实施（已开工，R1 已实证）

1. ✅ 采集器 `--seed` 播种参数（断点不落档，与常规轮隔离）
2. ✅ **R1 实弹收官（10-18 上午）**：seed=30000 挖 2015 区段，**8 请求 / 1.4 分钟 / 净增 105 条**（14212→14317），库底 2017-02→**2015-02**，换出口 0 次。实证效率 ~75 条/分钟（每页 13-17 条，比线性深翻后期快一个量级）
3. 🔄 R2 进行中：seed=45000（2016 区段）目标 1000 条（大目标稳定性验证）
4. 待排期播种计划（按映射锚点从远到近，每轮独立日志）：
   - R3：seed=75000（2017 下半年补密度）目标 2000 条
   - R4：seed=105000 / 190000（2018-2019 空窗补洞）目标 2000 条
   - R5：seed=20000（2014-2015 更早边界探边）目标 1000 条
5. ✅ **夜班自动化就位（10-18 上午）**：`xq_seed_auto.py` 队列状态机——SEED_QUEUE 11 档（20000→230000，feed 序号空间从远到近），每轮 target=1000，推进判据=挖穿（全 cat exhausted）OR 贫矿（连续 3 轮净增<50），全队列完成 done=true 永久停；播种断点独立档 seed_cursor.json（同 seed 重跑自动续挖）；45min 自愈锁。automation 每 30min 触发，与 18:00 生产轮共享出口池自动错峰

### 2.3 回测对齐层（已就绪）

- **舆情因子探针** tools/research/xq_sentiment_factor_probe.py：帖子次月收益（ts_monthly 全历史月线，无前视口径），链路已通；追平+扩容后重跑即全量研究
- 分类追平：385/14212，错峰 automation 推进中（Ollama 空闲窗口自动补；追平完成自动到位）
- 漏斗：带 ticker 帖中基金词占大头，v1.2 计划加指数→标的映射（沪深300→000300.SH）扩样本

### 2.4 历史线风险与对策

- **归档抽稀**：旧区段每页 5-11 条，靠轮次数量堆，不追求单轮高产
