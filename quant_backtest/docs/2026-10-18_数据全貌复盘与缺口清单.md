### ④ target 字段语义陷阱（schema 级发现）
`xq_status.target` 实际存的是 **`/{user_id}/{status_id}` 路径**，不是股票代码，每行唯一。任何后续分析把 target 当"标的"聚合都会错。标的维度只存在于 `xq_status_classified.tickers`。**schema 文档（_manifest.json）未标注此语义，须补**。

### ⑤ 复盘机制缺失：所有"发现"都靠人肉会话触发
本轮暴露的每个缺口（近期线 0、2013-2018 覆盖塌陷、吞吐、脏行）在此之前没有任何自动化探针在盯。**已建：每日 07:40 数据健康盘点 automation**（`xq_data_review`），自包含盘点 SQL 要点 + ALERT 规则，报告落 `C:/aios/automation_runs/xq_data_review/`。

## 三、次级发现（记录在案）

1. **存储类型判例**：`created_at`/`fetched_at` 均为 ISO **text**（`typeof='text'`）。SQL 分析严禁 `CAST AS INTEGER` 或 `strftime(...,'unixepoch')`——全部得 1970/NULL。分组一律 `substr(created_at,1,10)`。
2. **脏行**：`event_type IS NULL` 1 条；`user_id='-1'` 493 条（2.1%，匿名/失效作者，采样与作者分析时应排除，策略未裁决）。
3. **标签分布头部**：个股研判 1,249 / 基金理财 664 / 闲聊杂谈 403 / 广告推广 357 / 行情观点 331 / 宏观政策 102 / 交易策略 76。广告推广占 11.2%，回测前应考虑过滤位。
4. **2023 断点形态**：2023-06 起每月仅 2-5 条，渐进枯竭而非一刀切——与"feed 权重衰减"一致，源死定谳进一步坐实。
5. **prompt 版本三代并存**：v1.2-re(1,687) / v1.3(1,265) / v1.3-rule(196) / v1.2(2)。跨版本标签口径差异未做过对拍，若未来做统计要按 prompt_version 分层。
