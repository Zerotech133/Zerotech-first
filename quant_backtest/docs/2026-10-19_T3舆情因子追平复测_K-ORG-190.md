## 一、结论先行

1. **"样本翻倍"未发生**：追平实际只增 39 帖（11,220→11,259），v1.3 A 股帖 230→259（+29，+12.6%）；可复现口径下 weekly senti 有效 IC 截面 **15→15，追平前后不变**（07:53 离线审计 matched 96 对 → 本次 98 对，仅 +2 obs）。
2. **粒度放宽后 senti 有效截面 15（周）/ 13（双周）/ 6（月），全部 ≥5，形式上过样本闸门**；但 IC 方向跨粒度不稳（−0.19 / +0.01 / −0.01），**不建议进策略层评审，维持探索性**。
3. **重大发现：v1 报告的 34 截面/247 obs 物理不可复现**（缓存覆盖事故，见第三节），其 −0.0844 不应再被引用为基线。

## 三、v1 基线不可复现（缓存覆盖事故，须对账）

- 对照实验：HEAD 原版管道（git show e9aca955 同源）+ 现库 + 现缓存重算 weekly = **31 截面 / 98 obs / senti 15**，与本次复测零偏差（管道无回归），也与 07:45-07:53 六份离线审计 JSON 一致（v1.3 matched 96 对、15 截面）。
- 铁证：现缓存 SH600000 仅 1791 行（2019-05-29 起，行数=meta.days=1791，接口按最近 N 行返回）；v1 result 声称的 2018-08-27 等 **19 个 2018-2019 年上半年 senti 截面需要 2018-09 起行情**，该缓存在物理上给不出——weekly 分支 max_date=cutoff+7，2018 帖必被 skip。
- 时戳：daily_cache.json mtime 07:03:35.781 与 factor_v1_result.json mtime 07:03:35.906 紧邻（fetch_daily_cached 增量重写覆盖了早期更完整缓存）；缓存 _meta.saved_at=06:46:19 与 mtime 不一致佐证覆盖。**处置建议：v1 报告第二节的 34/−0.0844 与 60/247 停止引用，以本文可复现口径替换；离线审计的 INCONCLUSIVE 判例维持。**

## 五、判据对齐与建议

1. 闸门判据（有效 IC 截面 <5 → 闸门关闭；≥5 → 报 IC/方向）：senti 三粒度均 ≥5 → **闸门形式打开，已按约报告 IC 均值/ICIR/方向如上表**；mention 仅月粒度踩线，**闸门维持关闭**。
2. **是否可进策略层评审：不建议。** 依据：①方向跨粒度不稳（−0.19/+0.01/−0.01 翻号）；②ICIR 绝对值 ≤0.33 且无经济显著性；③基线本身建立在行情覆盖缺口未修复的 98 obs 上；④追平未兑现翻倍样本，xq 情报线当前 A 股帖增量速率（追平 +29）远低于统计要求。
3. T9 解锁优先级（比 regime 分层更前置）：**重拉 2018-2019 完整日线**（恢复 skipped_delayed 149 对，零写库风险、收益最大）→ 2018 norm NULL 回填 → 再复测。
