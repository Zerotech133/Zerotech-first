| 5 | /S/SH600519 个股页（无 warmup 直打） | **WAF_CHALLENGE**：同款滑块验证页 |

结构化结论行（脚本 stdout，未落库）：
```
{"ts":"2026-10-18 19:58:02","mode":"live","entry":"user_timeline",
 "url":"https://xueqiu.com/v4/statuses/user_timeline.json?user_id=9222060866&count=5&page=1",
 "http":200,"verdict":"WAF_CHALLENGE","detail":"marker='访问验证' ...","requests":2}
```

### 今晚初步印象（供明晨定谳参考，非定谳）
1. **无头 Playwright 过不了雪球滑块验证**——user_timeline 与个股页均滑块拦，
   与一期 requests 带 cookie 被拦结论一致，WAF 形态从 renderData 换成人机滑块。
2. 但**首页 xueqiu.com/ 真浏览器可过**（两次 warmup 均 PASS），说明 WAF 是
   分路径拦（首页放行、深页/JSON API 人机验证）。
3. 明晨候选路径：hot 入口还没实测过（预算用尽）；headed 模式（headless=False）
   或持久化用户数据目录+人工过一次滑块后复用会话，是绕滑块的仅存正经路径。
