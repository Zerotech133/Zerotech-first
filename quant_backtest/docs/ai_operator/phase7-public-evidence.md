## 临时休市与日历变更检索

本轮获取时点详见逐件 receipt（2026-10-07 UTC），检索方法和结果限定如下：

3. 两次 Bing 查询（交易规则及注册制首日）返回不相关结果；百度首日查询返回227字节空壳，均未提供有效事实证据。官方站内搜索首批主板的 HTML 为动态空壳，本轮只保存界面与脚本，未取得搜索结果，不能把界面“0条”当成无事件结论。停止扩大开放式搜集。

因此本轮没有发现可以归档的目标期间临时全市场休市/日历变更材料，但该结论只适用于上述已查看列表与查询。未证明此类公告不存在，未证明年度公告能完整解释455天，未完成历史公告全集搜索；参考日历应保留规则生效佐证和临时公告完整性缺口，不能用存量Tushare日历消除这些缺口。
