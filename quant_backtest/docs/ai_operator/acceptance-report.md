## 接受的边界

- SQLite 只读访问可能创建协调附属文件；保证不写业务、不初始化不存在的 DB，并读取活跃 WAL。
- 经验检索按当前审核集合与 available_at 过滤；完整审批状态历史回放需后续审批版本事件。
- JSONL 是事件视图，不是包含所有表的完整备份；完整备份须使用 SQLite backup API。
- 目录核查是前后文件身份核对，不提供操作系统级原子快照。
- 完整导出期间持有写锁；大规模数据后需实测调整。本批没有声称达到决策 P95 <100ms。
- 库结构冻结，额外对象或手工改写 DDL 会被拒绝；后续表扩展须显式版本迁移。
- 包 verified 只表示本地支持的完整性检查；schema_verified 和 production_eligible 始终 false。两个真实 ZIP 尚未取得，上游 Schema、规则 evidence 和结构算法未验收。
