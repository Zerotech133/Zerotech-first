## verdict

- **推荐主源：`akshare`** — 免 token、社区维护活跃；需网络且接口偶发变动
- 备选链：tushare

## 实测结论

- **tdx_local 数据未就位（解析器已就绪）**：`parse_tdx_day` 纯 stdlib 解析 + 13 测试绿；当前 C:/项目/new_tdx64 的 vipdoc/*/lday 无 .day 文件（通达信客户端未执行盘后下载）。在客户端「系统→盘后数据下载」跑一次后重跑本探针，即按优先级自动转为主源。
  - 原因：sh600519: 文件缺失 C:\项目\new_tdx64\vipdoc\sh\lday\sh600519.day；sz000001: 文件缺失 C:\项目\new_tdx64\vipdoc\sz\lday\sz000001.day
- **akshare：可用**：日K `stock_zh_a_daily` 可用；实时快照 `stock_bid_ask_em` 失败（RemoteDisconnected，东财单股盘口端点连不上；实时口径可改试 stock_zh_a_spot_em 全表）。
- **tushare：可用**：Pro daily 可用（token=.env.local XT_DATA_KEY），延迟 484ms；实时快照 ts.realtime_quote 失败（需先 `tushare.set_token` 本地落凭证后再试）。
- **短期建议**：tdx_local 数据未就位期间，日K 以 `tushare` 为主（实测 484ms，本次最快）、`akshare` 为备；实时快照两源端点本次均失败，接入前需小修（tushare 先 `tushare.set_token` 落本地凭证 / akshare 改试 `stock_zh_a_spot_em` 全表取行）。通达信客户端完成盘后下载并重跑本探针通过后，按优先级切回 tdx_local 主源。

## 与 xq_quote_snap 字段对齐映射

| xq_quote_snap 字段 | tdx_local | akshare | tushare |
|---|---|---|---|
| symbol | 文件名 sh/sz+code | symbol 列(sh600519) | ts_code(600519.SH) |
| ts_code | 由文件名推导 | norm_symbol 映射 | 原生 ts_code |
| current | close(日频，实时性受限) | stock_bid_ask_em 最新 | realtime_quote price |
| percent/chg | 与前一 close 差分自算 | daily 涨跌幅自算 / spot pct | daily pct_chg |
| volume | vol(股) | volume | vol(手) |
| amount | amount(元) | amount | amount(千元) |
| pe/pb | 无 | stock_zh_a_spot_em 有 | daily_basic(需积分) |
| market_capital | 无 | stock_zh_a_spot_em 总市值 | daily_basic total_mv |
| trade_date | 记录头 date(i32) | date 列 | trade_date |
| timestamp | 无(日频) | 快照抓取时刻 | realtime_quote time |

## 建议接入方案

1. **解析器**：`parse_tdx_day(path, limit=20) -> list[dict]`（tools/xq_quote_alt_probe.py，纯 stdlib struct，零依赖），正式接入时上移为独立模块 `tdx_day_reader.py` 并配 OHLC 自洽校验。
2. **更新频率**：tdx_local 日频（每日 17:00 后客户端盘后下载后触发同步）；
   akshare/tushare 作备选时：日K 盘后一次 + 快照盘中 1~5 分钟轮询。
3. **切换开关**：行情读取层增加 source 路由（tdx_local → akshare → tushare → xq 原源恢复），manifest 增加 `quote_source` 状态位，消费端（情绪×行情闭环）无感。
4. **已知限制**：tdx_local 为日频、无 pe/pb/市值字段，快照类消费（xq_quote_snap 的 current/percent 实时口径）降级为 T+0 收盘口径，
   盘中实时性由 akshare/tushare 新浪源补位。
