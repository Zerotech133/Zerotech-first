## 二、功效提升估算（为什么值得）

一年窗三买 n≈1163，检测 +20bp 笔均超额功效约 50%；三年窗 n≈3500（按
信号密度不变外推），同效应量功效升至 ~90%——**今天 bei24/tbe24 的
|t|<0.8 结论在三年窗下若仍不显著，就基本可以盖棺**；反之若变显著，
说明一年窗一直在拿放大镜找大象。两种结果都有价值。

## 四、风险与注意

1. **早年宇宙偏差是特性不是缺陷**：2023 年用当时存在的票（PIT 正确），
   但与现在 5170 宇宙的对比要分年报告，不能混算。
2. **ST/退市幸存者偏差**：hist_st（K-STOCK-311）已上线全窗剔除，三年窗
   自动生效；退市票 parquet 已含（5817>5170 的差值部分即含退市/ST）。
3. **regime 门在早年窗的行为**：cap_mode=regime_8050 依赖的池指数净值
   三年窗才够 60 日均线预热——回测引擎的 ma60 需窗口前 60 日数据，
   2023-10 起点正好满足。
4. **时长预算**：全市场三年扫 ~11 分钟（16 workers）；一年窗影子台账
   不受影响（d0 滚动一年逻辑独立）。
