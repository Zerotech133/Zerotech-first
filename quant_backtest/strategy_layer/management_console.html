适配原理：数据层是策略无关的统一插座

任何选股策略（缠论、图谱、机器学习、LLM、人工经验）只要能产出统一 Signal，就能挂进同一条链路——数据、情报、置信度三层完全复用，策略只写自己的翻译器（Adapter）。这就是"不断融合其他方案"的结构性保证：新方案接入零改主干。

StrategyAdapter 契约（接入方只需实现这两个方法）

# 策略侧唯一义务：实现 Protocol + 产出 frozen Signal
class StrategyAdapter(Protocol):
    def available(trade_date) -> bool: ...
    def generate(trade_date) -> list[Signal]: ...

@dataclass(frozen=True)
class Signal:
    symbol: str        # 000026.SZ
    action: str        # buy / sell / hold / watch
    score: float       # 策略原始分
    confidence: float  # 0~1 置信度
    rationale: str     # 人话依据（前端悬浮展示）
    strategy: str     # adapter id
    trade_date: str   # YYYYMMDD

Registry 负责：发现 / 启停 / 权重 / top-N 截断（防排序型策略全市场灌库）。

置信度三规则（异构信号统一标尺）

① 融合增益

双源同向 ×1.15（封顶 1.0）· 冲突 ×0.7——多策略互证自动加分

② 时间衰减

半衰期：quote 4h · news 24h · fundamental 168h · kg 720h，下限 0.1——旧情报自动降温

③ 事故惩罚

×(1−p)——负面事件直接扣减血缘置信度

data ─溯源→ information ─衰减/增益→ intelligence ─→ confidence ∈ [0.1, 1.0]

融合公式与流向

combined_score = Σ ( weight_i × conf_i × score_i )  →  组合动作 = 多数派 · 分歧标记 = 动作不一致 · 存 strategy.signals_combined（PK: trade_date+symbol，重跑幂等 upsert）

反馈与进化（P4 权重进化器数据源）

· 显式通道：多策略页签逐策略「采纳/驳回/静默」→ strategy.feedback
· 隐式通道：各策略贡献分 vs 次交易日收益（后复权基准）
· 进化器：WeightUpdater 每周日 20:00 运行，EWMA α=0.3 平滑，当前处于影子期（dry-run）——只出建议表不动权重，数据满窗后切换 --apply

feedback + 次日收益 → target = 0.5·norm(ret)+0.5·norm(fb) → EWMA → clamp[0.1,0.7] → weights
