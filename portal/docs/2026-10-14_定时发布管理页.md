## 功能

| 功能 | 说明 |
|------|------|
| 定时管理 | 页面添加/删除 HH:MM 时间点（正则校验），启停调度，即改即生效 |
| 到点执行 | 15s tick 精确匹配 + 当日去重（fired 键，保留 60 条），工作线程跑 `publish_watchdog.inspect()`（= 一键链 + 飞书红/绿卡 + 旗标全逻辑） |
| 立即巡检 | 页面按钮 / `POST /api/act {"action":"run_now"}`，`_run_lock` 串行防重入 |
| 状态总览 | 调度器心跳、下次触发时间、最近巡检结果（trigger/rc/耗时）、滞后横幅（含 mismatched 文件与处置指令）、看门狗日志尾 15 行 |
| API | `GET /api/state`、`GET /health`、`POST /api/act`（add/remove/toggle/run_now） |
