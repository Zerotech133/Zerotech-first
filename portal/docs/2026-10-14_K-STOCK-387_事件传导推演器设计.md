## 一、概念模型（口述 → 结构化）

用户原始表述：出一个公告 → 回放公告以后发生的所有事情（量能/K线/缠论/游资上榜）→ 反推公告前是否已满足某些技术形态（1买2买3买 / 1卖2卖3卖）→ 这叫事件驱动；并可抓东方财富/雪球评论作舆情源。

### A. 正向传导（事件 → 后果全要素回放）

以某条公告 T0 为锚，对齐回放 T0 后 N 日（建议 20 交易日）五轨时序：

| 轨 | 要素 | 判定 |
|---|---|---|
| 1 | 价格 K 线 | T0 前后涨跌、缺口、异动日标注 |
| 2 | 量能 | 量比 = 当日量/前 5 日均量（385 配方），≥2 放量 / ≤0.6 缩量 |
| 3 | 缠论结构 | 1买/2买/3买、1卖/2卖/3卖 标记（chanlun 口径） |
| 4 | 龙虎榜 | 上榜日 + 席位性质（游资/机构/量化）+ 差额 + 穿透 |
| 5 | 股吧舆情 | 恐慌/乐观日曲线 + 词云重心漂移 |

输出 = 一张「事件后剧本」画布（T0 竖线 + 五轨对齐）。

### B. 逆向归纳（前兆 → 事件统计指纹）

取同类事件历史样本池（如同类公告近 1 年全部样本），统计 T0 前 M 日（建议 10 日）各前兆特征发生率：

- 量能异动率（前 10 日出现 ≥2× 量比的样本占比）；
- 缠论结构成熟度（T0 时点处于二买/三买确认态的占比）；
- 席位前兆（T0 前已有游资上榜的占比）；
- 舆情前兆（恐慌→乐观翻转提前天数）。

输出 = 该类事件的「前兆指纹表」——回答"公告前去推演它是否满足了什么理论"。指纹命中 → 预警（P2）。

- 个股讨论流：`/query/v1/symbol/search/status?symbol=xxx&sort=time`（P2 舆情主源）

### 探针复核结果（10-15 04:22 实测·K-STOCK-395）

游客态 Playwright 会话三轮实测，结论比评级节预判更细：

| 端点 | 结果 | 判定 |
|---|---|---|
| `stock.xueqiu.com/v5/stock/quote.json` | **PASS**——游客 token 直打 requests 出实数据（SZ000993 现价 18.75） | 雪球**行情**数据面匿名可得 |
| `xueqiu.com/query/v1/symbol/search/status`（讨论流·舆情主源） | requests 直打=WAF JS 挑战；**浏览器级会话内 fetch 仍吃挑战**（该端点有专属 WAF 规则，挑战 JS 在 fetch 通道不执行）；个股页自身也未触发该 XHR | 舆情端点**登录态强制**，requests 死路，浏览器会话也有滑块风险 |
| `statuses/comments.json` | 因②无首条 id 未测 | 同②域，同口径 |

**关键事实**：
1. `xq_a_token` 只从**首页路径**发（个股页不发），且必须真浏览器过 WAF（curl/requests 四路全空已证）；游客 token 为会话级（无 expires），**每次采集须 Playwright 现种**——不能像登录 token 一样存 30 天复用；
2. 凌晨连打多轮后触发**滑块人机验证**——WAF 频控真实存在且惩罚敏感，采集节奏必须限流（探针随即收口未再重试）；
3. 游客 token 对 stock 域数据端点有效，主域舆情端点不行。

**⇒ 评级修订（叠加原评级节）**：
- 雪球**行情类**（quote/F10）＝「游客态可白嫖」：Playwright 每次现种 token → requests 打 stock 域，零登录运维；适合低频日频采集；
- 雪球**舆情类**（讨论流/评论）＝维持「登录态强制·半开放」：稳定路径仍＝老田浏览器导 `xq_a_token`（登录态，~30 天有效可持久复用），配合严格限流；浏览器级会话兜底仍有滑块不确定性；
- **P2 落点微调**：舆情主源东财不变；雪球补充源若只取行情/情绪面数据（如热度、讨论数计数），走游客态路径零运维即可；若要抓讨论正文，再走登录 token 通道。
