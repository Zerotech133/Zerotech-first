## 一、概念模型（口述 → 结构化）

用户原始表述：出一个公告 → 回放公告以后发生的所有事情（量能/K线/缠论/游资上榜）→ 反推公告前是否已满足某些技术形态（1买2买3买 / 1卖2卖3卖）→ 这叫事件驱动；并可抓东方财富/雪球评论作舆情源。

### A. 正向传导（事件 → 后果全要素回放）

以某条公告 T0 为锚，对齐回放 T0 后 N 日（建议 20 交易日）五轨时序：

| 轨 | 要素 | 判定 |
|---|---|---|
| 1 | 价格 K 线 | T0 前后涨跌、缺口、异动日标注 |
| 2 | 量能 | 量比 = 当日量/前 5 日均量（385 配方），≥2 放量 / ≤0.6 缩量 |
| 3 | 缠论结构 | 1买/2买/3买、1卖/2卖/3卖 标记（chanlun 口径） |
| 4 | 龙虎榜 | 上榜日 + 席位性质（游资/机构/量化）+ 差额 + 穿透 |
| 5 | 股吧舆情 | 恐慌/乐观日曲线 + 词云重心漂移 |

输出 = 一张「事件后剧本」画布（T0 竖线 + 五轨对齐）。

### B. 逆向归纳（前兆 → 事件统计指纹）

取同类事件历史样本池（如同类公告近 1 年全部样本），统计 T0 前 M 日（建议 10 日）各前兆特征发生率：

- 量能异动率（前 10 日出现 ≥2× 量比的样本占比）；
- 缠论结构成熟度（T0 时点处于二买/三买确认态的占比）；
- 席位前兆（T0 前已有游资上榜的占比）；
- 舆情前兆（恐慌→乐观翻转提前天数）。

输出 = 该类事件的「前兆指纹表」——回答"公告前去推演它是否满足了什么理论"。指纹命中 → 预警（P2）。

## 二点五、C 轴：产业链/商品价格传导（10-14 16:58 老田扩展）

### 传导链模型（三层）

```
源头层：商品期货（铜/铝/锂…）· 海外龙头事件（英伟达）· 政策监管
   ↓

   ↓
映射层：概念板块 → 成分个股 → 股价联动验证（K35 三线联动五信号现成）
```

**样例链（老田给出）**：美国铜期货 ↑ → 散热器铜连接管涨价预期 → 铜缆/散热概念成分股 → 联动验证（概念指数 vs 个股超额）。

### 雪球 —— 补充源（🟡 需 token 运维的半开放源）

雪球**无官方公开 API**（开放平台已下线），实际可用的是网页端非官方接口，评级为「需 token 运维的半开放源」。

**实测证据（10-15 03:41 三连探针·curl）**：

| 探针 | 结果 |
|---|---|
| `GET xueqiu.com/` 首页 | HTTP 200，仅种阿里云 WAF `acw_tc`，**不种 `xq_a_token`** |
| `stock.xueqiu.com/v5/stock/quote.json?symbol=SZ000993` | `error_code 400016`「请重新登录」——数据端点要 token |
| `xueqiu.com/query/v1/symbol/search/status?symbol=SZ000993&sort=time`（个股讨论流） | 阿里云 WAF **JS 挑战页**拦截（curl/requests 直打不动） |

**结论**：早年「requests.Session 空手 GET 首页白嫖 token」配方**已失效**；带有效 `xq_a_token` + UA + 合理频率时数据端点正常出 JSON，WAF 主要拦未带 token 的散请求。

**对 387 有用的端点**（带 token 时）：
- 个股讨论流：`/query/v1/symbol/search/status?symbol=xxx&sort=time`（P2 舆情主源）
- 评论树：`/statuses/comments.json?id=<帖子id>`
- 行情：`/v5/stock/quote.json`；F10：`/v5/stock/f10/cn/...`

**运维要点（拍板口径）**：
1. token 来源＝浏览器登录雪球 → F12 复制 `xq_a_token`（有效期约 30 天，续登续期）→ **人工 ~30 天一轮续期**，登记进运维台账；
2. **频控自律**：低频、单股、本地缓存（风险节 #2 既有约束），WAF 在看着；
3. 落地方案＝**最轻方案：浏览器导 token + 请求头直打**；不上 Playwright 无头浏览器种 cookie（重，不值得为舆情上）；
4. 现成封装参考：pysnowball / pysnowballplus / PyPI xueqiu_api（均要求自带 token，佐证无匿名通道）。

**⇒ 分期落点**：P0 舆情轨＝东财 guba（零成本）；P2 雪球接入按上述半开放源口径执行，接入前先做一次带 token 的手工探针复核（token 失效周期与 WAF 频控阈值以实测为准）。
