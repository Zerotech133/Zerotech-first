# 知识库 × 飞书联动（KM Hub）

日期：2026-10-14 ｜ 服务：`portal/km_feishu_hub.py`（127.0.0.1:8096，零第三方依赖）

## 需求与实现

用户需求：知识管理库 → 飞书机器人 → 群 → 定时推送；每日统计各库新增/发送条数；统计展示与快速分类。

实现形态（复用 8095 调度器已验证架构）：

| 能力 | 实现 |
|---|---|
| 库管理 | 页面增删改：库名 + 目录路径 + 分类方式 + 发送时间 + 目标 + 扩展名过滤 |
| 目标映射 | 目标注册表 = `news_collector/news_config.json` 的 `push_targets`（个人/家人群/量化群，单一事实源）+ `km_config.extra_targets` 追加新群 |
| 定时推送 | 每库独立 `times`（HH:MM），15s tick + 当日去重；到点扫描增量 → 摘要卡 → `feishu_card_v2.send_card` 按 `receive_id_type` 发群/个人 |
| 增量扫描 | 快照（`work/km_snapshots/<md5(库名)>.json`：relpath→[mtime,size]）对比出 新增/更新/移除；首扫作基线记 0；`max_files` 防爆（默认 2 万） |
| 快速分类 | `category_by`: `ext`（扩展名）或 `subdir`（一级子目录），卡片与统计均带分类计数 |
| 每日统计 | `work/km_stats.jsonl` 每次推送一行（added/changed/total/sent_ok/sent_targets/error）；页面聚合今日统计 + 近 14 天趋势（纯 CSS 柱图） |
| 防打扰 | `skip_empty`（默认开）：定时触发且无变更 → 只记日志不发卡；手动推送恒发 |

- 增量判定基于 mtime+size（非内容 hash）：同尺寸 touch 会计为"更新"，属可接受噪声
