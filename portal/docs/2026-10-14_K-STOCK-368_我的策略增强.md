## 1. 交付内容

### ① 「编辑后保存」显式入口（候选 #2 的核心缺口）

359 已让 NL 参数墙可编辑，但「我的策略」卡面板只能重跑/删除——用户改了参数没法存回。本次补齐：

- **后端 upsert**：`/api/my_strategies` save 分支支持带 `id` 更新（保留原 id 与创建语义，`ts` 追加「编辑」标记）；不存在的 id fail-closed 拒绝（`{"ok":false,"error":"策略不存在"}`）
- **面板参数可编辑**：`exec-mystrat` 的只读 chips 升级为行内 input（白名单键渲染，与 359 nl-edit 同款）；数值键 min_score/slot_pct/top_n 自动转 Number
- **「💾 保存修改」按钮**：取面板当前值 → upsert → 刷新卡墙并重新选中该卡；prompt 预填原策略名
- **重跑语义升级**：`myRunBtn` 改用面板当前编辑值——改了没保存也能先试跑（try-before-save）

### ② 分享 / 导出

- **「📤 导出」**：Blob 下载 `{name,params,note,exported_from:'零界门户',ver:1}.json`，文件名非法字符清洗
- **「🔗 复制分享」**：策略名+参数 JSON 一键复制剪贴板（`navigator.clipboard`，未授权降级 prompt 手动复制）
- 导入端（别人拿到 JSON 存回自己的策略）挂账后续——分享动线先闭环「导出+复制」

## 3. 判例沉淀

🔴 **E2E 隐藏页签陷阱**：`tabpanel d=none` 时内联 style 正常（`display:block`）但 playwright `isVisible`/`fill` 判不可见——e2e 操作非默认页签内的元素，必须先 `gotoTab('strategy')`。产品无 bug（真实用户必在页签内操作），纯脚本缺陷；决定性证据=祖先链 computed style 检查（`#tab-strategy.tabpanel d=none`）。

🔴 **Node http 模块直连 8091 必须 Content-Length**：`BaseHTTPRequestHandler` 不读 chunked body，缺 Content-Length 时服务端拿不到 POST 数据（表面 200 实则空请求）——直连脚本用 urllib（自动 Content-Length）或手动补头。
