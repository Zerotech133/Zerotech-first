02P1-3 · 信号注册名盘点（0.5 阶段，随 K-ORG-199 先行）

  1. 盘点途径：① czsc.parse_signal_doc 遍历内置信号文档清单；② 直接解包 wheel 内 Rust crate 的信号注册表（czsc.*.__doc__ / docs/examples/05_signals.py 同款姿势）；③ 全量 get_signals_config 探测「一买」候选命名（如 cxt_first_buy_V221126、一买V221126、cxt_bi_turn_V221126 等变体）。
  2. 输出三态：可用（给出可直接用的信号串）/ 换名（给出正确注册名与等价串）/ 弃用（1.0.2 未注册该信号，记录出处防止后续误引）。
  3. 顺带产出：信号串 → 注册名映射表落 C:\Temp\czsc_eval\signal_registry.json，供 P1-1 与后续 Phase 直接复用。

03P1-1 · 无偏样本复跑（K-ORG-199 主体验收物）

抽样框（固定 seed 可复现）

  • 总体：本地 5600 票 parquet 全集；随机 100 票，random.Random(42).sample，抽样名单落 unbiased_100.json 归档；
  • 排除项：P0 十票（605388/603188/605266/000159/600748/603639/601727/688695/300753/000001，偏置源）；窗口 < 400 根的票（保证 sdt 预热 120 + T+20 对账余量）；
  • 不足 100 时按序补抽（同 seed 序），最终名单写入报告附录。

跑批内容（每票）

  1. 结构层：CZSC(bars, max_bi_num=500)，落笔/中枢计数与 BI 衍生特征（power/slope/rsq/angle/acceleration + zz_rel=中枢相对位置）；
  2. 信号层：3+1 个原生信号（含 P1-3 结论），generate_czsc_signals(df=True)，状态翻转首日为事件；
  3. 对账层：T+5/10/20 前向收益（pct_chg 复权链，与学习环同口径）；
  4. 特征侧：事件日截面特征 vs T+10 收益的 RankIC（整体 + 前/后半窗分漂）；信号侧：各信号 win/avg/p10 与同票基准（同票全部 CZSC 事件池 + 我方 L2 同票若有）。

产出与判定

  • 对照报告（HTML，沿用 P0 风格）：抽样名单、3+1 信号统计、特征 RankIC 表、G1 判定结论；
  • 数据产物：unbiased_events.csv / unbiased_feats.csv（沙箱内，报告引用）；
  • G1 判定按 §1 预注册判据执行，判定过程与数字全部写入报告，不允许跑完再改门槛。

04P1-2 · 影子旁路特征管道（K-ORG-200，开发变更）

架构决策：旁路（选项 B），不内嵌 L1

生产 ledger.jsonl 是 append-only 契约（K-ORG-195 S2 曾因行指纹变化一次性重记 8 行）。旁路设计零侵入：独立脚本、独立 venv、独立影子文件，主仓代码只读产物。若选内嵌（选项 A）需改 L1 采集函数并引入 czsc 硬依赖 + 主环境 pandas 升级风险，P0 已证没必要。

件落点内容

② 包装与部署czsc_shadow_task.ps1 + deploy_czsc_shadow.ps1照 JevDriftDaily / GuojiaDaily 幂等部署先例；计划任务 CzscShadowDaily 每日 19:55（排在 ChanlunLearnDaily 19:40 之后，消费其当日产出）
