图例与边界

· 本页只读投影，零写操作；购买、续费、退订请通过飞书联系（M3 收银台上线后在本页接入）。
· 字段最小化：/api/subscription/status 只回当前档位（plan_id / plan_name / start / end / status）与本人当日额度余量，open_id 仅回掩码（如 ou_abcd**），金额与账本内部判定细节不在响应内。
· 额度余量为当日已放行计数（entitlement_log 投影），非实时闸门计数；「不限额」指档位未设 daily_quota。
· 剩余天数由本页按 start / end 在前端按日历日自算（纯日期按当日结束计，与到期提醒同口径），响应内不含任何派生的剩余天数字段——状态端点字段保持最小化。
· 读取失败时本页降级为说明文案，不显示静态兜底数据；error 响应原样透出，不修饰。
