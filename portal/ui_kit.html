使用约束

  • 禁用原始 hex / inline style；颜色走 tokens。
  • 按钮必须有文字或 aria-label；触达 ≥ 40px（移动 44px）。
  • 加载态用 skeleton，空态给下一步，错误态给原因。
  • UI Kit 只做基础原语；业务页优先复用，不复制样式。
