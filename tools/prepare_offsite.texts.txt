## 一、上传什么

**9 个文件，一个都不能少**（6 个产物 + 3 个清单），文件名保持原样：

| # | 文件 | 字节数 | 说明 |
|---|---|---|---|
{ROWS_TABLE}
| - | `SHA256SUMS.txt` | 见文件 | 标准 sha256sum 格式，落地端整包校验用 |
| - | `{DATE}-offsite.txt` | 见文件 | 人读清单：名称 + 字节数 + sha256 + 上传后核对步骤 |
| - | `README-上传说明.md` | 见文件 | 本文件 |

- 上传时**不要改名、不要加日期后缀、不要让网盘"智能压缩/改名去重"**——`SHA256SUMS.txt`
  里写死了文件名和哈希，改一个名，整包校验就废了。
- 落地端建议（任选其一）：
  - **对象存储**（阿里云 OSS / 腾讯 COS / AWS S3）：单独建一个**私有** bucket，
    路径 `vault/{DATE}/`，关掉公共读。
  - **私有 Git 仓**：`git bundle` 能被 git 直接 clone；683 MB 需要走 LFS 或支持大文件的
    私有托管，普通托管平台多半拒收。
  - **网盘**：只认客户端原始上传；网页版容易改名、加 `(1)` 后缀。
- 落地端**不要**共享、**不要**开公开链接——包里是全部代码历史和治理文档。

## 二、怎么校验

校验必须在**落地端**做（或把文件从落地端下载回来再做）。在源机器上校验等于自己证明自己。

### 方式 A：Windows（PowerShell 5.1，本机同款）

```powershell
cd <落地端目录>
Get-Content .\SHA256SUMS.txt | ForEach-Object {
    if ($_ -match '^([0-9a-f]{64})\s+(.+)$') {
        $want = $Matches[1]; $f = $Matches[2]
        $got = (Get-FileHash -LiteralPath $f -Algorithm SHA256).Hash.ToLower()
        if ($got -eq $want) { "OK   $f" } else { "FAIL $f" }
    }
}
```

### 方式 B：Linux / WSL / git-bash

```bash
cd <落地端目录>
sha256sum -c SHA256SUMS.txt      # 6 行全 OK 才算过
```

### 判定标准

- **6 行全 OK** → 校验通过。
- 出现 `FAILED` / `FAIL` → 该文件字节坏了（多半是没传完，或网盘改过），**重传该文件**，
  不要"就差一点"。
- 先比字节数、再比哈希：字节数不对就不用算哈希了（`{DATE}-offsite.txt` 里有逐项字节数）。
- `SHA256SUMS.txt` 是纯 ASCII + LF 换行，Windows/Linux 都能直接用。

## 三、校验通过后做什么

1. **记账**：打开 `_vault\README.md`，把「异地副本」那一行的"没有"改成
   `对象存储 OSS://<bucket>/vault/{DATE}/ · 上传 <日期> · 6/6 SHA256 通过`。
   不记账 = 三个月后没人知道东西在哪，等于白传。
2. **改掉旧结论**：README 里"盘坏即全丢"的说明同步更新。留着不改比不写更糟——
   下一次危机时你会按旧结论做错决定。
3. **下次照做**：每次备份（`tools\backup_bundles.ps1`）之后跑一次
   `tools\prepare_offsite.ps1`，再走一遍这三步。建议每周一次，和备份同一天。
4. **每季度做一次还原演练**：把 bundle 从落地端下载回来，
   `git clone --bare <bundle> <临时目录>` 再 `git -C <临时目录> fsck --no-progress`，
   提交数与 HEAD 要和源仓对得上。只验证"文件在"、不验证"能用"的异地备份，
   和没有备份差不多。

## 常见坑

- **网盘改名**：网页上传会自动加 `(1)`、改扩展名。校验前先看文件名对不对。
- **对象存储的 `Content-MD5` 是 MD5**，不是 SHA256，别拿它跟 `SHA256SUMS.txt` 比。
- **本包没有加密**，靠落地端的私有权限兜底。真要加密，先用 `age` / `7z -p` 包一层再传，
  但那样哈希对不上，需要另立清单（别在同一个目录里混两种格式）。
- **上传中断的文件看起来"在"**，字节数会少一截。所以第一步永远是比字节数。
- **别把 `_offsite` 当异地副本**：它和 `_vault` 在同一块盘，只是上传前的暂存区。

## 这个目录不是什么

- **不是异地副本**：上传完成并校验通过之前，异地副本数量仍然是 **0**。
- **不是加密包**：没做加密，落地端务必私有。
- **不是增量**：每次都是全量 6 个产物，合计 {MIB} MiB。
- **不是自动上传**：整个过程没有任何账号、cookie、token 被使用或保存。
