## 迁移规则

1. 每个 automation 对应本目录一个 md 文件，文件名 `<哨位>_<时间>_<名称>.md`。
2. automation 定义侧 prompt 只写一句话：**「读 `tools/automation_prompts/<文件名>` 并按其执行」**（绝对路径以仓库根为锚）。
3. 改 prompt = 改本目录文件 + git 提交（走 K-STOCK 编号），调度平台侧不动。
4. 尚未迁移的 automation 在下表登记，逐步迁移；**改动频率高的优先迁**。
