## 二、WA 智能接线波（W1.4 后即启，建议 L1→L3 先行）

> 原则（方案 v1 §二）：**不建第二调用层**——一律复用军团 `agent_platform/engine/llm.py`（多模型路由+降级三态）；中台只加接线层，智能住在 agent_platform。

### 2.1 L1 入向意图层（最高优先）

**改动点**：`portal/inbound_gateway.py` `classify()`（L253-268）——unclear/长文本分支接 LLM。

**设计**：
```python
# inbound_gateway.py 接线（伪码）
# 规则先行：指令/代码/URL 不过 LLM（防"假智能"与成本浪费）
result = classify_regex(msg)            # 既有四条正则
if result.kind in ("unclear", "long_text"):
    llm = llm_chat("qwen3.5:9b", INTENT_PROMPT, timeout=3s)  # engine/llm.py
    if llm.ok:
        result = parse_intent(llm.text)  # {intent, entities, confidence}
    else:
        result.kind = "unclear"          # 降级回落正则基线，链路不断
```
**意图词表 v0**：查询 / 投喂 / 调整 / 咨询 / 投诉（WA.1 定稿）。
**验收判据**（拒绝表面）：真实消息模型往返留痕；unclear 率对比基线下降；**降级实测**（停 Ollama → 自动回正则，链路不断）；50 条真实历史消息离线评测混淆矩阵 ≥ 基线。

### 2.2 L3 出向智能摘要

**改动点**：`portal/feishu_card_v2.py`（卡片渲染）+ 出向发送路径——日报/预警卡加 9b 生成段。

**设计**：模板结构保留（标题/字段/链接），正文摘要段走 `llm_chat(9b)`；**llm_ok 标记**进卡片 JSON（运维可查）；llm_ok=false 回模板字面量（兜底判例已有）。
**验收**：真卡含模型生成段留证；模板兜底路径实测（停 Ollama 发卡成功）。

### 2.3 L2 会话记忆（WA.3，L1 落地后）

**改动点**：`portal/inbound_gateway.py` 新增 session_store（open_id → 近 N 轮窗口），存储复刻军团 checkpoints 模式（sqlite WAL / 文件皆可）。
**验收**：「刚才那只票」代词消解用例绿；请求体留痕证明上下文进了 prompt。

### 2.4 L4 派单通道（WA.4，设计稿并行）

纯文档工位：`agent_platform/bridge_inbox/` 投递协议（中台→军团席位）+ 回执卡模板 v0。不改代码。

### 2.5 L5 诸葛亮咨询位（等 Q12 key）

## 六、贯穿纪律（开发文档级重申）

1. 无单不写码；add 即 commit；单文件不并发编辑；工作树只碰独占文件。
2. 生产变更五要素明批；「继续」≠批准；沉默≠同意。
3. Key/凭据不经对话传输（Key 泄露判例）；10.205.0.118 红线 9。
4. marker 换血一次性 touch。
5. 测试承重：先红后绿、双向变异；收集期 error 不算真红。
6. L1/L3 上线必须含**降级实测**，没有降级实测=未完成（拒绝假智能判例）。
7. 账本/勾稽/提醒/enforce 判定**保持纯工程**，不进 LLM。
