# CnOpenData 数据源：建档结果与接入路线 v1

> 2026-10-21 12:10（北京时间）｜归属：情报板块·数据源档案｜配套档案：`registry.json`（408 条）、`INDEX.md`、`档案总览.html`
>
> **边界**：本路线只做**选源与接入顺序**判断。所有"需采购/需 API Key"条目的合同权利、上游来源合法性均未核验，**未获授权前不得把任何一条当作可用数据源**。档案本身不含数据内容。

## 一、结论先行

1. **408 条已建档**：core 236 / factor 81 / context 91；P0 17、P1 89、P2 171、P3 131。
2. **真正"今天就能接"的只有 22 条免费 OPEN**；357 条需采购、29 条需 API Key。免费那批以指数与评分类为主（经济政策不确定性、数字化转型、新质生产力、社会责任评分、问询函、内幕交易），拿来即用但覆盖面窄。
3. **对雪球主线是坏消息**：其雪球帖子 API 页面明写「**从 2025 年开始采集**，2025 年前数据存在量级限制」。它**解决不了单股全历史（2012 起）**这个核心目标。
4. **追新与历史是两笔不同的采购**：API 强在实时增量、弱在历史深度；直售强在一次性历史、弱在更新（309 条为年度更新）。混在一笔里买，必然一边不够用。

## 二、三条通道，能力完全不同

| 通道 | 条数 | 强项 | 硬伤 | 适用目标 |
|---|---|---|---|---|
| 免费 OPEN | 22 | 零成本、可直接下载 | 覆盖面窄，多为指数/评分 | 因子补强、方法验证 |
| API（Key） | 29 | 实时/增量、字段结构化 | 覆盖起点短（雪球 2025 起；股吧帖近 2 年；股吧回帖仅 7 天窗口） | **追新** |
| 直售批量 | 357 | 长历史、一次性交付 CSV/Stata | 以年度更新为主，不能追新 | **历史纵深、因子回填** |

## 三、对雪球/舆情主线的三个硬结论

1. **雪球 API 不能替代自建历史**。2025 起采集、2025 前量级受限。单股从最新翻到 2012 这条需求，仍然只能靠自建（须雪球授权）或持权方导出。
2. **雪球发帖数据集存在口径矛盾**。「雪球网上市公司个人投资者发帖实时更新数据」标题写"实时更新"，频率字段却是"年度更新"，且不写历史起点。**采购前必须拿到书面的 T+0 增量交付承诺与延迟指标**，否则买回来只是年度快照，对追新无用。
3. **股吧可补历史纵深，但不是雪球**。股吧文本库 1988–2024、发帖 7.78 亿 / 回帖 15.20 亿，是现成的长历史语料；但股吧与雪球用户结构、讨论风格不同，**不能作为同一舆情源合并计算情绪指标**，只能各自建模、分别标注来源。

| 组别 | 条目 | 通道 | 用途判断 |

## 五、接入顺序（按"零成本→高价值"排）

**S0 零成本先跑通（本周可做）**
把 22 条 OPEN 建 manifest、落最小接入样本，验证"下载→解析→入湖→因子"这条链本身通不通。**不涉及任何采购与谈判，只验证工程链路。**

**S1 询价 + 试用 API（需老田点头）**
申请 API Key 试用，只测三件事：①雪球接口 2025 年数据实际完整度；②股吧帖子接口"近 2 年"边界外能否补；③延迟是否支持盘中。用实测结果反推是否值得采购。

**S2 买断历史（S1 之后）**
股吧文本/统计、雪球三库、研报文本。一次性入湖，作为历史纵深与自建库的交叉校验源。

**S3 因子包（与量化板块协同）**
专利、招聘、招投标、违规处罚 + **A股及子公司关联表**。最后一者是主体归一的粘合剂，**单独买任一项都进不了因子管线**，必须打包评估。

## 六、合同必须书面核实的六件事

1. **上游来源合法性**：供应商页面自述雪球数据是"从各上市公司雪球专属页面下方获取"——即抓取所得。必须确认其是否有权向我们转授权，而不是默认"他敢卖就合法"。
2. **允许用途**：内部研究 / 模型训练 / 对外产品 / 再分发，四者权限不同。
3. **存储与二次加工权**：我方落湖、建索引、做特征、长期保存是否允许。
4. **交付节奏与延迟**：T+0？T+1？盘中推送？按"实时更新"标签付款却拿到年度包，是最常见坑。
5. **历史起点与缺口**：书面确认 2025 年前到底有多少、缺哪些股票、缺失率多少。
6. **停止条件与删除义务**：合同终止后已入湖数据是否必须删除——这直接影响我们能不能把它沉淀成长期资产。

## 七、已知缺口（本版档案不完整的地方，如实列出）

- **未全量收录**：专利页共 64 条、工商页 61 条、ESG 页 35 条，本次只保留与个股/事件可映射的子集（专利 16、工商 13、ESG 16）。要全量需再派一轮。
- **年鉴分类仅 4 条**，明显偏少，疑有未挂出条目，无法在不点详情页的前提下确认。
- **`ssgsxxxx-posts` 文档错配**：商店标题与"实时"标签写"上市公司帖子实时数据查询"，正文却是"A股上市公司详细信息查询"且每天更新一次。接入前必须找供方确认真实返回。
- **工商某卡片链接含冗余路径**（`registered-information%2F...`），已按主 slug 归一并在 notes 标注，采购前建议人工点一次确认。
- **api_available 仅 API 商店 29 条为 true**：分类页不标注 API，故直售条目的"有没有对应接口"未逐条核实。
- **量级字段大量"未标注"**：分类页普遍不写数据量，需在询价时向供方索取。
