# 因子升级 v2：从子串匹配到分词打分（含一次自我更正）

> 2026-10-21 15:25｜前置：`S0验收报告.md` §五
> **结论**：链路通、分词已加、缺陷已修；但**正偏不是 bug，是语料属性**。这个指标现在能算、能看，**还不能叫因子**——缺个股映射、可用时点、前瞻检验三件。

## 一、做了什么

在 `sentiment_probe.py`（v1，子串匹配）之上重写为 `sentiment_v2.py`：

| 环节 | v1 | v2 |
|---|---|---|
| 匹配 | `w in text` 子串扫描 | jieba 分词 + 词典词全量 `add_word`，分词后精确匹配 |
| 否定 | 无 | 紧邻前一词若为否定词则翻转极性 |
| 程度 | 无 | 很/非常/极 → ×1.5；略/稍/有点 → ×0.6 |
| 输出 | 情感分 | 情感分 + 强度（命中数/词数）+ 词数 |
| 聚合 | 无 | 按日聚合，产出时间序列 |

产出：`quant_backtest/data/cnopendata/_probe/xq_sentiment_v2.parquet`（逐帖）与 `..._daily.parquet`（按日）。

## 三、三个诊断，其中两个推翻了我的初判

### 诊断一：96% 命中率不是"子串过宽"（自我更正）

S0 报告里我写的是"单字词命中一切导致 96%"。核对命中词后，这个说法**站不住**：

- 积极侧前 15：增长 641、上涨 301、发展 286、机会 278、最大 261、涨 207、成长 200、教育 196、好的 185、欢迎 183
- 消极侧前 15：问题 363、下跌 283、风险 236、跌 157、被动 150、不能 129、下降 121、暴跌 109、大跌 100、亏损 100
- 单字词在命中数中的占比：积极 1.4%、消极 3.9%

也就是说，命中的确实是金融情感词，因为**雪球帖本身就是金融文本**。96% 不是缺陷，是语料性质。原判断已从 S0 报告中改掉。

### 诊断二：正偏来自语料，不来自算法

把否定窗口从 1 加到 3：

| 窗口 | 翻转率 | 均分 |
|---|---|---|
| 1 | 1.7% | +0.3614 |
| 2 | 2.4% | +0.3580 |
| 3 | 2.9% | +0.3562 |

翻转率变化 0.7 倍，均分几乎不动（±0.005）。**说明否定处理对整体极性影响极小**，+0.36 是语料里看多词汇天然占优的结果——雪球散户社区的话语结构如此。

### 诊断三：真缺陷是七词冲突 + 分母太小

1. **七词冲突（已修）**：`不能 / 不足 / 否认 / 毫无 / 缺乏 / 避免 / 难以` 同时出现在否定词表和我自建的消极词典里。若同时参与翻转，"不足"会被翻成积极，属逻辑自相矛盾。v2 改为：**与情感词典重叠时以情感词身份为准，不作否定标记**，生效否定词从 19 降到 12。
2. **分母太小（未解决）**：中位情感分 +0.50、平均命中 4.65 词。短帖只命中 1 个词时，极性非 ±1 即 0，区分度低。这是词典法的结构性上限，不是调参能解决的。

## 四、这个指标现在是什么、不是什么

**是**：一个可复现、可审计、按日可聚合的舆情极性描述统计。能回答"这 771 天里讨论偏正面还是偏负面、哪天异常"。

**不是**：可用于交易的因子。三条硬缺口：

| 缺口 | 现状 | 影响 |
|---|---|---|
| 个股映射 | `target` 是帖子路径 `/{user_id}/{status_id}`，不是股票码；股票码只在分类表 `norm_tickers` 里，且仅覆盖 12% 帖子 | 没法做"个股情绪 → 个股收益" |
| 可用时点 | 旧库无 `available_at`、无 `first_seen_at`，`fetched_at` 会被 REPLACE 覆盖 | 无法做 PIT 回测，任何"历史信号"都可能用了当时拿不到的数据 |
| 前瞻检验 | 未做 | 未经验证的指标只是描述统计，不能进策略 |

## 五、下一步（按依赖排序，均需立单）

1. **情绪×收益检验（前置：个股映射）**：先在 `norm_tickers` 覆盖的 248 只 A 股上，做"当日情绪 → 次日/次周收益"的 IC 与分组检验。**没有这一步，后面都不该做。**
2. **PIT 补齐**：新采集链必须落 `first_seen_at` / `available_at`（属 L3 追新工单范围），旧库缺口只能标 unknown，不许猜填。
3. **词典增强**：加金融领域否定句式（"不及预期""低于预期"）与程度副词表，或换用带权重的情绪词典。当前词典无权重，是精度上限。
