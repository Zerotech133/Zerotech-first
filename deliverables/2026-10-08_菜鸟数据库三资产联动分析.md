## 三、五条核心业务链路（DDL+源码交叉实证）

### ① 策略决策链（AGENT 模式）
`stock_trade_strategy`（三模式：AGENT 纯Agent / MODEL 规则模型 / HYBRID 混合；MODEL 模式带 selection_cron/trade_cron 自调度）
→ `stock_trade_strategy_agent`（trader/selector Agent 绑定+运行 cron）
→ AI 团队分析（`ai_team`→`ai_team_task`→`ai_team_node_execute` 7096 条含辩论日志）喂 LLM
→ `stock_trade_strategy_pool`（选股结果：reason/score/weight/signal_strength/target_price/factor_detail 归因 JSON）
→ `stock_trade_strategy_instruction`（**源头指令**：direction/position/止损止盈价/signal_strength/reason 交易理由/trade_model_id）

### ② MODEL 模式规则链
`stock_trade_selection_model`（RULE/FACTOR/COMPOSITE，universe+rebalance_days+top_n）
+ `stock_trade_model`（buy_rules/sell_rules JSON、止损止盈四型、仓位四法 EQUAL/SIGNAL_WEIGHTED/VOLATILITY/KELLY、max_total 90%/single 20%/max_holdings 10）
→ `backtest_joint_task` → TDX-Trading `/api/backtest/joint`（Python 端撮合：T+1+滑点0.1%+佣金0.03%+印花税0.1%）→ `backtest_result` → 回填 last_backtest_id

### ③ 盯盘触发链（TDX-Trading 上游）
`stock_trade_strategy_condition_order`（breakout/breakdown 价+比例+时间窗+有效交易日）
→ TDX-Trading 盯盘四模型（speed/cond）盘中触发
→ `stock_trade_strategy_signal`（QMT 上报中文信号，reported_by、condition_order_id 关联）
→ 飞书确认（operator_open_id）→ instruction_no 下发

### ④ 分发执行链（Java 编排核心）
`stock_trade_strategy_instruction`（源头）→ distribute（controller 批量转换 fullPosition→position；**已知坑：单条 /create 无转换、返回固定 0L**）
→ `stock_trade_member_instruction`（分发到各绑定账户 23,735 条，策略×会员展开）
→ `stock_trade_member_binding`（策略↔模拟/实盘账户）
→ QMT 执行 → `stock_trade_member_real_order`（6,829 委托，entrust_no upsert、成交/撤单状态、手续费）
→ 收盘上报：`real_asset`（OPEN/CLOSE 总资产）/ `real_position`（持仓明细）→ `real_account_daily`（日快照 FIFO 已实现盈亏）

### ⑤ 绩效快照链
策略层：`strategy_daily`（虚拟市值口径）+ `strategy_stock_daily`（个股级）+ `strategy_trade`（虚拟成交，instruction_id 关联）
会员层：`account_daily`/`position_daily`/`stock_daily`（三表=临界侧 R4/OOS 现有数据源）

## 六、风险与注记

- **租户隔离**：所有业务表带 tenant_id，拉取时按租户过滤（现六表同口径）
- **逻辑删除**：deleted 位普遍存在（tinyint 或 bit 两型混用），/page 默认过滤
- **雪花 ID 陷阱**：ai_chat_conversation AUTO_INCREMENT=1781604279872583680 系雪花 ID 非量级（DDL 统计已识别）
- **bak 表**：simulation/account_daily 各有 20260722/20260811 备份表（历史事故修复产物，账号72/9_33 资金异动事件——见 doc/archive），拉取须排除
- 老田侧记忆：doc/archive/创建指令业务流程分析.md 已记录 5 个已知实现坑（单条 create 无仓位转换/返回 0L/持仓周期默认不一致等）——分析指令数据时须知悉
