# OHAST：上下文引擎 AST 符号检索

- 日期：2026-10-30
- 关联：K-QUANT-20261030-OHAST
- 状态：**已完成并实测**

## 改动

`agent_platform/legion_command/ide_context.py`：

- 新增 Python AST 解析：class / function / method
- `search_symbols(query)`：
  - 先用查询词预筛含关键词的 `.py` 文件
  - 只对命中文件做 AST 解析（避免全仓扫描）
  - 返回 path / name / kind / line / score
- `build_context()`：
  - 新增 `symbols` 字段
  - 在 context 头部注入 `[Python symbols · AST]`
  - 字符预算仍生效
- 文件缓存：按 `path + mtime` 缓存 AST 结果，TTL 120s

## 性能

第一版全仓 AST 扫描：**62s**，不可接受。  
改为预筛后：

```text

```
