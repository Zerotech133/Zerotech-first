# OHLIVE：实时事件 + 停止 + 工单锁

- 日期：2026-10-30
- 工单：K-QUANT-20261030-OHLIVE
- 状态：**已完成并实测**

## 1. 异步 start

```text
POST /api/ide/openhands/start
→ { conversation_id, worktree, model, status:"running" }
```

不再让一个 HTTP 请求阻塞到任务结束。

## 2. 实时 status

```text
GET /api/ide/openhands/status?id=<cid>
```

返回：

- `status`（running/finished/paused/error/...）
- `events`（Action/Observation/Message）
- `terminal`
- 完成后 `reply`

前端每 1.2 秒轮询，过程面板实时追加事件。

## 3. 停止

```text
POST /api/ide/openhands/interrupt
```

- 调 OpenHands `/api/conversations/<cid>/interrupt`
- 状态落到 `paused`
- 前端显示“⏹ 已停止”
- 释放工单锁

## 4. 工单执行锁

锁文件：

```text
C:\legion-worktrees\.oh-locks\<TID>.lock
```

- 原子 `O_CREAT|O_EXCL`
- owner + 30min TTL
- 同一工单已有任务时返回 `oh_lock_busy`
- 完成/停止后释放
