# Trend Template v1.1 组合回测 · 回执

## 一、背景
v1.1 目标：股票池过滤 + 退出规则 + RS 双口径（外部回测提示「股票池/退出比入场更重要」）。

## 二、结果（2019-2026，20 仓×5%，成本 0.15% 单边）
| 维度 | 发现 |
|---|---|
| **RS 口径** | **R_252 -7.45%** vs 近似 -6.53% → 口径决定成败 |
| **退出规则** | **8% 固定止损最优**；200 日线退出 CAGR -20.96%、MDD -91.41%（A 股 whipsaw，与 TSX 结论相反） |
| 股票池 | 三档流动性过滤结果完全相同 → TT 候选上不 binding |
| **最佳组合** | U0_all/R_252/E_8：CAGR **14.14%**、MDD **-48.68%**、波动 32.99%、平均仓位 81.3%、交易 197 次 |
| 对比市场 | 市场等权 CAGR≈13.4% → **风险调整后不通过** |

## 三、结论
1. **TT 单用不适合 A 股实盘**（CAGR 与市场持平、MDD -49%、收益集中在 2019/2020/2025）；
2. **规则不可跨市场照搬**：TSX 25 年「破 200 日线」最优，A 股 whipsaw 反而 -21%/年、-91% MDD；
3. RS 口径影响巨大：R_252 明显优于近似口径 → 对外能力口径需标注（当前 v1 用近似，需说明局限）；
4. 流动性过滤未区分 → 股票池结论无法在 A 股验证（daily_basic 早期缺失）。
