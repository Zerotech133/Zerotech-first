## 2. 三域收件人模型（`push_targets`）

域常量与 `portal/notify_contracts.DOMAINS`（`owner`/`ops`/`customer`）**逐字对齐**——本模块**只镜像常量、不 import portal**（保 stdlib-only 与零跨域耦合）。

| 域 | 常量 | 对象 | 模板白名单 | 频控 | 静默窗 critical 豁免 | 订阅闸门 |
|---|---|---|---|---|---|---|
| 本人 | `owner` | 老田（司马懿汇报线） | 全量（`sima_report`/`alert`/`ticket`） | **免额度**（`daily_limit=null`） | **豁免** | 直通（免订阅） |
| 运维 | `ops` | 内部运维值班 | `alert`/`ticket` | 200/日 | **不豁免** | 直通（内部白名单免订阅） |
| 客户 | `customer` | 订阅用户 | **最小集占位**（`alert`） | 20/日 | **不豁免** | **强制** |

注册表落在 `k_stock/paper/push_targets.json`（可覆盖，覆盖后仍走 `load_targets()` 严格校验）。

### 防绕闸红线（配置层硬拒）

1. **客户域不得降级闸门**：`subscription_required=false` → `load_targets` 显式抛 `push_target_invalid`；
2. **critical 豁免仅本人域**：非 `owner` 域声明 `critical_exempt_silence=true` → 显式抛；
3. **不猜默认收件人**：`resolve_target()` 命中 0 个或多个 → `push_target_unknown`；给了 `domain` 但与实际不符 → `push_target_domain_mismatch`；
4. **模板白名单按域**：客户域收 `sima_report` → `template_not_allowed`。

## 3. 订阅闸门边界（`subscription_gate`）

### 判定口径（立项方案 §5，`_decide_entitlement`）

```
生效 = 状态=生效 AND now∈[起,止] AND 当日额度未耗尽
```

| 输入 `status` | 判定 | `reason_code` |
|---|---|---|
| `unwired`（默认 provider） | **拒** | `subscription_gate_not_implemented` |
| `none` / `not_subscribed` | 拒 | `subscription_not_subscribed` |
| `expired` / 超出 `period` | 拒 | `subscription_expired` |
| 额度耗尽（`used_today >= daily_quota`） | 拒 | `subscription_quota_exhausted` |
| 其他未知状态 | 拒 | `subscription_status_unknown` |
| `active` + 在期内 + 有额度 | **放行** | `delivered_api_accepted` |

### fail-closed 铁律

默认 provider = `UnwiredEntitlementProvider`，判定**恒为 `unwired` → 一律拒绝**。
**绝不「查不到就放行」**——这是本单最重要的一条：客户域在 M2 接线前**结构性不可发**，
不会出现「闸门空转导致误发客户」。

### provider 接口（M2 实现契约）

```python
class EntitlementProvider:
    name: str
    def lookup(self, subject, *, kind: str, now: datetime) -> dict:
        """返回 {"status": "active"|"expired"|"none"|"unwired"|...,
                 "plan_id": str|None, "period": (start_iso, end_iso)|None,
                 "daily_quota": int|None, "used_today": int|None}
        —— 只读订阅账本，不反推业务账（立项方案 §8）。"""
```

- **默认实现 `UnwiredEntitlementProvider`**：未接线，恒拒；
- **`StaticEntitlementProvider`**：仅供单测/影子按字典回结论，**不实现计费、不产生任何真实权益**；
- **单进程语义**：读-判定-写账在同一调用内完成；跨进程并发去重为已知边界（同 -007 回执账口径），多进程部署前需换 sqlite 唯一索引。

## 4. `entitlement_log` schema（append-only）

存储：`k_stock/data/entitlement_log.jsonl`（append-only，**逐行自校验 sha256**，改写 → `verify_integrity` 显式拒 `ledger_tampered`）。

| 字段 | 类型 | 说明 |
|---|---|---|
| `ts` | str | 判定时刻 ISO（**可注入 `now` 以保可复现**） |
| `log_id` | str | `sha256(ts\|subject\|domain\|target\|template\|kind)[:16]` |
| `schema_version` | int | 当前 1 |
| `subject_ref` | str | **主体哈希指纹** `subj:<sha256[:12]>`——**open_id/手机号明文一律不落账** |
| `domain` | str | 三域之一 |
| `target_id` | str | 收件人注册 id |
| `template` | str | 模板名 |
| `kind` | str | 发送 kind（`daily`/`alert_critical`/…） |
| `provider` | str | 判定 provider 名（`unwired`/`static`/M2 的实现名） |
| `implemented` | bool | 判定链路是否已接线（`false` 即 not_implemented 留痕） |
| `allowed` | bool | 放行/拒绝 |
| `reason_code` | str | 判定原因码 |
| `checked` | dict | 只记**查了哪些字段与中间量**：`status`/`plan_id`/`period`/`daily_quota`/`used_today`/`kind`/`checked_at`/`in_period`/`quota_exhausted` |
| `entry_sha256` | str | 逐行自校验摘要 |

**字段白名单封闭**：`_append_jsonl` 只收 `_ENTITLEMENT_FIELDS`，夹带字段 → `log_field_forbidden`（顺手入账明文敏感值在写入前就被拒）。

**不记**：金额、支付流水号、密钥、open_id 明文、手机号（沿用 R-1~R-4 凭据纪律）。

## 5. 投递回执（`send()` 返回 / 写入 `-014` 的 `outlet` 段）

投递账本 `k_stock/data/feishu_delivery.jsonl`，同样 append-only + 逐行自校验。回执字段（= `_DELIVERY_FIELDS`）：

`ts` / `receipt_id` / `schema_version` / `report_id` / `report_summary` / `idempotency_key` / `domain` / `target_id` / `template` / `kind` / `mode` / `pushed` / `charged` / `reason_code` / `evidence` / `critical` / `quiet_window` / `rate_used` / `rate_limit` / `gate` / `credential_state` / `message_chars` / `payload_sha256` / `entry_sha256`

- `pushed`：是否**真实送达**。dry-run 恒 `false`；
- `evidence`：证据分级 `dryrun_preview` / `api_accepted` / `none`（口径引中台 EVIDENCE_DELIVERY，不另立）；
- `payload_sha256`：payload 指纹（**只留指纹，不把 payload 打进日志冒充已送达**）；
- `gate`：判定快照（allowed / reason_code / provider / implemented / checked）。

### 与 -014 的接线（只写 outlet）

`deliver_report(report, target_id="owner.laotian")` 消费 -014 `build_report()` 的产物 dict，**只写 `report["outlet"]`**：

```
pushed / reason_code / target / target_domain / template / kind / mode /
idempotency_key / evidence / critical / quiet_window / rate_used / rate_limit /
gate / credential_state / push_module / push_ticket / domain_gate / notice
```

**五段 `sections` 与 `scope`/`period`/`sources` 等口径字段零改动**——单测以「接线前后 `sections` 序列化逐字相等」+ `rb._assert_no_live_fields(report)` 仍通过做断言。-014 的 `-014 五段口径` 一个字没动，本模块**不 import -014**（零依赖，方向单向：feishu_push 消费 report 产物）。

报告幂等身份 = `report_fingerprint(report)` = `sha256(generated_at | month | combo_ids)[:16]`，**不改报告字段**（不塞 `report_id` 进 -014 结构）。

## 6. 幂等 / 频控 / 静默窗 / 凭据纪律

### 幂等

- 幂等键 = `sha256(report_id | target_id | template)[:16]`；
- 同报告 + 同目标 + 同模板重复推 → **零发送**（`duplicate_suppressed`），仍**留痕**写回执（`charged=false`，不洗额度）；
- 幂等命中在订阅闸门/凭据之前判定——重复推**不会**二次触达任何闸门或出口。

### 频控（按域）

- 本人域 `daily_limit=null` → 免额度（立项方案 §4）；
- 运维 200/日、客户 20/日（客户域最终由 plan 额度下发，此为保守默认封顶）；
- 计次口径：只数 `charged=true` 的行；被幂等/频控/静默窗/闸门挡下的**不计次**；
- dry-run **计次**（否则干跑会洗掉额度，导致真实发送时额度已被架空）。

### 静默窗

- 窗口 **22:00-07:30**（跨零点，闭开区间 `[start, end)`）；
- 窗内非 critical → 拒 `quiet_window_suppressed` 并留痕；
- **critical 豁免仅本人域**（立项方案 §7-5 拍板：客户域 critical **不豁免**，运维域同样不豁免）；
- critical 窄口径：仅 `kind="alert_critical"`（沿用中台 W34 拍板：仅风险提示类）。

### 凭据纪律

| 项 | 口径 |
|---|---|
| 凭据来源 | **只从环境变量读**：`FEISHU_PUSH_WEBHOOK_URL`（必填）、`FEISHU_PUSH_SIGN_SECRET`（选填，签名校验用） |
| 凭据登记表 | `FEISHU_PUSH_CREDENTIALS` 指向的 JSON **只登记环境变量名**（`webhook_env`/`sign_secret_env`），**本身无密可失**、不落盘明文 |
| 明文暴露面 | `FeishuCredentials.__repr__`/`__str__` **不可逆**（只出 `webhook_sha256_8` 前 8 位指纹 + `sign_secret_present` 布尔）；`fingerprint()` 同；账本/回执**零明文** |
| 过期判定 | env `FEISHU_PUSH_WEBHOOK_EXPIRES_AT`（ISO 时刻）→ `expired`；只判过期，不打印值 |
| 缺失语义 | **显式抛** `CredentialsMissing(reason_code=feishu_credentials_missing)`——**严禁静默成功、严禁把 payload 打进日志冒充已送达** |
| 预检 | `check_credentials()` 只回 `{present, reason_code, ...指纹}`，**不抛**、**不回明文** |

### 真实发送三重门禁（缺一即显式抛）

| 门禁 | 位置 | 未满足时 |
|---|---|---|
| ① 调用方显式 `dry_run=False` | 参数 | 默认 `dry_run=True`（**默认零出口**） |
| ② env 总闸 `FEISHU_PUSH_LIVE=1` | 环境 | 抛 `live_switch_off` |
| ③ env 域白名单 `FEISHU_PUSH_LIVE_DOMAINS` 含目标域 | 环境 | 抛 `live_domain_not_allowed` |
| ④ 凭据齐备（webhook https + 未过期） | 环境/登记表 | 抛 `CredentialsMissing` |

- **HTTP 出口唯一**：`_webhook_post()`（`urllib.request`），只被 live 分支触达；返回 `code != 0` → 抛 `feishu_send_rejected`，传输失败 → 抛 `feishu_send_failed`，**失败一律不吞、不静默成功**；
- **零真实出口铁律由单测守**：socket `connect`/`connect_ex`/`create_connection` 全桩抛 `AssertionError`，全链路（含 -014 报告接线）跑通。
