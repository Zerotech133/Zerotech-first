## 一、AI 智能到位的标准（每个岗位必须齐备）

| 要素 | 定义 |
|---|---|
| **有 Agent** | `agent_id` + 中文名 + 职级（E1-E3）+ 汇报线 |
| **有模型** | `llm_binding`：E3=strong（glm/glm-5.3）；E2=strong/fast；E1=fast/local（qwen3.5:9b） |
| **有工具** | MCP 工具面（dw-governance / dataops / dw-etl-dryrun / 质量/目录/语料/因子工具）+ tools_allowed 读写边界 |
| **有记忆** | memory_grants：domain/dept/data/agent 分域读写 |
| **有日常** | daily_work 任务（巡检/清洗/挖掘/登记）+ 证据路径 + 时效 |
| **有 KPI** | 每岗 2-4 项可量测指标 |
| **有 HITL** | 每岗写操作的人工审批级别（只读 / 受控写 / L2） |
