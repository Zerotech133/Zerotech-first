## 1. 资源配额（已实现，L1）

`agent_platform/tools/agent_sandbox.py` 新增容器资源上限（默认值+可覆盖）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--memory` | `512m` | 容器内存上限（Docker `--memory`） |
| `--cpus` | `1.0` | CPU 配额（Docker `--cpus`） |
| `--pids-limit` | `256` | 进程数上限（防 fork 炸弹） |

```powershell
python -X utf8 agent_platform/tools/agent_sandbox.py run --cmd "python3 -c 'print(1)'" \
  --memory 128m --cpus 0.25 --pids-limit 32 --dry-run
# 实测：docker run 参数含 --memory 128m --cpus 0.25 --pids-limit 32
```

- 测试：`agent_platform/tests/test_sandbox_quota.py`（配额 flags/dry-run 报告）；
- 实测：`--memory 256m --cpus 0.5 --pids-limit 64` 下 `print(3)` → ok/rc0。

## 2. 出口白名单（策略/校验已实现，未启用）

文件：`agent_platform/rules/sandbox_network_policy.json`

```json
{
  "schema": "sandbox_network_policy/v1",
  "default": "deny",
  "mode": "proxy",
  "proxy": "http://127.0.0.1:3128",
  "allow": [
    {"host": "pypi.org", "port": 443, "reason": "..."},
    {"host": "files.pythonhosted.org", "port": 443, "reason": "..."}
  ]
}
```

校验/决策工具：`agent_platform/tools/network_policy_check.py`

```powershell
python -X utf8 agent_platform/tools/network_policy_check.py --check
python -X utf8 agent_platform/tools/network_policy_check.py --host pypi.org --port 443   # allowed
python -X utf8 agent_platform/tools/network_policy_check.py --host evil.com --port 443    # denied(exit3)
```

规则：默认 deny；host 精确匹配（禁通配/路径/端口拼接）；port 整数；重复项拒绝；`mode=proxy` 时必须配置代理。

## 3. 启用架构（三选一，均需 L2 批准）

| 方案 | 做法 | 优点 | 代价/风险 |
|---|---|---|---|
| **A（当前）** | `--network none` | 零风险、零额外进程 | 完全离线，依赖下载不可用 |
| **B（推荐按需）** | Docker 内部网络 + 受控 HTTP(S) 代理：容器只连代理，代理按 policy allowlist 转发；`HTTPS` 用 `CONNECT` allowlist（不 MITM） | 出口可审计、可开关 | 需部署代理进程/端口（L2）；需处理 CA（若 MITM） |
| C | 宿主防火墙/DNS 限制 | 无需容器改造 | 影响宿主全局网络，L2 风险最高，不推荐 |

**启用清单（未来 L2 批）**：
1. 部署 allowlist 代理（本地 127.0.0.1，端口登记 REGISTRY）；
2. 策略文件 `mode=proxy` + `proxy` 指向代理；
3. 容器网络从 `none` 改为专用 bridge（仅通代理）；
4. 验证：allow 域名成功、未列域名拒绝、日志有 run 记录；
5. 回滚：容器网络回 `none`，停代理，删规则。
