## 2. 问答使用（CLI + HTTP）

默认链路：**prompt v4 + guard marker=segment + citation_retry=on**（灰度默认，已验证 v4 可答率 83%、citation_retry guard 通过率 100%）。

### 2.1 CLI

```powershell

& 'C:\项目\py312\python.exe' -X utf8 tools/kb_corpus/kb_qa.py ask "M9 级覆铜板对 AI 服务器 PCB 的价值量有什么影响？" --mode multi

# 关闭守卫（灰度对比） / 守卫失败动作
... kb_qa.py ask "问题" --no-guard
... kb_qa.py ask "问题" --on-guard-fail mark|fallback|refuse

# 只读检索冒烟（不调 LLM，安全快速）
... kb_qa.py ask "问题" --retrieval-only
```

### 2.2 HTTP（8091）

```powershell
# 只读检索（默认 mode=retrieval，控成本）
Invoke-RestMethod 'http://127.0.0.1:8091/api/kb/qa?q=问题&mode=retrieval&topk=3&cache=0'

# 生成（multi 默认 v4+segment+retry；single 需显式）
Invoke-RestMethod 'http://127.0.0.1:8091/api/kb/qa?q=问题&mode=multi&topk=8'
Invoke-RestMethod 'http://127.0.0.1:8091/api/kb/qa?q=问题&mode=single&topk=5'
```

参数：`q`（必填）、`mode=retrieval|single|multi`（默认 retrieval）、`topk`（3–10）、`cache=0`（跳过响应缓存，灰度/验收用）、`prompt=v4|v1`、`guard_marker=segment|strict`、`citation_retry=1|0`、`guard=0|1`。
限流（进程内窗口 60s）：**retrieval 300/分、single 6/分、multi 6/分**；429 时等待窗口重试。
健康检查：`Invoke-RestMethod 'http://127.0.0.1:8091/api/kb/qa?q=M9&mode=retrieval&topk=3'`（ok=true）。

### 2.3 限流语义（2026-11-02 复核，task-119/122）

- **限流 = 并发突发上限，不是串行吞吐目标**：滑动窗口 60s，按通道独立计数；
  - `retrieval` **300/分**（纯检索/缓存，无 LLM 成本）；
  - `single` **6/分**、`multi` **6/分**：**突发上限**（保护本地 Ollama 不被并发压垮）。
- **实测语义**（mock 慢 LLM：single 12s / multi 10s，进程内 handler，真实 LLM 0 次）：
  - 并发 10 突发：**前 6 个 200、第 7 个起 429**（429 在 LLM 之前拒绝，不占 GPU）；
  - 并发 1 串行：10 个请求全部 200（窗口自然滑动），**不会误伤**正常串行调用；
  - 单次真实延迟 single ≈10–16s、multi ≈7–15s，串行自然吞吐 <6/分，因此 6/分适合做「突发保护」而非吞吐目标。
- **建议（不改配置）**：single/multi 维持 6/分 = 突发上限；retrieval 维持 300/分。
  若未来要放宽单通道吞吐，需另行评估 Ollama 并发能力（单实例串行生成）+审批后改配置并重启 8091。
- 429 处理：客户端应退避重试（等待窗口内旧请求过期），不要立即重发；服务端 `meta.rate_limit` 含 limit/used/remaining/window。
- 复核产物：`research/reports/qa_channel_limit_20261102.md`（真实延迟/可达性）、
  `research/reports/qa_channel_capacity_20261102.md`（并发矩阵/突发验证）。

## 5. 回滚手册（各能力一行命令）

> 原则：先记录当前 PID/配置，再回滚；HTTP 通道变更需 K-RESTART 生效（勿直接裸启 8091）。

| 能力 | 一行回滚 |
|---|---|
| 问答 prompt（v4→v1）+ guard 解析 | `$env:KB_QA_PROMPT_VERSION='v1'; $env:KB_QA_MARKER_MODE='legacy'; $env:KB_QA_CITATION_RETRY='0'`（CLI 即时生效；HTTP 需下一步重启） |
| 问答 HTTP 默认配置生效/回滚 | `'rollback' | Out-File C:\Temp\PORTAL_API_RESTART.flag; Start-ScheduledTask -TaskName 'AI工作站门户API'`；验证 `Invoke-RestMethod 'http://127.0.0.1:8091/api/kb/qa?q=M9&mode=retrieval&topk=3'` |
| 引用自检重试单独关闭 | `KB_QA_CITATION_RETRY=0`（CLI/HTTP 同源环境变量；HTTP 需 K-RESTART） |
| 检索限流（300→60） | 改 `portal/api_kb_qa.py` 的 `RATE_LIMIT['retrieval']=300` 为 60 → K-RESTART |
| 检索缓存（回退到每次重载） | `git checkout -- tools/kb_corpus/kb_read_api.py portal/api_kb_qa.py` → K-RESTART（缓存仅进程内存，重启即回旧行为） |
| 每日任务停用/恢复 | `Disable-ScheduledTask -TaskName ZeroBound_DailyKB` / `Enable-ScheduledTask -TaskName ZeroBound_DailyKB` |
| 8091 全量重启 | 先记 PID（`Get-NetTCPConnection -LocalPort 8091`），再 `'restart' | Out-File C:\Temp\PORTAL_API_RESTART.flag; Start-ScheduledTask -TaskName 'AI工作站门户API'`；观察 `C:\Temp\portal_api_task.log` 出现 "starting" 且端口监听 |

## 6. 已知限制与注意

1. **飞书卡片权限**：飞书卡片/频道推送需对应应用权限与审批，当前通道验证通过但卡片权限范围有限，推送到群前先在测试会话确认。
2. **multi 容量未压测**：multi 仅 6/分且验收仅 3 次真 LLM（qwen3.5:9b，约 8–25s/次）；高并发/长稳未压测，放量前需按 3–5 QPS 试跑并控 LLM 成本。
3. **限流为进程内单实例计数**：多进程/多实例部署需一致性方案（网关或 Redis 计数），否则各实例独立限流。
4. **8091 重启走 K-RESTART**：改 8091 代码必须经 flag+计划任务重启并看 `portal_api_task.log`；冷启动 import smoke 失败会拒绝拉起（勿绕过）。
5. **35b 模型慢**：qwen3.6:35b-a3b 冷加载可达 2–3 分钟、单次 20–40s，仅作观察/可选，不作默认。
6. **v3 严格 prompt 未合入**：v3 段落式 prompt 在 9b/35b 下推断标记失控，已回退；v4 为当前默认。
7. **数据口径**：研报/知识单元引用需人工复核；答案仅供参考，不构成投资建议。
8. **门户静态页**：改 `portal/static/*.json` 无需重启 8091（nginx 直读），页面刷新即可；改 8091 代码才需重启。

## 7. 常见排障速查

| 现象 | 排查 |
|---|---|
| 问答 HTTP 超时/失败 | `Get-NetTCPConnection -LocalPort 8091`；`C:\Temp\portal_api_err.log`；K-RESTART |
| 检索/问答很慢 | 是否首次冷启动（可预热）；看 `cache_stats`；确认不是 LLM 慢（multi 8–25s 正常） |
| 每日任务没跑 | `Get-ScheduledTask ZeroBound_Daily*` 状态 + `C:\Temp\zero_daily_*.log` 尾部；手动 `Start-ScheduledTask` |
| 学习卡/面板数据不更新 | 跑 `python tools/kb_corpus/daily_kb.py --check-only` 看状态；再 `run` |
| 429 限流 | 等 60s 窗口；确认配额（retrieval 300/分，single/multi 6/分） |
