## 二、五要素

### 要素 1：命令全文（逐字，可复制执行）

```
schtasks /change /tn "\StrongEod" /st 06:30
```

- `/st 06:30` 修改该任务唯一日触发器的 StartBoundary 时间部分：15:45 → 06:30（日期部分不变，每日间隔不变，双动作、工作目录、账户、时限均不受影响）。
- 任务名带 `\` 前缀精确匹配根路径，避免歧义。
- 变更后复核（逐字）：

```
schtasks /query /tn "\StrongEod" /v /fo LIST | findstr /i "Start Time 任务名"
```

### 要素 2：影响面

**本任务**：每日触发 15:45 → 06:30；动作链不变（先 scan 后 card 推卡，推卡时点由傍晚移至约 06:5x，与 10-09~10-13 时代实测一致）。

**同链任务时序变化清单**：

| 任务 | 现时点 | 是否变动 | 变化说明 |
|---|---|---|---|
| zhice 凌晨补数（外部） | 01:30~05:30 浮动 | 不变 | 06:30 首跑的前置供给（个股锚 D-1） |
| TdxSync | 17:30 | 不变 | 昨日 17:30 成功为 06:30 首跑的前置供给（板块锚 D-1） |
| **StrongEod** | 15:45 | **改 06:30** | 本单标的 |
| TodaysPicks | 15:40 | 不变（时序关系反转） | 由「消费昨日 15:45 产物」变为「消费当日 06:30 产物」 |
| RpsDaily | 16:05 | 不变 | 与强名单链无依赖 |

**下游消费者影响**：

- **TodaysPicks（15:40）**：新鲜度 +1 天（正面）。备忘 §二实证其有 >4 天整源闸门，当前 basis=10-12 已被排除；改 06:30 后次日 15:40 即可拿到 basis=D-1 的新名单。
- **strong_card 推卡**：推卡移至晨间盘前；10-19 实测的「旧名单静默重推」缺陷须先由 stale 闸门修复兜住（见 §三 前置 1）。
- **portal/strong.html + api_flow/api_misc**：strong_latest.json 由傍晚刷新变晨间刷新（strong_scan 落盘 webroot 副本机制不变）。
- **shadow_weekly_report / strong_review**：读取产物时间点后移至晨间，机制不变。
- **守卫语义**：不变（两时点消费的均为 T-1 收盘锚，数据语义等价，备忘 §1.2）；06:30 被拦时恢复「当日人工补数 + `--force` 重扫」补救窗口（10-13 判例）。
- **风险点**：06:30 跑次依赖凌晨补数完成，浮动到 05:30 之后的贴边日会被守卫拦截且当日无 15:45 兜底跑次（除非采用要素 4 双跑）。

### 要素 3：不可逆点

**无。** 触发时点为纯计划任务配置，随时可用要素 5 的一条命令改回 15:45；本变更不触碰任何脚本、数据、产物或状态文件。唯一需接受的过渡态风险：改后至首次 06:30 成功前，若守卫拦截则当日无名单（可人工补扫补救）。

### 要素 4：替代方案——双跑 06:30 + 15:45

保留现 StrongEod（15:45）不动，新增 06:30 伴生任务。幂等双保险：strong_scan 当日熔断（06:30 成功则 15:45 跳过，零成本）；strong_card 按 pushed state 当日去重（不会重复推卡）。命令（PowerShell，复刻 register_ai_tasks.ps1 的双动作模式，逐字可复制）：

```powershell
$s  = New-ScheduledTaskSettingsSet -ExecutionTimeLimit (New-TimeSpan -Hours 1)
$a1 = New-ScheduledTaskAction -Execute 'C:\Program Files\Python311\python.exe' -Argument '-X utf8 C:\aios\quant_backtest\strong_scan.py' -WorkingDirectory 'C:\aios\quant_backtest'
$a2 = New-ScheduledTaskAction -Execute 'C:\Program Files\Python311\python.exe' -Argument '-X utf8 C:\aios\quant_backtest\strong_card.py --send' -WorkingDirectory 'C:\aios\quant_backtest'
Register-ScheduledTask -TaskName 'StrongEodMorning' -Action $a1,$a2 -Trigger (New-ScheduledTaskTrigger -Daily -At 06:30) -Settings $s
```

双跑回滚（逐字）：`Unregister-ScheduledTask -TaskName 'StrongEodMorning' -Confirm:$false`

