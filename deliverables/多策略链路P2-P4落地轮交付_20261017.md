## 三、权重进化器（P4）设计定稿

```
显式通道  strategy.feedback：accept=+1 / reject=−1 / mute=0，按策略汇总

          （data/ashare 单票后复权 parquet，C: 真身 S4U 可达，收益 clamp ±5%）
融合      target = 0.5·norm01(ret) + 0.5·norm01(fb)；单通道退化；双缺保权
平滑      EWMA α=0.3（防单周噪声）
约束      注水法归一 Σ=1，clamp [0.1, 0.7]（上界优先钉死防下界抢预算）
影子纪律  默认 dry-run；--apply 才写 strategy.weights + registry.json
          参数预注册（α/上下限/融合系数）防事后调参
```
