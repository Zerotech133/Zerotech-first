# H14 · 影子盘实施方案（草案，待 10-30 例会审议）

## 一、背景（H7→H14 证据链）
- **H7（rejected）**：PIT 财务因子中质量/价值/成长均未通过；质量因子 OOS IC -0.033~-0.038（t≈-2.1），高 ROE 跑输是稳健负向异象。
- **H14（backtested）**：估值分层内质量反向成立。5 年窗口（2021-07~2026-10，62 个调仓月，16.7 万观测）：OOS PE 三分位内 ROE Q5-Q1 全为负（低/中/高 PE：**-0.83% / -1.35% / -1.83%**）；
  **高ROE+高PE 质量陷阱 OOS -0.60%（t=-2.15）vs 高ROE+低PE +0.57%（t=4.90），差 -1.17%**（IS 差 -3.37%）；3 年窗口同向（差 -1.24%，t=-4.08）。
- 结论：可制定「**高ROE+高估值低配/规避**」风控规则；例会需在 A/B/C 中拍板（建议 A：组合层权重上限 5%）。

## 二、影子盘目标（A 方案）
在现有研究组合上叠加一条**风控约束**（非新 alpha）：
> **高ROE+高PE（质量陷阱组）总权重上限 5%**；超限部分削减，释放权重按原持仓等比例分配。
影子盘 = 约束组合 vs 无约束组合（同池、同调仓、同成本）的并行模拟，验证风控规则是否降低回撤/提升夏普且不显著牺牲收益。

## 三、实施口径（可复现）
| 项 | 定义 |
|---|---|
| 股票池 | A 股全市场；剔除 ST、停牌、上市<60 交易日、财务数据缺失 |
| 质量分 | ROE（PIT：最新已公告财报，TTM/单季按 H14 口径），当日截面五分位 |
| 估值分 | PE_TTM（PIT），当日截面三分位（H14 阈值约 22.3/43.6，需滚动重算） |
| 陷阱组 | ROE Q5 且 PE T3（高ROE+高PE） |
| 约束 | 陷阱组目标权重合计 ≤ **5%**；超出时按比例削减，差额按其余持仓等比例放大 |
| 调仓 | 月度：月末收盘出信号，次月首个交易日执行（T+1 机制） |
| 成本 | 双边 **30bp**（同 H14） |
| 基准 | ①无约束组合（同池同权）②中证800 |
| 数据 | daily / daily_basic / fina_indicator / income+balancesheet（ROE 计算）PIT |

## 四、影子盘机制（不实盘）
1. **每日估值**：持仓权重 × 日收益（收盘价），组合净值曲线；
2. **月度再平衡**：按约束规则生成新权重，记录换手与成本；
3. **输出**：净值、年化、波动、最大回撤、夏普、换手、相对基准/无约束的超额；
4. **落盘**：`work/research/h14_shadow/<stamp>.json` + 月度报告（初版脚本 `tools/research/h14_shadow.py` 待例会批准后实现）；
5. **通知**：仅生成报告，不接交易、不推送指令。

## 五、验收标准（影子跑 ≥3 个月 / ≥3 次调仓后评估）
1. **约束执行**：每月核验陷阱组实际权重 ≤5%（含漂移后 ≤5.5% 容忍带）；
2. **风控效果**：约束组合最大回撤 ≤ 无约束组合；夏普不低于无约束（允许 -0.1 容忍）；
3. **收益不劣化**：年化收益相对无约束下降 ≤0.5pct；
4. **一致性**：影子方向与 H14 回测一致（陷阱组贡献为负、规避后改善）；
5. **可复现**：任一调仓月可从数据重放（PIT 校验通过）。
