# 交易手法能不能当身份指纹

> 2026-11-06 · 零界 · 议题：T-1 能否从成交数据判断「哪 1 亿是陈小群买的」
> 全部数字本机实测，脚本 `tools/research/behavior_fingerprint.py`，可复算

---

## 零、先给结论

你的思路在情报学上完全成立——**行为反推身份（behavioral attribution）是标准手段**。但它能不能落地，取决于两个硬约束，实测结果如下：

| 你的设想 | 数据支撑 | 结论 |
|---|---|---|
| 每手买多少手 | ❌ 无 tick、无个股分钟线 | **做不了** |
| 分时线上方 / 下方 | ❌ 同上 | **做不了** |
| 单笔仓位规模 | ✅ 龙虎榜金额 82,955 笔 | **可做，有差异** |
| 选股偏好（他会买哪只） | ✅ 四档结构 + 换手 + 市值 | **AUC 0.954，强信号** |
| 归因（这 1 亿是谁的） | ❌ 无逐笔、无委托队列 | **不可做** |
| 区分是哪个游资 | ⚠️ 四人画像高度重合 | **几乎不可做** |

**但有一个数字把问题直接解掉了**：龙虎榜买入榜第 5 名的中位金额是 **794 万**（p25 364 万 / p75 1745 万）。你要追的是 **1 亿**，是门槛的 **12.6 倍**。

> **1 亿这个量级的买入，在龙虎榜上藏不住。** 他 T-1 如果真买了 1 亿，T-1 的榜单上必然有他。所以「T-1 那 1 亿是不是他的」，不需要从成交数据反推——**直接查 T-1 的龙虎榜就能证伪**。

我把 `quant_backtest/data` 全量扫了一遍：

**「每手多少手、分时线之上还是之下」这件事，现有数据物理上算不出来。** 不是算法问题，是没有那个数据。要做，只有一条路：买 Level-2 逐笔委托（约 3~8 万/年/市场），而且只买得到近月。

**但不必急着买。** 下面说明为什么。

## 二、真正的钥匙：794 万这个门槛

龙虎榜披露规则是「当日买入前 5 名 + 卖出前 5 名」。所以第 5 名的金额 = **可见性门槛**。实测：

| 分位 | 买入榜门槛 | 卖出榜门槛 |
|---|---|---|
| p25 | 364 万 | 263 万 |
| **中位** | **794 万** | **581 万** |
| p75 | 1,745 万 | 1,112 万 |
| p90 | 3,550 万 | 2,021 万 |

**推论链**：

1. 单笔买入 > 794 万，大概率进前 5 → **必然披露**
2. 陈小群单笔中位 **3,460 万**，是门槛的 4.4 倍
3. 他的席位只有 **2 个真实营业部**（见第五节）
4. 龙虎榜按**营业部**披露，同营业部多账户会被合并 → **多账户拆单无效**
5. 所以他能"藏"的量，上限约 2 × 794 万 = **1,600 万**

**结论：陈小群无法隐藏 1 亿级别的买入。** 如果 T-1 的榜单上没有他，那 1 亿就不是他的。

这条判断用现有数据 100% 可执行，且不需要任何新数据。

## 三、实测 AUC 0.954 —— 但它测的是"选股"，不是"归属"

我用 T-1 的公开数据训练了一个二分类器：判断「某股 T 日会不会被陈小群买入」。

**特征**：T-1 的四档买入占比、超大单净额、换手率、量比、流通市值
**正样本**：陈小群 T 日上榜的 902 笔
**负样本**：两个对照组

| 对照组 | AUC | 含义 |
|---|---|---|
| 全市场随机 | **0.9527** | 有强信号 |
| **同市值十分位 + 同换手十分位邻域** | **0.9540** | 剥离选股偏好后**没降反升** |

**同市值同换手邻域的 AUC 反而略高**，这个结果是反直觉的，说明信号不在"他偏爱小盘高换手"。特征重要性给出解释：

| 特征 | 重要性 | 解读 |
|---|---|---|
| `p_turnover_rate` T-1 换手率 | **0.1069** | 主力信号：他买"明天会更活跃的票" |
| `p_sh_elg` T-1 超大单买入占比 | **0.0896** | 结构信号：该票 T-1 就以大单为主 |
| `p_volume_ratio` 量比 | 0.0114 | 很弱 |
| `p_circ_mv_yi` 流通市值 | 0.0044 | 几乎无关 |
| `p_elg_net` **超大单净额** | **0.0020** | **几乎无用** |

**`p_elg_net` 只有 0.002 是决定性的**：如果陈小群 T-1 真在偷偷建仓，超大单**净额**应该显著为正、应该是强特征。它几乎为零，说明——

> **AUC 0.95 抓到的是「这只票明天会活跃」这个特征，不是「他 T-1 已经动手」这个痕迹。**

所以 AUC 0.954 的正确用法是：**判断"这票他会不会买"（选股），不是"这钱是不是他的"（归因）**。两者差一个数量级的信息量。

## 四、更麻烦的：四个游资的画像几乎一样

| 游资 | 样本 | 单笔中位 | T-1 超大单占比 | 换手率 | 流通市值 |
|---|---|---|---|---|---|
| **陈小群** | 903 | 0.346 亿 | 0.220（分位 98） | 15.47%（97） | 56 亿（56） |
| 章建平(章盟主) | 1,293 | 0.289 亿 | 0.180（97） | 13.50%（96） | 59 亿（58） |
| 方新侠 | 899 | 0.366 亿 | 0.190（98） | 15.83%（97） | 75 亿（66） |
| 赵强(赵老哥) | 937 | **0.141 亿** | 0.180（97） | 11.58%（95） | **36 亿（39）** |

**四人的超大单占比全在 0.18~0.22、换手全在 11.6%~15.8%、分位全在 95 以上。** 只有"单笔规模"和"市值偏好"有差异：

- 赵老哥仓位最小（0.141 亿）、最偏小盘（36 亿）
- 方新侠仓位最大（0.366 亿）、最偏大盘（75 亿）
- 陈小群、章盟主在中间

**这个差异不足以识人。** 用这四个特征做四分类，重叠区太大。所以：

> **现有数据能识别"这里有游资"，不能识别"是哪个游资"。** 前者 AUC 0.95，后者接近随机。

要突破这一层，唯一的办法就是 tick——**因为"手法"（拆单节奏、挂单撤单、冲击成本）才是真正区分人的东西**，而不是"选了什么票"。

## 五、顺带查出一个必须修的数据问题：席位未归并

查陈小群席位时发现的：

```
中国银河证券股份有限公司大连黄河路证券营业部          317 天 / 542 笔
东亚前海证券有限责任公司苏州留园路证券营业部         214 天 / 365 笔
东亚前海证券有限责任公司苏州留园路营业部            24 天 /  29 笔   ← 同一家，写法少了"证券"二字
```

**后两个是同一个营业部**，被拆成两个 `Seat` 节点。全图范围：

| 指标 | 实测 |
|---|---|
| Seat 总数 | 13,166 |
| 归一化后出现重复名的组 | **692 组** |
| 涉及 Seat 节点 | **1,384 个（10.5%）** |

归一规则极简：`replace("证券营业部","营业部")` + `replace("有限责任公司","")`。

**影响**：这直接压低了"游资席位覆盖率"的计算——陈小群被算成 3 个席位，实际 2 个；他 24 天/29 笔的交易被算在"另一个席位"名下。**这是 P0 级数据修正，10 分钟可做，影响所有涉及席位的统计。**

## 六、那到底该怎么做：三层能力，别混用

| 能力 | 用什么 | 实测强度 | 输出 |
|---|---|---|---|
| **① 痕迹检测**「这票有游资」 | T-1 换手率 + 超大单占比 | AUC **0.954** | 概率 0~1 |
| **② 身份约束**「不是他」 | T-1 龙虎榜 + 794 万门槛 | **硬判据** | 是/否 |
| **③ 规模画像**「像不像他」 | 单笔仓位分布（0.35 亿中位） | 弱 | 似然比 |
| **④ 归因**「这 1 亿是谁」 | 需 tick | **不可做** | — |

**正确的工作流是一、二、三组合，不是追求四**：

```
T 日：陈小群上榜 X 股 1 亿
  ↓
T-1：查龙虎榜 → 有他？ → 有：链条闭合，直接确认（② 硬判据）
                        → 无：那 1 亿不是他的（②硬判据，因 1 亿 > 12.6×门槛）
  ↓
T-1：查全市场 → 哪几只票有游资痕迹？（① AUC 0.954 打分）
  ↓
T-1：这些票的 T-1 结构像不像他的风格？（③ 弱信号，只做加权，不做判定）
  ↓
产出：候选清单 + 概率，而不是"确定是他"
```

**关键在于承认：能给出的是概率，不是归属。** 把概率包装成归属，就是前面反复说的"把猜测写成事实"的同一个错误。

## 七、图谱怎么表达：BehaviorProfile，不是标签

不建 `(:HotMoney)-[:HAS_FINGERPRINT]->` 这种标签边，因为指纹是**分布**不是**值**。建一个独立节点：

```cypher
(:BehaviorProfile {
  subject: "陈小群",
  version: "20261106",
  window: "20230810-20261016",
  n_obs: 903,
  amt_median, amt_p25, amt_p75,      // 仓位规模分位（不是均值，游资分布是厚尾）
  sh_sm_med, sh_md_med, sh_lg_med, sh_elg_med,  // 四档结构
  turnover_pct, mv_pct,               // 相对全市场分位
  hidden_capacity_max: 1.6e7,         // 能藏住的上限（元）
  discriminative_power: 0.31,         // 与其他游资的可分性，低=不可用于识人
  calibrated_at, method
})
```

三条关键边：

```cypher
(BehaviorProfile)-[:PROFILE_OF]->(HotMoney)          // 谁
(BehaviorProfile)-[:DERIVED_FROM]->(TradeAction)     // 从哪些样本算的，可回溯
(BehaviorProfile)-[:COMPARABLE_TO {js_divergence}]->(BehaviorProfile)  // 与其他游资的分布距离
```

**`discriminative_power` 是必须字段**：它明确告诉下游"这个画像能不能用来识人"。陈小群 vs 章盟主的 JS 散度很小 → 该字段低 → 因子层不许用它做身份判定。**这是把"不可知"写进 schema，而不是假装知道。**

## 八、你说"用图谱看量化交易也行得通"——对，但要分清能看什么

这句话成立，但边界很清楚，分错了会浪费几个月：

| 量化要素 | 图谱适合吗 | 正确用法 |
|---|---|---|
| 价格序列、收益率 | ❌ 不适合 | 留在列式存储，别塞图 |
| 因子值、IC 时序 | ❌ 不适合 | 同上 |
| **策略依赖的路径**（哪个信号依赖哪条链路） | ✅ **非常适合** | 策略 = 图上的路径模板 |
| **传导约束**（A 事件影响 B 标的要几跳） | ✅ 非常适合 | 三约束（深度≤3、强度、可信度） |
| **冲突检测**（两个策略抢同一批标的） | ✅ 适合 | 同标的入边 > N 则告警 |
| **归因**（这个收益来自哪条链路） | ✅ 适合 | 沿路径回溯，而不是拆因子 |

**核心一句：图谱管"关系和路径"，矩阵管"数值和统计"。** 我上一轮说"因子是边上的探针"，这轮补一句——**策略是图上的路径模板**：

```
(:Strategy)-[:ENTRY_VIA]->(:PathTemplate{hops:2, rels:['HOTMONEY_INFLOW','OF_COMPANY']})
          -[:GATED_BY]->(:Gate{condition:'oos_survived && decay_class!="flip"'})
          -[:SIZED_BY]->(:BehaviorProfile{subject:'陈小群'})
```

这样"陈小群进场"就是一个可复用的路径模板，能挂在任何策略上，而不是散落在某个 py 文件的 if 判断里。**这才是"用图谱看量化"的正确形态——不搬数值，搬结构与约束。**

## 十、一页话

**你的方法论对，但工具选错了一层。** 你想用 tick 级微观数据反推归属，实测发现：1 亿的行为**根本不需要反推**——龙虎榜 794 万的门槛让它自己暴露了。真正藏在门槛之下的，是 800 万以下的小额建仓，那部分才需要 tick。

**实测的三个数字**：

- **794 万**：可见性门槛。1 亿 = 12.6 倍门槛 → 藏不住 → 直接查 T-1 榜即可证伪
- **AUC 0.954**：能识别"这票有游资痕迹"，但 `p_elg_net` 仅 0.002 → 测的是选股，不是归属
- **四人画像重合**：超大单占比 0.18~0.22、换手 11.6~15.8%、分位均 >95 → 能识"游资"，不能识"是谁"

**所以现阶段能给的是「概率 + 硬判据」，不是「归属」。** 硬判据（T-1 榜有无 + 门槛）免费且确定性最高，先用它；概率打分（AUC 0.954）做候选排序；真正需要 tick 的只剩 800 万以下的暗流。

顺带查出的 **692 组席位重名（10.5% 节点）是 P0 级 bug**，它一直在低估游资覆盖率，10 分钟能修。
