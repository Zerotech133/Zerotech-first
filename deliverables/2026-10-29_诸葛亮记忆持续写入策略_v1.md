# 诸葛亮长期记忆持续写入策略 v1

- 日期：2026-10-29
- 状态：生效（代码自动写入）
- 范围：AI1 诸葛亮 / P1 长期记忆 `work/p1/memory/memory.jsonl`

## 1. 写什么

只写三类高价值、可复用信息：

| 类型 | 触发 | 示例 |
|---|---|---|
| decision | C1 质询卡结案为 accepted/approved | 决策标题 + 处理建议 |
| lesson | 人工显式写入（后续） | 踩坑后的纠正规则 |
| preference | 人工显式写入（后续） | 老田的稳定偏好 |

**不写**：原始质询全文、用户隐私、聊天原文、未结案提案、临时上下文。

## 2. 何时写

- C1 `sync_card` 发现决策状态变为 `approved` / `implemented` 时自动写；
- 同一决策重复同步不重复写（`zhuge_memory.remember` 按文本 sha256 去重）；
- 写入失败（磁盘/权限/模块异常）**fail-open**：不影响 C1 决策主链，只记 warning。

## 3. 口径

- `kind=decision`
- `confidence=high`（有 `decided_by`）
- `tags=[decision_id, card_id, "c1"]`
- `source=c1_decision`
- 文本 = `title：recommendation`，截断保护
- 过期策略：默认不过期；后续可按 `ttl_days` 人工 prune

## 4. 使用

- 自动：C1 每日/手动同步时写入；
- 手动种子：`python -X utf8 tools/zhuge_memory_seed.py --apply`（仅 approved/implemented）；
- 召回：`zhuge_memory.recall(query, k)`；`zhuge_grounding._memory_context` 只读；
- 关闭自动写入：`ZHUGE_MEMORY_AUTOWRITE=0`。

## 5. 边界

- 只写本地 `work/`，不入 git、不写业务库；
- 不改 C1 账本、不派单、不执行；
- 记忆是“经验召回”，不是事实源；事实仍以账本/证据为准。
