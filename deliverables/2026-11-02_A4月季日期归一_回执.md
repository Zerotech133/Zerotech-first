## 一、改法

`qualify_probe.norm_date` 扩展（保持原 YYYYMMDD/date 对象行为兼容）：

| 输入格式 | 归一结果 |
|---|---|
| `YYYYMMDD` / `YYYY-MM-DD` / `YYYY/MM/DD` / ISO datetime 串 | 当日 `YYYYMMDD`（取日期部分） |
| `YYYYMM`（如 `202608`） | **当月最后一天** `20260831` |
| `YYYY-MM` / `YYYY/MM`（如 `2026-08`） | **当月最后一天** `20260831` |
| `YYYYQn` / `YYYY-Qn`（如 `2026Q2` / `2026-Q4`） | **当季最后一天** `20260630` / `20261231` |
| epoch 秒/毫秒（数值或 10~13 位数字串）、parquet date32 天数 | 对应日期 |
| 非法值（月份 00/13+、季度 0/5+、`2026-02-30`、无法识别串） | **None**（fail-visible，probe 落 no_latest_date/no_date_column 等 reason，不静默当 ok） |

新增辅助：`quarter_end(year, quarter)`、`_parse_month_quarter(raw)`（返回 `(matched, value)` 以区分「不匹配」与「匹配但非法」）、`_norm_epoch`；`month_end` 复用（支持闰年 2 月：202402→20240229）。
