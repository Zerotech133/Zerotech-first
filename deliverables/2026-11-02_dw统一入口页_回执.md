## 四、关键发现：`/api/dw/*` 经 8734 被 H4-B 白名单拦截（当前 401）

实测（只读）：

```text
$ curl -s -i http://127.0.0.1:8734/api/dw/stats
HTTP/1.1 401 Unauthorized  (nginx/1.31.7)
{"ok":false,"error":"api_not_in_whitelist","message":"/api 前缀未在 H4 公开白名单登记，默认拒绝（见 portal/nginx.conf H4-B 段）"}
$ curl -s -i http://127.0.0.1:8091/api/dw/stats        # 直连 portal_api
HTTP/1.0 200 OK  {"ok":true,"total":314,"registered":265,...}
```

`portal/nginx.conf` 的 **H4-B（K-ORG-20261101-H4HARDEN）** 已把通用 `/api/` 从"公开基线"收敛为**显式白名单**，`dw` 一级前缀未登记 → 经 8734 默认拒绝；直连 8091 正常。

**页面处置（不越权改路由）**：启动时探测统一取数接口，401/403 自动进入**快照只读降级**并在横幅明示原因，用 `/static/dw_snapshot.json` + 公开 `/api/dataops/overview` 保证"目录/搜索/状态"可用，只有"样本取数"暂时不可用（点击「详情」显示登记口径 + 说明）。接口放行后**零改动自动切回全功能 API 模式**。
