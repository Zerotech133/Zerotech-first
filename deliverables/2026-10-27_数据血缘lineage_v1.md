# 数据血缘 lineage v1（DATA1 实施说明）

> 工单：`WO-DATA-LINEAGE-20261027` ｜ 日期：2026-10-27 ｜ 状态：**MVP 已实现**
> 依据：开源调研报告 §4.2 P0-7（OpenLineage run/job/dataset + facets）；LCS-1 冻结回执 lineage 段。

## 1. 目标

给数据任务补上**可追溯的 run/job/dataset 血缘**，并让冻结回执能携带、可校验：

```
数据任务开始/完成 → 发 START/COMPLETE 事件（run_id/job/inputs/outputs/facets）
→ manifest 生成冻结回执 lineage 段（name/version/sha256/produced_by/upstream）
→ 回执落 freeze_receipts → check 复算 sha256
```

- 本地 JSONL，零依赖；只写 `agent_platform/data/lineage/`（运行态）；
- 不连外部服务、不改数据根。

## 2. 事件 schema（OpenLineage 风格简化）

```json
{
  "schema": "lineage_event/v1",
  "event_type": "START|COMPLETE|FAIL",
  "event_time": "2026-10-27T16:00:00+08:00",
  "producer": "agent_platform/tools/data_lineage.py",
  "run": {"run_id": "r1", "job": {"namespace": "zerobound", "name": "ts_daily_sync"}, "facets": {}},
  "inputs":  [{"namespace": "table", "name": "tdx_raw"}],
  "outputs": [{"namespace": "file",  "name": "ts_daily", "version": "20261026",
               "uri": "quant_backtest/data/tdx/ts_daily"}]
}
```

## 3. CLI

```powershell
# 发事件（数据任务开始/完成）
python -X utf8 agent_platform/tools/data_lineage.py emit --job ts_daily_sync --status COMPLETE --run-id r1 \
  --inputs  '[{"namespace":"table","name":"tdx_raw"}]' \
  --outputs '[{"namespace":"file","name":"ts_daily","version":"20261026","uri":"quant_backtest/data/tdx/ts_daily"}]'

# 查某数据集由哪些 run 产出
python -X utf8 agent_platform/tools/data_lineage.py dataset --name ts_daily

# 生成冻结回执 lineage 段
python -X utf8 agent_platform/tools/data_lineage.py manifest \
  --datasets '["ts_daily","ts_adj_factor","ts_index_daily"]' --out work/lineage/lcs1_manifest.json

# 校验回执 lineage 与 sha256
python -X utf8 agent_platform/tools/data_lineage.py check \
  --receipt agent_platform/data/academy/freeze_receipts/AC-20261017-LCS1.json
```

退出码：0 正常/校验通过；2 输入或校验失败。

## 4. 冻结回执要求的 lineage 段

在 `freeze_receipts/<topic>.json` 增加：

```json
"lineage": {
  "datasets": [
    {"name": "ts_daily", "version": "20261026", "sha256": "<64hex>",
     "produced_by": "run-id", "upstream": ["tdx_raw"], "uri": "quant_backtest/data/..."}
  ]
}
```

- 必填：`name / version / sha256 / produced_by`；
- `uri` 存在时 `check` 会复算：文件=全文 sha256；目录=**目录指纹**（相对路径+文件大小+前 64KB 样本），避免对 21GB tdx 全量读；
- 回执四字段（data_version/sample_in/sample_out/cost_model）仍按冻结请求单。

## 5. 集成步骤（DATA1 冻结执行时）

1. 每个数据准备任务发 `START`/`COMPLETE`（含 inputs/outputs）；
2. 用 `manifest --datasets ...` 生成 lineage 段；
3. 与四字段+sha256 一起写 `freeze_receipts/AC-20261017-LCS1.json`；
4. `check --receipt` 通过（exit 0）后，BACK1 `BACK1Check` 才判 READY；
5. 回执 JSON 是运行态（不入 git），manifest 可落 `work/lineage/` 供审计。
