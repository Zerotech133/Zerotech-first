# 资金迁移本体：从"猜"到"证"

> 2026-11-06 · 零界 · 议题：游资资金迁移能否成为可验证的知识对象
> 本文所有数字均为本机 Neo4j + moneyflow.parquet 实测，脚本见 `tools/research/fund_migration_probe.py`

---

## 零、结论先行

你的判断**对**，但需要修正一处位置：**资金迁移不是一条关系，是一个竞争假设**。

建一条 `(:Security)-[:MIGRATED_TO]->(:Security)` 的边，等于把"猜测"写成了"事实"——图和因子都会把它当真。正确做法是把它建成 `:Hypothesis`，带多个 `rival`（竞争解释），靠证据打分升级或降级。项目里 `Hypothesis` 已经有 1,720 个、带 `rivals` 和 `uncalibrated` 字段，`INTEL_RD_PLAN.md` 早有 ACH 竞争假设分析法，这条路是通的，只是没接上资金流。

实测给出三层可验证性，差别是数量级的：

| 层级 | 判据 | 实测成立率 | 能否当证据 |
|---|---|---|---|
| **主体级**（同一游资同日卖 A 买 B） | 金额差 < 10% | **6.4%**（29/451 组），但金额高度吻合 | ✅ 可作 B 级证据 |
| **板块级**（板块间轮动） | 流入/流出比 0.8~1.2 | **12%**（109/929 日） | ⚠️ 只能测方向，不能测金额 |
| **全市场级**（5 亿出逃 → 5 亿进入） | 金额守恒 | **1.9%**（15/776 日） | ❌ 不成立，不可用 |

**关键结论：能不能证，取决于"有没有主体标签"。** `OCCUPIED_BY` 现在只覆盖 19.3%（83,150/431,277），剩下 80.7% 的资金流动，只能停在"全市场级"——也就是完全不可验证的那一层。

## 一、你说的两个推断，在数据上是两种东西

### 1.1 你的原话拆开看

> "陈小群今天这只股票大量资金出逃，出逃了 5 个亿"
> "全网 5000 多只股票，突然有 3 只股票各有 5 亿进入，是否可能是陈小群的钱进去了"

这是一个**跨标的、跨主体、同日的三角推断**：

```
    [A 股票] ── 出逃 5 亿 ──→ ?（不知道是谁）
                                  ↓  ?  ?  ?
    [B/C/D 股票] ── 各进 5 亿 ──→ ?（不知道是谁）
```

推断链是「A 的卖方 = B/C/D 的买方」。这个链条中间缺了两个环：**A 的卖方是谁**、**B/C/D 的买方是谁**。

### 1.2 实测：这两类事件在图里几乎不重叠

以交集最新日 **2026-10-16** 为例（`TradeAction` 到 10-16，`moneyflow` 到 11-05，取交集）：

**全市场净流出 top5：**

| 代码 | 净流出 | 超大单买 | 超大单卖 |
|---|---|---|---|
| 600418.SH | **-6.63 亿** | 10.27 亿 | 1.78 亿 |
| 002860.SZ | **-5.34 亿** | 5.36 亿 | 3.81 亿 |
| 300394.SZ | **-5.16 亿** | 11.71 亿 | 16.56 亿 |
| 688498.SH | **-5.15 亿** | 10.72 亿 | 15.79 亿 |
| 002636.SZ | **-5.03 亿** | 4.32 亿 | 6.41 亿 |

**你说的"5 个亿"量级，完全真实**——每天都有 5 只票净流出 5 亿左右。

**但这 10 只票（净流出 top5 + 净流入 top5），当日在龙虎榜上一条记录都没有。**

这就是问题的真相：**"5 亿出逃"是 `moneyflow` 能看到的，"谁在卖"是龙虎榜才能看到的，而龙虎榜只覆盖极端异动**。两者交集极小，中间没有桥。

### 1.3 更麻烦的是：龙虎榜自己把卖出侧漏了

| 维度 | 实测 |
|---|---|
| 标的-日 组合 | 51,808 |
| 买入满 5 席 | **39,171（75.6%）** |
| 卖出满 5 席 | **13,813（26.7%）** |
| 卖出侧 0 笔的天数 | 1,808 |
| 卖出侧 1~2 笔 | 12,490 |

真龙虎榜每日每股应披露"买入前 5"和"卖出前 5"，两侧对称。实际卖出侧只有 **26.7%** 满 5 席——**你想知道"谁在出逃"，数据源恰好把出逃那一侧漏了 73%**。

后果直接：**"谁在出逃"这个问题，用现有龙虎榜数据无法回答。** 这不是算法问题，是采集缺口。而且买入侧还有 420 行金额异常（最大 3,009 亿，p99 才 6.09 亿，差 472 倍，全在年末半年末），一并污染了统计。

## 三、为什么"金额守恒"这条路走不通

全市场层面，我实测了 776 个交易日：每日 top5 净流入合计 ÷ top5 净流出合计，**中位 6.687**（p10 1.786 / p90 58.792），落在 0.8~1.2 的只有 **15 天（1.9%）**。

板块层面稍好：929 日里 **109 日（12%）** 落在 0.8~1.2。

**根本原因是 `net_mf_amount` 不是零和的。** 它是按主动买/主动卖划分的四档（小/中/大/超大单）净额，全市场逐日求和的中位数是 **-310 亿**——理论上每笔买入都有卖出，应该趋近 0，实际却系统性偏负。原因有两层：

1. **主动成交口径天然有偏**：主动买 = 吃卖单，主动卖 = 砸买单，两者不是同一批钱；
2. **缺席的资金**：出逃的钱不一定进股票（可能离场、进债券、进理财），所以"流出 ≈ 流入"在真实市场里本来就不成立。

**所以：任何靠"金额相等"来配对资金迁移的算法，命中率上限只有 1.9%~12%，做完就是噪声。** 这是本轮最重要的否证。

## 四、正确建模：迁移是竞争假设，不是一条边

### 4.1 为什么不能建边

如果建成 `(:Security)-[:MIGRATED_TO {amount}]->(:Security)`：

- 每对股票都可能连边 → 5,912 × 5,912 / 2 = **1,748 万条潜在边**，图立刻稠密化
- 边的语义是"可能"，但图上查询会把它当"是"
- 因子把 `MIGRATED_TO` 计数当特征 → 学到的是噪声
- 一旦错了，删边要重算全图

**这正是我上一轮说的"因子不该做节点、该做边上的探针"同一个错误的反面——把假设做成事实。**

### 4.2 三层对象

```
  第 1 层：事件（客观、可观测、双源）
  ─────────────────────────────────────
  (:TradeAction)  龙虎榜主体级   431,277 条  ← 已有，缺卖出侧
  (:FlowEvent)    全市场量能级   475 万行    ← 新建，来自 moneyflow
        │
        └─ BRIDGES ── 同日同标的 → 带 overlap 分数（弱链接）

  第 2 层：假设（主观、有竞争、可证伪）
  ─────────────────────────────────────
  (:Hypothesis {
      claim: "陈小群 T 日自 A 换仓至 B",
      kind: "capital_migration",
      confidence: 0.62,
      rivals: ["A/B 分属两个独立游资", "同日巧合"],
      falsifiers: ["T+1 B 出现同席位继续买入", "A 的卖方席位已确认为他人"],
      uncalibrated: true
  })
        │
        └─ EVIDENCED_BY ─→ TradeAction / FlowEvent

  第 3 层：结论（校准后、可回溯、有时点）
  ─────────────────────────────────────
  (:MigrationVerdict {level: A|B|C, decided_at, decay})
```

**关键：第 1 层永远不写"迁移"，只写"两个事件同日在两个标的上发生"。** 迁移是第 2 层的假设，靠第 3 层校准。

### 4.3 打分公式（可算，不是拍脑袋）

```
confidence = w1 · amount_match      // 1 - |买-卖|/卖        实测中位 0.689 → 0.311
           + w2 · subject_bonus     // 同游资 1.0 / 同营业部 0.5 / 无主体 0
           + w3 · sector_distance   // 跨板块 1.0 / 同板块 0.3（跨板块更符合实证）
           + w4 · follow_through    // T+1..T+3 买入席位再现同游资
           - w5 · alternative_explain // 存在竞争假设且证据更强则扣减
```

初值建议 `w1=0.35, w2=0.30, w3=0.15, w4=0.20, w5=0.30`，但**必须标 `uncalibrated: true`**，等回测校准。这跟项目里 `Hypothesis.uncalibrated` 字段的语义完全一致。

**分层判定门槛与证据等级对齐：**

| 置信度 | 等级 | 含义 | 能干什么 |
|---|---|---|---|
| ≥ 0.75 | **A** | 金额吻合 + 同游资 + 有跟随 | 直接进因子 |
| 0.45~0.75 | **B** | 金额吻合 + 同营业部 | 进假设池，人工抽审 |
| 0.20~0.45 | **C** | 仅同日 + 跨板块 | 只做提示，不进因子 |
| < 0.20 | — | 丢弃 | 不建节点，避免噪声入图 |

## 五、七维坐标：为什么"人地事物组织时空"正好是这个问题的骨架

你说"都属于知识、属于实体链接变化"——对。迁移的每一维都有实测对应物，不是概念套壳：

| 维 | 在迁移里的角色 | 图内实测存量 | 当前用在因子上的数量 |
|---|---|---|---|
| **人** | 谁在换仓（游资/营业部/机构） | Person 192,031 / HotMoney 21 | **0** |
| **地** | 营业部所在地 vs 标的注册地（异地资金） | Location 边 346,083 | **0** |
| **事** | 龙虎榜上榜事件、涨停、公告 | MarketEvent 683,910 / TradeAction 431,277 / Event 165,376 | **0** |
| **物** | 标的 A → 标的 B | Security 5,912 | **252 个因子挤在这** |
| **组织** | 板块、行业、产业链位置 | Industry 110（`INDUSTRY_OF` 94.4%）/ Concept 430 | 19 |
| **时** | 同日 / T+1 / 连续 N 日 | 776 交易日 | 0 |
| **空** | 板块间距离、产业链距离、地理距离 | 同「地」+「组织」 | 0 |

**「时」这一维是让迁移从"统计相关"变成"因果可追溯"的唯一关键**，而且 A 股制度恰好让同日换仓成立：

- 卖出股票的资金 **T 日当日即可用于买入**（资金 T+0 可用）
- 买入的股票 **T+1 才能卖出**（股份 T+1）

所以「T 日卖 A、T 日买 B」在制度上完全可行且是高频行为——**陈小群 38% 的交易日就是这么干的**。这条制度事实，是整个迁移假设能成立的物理基础。

**「空」这一维现在完全没有数据支撑**：7/8 跨板块是实测出来的，但"板块间距离"没有度量。产业链距离可以用 `SUPPLIES_TO`（只有 20 条边，远不够）、地理距离可以用 `Location`（346,083 条边，够用但没用过）。

## 六、落地：三件事，不动现有代码

### 6.1 第一步：建 `FlowEvent`（补上"量能级"这一层，1 天）

`moneyflow.parquet` 已经躺在 `data/tushare_curated/`，**475 万行 × 20 列，929 日 × 5,730 股**，四档买卖额 + 净额全有。不需要采购。

```cypher
(:FlowEvent {
  id, ts_code, trade_date,
  net_mf,                      // 净流入（万元）
  buy_sm, buy_md, buy_lg, buy_elg,
  sell_sm, sell_md, sell_lg, sell_elg,
  elg_net,                     // 超大单净额，迁移的主判据
  knowledge_time               // = trade_date 收盘后，PIT 严格
})
-[:FLOW_OF]->     (Security)
-[:FLOW_IN]->     (Industry)
```

**为什么不复用 `TradeAction`**：`TradeAction` 是"某席位在某股上的成交"，`FlowEvent` 是"某股当日的全市场量能"，粒度和来源都不同。合并会污染主体级信号。

### 6.2 第二步：修卖出侧（这是真正的缺口，需要决策）

卖出侧只有 26.7% 满 5 席。三条路：

| 方案 | 成本 | 能补多少 | 风险 |
|---|---|---|---|
| **A. 重采 tushare `top_inst`（按 `trade_date` 逐日拉）** | 低，接口已有 | 取决于上游是否本就缺 | 上游缺就白干 |
| **B. 换数据源（同花顺/东财龙虎榜，卖出侧齐全）** | 中，需采购 | 可到 95%+ | 字段口径要归一 |
| **C. 用 `moneyflow` 的 `sell_elg` 反推量级，主体留空** | 零成本 | 只补量能，主体仍缺 | 只能做 C 级假设 |

**建议先 A 后 B。** A 是零采购验证：拉 5 个交易日对比，如果上游本来就缺，立刻转 B。

### 6.3 第三步：`kg_migration.py`（假设生成器，2 天）

输入 `TradeAction` + `FlowEvent`，输出 `Hypothesis(kind='capital_migration')`。三条产出路径：

1. **主体级**（置信度最高）：同游资/同席位，同日，卖 A 买 B，`|买-卖|/卖 < 0.10` → 直接 A/B 级
2. **板块级**：同日 A 板块净流出 > 2 亿 且 B 板块净流入 > 2 亿，且 A/B 无 `SUPPLIES_TO` 关系 → C 级假设
3. **跟随级**：T 日假设成立，T+1~T+3 同游资在 B 继续买入 → 升级置信度

**必须先跑 dry-run**，输出"如果建，会建多少个假设、各等级多少"，再决定写不写库。

## 七、三个必须说清的边界

1. **"5 亿出逃"能测，"谁在出逃"测不了。** 前者靠 `moneyflow`（全覆盖），后者靠龙虎榜（卖出侧缺 73%）。在补齐卖出侧之前，任何"A 的卖方是陈小群"的判断都是编的。

2. **金额相等不是证据，主体相同才是。** 全市场守恒率 1.9%，板块 12%，主体级 6.4%——**越低层越不可信**。所以宁可少建假设，也不要为了"看起来覆盖全市场"去建全市场级的迁移边。

3. **迁移假设必须有 `falsifiers`。** 至少三条：T+1 同席位未再现（说明不是他）、A 的卖方席位已确认为他人、A/B 同属一个产业链上游下游（说明是套利不是轮动）。**没有证伪条件的假设，进了图就是永久噪声。**

---

## 八、一页话

你说的"都是知识、都是实体链接变化"，成立。但**实体要分三层：事件是事实、迁移是假设、结论是校准结果**。把假设做成边，等于让系统把猜测当记忆——这正是过去 271 个因子全挤在"物"维、8 个图特征空转的同一个病根。

实测给的最硬一条：**陈小群 445 个交易日里 169 天在换仓，29 组卖 A 买 B 金额差不到 10%，7/8 跨板块。** 这条链是通的、可证的、能进因子的。而全市场"5 亿出逃对应 5 亿进入"只有 1.9% 成立——**那不是知识，那是噪声**。

**所以先做主体级，别做全市场级。** 主体级有 934 条真实记录撑着，全市场级只有数学上的巧合。
