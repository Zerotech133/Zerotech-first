## 三、影响面
| 项 | 说明 |
|---|---|
| 服务中断 | 8091 portal-api **短暂重启（约 5–20s）**；期间门户动态接口不可用，静态页/静态 JSON 不受影响（nginx 同源） |
| 依赖方 | 依赖 8091 的页面（数据仓动态区、投研页等）在窗口内会 502/失败一次 |
| 知识库数据 | **零影响**（只读接口，不写数据） |
| 时间建议 | 任一低峰（如 08:00 前或 22:00 后），或明早 08:30 前完成（H14 节点 08:30 不受影响，因为 H14 走计划任务非 8091） |

## 四、不可逆点
- 无数据不可逆：仅进程重启 + 代码接线（git 可回滚）。
- 若接线后 import 断链：`start_portal_api.ps1` 预检会**拒绝启动**（红线条），此时回滚 = `git revert` 接线提交并重启。
