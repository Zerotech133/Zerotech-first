# W27 multi 两问题修复回执（自检空答案 / 同源重复引用）

日期：2026-11-05
范围：`tools/kb_corpus/kb_qa_multi.py`（生产 multi 生成的公共入口）、`tools/tests/test_citation_retry.py`
生产状态：`KB_QA_LLM_PROVIDER=ollama`（沿用 2026-11-05 回滚决策，本次未重启生产）

## 1. 问题与修复

### 1.1 自检修正后空答案 → 干净拒答

**现象**：v4d 在资料不足时输出
`【自检修正】上一条回答的有效引用不足 2 个不同知识单元。现重新作答如下：`
后无任何有效内容，仍以 `refusal=false`、`confidence=low` 返回半句。

**修复**（`kb_qa_multi.py`）：
- 新增 `REFUSAL_ANSWER = "知识库中没有足够依据回答该问题。"`；
- 新增 `_strip_retry_echo()`：删除含「自检修正」「重新作答如下」的提示残句；
- 新增 `clean_multi_answer(answer, clusters)`：
  - 清空后无内容 → `REFUSAL_ANSWER`；
  - 仅剩提示残句、且清洗后没有任何 `[unit_id]` 引用 → `REFUSAL_ANSWER`；
  - 清洗后仍有有效答案/引用 → 保留；
- `answer_multi()` 在非 `fallback` 路径统一调用清洗，再执行 `validate_multi_answer` / `assess_confidence`；fallback 路径不受影响。

**真实 v4d 复现验证**（生产同题复放，`mode=multi,k=6,llm-provider=router,no-guard`）：
- 题：`布林线中轨的突破信号是否有效`
- 修复前：37 字，只有自检修正残句，0 引用，confidence=low；
- 修复后：**`知识库中没有足够依据回答该问题。`**，0 引用，confidence=**none**，5.09s，成本约 ¥0.0018；
- 回归：正常可答题（M9 覆铜板）仍输出 2 条引用，不被误拒。

### 1.2 同源重复引用去重

**现象**：v4d 推断行出现 `（依据：[381811df2585] p.1、p.1）`，同一来源/页码在括号内重复；同一事实行偶发重复。

**修复**（`kb_qa_multi.py`）：
- `_dedupe_inline_cites()`：同一括号内重复 `[unit_id] p.n`、重复纯页码（`p.1、p.1`）只保留一次，并清理悬空分隔符；
- `_normalize_fact_line()` + 清洗循环：归一化（去引用/页码/标点空白）后完全相同的事实/推断行只保留一条；
- 不改 `validate_multi_answer()` 的 `cited_ids`/citations 契约，不改变 `retry_info` 字段形状（既有断言保持）。

**真实 v4d 复现验证**：
- 题：`知识图谱如何识别叙事矛盾`
- 修复前：推断依据 `（依据：[381811df2585] p.1、p.1）`；
- 修复后：`（依据：[381811df2585] p.1）`，334 字，1 条可核验引用，confidence=medium，11.36s。

## 3. 影响面与风险

- 仅影响 multi 非降级路径的**答案文本清洗**；single 路径、检索、prompt、guard、citations 列表契约不变。
- 清洗规则保守：只删自检提示残句、完全重复的事实行、同括号重复引用；不同事实行即使同源也保留（避免丢信息）。
- 若模型在正常答案里无意写出「重新作答如下」句子，可能被删除；该短语仅用于自检提示，风险低。
- 生产当前仍为 Ollama；本修复在下次 L2 重启后对生产 multi 生效（Ollama 正常答案通常不含自检残句，主要收益在切回 v4d 后的资料不足场景）。
