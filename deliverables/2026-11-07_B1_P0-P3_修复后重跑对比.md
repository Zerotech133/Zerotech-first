## 0. 结论摘要

1. **P1 holdout 真实 Sharpe 为 `-0.1535`，年化 `-0.984%`，MDD `-9.77%`**；旧报告的 `+0.4238 / +3.1034%` 不成立。
2. 修复后的 P0/P1/P2/P3 **60d holdout Sharpe 全部为负**：P0 `-0.2451`、P1 `-0.1535`、P2 `-0.2153`、P3 `-0.1214`。
3. 旧正收益的主要来源不是 alpha，而是 **回测尾部多算了 22 个交易日**；P1 旧序列 443 天，实际应为 421 天，多出的 22 天累计收益 **+5.98%**。
4. 即使把成本降到 0bp，P0/P1/P2/P3 的 holdout 仍全部为负；成本不是唯一原因。
5. **建议：撤销 P3 候选资格，不接生产，也不再以“P3 候选”对外引用。** P0 仅保留为研究基线；P1/P2/P3 均不升级。

## 1. 重跑口径与修复影响

本次重跑使用修复后的 `factor_lib.py`、`factor_portfolio.py` 和 `run_b1_prior_strategy.py`，关键变化：

- `simulate(..., end=...)` 现在严格截断到最后有效交易日；旧版会把最后持仓持有到面板末日 `20261105`，而声明 end 是 `20260929`。
- 首次建仓不再被 `max_one_way_turnover=0.3` 截断，首日允许建满目标 gross。
- 删除了 `prior` 的二次漂移；换手和成本按实际成交计算。
- 多空/事件收益不再重复扣成本；换手成本只在组合层扣一次。
- 重叠 20 日 IC 的 t 值改为 Newey-West HAC；旧报告的 t 是 IID t，偏大。
- 中性化默认使用 PIT L2 行业映射，不再默认用当前行业快照。
- 退市股、`list_date`、ROE 年化、PEG/B3 方向、bootstrap block 等修复也共同影响结果。

> 因此本报告的新数字是“修复后引擎 + 当前数据”的完整重跑，不是对旧数字做手工扣减。

## 4. dev 端变化（不要误读）

修复后 dev 端并非全部变差：

- P0 dev 60d：旧 `0.5146% / 0.0882` → 新 `2.5412% / 0.6323`，明显变好。
- P1/P2/P3 dev 60d 均为小幅负值：P1 `-0.1785% / -0.0466`，P2 `-0.1476% / -0.0408`，P3 `-0.1870% / -0.0495`。

这说明 dev 段对首次建仓、换手 cap、prior 漂移等修复很敏感；**不能用 dev 变好来挽救 holdout**。研究判定仍以 holdout 为准。

## 6. 差异来源

按影响从大到小：

1. **尾部 22 个交易日**：旧 `simulate` 没有在声明 end 截断。P1 旧 443 天中多出的 22 天贡献 +5.98%；这几乎单独解释了旧 P1 的正收益。
2. **首次建仓与换手**：修复后首次建仓不再被 30% cap 截断，换手从 1.365 升到 1.556，成本从 0.72% 升到 0.78%；对高换手组合是持续拖累。
3. **prior 二次漂移**：旧路径重复漂移一次，改变了实际持仓与换手。
4. **成本口径**：旧多空收益把每只股票都扣一次成本后在 Q5−Q1 抵消；修复后只在组合层扣一次，毛/净口径更真实。
5. **PIT 行业映射、退市股、ROE、PEG/B3 方向**：影响 IC 与组合选股，但 IC 均值变化很小，说明主要不是 IC 信号本身被改写。
6. **HAC t**：不改变收益，但把“统计显著”从 15 降到 4 左右，降低了过强结论的可信度。

## 7. 对 P3 候选的建议

**建议：撤销 P3 候选资格（retire / 归档为失败研究），不接生产，不再作为候选维护。**

理由：

- 预注册 Sharpe 门槛未过，且不是小幅未过；
- 5%/7.5%/10% 三档全部负 Sharpe；
- 修复后 0bp 仍为负；
- 此前归因已经证明 `b1_mom_21d` 与 `return_21d` 秩相关 1.0，P3 只是重复暴露；
- 旧 P3 的 +3.17%/.442 是旧引擎尾部/口径产物，不可继续引用。

P0 仍可作为“先验基线/对照”，但也不构成可交易策略；P1、P2、P3 均不应升级。若未来继续 21d 方向，必须：

1. 在修复后引擎上重新预注册，不得复用旧阈值；
2. 先解决“IC 约 0.10 但组合负收益”的传导问题（组合构建、成本、尾部风险）；
3. 不再把 P3 的旧结果写进对外材料。
