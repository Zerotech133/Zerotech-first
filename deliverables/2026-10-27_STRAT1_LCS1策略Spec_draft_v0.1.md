## 1. 研究问题与可证伪假设

- **研究问题**：图形先行、事件和资金佐证的方法能否形成稳定、可复现、可交付的策略能力？
- **主假设（H1）**：先由图形推演出运作假设，再用事件与资金做**定向**核验，其样本外判别力优于（a）仅图形、（b）仅事件、（c）仅单一指标。
- **竞争假设（H0）**：LCS-1 信号在样本外无超额，或超额来自样本选择/数据泄漏（成本后归零）。
- **否定条件（必须可证伪）**：
  1. 样本外（2025-07-01~2026-10-16）成本后超额 ≤ 0，且 bootstrap 95% CI 含 0；
  2. 3 个等长子区间中 ≥2 个区间方向为负；
  3. 去除事件/资金单层后结果无显著下降（说明分层无增量信息）；
  4. S3 回放对账一致率 <99%（口径不可复现）。
- **结论等级**：事实 / 推断 / 暂定 / 否定 / 未知；禁止把「故事」当证据。

## 2. L1 图形算子（完全引用既有实现，不另造口径）

实现：`tools/chart_hypothesis.py`（纯 pandas，可复算）。五算子定义与本 Spec 采用阈值如下（**与代码逐条对齐，改动须同步 ADR/工单**）：

| 算子 | 名称 | 判据（代码阈值） |
|---|---|---|
| 1 | 放量吸筹嫌疑 `accumulate` | 60 日振幅 < 25% 且 250 日位置 < 40% 且 近 60 日「量比 ≥3」放量日 ≥3 且 箱底不破（收盘最低 > 60 日最低 × 0.97） |
| 2 | 缩量洗盘嫌疑 `wash` | 近 20 日均量 < 前 20 日均量 × 0.8 且 60 日回撤 < 15% 且 60 日内存在「涨幅 >4% 且量比 ≥2.5」的拉升日 |
| 3 | 对倒出货嫌疑 `distribute` | 250 日位置 > 80% 且（近 20 日出现「跌幅 >4% 且量比 ≥3」天量长阴 或 近 20 日长上影 ≥5 天） |
| 4 | 抢跑异动嫌疑 `runup` | 近 90 日存在「涨幅 ≥5% 且（量比 ≥2.2 或 前 5 日均量 < 60 日均量 × 0.6 的地量骤放）」 |
| 5 | 无为自然 `idle` | 算子 1–4 全部未命中 |

- **主假设排序**（代码 `primary_hypothesis`）：抢跑 > 出货 > 吸筹 > 洗盘 > 无为。
- 输出：`ops`（五算子 hit/evidence/runup_days）+ `context`（close/pos250/量缩比/amp60）+ `primary`。
- 可复现命令：`python tools/chart_hypothesis.py 600337`（单标的演示；回测批量由 BACK1 按冻结数据执行）。
- **已知局限**：五算子是量价几何近似，非主力意图真值；对倒/吸筹可能同图不同因；须靠 L2/L3 定向核验（这是 LCS-1 的差异化所在）。

## 3. L2 事件佐证（三态）

**核验对象**：L1 主假设为 `runup` 时，核验「异动日 vs 公告日的时间耦合」；`distribute` 时核验「利好兑现/高位公告」；`accumulate/wash` 时核验「无公告支撑的隐性建仓/洗盘」是否成立（缺证）。

**数据源**：
- `news_collector/news.db` → `news` 表（`id, source, ts, title, content, hit, pushed, digested, stocks, jev`）；
- 可选补充：`ts_news` / `ts_major_news` / `ts_cctv_news`（法定/媒体级，按 DATA1 冻结清单为准）；
- 知识图谱事件（`kg_graph`）暂列 v1.1 可选，不进 v1 判定，除非冻结清单明确纳入。

**规则草案（待 ACAD1 评审）**：
1. 对每个 `runup_days` 异动日 `t0`，在 `[t0, t0+20 交易日]` 窗口检索与标的相关的公告/新闻事件 `t1`；
2. 领先天数 `lead = 交易日数(t0 → t1)`：
   - `0 < lead ≤ 10` → **佐证**（内幕/抢跑特征）；
   - `lead ≤ 0`（公告先于异动）→ 视事件性质：若为利好兑现且高位放量 → **证伪**（借利好出货）；否则**无关**；
   - 窗口内无相关事件 → **存疑**；
3. 事件相关性判定：先说「公告/新闻是否含该标的 + 是否属重大事项（重整/控制权/业绩/订单/监管）」，再谈方向；**不把全市场新闻当个股事件**（判例：`news_collector` JEV 池化误配）；
4. 输出三态：`support` / `refute` / `unknown` + 证据（新闻 id/标题/日期/lead）。

## 4. L3 资金佐证（三态）

**数据源（法定级）**：`ts_top_inst`（龙虎榜机构）、`ts_top_list`（龙虎榜明细）；可选 `ts_moneyflow` / `ts_moneyflow_dc` / `ts_hsgt_top10`。
**规则草案**：
1. 检查异动日/信号日是否上榜（龙虎榜覆盖「达标日」，覆盖不全 → 未上榜=**存疑**，不默认证伪）；
2. 上榜时计算：买方前 5 席位净买额、卖方前 5 席位净卖额、机构专用席位方向；
3. 与 L1 假设匹配：
   - `accumulate/runup`：买方净买 >0 且卖方无「前期介入知名游资/机构专用大额卖出」→ **佐证**；卖方出现前期主力大额出货 → **证伪**；
   - `distribute`：卖方净卖 >0（尤其机构/知名游资）→ **佐证**；买方仅散户席位且股价不涨 → **存疑**；
   - 反例判据：买一买二同地域/高协同席位后未在卖方出现 = 锁仓信号（辅助，不作主判据）；
4. 输出三态 + 席位证据（营业部/机构、净额、日期）；**数据血统**必须标注（机器级/法定级/需降噪）。

## 5. L4 定性 → 候选池 → 研究信号（边界写死）

- **定性状态**：
  - `定性成立`：L2 或 L3 至少一项 `support`，且无 `refute`；
  - `存疑观察`：证据矛盾或缺失；
  - `散手票`：`idle`（L1 已出局，不进入 L2/L3 查证，节省成本）。
- **候选池**（本策略唯一对外产出）：`定性成立` 且 `primary ∈ {accumulate, runup}`（`distribute` 为风险信号，不进候选池；`wash` 仅观察）。
- **研究信号**：候选池 + 风控三师（R1/R2/R3）与 D1 复核后才成为「研究信号」；**执行信号/下单不属于本 Spec**，`execution_allowed=False`。
- **禁止**：L4 在证据矛盾时加权/强行 BUY；存疑只能 WATCH；`distribute` 不得输出买入候选。

## 6. 数据需求（冻结令牌清单 → DATA1 回执四字段依据）

| 编号 | 用途 | 数据令牌/表 | 字段要点 | 窗口/口径 |
|---|---|---|---|---|
| D1 | L1 量价 | `ts_daily`（或 `quant_backtest/data/ashare` parquet）+ `ts_adj_factor` | trade_date/open/high/low/close/volume/amount/pct_chg；后复权因子链 | 样本内+样本外，逐日 |
| D2 | 基准 | `ts_index_daily` | 沪深300（000300.SH）或等权全市场基准 | 同窗口 |
| D3 | L2 事件 | `news_collector/news.db`（`news` 表，`jev` 字段）/ 可选 `ts_news` | id/ts/title/content/stocks/jev | 异动日±20 交易日窗口 |
| D4 | L3 席位 | `ts_top_list`、`ts_top_inst` | 营业部/机构席位、买卖额、净额、日期 | 信号日及前后 1 交易日 |
| D5（可选） | 资金辅助 | `ts_moneyflow`/`ts_moneyflow_dc`/`ts_hsgt_top10` | 主力/超大单净额、北向 | 同窗口；未纳入则全程不用 |
| D6（v1.1） | KG 事件/形态 | `kg_graph`（MATCH Security-[:HAS_PATTERN/HAS_VOL_EVENT]->me） | kind/date/type/vol_ratio | v1 不纳入，避免数据血缘扩张 |

- **股票池**：A 股全市场可交易池，剔除 ST/停牌/上市不足 250 交易日；持仓/回测按信号日可交易性过滤。
- **样本窗口（与冻结请求单一致）**：sample_in `2023-01-01 ~ 2025-06-30`；sample_out `2025-07-01 ~ 2026-10-16`；锚定样本 600337 仅用于口径校准，不参与样本外统计。
- **成本口径**：以 `quant_backtest/fee_schedule.py`（commission_rate/commission_min/stamp_duty_rate/transfer_fee_rate）与 `quant_backtest/fill_model.py` 现行参数为准，DATA1+BACK1 写死登记；保守成本压力测试另跑 ×1.5。
- **冻结判据**：四字段（data_version/sample_in/sample_out/cost_model）+ sha256 回执；BACK1 `BACK1Check` 判 READY 才开跑（规则见 `research_seat_ops.py`）。

## 7. 回测协议（BACK1 执行，STRAT1/ACAD1 复核）

1. **信号时点**：t 日收盘后计算 LCS-1（L1 用截至 t 的 K 线，L2/L3 只用 t 及以前可得数据）→ t+1 开盘买入（避免未来函数）；事件数据 as-of 截断。
2. **组合形式**：先做事件研究（每个「候选池」事件的前向 5/10/20 日超额），再做等权/上限持仓组合回测；两者分开报告。
3. **出场**（草案，回测前预注册，不得事后挑参数）：
   - 固定持有 N∈{5,10,20} 交易日；或
   - 结构止损：跌破信号日关键位（1买/3买低点或 -8%）；或
   - 风险信号出场：L1 转 `distribute` 或 L3 证伪。
   三种方案各跑一遍，**按样本内表现预选 1 种**，样本外只验证不重选。
4. **对账**：S3 回放对账与既有基线口径一致率 **≥99%**；否则先修口径再谈结论。
5. **样本量**：每个假设分组 n≥30；不足则结论只能「存疑/补证」，不得出 Go。
6. **可复现**：命令、参数、数据版本、产物哈希全落回测报告；严禁手改结果。

## 8. 指标与 Go/No-Go 初判（草案阈值，待 ACAD1/老田签）

| 指标 | 初判阈值（草案） |
|---|---|
| 样本外成本后超额（vs 等权基准） | > 0；bootstrap 95% CI 下限 > 0 |
| PF | ≥ 1.1 |
| 最大回撤 | ≤ 基准回撤 + 5pp |
| 稳定性 | 3 个等长子区间 ≥2 个同向；top 假设分组不依赖单一板块 |
| 样本 | 每组 n ≥ 30；事件研究窗口覆盖 ≥ 2 个市场状态 |
| 复现 | S3 对账 ≥99% |

**判定映射**：全部达标 → 建议 Go（试点/产品化，仍须老田签）；部分达标 → 补证/限缩（如只保留事件研究结论）；核心证伪 → No-Go（终止或重立项）。**任何结论未经评审不得外发**。

## 10. 风险与合规边界

- 样本选择偏差（600337 为案例校准样本，不作为回测样本外）；数据血缘/版本漂移；事件标注延迟与 JEV 误配；席位数据覆盖不全；过拟合（多算子/多出场参数组合）；对外表达构成投资建议风险。
- 本策略**只产研究结论与候选池**，不连接交易执行；不承诺收益；不对外发布未评审结论。
