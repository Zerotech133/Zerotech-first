## 三、关键默认值（可配）

| 参数 | 默认 | 说明 |
|---|---|---|
| `--max-attempts` | 3 | 单页总尝试次数（含首次，≤3） |
| `--backoff-base` | 5.0s | 退避基数：第 2 次等 5s、第 3 次等 10s |
| `--batch-size` | 15 | 每批码数上限；pool 模式每轮 1 批 |
| `--batch-index` | 0 | pool 模式取第几批（多窗口轮换用） |
| `--fail-rate` | 0.20 | 失败率阈值（>` 阈值 → rc=2 + 告警） |
| `--pages` | 2 | 每码翻页上限（沿用） |
| `--no-shuffle` | 关 | 随机顺序默认开启（`--seed` 可复现） |
| `--alert-direct` | 关 | 采集器直调告警链（默认由 launcher rc≠0 链负责，避免双告警） |
