## 三、统一信封（所有通道）
```json
{"api_version":"1.0","request_id":"…","ok":true,"data":{…},"error":null,"generated_at":"…"}
```
错误码：`INVALID_ARGUMENT(400)` / `NOT_FOUND(404)` / `NOT_READY(503)` / `UPSTREAM_UNAVAILABLE(502)`；失败退出码非 0。

## 四、Unit 核心字段（消费方必须带出处）
`id`（sha1 稳定 12 hex）/ `source`（书籍|研报）/ `book` / `chapter` / `page_start` / `page_end` / `concept` / `claim` / `evidence`（search 另含 `score`）。

## 五、消费方规则（已写入规范 §五）
1. 引用必带 `book/chapter/page`；2. 证据不足答「未覆盖」；3. 只读（更新走入库流程）；
4. CLI 30s / HTTP 10s 超时，失败重试 1 次；5. 以 `generated_at` 判断新鲜度；6. `api_version` 不兼容拒绝消费。
