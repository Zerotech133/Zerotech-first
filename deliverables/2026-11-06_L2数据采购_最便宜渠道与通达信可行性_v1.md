# L2 数据在哪买最便宜 & 通达信能不能"盘后推演"

> 触发：老田问"全网哪个平台最便宜"+"本地用类似通达信的工具能不能看到，不需要实时，半小时一小时推演就行"
> 方法：本机实测（pytdx / mootdx / akshare）+ 多源价格交叉 + 区分"分笔"与"逐笔"
> 结论前置：**最便宜是 0 元（找券商要），不是买。而通达信"能看"是真的，"能下载来推演"有陷阱。**

## 二、问题二：通达信能不能看到

### 能看，而且"盘后下载"这个功能正好对您的节奏

通达信 L2 版有 **【系统】→【盘后数据下载】（Ctrl+F5）**：

- 勾选项含「沪深分钟线」「**沪深分笔成交数据**」
- 支持时间区间、可选「全部 A 股」
- **15:30 之后下载当日数据才完整**（收盘前下会残缺）

这条对"不需要实时、半小时到一小时推演"是完美匹配——您 15:30 之后点一下，数据就齐了。

### 但这里有个陷阱，我必须先说清

**通达信盘后能下的"分笔成交"，大概率不是 L2 逐笔，而是 3 秒快照聚合。**

依据（百度百科"分笔成交"词条，技术定义准确）：

> "在传统行情中，分笔成交数据是基于固定时间间隔（如 5 秒或 3 秒）的快照，显示该时间段内的累计成交情况……**分笔成交与逐笔成交不同**……**分笔成交是聚合后的数据**"
> "传统行情是 6 秒撮合数据，level2 是 3 秒撮合数据"

**这意味着：如果下到的只是 3 秒分笔，那它和我们免费从 pytdx 拉的、已经入库的 9 年数据完全相同。花 258 元买到的"历史"，一分增量都没有。**

网上有券商顾问声称"沪深分笔成交数据就是 L2 逐笔 tick"——**这个说法与上述定义冲突，我不采信，标为待实测。**

### 补充实测：下载下来也读不出来

我装了 `mootdx` 看它能不能读通达信本地文件，结论是：

```
reader.py 只有 4 个读取器：
  daily()   → vipdoc/*/lday/*.day
  minute()  → vipdoc/*/minline/*.lc1
  fzline()  → vipdoc/*/fzline/*.lc5
  block()   → 板块
没有 tick / 分笔 读取器
```

**通达信本地 tick 文件没有现成开源解析器。** 要读只能自己逆向文件格式。

再加上一条已知限制（券商顾问原话）：**"部分券商定制版通达信，会限制 L2 数据导出，仅支持软件内查看，不能直接导出外部文件。"**

### 顺带把零成本路线全部测死了

| 方案 | 实测结论 |
|---|---|
| `pytdx`（我们已在用） | 25 个接口，`get_security_quotes` **只有五档**，无十档无队列 |
| `akshare` `stock_bid_ask_em` | 源码里只有 `buy_1..5` / `sell_1..5`，**五档** |
| `mootdx` | 无 tick 读取器 |
| `CMES` 数据源 | 官网自述"**约 3 秒一次**的简易分笔"，也不是真逐笔 |

**结论：所有免费/低成本路线，天花板就是 3 秒分笔 + 五档。想要十档、逐笔委托、委托队列，没有免费路径，只能走券商 L2 客户端"看"。**

## 三、一个重要的重新定义：您要的"推演"，可能根本不用买

您说"不需要实时，半小时一小时推演"。这句话其实指向一个更关键的判断：

**如果目的是复盘推演，我们手里的东西已经够了。**

对比一下"想买的"和"已经有的"：

| 能力 | 已有 3 秒分笔 | L2 增量 |
|---|---|---|
| 历史长度 | **9 年（回溯 2017）** | 0（开通日起） |
| 全市场 | **5,217 只** | 仅深市完整（沪市无逐笔委托） |
| 能入库 | **✅ 79.6MB/日，已跑通** | ❌ 客户端内看，导不出 |
| 成本 | **0** | 0~1980 |
| 分钟级买卖力道 | ✅ | ✅ |
| 十档深度 | ❌ | ✅ |
| 委托队列（50 笔手数） | ❌ | ✅ |
| 毫秒真逐笔 | ❌ | ✅（仅深市） |

**L2 相对我们已有数据，真正的增量只有三样：十档深度、委托队列、毫秒逐笔。而这三样恰好全部无法落盘。**

所以问题变成：**您推演时，到底需不需要看"封单是 308 手大单还是 100 个散户小单"？**

- **不需要** → 现有数据完全够，一分钱不用花，直接开始推演。
- **需要** → 那是"人眼看"的需求，0 元券商 L2 + 通达信就能满足，也不用买 API。

**两种情况下都不需要买 5000 元的数据商服务。**

## 四、建议路径（按成本从 0 开始，逐级加码）

**第 0 步（今天就能做，0 元）：**
打开券商 APP 找客户经理，一句话问三件事：
1. 我的账户能不能**免费开通 Level-2**？门槛是什么？
2. 开通的是**通达信版还是同花顺版**？能否登录通达信金融终端？
3. **L2 数据能不能盘后导出成文件**？（这条决定能不能进我们的库）

**第 1 步（0 元验证需求）：**
装上带 L2 权限的通达信，跑一周，就盯您最关心的那几只票，看"十档 + 队列"到底有没有带来增量判断。

**第 2 步（只有第 1 步证明有用才做）：**
- 只是自己看 → **到此为止，0 元**。
- 要沉淀成数据 → 再谈 1980 专业版或数据商，且必须先确认"能导出"。

**这个顺序的价值：用 0 元把需求真伪验掉，避免直接掉进 1980 或 5000 的坑。**

## 五、如果有人告诉您"买 API 就能拿全 A 股 L2"

三句话可以挡回去：

1. **沪市没有逐笔委托。** 上交所 L2 只给逐笔成交 + 十档，这是交易所披露规则，任何供应商都变不出来。A 股 5,200 只里沪市约 2,300 只。
2. **"分笔"不等于"逐笔"。** 大量供应商卖的"逐笔"其实是 3 秒聚合，字段长得一样但信息量差一个量级。验收方法：抽一只活跃股，比对其总条数——真逐笔单只票单日 10 万条以上，3 秒分笔只有 4,000~5,000 条。
3. **历史长度要问清。** 交易所不提供无限历史 L2，多数只能回溯近 1~2 年。

**这条验收方法（比条数）是本文最实用的一条，可以直接用于任何供应商的尽职调查。**
