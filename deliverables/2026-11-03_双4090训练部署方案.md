# 双 4090（2×24GB）训练与部署方案（2026-11-03）

> 场景：若有两张 RTX 4090（24GB×2，无 NVLink，PCIe 互联）→ 相比单卡：14B 训练提速、可上 32B QLoRA、部署可 TP=2 跑 72B-int4
> 结论：**主力训练 Qwen2.5-14B-Instruct（DDP 双卡，SFT+DPO）；可选升级 Qwen2.5-32B-Instruct QLoRA（stretch）；部署 Qwen2.5-72B-Instruct AWQ-int4（TP=2）或 32B/14B-int4 单卡**

## 一、显存与能力账
| 项 | 数值/说明 |
|---|---|
| 总显存 | 48GB（24×2） |
| 互联 | 无 NVLink，PCIe 全双工；DDP all-reduce 效率约 80-90% |
| 精度 | BF16 + FP16 全支持；FlashAttention-2 可用 |
| 训练能力上限 | 14B QLoRA（轻松，batch 可加大）；32B QLoRA（模型并行/ZeRO-3，seq 1024-2048，可行但需实测）；72B 训练不可行 |
| 部署能力上限 | 72B AWQ-int4（~40GB）TP=2 可跑；32B int4 单卡；14B int4 单卡富余 |

## 二、模型选择（训练）
| 优先级 | 模型 | 方法 | 显存/卡 | 用途 |
|---|---|---|---|---|
| **主力** | **Qwen2.5-14B-Instruct** | QLoRA r32/α64，DDP 双卡（DeepSpeed ZeRO-2） | ~10-14GB/卡 | 方案 v1 的 D3 正式模型；双卡 SFT 约 20-35 分钟 |
| 冒烟 | Qwen2.5-7B-Instruct | QLoRA，DDP | ~6-8GB/卡 | D1 管线验证（10 分钟级） |
| 可选升级 | **Qwen2.5-32B-Instruct** | QLoRA r16/α32，ZeRO-3，seq 1024，batch1×ga16 | ~18-22GB/卡（紧张） | 14B 效果不足时升级；SFT 约 4-8h |
| 不推荐 | 72B | — | 训练需 >48GB | 只做推理（部署） |
| 不推荐 | 14B 全参 | ZeRO-3+CPU offload | 显存/时间不划算 | LoRA 已足够 |

## 三、双卡训练配置差异（相对单卡）
| 参数 | 单 4090 | **双 4090** |
|---|---|---|
| 并行 | 单卡 | `torchrun --nproc_per_node=2` + `deepspeed: ds_z2_config.json`（14B）；32B 用 `ds_z3_config.json` |
| `per_device_train_batch_size` | 2 | 2（14B）/ 1（32B） |
| `gradient_accumulation_steps` | 8 | 8（14B，等效 batch 32）/ 16（32B） |
| `cutoff_len` | 2048 | 2048（14B）/ 1024（32B） |
| `bf16` | true | true |
| `flash_attn` | fa2 | fa2（4090 支持） |
| `learning_rate` | 7e-5（14B） | 7e-5（DDP 线性缩放可试 1.4e-4，先用 7e-5 稳） |
| DPO | SFT adapter 起点 | 双卡 + ZeRO-2；ref=SFT 权重不变 |

**注意**：QLoRA(4bit)+ZeRO-3 在部分版本组合下有兼容性坑（初始化/保存），32B 需先小步冒烟（10% 子集）确认；若失败退回单进程 `accelerate` 模型并行（不提速但能训）。

## 四、时间与成本估算（本项目数据：2,678 条 SFT / 74 万 tokens/3epoch）
| 任务 | 单 4090 | **双 4090（DDP）** |
|---|---|---|
| D1 冒烟（10%） | 2-5 分钟 | 2-3 分钟 |
| 14B 全量 SFT | 0.5-1h | **20-35 分钟** |
| 14B DPO | 0.2-0.5h | **15-25 分钟** |
| 32B 全量 SFT（QLoRA/ZeRO-3） | 不可行 | **4-8h（需实测）** |
| 拒绝采样（k=8×641，用 14B/32B 批量推理） | 1-2h | **0.5-1h（双卡并行）** |
| 全流程（14B） | 3-4h | **约 1.5-2h** |
| 成本（若租） | ¥1.5-2.5/h | **¥3-5/h，全程约 ¥10-20** |

## 五、部署方案（双卡的最大价值）
| 模型 | 量化 | 服务方式 | 显存 |
|---|---|---|---|
| **Qwen2.5-72B-Instruct** | AWQ-int4（~40GB） | **vLLM TP=2**（两张卡） | 48GB 可跑（需实测上下文长度） |
| Qwen2.5-32B-Instruct | AWQ-int4（~18GB） | vLLM 单卡 / TP=2 提速 | 单卡即可 |
| Qwen2.5-14B-Instruct（SFT/DPO） | AWQ-int4（~9GB）/ fp16（~28GB） | vLLM/Ollama；fp16 可单卡 32G? 不行（24G）→ int4 | 单卡 |
| 7B（SFT/DPO） | AWQ-int4 | Ollama/vLLM | 单卡富余 |

**建议**：训练产物 14B/32B → merge → AWQ-int4；**生产问答用 72B-int4 TP=2（旗舰）、微调后的 14B-int4 做垂域专用（快、便宜）**，按问题分流（通用/长文 → 72B，垂域知识/拒答 → 14B SFT）。
**D4 裁判**：直接用 32B 或 72B 做 rubric 裁判，质量显著优于 7B 裁判。

## 六、与其它方案对比
| 方案 | 训练上限 | 部署上限 | 成本 | 结论 |
|---|---|---|---|---|
| 本机 APU（现有） | 仅 7B CPU 冒烟 | 9B 推理 | ¥0 | 只适合数据/推理 |
| V100 32G | 14B QLoRA | 14B int4 | ¥0/租 ¥1-2h | 能训能部，慢一些 |
| 免费 T4 16G | 7B QLoRA | 7B int4 | ¥0 | 只够 7B |
| **双 4090 48G** | **14B 快 / 32B 可试** | **72B-int4 TP2** | ¥0（自有）/租 ¥3-5h | **最优：训 14B、部 72B** |
| 单 4090 24G | 14B QLoRA | 32B-int4 单卡 | 低 | 次优 |

## 七、建议路线（有双 4090 后）
1. **D1 冒烟**：7B（10% 子集，双卡 DDP，10 分钟）→ 通过后直接 **14B 全量 SFT**（20-35 分钟）；
2. **D3 14B 正式**：双卡 DPO（15-25 分钟）；产出 14B SFT/DPO adapter；
3. **可选 32B**：14B held-out 评测若不足（+15pt 未达）→ 32B QLoRA（4-8h，需冒烟验证 ZeRO-3+4bit）；
4. **D4 拒绝采样/评测**：双卡批量推理，用 32B/14B 做裁判；
5. **部署**：14B AWQ-int4（垂域专用）+ 72B AWQ-int4 TP=2（旗舰通用）分流；
6. 数据缺口（C 补量/F 通用回混）与控制卡无关，仍按 D0 回执补齐。
