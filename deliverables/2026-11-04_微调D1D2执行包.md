# 微调 D1/D2 GPU 执行包（V100 / 双 4090 自适应）

> 前置：D0 数据已就绪（SFT 2,678 / held-out 105 / DPO 规则对 65）；本机无 NVIDIA GPU，需 V100 或 4090 环境执行。
> 目标：**D1 7B 冒烟 → D2 14B 正式 SFT**；DPO（D4/D5）在 SFT 评测通过后执行。

## 一、环境自检（先跑）
```powershell
python tools/finetune/check_gpu_env.py
```
- 输出 GPU/驱动/PyTorch CUDA 状态与**推荐模型+配置**：
  - 2×4090 → `configs/sft_14b_2x4090.yaml`（DDP + ZeRO-2）
  - V100 32G → `configs/sft_14b_v100.yaml`（FP16/sdpa/无 bf16）
  - V100 16G → `configs/sft_7b_v100.yaml`
  - 单 4090 → `configs/sft_14b.yaml`

## 二、环境安装（Linux 推荐，CUDA 12.x）
```bash
conda create -n qlora python=3.10 -y && conda activate qlora
pip install torch==2.4.1 --index-url https://download.pytorch.org/whl/cu121
pip install "llamafactory==0.9.*"  # 含 transformers/peft/trl/bitsandbytes
# 校验
python -c "import torch;print(torch.__version__,torch.cuda.is_available(),torch.cuda.device_count())"
```

## 四、执行命令
### D1 7B 冒烟（10% 子集，2 epoch）
```bash
# 取 10% 训练子集（首 268 条，仅冒烟用）
head -n 268 research/finetune/sft/quant_kb_sft_v1_train.jsonl > /tmp/smoke.jsonl
llamafactory-cli train research/finetune/configs/sft_7b_v100.yaml \
  --dataset_dir research/finetune \
  --dataset smoke.jsonl \
  --output_dir saves/smoke-7b --num_train_epochs 2
```
验收：loss 正常下降、保存 adapter、无 OOM/NaN；**不用于发布**。

### D2 14B 正式 SFT
```bash
# V100 32G
llamafactory-cli train research/finetune/configs/sft_14b_v100.yaml
# 或 2×4090 DDP
torchrun --nproc_per_node=2 src/train.py research/finetune/configs/sft_14b_2x4090.yaml
```
期望：3 epoch / 2,678 条；V100 32G 约 2.5–4h，双 4090 约 20–35 分钟。

## 五、验收（D2 后）
| 项 | 阈值 |

## 六、DPO（D4/D5，待 SFT 验收后）
1. 用 SFT 模型拒绝采样 k=8 → 800–1200 对（补足现有 65 对规则对）；
2. 配置 `sft_14b_*` 对应 `dpo_14b_*`（ref=SFT adapter；β0.1/LR5e-7/1epoch）；
3. 验收：DPO 后 held-out 不降、拒答率提升、无长度崩塌。

## 七、阻塞与替代
| 阻塞 | 替代 |
|---|---|
| 无 GPU 卡 | 云 4090（¥1.5-2.5/h）或 V100（¥1-2/h）按量 |
| 无 AutoDL 账号 | 先本机 CPU 跑 0.5B QLoRA 冒烟验证脚本（可选） |
| 显存不足（16G 跑 14B） | 降 seq 1024 / batch1 / grad ckpt；仍不行则 7B |
| 数据/配置错误 | 先用 `head -n 64` 小样本跑通再全量 |
