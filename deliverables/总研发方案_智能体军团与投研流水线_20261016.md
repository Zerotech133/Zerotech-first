## 〇、一句话战略

**把工作站从「量化产线 + 零散智能体」升级为「数字军团驱动的完整投研流水线」：任何 AI 出生即入职、任何情报进门即入图、任何决策落账即归因、任何交易执行前必过风控辩论。**

## 一、我的总判断（最优解的三个取舍）

1. **组织先行，能力后置**——先花一周把军团底座（名册/入职/账本/体检）立起来，再往上叠能力。理由：今天已出现 k266 静默失败一整天无人知晓、运行体干完活账本无归因的真实事故，底座不牢叠得越多坑越大。
2. **菜鸟精华全部吸收，但走军团自己的路**——风控三师（左右侧语义载体）、六维评分（量化工具层）、盯盘信号两族（右侧 2+3/左侧底分型）全量移植；但**不用菜鸟运行时**，全部人设进我们的 prompts/registry 体系（K-STOCK-004 独立版先例）。
3. **流水线闭环优先于单点智能**——五虎辩方向 → 风控组定仓位 → TR1 执行 → 复盘进化。每一环都影子运行，用数据逐步转正，绝不一把梭上线。

## 二、总体架构：五层纵队

```
L5 复盘进化层   影子期裁决 · 月度review · 判例库 · 军团周报（一查全知）
L4 决策执行层   D1五档裁决 → 风控三师辩论(左右侧落子) → TR1执行单 → 模拟仓验收
L3 投研能力层   投研五虎(方向) + 风控组(仓位/止损) + 六维评分(工具) + 盯盘信号(触发)
L2 情报供给层   OSINT视频管线(喂N1) · 新闻采集(已在跑) · KG事件图谱(147万节点) · 股吧/雪球
L1 组织底座层   org_registry v2名册 · 入职流水线 · 三账本 · 体检 · Hermes/飞书双表面
```

数据流一句话：**L2 情报 → L3 五虎辩论（输入=三线交叉标准件）→ L4 风控定仓执行 → L5 复盘反哺人设与阈值 → 循环进化。**

### 线 B：投研流水线（下周-10月底，核心新能力）

**B1 三线交叉标准件**（把今天 600337 的临时分析固化为五虎的标准输入工具）
- 新工具 `tools/xsec_profile.py`：一键生成「事件传导时间线 + K线审美判定 + 资金主体席位」三线报告（直接查 Neo4j/K线parquet/news.db——全部今天已验证的查询路径）
- 五虎辩论时注入该报告作为公共事实底座，分析师只做判断不做检索——**消除臆造数据**（人设纪律的技术保障）

**B2 六维评分引擎**（菜鸟 24 因子全表移植）
- `quant_backtest/six_score.py`：6 维度 24 因子（营收/盈利/市场环境/行业热度/资金/舆情），WEIGHT/PENALTY 结构照搬，数据源接 Tushare+新闻库+KG
- 定位：**F1/N1 的量化工具**（他们引用分数，不做自由发挥）；先影子 20 交易日对照人工评分

**B3 盯盘信号两族**（接入现有 weak 产线）
- 右侧族（2+3模式/涨停突破/均线粘合发散）与左侧族（强底分型支撑/回踩确认）作为 WeakTrackCheck 的信号词表扩展
- 触发时自动标注左右侧属性 → 飞书卡显示「右侧确认触发」或「左侧试探触发」

**B4 风控辩论组上线**（影子）
- 输入：D1 的五档裁决 + 三线报告
- 辩论：R1（激进·左侧立场）vs R2（保守·右侧立场）各 1 轮 → R3 中性仲裁 → 输出结构化风险参数（maxPosition/stopLoss/takeProfit/keyRisks）
- 纪律：**影子期只落盘不拦截**，与 RiskGuard 新阈值同窗观察（10-20 满窗裁决后合并评估）

### 线 C：情报供给（与 B 并行，等外部输入）

- C1 OSINT PoC：管线已就绪（128 测试全绿+OCR 冒烟 PASS+SenseVoice 就绪），等你的 3-5 账号 mp4 样本 → 出首份质量报表 → Go/No-Go

### 线 D：量化主线不变（open1016 继续）

- D0-D5 守护 → 10-20 RiskGuard 满窗裁决 ⭐ → 10月底 S3 裁决材料 → 策略迭代 A/B/C 拍板

### 线 E：表面与治理（月底）
