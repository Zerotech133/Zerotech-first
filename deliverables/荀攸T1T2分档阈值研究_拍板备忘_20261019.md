## 2. 候选分档方案（4 个，档内构成为今日批次实算）

> 各方案均不改变池产出逻辑，仅定义"如何把 action=buy 的 87 只划成 T1/T2/其余"。

### 方案一：天然断层双断点（主推）
- 规则：**T1 = score > 99.0；T2 = 95 ≤ score ≤ 99.0；其余不分级**
- 断点依据：99.0→99.17 的 0.17 微断层恰是两策略的量纲分界（实算：99.0 分全是 chan_monitor×8，≥99.17 全是 kg_boost×49）；95→97 的 2.0 断层收 T2 下沿。
- 档内构成：**T1=49**（纯 kg_boost，score 99.17–100.0，conf 除 2 例外全 0.8）；**T2=23**（纯 chan_monitor，score 95–99，conf 0.6/0.7/0.8 混合）；**未分级=15**（chan 60–87 + 分歧票）。
- 变体 1b（若嫌 T1 排他太强）：T1 = score ≥ 99.0 → **T1=57**（kg 49 + chan@99 的 8），T2=15（chan 95–97），未分级 15。

### 方案二：固定分位 Top-K
- 规则：T1 = 前 20%（score ≥ 99.70）；T2 = 前 20–50%（99.26 ≤ score < 99.70）；其余不分级。
- 档内构成：**T1=17**（纯 kg_boost，conf 全 0.8）；**T2=27**（纯 kg_boost，含 1 票 conf=0.5）；**未分级=43**（kg 尾部 5 + chan 全部 37 + 分歧票 1）。
- 特点：切点落在 kg 连续带内部（rank17=99.71 / rank18=99.70 同为 0.01 级差），**档界是任意的**；chan 全军落未分级。

### 方案三：score×confidence 双门
- 规则：T1 = score ≥ 99 ∧ conf ≥ 0.8；T2 = score ≥ 95 ∧ conf ≥ 0.7；其余不分级。
- 档内构成：**T1=55**（kg 47 + chan@99 的 8）；**T2=13**（chan@97 全档）；**未分级=19**。
- 问题实算：688370.SH（99.26，conf 0.5）与 688073.SH（99.21，conf 0.65）两票 kg 分极高却被踢出 T1；而 81 分毒层降档票 conf=0.9 若进 T2 门会制造"低分高置信"倒挂（本批因 score<95 未入选，属侥幸）。

### 方案四：三带 + 分歧旁路
- 规则：T1 = score > 99.0；T2 = 77 ≤ score ≤ 99.0；观察带 = score < 77；**divergence=true 一律旁路进人工复核，不进档**。
- 档内构成：**T1=49**；**T2=31**（chan 77–99，conf 0.6/0.7/0.8/0.9 混合，含 4 票 0.9 的毒层降档 81 分票）；**未分级=7**（60×6 + 分歧票）。
- 特点：保留全带宽，分歧票隔离最显式。

## 4. 建议倾向 + 前置问题

### 4.1 建议倾向（供老田拍板参考，非结论）

**主推方案一（T1 = score > 99.0，T2 = 95 ≤ score ≤ 99.0）**，理由：
1. 断点落在真实数据断层 + 策略量纲分界上，是今日批次中唯一"有物理意义"的位置（1.3 节实算）；
2. 绝对阈值跨日稳定，下游（盘前消费、告警）语义不漂移；
3. 实现成本最低，符合章程"不发明分档阈值"的精神——阈值来自数据断层而非人工发明。

**若 T1 的用途是告警档**（49 条/日偏吵），建议在方案一上加"分位封顶"旋钮：T1 = score > 99.0 **且当日排名 ≤ 20**（今日即 17 条，score ≥ 99.70）——断层语义保底，容量可控。

**分歧票无论何档一律人工复核**（今日仅 300947.SZ 一例，成本可忽略，建议采纳方案四的旁路条款）。

### 4.2 需要老田补充的决策信息（前置问题清单）

1. **T1/T2 用途定义**（最优先）：是仓位档、关注档还是告警档？章程与本备忘所查研发计划均无定义（章程全文无 T1/T2 表述，grep 核对；json `notes` 亦仅言"分档阈值未拍板，池内不做分级"）。用途决定 T1 容量要求（仓位档看风险预算、告警档看每日条数上限、关注档可宽松），**在用途明确前任何阈值都无法定稿**。
2. **阈值隐含选策略是否可接受**：方案一/四的 T1 实质=kg_boost 头部。若上游要求 T1 策略中性，则需改为"每策略内部各自分档"（本备忘未展开，需额外指令）。
3. **confidence 是否参与分档**：本批实算显示其只有 7 个离散值且与 score 非单调（0.9 在 81 分、0.4/0.5 在顶部带），建议明确排除或先修 conf 口径。
4. **T1 容量上限**：下游每日能消费/复核多少条？（今日 T1 候选 49 条是否超预算）
5. **kg_boost pagerank 分位口径跨日稳定性**：99.17 阈值的语义=pagerank 前 0.83%（rationale"pagerank分位100"推断），若图谱 universe/算法迭代，该阈值语义会变，需约定 recalibration 时机。
6. **分歧票处理**：确认"divergence=true 强制人工复核、不自动进档"是否采纳。
