# 入场特征：结构是真的，但它不迁移

**日期**：2026-11-08  
**样本**：6,900 笔（只 1 买）｜398 个入场日｜入场 2024-01-03 ~ 2025-10-27  
**成本**：佣金双边 20bp（买 7.5 / 卖 12.5）+ 单边滑点 51bp ×2 = **122bp / 次进出**  
**脚本**：`tools/research/hf_feat2.py`（面板 + 单变量筛）、`hf_holdout.py`（一次性验收）、`hf_feat2_diag.py`（迁移诊断）、`hf_feat2_selfcheck.py`（11 条自检）

> ⚠️ **阅读前必看（2026-11-09 01:40 补）**：本文全部数字建在 6,900 笔样本上，而其中 **602 笔（8.7%）是 d0 当日成交额 < 2,000 万的票**，它们单独贡献了全部正超额。剔除后全样本从 **+195bp 变成 −145bp**。**本文 §2~§6 的 ΔA / Δt / holdout 结论在 U0 补齐、面板重算之前不要引用。** 详见 **附录 E** 与 `deliverables/2026-11-09_U0可交易域审计_v1.md`。

## 0. 结论

**三步都按预注册跑完了，holdout 判 FAIL。但失败原因不是"这批特征没区分度"——单变量筛出 95 桶 / 8 条过线（纯噪声期望 4.4）、训练集 96 次检验 / 26 条过线（期望 4.4），结构是实的；它在 2025 年整体不成立。**

三条证据同向：

| # | 证据                           | 数字                                                             |
| - | ---------------------------- | -------------------------------------------------------------- |
| 1 | 5 条候选规则进验收，**3 条符号翻转**       | 主规则 +503bp → **+25bp**（门槛 50），聚类 t=1.49（门槛 2）                  |
| 2 | 92 个桶的训练 ΔA 与验收 ΔA **秩相关为负** | ρ = **−0.164**；训练集 ΔA>0 的 56 个桶里，OOS 还 >0 的只占 **33.9%**——比抛硬币差 |
| 3 | 观测 +25bp 落在随机抽样的**正中间**      | 2000 次随机留同样比例：sd=51.8，90% 区间 [−89.7, +79.5]，观测落在 **p=0.332**   |

**所以"把左尾从 20.7% 压到 10%"这条路，不是没做，是做了不成。** 15 个新特征里最强的 5 条，在 2025 年全部退回 25bp 以内。卡住的仍是第十九轮那个数：**单笔 α 196bp vs 一次进出 122bp**，而这个差距不是靠挑票能补的——挑得准的那几年，本来就不需要挑。

**本轮最重要的一条副产品**（第 7 节）：2024 与 2025 不是同一个分布。毛收益右尾（>+20%）从 **60.7% 掉到 33.3%**，左尾（<−10%）从 **13.1% 涨到 38.6%**，笔均毛收益从 **+50.05% 掉到 +18.06%**，笔均超额从 **+289bp 变成 −26bp**。在一个右尾 60.7% 的年份上做出来的分桶，本质是在拟合"哪批票涨得更多"；而这个问题的答案在 2025 年换了。

## 3. 单变量筛：95 桶，8 条过线

|       |    |                                                                         |   |                    |
| ----- | -- | ----------------------------------------------------------------------- | - | ------------------ |
| 判据：\` | Δt | ≥ 2`且`a`、`a1\` 两个 β 口径的 **t 同号**，且 ΔA > 0，且配对天数 ≥ 20。纯噪声期望 **4.4 条**（单侧 | t | ≥2 ≈ 4.6%/次 × 95）。 |

| 特征            | 桶                | 用法 | ΔA         | Δt(`a`)   | Δt(`a1`) | n       |
| ------------- | ---------------- | -- | ---------- | --------- | -------- | ------- |
| `crowd_ind`   | 1~3              | 剔  | +161bp     | +3.15     | +3.68    | 2,462   |
| `ind_rs60`    | 0.0718~4.1328    | 剔  | +239bp     | +3.06     | +2.22    | 1,283   |
| `ind_ret20`   | −0.2931~−0.0229  | 剔  | +137bp     | +3.01     | +2.50    | 1,269   |
| `tbe`         | False            | 只留 | +164bp     | +2.72     | +2.17    | 3,377   |
| `tbe`         | True             | 剔  | +87bp      | +2.51     | +2.08    | 2,142   |
| `listed_days` | 172~1124         | 只留 | **+868bp** | +2.45     | +3.63    | 1,376   |
| `lag`         | 43~60            | 只留 | +66bp      | +2.25     | +2.12    | 1,439   |
| `ind_ret20`   | 0.174937~0.52529 | 只留 | +258bp     | **−2.11** | −1.09    | 1,284 ⚠ |

`listed_days 172~1124` 是全场最亮的一条：桶内笔均超额 **+1,063bp**，右尾 57.8%。看着像找到了金矿。

三个必须一起读的技术点：

|   |   |   |
| - | - | - |

- **⑧ 号那条 ⚠ 是反号项**：按笔加权 +258bp、按日等权 −2.11（只有 32 个配对日）。判据只写了 `|Δt| ≥ 2` 与双口径同号，**没有要求 sign(ΔA) = sign(Δt)**——因为 ΔA 按笔加权、Δt 按日等权，权不同就能反号。看到结果再把门槛加严就不叫预注册了，所以只标不改。自检 C11 专门验这类项必须能被"按笔加权 vs 按日等权"解释。
- **`crowd` / `regime` 是日级变量，日聚类 t 无定义**：同一天所有票取同一个值，当天没有组间差，聚类 t 恒为空。这类换 HAC（Newey-West，Bartlett 核，滞后 = min(250, N/2)）——先算每日均值，再对日序列做两样本 t，一次修两个问题：同日几十只票不独立、250 日前瞻窗口在相邻入场日之间共享 249/250 样本。结果：`crowd` 5 档里 3 档求得出（极端桶只有 2~4 天，HAC 求不出）、`regime` 3 档全有，最大 |t| = **1.51**，全部没过线。`regime=weak` 那档还正好是"ΔA 与 Δt 反号"的样本：ΔA=+78bp、HAC t=−0.14。
- **Δt 的符号曾经全局是反的**：`cluster_diff_t` 算的是 `hit − rest`，而 `dA` 是 `rest − base`，"剔除"这一侧必须取反。第一版没取反，95 行的 Δt 与 ΔA 全反号——**判据只看 |t| 与双口径同号，所以通过名单不变，但读表的人会得出完全相反的结论**。修正后重开一次 holdout 验证候选集与 OOS 数字逐位不变。这条写进注释挂在原地。

## 6. 功效诊断：把"没效果"和"看不出效果"分开

| 项                  | 值        |
| ------------------ | -------- |
| 验收集交易日             | 183      |
| 250 日前瞻窗口下的独立窗口数   | **0.73** |
| 60 日窗口下的独立窗口数      | 3.05     |
| 让聚类 t 到 2 需要的 ΔA   | **34bp** |
| 让 HAC t 到 2 需要的 ΔA | 20bp     |
| 主规则实测 ΔA           | 25bp     |

**这个诊断很重要，因为它把判决的性质说清了**：183 个入场日、250 日窗口，重叠得只剩 0.73 个独立样本。"OOS 聚类 t ≥ 2"在这个样本量上要求 ΔA 到 34bp；实测 25bp，**幅度上够 HAC 门槛（20bp），不够聚类门槛（34bp）**——也就是说，单看幅度不能说"完全没效果"，但方向在一年之内就没了（第 4 节 60 日窗口翻负）。所以判决 FAIL 归因于**不迁移**，不是**不可测**。

反过来也要说清：这条门槛本身是预注册时定的、偏严的。如果当初把门槛定成"HAC t ≥ 2"，主规则 2.48 就过了。**这正是预注册的意义——门槛不能等看到数字再改。** 记在这里，不追认通过。

## 7. 真正的答案在这里：训练年和验收年不是同一个分布

| 指标            | 2024（训练）    | 2025（验收）    | 变化      |
| ------------- | ----------- | ----------- | ------- |
| 笔数 / 入场日      | 4,838 / 215 | 2,062 / 183 | —       |
| 笔均毛收益（250 日）  | **+50.05%** | **+18.06%** | −32pp   |
| 笔均超额 `a`      | **+289bp**  | **−26bp**   | −315bp  |
| 右尾（毛收益 >+20%） | **60.7%**   | **33.3%**   | −27.4pp |
| 左尾（毛收益 <−10%） | 13.1%       | **38.6%**   | +25.5pp |

（全样本 6,900 笔的分布是右尾 52.5% / 左尾 20.7% / 笔均超额 +195bp——第十九轮那个 196bp，就是这两年被平均出来的。）

三个直接后果：

1. **2024 是个"买什么都涨"的年份**（右尾 60.7%、笔均毛收益 +50%）。在这种年份上做分桶，拟合的是"哪批票涨得更多"；2025 的右尾腰斩到 33.3%、左尾涨到 38.6%，同一个问题换了答案。
2. **基准本身从 +289bp 变成 −26bp**。也就是说"这个策略在 2025 有没有 α"这个前提都不成立了，再去讨论"哪些特征能挑出 α"没有意义。第 0 节那句"挑得准的那几年，本来就不需要挑"，指的就是这个。
3. **每条规则在 OOS 上都几乎不触发**（主规则从剔 3,321 笔变成剔 202 笔），因为分位边界是用 2024 定的，2025 的分布整体移位了。这是真实部署会遇上的问题，不是实现缺陷。

单看 `listed_days 172~1124` 最能说明这点：桶内笔均超额 2024 年 **+1,363bp**、2025 年 **+72bp**；ΔA 从 +1,074bp 掉到 +98bp。**同一条规则、同一批"次新股"，一年之内从金矿变成白干。**

## 8. 做什么，不做什么

**不做**：

- ❌ 不再在这 15 个特征里继续调阈值 / 换分桶数 / 试交互项。本轮已经证明的是"结构不迁移"，多试 10 组只会多出 10 个 33.9% 的符号一致率。
- ❌ 不把主规则的 25bp 拿去做任何形式的"部分采纳"。60 日窗口翻负这一条就够否掉它。
- ❌ 不重开 holdout。2025 已经烧掉了，再开就是拿验收当训练。

**做**：

- ✅ **先把"2025 为什么 α 归零"这件事单独查清**。基准 +289bp → −26bp 是本轮最大的发现，优先级高于任何特征工程。若 α 消失是市场层面的（2025 整体没有这个形态的超额），那入场端就不该继续投入；若是样本层面的（1 买信号在 2025 抓到的票换了类型），才轮到特征。
- ✅ **改用滚动/扩展窗口的分位**（而不是训练集固定边界），让规则在分布移位时仍能触发。这是本轮唯一确定的工程缺陷，值得独立做一次。
- ✅ **门槛与样本量先对齐再谈成败**：250 日窗口在 2025 上只有 0.73 个独立样本，任何"OOS t ≥ 2"的验收在这种窗口下都不可能通过。要么把前瞻窗口缩短（60 日有 3.05 个独立窗口），要么把验收期拉长到 3 年以上。

**回到第十九轮那条主线**：单笔 α 196bp vs 一次进出 122bp，成本吃掉 62%。本轮试图从入场端把 196bp 抬高，实测抬高不了——**在挑得准的年份不需要挑，在需要的年份挑不动**。所以下一步应该转向"能不能少进出几次"（成本侧），而不是继续加特征（α 侧）。

## 附录 D：课题关闭（2026-11-09 00:45）

**本课题到此关闭，不再追加特征。**

关闭依据不是"试过但失败"，而是**失败的形态不支持继续投入**：

| 如果现象是 | 那应该做的下一步 | 实测是哪一种 |
|---|---|---|
| 单变量筛过不了线（≈噪声期望） | 换特征、换定义、扩样本 | ❌ 不是——95 桶过 8 条，训练集 96 次检验过 26 条，**信号真实存在过** |
| 过线但 OOS 衰减一半 | 调阈值、加正则、要更多样本 | ❌ 不是——是**符号翻转**，5 条候选 3 条反向 |
| OOS 完全不相关 | **结构不迁移，换战场** | ✅ **是这一种**：ρ = −0.164、符号一致率 33.9%、置换 p = 0.332 |

ρ 为负意味着：**训练集里越强的桶，在验收集里越倾向于失效**。这不是"不够强"，是"强的方式属于 2024 那个年份"。在一个买什么都涨的年份里做分桶，学到的是"哪批票涨得更多"；换一年答案就变了，而且连基准 α 都归零（+289bp → −26bp）。

所以：**不再加特征，不再开新线。** 主线回到第十九轮那个数——单笔 α 196bp vs 一次进出 122bp。入场端抬不上去，就去成本侧（少进出几次）。真要再碰这条线，前提是先回答"2025 的 α 去哪了"，而不是再加 15 个 ρ≈0 的表。

> ⚠️ **本段结论已于 2026-11-09 01:40 被推翻一半，见附录 E。**
> 上句"主线回到 196bp vs 122bp"里的 **196bp 不成立**——它是 602 笔日成交额 <2,000 万的票撑出来的会计假象，剔掉后全样本是 **−145bp**。
> "不再加特征"这个决定仍然成立，但**成立的理由换了**：不是"入场端抬不上去"，是**基座样本本身不可交易**。

## 附录 E：勘误——196bp 的来源（2026-11-09 01:40）

老田追问"选都不选，哪来买不买的问题"，去查了扫描池（`chanlun_scan.py` 只有 `MIN_BARS=120`，无市值/ST/流动性过滤），顺带把 6,900 笔按 d0 当日可交易性拆了一遍。结果推翻了本文多处引用的 195bp / 196bp。

**一句话：这 195bp 全部由 602 笔「d0 日成交额 < 0.2 亿」的票贡献，占样本 8.7%，均值 +3,756bp，右尾 87.7%。**

| 口径 | n | A(bp) |
|---|---|---|
| 全样本（本文全部数字的基座） | 6,900 | **+195** |
| 只剔 ST/退 | 6,763 | +116 |
| 只剔 次新 <250 日 | 6,831 | +188 |
| **只剔 成交额 <0.2 亿** | 6,298 | **−145** |
| 剔 ST/退/低价/次新 **+** 低量 | 6,142 | **−189** |

成交额门槛从 0.1 亿扫到 2.0 亿，**没有一个是正的**（−134 / −189 / −226 / −278 / −282 / −212）。

而且可交易域里按市值五档 × 年份拆，**10 个格子没有一格两年都为正**：Q1 是 2024 +761 / 2025 −1,318，Q5 是 2024 −15 / 2025 +791。"小盘优势"从 +1,670bp 掉到 +105bp，而可交易的大盘是 +287bp——**能买的票里，大盘比小盘好。**

所以本文附录 D 说的"结构不迁移"，真正的机制不是"特征学了 2024 的答案"，而是**特征学的是风格，而风格一年一换**（2024 微盘 / 2025 大盘）。同一个原因，只是位置更靠上游。
