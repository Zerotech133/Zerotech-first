> 工单：`WO-LCS1-BASELINE-ACCEPT-20261027`（本清单）→ 实现单 `WO-LCS1-BASELINE-20261027`（owner BACK1）
> 目的：在 LCS-1 补证链里补上**基线对照**，否则"图形先行更好"没有机器可核的证据。
> 依据：开源方案 Qlib（Alpha158/IC/RankIC/Point-in-Time）与投研评测纪律；报告 `2026-10-27_开源同类项目调研与优化方案_v1.md` §4.2 P0-5。

## 0. 目标 / 非目标

- **目标**：用**基础因子基线**（Alpha158 子集）+ IC/RankIC + 分组收益，与 LCS-1 候选池在同一窗口/同一口径下比较，回答"LCS-1 是否提供增量信息"。
- **非目标**：不训练 ML 模型、不做选股产品化、不做实盘/执行、不替代 LCS-1 Spec。

## 1. 输入与数据口径（与 LCS-1 Spec/BACK1 清单一致）

| 项 | 要求 |
|---|---|
| 行情 | `ts_daily` + `ts_adj_factor`（或 ashare parquet），后复权；只读 |
| 基准 | `ts_index_daily`（000300.SH 或等权全市场） |
| 股票池 | A 股可交易池，剔除 ST/停牌/上市<250 日 |

| 成本 | 对比层用 `fee_schedule.py`/回测清单成本口径；因子 IC 层不计成本但报告需附成本前后 |

## 3. 因子集合（最低要求：12 个，Alpha158 子集同义实现）

| ID | 定义（t 日可得） |
|---|---|
| MOM5/10/20/60 | `close_t / close_{t-N} - 1` |
| MA_DEV20 | `close_t / MA20 - 1` |
| MA_DEV60 | `close_t / MA60 - 1` |
| VOL20 | `std(return, 20)` |
| RSV20 | `(close_t - min(low,20)) / (max(high,20)-min(low,20))` |
| VOL_RATIO | `volume_t / MA(volume,20)` |
| RSI14 | 经典 RSI(14) |
| MACD_DIF | `EMA12 - EMA26`（除以 close 归一） |
| BOLL_POS | `(close_t - MA20) / (2*std20)` |
| TURN20 | `MA(turnover,20)`（若 `ts_daily_basic` 可用，否则用 volume/流通股近似并标注） |

- 所有因子**按日截面** z-score 或分位标准化（报告写死）；去极值（MAD 3 倍）。
- 因子实现必须带公式注释与 as-of 断言；禁止用未来 N 日收益计算因子本身。

## 4. 指标与对比表（报告必须含）

1. **IC/RankIC**：每日截面 Pearson IC、Spearman RankIC，报告均值/标准差/ICIR/胜率（IC>0 天数占比），样本内/外分开。
2. **分组收益**：按因子分 5 组，前向 5/10/20 日平均收益、多空组合（Q5-Q1）、换手/覆盖率。
3. **LCS-1 对照**：
   - 基线 = ①最佳单因子 ②等权因子组合（12 因子等权打分）；
   - LCS-1 = 候选池（Spec 冻结版本）中的实际表现；
   - 对比指标：命中率、前向收益、超额（vs 等权基准）、PF、最大回撤、样本量；
   - **增量结论**：LCS-1 必须在样本外相对基线有正增量，且 bootstrap 95% CI 下限 >0（或明确说明样本不足→补证）；否则写"无增量/证据不足"，不得美化。
4. **稳定性**：样本内/外分开；3 个等长子区间方向；TOP 因子不依赖单一板块。
