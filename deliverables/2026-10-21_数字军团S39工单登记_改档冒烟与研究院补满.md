## 一、② 编制工具补两条腿（新增/补档之外）

### 1. `--rebind` 改档模式
S38 发现「词表合法但实调 400」后，改档成了常规运维动作。**手改真源不可接受**（无备份、无自检、无痕迹），故加改档能力：

| 项 | 实现 |
|---|---|
| 前置 | id 在该部门**已有档案**（无档者提示先 `--backfill`） |
| 拒改 | 目标绑定 == 当前绑定（「无需改档」） |
| 只改 | `llm_binding` + `binding_note`（追加变更记录：从什么改到什么、工单、放行人、原因） |
| 不动 | 职责、档级、工具、名单、其他席位、其他部门（自检逐项断言） |
| 保险 | 备份 → 原子写 → 自检（字段级 + 跨部门深比较）→ 失败自动回滚 |
| TOCTOU | 执行前复核 `from_binding` 未变 |

### 2. `--probe` 连通性冒烟
```
python engine/org_enroll.py --probe ollama/qwen3.5:9b
```
- **`none` → `ok:true / kind:rule_only`**，`latency_ms=0`，不发起任何调用
- 其他绑定真发一次极短请求，返回 `ok / latency_ms / error`
- 退出码：通 0、不通 1（可挂 CI）

**实测三档**：
| binding | 结果 |
|---|---|
| `none` | ✅ rule_only，0 次调用 |
| `ollama/qwen3.5:9b` | ✅ llm，810ms，返回 "OK" |
| `glm/glm-5.3-flash` | ❌ **HTTP 400 Bad Request**（坐实 S38 发现） |
