## 一、020 喂价入口契约回顾（咬合对象）

`k_stock/paper/posterior_link.py`（f68fc304）的喂价面：

- BUY 腿：`entry = orders.filled_price`（成交事实），`exit = marks[stock]`（**显式喂**，缺 → 该腿 `pending`，不猜价）——posterior_link.py:404-415；
- SELL 腿：`exit = orders.filled_price`，`entry = cost_basis` 显式喂，或 orders 中**唯一一笔严格早于**本腿成交的同账户同票 BUY 成交，多笔 → `ambiguous`——posterior_link.py:417-445；
- 前视闸：`marks`/`cost_basis` 若带 `asof` 且 `asof < fill_date` → 抛 `lookahead_price`——posterior_link.py:299-306；
- 收益算式三口径同一式：`(exit − entry)/entry`、`exit − entry`、`(exit − entry)×qty`——posterior_link.py:311-330。

**结论性判断**：020 已经把"哪侧是 entry/exit、何时 pending、歧义怎么办"全部定型。本单要定的只有一件事——**调用方从哪个湖、按什么口径、在什么时点，把 `marks[stock] = {"price": …, "asof": …}` 算出来**。以下所有候选口径均以此为出口形状，不改 posterior_link 任何一行。

注意一个结构性事实：**SELL 腿两侧都是成交事实（不复权真实价），天然同基，无复权问题**。复权问题只存在于 **BUY 腿的 entry（成交价，真实价）与 exit（估值价）之间的跨期可比性**。因此本单口径之争全部聚焦在 marks 一侧。

## 三、候选取价口径表（核心产出）

四把尺子：**取价时点 / 复权口径 / 停牌无 bar 处置 / 分红送转窗口处理**。每条标注本仓数据下的可行性与坑。

### 方案 A：T0 收盘 · 双侧不复权真实价 · 除权窗口显式 pending

| 维度 | 口径 |
|------|------|
| 取价时点 | marks = 最近一根**已落湖**日线的 `close`；`asof` = 该 bar 的 `trade_date`（诚实标注价格事实时点，**不是**运行日） |
| 复权口径 | **不复权**。entry=`filled_price`（成交当时真实价）与 exit=估值日真实价，**同基天然成立**——只要中间没发生除权 |
| 停牌处置 | 湖文件只含成交日 → 停牌=无 bar。**顺延最近一根 bar + asof=该 bar 日期**，并设**龄期上限**（建议 >5 个交易日转 `pending`，阈值老田圈选）；**禁止**把 asof 填成运行日（那会把"8 天前的价"冒充成"今天的价"，asof 语义即被污染） |
| 分红送转窗口 | **检测到除权即该腿显式 pending，不估值**。检测器三市场各一条：CN=因子线 `F(t)≠F(t−1)`（分片日界，现成）；US=`\|close/pre_close−1\|` 超阈（us_daily 有 pre_close；拆股断裂检测与 us_market.py:39-40 启发式同型）；**HK=无源不可检** → 挂账 |

- **可行性**：CN ✅（检测器=因子线现成）；US ✅（pre_close 自带，但 us_daily pre_close 在**分红日也会跳**——美股分红除息同样改 pre_close，检测器把分红也拦下，口径保守但诚实）；HK ⚠️ 跨除权样本**测不出**，估值价系统性偏差（分红高峰月 4-6 月尤甚）。
- **坑**：① 龄期上限与 pending 率的权衡——停牌股后验长期挂起；② HK 不可检是硬缺口，只能靠"补 HK 复权源（另立工单）"或"接受偏差并注记"；③ 除权检测窗口内所有快照不出数（020 语义：腿 pending → 快照整体 `legs_partial`），除权高峰期产出会缩水。

### 方案 B：T0 收盘 · fill-date 锚后复权（推荐 · CN 主口径）

| 维度 | 口径 |
|------|------|
| 取价时点 | 同方案 A（最近已落湖 bar 的 close） |
| 复权口径 | **后复权、锚=成交日**：喂价方计算 `exit_adj = close(T) × F(T) / F(fill_date)`，喂 `marks={price: exit_adj, asof: T}`。数学性质：`F(T)/F(fill)` 即两日间累积复权比（tushare adj_factor 为累积因子，历史值固定——chanlun_scan.py:128-129 头注自证），使 `（exit_adj − filled_price)/filled_price` **精确等于含分红送转的真实总收益**（分红按除权价折入，近似红利再投资）。entry 永远是真实成交价，**不改写任何历史事实** |
| 停牌处置 | 同方案 A（顺延 + asof 诚实 + 龄期上限；顺延日的因子取该 bar 自身分片的 F） |
| 分红送转窗口 | **无需检测、自动消化**——这正是后复权的本体优势：除权日因子跳变被 `F(T)/F(fill)` 显式计入，收益连续。唯一残留风险=因子线滞后（实测最新分区 20261016，落后 CN 湖 2 日）：除权日恰逢因子缺分区 → 脏价。兜底判例已在本仓：chanlun_scan.py:176 "头部/尾部/内部无因子日以 pre_close 链接续"——CN 湖 `pre_close` 是交易所除权参考价，`close/pre_close` 链可桥接缺失因子 |

- **可行性**：CN ✅ 两件套（湖+因子线）皆在役；US ⚠️ 无因子线 → 本方案仅 CN；HK ❌ 无源。
- **坑**：① **因子线滞后是本方案的生命线**——SLA 清单 #15 已定"除权日缺因子=脏价、窗口升 P0"，本单实测其最新分区落后湖 2 个交易日，须接 freshness 巡检后此口径才可上线（建议作上线前置条件，老田圈选）；② marks.price 语义从"真实价"变"可比价"，喂价契约须显式声明复权口径（建议在 marks dict 增 `basis:"hfq_fill_anchor"` 自描述字段——020 的 `_price_input` 只认 price/asof 两键、多余键会被忽略（posterior_link.py:286-295），**加字段零破坏**，但属 020 侧微改，是否加由老田定）；③ 双保险问题：F(fill_date) 若早于因子线首日（1991 前）不可得——实际不可能（订单都在近期），如实 pending 即可。

### 方案 C：T+1 开盘 · 双侧真实价 · 除权窗口 pending（决策公平性最优）

| 维度 | 口径 |
|------|------|
| 取价时点 | marks = **决策/成交次一交易日**的 `open`；asof=T+1 |
| 复权口径 | 同方案 A（不复权 + 除权窗口 pending） |
| 停牌处置 | T+1 无 bar（停牌）→ 再顺延至恢复日 open；顺延越久 pending 语义越弱，同样建议龄期上限 |
| 分红送转窗口 | 同方案 A |

- **公平性论证**：方案 A/B 用 T0 收盘估值，若快照 `ts` 在 T0 盘中，则 exit 用了决策时点之后的价格——020 前视闸只防 `asof < fill_date` 方向，防不了"决策在盘中、估值在当日收盘"。方案 C 使 exit 恒晚于决策，是唯一对"决策时点"严格公平的口径。
- **可行性**：三市场均可（T+1 bar 均落湖后才有值）；但**估值时滞 +1 交易日**：T0 晚间跑批时 T+1 bar 不存在 → 全部 pending 到 T+1 晚批，后验回填节奏慢一拍。
- **坑**：① 开盘价噪声大（跳空、集合竞价撮合量小），估值方差高于收盘口径；② 慢一拍的回填节奏与 020 "快照一出行就回填"的驱动初衷相抵触；③ 除权检测负担同方案 A（HK 依旧不可检）。

### 方案 D（变体，不单列推荐）：exit 价改用 VWAP

- 三市场可算性实测：US **自带 vwap 列**（us_daily，AAPL 343.99@20261016）；CN=`amount×1000÷(volume×100)`（千元/手单位换算，600519@20261020 自算≈1325 与收盘同量级，实测通过）；HK=`amount÷volume`（00700@20261020 自算=410.4，实测通过）。
- 定位：作为 A/B/C 的 **exit 价开关**（复权维度仍按所附方案处理——后复权乘 `F(T)/F(fill)` 对 VWAP 同样成立）。
- 坑：① CN 单位换算错一手差 100 倍，须单测钉死；② 成交量极小日 VWAP 偏离收盘价且不稳定；③ 口径解释成本高（老田圈选时按需启用）。

### 前复权为何被否（须论证项，正面回答工单质疑）

前复权（含青萍 sina 线的拆股前复权、us_market.py 现行口径）在 marks 场景**不可用**，论据三条：

1. **基准漂移改写历史**：前复权以"最新一日"为基准反推全序列——每次新除权，**全部历史价被重写**。同一个 entry（filled_price）在不同回填批次会读到不同的"前复权成交价"，`entry_source=settle_fill:{id}@{date}` 写下的快照时点事实从此对不上号。020 的账是 append-only、历史不可覆盖（posterior_link.py:515-520），而前复权价天然"历史可变"，两者**根本冲突**。
2. **us_market.py 自己的适用面就是反证**：其头注（us_market.py:16）写明前复权理由是"模拟盘买入都在近期，前复权近期价=真实价"——这是盯盘止损场景的权宜。marks 场景 fill 与 mark 之间可跨任意时长，"近期价=真实价"前提不复存在。
3. **后复权等价替代存在**：fill-date 锚后复权（方案 B）数学上等价于"以成交日为基准的前复权"，但**锚固定**、历史值不漂移，且 entry 保持真实成交价。凡前复权能算的，方案 B 都能算且不污染事实。

## 四、推荐口径与理由

**推荐组合（一票）**：

| 市场 | 推荐口径 | 理由 |
|------|----------|------|
| **CN（A股）** | **方案 B**（T0 收盘 · fill-date 锚后复权） | ① 唯一能把分红送转**自动算对**的口径（A 靠 pending 躲、C 同 A）；② entry=真实成交价，审计链直连 orders，不碰 020 一行代码；③ 复用本仓两件现成资产：因子湖 + pre_close 链接续判例，实现最薄 |
| **US** | **方案 A-US 变体**（T0 收盘 · 不复权 · pre_close 断裂检测 pending）+ 可选 VWAP 开关 | 无因子线，B 不可行；us_daily 自带 vwap 是三市场唯一直供，VWAP 收益比最高 |
| **HK** | **方案 A-HK 变体**（T0 收盘 · 不复权 · 龄期上限）+ **补源挂账** | 除权不可检是硬缺口：短期接受"跨除权样本偏差、卡片注记"；中期另立工单补 HK 复权因子源（建议归荀彧数据学院，接 SLA 清单 #9 同一线） |
| 取价时点 | 默认 **T0 收盘**；若老田要求"决策时点严格公平"则全市场切**方案 C（T+1 开盘）** | 这是**语义圈选项**不是技术题：后验若定义为"持仓当前值"→T0 收盘；若定义为"决策若执行的次日起算收益"→T+1 开盘。技术实现两者等价，只换喂价函数 |

**推荐的理由总纲**：020 的纪律是"不猜价、显式喂入、pending 不填 0"。方案 B 与该纪律同构——它不猜除权的影响，而是**用因子把影响显式算出来**；方案 A 在算不出时显式 pending；方案 C 在时间上显式让渡。三者都把"不造数"落到了口径层。

**上线前置条件（须老田确认）**：因子线滞后巡检接 freshness_guard（实测落后 2 个交易日）——方案 B 在 CN 除权日恰逢因子缺分区时会产脏价，此前 SLA 清单 #15 已定级"除权窗口升 P0"，本单建议把"因子线新鲜度 ≤1 交易日"作为 B 口径的上线闸门。

## 五、与 020 前视闸的咬合设计（描述，不落码）

现有闸（posterior_link.py:299-306）：`asof < fill_date` → 抛 `lookahead_price`。候选口径下的咬合要点：

1. **asof 语义钉死为"价格事实时点"**：喂价方必须把 `asof` 填**取价 bar 的 trade_date**，绝不填运行日。这一条同时解决两个问题：① 前视闸的判定基准真实有效（asof 撒谎=闸失效）；② 停牌顺延时旧价不冒充新价（asof=最后 bar 日期，审计可查"这价是 8 天前的"）。
2. **T0 收盘口径与闸的交互**：fill_date ≤ T0 时（常态），asof=T0 ≥ fill_date，闸自然通过。**边界情形**：当日买入当日估值（fill_date=T0=asof）——闸放行（`<` 为严格比较），语义正确：用当日收盘估当日成交的持仓无前视。
3. **T+1 开盘口径与闸的交互**：asof=T+1 > fill_date，闸通过且**时滞 +1 天天然在闸的语义之内**——闸防的是"用过去的价格"，不防"用更晚的价格"；晚价格正是估值本意，无需改闸。
4. **建议增补第二道闸（020 侧微改，须老田批）**：`marks.asof < snapshot.ts[:10]` → 警告或拒绝。现闸只保护"entry 侧因果"（不能拿成交前的价格当估值），不保护"exit 侧公平"（不能拿决策前的价格当卖出参考）。若老田圈选方案 C 则此闸天然不需要；若圈选 T0 收盘，建议至少加**警告级**（不阻断，写进 legs 留痕），把"决策盘中、估值收盘"的窗口如实暴露给审阅者。
5. **"严格早于"约束的适用面澄清**：020 的"严格早于"只用于 SELL 腿成本基准的 orders 检索（posterior_link.py:256 `fill_date<?`），**不适用于 marks**——marks 的 asof 允许等于 fill_date。喂价方设计时勿把"严格早于"误推广到 marks 侧，否则当日成交当日估值会被误杀成 pending。
6. **复权口径的自描述**：若圈选方案 B，marks 值建议携带口径声明（如 `basis:"hfq_fill_anchor"`）。020 的 `_price_input` 忽略未知键（posterior_link.py:286-295 实读：只取 price/asof 两键）——加字段零破坏、零落码于 020 主链，但让 posterior_ledger 的 legs_json 里的每条 exit_source 自带口径溯源，审阅时不用翻本单。
7. **喂价方自身的取数时点纪律**（设计描述）：喂价方读湖时只允许取 `trade_date ≤ 运行日−安全边际` 且**该 bar 已在湖中落盘**的价格；"bar 应该有但还没落"（如 23:35 批未跑）→ 该票本轮 pending，**禁止**用前一日 bar 冒充当日（asof 诚实原则自动覆盖此情形，但喂价方须把"湖无 bar"与"停牌无 bar"区分开——前者是数据未到，后者才走顺延逻辑）。
