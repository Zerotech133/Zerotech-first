# 数据仓 · 前后端对齐 v1（2026-11-03）

> 范围：`portal/static/dw_v2.html`（前端原型）与 8091/8734（后端 + 静态服务）
> 原则：**前端不假装有后端**；能接的接真实接口，不能接的明确标注“原型/待 P1”。

## 一、对齐后的数据来源

| 视图 | 数据来源 | 说明 |
|---|---|---|
| 总览/数据地图/质量/血缘/治理 | `GET /static/dw_v2_data.json`（8734 可用） | 页面加载时在线拉取构建快照；失败/404（如 8091 无静态）自动回退**内嵌快照** |
| 查询台 | `GET /api/dw/query`（后端） | 真实只读查询；参数 `id/limit/since/where/order/count`；返回 `state/columns/rows/count` |
| 手动录入 | 前端 staging（演示） | 后端 `/api/dw/manual/*` **未实现**；页面已明示“提交不会写入数据（P1）” |
| 张松部门/军团/智能体 | 构建快照内嵌 | 由 builder 从 8796/8096/8787 汇总；后端尚无对应 API（见 §五） |

**实测**：
- 8734 `/static/dw_v2.html` 200，页面提示「数据源：服务端快照（已在线刷新）」；
- 8734 `/static/dw_v2_data.json` 200（application/json）；
- 8091 `/api/dw/query` GET 200、POST 200（当前已生效）；
- 8091 `/api/dw/manual/ingest|entries` **404**（未实现，符合预期）；
- 文件（file://）打开时 fetch 失败 → 内嵌兜底；Playwright 无报错。

## 三、字段契约（UI 侧）

| UI 字段（`DW.datasets`） | 后端 raw 字段（`/api/dw/list`） | 处理 |
|---|---|---|
| `id` | `dataset_id` | 前端内部使用，不展示 |
| `label_cn` | 无（builder 由关键词生成） | 前端展示中文名 |
| `domain` / `freq_cn` / `qual_cn` | `domain` / 无 / `qualification_status` 衍生 | builder 生成中文标签 |
| `rows` / `freshness` | `rows` / 无 | builder 汇总 |
| 查询列 `columns` | `/api/dw/query` 返回英文列名 | 查询结果按所选数据 `columns` 顺序映射中文；常用列有内置词典 |

> 结论：`/api/dw/*` 是**注册层 API**（314 数据集口径）；`dw_v2_data.json` 是**数据仓 UI 快照**（catalog 256 表口径）。两者不是同一统计面，前端明确以 UI 快照为展示口径，查询走 API，避免混用。

## 四、前端改动

1. 页面启动 `fetch("/static/dw_v2_data.json")` → 成功替换 `DW` 并显示「数据源：服务端快照（已在线刷新）」；失败回退内嵌并显示「构建时内嵌快照」；
2. 查询台结果列名按 `DW.datasets[].columns` 顺序映射中文，常用列有中文别名；
3. 手动录入页明示「前端演示，后端暂存/审核接口尚未上线（P1），提交不会写入数据」；
4. 保留 file:// 离屏预览能力（内嵌数据），不影响检查器/截图。
