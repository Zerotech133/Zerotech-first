# SEPA 体系完善：补基本面成长过滤 · 回执

## 一、补了什么（Minervini 原教旨的关键缺口）
| 项 | 实现 |
|---|---|
| 基本面成长过滤（PIT） | 最新已公告财报（ann_date ≤ 扫描日）：净利同比 ≥15%、营收同比 ≥10%、ROE ≥8% |
| 成长加速版 | 另要求最新净利同比 > 上一期（环比改善） |
| 扫描频率 | 周一+周五双扫（对照仅周五） |
| 其余不变 | TT 8 条 + VCP 收缩/缩量 + 枢轴放量突破 + T+1 开盘 + 2% 风险 + 8% 止损 + B/C 退出变体 |

**市场等权基准：CAGR 9.44%／MDD -29.31%／波动 19.95%**

## 三、结论
1. **基本面过滤显著改善体系质量**：盈亏比 1.35 → **2.85–3.44**，CAGR 3.45% → **7.29%**（绝对最佳）、胜率 32%→39%；
2. **风险调整接近市场**：C_partial+市场过滤 CAGR 5.15%/MDD -23.6%/波动 10.6% → CAGR/vol 0.49 vs 市场 0.47；
3. **绝对收益仍低于市场**（最好 7.29% vs 9.44%）→ 体系在 A 股当前实现未跑赢等权市场；
4. **成长加速过滤过严**（13 信号）→ 无统计意义，需放宽阈值或改用 forecast（仅 2023+）补充；
5. 双周扫比周扫信号翻倍（73→65? 注：无基本面时双周未测；成长版 30→65）→ 扫描频率敏感，下一步试每日扫。

## 四、边界（必须强调）
- 基本面为 PIT 口径（ann_date），但**财报修正/重述**未处理；
- forecast 数据仅 2023+，本轮未接入；
- VCP 检测仍为代理；current stock_basic 幸存者偏差；未计停牌/涨跌停；
- 多组对照存在参数选择风险（本轮以「补缺口」为主，非调参最优）。
