# 研究流水线状态机 v1（ACAD1 实施说明）

> 工单：`WO-RESEARCH-FSM-20261027` ｜ 日期：2026-10-27 ｜ 状态：**MVP 已实现**
> 依据：开源调研报告 §4.2 P0-6（TradingAgents checkpoint/resume；MetaGPT SOP-as-code）；研究院 8 阶段流程。

## 1. 目标

把研究院 8 阶段从「口头流程」变成**可校验、可恢复、可审批**的状态机：

```
intake → hypothesis → evidence → validation → review → joint_review → decision → closed
```

- 每阶段有 required artifact schema（JSON）；
- 离开阶段必须提交 artifact，写入 history（checkpoint）；
- `decision`/`closed` 为审批门：必须人类 `approve --by <人>`，拒绝 AI 代签；
- 状态 JSON 持久化，进程中断后 `status`/`advance` 可继续；
- 纯本地、无 LLM、无网络、无新依赖。

## 2. 阶段与 artifact schema

| 阶段 | 含义 | required keys |
|---|---|---|
| intake | 立项 | title, question, object |
| hypothesis | 假设 | hypothesis, falsify_conditions, evidence_scope |
| evidence | 取证 | evidence, sources |
| validation | 验证 | method, metrics, result_summary |
| review | 评审 | reviewer, verdict, notes |
| joint_review | 联评 | participants, verdict, gaps（允许空=无缺口） |
| decision | 决策门 | decision, reason, signed_by |
| closed | 结项 | closure_summary, archive_path |

## 3. CLI

```powershell
# 初始化（状态落 agent_platform/data/academy/research_fsm/<topic>.json）
python -X utf8 agent_platform/tools/research_fsm.py init --topic AC-20261017-LCS1 --title "LCS-1 补证"

# 查看当前阶段/下一阶段/待补 schema/审批状态
python -X utf8 agent_platform/tools/research_fsm.py status --topic AC-20261017-LCS1

# 推进（提交当前阶段 artifact）
python -X utf8 agent_platform/tools/research_fsm.py advance --topic AC-20261017-LCS1 --to hypothesis \
  --artifact '{"title":"...","question":"...","object":"..."}'

# decision/closed 门：先审批
python -X utf8 agent_platform/tools/research_fsm.py approve --topic AC-20261017-LCS1 --by 老田 --note "同意"
```

- `--dry-run`：只校验并输出计划，零写入；
- `--json`：机器可读；
- 退出码：0 成功 / 2 输入或状态错误 / 3 审批门未过。

## 4. 恢复与审批语义

- 每次 `advance` 前必须通过 artifact schema；成功后 `history` 追加 `{from,to,at,artifact,approval}`；
- 中断后重新执行 `status` 即可看到当前阶段与 `resume_hint`；`advance` 从当前状态继续；
- 进入 `decision`/`closed` 后，`advance` 返回 exit 3 并提示 `approve`；approve 记录 `by/note/at`；
- 审批人不得为 `AI/ai/agent`（不代签）；
- 进入下一阶段时 approval 自动清空（每门独立）。

## 5. 边界

- MVP 不自动读写 `research_topics.json`/`academy_ops` 流水线（避免改动现有生产路径）；后续可加 `sync` 适配；
- 不自动生成 artifact 内容（由席位列产出）；
- 不替代 ACAD1/老田的评审与签字。
