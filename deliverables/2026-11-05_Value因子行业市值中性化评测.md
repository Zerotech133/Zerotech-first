# Value 因子行业+市值中性化后 20 日 CAR 评测

- 日期：2026-11-05
- 任务：m05527「对 Value 类因子做行业和市值中性化后重跑 20 日 CAR 评测」
- 结论：**中性化后 Value 因子的 IC / IC_t 普遍增强，多空方向由混乱转为一致向上；`book_to_market` 最强（中性化 IC +0.064、t=11.0、多空年化 +11.2%）。但 `fcf_to_market` 仍为负向、`ncf_to_market` 接近 0，`pegh5` 无足够历史。仍属研究结论，未接入生产。**

## 1. 口径

| 项 | 设置 |
|---|---|
| 中性化方法 | 每个交易日横截面 OLS：`factor ~ 1 + log(total_mv) + industry_dummies`，取残差 |
| 行业 | `stock_basic.industry`，缺失归为 `UNKNOWN`；行业哑变量 drop_first |
| 市值 | `daily_basic.total_mv`，取自然对数；缺失样本剔除 |
| 有效截面 | 每日 ≥ 50 只有效股票（`min_obs=min_cross_section=50`） |
| 信号窗口 | 20250102 ~ 20260929（423 个交易日） |
| 面板 | 484 个交易日 × 5,662 只（含 warmup） |
| 股票池 | tradable：收盘≥2 元、成交额≥5,000 万、上市≥250 天 |
| 前瞻收益 | 20 日 CAR：T+1 收盘入场、T+21 收盘卖出；个股复权收益−等权市场−30bp |
| IC | 每日横截面 Spearman；bootstrap 300 次 |
| 多空 | 每日五分组 Q5−Q1，方向调整后 ×252/20 年化（重叠窗口近似） |
| 基准 | 等权 20 日 CAR 均值 -1.81%（n=1,773,242） |
| 耗时 | 面板+财报加载+中性化+评测约 445 秒 |

## 3. 读表结论

- **`book_to_market` 仍是 Value 首选**：原始 IC +0.060 → 中性化 +0.064，t 由 6.2 升到 11.0；多空年化由 +3.0% 升到 **+11.2%**，p(≤0)=0.0000。
- **多数 Value 因子在中性化后改善**：`earnings_cut_to_market`（+0.025→+0.033）、`earnings_to_price`（+0.026→+0.034）、`ebitda_to_market`（+0.032→+0.041）、`ocf_to_market`（+0.026→+0.036）、`sales_to_market`（+0.042→+0.043）IC 均上升，t 值普遍翻倍以上；多空由负转正或显著增强。
- **`etp5`**：IC +0.042→+0.041 基本持平，多空 +6.5%→+6.4%；但只有 212 个有效日（历史不足），稳健性弱于 423 天因子。
- **`fcf_to_market` 中性化后仍为负**：IC -0.021→-0.014、多空 -7.9%→-5.1%、p(≤0)=1.0，说明其价值方向在样本内反向，不能按常规“低估值好”解释；需要单独做方向/行业条件检验。
- **`ncf_to_market` 接近 0**：中性化 IC +0.002、t≈2.6、多空 -0.7%，区分度弱。
- **`pegh5` 不可评测**：需要 1,260 日历史，当前面板仅 484 日。

## 4. 中性化诊断

- 每个因子在 484 个交易日均有有效截面（`pegh5` 除外）；`book_to_market` 累计有效样本约 202 万。
- 中性化后残差与 log(total_mv) 在每日截面上正交（OLS 性质），行业组均值约为 0。
- 多空年化为重叠 20 日窗口近似，不能直接当可交易组合收益；显著性以 IC_t / bootstrap p 为准。

## 5. 方法与边界

- 中性化只使用 T 日截面信息，无未来数据；但行业分类来自当前 `stock_basic`，存在轻微回看偏差。
- 未做涨跌停/停牌可交易性过滤、换手率约束、交易成本以外的冲击成本；未按市值/行业做分层组合回测。
- 评测为研究用途，**生产选股链路未接入 Value 中性化因子**。
