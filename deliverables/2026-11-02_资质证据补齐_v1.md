## 六、边界与风险（如实声明）

- **只读**：本轮未修改 `warehouse_registry.json` / `catalog.json` / contracts / lifecycle，未 `--apply`、未 commit、未重启服务；所有证据为读取与**只读探针**（footer statistics / sqlite mode=ro）。
- **probe 抽样局限**：每表最多 5 个文件 footer，行数为抽样行数；最新业务日若不在抽样文件内可能低估——最终以 apply 前逐表 dry-run 复取证为准。
- **证据 ≠ 覆盖核验**：manifest/审计证明「采集/对齐」，不等于源侧全量覆盖与发布资格；policy_evidence/verification_rule 仍需人工口径（本报告只给模板）。

- **sqlite/pg 判定口径未定**：即使扩探针，sqlite 表的「行数/最新日期」是否足以判 evidence_ok 需 DATA1 与 A0 确认。
- **凭据掩码**：全文与 JSON 不含任何 token/密码/DSN；数据源只写路径与公开标识。
- **清单性质**：60 表为分析建议，非批准后的执行清单；执行需按 S3-01 工单批准后逐批推进。
