# 中性化 book_to_market：PIT L2 + snapshot 标签体系复评（m06277）

> 日期：2026-11-05 11:51
> 结论：**snapshot 版 3.15% / Sharpe 0.708 不能复现，基本可判定主要由静态行业标签的前视/幸存偏差放大；但不能严格说“全部”来自前视——分类体系/映射误差仍占约 0.1–0.3pp 量级。**
> 生产状态：未接入选股，无生产变更。

## 1. 实验设计

上一轮结论留下的问题：snapshot（110 类）3.15% vs PIT L2（131 类）1.50%，差 1.65pp。差异可能来自两部分：

1. **标签前视/幸存偏差**：`stock_basic.industry` 是当前快照，回填到 2025 年等于用了未来行业分类信息；
2. **分类粒度/标签体系差异**：snapshot 110 类 vs 申万 L2 131 类，分组不同。

为拆开两者，构造三组同配置回测（60d、buffer 0.3、penalty 0.5、单边上限 0.3、30bp、多空各 50%）：

| 组 | 行业成员 | 行业标签 | 类别数 |
|---|---|---|---:|
| **S** snapshot | 当前 `stock_basic.industry` 静态映射 | snapshot 当前标签 | 110 |
| **P** PIT L2 | 申万 L2 历史成员（in_date/out_date） | 申万 L2 名称 | 131 |
| **M** PIT L2 + snapshot 标签 | 申万 L2 历史成员 | 每个 L2 指数取最新有效成员的 `stock_basic.industry` 众数 | 81 |

M 组的含义：保留 PIT 历史成员，但把标签体系尽量换成 snapshot 口径；若 3.15% 的差距全来自粒度，M 应接近 S；若全来自前视，M 应接近 P。

M 组映射说明：130 个 L2 指数成功映射，聚合后只有 81 个 snapshot 标签（多个 L2 对应同一 snapshot 行业，另有 29 个 snapshot 标签未被任何 L2 的众数覆盖）。因此 M 的分类粒度实际比 S 更粗，这会**低估** M 的收益，从而**高估**前视效应——这是本实验的主要保守性偏差。

## 3. 分解：3.15% 的差距去哪了

以 both 配置为例：

```
S - P = 1.65pp
S - M = 1.91pp   ← 静态标签（前视/幸存）效应（含映射误差）
M - P = -0.26pp  ← 标签体系/粒度效应（M 更粗，反而更低）
```

| 配置 | S-P 总差 | S-M 标签效应 | M-P 粒度/映射效应 |
|---|---:|---:|---:|
| base | +0.97pp | +1.00pp | -0.03pp |
| +行业 | +1.24pp | +1.13pp | +0.10pp |
| **+行业&市值** | **+1.65pp** | **+1.91pp** | **-0.26pp** |

Sharpe 同向：both S-P 0.388，S-M 0.468，M-P -0.079。MDD：S -4.46% → P -5.38% → M -6.77%。

**解读：**

1. **粒度不能解释 3.15%。** 从 L2 131 类换成更粗的 81 类，收益只下降 0.26pp；而从 L1 31 类升到 L2 131 类也只提升 0.36pp。行业粒度在 31→131 区间的总效应仅 0.3–0.4pp，不可能解释 1.65pp。
2. **标签前视/幸存偏差是主因。** 保留 PIT 历史成员、把标签换成 snapshot 口径后，M 仍只有 1.24%，远低于 S 的 3.15%。S 的超额收益依赖“用当前行业分类回填历史”，属于不可实现的未来信息。
3. **不能严格说“全部”。** M 的 81 类比 S 的 110 类更粗，且 modal 映射有误差；若把这部分修正回去，M 可能略高（估计 +0.1–0.2pp），但不足以改变结论。因此更准确的说法是：**约 1.4–1.5pp 可归因于静态标签前视/幸存偏差，≤0.3pp 可归因于分类粒度/映射误差，3.15% 不是可持续基线。**

## 4. 限制

- M 组标签只有 81 类，分类粒度比 snapshot 的 110 类更粗；modal 映射会丢失部分行业区分，M 结果偏保守。
- PIT L2 末端覆盖 5,216/5,662（92.1%），未覆盖约 446 只按 UNKNOWN 处理；snapshot 标签覆盖当前 5,582 只，生存者偏差的精确规模无法从现有数据完全量化。
- 60 日调仓、8 次调仓、30bp 单边成本、多空各 50%；未做涨跌停/停牌以外更细的成交约束。
- 本实验只针对中性化 `book_to_market` 单因子，不代表其他因子或更复杂组合。
- 结论是“3.15% 不可作为研究基线”，不是“所有行业中性化研究都无效”；PIT L2 的 1.50%/.320 仍优于 PIT L1 的 1.14%/.201。

## 5. 结论与建议

- **采用 PIT L2 both（年化 1.50%、Sharpe 0.320、MDD -5.38%）作为该因子的研究基线**；移除 snapshot 3.15%/.708 的结论。
- 行业约束方向仍成立：PIT L2 内 base 0.88% → +行业 1.27% → +行业&市值 1.50%，暴露下降、换手/成本基本不变。
- 若要进一步精确分解，需要**同 taxonomy 的历史行业标签**（例如按 snapshot 110 类逐期重建的 PIT 分类，或更细的 PIT L2/L3 全量成员），现有 Tushare 数据只能做到近似。
- 仍不接生产：收益水平低、样本窗口短、未做交易约束与容量评估。
