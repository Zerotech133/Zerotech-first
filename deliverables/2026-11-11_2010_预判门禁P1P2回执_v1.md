## 五、教训与建议（防复发）

**根因**：多会话共用一个主工作区的 index。`git add` 一旦落下，任何人 `git commit`（尤其带 `-a` 或整索引提交）都会把它带走。

**改法**：

1. **不要先 `git add` 再提交**。用 `git commit -F <msg> -- <显式路径>` 一步完成，工作区内容直接落进提交，不在 index 里停留
2. 提交前 `git diff --cached --name-status` 核对一次；提交后 `git show --name-only HEAD` 复核一次
3. 大批量并行时，改用独立 `worktree`（仓库已有 `.worktrees/` 惯例），各自一套 index
