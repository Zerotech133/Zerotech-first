### 1.1 sqlite_table — `xq_xq_status`（`quant_backtest/data/xueqiu/xueqiu_info.db`）

| 用例 | 期望（直连 SQL） | 实际（query） | 判定 |
|---|---|---|---|
| count | 33,353 | 33,353 | ✅ |
| where `like_count>=1000` | 17 | 17 | ✅ |
| order `created_at:desc` + limit/offset（page1/page2） | page1 `414982133,414967907,414951448,414941410,414938797`；page2 `414937529,414936906,414933564,414916392,414916279` | **逐 id 完全一致** | ✅ |
| **since `2026-10-01`** | **279** | **0**（state=no_data） | 🔴 **FAIL** |

- 根因：`dataset_registry.py:1378` — `val = int(since["ymd"]) if "INT" in t_type else since["ymd"]`，将 `20261001` 与 `created_at` 的 ISO 文本（`'2026-11-01 20:17:19'`）做字符串比较，恒 false；`since_applied=true` 但结果为空（假绿风险）。
- 修复建议（L1）：TEXT 列用 `since["date"].isoformat()`（`2026-10-01`）或 `"%Y-%m-%d 00:00:00"` 下界；INT 列保持 `int(ymd)`。

### 1.4 文件级目录 — `research_reports`（424 文件）

| 用例 | 期望（os.walk 直扫） | 实际（query） | 判定 |
|---|---|---|---|
| count | 424 | 424 | ✅ |
| where `ext=.md` | 173 | 173 | ✅ |
| order `mtime:desc` | mtime 倒序 | `2026-11-02 17:11 / 17:03 / 17:00 / 16:47 / 16:22` 倒序正确 | ✅ |
| **since `2026-10-01`** | 424（全部文件 mtime≥10-01） | **`AttributeError: 'datetime.date' object has no attribute 'timestamp'`** | 🔴 **FAIL** |
| **order `size:desc`** | 987182 应排第 1 | 实际 `[9965, 989, 987182, 98407, 980]`（字符串序） | 🔴 **FAIL** |

- 根因 ①：`dataset_registry.py:1827` — `since_ts = since["date"].timestamp() if since else None`（`datetime.date` 无 `timestamp()`；对比 `_query_jsonl:1713` 已正确用 `datetime.datetime.combine(...).timestamp()`）。
- 根因 ②：`dataset_registry.py:1849` — 排序 key `str(r.get(o["field"]))`，`size` 按字符串排序；`mtime` 因 ISO 文本字典序与时间序一致而"碰巧正确"。
- 修复建议（L1）：`datetime.datetime.combine(since["date"], datetime.time()).timestamp()`；排序对数值字段用 `float(value)`、文本字段保持 str（或按字段类型给 key）。
