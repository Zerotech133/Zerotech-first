## 二、路径 A：百炼控制台（推荐先做，无需给凭据）
### 步骤
1. 打开 [百炼控制台](https://bailian.console.aliyun.com/) → 开通服务（新户常有免费额度）；
2. 「模型调优 / 训练」→ **创建数据集** → 上传训练/验证 jsonl（格式 ChatML messages，单文件 ≤300MB）；
3. **创建训练任务**：
   - 基座模型：`Qwen2.5-14B-Instruct`（若控制台无，则选 `Qwen3-14B`）；
   - 训练方式：**SFT（高效微调 / LoRA）**；
   - 超参建议：`n_epochs=3`、`batch_size=16–32`、`max_length=2048–4096`、`split=0.9`、`learning_rate=1.6e-5`（默认即可）、`lora_rank=64`；
   - 数据：训练集=上表 train；验证集=val（可选）；
4. 训练（约 1–2h，期间可看 loss）；
5. 训练完成后选 checkpoint → **部署**（按 token 计费或专用算力）；
6. 部署成功后在控制台拿 **Model Code / 实例 ID + API Key**，调用测试：
```bash
curl 'https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation' \
 -H 'Authorization: Bearer <API_KEY>' -H 'Content-Type: application/json' \
 -d '{"model":"<你的模型实例ID>","input":{"messages":[{"role":"user","content":"什么是均线粘合？"}]},"parameters":{"result_format":"message"}}'
```
7. 把 10 条测试问题结果发我，或我给你 `answer_eval.py` 的 40 题评测对照。

## 三、路径 B：用 API 自动跑（需新加坡区 Key）
> 官方文档：创建微调任务 API **仅新加坡区**（[fine-tuning API guide](https://www.alibabacloud.com/help/en/model-studio/fine-tuning-api-guide)）；北京区请在控制台建任务。

1. 在百炼控制台创建 API Key（注意选**新加坡**区）；**不要把 Key 发在聊天里**；
2. 把 Key 写入本机文件（只读权限即可）：
   `C:\项目\_vault\secrets\dashscope_api_key.txt`（单行）；
3. 告诉我「Key 已放好」，我执行：
```powershell
python tools/finetune/bailian_sft.py prepare        # 已生成，可跳过
python tools/finetune/bailian_sft.py upload --file deliverables/bailian/sft_v2_train_chatml.jsonl
python tools/finetune/bailian_sft.py create --file-id <返回id> --model qwen3-14b --epochs 3 --batch 16 --max-length 2048
python tools/finetune/bailian_sft.py status --job-id <job_id>
```
4. 训练完成后在控制台「部署」→ 拿实例 ID；我用 W13 40 题评测。

## 四、路径 C：如果要在阿里云租 GPU（PAI-DSW）
> 阿里云**不提供 4090**；可选 A10 24G / A100 40G，价格比 AutoDL 高。
- 开通 PAI-DSW → 新建 Notebook（A10 24G 或 A100 40G，PyTorch 镜像）；
- 上传 `deliverables/2026-11-04_微调云训练上传包_v1.zip`；
- 环境：`pip install -U "llamafactory==0.9.*" modelscope`；下载 Qwen2.5-14B；
- 配置用 `configs/sft_14b_v2.yaml`（bf16/fa2 适配 4090/A10/A100），A10 24G 与 4090 显存相同；
- 成本：A10/A100 约 ¥3.5–8/h，4–6h → **¥20–60**；仍高于 AutoDL 4090。
