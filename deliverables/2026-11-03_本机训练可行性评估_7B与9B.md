# 本机训练可行性评估（7B / 9B）· 2026-11-03

> 对象：AMD Ryzen AI MAX+ 395（Strix Halo）本机｜评估：D1 7B QLoRA 冒烟能否本地跑、9B 本地模型可用性
> 结论：**9B 本地推理可用（34 tok/s），但 9B/7B 的 QLoRA 正式训练本机不可行；7B CPU-LoRA 冒烟可行（约 2.5–5h，需装 PyTorch 栈），正式训练仍需云 4090。**

## 一、硬件实测
| 项 | 实测 |
|---|---|
| CPU | AMD Ryzen AI MAX+ 395，16 核 / 32 线程，3.0GHz |
| 内存 | **128GB 统一内存**（当前空闲 62.7GB） |
| iGPU | Radeon 8060S（RDNA3.5，40CU，共享内存） |
| 磁盘 | **1,081GB 空闲** |
| OS | Windows（无 NVIDIA CUDA；无 ROCm） |
| Ollama | 0.40.5；qwen3.5:9b 全量加载在 iGPU（5.9GB vram） |

## 二、实测吞吐（qwen3.5:9b）
| 后端 | 吞吐 | 说明 |
|---|---|---|
| **iGPU（默认）** | **34.2 tok/s** | 推理可用（生成 128 tokens 3.74s） |
| **CPU-only** | **13.7 tok/s** | 16 核并行，仍可用 |

→ **9B 本地推理完全可用**：可做 C 类生成、D4 裁判/拒绝采样、评测、RAG 问答；成本为 0。

## 三、训练可行性
### 3.1 现实约束
- LLaMA-Factory QLoRA 依赖 **CUDA + bitsandbytes 4bit** → 本机无 N 卡，**不可用**；
- 本机 PyTorch 训练栈未安装（torch/transformers/peft/bnb 全部缺失，需约 2–3GB 安装）；
- Windows 无 ROCm；WSL 只有 docker-desktop 发行版（无 Ubuntu），ROCm 路线暂不可行；
- iGPU 训练只能走 **torch-directml**（实验性）：不支持 4bit、算子覆盖有限，训练稳定性未知。

### 3.2 基于实测的耗时估算（D0 数据集：2,545 样本，平均 97 tokens/样本）
| 方案 | 冒烟（10% 子集×2 epoch ≈ 4.9万 tokens） | 全量 SFT（×3 epoch ≈ 74万 tokens） | 可行性 |
|---|---|---|---|
| **CPU 7B LoRA（fp32，无量化）** | **约 2.5–5h** | **约 40–55h** | ⚠️ 冒烟勉强可行；全量不可行 |
| **CPU 9B LoRA（fp32）** | 约 3–6h | 约 50–70h | ❌ 不建议 |
| iGPU torch-directml（若可用） | 约 0.5–1h（乐观） | 约 8–20h | ⚠️ 实验性，风险高 |
| 云 4090 QLoRA（方案原定） | **约 2–5 分钟** | 约 0.5–1h | ✅ 推荐 |
| 9B 本地推理（非训练） | — | — | ✅ 34 tok/s 可用 |

> 说明：CPU 训练按「推理 13.7 tok/s ÷ 3（fwd+bwd）」估算；fp32 7B 权重约 28GB，128GB 内存可容纳；但无 bnb 4bit，显存/内存与速度均不占优。

## 四、9B 本地模型评估
| 用途 | 可行性 | 说明 |

## 五、建议（混合路线，省钱且保进度）
1. **D1 冒烟**：先在本机做 **CPU 7B LoRA 冒烟**（免费，约 2.5–5h，验证数据/配置/训练代码；需安装 PyTorch CPU 栈约 2–3GB）——把「管线错误」在花钱前暴露；
   - 若要求更快：装 torch-directml 试 iGPU（实验性，不建议作为唯一路径）；
2. **正式 D2/D3（7B/14B SFT）**：仍租 **AutoDL 4090**（¥1.5–2.5/h；冒烟后正式约 2–4h，费用中位 ~¥50，上限 ¥240 < ¥300 红线）；
3. **9B 本地**：用于 C 补量、D4 裁判、评测，替代部分 API 成本；
4. **9B/14B 本地训练**：不投入（无 CUDA/ROCm，时间成本 > 云租金）。
