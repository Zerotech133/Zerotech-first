## 三、推荐执行路线（AutoDL 4090）
### 0) 准备
- 注册 AutoDL（支付宝/微信），实名；新户可用体验额度；
- 本地上传包：`deliverables/2026-11-04_微调云训练上传包_v1.zip`（含 SFT v2 / DPO v2 / dataset_info / v2 配置 / 运行脚本 / README）。

### 1) 租实例
```text
地区：选 4090 有货且价格低的区（凌晨/现货更便宜）
GPU：RTX 4090 24G ×1
镜像：PyTorch 2.4 + CUDA 12.1（或社区 LLaMA-Factory 镜像）
数据盘：≥50GB（模型 14B fp16 约 28GB + 输出）
计费：按量；训练完立即关机
```

### 2) 上传与解压
```bash
# 本地 scp 到实例（AutoDL 控制台有 SSH 命令）
scp deliverables/2026-11-04_微调云训练上传包_v1.zip root@<host>:/root/autodl-tmp/
cd /root/autodl-tmp && unzip -q 2026-11-04_微调云训练上传包_v1.zip
```

### 3) 装环境 + 下模型
```bash
pip install -U "llamafactory==0.9.*"   # 若镜像已带可跳过
pip install modelscope
modelscope download --model Qwen/Qwen2.5-14B-Instruct --local_dir /root/autodl-tmp/models/Qwen2.5-14B-Instruct
# 7B 冒烟再下 7B（可选）
```

### 4) D1 7B 冒烟（约 10–20 分钟）
```bash
cd /root/autodl-tmp && bash run_smoke_7b.sh
```

### 5) D2 14B SFT（2.5–4h）
```bash
cd /root/autodl-tmp && bash run_sft_14b.sh
# 输出：saves/qwen25-14b-qlora-sft-v2/adapter_*
```

### 6) 训练后
- 把 adapter 目录打包下载（约 100–300MB）；
- 立即关机/释放实例（避免计费）；
- 本地用 W13 的 40 题复评（`tools/kb_corpus/answer_eval.py`）对比基线阈值。

### 7) DPO（可选，SFT 验收后）
```bash
cd /root/autodl-tmp && bash run_dpo_14b.sh   # 42 对先验；正式 DPO 需 SFT 模型拒绝采样扩充
```

## 四、风险与对策
| 风险 | 对策 |
|---|---|
| 4090 缺货/被抢占 | 备选 3090 24G / A100 40G；训练中定期 save（配置已 save_strategy） |
| 显存 OOM（24G 跑 14B QLoRA） | 已配 4bit + grad ckpt + seq 2048 batch1；OOM 则 seq 1536 / 1024 |
| 模型下载慢 | 用 ModelScope 国内源；或 AutoDL 公共模型目录 |
| 环境装不上 | 用社区「LLaMA-Factory」镜像；或 pip 指定镜像源 |
| 费用失控 | 训练前预估 4–5h；设自动关机；**上限 ¥50** |
| 数据隐私 | 上传数据为公开学习资料/合成数据，无个人敏感信息；不上传 `_vault`/token |
| 托管方案锁死 | 若选百炼，先确认 LoRA adapter 是否可导出；否则仅用于对比实验 |
