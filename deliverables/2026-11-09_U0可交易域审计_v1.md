# U0 可交易域审计：195bp 是从哪来的

- 日期：2026-11-09
- 触发：老田一句「选都不选，哪来买不买的问题」
- 性质：**只读审计**（不改信号、不改特征、不落新面板）
- 样本：`portal/hf_feat2_panel.jsonl` 6,900 笔 / 398 入场日 / 2024-01-02 ~ 2025-10-24
- 数据源：`ts_bak_basic`（逐日名称，PIT 定 ST）、`ts_daily`（收盘/成交额）、`ts_daily_basic`（逐日 `circ_mv`）

---

## 0. 一句话结论

> **第十九轮那个「单笔 α 196bp」不是一个策略的边际，是一个会计口径的假象：**
> **它 100% 由 602 笔「日成交额 < 2,000 万」的票贡献（占 8.7%，均值 +3,756bp，右尾 87.7%）。**
> **把这批票剔掉，全样本从 +195bp 变成 −145bp。剔得越干净，越负，且单调。**

这条结论推翻的不是某一个特征，而是**前面五轮所有 ΔA / Δt / holdout 的基座**。

## 1. 现状：扫描器根本没有"选"这一步

| 环节 | 事实 | 证据 |
|---|---|---|
| 扫描池 | `os.listdir(ASHARE)` 枚举全部 A 股 parquet，**唯一过滤 `MIN_BARS = 120`（剔次新）** | `quant_backtest/chanlun_scan.py` L441 |
| 市值过滤 | **无** | 同上，全文无 `circ_mv` / `total_mv` |
| ST 过滤 | **无** | 同上 |
| 流动性过滤 | **无** | 同上 |
| 信号覆盖 | 6,900 笔落在 **4,268 只票**（全 A ≈5,400，**79%**） | 面板去重 |
| 池子规模分布 | 信号中位流通市值 **39.2 亿**，当日全市场中位数的 **0.99×** | `ts_daily_basic` PIT |

**所以这个池子不是"小盘池"，它是"全 A 流过就记一笔"。** 它连"小盘"这个标签都没兑现——规模分布和全市场几乎重合。

这也解释了为什么前几轮"小盘"的说法一直对不上：**小盘从来没有被显式选过，它是被动混进来的。**

## 2. 分解：195bp 归谁

只剔一类，看 A 怎么动（A 为 250 日超额，bp）：

| 口径 | n | A(bp) | ΔA | 右尾 | 左尾 |
|---|---|---|---|---|---|
| 全样本 | 6,900 | **+195** | — | 52.5% | 20.7% |
| 只剔 ST/退 | 6,763 | +116 | −79 | 52.1% | 20.9% |
| 只剔 次新 <250 日 | 6,831 | +188 | −7 | 52.5% | 20.6% |
| **只剔 成交额 < 0.2 亿** | **6,298** | **−145** | **−340** | 49.1% | 22.1% |
| 剔 ST/退/低价/次新（保留低量） | 6,693 | +109 | −86 | 52.1% | 20.8% |
| 上述 **+** 剔成交额 <0.2 亿 | 6,142 | **−189** | −384 | 48.9% | 22.2% |

**监管类（ST/退/次新）加起来只值 −86bp；流动性一项值 −340bp，单独一项就把符号翻过来。**

### 2.1 那 602 笔长什么样

| 项 | 值 |
|---|---|
| n | 602（占 8.7%） |
| A | **+3,756bp** |
| 右尾 >+20% | **87.7%** |
| 左尾 <−10% | **5.6%** |
| d0 当日成交额中位 | **0.126 亿**（126 万元） |
| d0 流通市值中位 | **14.1 亿** |
| 2024 年 | 564 笔，+3,754bp |
| 2025 年 | **38 笔**，+3,776bp |

8.7% 的样本，贡献了全部正超额还多——剔除后全样本净额为负。

### 2.2 成交额门槛敏感性（同时剔 ST/退/低价/次新）

| 门槛 | n | A(bp) | 右尾 | 左尾 |
|---|---|---|---|---|
| 无 | 6,900 | **+195** | 52.5% | 20.7% |
| ≥0.1 亿 | 6,509 | **−134** | 50.9% | 21.3% |
| ≥0.2 亿 | 6,142 | **−189** | 48.9% | 22.2% |
| ≥0.3 亿 | 5,640 | −226 | 47.3% | 22.8% |
| ≥0.5 亿 | 4,718 | −278 | 45.1% | 24.2% |
| ≥1.0 亿 | 3,255 | −282 | 43.1% | 25.8% |
| ≥2.0 亿 | 1,929 | −212 | 41.0% | 27.4% |

**单调。连最宽松的 0.1 亿门槛都是负的。** 不存在"门槛挑错了"这一说——是这条曲线本身没有正值区间。

## 3. 但"买不到"这个说法要修正

第一版判断是"这些票买不到"。查了 T+1 开盘跳空，**这个判断是错的**：

| 分组 | n | 中位跳空 | 开盘涨停(≥+9.5%) | 高开≥+5% | 低开 |
|---|---|---|---|---|---|
| 全样本 | 6,898 | −0.10% | **0.2%** | 0.6% | 53.4% |
| 可交易 | 6,141 | −0.11% | 0.2% | 0.6% | 54.3% |
| 被剔除 | 757 | 0.00% | **0.1%** | 0.7% | 46.1% |

只有 0.1% 开盘涨停，46% 还是低开。**它们能成交，进得去、出得来。真正受限的是量，不是价。**

### 3.1 容量才是约束

低量集合中位日成交额 0.126 亿。按 5 仓均分：

| 账户 | 单票(万) | 占 p10 成交额(0.046亿) | 占中位成交额(0.126亿) |
|---|---|---|---|
| 100 万 | 20 | 4.4% | 1.4% |
| 300 万 | 60 | 13.0% | 4.2% |
| 500 万 | 100 | 21.7% | 6.9% |
| 1,000 万 | 200 | 43.5% | 13.9% |
| 2,000 万 | 400 | 87.0% | 27.8% |

**百万级账户能吃；300 万开始明显；1,000 万以上就不是这个策略了。** 而且 2024-02 微盘流动性断崖那种日子，回测里直接没样本（那个月只有 2 笔信号），风险是隐藏的。

## 4. 更关键的一层：可交易域里，没有一个格子两年都为正

T+1 开盘可成交、剔除 ST/退/低价/次新/低量之后的 6,142 笔，按市值五档 × 年份拆（A, bp）：

| 市值档 | 2024 | 2025 |
|---|---|---|
| Q1 最小 | **+761** (n=687) | **−1,318** (n=317) |
| Q2 | −619 (n=886) | −1,052 (n=328) |
| Q3 | −625 (n=871) | −59 (n=359) |
| Q4 | −298 (n=866) | +116 (n=425) |
| Q5 最大 | **−15** (n=878) | **+791** (n=525) |

**10 个格子里，正号只有 3 个，且没有任何一格两年都为正。** 2024 小盘赚（Q1 +761）、2025 大盘赚（Q5 +791），中间四档基本全负。

对照全样本口径（未过滤）的五档：

| 档 | 全样本 A / n / 右尾 | 可交易 A / n / 右尾 |
|---|---|---|
| Q1 最小 | **+1,670** / 1,432 / 64.0% | **+105** / 1,004 / 56.3% |
| Q2 | −475 / 1,403 / 58.2% | −736 / 1,214 / 54.0% |
| Q3 | −386 / 1,325 / 52.1% | −460 / 1,230 / 49.8% |
| Q4 | −210 / 1,329 / 46.9% | −162 / 1,291 / 46.5% |
| Q5 最大 | +291 / 1,411 / 40.8% | +287 / 1,403 / 40.6% |

**"小盘优势"从 +1,670bp 掉到 +105bp，跌幅 94%。** 而可交易的大盘（Q5）是 +287bp——**在能买的票里，大盘比小盘好。**

## 5. 顺带解释掉的两个旧结论

### 5.1 为什么"结构不迁移"（第二十轮 ρ=−0.164）

不是特征失效，是**特征学到的是风格，风格一年一换**。可交易域里 2024 微盘 / 2025 大盘这条主线一翻转，任何以"哪批票涨得多"为目标的固定阈值都会反号。ρ<0 只是这个翻转在秩相关上的投影。

### 5.2 为什么"196bp vs 122bp"这条主线不成立

| 口径 | A | 对 122bp 成本 |
|---|---|---|
| 全样本（旧口径） | +195 | 看起来覆盖 |
| **可交易域 250 日** | **−189** | **亏** |
| 可交易域 160 日 | +109 | 约打平 |
| 可交易域 60 日 | +36 | 亏 |

按年：可交易域 2024 是 −201 / +203 / +90，2025 是 −163 / −92 / −81。

**成本侧本来是对的（少进出几次），但入场端的 196bp 先被证伪了。** 两个数都不成立时，讨论"谁大谁小"没有意义。

## 6. 对业务流程的判断

老田那句"选都不选，哪来买不买"——机制上完全正确，而且比原话更严重一层：

**"选"不是买不买的前置优化，它直接决定这条策略的符号。**

```
U0 可交易域   上市>250日 / 非ST非退 / 价格>1元 / 日成交额>0.2亿
              现状：全空（只有 MIN_BARS=120）        ← 决定 +195 还是 −145
U1 选         规模 × 风格，决定"这一段在哪一层做多"
              现状：全空                              ← 决定 +761 还是 −1318
S  信号       缠论 1买/2卖/3卖 —— 现状：有，但跑在"全A"上
E  买不买     入场特征（两轮，结论不迁移）
X  怎么卖     出场规则（第十九轮判死）
```

现在系统是 `S(全A) → E`，U0 和 U1 都缺。而且缺的方式不一样：

- **U0 是"卫生"问题**，一天能补，补完所有历史结论都要重算；
- **U1 是"择时"问题**，不是选股问题——因为 20 个格子里没有稳定为正的格子，剩下能做的只有"判断今年是微盘年还是大盘年"。这属于宏观/风格择时，跟加特征不是一回事。

### 6.1 一个重要提醒

Q1 可交易档 2024 +761bp、n=687，是唯一看着有戏的格子。但它 **2025 是 −1,318bp**，且 2024 那半年（3~10 月）正是微盘暴力反弹期。**在这个格子上继续调参，等于赌风格不切——这跟第二十轮赌的是同一件事，只是换了个入场券。**

## 7. 口径缺陷（本报告自己承认的）

1. **成交额用 d0 单日，没用 20 日均值。** 单日缩量会误伤，可能多剔了一些本可交易的票。方向上会**低估**可交易域的正面程度，所以不改变结论方向，但数字会有偏移。下一步该用 20 日均额重算一次。
2. **A 用 000985 基准 + 逐笔 β。** 低量票的 β 估计噪声大。但低量集合的**右尾 87.7% 是原始收益**（`ret`，非超额），不依赖 β，所以"这批票确实涨了"这个事实是稳的。
3. **250 日窗口只用前复权收盘，未考虑停牌/退市处置。** 低量票中途停牌的比例应高于均值，真实可交易性比数字更差，不会更好。
4. **未做 2026 年样本。** 信号只到 2025-10-24，2026 年（数据到 2026-11-06）没有覆盖。

## 附：复算方式

本报告全部数字来自一次性只读脚本（未落盘、未入研究线），复算需三步：

```bash
# 1) 读 panel
portal/hf_feat2_panel.jsonl          # 6,900 笔，字段 c/d0/ed/ret/a/a1/a60/a160/listed_days

# 2) 关联 PIT 数据（按 (trade_date, ts_code) 键）
quant_backtest/data/tdx/ts_bak_basic/     # name  -> ST/退 判定
quant_backtest/data/tdx/ts_daily/         # close/amount/open/pre_close
quant_backtest/data/tdx/ts_daily_basic/   # circ_mv -> 市值分位

# 3) 过滤条件（全部在 d0 当日判定，只用 d0 及之前）
上市 >250 交易日 / name 不含 ST 与 退 / close ≥1 元 / 成交额 ≥0.2 亿
```

`circ_mv` 分位按 d0 当日全市场截面计算（`bisect_left / (n-1)`，0=最小 1=最大）。
