# 板块口径核对：行业「新型电力」vs 概念「电力」

日期：2026-11-08　对象：2026-11-06 交易日　数据源：xtcloud `ts_kpl_concept_cons`（13711 行/日，250 个题材）
结论一句话：**行业口径把「板块」划错了对象。** `stock_basic.industry` 的「新型电力」是
tushare 的「新能源发电运营商」桶，32 只、只覆盖市场「电力」概念的 12%，且**一家电力龙头都不含**。

---

## 一、三项实测

### 1. 这个板块名有两套完全不同的东西

| 口径 | 名称 | 成员数 | 性质 |
|---|---|---|---|
| 行业（stock_basic.industry） | 新型电力 | **32** | tushare 细分行业桶 |
| 概念（开盘啦 ts_kpl_concept_cons） | 电力 | **219** | 市场题材 |
| 概念族并集（电力+智能电网+储能概念+北美/欧洲电力基建+华为储能） | — | 382 | 太宽，不宜当单一板块 |

开盘啦 250 个题材里**没有「新型电力」这个名字**。最接近的是「电力」「智能电网」（60 只）、
「储能概念」（104 只）、「北美电力基建」（73 只）、「欧洲电力基建」（64 只）。

### 2. 成员差异：只重合 26 只

    A（行业新型电力，32） ∩ B（概念电力，219） = 26
    A 独有 6 只：东方新能、云南能投、富春环保、珠海港、蓝丰生化、龙源电力
    B 独有 193 只

行业独有那 6 只里，**珠海港是港口、蓝丰生化是农药**，开盘啦给它们挂的概念分别是
「港口航运」「（无）」——本来就不该出现在电力板块里。富春环保同样零电力概念。

概念独有那 193 只里，包含电力板块的绝对主力：

| 股票 | 在行业「新型电力」 | 在概念「电力」 |
|---|---|---|
| 长江电力 600900 | 否 | 是 |
| 华能国际 600011 | 否 | 是 |
| 国电电力 600795 | 否 | 是 |
| 国电南瑞 600406 | 否 | 是（V2G/充电桩/中证A50） |
| 中国电建 601669 | 否 | 是（中字头/储能/俄乌重建） |
| 特变电工 600089 | 否 | 是（AI硬件/储能/光伏/北美电力基建） |
| 许继电气 000400 | 否 | 是（智能电网/充电桩） |

一个叫「新型电力」的板块，不含长江电力（水电）、华能国际（火电）、国电南瑞（电网设备），
那它就不是市场说的新型电力系统。**它是发电运营商**：川能动力、太阳能、龙源电力、三峡能源、
华电新能、浙江新能、江苏新能、嘉泽新能、中国核电、中国广核、节能风电、中闽能源……

### 3. 接力判据在两边各是什么结果（11-06）

| 指标 | 行业「新型电力」 | 概念「电力」 |
|---|---|---|
| 成员数 | 32 | 219 |
| 当日封住涨停 | 3（新能股份、立新能源、东方新能） | 3（新能股份、立新能源、润建股份） |
| 连板梯队（ts_limit_step） | **0 只** | 1 只：润建股份 2 板 |
| 龙虎榜上榜 | **0 只** | 2 只（大业股份净卖） |

归一化凝聚度（同袍数 / 期望同袍数，消除板块规模差异后可比）：

    行业口径 lift = 2.64    概念口径 lift = 2.96      （差 12%，不算悬殊）
    板块内只有自己一个涨停：行业 15/30 只  →  概念 9/30 只

**读法**：概念口径并没有在统计上碾压行业口径（lift 只高 12%），它胜出的地方是
「把孤立的涨停票找到同伴」——15 只降到 9 只。对联动/接力分析这才是要害。
而行业口径的真正问题是**名字与成员对不上**，不是凝聚度差。

## 二、对已有结论的影响

11-06 那条结论链（「新型电力 32 只全员首板、主力净买而全档净流出 = 散户接盘、涨得不实」）
**结论方向未被推翻，但载体和强度都要改**：

- 「梯队 0 只全是首板」在 32 只桶内成立，但它只是电力概念的 12%，且当日概念口径里
  电力方向至少有一只 2 板（润建股份）。说「电力方向没有接力」是**过度归纳**，
  正确表述是「发电运营商子桶内没有接力」。
- 「散户接盘」的三方交叉（股吧追捧 / 雪球无视 / 资金背离）是针对这 3 只涨停做的，
  样本没变，所以判定不变；但不能外推到「电力板块」，只能外推到「这三只」。
- 所有以行业名当板块名的措辞（「新型电力板块领涨」「板块内传播链」）都要改成
  「行业桶」或直接换成概念名。

## 四、处置建议

**不做二选一，做双轨。** 行业和概念是两套正交的分类，各有各的用处：

- 行业桶适合「产业链位置」（谁是上游设备、谁是运营商），但**不能当市场题材用**；
- 概念适合「市场在炒什么」，但 250 个题材互相重叠（一只票平均挂 4~5 个），
  不能当互斥分区用。

落地三件事：

1. ~~采集层~~（已完成）`tools/jev_concept_fetch.py`，输入 day、输出
   `quant_backtest/data/tushare/_jev_concept/<day>.json`，日期纯净性校验 + 幂等 + 原子写。
2. `portal/jev_graph.py`：`board_frame` 增加 `theme`（首个/最强题材）与 `themes`（全部），
   板块聚合并存一份按 theme 算的，页面加口径切换。改动是**追加字段**，不动默认 board，
   保证历史结论可复算、不静默换口径。
3. 判例 #28 写进 DEVELOPER_GUIDE：**名称不可直接映射**。行业名 ≠ 题材名，
   同名不同物（新型电力）、异物不同名（电力 ⊃ 新型电力），禁止字符串匹配把行业当题材。

### 一个差点做错的决策（留档）

题材口径最初按「主题材」做互斥分区（一票只归一个题材），结果概念「电力」**218 只被切成 52 只**，
润建股份（属电力、但主题材是算力）直接不在板块里——**这正是要修的漏人，等于白改**。

改成按**全量成分**聚合（一票可同时在多个题材），`row["board"]` 只作默认展示口径：

    行业口径  互斥分区，一票一个行业           → 直接按 row["board"] 分组
    题材口径  成分允许重叠（平均挂 3.16 个）   → 按 by_theme 全量成分聚合

代价是同一只票会出现在多个板块里，`pct_rank` 不能预写，改由 `rank_board` 按焦点板块现算。

### 另外三处必须同时立的口径

1. **属性标签不是题材**：开盘啦 250 个标签里混着「地方国资」（346 只）、「汇金证金持股」
   （86 只）、「破净整理」「高股息」——它们是选股筛选项，拿来当「该股属于什么题材」等于没说。
   主题材选举时排除（`jev_theme.GENERIC`），但 `themes_of()` 仍如实返回，供页面展示。
2. **无题材回落行业并标来源**：4342/5400 只有题材，其余回落 `industry` 且 `theme_src="industry"`，
   不静默当成「这只票没有题材」（那会造出一个 1058 只的巨型「未分类」板块霸榜）。
3. **节点上限 60**：题材口径焦点板块 218 只，全塞进 payload 是 5 倍冗余，而前端只画
   lead / same_wave / followers / unpriced。涨停票优先保留，其余按涨幅截断。

### 为什么根在 allow_reuse_address

ThreadingHTTPServer 继承 `allow_reuse_address=1`，Windows 上第二个实例 bind 同端口**会成功**——
启动代码里 `except OSError: 静默退场` 在本机永不触发。所以孤儿不是 bind 失败的残尸，
是**活着抢服务的完整实例**。守卫锁把判定前移：抢不到锁就退场，与 bind 行为解耦。
