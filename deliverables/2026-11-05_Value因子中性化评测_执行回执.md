## 1. 实现

### 1.1 中性化模块 `tools/research/factor_neutralize.py`

- `neutralize_matrix(panel, values, industry=True, size=True, min_obs=30, eligible=True)`：
  - 每个交易日横截面 OLS：`factor ~ 1 + log(total_mv) + industry_dummies`，取残差；
  - 行业来自 `panel.load_meta["industry"]`（`stock_basic.industry`），缺失归 `UNKNOWN`；哑变量 drop_first；
  - 市值用 `daily_basic.total_mv` 的自然对数；市值/行业缺失或不在股票池的样本剔除；
  - 每日有效样本 < `min_obs` 时该日输出 NaN；
  - 只使用 T 日截面信息，无未来数据。
- `build_neutralized_specs(panel, names, ...)`：先算原始因子，再逐因子中性化，生成临时 `FactorSpec`（family 加「-中性化」），复用同一套 `evaluate_panel` 评测。
- `parse_modes(text)`：解析 `industry,size` / `industry` / `size` / `none`，非法模式报错。

### 1.2 `tools/research/factor_lib.py` 接入

- `evaluate_panel(..., factor_specs=None, neutralization=None)`：支持临时因子定义（同名优先于 `FACTORS`），报告 `meta.neutralization` 记录中性化信息。
- `run_eval(..., neutralize="")`：`neutralize="industry,size"` 时构造中性化 specs 后调用同一评测链路。
- CLI：`python tools/research/factor_lib.py eval ... --neutralize industry,size`。
- 原有 17 个内置因子 + 288 个 Tushare 因子行为不变；中性化默认关闭。

### 1.3 测试

`tools/tests/test_factor_neutralize.py`：7 项，覆盖：

- 中性化后残差与 log(total_mv) 逐日相关系数 ≈ 0（<1e-8），行业组均值 ≈ 0；
- min_obs 不足输出 NaN；
- 行业缺失、仅行业/仅市值、`parse_modes` 非法值；
- `build_neutralized_specs` + `evaluate_panel` 集成；
- `run_eval(neutralize="industry,size")` 端到端（monkeypatch panel）。
