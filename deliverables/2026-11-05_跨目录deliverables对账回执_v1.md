## 二、数量差异原因

1. **目录定位不同（已裁决）**  
   `DOCS_INDEX.md` 第六节注记：根 `deliverables` 为**唯一索引根（主文档位）**；`老田的AI助手/deliverables` 为 **git 归档副本**（依据 `双写文档裁决建议_2026-10-22.md` §〇，2026-10-25 裁决）。仓库副本不是生产交付目录，不会与根目录全量同步。

2. **扫描深度不同**  
   根目录索引递归包含 82 个子目录；仓库索引只扫直接文件。根目录 3,264 个文件中 948 个在子目录。

3. **文件类型过滤不同**  
   根目录全局索引只收 `.md`（2,336 份）；仓库索引收全部直接文件，包括 json/png/zip/csv 等，共 846 份。仓库索引另有 539 份“命名待治理”（不符合 `YYYY-MM-DD_主题_vN` 严格规范），仍计入总数。

4. **内容重叠有限**  
   两目录直接文件名重叠 426 个；按相对路径递归比较 markdown，重叠 **399 篇**（与索引注记一致）。根目录独有 markdown 1,937 篇，仓库副本独有 431 篇。

5. **同步后计数已闭环**  
   仓库索引在 15:08 重新生成后为 **846 条 = 实际 846，delta 0**；根目录 `DOCS_INDEX.md` 同步重生成，§六为 **2,336 份**，与工作区递归 markdown 数 **2,336** 一致。两目录均包含本回执。

## 三、判定

- 仓库 `deliverables/INDEX.md`：**846 / 846，差 0**。
- 根目录权威索引 `C:\项目\DOCS_INDEX.md` §六：**2,336 份，全部可解析**；全局合计 **3,365 份**。
- 跨目录不应比较总数；对账指标应为“同名文档”：当前同名 markdown **399 篇**，直接文件名同名 **426 个**。
- 两目录索引的“总数相等”不是治理目标；各自“索引条数 = 实际扫描数”才是。
