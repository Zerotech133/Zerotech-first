## 1. P2 定义（冻结）

### 1.1 动量 sleeve 权重

P1 的动量族是 20 个因子等权。P2 只保留四个**精确回看周期**因子，按以下权重组成动量 sleeve：

| 周期 | 因子 | 权重 | 角色 |
|---:|---|---:|---|
| 5d | `b1_mom_5d` | **0.20** | 辅助 |
| 21d | `b1_mom_21d` | **0.60** | 核心 |
| 60d | `b1_mom_60d` | **0.15** | 成本约束 |
| 120d | `b1_mom_120d` | **0.05** | 成本约束 |

- 四个因子方向全部为 **−1（反转）**。
- 因子定义：`adj_close / adj_close.shift(H) − 1`；不做额外平滑。
- 权重和 = 1.0；权重冻结哈希（JSON sorted）见第 5 节。

### 1.2 复合结构

- 五个族：动量 sleeve、流动性、风险、反转、规模；
- **族间等权**（每族 1/5），与 P1 的族间等权一致；
- 动量族内部改为上述 4 因子加权，不再使用 P1 的 20 因子等权；
- 其他四族内部保持 P1 等权（剔除 unknown）；
- 方向：P2 的非动量因子沿用 P1 方向（P1 只改动量族，非动量方向与 P0 相同）；四个 `b1_mom_*` 为 −1。

### 1.3 为什么是这组权重

- 5/21/60/120 拆分结果（2026-11-06）：holdout 反转 IC：21d +0.0837 > 60d +0.0679 > 120d +0.0632 > 5d +0.0469；holdout 多空：21d +12.81% > 5d +8.43% > 60d +4.74% > 120d +0.68%。
- 21d 同时是 IC 与多空最强、逐年最稳定，故 0.60；
- 5d 多空尚可但 IC 最弱，降为 0.20 辅助；
- 60d/120d 的 IC 尚可但多空转化弱，合计仅 0.20，作为成本约束下的低权重。
- 该权重来自拆分研究，**在跑 P2 之前冻结**；不根据 P2 结果回调。

## 2. 评测设计

- 数据/面板：与 P1 OOS 一致，`load_panel` 2023-01 起；前向 20 日 CAR、30bp、`universe=tradable`。
- 时间切分（与 P1 相同）：
  - dev：2023-04-03–2024-12-31；
  - holdout：2025-01-02–2026-09-29；
  - 全样本仅描述。
- 组合：60d 调仓、quantile 0.2、buffer 0.30、turnover penalty 0.50、单边上限 0.30、30bp、行业+市值约束、PIT SW L2（snapshot-assisted fallback）。
- 辅助检查：holdout 40d/20d、原始（不中性化）60d、成本 0/30/50bp。
- 对照：
  - P1：`research/reports/b1_prior_p1_oos_20261105.json`（旧 P1）；
  - P0：`research/reports/b1_prior_p0_oos_20261105.json`（基线，仅作背景）。
- 预注册限制：P1/P2 都受同一研究者看过 2025–2026 数据影响，P2 的 holdout 仍是 quasi-OOS，不是干净预注册 OOS。

## 3. 预注册判定阈值（跑前写死）

以 **holdout 60d 中性化组合**为主：

### 3.1 主判定（必须全部满足）

1. **P2 holdout 60d Sharpe ≥ P1 holdout 60d Sharpe + 0.05**（P1=0.4238，故阈值 ≥ 0.4738）。
2. **P2 holdout 60d MDD 不比 P1 差超过 2pp**（P1=−10.02%，故 P2 ≥ −12.02%）。
3. **P2 holdout 中性化复合 IC ≥ P1 holdout IC − 0.005 且 > 0**（P1=0.1024，故阈值 ≥ 0.0974）。
4. **P2 holdout 60d 年化 ≥ P1 holdout 60d 年化**（P1=3.1034%）。

### 3.2 辅助判定（不单独否决，但写入结论）

- dev 60d Sharpe ≥ P1 dev Sharpe − 0.02（P1=0.248，故 ≥ 0.228）；
- holdout 40d/20d 不弱于 P1 同周期超过 0.05 Sharpe；
- P2 的相对 P1 改善不集中在单一年份（2025 与 2026 至少一年为正贡献，且另一年不出现 >2pp 年化恶化）；
- 成本 50bp 下 P2 仍为正。

### 3.3 判定语义

- **全部主判定通过** → P2 登记为“候选研究版本 P2”，与 P1 并列；P0 仍为基线，不覆盖 P0；不接生产。
- **任一主判定失败** → P2 不升级；P1 保持候选；P2 仅作为研究变体保留，报告写明失败项。
- 无论结果，**不生成实盘信号、不修改生产配置**。
