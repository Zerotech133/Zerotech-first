# 零界项目重规划 v1（UI 能力增强版）

- 日期：2026-10-30
- 范围：个人 OS / 量化 / 情报 / 创作 / 开发军团 / 数据底座 / AI 能力
- 依据：当前 95 个前端页、OS 定版视觉、UI Kit v0.1、诸葛亮 P0-P2 现状

## 1. 一句话战略

**把“零界”从一堆能跑的工具页，收束成“一个个人指挥部 + 五个领域驾驶舱 + 一个 AI 参谋长”。**

- 人类入口唯一：8734；
- 个人指挥部：`/os-entry`（四视图）+ `/os-board`（态势/证据）；
- 五个驾驶舱：量化、情报、创作、开发、系统；
- AI 参谋长：诸葛亮只做建议/质询/下钻，不自动派单。

## 2. 现状盘点

### 已有优势

- 端口/任务/健康/工单治理链完整；
- 95 页统一 OS 主题层；`/os-entry` 四视图 IA 已落地；
- 量化/情报/开发域有真实业务页与数据；
- 诸葛亮：建议面、决策账本、采纳回填、记忆、RAG、MCP、红队、评测底子。

### 主要问题

| 问题 | 影响 |
|---|---|
| 页面多、层级平、入口靠 nav 胶囊 | 找不到、重复导航 |
| 组件层缺失，样式复制 | 改一处要改多页 |
| 量化/情报页信息密度高、单屏缺折叠 | 首屏压力大 |
| UI 与 AI 能力各自演进 | 建议无法顺畅进入页面动作 |
| 采纳/推送/MCP 数据和接线仍弱 | 闭环未验真 |

## 3. 目标架构

```
┌ 统一入口 8734 ──────────────────────────────────────┐
│ PageShell（nav + page-head + footer + skip link）     │
│ UI Kit（button/badge/card/tabs/table/drawer/toast）  │
├ 个人指挥部 ─┬ 领域驾驶舱 ──────────────┬ AI 参谋长 ──┤
│ /os-entry   │ /quant  /intel  /creator │ 建议/质询   │
│ /os-board   │ /dev    /ops             │ 下钻/回看   │
└─────────────┴──────────────────────────┴─────────────┘
```

## 4. 四阶段路线（90 天）

### P0（已完成，2026-10-30）

- 端口门恢复、全站 OS 主题、下钻/返回、页面搜索/折叠、折叠偏好；
- `/os-entry` 四视图重排、P3/P4 折叠；
- UI Kit v0.1 与组件示例页。

### P1（未来 2 周）：组件化收口

1. 把 UI Kit 接入 4 个高频面：`/os-entry`、`/os-board`、`/quant`、`/intel`；
2. PageShell 生成器：head/nav/footer 统一生成，减少 95 页重复；
3. 组件级截图基线（1440/390）+ a11y 检查；
4. 验收：新增页面 0 手写导航、0 原始 hex、0 重复 footer。

### P2（3-4 周）：领域驾驶舱卡片化

1. 量化：KPI/策略/持仓/风险四区，表格可折叠、可下钻；
2. 情报：来源/证据/事件/图谱四区，证据抽屉统一；
3. 创作/开发：先做入口卡，不重写业务；
4. 验收：每域首屏 ≤3 个决策点，搜索/折叠可用。

### P3（5-8 周）：AI 闭环

1. 采纳：真实点击或明确 smoke，形成可读采纳率；
2. 晨报：08:55/17:55 两期推送稳定；
3. MCP：OpenClaw 真实工具调用进生产路径；
4. 记忆/RAG/评测：lesson/preference、自动重建、LLM judge、golden 50；
5. 验收：建议→采纳→结果有账可查。

### P4（9-12 周）：运维与安全

1. 端口/任务/健康/证书/密钥轮换纳入统一巡检；
2. 观测：trace/成本/延迟/失败率；
3. 安全：明文凭据清零、权限最小化；
4. 验收：健康卡零红或每项有明确处置人。

## 5. 优先级矩阵

| 优先级 | 事项 | 理由 |
|---|---|---|
| P0 | 组件接入高频面 | 一次投入，长期减少页面重复 |
| P0 | PageShell 生成器 | 95 页头尾统一的最低成本路径 |
| P1 | 量化/情报卡片化 | 用户最高频域 |
| P1 | 真实采纳/推送/MCP | AI 闭环的关键证据 |
| P2 | 创作/开发域重构 | 业务价值稍后 |
| P2 | 观测/安全 | 持续治理，非一次性 |

## 6. 风险与边界

- 不再一次性重写 95 页；只做“共享层 + 高频面”，其余按 wave 迁移。
- UI Kit 不引入 React/构建链，避免把简单页面复杂化。
- AI 建议仍只读；下钻/回看不等于派单。
- 端口门、质量闸、L2 审批继续执行，不因 UI 工作绕过。
- 旧页面保留回退；视觉基线可回滚到 git 历史。

## 7. 验收指标

- UI：组件复用率、原始 hex/内联样式新增=0、375/1440 无溢出、键盘可达；
- 页面：首屏决策点 ≤3、搜索/折叠可用、下钻/返回可用；
- AI：真实采纳记录、两期推送成功率、MCP 调用成功率、评测通过率；
- 运维：端口未登记=0、任务失败有归因、健康卡红项有 owner。
