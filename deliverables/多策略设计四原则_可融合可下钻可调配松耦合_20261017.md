## 原则四：松耦合（耦合度审计）

| 边界 | 耦合方式 | 审计结论 |
|---|---|---|
| 策略 ↔ 数据层 | 只经 Adapter 读原始数据，策略间互不可见 | ✅ 换策略数据层零改动 |
| 策略 ↔ 融合器 | 只经 Signal frozen dataclass 值传递 | ✅ 无对象引用、无回调 |
| 融合器 ↔ 前端 | 只经 REST API（/api/strategies、/api/signals、/api/feedback、/api/strategies/adjust） | ✅ 前端可独立替换 |
| 前端 ↔ 主仪表盘 | register_routes 零侵入包装（未命中回落原逻辑，幂等防叠加） | ✅ 主屏 1939 行未感知多策略 |
| 管理台 ↔ 后端 | 页面现读（改 HTML 免重启）+ 静态元数据下钻 | ✅ 无新增后端依赖 |
| 调整 ↔ 生效 | 全部经 strategy_registry.json 单一事实源，编排器同源消费 | ✅ 无内存态漂移 |
