## 二、审计修复明细（P53，WO-GUANYU-P53-20261030）

### Bug A：`test_no_external_sdk_imported` 假失败（测试缺陷）

- 现象：`AssertionError: 生成器不应加载对外推送 SDK: httpx`；
- 根因：断言检查当前进程 `sys.modules`，而同目录 `test_feishu_push.py` 在 **pytest 收集期** 就 import httpx → 与生成器无关的污染；
- 修复：改为**干净子进程**验证（`python -c` 内 import report_builder 后检查 SDK 是否被加载）；
- 验收：测试通过；且真实证明生成器零推送 SDK 依赖（比原断言更严格）。

### Bug B：`_welch_t` 零方差退化 → 假"强显著"（真 bug）

- 现象：常数样本（blocked 全 -0.02 / passed 全 -0.05）被判 `false_kill_topics_found`，t ≈ **8.05e15**；
- 根因：常数序列方差是浮点噪声（~1e-34），原实现只挡 `den <= 0`，`den` 极小但 >0 → t 被放大；
- 修复：`v1/v2 < 1e-20` 或 `den <= 1e-20` → 返回 None（无估计方差，不下结论）；
- 验收：复现脚本 status 由 `false_kill_topics_found` → `no_rule_level_false_kill_evidence`；`test_riskguard_topics.py` 50 passed / 2 skipped；`test_report_builder.py` 全绿。
