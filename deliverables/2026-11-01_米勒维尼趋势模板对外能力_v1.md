## 二、对外接口（v1）

### 2.1 静态快照（推荐）
- URL：`GET http://127.0.0.1:8734/static/trend_template_latest.json`
- 契约：`agent_platform/contracts/trend_template.v1.yaml`
- 关键字段：
  - `trade_date`：交易日（如 20261030）
  - `dataset.universe_base / universe_all`：基础宇宙/全市场
  - `results.pass_all / near_miss`：八条全过数 / 差一条数
  - `results.condition_pass_rate_pct`：各条件通过率
  - `candidates[]`：`code/name/close/rs_approx/s50/s150/s200/low_dist_pct/high_dist_pct`
  - `method`：复权/窗口/C3/RS 口径说明
  - `boundary_notes` / `disclaimer`：边界与免责
- 新鲜度：手动或任务运行（以 `trade_date` 为准）；失败时页面提示「数据未就绪」。

### 2.2 命令行
```powershell
# 1) 运行筛选（输出 research/reports/trend_template_<date>.{json,md}）
python tools/research/trend_template.py --date 20261030 --top 60
# 2) 导出对外 JSON（portal/static/trend_template_latest.json）
python tools/research/trend_template_export.py
```

## 三、口径与已知限制（必须随输出附带）
1. **书版基线**：C1–C8 严格不等式（均线 >，边界等号不通过；C6/C7 等号允许）；
2. **C3**：端点代理 `S200(t) > S200(t-21)`，非逐日单调；
3. **RS**：全 A 横截面近似（ret12m+ret3m 百分位 1–99），**非 IBD 专有 RS**；
4. **一年窗口**：250 交易日（书版 52 自然周 ≈ 252）；
5. **复权**：前复权 close/high/low（×adj_factor），不可与不复权极值混用；
6. **股票池**：当前为全 A（非ST/上市≥250日/价≥2），**未做指数成分/流动性过滤**——外部回测（MarketInOut 14 池）显示大盘成分内更有效、全交易所尤其小盘易失效；
7. **未实现**：VCP/买点、仓位、退出规则、成本/容量、四关验证。
