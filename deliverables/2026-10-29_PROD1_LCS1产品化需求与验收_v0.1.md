# PROD1 · LCS-1 产品化需求与验收标准 v0.1

> 责任：PROD1 产品经理｜2026-10-29｜状态：**需求/验收草案，数据未冻结，不构成上线承诺**
> 依据：LCS-1 评审记录（No-Go/补证）、STRAT1 Spec draft、BACK1 回测清单

## 一、产品假设（待验证）

把 LCS-1 的“图形先行 + 事件/资金佐证”研究能力，产品化为**可解释的研究信号/报告**，而非直接交易指令。当前 **No-Go/补证**，本文件只定义“若补证通过，需要什么产品验收”。

## 二、用户与场景

| 用户 | 场景 | 核心诉求 | 证据等级 |
|---|---|---|---|
| 内部投研/策略团队 | 研究信号复核、候选池筛选 | 可复现、可追溯、可对照基线 | 推断 |
| 机构投顾（合规允许范围内） | 研究内容/白标报告 | 可解释、有风险边界 | 未知 |
| 个人用户 | 学习/研究 | 不承诺收益、合规风险高 | 未知（不建议首发） |

## 三、产品形态（候选）

1. **研究日报/周报**：信号 + 图形/事件/资金证据 + 风险边界；
2. **研究 API**：返回信号、证据链、版本/数据指纹；
3. **白标研究服务**：给机构做策略研究与可视化，不下单。

> 首发建议：内部研究工具 → 白标报告；**不做**直接荐股/代客理财。

## 四、验收标准（可测）

| # | 验收项 | 判据 | 证据 |
|---|---|---|---|
| A1 | 数据冻结 | data_version/sample_in/sample_out/cost_model 四字段 + sha256 | `freeze_receipts/` |
| A2 | 可复现 | 同输入重跑输出一致（hash/排序） | 回测报告 + manifest |
| A3 | 证据链 | 每条信号可追溯图形/事件/资金/版本 | API/报告字段 |
| A4 | 基线对照 | 与基线策略对比有增量/不劣化结论 | A6 对比表 |
| A5 | 成本口径 | 佣金/印花税/滑点/冲击参数版本化 | `fee_schedule.py`/`fill_model.py` |
| A6 | 合规 | 不构成投资建议；有免责声明；外部发布经法务 | 合规审核记录 |
| A7 | 失败降级 | 数据/信号缺失时显示“未取得/不可用”，不编造 | 空态测试 |
| A8 | 回滚 | 版本可回滚；旧版本可复现 | 版本记录/回滚演练 |

## 五、依赖与阻塞

- **DATA1**：数据冻结回执（当前 0/1，阻塞 A1）；
- **BACK1**：回测执行与登记（当前 queued，阻塞 A2/A4）；
- **STRAT1**：策略 Spec 冻结（当前 draft，阻塞 A3 口径）；
- **ACAD1**：评审与 Go/No-Go（当前 No-Go/补证）；
- 合规/法务：外部发布前审核。

## 六、试点与退出条件（补证通过后）

- 试点范围：内部研究团队 + 1 家合规允许的机构（白标报告）；
- 试点指标：报告可用率、证据链完整率、用户反馈、无合规事故；
- 退出条件：数据/回测证据不达标、合规否决、用户无法理解证据链 → 停止；
- 不承诺收益；不做买卖指令。

## 七、风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 数据未冻结/不可复现 | 产品结论不可信 | A1/A2 硬门 |
| 过拟合/样本外不足 | 误判 | 样本外 + 成本压力测试 |
| 合规（投资建议） | 法律风险 | 只做研究内容/工具，法务审核 |
| 图形信号解释成本高 | 用户不理解 | 证据链可视化/分级 |
| 单人研究产能 | 交付不稳 | 模板化/自动化，先内部 |

## 八、下一步

1. DATA1 冻结 → BACK1 回测 → ACAD1 评审（当前阻塞）；
2. 补证通过后：内部试用 → 验收清单 A1–A8 → 试点决策；
3. 本文件不改变 LCS-1 No-Go/补证状态，不构成上线承诺。
