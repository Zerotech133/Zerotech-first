## 二、工具侧：先补了个能力缺口

S33 的 `org_enroll` 只能**新增席位**，对「已在 agents 名单但没档案」的 34 个席位**用不了**（会报 id 已占用）。
本轮新增 **`--backfill` 补档模式**：

| 差异点 | 说明 |
|---|---|
| 前置要求 | id **必须**在该部门 agents 名单里（否则提示走新入编） |
| 拒绝条件 | 该部门**已有**此 id 档案 → 拒绝（不改既有档案，避免覆盖他人成果） |
| 不做 | 中文名重名校验（席位既已存在，名字是既成事实，重名另单治理） |
| 写入 | **仅追加 `agent_profiles`，不动 `agents` 名单**（自检硬断言） |
| 复用 | 工单号 + 放行人必填、duty≥10 字、binding/grade 词表、备份、原子写、自检失败自动回滚 |

**顺带修了一个真实缺陷**：备份文件名原为秒级时间戳，**同秒连续补档会互相覆盖备份**——
备份是回滚唯一依据，被覆盖等于早期状态永久丢失。改为冲突时追加序号，并加了「同秒连补三席须产生三个独立备份、首个备份不得被污染」的承重用例。
