# WP-I 骨架：数据集统一登记 + 统一取数入口 · 回执

## 一、本次交付（方案 v2 · WP-I1/I3 骨架）
| 项 | 内容 |
|---|---|
| 统一登记模型 | `tools/datawarehouse/dataset_registry.py`：301+ 数据集统一为 dataset_id，字段 domain/label/kind/path/owner/registered/exposed/access |
| 统一取数入口（CLI） | `tools/datawarehouse/dataset_registry_cli.py`：`stats / list / search / get / sample / emit`，按 dataset_id 一码查询与取样（只读、白名单路径） |
| 登记草稿 | `agent_platform/catalogs/dataset_registry_v1.yaml`（status=draft_pending_DATA1_merge，待 DATA1 合并进 data_catalog v7） |
| 测试 | `tools/datawarehouse/tests/test_dataset_registry.py` 3/3 通过 |

## 二、覆盖与验证
- 全域数据集：**314**（接口 241 / 开源情报 19 / 学习派生 29 / 平台运行 25）；登记 265（84%），取数入口 72（23%）；
- YouTube 语料：`yt_learning.db` **13 张表**已按 `yt_learning_db.<table>` 独立登记，CLI 可直接取样；
- 实测：`dataset_registry_cli.py sample --id yt_dim_video` 返回 45,827 视频表的真实样本（列/行/内容）；
- `stats` 实测：314 数据集；`list/search` 支持按域/关键词/登记/入口过滤。

## 三、边界与后续
- 只读；路径白名单（平台数据根/知识库/PDF/automation_runs）；不写业务数据；
- **待 DATA1/DEV1**：①将 registry 草稿并入 data_catalog v7；②补 dataset 级 HTTP `/api/dw/*` 与 MCP `dw_query`（WP-I3 正式版）；③YouTube 语料层登记补齐（14 层中尚缺若干独立 entry）；④统一取数入口覆盖率从 23%→80%（Sprint3 目标）。
