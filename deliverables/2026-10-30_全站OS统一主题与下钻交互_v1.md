# 全站 OS 前端统一与下钻交互 v1

- 日期：2026-10-30
- 工单：`WO-LEGION-OS-UI-UNIFY-20261030`
- 范围：`portal/` 下 95 个用户可见 HTML（72 个顶层页 + m / picks_public / protos / czsc-eval / chanlun-learn-report）
- 依据：`docs/design/2026-10-27_OS定版视觉规范_v1.md`、`docs/design/2026-10-27_零界双版本UI规范_v1.md`、v4-v9 历史页面

## 1. 做了什么

### 1.1 共享主题层

新增 `portal/static/os_theme.css`：

- 深海军蓝底、青色高亮、琥珀预警，统一自 `tokens.css` 的 `--os-*`；
- 统一 h1/h2/h3/正文/元信息字号，卡片/面板圆角+渐变+阴影；
- 按钮统一 40px 触达、hover/禁用/主次态；输入、表格、空态、滚动条、焦点统一；
- 移动端 ≤920 / ≤590 断点；`prefers-reduced-motion` 降级。

### 1.2 全站“下钻 / 返回”交互层

新增 `portal/static/os_drill.js`：

- 自动给含链接的 `.card` 加「下钻详情」按钮；
- 点击打开只读 drawer：标题、正文、当前页/来源、打开原页；
- drawer 内「← 返回」关闭并归还焦点；Esc/遮罩关闭；
- 支持显式 `[data-os-drill]`、`[data-os-back]`；
- 只读，不发起写请求。

### 1.3 批量注入

新增 `tools/unify_os_ui.py`：

```powershell
python tools/unify_os_ui.py --check    # 检查覆盖
python tools/unify_os_ui.py --apply    # 注入全部目标页
python tools/unify_os_ui.py --revert --apply  # 回滚
```

- 幂等；已注入页面不会重复；
- 只在 `</head>` 前加 CSS、`</body>` 前加 defer JS；
- 不改页面业务结构。

## 2. 验证

- 目标页 95 / 注入后 missing=0 / 重复标记 0；
- Playwright 1440 截图：`/os-entry`、`/home.html`、`/os.html` 正常；
- 390px 移动端 `/os-entry` 无横向溢出；
- 7 个代表页（home/os/zero_proto/quant/intel/dev/ops）无横向溢出；
- drawer 实测：打开 true、标题“软件开发”、点「返回」关闭 false；
- 95 页冒烟：5 条历史页/接口页既有 JS 报错（os_entry_v4/v5、market_strategy、model_admin），非主题层引入。

## 3. 边界

- 本次是**统一视觉层 + 交互层**，不是逐页信息架构重写；后续可按 wave 做单页布局优化。
- 页面仍保留各自业务逻辑/路由/数据契约；新增层不写数据。
- 全站按深色 OS 主题统一；浅色驾驶舱 `zero_proto.html` 也被统一层覆盖，若需保留双版本浅色，可从注入清单排除该页。

## 4. 回滚

```powershell
python tools/unify_os_ui.py --revert --apply
```

或只删目标页中的 `OS-UI-UNIFY` 标记、`os_theme.css` link、`os_drill.js` script。
