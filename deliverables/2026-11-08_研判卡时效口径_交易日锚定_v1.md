# 研判卡时效口径：从「自然日」改为「交易日锚定」

**日期**：2026-11-08  
**触发**：老田令「按顺序执行批 Step 3」——堵住"周一/节后第一天的卡必被丢掉、用户又要等 100 秒"的坑  
**结论**：判据已改为按交易日锚定并上线（8091 pid 12004）；历史 33 张错标日期的卡已无损迁移；新增 8 条回归用例全绿。

---

## 一、问题：两处同源缺陷，一处决定"看不看得到卡"，一处决定"卡上写的是哪天"

### 缺陷 1（读取侧）：过期判据用自然日

`portal/api_jev_interpret.py::_sediment` 原逻辑：

```python
age = (dt.date.today() - dt.date.fromisoformat(str(td))).days
if age > 1:
    return None          # 判过期 → 回落在线现算（实测 100s+）
```

后果按周历排一遍就很清楚：

| 打开时刻 | 卡交易日 | age | 旧判据 | 用户体感 |
|---|---|---|---|---|
| 周五 18:40（盘后刚生成） | 周五 | 0 | 命中 | 秒开 |
| **周一 09:00** | 周五 | **3** | **MISS** | **等 100 秒** |
| 周二 09:00（周一任务跑过） | 周一 | 1 | 命中 | 秒开 |
| 节后第一天 | 节前最后交易日 | ≥3 | MISS | 等 100 秒 |

也就是说，"打开即有结论"这个承诺，**在每个周初、每个节后第一天恰好失效**——正是最需要它的时候。

本次实测坐实：周日晚 12 点查 300750，卡 `trade_date=2026-11-06`（周五），`age=2` → 直接 MISS。

### 缺陷 2（写入侧）：预生成默认日期写 `today`

`tools/intel_brief_pregen.py::main`：

```python
date = a.date or dt.date.today().strftime("%Y-%m-%d")
```

周末/盘中跑出来的卡，`trade_date` 被标成自然日。库里实测 33 张卡全部 `trade_date=2026-11-08`（周日），而它们的数据实为周五（`datamart.latest('daily') = 20261106`）。页面显示"11-08 盘后"，读起来像"周日也有行情"；更麻烦的是，任何按 `trade_date` 做的时效判断都会跟着错。

## 二、改法

### 读取侧：卡的寿命跟交易日走

```python
def _expect_trade_day():          # 最近一个「已收盘」A 股交易日
    import datamart as dm          # 延迟导入，日历复用 quant_backtest/trade_cal
    e = dm._expected_trade_day(dm._recent_trade_days())
    ...

def _card_fresh(td_s, expect):     # 纯函数，便于回归
    if expect:
        ok = td_s >= expect
        return ok, "卡交易日 %s %s 最近已收盘交易日 %s" % (td_s, "≥" if ok else "＜", expect)
    gap = _weekday_gap(td_s)       # 日历不可用 → 工作日近似
    return gap <= 1, "..."
```

- 判据：`卡交易日 ≥ 最近一个已收盘交易日` → 新鲜，直接展示；否则回落在线重算。
- 口径来源统一：`_expected_trade_day` 是 `datamart` 现成的 freshness 口径（`<17:30 视当日未收盘`），与 `facts` 读行情用的是同一批数据——不会出现"卡按 A 日历判新鲜、facts 按 B 数据算出来是旧的"。
- 日历读不到时退回工作日近似（阈值 1 个工作日）：宁可给用户看昨晚的卡，也不让人空等 100 秒。
- 进程内缓存：成功 30 分钟 / 失败 5 分钟（日历修好后自愈）。实测冷启 0.79s（含 datamart 导入）、热 0.0000s。
- 返回体新增 `sediment.expect_trade_date` 与 `sediment.anchor`（一句人话依据），排查时不用猜。

### 写入侧：默认日取最近已收盘交易日

```python
def _default_trade_date() -> str:
    """取不到日历才退回 today。"""
```

`--date` 仍可显式指定（补跑历史用），但默认不再写自然日。

### 数据侧：33 张错标卡无损迁移

只改 `trade_date`（`2026-11-08` → `2026-11-06`），`facts`/`conclusion`/`engine`/`built_at` 全部原样：

- 迁移前备份：`C:\Temp\intel_briefs_20261108_backup.json`（33 行，含 code/trade_date/tier/engine/built_at）
- 迁移后校验：`('2026-11-06','MANUAL',1)`、`('2026-11-06','T2',32)`，无 11-08 残留
- 附带收益：`pregen` 的 `datasig` 指纹按 `(code, trade_date)` 查，迁移后工作日跑预生成会**直接命中跳过**，不重复烧 token
