## 4. 结论

1. **3.15% / 0.708 不能复现**；保留 PIT 历史成员后，无论用 SW L2 名称（1.50%）还是 snapshot 标签体系（1.24%），都远低于 snapshot 静态版。
2. **前视/幸存偏差是主因**：S-M 约 1.91pp；从 L1 31 类升到 L2 131 类仅 +0.36pp，行业粒度不可能解释 1.65pp。
3. **不能严格断言“全部”来自前视**：M 只有 81 个标签，比 snapshot 110 类更粗，modal 映射有误差；修正这部分后估计 M 略升 +0.1–0.2pp，但仍无法接近 3.15%。更稳妥表述：**约 1.4–1.5pp 可归因静态标签前视/幸存偏差，≤0.3pp 可归因粒度/映射误差**。
4. **研究基线改用 PIT L2 both 1.50%/.320/-5.38%**；snapshot 3.15%/.708 不再作为策略结论；不接生产。
