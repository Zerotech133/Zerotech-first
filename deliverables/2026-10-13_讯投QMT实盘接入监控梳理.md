## 一、结论先行

1. **QMT 实盘链已在菜鸟平台跑通**，不是从零开始：44 个实盘账户、6,829 笔 QMT 回流委托、466 条 OPEN/CLOSE 资产双报、400 条盯盘信号、实盘日快照 186 天——五张表全有真实数据。
2. **个人 OS 侧目前是纯模拟**：paper.db 五个策略模拟账户（main/taishan/chaser/hawk_test= A股，us_qingping=美股），模拟资产矩阵已在指挥大屏呈现（K-STOCK-262 起，按 A股/美股/港股/虚拟币四板块，大宗预留）。
3. 接入路径 = **三阶段**：S1 只读并排（最快可落地）→ S2 账户级实盘监控 → S3 告警与风控联动。每阶段独立可回退。

## 二、菜鸟平台 QMT 现状（数据实锤）

| 表 | 量级 | 内容 | 对监控的价值 |
|---|---|---|---|
| stock_trade_member_real_account | 44 | 实盘账户主档 | 账户清单与绑定关系 |
| stock_trade_member_real_order | 6,829 | QMT 回流委托（entrust_no upsert、成交/撤单、手续费） | 执行质量、成交率、撤单率 |
| stock_trade_member_real_asset | 466 | OPEN/CLOSE 总资产双报 | 日内波动截面、日终净值 |
| stock_trade_member_real_position | 2,448 | 实盘持仓明细 | 持仓集中度、停牌/可卖 |
| stock_trade_member_real_account_daily | 186 | 实盘账户日快照（FIFO 已实现盈亏） | 累计收益、回撤 |
| stock_trade_strategy_signal | 400 | QMT 盯盘中文信号（冲高回落/跳水回调等） | 信号→指令时效 |
| stock_trade_member_simulation_trade | 10,648 | 模拟盘成交 | **模拟 vs 实盘两轨偏差** |

**既有链路**（⑤分发执行链）：策略指令 → 分发到绑定账户 → QMT 执行 → 委托回流 → 收盘上报资产/持仓 → 日快照。

**已知坑**（10-08 文档 §六）：单条 /create 无仓位转换、返回固定 0L、持仓周期默认不一致、bak 表（20260722/20260811 资金异动事故）须排除、拉取按 tenant_id 过滤。

## 三、个人 OS 侧接入缺口

CainiaoPull 每日 19:00 只拉六表（全是**会员层分发后**数据），源头层七表空白（strategy 主档 / strategy_instruction 2,167 / strategy_pool / signal / strategy_daily / stock_daily / strategy_trade）——**监控要的是源头层**，否则只有执行结果没有决策上下文。

## 四、三阶段规划

### S1 只读并排（1-2 天量级，零风险）
- CainiaoPull 六表 → 九表（+strategy / strategy_instruction / strategy_pool，wrapper 改 ENDPOINTS 三行，10-08 文档 P0 建议原样采纳）
- 指挥大屏「个人模拟资产」板块并列一排**实盘账户卡**（数据源 real_account_daily + real_asset CLOSE 口径），口径：账户数 / 总资产 / 当日盈亏 / 累计收益
- 模拟 vs 实盘同一策略两轨对照卡（simulation_trade × real_order 按 instruction 溯源）

### S2 账户级实盘监控（1 周量级）
- 新增 `/api/live_accounts`：聚合 real_asset（OPEN/CLOSE）、real_position、real_order 当日委托/成交/撤单
- 监控四指标：**资产曲线**（CLOSE 序列）、**执行质量**（委托→成交率、撤单率、手续费占比）、**信号时效**（signal.ts → instruction.ts → real_order.entrust_ts 延迟链）、**持仓风控**（单票集中度 >20% 亮牌、停牌持仓亮牌）
- 大屏实盘区与模拟区同构渲染（涨红跌绿同 tokens）

### S3 告警与风控联动（2 周量级）
- 实盘异常入告警收件箱：成交失败 / 资产 OPEN-CLOSE 偏差超阈值 / 信号后 N 分钟未执行 / 持仓集中度破线
- 与 RiskGuard 四规则（市场质量/流动性冲击/事件风险/仓位集中度）打通——实盘持仓喂风控引擎
- 菜鸟股确认（飞书 operator_open_id 确认链）状态回显到大屏

## 五、市场维度说明（与本次大屏板块对齐）
