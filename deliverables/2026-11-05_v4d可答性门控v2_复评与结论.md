# v4d 可答性门控 v2：同一批 20 题复评与结论

日期：2026-11-05
范围：`K-KB-MULTI-ANSWERABILITY-20261105`（研究/评测线，生产 multi 未变更）

## 1. 背景

20 题盲评已定论：multi 生产保持 Ollama，v4d 只用于 single。用户批准后，给 v4d 增加“可答性门控”，并用**同一批 20 题**复评。

- v1（材料充分性门控）：判定器看检索材料是否足以回答，结果过度拒答可答题（门控拒答 13/20），盲评大幅输给 Ollama。
- v2（领域范围门控）：只判**问题主题是否属于研报知识库领域**，不把检索材料交给判定器；属金融/产业/公司/策略/市场/宏观/交易 → 可答；体育/娱乐/医疗诊断/物理数学推导/签证旅行/生活常识 → 不可答。

## 2. 实现

`tools/kb_corpus/kb_qa_multi.py`：

- 常量：`ANSWERABILITY_PROMPT_VERSION="v2"`、`ANSWERABILITY_TIMEOUT_CAP=30.0`、`ANSWERABILITY_DECISIONS=("answerable","unanswerable","unknown")`。
- `build_answerability_prompt(question, clusters=None)`：只填问题；`del clusters` 忽略材料（保留签名兼容）。v2 prompt 明确“只做领域范围判断，不要求当前资料一定命中答案”。
- `parse_answerability(text)`：前缀「不可答」优先于「可答」子串；空 → `unknown`。
- `assess_answerability(...)`：无检索材料 → `unanswerable`；未提供判定模型/调用异常 → `unknown`（fail-open）；返回 `{enabled,decision,reason,error,model,raw,elapsed_seconds}`。
- `answer_multi(..., answerability_gate: bool=False)`：生成前先判定；`unanswerable` 直接返回 `REFUSAL_ANSWER`（`refusal=True`、`confidence=none`、`citations=[]`、附 `answerability` 元数据），不调用生成；`unknown/answerable` 继续原流程。
- CLI `ask` 新增 `--answerability-gate`。**默认关闭**；生产 `KB_QA_LLM_PROVIDER=ollama` 的 multi 行为不变。

测试：`tools/tests/test_multi_answerability.py` 12 项 + `tools/tests/test_multi_pair_eval.py` 6 项 → 18 passed；multi/retry/API 相关 65 passed。

## 4. 独立盲评

- 盲评包：`deliverables/2026-11-05_multi模型盲评_门控v2_20题_评测包.md`（A/B 随机、不标模型名）。
- 答案 key：`deliverables/2026-11-05_multi模型盲评_门控v2_20题_答案key.json`。
- 独立评审（只读包，不读 key/报告）：原始总分 **A=325 / B=339**，偏好 A 胜 3 / B 胜 7 / 平 10；4 道不可答题双方均正确拒答；5 道可答题双方同时误拒（A13/A18/A24/heldout_011/citation_sft_0178）。
- 按 key 揭盲：**Ollama 胜 9 / v4d 胜 1 / 平 10**。评审反馈：v4d 信息量有时更足，但常见拼凑来源、推断越界、答非所问；Ollama 更常逐条挂引用并说明材料缺口。

## 5. 结论

1. **门控 v2 是有效的安全改进**：不可答硬答从 2/4 降到 0/4，且比 v1 少误拒 6 题；实现默认关闭，对 Ollama 生产零影响。
2. **但门控不能弥补 v4d 在 multi 场景的质量差距**：可答题仍有 7/16 拒答、平均引用 0.65、guard 通过 3/20；盲评 Ollama 9:1 胜。
3. **维持生产定论：multi 用 Ollama，v4d 只用于 single**；门控作为 v4d 的可选安全开关保留（研究/未来 hybrid 用），不接入生产 multi。
4. 后续若要重启 hybrid：需先解决 v4d 可答题误拒与“单引用/引用不足”问题；本次门控已把“不可答硬答”风险消除，可作为 hybrid 的拒答侧组件。
