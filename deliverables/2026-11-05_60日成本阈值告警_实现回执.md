# 60 日主基线：成本阈值告警落地回执

- 日期：2026-11-05
- 任务来源：用户 m06916「按成本曲线给 60d 加一个成本阈值告警，实盘成本超过 100bp 时提示重评容量」
- 状态：完成（研究/监控代码；未改生产策略、未注册系统任务、未自动外发）

## 1. 告警规则

以覆盖修复口径的 60 日成本曲线为基准：

| 实盘单边成本 | 状态 | 动作 |
|---:|---|---|
| ≤ 100bp | ok | 不提示，正常观察 |
| 100–198bp | warning | **提示重评容量/换手/执行方式** |
| > 198bp | critical | 提示已超盈亏平衡、策略无经济性，建议暂停或重新设计 |

- 阈值：`COST_ALERT_THRESHOLD_BP=100.0`
- 盈亏平衡参考：`COST_BREAKEVEN_BP=198.0`（150bp +0.55% 与 200bp -0.03% 的线性插值）
- 60d 历史年化收益：用 0/10/30/50/100/150/200/250bp 曲线做线性插值；超出 0–250bp 时返回 `None` 并标注 `outside_tested_curve_0_250bp`。

## 2. 实现

### 2.1 核心判定 `tools/research/factor_portfolio.py`

- 新增常量 `COST_ALERT_THRESHOLD_BP`、`COST_BREAKEVEN_BP`、`COST_CURVE_60D`。
- 新增 `_interp_cost_return_60d(cost_bp)`：在已测曲线上线性插值 60d 年化。
- 新增 `assess_cost(cost_bp, threshold_bp=100, breakeven_bp=198) -> dict`：
  - 返回 `status`（ok/warning/critical）、`severity`、`headroom_bp`、`capacity_review_required`、`estimated_ann_return`、`message` 等；
  - `capacity_review_required` 仅在 **cost_bp > 100** 时为 True；
  - 只判定、不交易、不自动暂停策略；
  - 输入校验：负成本、阈值不低于盈亏平衡时报 `ValueError`。

### 2.2 CLI `tools/research/strategy_cost_guard.py`

- 输入优先级：`--cost-bp` > `--from-file` > 环境变量 `STRATEGY_COST_BP`。
- 文件输入支持 JSON（键 `cost_bp`/`live_cost_bp`/`estimated_cost_bp`/`all_in_cost_bp`）或纯数字。
- 输出：人类可读告警文本；`--json` 输出结构化 payload；默认写 `research/reports/strategy_cost_alert_<timestamp>.json`，`--no-write` 可关闭。
- 返回码：0=ok、2=warning、3=critical、4=输入/参数错误；`--no-fail` 时告警也返回 0（适合监控任务）。
- 飞书：默认 **dry-run**；显式 `--send` 且 status≠ok 时才调用 `news_collector/send_feishu.send_text`，失败只记录不抛异常。

### 2.3 监控包装 `tools/scheduled/strategy_cost_alert.ps1`

- 输入优先级：`-CostBp` > `-CostFile` > 默认读取 `research/reports/strategy_live_cost.json`。
- 无输入时记录 `SKIP` 并退出 0；有输入时调用 guard `--no-fail`，日志写 `C:\Temp\strategy_cost_alert.log`。
- 默认不发送飞书；`-Send` 显式开启。
- 兼容 Windows PowerShell 5.1（路径由 `$PSScriptRoot` 推导，避免中文路径字面量在 GBK 解析下乱码）。

## 3. 使用

```powershell
# 手动检查（120bp → warning，退出码 2）
python tools\research\strategy_cost_guard.py --cost-bp 120

# 结构化输出，不落盘
python tools\research\strategy_cost_guard.py --cost-bp 120 --json --no-write

# 从实盘成本文件读取；写入 research/reports/strategy_live_cost.json，如 {"live_cost_bp": 120}
python tools\research\strategy_cost_guard.py --from-file research\reports\strategy_live_cost.json

# 监控包装（默认 dry-run；-Send 才发飞书）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\scheduled\strategy_cost_alert.ps1 -CostBp 120

# 可选：注册为每日任务（本轮未执行，需另行审批/确认）

```

## 5. 边界

- 告警仅研究口径，**不构成投资建议、不下单、不自动暂停策略**。
- 实盘成本源尚未接入：默认读取 `research/reports/strategy_live_cost.json`，需由执行/交易侧写入；没有该文件时包装脚本只记 SKIP，不误报。
- 100bp 以上成本容忍度来自历史回测曲线；实际冲击成本、容量和流动性变化可能使盈亏平衡更早，critical 仅作粗边界。
- 未自动发送飞书，避免未经批准的外发；`-Send` 为显式 opt-in。
