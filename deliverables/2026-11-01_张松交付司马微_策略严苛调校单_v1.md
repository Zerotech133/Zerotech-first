8. **S01 仅过滤器无 alpha**：任何策略叠加 S01 后的净效应必须重测（S05 已证明截面冲突）；

## 三、司马微严苛调校协议（验收标准，必须逐项给出证据）

| # | 关卡 | 要求 | 不通过判据 |
|---|---|---|---|
| G1 | 多重检验 | 全部已测假设统一 BH-FDR（q≤0.10）或 Bonferroni，报告原始 p 与校正后 q | q>0.10 → 不得称显著 |
| G2 | Walk-forward | ≥3 folds，5 交易日 embargo，逐 fold OOS 汇总（不是单次切分） | fold 间符号翻转/中位数≤0 → 不稳定 |
| G3 | 成本敏感性 | 30/50/80bp + 冲击成本；报告净超额与换手 | 50bp 下净超额≤0 → 不可交易 |
| G4 | 安慰剂对照 | 同覆盖率随机信号 ≥1000 次置换；报告真实信号在分布中的分位 | 分位<90% → 只是暴露代理 |
| G5 | 容量/覆盖 | 日均成交额门槛、最大剔除/持仓容量、涨跌停不可执行性 | 容量<目标资金或覆盖>30% → 不可执行 |
| G6 | 分层稳健 | 市值×行业×波动层内同向；子样本 bootstrap CI | 任一分层反向且不显著 → 标注依赖 |
| G7 | 数据审计 | PIT/除权/停牌/ST/新股逐条核对；代码级 code review | 发现前视/幸存者偏差 → 全项重跑 |
| G8 | 决策 | 每策略输出 keep/close/needs-more，更新注册表 + 证据路径 | 无决策 = 未完成 |
