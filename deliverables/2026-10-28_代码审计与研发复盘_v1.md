## 二、审计发现与修复

### P0：IDE 全站打不开（已修复）

**现象**：IDE 显示 `bundle 加载失败：SyntaxError: Unexpected token '<'`，页面 body 仅 ~620 字符。

**根因**：并行安全加固 C1b 新增全局规则：

```nginx
location ~* \.(...|json)$ { return 404; }
```

该规则误伤 IDE 数据源 `/agent_ide_bundle.json`，bundle 返回 404 HTML。

**修复**：

- 在 `portal/nginx.conf` 增加精确白名单（`=` 优先级高于正则）：
  `location = /agent_ide_bundle.json { try_files $uri =404; ... }`
- `nginx -t` 通过，reload 容器；
- 验证：bundle 200 / `application/json` / 624073 bytes；IDE console 0、在编/指挥部正常显示。
- 工单：`K-QUANT-20261028-NGINXIDE`

### P1：security_gate 全量扫描崩溃（已修复）

**现象**：`security_gate.py scan` 遇到 Docker volume 中 `mysql.sock` 抛 `WinError 1920` 直接退出。

**修复**：

- `_iter` 对 `is_file/stat/relative_to` 全链路捕获 `OSError`，不可访问项跳过，不中断扫描；
- 回归测试：模拟不可访问文件仍能扫完。
- 工单：`K-QUANT-20261028-AUDITFIX1`

### P1：安全扫描噪声过大（已修复）

**现象**：全量扫描 786 high，绝大多数来自 `.venvs/site-packages/pylibs/vendor`。

**修复**：

- 排除 vendor 目录；high 从 **786 → 80**；
- 剩余 80 条中绝大多数是 Hermes/测试夹具；
- 非测试/非子工程生产项仅 3 条：
  1. `config/model_keys.local.json`（gitignored 本地明文 Key）
  2. `portal/audit_ai_config.json`（gitignored 本地明文 Key）
  3. `ollama_service/serve_wrapper.py`：`os.system()` 阻塞托管 Ollama（可接受，但仍建议 subprocess）
- 风险：两个本地明文 Key 文件虽然未入库，但仍在磁盘；建议迁移 DPAPI/轮换。

### P1：Worker 验收断言可被空字符串绕过（已修复）

`file_contains` / `file_not_contains` 的 `text` 为空时会误通过。

- 修复：空 needle 直接判 `check_failed:*_empty`；
