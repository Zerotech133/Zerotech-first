## 切默认建议与回滚

- 回滚方案：配置 `KB_QA_PROMPT_VERSION=v1` 或将 kb_qa_multi 默认 prompt 切回 v1、guard `marker_mode="legacy"`（或 strict_line）；静态配置改动无需重启 8091 时对 CLI 即时生效，HTTP 通道需按既有流程重启/灰度验证。

## 风险与说明

- 风险：扩样条数受 LLM 时间预算限制（本轮 30 条，可减到 25 条），仍小于全量 50 条；切换默认后需继续监控。
- 风险：v1 与 v4 为串行/并行分批采样，模型负载与耗时受同时段其他任务影响。
- 风险：segment 解析依赖模型输出段标题；若模型不写标题会退化为行首标记统计。
- 风险：切默认为行为变更：需在 kb_qa_multi 增加 prompt 版本开关 + guard marker_mode 配置，默认 v4/segment，保留 v1 回退开关。

- 扩样 A/B 结果仅供研究参考，不构成投资建议；答案需人工复核。
- 说明：v1/v4 两臂分别采集后合并；均为真实 LLM 调用（可并行跑）
