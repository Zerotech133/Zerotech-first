## prompt v3 改动点

- 先事实摘录段（每条带引用）
- 再推断段（≤2 条且引用线索）
- 事实段优先/推断占比≤40%
- ≥2 个不同单元
- 1 个 few-shot 结构示例
- 不确定拒答

## few-shot 示例

```
【示例（few-shot，结构示范）】
材料：[unit_A] p.2 「M9 级覆铜板支持 224Gbps 与 78 层 PCB 量产。」；[unit_B] p.5 「单颗 GPU 配套 PCB 价值量约为传统方案三倍。」
回答：
【事实】M9 级覆铜板支持 224Gbps 与 78 层 PCB 量产（[unit_A] p.2）。
【事实】单颗 GPU 配套 PCB 价值量约为传统方案三倍（[unit_B] p.5）。
【推断】综合两条材料，高速材料升级将带动单机柜 PCB 价值量提升（依据：[unit_A] p.2、[unit_B] p.5）。
```
