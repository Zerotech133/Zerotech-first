## 一、口径

按规格简化定义：

```
左右两柱：
  close>open
  1.0 <= vol/prev_vol < 1.9
  间隔 3~5 个交易日
  两柱实体底（min(open,close)）相差 <= 1%（精准线近似）

右阳确认：
  R+1、R+2、R+3 收盘均不破右阳实体底

信号：
  T >= R+3
  且 T 日 close > 右阳实体顶（max(open,close)）
  → T 日收盘确认

执行：
  T+1 收盘入场，T+21 收盘卖出，20 日持有，30bp 成本
```

## 二、PIT 检查（重要）

第一版向量化实现里，把 `R` 日条件移动到 `T=R+k` 时误用了 `shift(-k)`，会把未来条件带到当前行，导致出现 **IC +0.139、t 60+** 的虚假强结果。

已修正为 `shift(k)`，并重新跑：

- 信号只在 `T>=R+3` 出现；
- T 日只使用 T 及以前已知数据；
- 修正后结果从“异常正”变为稳定负。

这不是“调参”，是修前视 bug。

## 五、结论

**LX14_RELAY_DOUBLE_YANG = rejected。**

原因：

1. 三个 OOS 切分全部显著为负；
2. 成本后没有正超额；
3. 日均 326 个信号，事件过宽，容量/冲击未评估；
4. 简化口径无法表达原书的“阶段性底部、小 W 双底、左阳阳盖阴/长阳矮柱”等条件；但这些缺失不影响“当前可计算口径为负”的结论。
