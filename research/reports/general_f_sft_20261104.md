## 样例（前 3 条）

### 写作

- user：我下周要在班级家长会上做一次五分钟发言，主题是“家校配合”。能不能先讲讲演讲稿的基本结构应该怎么安排？
- assistant：可以按“开场—主体—结尾”来安排。开场用问候、自我介绍和一句点题的话，迅速说明你要讲什么；主体选两到三个重点，每个重点用“观点+例子+建议”展开，比如先肯定家长配合的重要性，再举具体做法；结尾用一句话总结并发出行动号召。五分钟发言不宜贪多，重点控制在两个左右，每部分之间用过渡句连接，让听众跟得上。

### 编程

- user：我想用 Python 调用一个公开的天气 API 获取当前温度，能按步骤说明怎么写吗？
- assistant：可以。步骤：1）读 API 文档，确认请求地址、参数和认证方式；2）用 requests 发 GET 请求并传 params；3）检查 status_code，非 200 时打印错误；4）用 response.json() 解析，按文档字段取温度；5）把密钥放环境变量，不要硬编码；6）加超时和异常处理。示例：requests.get(url, params={'city':'北京'}, timeout=5)。

### 健康

- user：每天坐办公室很久，想做几个久坐拉伸动作，为什么这些动作能缓解不适？
- assistant：久坐会让髋屈肌、胸肩肌群变紧，臀肌和核心变弱，颈肩腰背代偿紧张。拉伸能降低肌肉张力、改善局部循环、恢复关节活动度。可做颈侧屈、胸肩开合、坐姿转体、髋屈肌拉伸、腘绳肌拉伸，每个动作20—30秒，做2—3轮，缓慢呼吸、不弹震。每坐45—60分钟起身活动1—2分钟，效果更好。
