## 一、方法（严苛复验七件套）

1. **行业中性 M0** = 个股 20 日收益 − 所属行业等权 20 日收益（对行业等权回归取残差）；
2. **规模/波动/换手控制 M1**：逐日横截面 OLS `fwd ~ 1 + ln(流通市值) + vol20 + turnover` 残差；
3. **板块 beta 控制 M2**：M1 的回归再加「行业等权未来 20 日收益」→ 剔除板块 beta（**严格主指标**）；
4. **walk-forward**：2023-2024 观察 / 2025-2026 验证；
5. **安慰剂**：同日同覆盖率随机选股 1000 次，报真实信号分位（≥90% 才算非暴露代理）；
6. **多重检验**：19×3=57 个假设 BH-FDR q≤0.1；
7. **裁决**：真 alpha / 板块 beta / 无增量。

## 四、结论（C 模式：真 alpha 还是板块 beta？）

**裁决：真 alpha = 0 个；板块 beta = 8 个（LX02/LX03/LX05/LX09/LX10/LX12/LX13/LX17）；无增量 = 11 个。**

- C 模式在**事件等权口径**下确实让 15/19 个战法的 20 日板块相对超额相对无 RS 基线改善（ΔM0>0），但：
  1. 57 个假设 BH-FDR 后 C 模式仅 2 个显著（其中一个为负向），**没有任何战法满足**
     「q≤0.10 + M2>0/t≥2 + 安慰剂分位≥90% + 2023-24/2025-26 双窗同正」；
  2. C 模式样本高度集中在「板块普涨日」——这些日子的**日频聚合 t 普遍为负**，
     说明在板块上涨日追已涨个股、20 日后反而跑输板块；改善集中在触发股极少的交易日，不可交易；
  3. 控制规模/波动/换手/板块未来收益（M2）后残差大幅缩水甚至转负，
     板块 beta（行业上涨暴露）+ 样本重叠是「改善」的主要来源；
  4. 8 个「板块 beta」战法仅表示其 C 模式事件均值相对基线有改善但被板块 beta 解释，
     **均不构成可交易 alpha**。
- 结论：**C 模式不是真 alpha，是板块 beta（板块上涨暴露）+ 样本重叠造成的假改善**；
  A/B 模式同理（FDR 显著项以负向为主）。量学选股不应叠加 RS 作为入场条件。

C 模式本质是「板块上涨日 + 个股同步上涨」的事后筛选，板块 beta 是主要来源；严格残差（M2）+ 安慰剂 + walk-forward 后才可称 alpha。

逐战法证据见上表与 JSON；只有同时满足「FDR q≤0.10 + M2>0/t≥2 + 安慰剂分位≥90% + 两个 walk-forward 窗同为正」才判为真 alpha，否则归为板块 beta/无增量。

## 五、局限

- 板块代理 = stock_basic 行业等权（非官方指数，成分/权重有差异）；
- 安慰剂为同日分层无放回抽样矩的 1000 次正态抽样（非逐股枚举置换），分位为近似值；
- M2 用未来行业收益作回归项属于**归因**（解释收益来源），不是可交易信号；剔除板块 beta 后残差均值不再保证可实盘获得；
- 20 日重叠窗口的日频 t 已缓解但未完全消除序列相关，结论仍以 FDR+安慰剂+WF 三关合并判断；
- 不构成投资建议。
