## PR-20261104-01：LX05 v2 评分预注册

度量定义（全部相对 v3 锚点）：

- 回踩量比 `pb_vr`：`mean(vol[事件日-3 .. 事件日-1]) / vol[base_date]`。
- 金柱成色：`base vr5`、`base body%`。
- 线龄：`base_date → asof_date` 交易日数。
- 精准触点：金线生成后（`base_date+3` 起）至事件日，`|low/line-1| <= 0.5%` 的次数。
- 起柱位置：基柱前 20 日涨幅、基柱距 60 日高点回撤。
- 上影：`(high - max(o,c)) / c`。

评分项与权重（v2 主线）：

| 项 | 权重 | 方向 |
|---|---:|---|
| 金柱实体 | .20 | 大优 |
| 金柱量能 | .15 | vr5 高优 |
| 回踩量比 | .20 | 缩量优 |
| 线龄 | .10 | 新鲜优 |
| 起柱位置 | .15 | 低位优 |
| 精准触点 | .15 | >=2 次优 |
| 上影 | .05 | 短优 |

先验声明：

- v1 错误度量显示“起涨根放量”与 20 日超额正相关（放量 +3.16% vs 缩量 -1.29%），且精准触点区分力弱（Δ+0.12%）。
- 该证据使用错误度量，不得据此改 v2 方向；v2 主线按量学先验注册：回踩缩量优。
- `H_alt`（同批计算、只报告不改标签）：回踩放量优。若 v3 上 `H_alt` 与主线结论再次背离且方向一致，触发 PR-20261104-04，在 v3 结果上二选一定稿。

否决项（硬）：

```
事件日收盘破线（close < line*0.99）→ negative
金线无阳线基柱支撑（factor_lib 1.0.1 口径）→ negative
```

分档：

```
S >= 60 positive
S < 56 negative
56 <= S < 60 unsure
```
