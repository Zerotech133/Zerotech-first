# ADR-0001：独立系统与模块化单体架构

- 状态：已接受
- 日期：2026-08-18

## 背景

原 zhice 系统已经跑通多市场交易闭环，但存在领域层空壳、CN 专属逻辑、执行层未抽象、实时性靠轮询等问题。

用户要求新建完全独立的 `zhice-os-v2`，可以复制原系统资产，但不能调用原系统。

## 决策

1. `zhice-os-v2` 是独立代码库、独立 Git 仓库、独立运行环境。
2. 采用模块化单体架构，不引入微服务。
3. 核心业务逻辑放在 `domain/`，不依赖 FastAPI/SQLAlchemy。
4. 引入 Palantir 式 Ontology / Action / Provenance / Governance。
5. 所有市场差异通过 `MarketContext` 注入。
6. 所有策略统一为 `StrategySpec + StrategyExecutor`。
7. 所有执行统一通过 `BrokerPort`，模拟/实盘可插拔。
8. 所有关键交易动作经过统一授权中心。

## 后果

- 优点：边界清晰、可测试、可扩展、可独立演进。
- 代价：初期需要重建基础设施，不能直接复用原系统内部模块。
- 缓解：允许从原系统复制数据、代码、经验，但保持 V2 独立。
