# ADR-009：端口注册表为唯一真源，一切绑 127.0.0.1

- **状态**：Accepted（历史回填，2026-10-27；K-STOCK-113/115 等立宪）
- **关联**：P4/P6；`tools/check_ports.py` REGISTRY（52 口）；`AGENTS.md` §1

## 背景

多服务并行，历史上出现抢占端口、私起服务、双入口表述（8080/8734）混乱。

## 决定

1. `tools/check_ports.py` 的 `REGISTRY` 是端口唯一权威（当前 52 口在册）；
2. 起服务前查 REGISTRY/`devtask.py port` 申请，分配到后同一提交写回 REGISTRY；
3. 一律绑 `127.0.0.1`，对外只走 nginx 反代；
4. 人类入口唯一 = **8734**；8080 仅为容器/局域网链路，文档/页脚不得再写双口。

## 后果

- 正面：无端口冲突；合并门 `--strict` 可拦未登记服务。
- 代价：新服务多一步登记；离线服务需在 REGISTRY 保留（提示不判负）。
- 不做：不做动态端口分配/服务网格。
