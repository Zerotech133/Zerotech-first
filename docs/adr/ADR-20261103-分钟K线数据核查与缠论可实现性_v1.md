# ADR-20261103 · 分钟K线数据核查与缠论战法可实现性修正

- 状态：已接受（2026-11-03）
- 决策人：DSH Lead（核查执行）｜影响：W2/W3、能力图谱、缠论战法线
- 依据：W3-2 数据可用性核查（`research/reports/dataset_inventory_20261102.json` + 实际文件抽样）

## 背景
学习能力图谱 v1 曾把「分钟K线」列为**数据缺失（需补齐）**，据此把缠论结构战法（笔/线段/中枢/背驰/买卖点）标为 B 类（需补齐数据），并把 8 个因子中的「缠论笔/中枢/背驰」标为不可实现。

## 核查发现（实证）
| 项 | 实测 |
|---|---|
| 数据集 | `quant_backtest/data/tushare/stk_mins` |
| 文件 | **33,998 个 parquet**（按 代码_月份 分片） |
| 覆盖 | **5,038 个代码**，月份 **202509–202611（15 个月）**，202611 已有 800 文件 |
| 频率/字段 | **1 分钟**K线；`ts_code, trade_time, close, open, high, low, vol, amount` |
| 其他分钟数据 | idx_mins（2,030 文件）、sw_mins（2,201）、etf_mins（780）、tdx 板块分钟 |

## 决策
1. **分钟K线并非缺失**：数据仓已具备 1 分钟股票K线，缠论结构的**数据前置条件已满足**；
2. 能力图谱修正：分钟K线→「已入库」；缠论战法可计算性 **B→A**（数据就绪，待实现）；
3. 因子清单修正：「缠论笔/中枢/背驰」→「数据已具备，待实现（W2+）」；
4. 仍缺失的是 **盘口/Level2**（无 tick/委托队列），短线盘口类不可行结论不变；
5. 不采购分钟数据；后续若需要更长历史/更多频率，再评估 Tushare 积分或本地通达信导出。

## 后果与风险
- 正面：缠论战法线可从「等待数据」转为「实现 + 四关」；W2-6 可直接排期；
- 风险：①stk_mins 历史仅 15 个月（202509 起），回测样本有限；②按代码×月分片，需增量更新任务与完整性检查；③PIT：分钟级因子需按交易日 15:00 后入库口径，避免盘中未来数据；④Level2 缺失仍是硬缺口。
- 验证证据：本 ADR 附核查脚本 `C:\项目\work\research2\_check_minute_data.py` 输出（文件/代码/月份/频率/字段）。
