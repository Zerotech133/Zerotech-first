# ADR-013：单机个人 OS 的范围边界与文档纪律

- **状态**：Accepted（2026-10-27）
- **关联**：P1/P9；`docs/standards/2026-10-27_版本与发布流程_v1.md`；`CHANGELOG.md`

## 背景

开源同类项目（Home Assistant/Dify/Open WebUI）有插件市场/多租户/多语言/大规模 CI；若照搬会超出个人维护能力，拖慢主线。

## 决定

1. **范围**：单机 Windows、个人 OS/单用户；**不做**多租户、RBAC 大改、插件市场、K8s、多语言 i18n；
2. **Docker 仅作辅助**（已有）；不强制容器化全部服务；
3. **文档纪律**：架构变更写 ADR；行为变更写回执 + `CHANGELOG.md`；文档与代码同批提交；`DOCS_INDEX --check` rc=0；
4. 扩展先目录/manifest（O3），规模到了再拆仓；
5. 质量门槛取"可自动检查的 15-20 条"而非全量规则（O2）。

## 后果

- 正面：避免过度工程，主线（投研/军团/门户）优先。
- 代价：与开源项目的"完备度"有差距（接受）。
- 不做：不为对标而堆功能/堆文档。
