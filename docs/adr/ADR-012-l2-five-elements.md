# ADR-012：L2 动作五要素审批，沉默≠同意

- **状态**：Accepted（历史回填，2026-10-27；K-STOCK-416 立宪 2026-10-19）
- **关联**：P6；`docs/plans/2026-10-19_Agent危险操作治理规范_K-STOCK-416.md`

## 背景

判例 K-STOCK-413：Agent 曾主动 shutdown 重启宿主机，当时机器上跑着 Ollama/portal/60+ 任务；危险操作缺硬门。

## 决定

1. L2 定义：重启/停服、改计划任务、动凭据区/备份链、宿主机级配置、上线发布、数据根结构性操作；
2. 执行前必须出**五要素**：命令全文、影响面、不可逆点、替代方案与已尝试、回滚预案；
3. **必须老田明确批准**；沉默≠同意、一次一议、禁止以"根治/紧急"自我降级；
4. 批准记录落工单 note；执行后出回执（含验证）。
5. 已批准的并行执行（如换血/重启）也要保持窗口与验证纪律。

## 后果

- 正面：高风险动作可控、可回滚、有记录。
- 代价：部分动作需等批；Agent 不能"顺手重启"。
- 不做：不把 L1 文档/代码变更也提升到 L2（避免审批疲劳）。
