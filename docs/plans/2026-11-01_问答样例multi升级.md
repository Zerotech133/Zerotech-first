# 问答样例 multi 升级（门户静态样本 v2，2026-11-01）

> 任务单：task-64（wave21 CE 门户问答样例升级 multi+guard）。
> 上游：wave15 v3 问题库（`research/reports/kb_qa_bank_v3_20261101.json`）、wave20 CLI multi+guard 出口（`kb_qa.ask(mode="multi", guard=True)`）、wave19 质量守卫（`kb_qa_guard.py`）。
> 本文档记录：样例重生成流程、schema v2 字段、页面适配、状态统计与验证。

## 1. 背景与目标

门户问答样例此前是 single 模式旧答案（17 条，schema v1-ish），而 CLI 已默认 multi+guard。
本任务把门户样本刷新为 **multi + guard** 答案（12 条），并在页面显示 multi / 守卫 / fallback / 引用质量标记。

## 2. 重生成流程

```
1) 备份原门户样本（仅首次，不覆盖）：portal/static/kb_qa_samples.json
      → research/reports/kb_qa_samples_backup3_20261101.json（48582B）
2) 取 v3 问题库前 12 条（7 主题覆盖），逐条串行调用：
   kb_qa.ask(question, topk=8, model=qwen3.5:9b, timeout=300,
             mode="multi", guard=True, on_guard_fail="fallback")
3) 写入：
   - portal/static/kb_qa_samples.json（schema v2，供 /kb_reports.html 静态区块消费）
   - research/reports/kb_qa_samples_multi_20261101.json（逐条+统计+备份信息）
   - research/reports/kb_qa_samples_multi_20261101.md（状态统计表）
```

- 总耗时：**120.9s**（12 次串行 LLM 调用，约 10s/条；未触发 600s 整体 deadline，无跳过）；
- guard 为后处理（零额外 LLM 调用）。

## 4. 门户样本 schema v2

顶层新增/变更：

| 字段 | 说明 |
|---|---|
| `schema_version` | **2** |
| `mode` | `"multi"`（样本默认模式） |
| `guard` | `{enabled:true, on_fail:"fallback", rules:[引用可解析硬门, 推断比例≤0.6, 被引单元≥2]}` |
| `stats` | total/success/no_evidence/fallback/guard_passed/guard_failed/avg_citations/avg_inference_ratio/elapsed_seconds/by_theme |
| `source` | v3 问题库路径（选样说明） |

每条 sample 新增字段：`mode`、`status`（success/no_evidence/fallback）、`guard_enabled`、`guard_passed`、`guard_action`、`guard_issues`、`citation_valid`、`citation_invalid`、`citation_resolvable_rate`、`inference_ratio`、`inference_heavy`、`distinct_cited_units`、`direct_fact_markers`、`inference_markers`、`clusters`、`elapsed_seconds`、`error`；保留 question/answer/citations/confidence/fallback/refusal/category/theme/source_unit_id。
