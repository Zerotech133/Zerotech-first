## 二、核心问题直答：调动页面与调度动线清不清晰？

**动线本身是清晰的（设计层面）**，但**透明度不达标（可视层面）**：

```
设计动线（✅清晰，三处入口都有章程）：
  任务入口：router.py 路由 → 8093 工单 → 席位执行 → 账本归因
  定时入口：计划任务 105 个 → 各产线 → 飞书汇报
  情报入口：OSINT/新闻 → KG → 五虎 → LCS-1 报告

可视现状（❌三断点，刚才实测确认）：
  ① 8080 门户 ide.html：有工单/岗卡区，但数据是 10-15 的静态快照
  ② 8787 Hermes：有军团连接器，但只覆盖旧 29 员、无 presence
  ③ observe 账本：legion_debate/router/xsec 全都不写账——
     今天 42 员建制的建军日，在账本上是空白的一天
```

**一句话：军团能打仗，但指挥部没有实时地图。**

## 三、开发方案：军团作战大屏（W2 立项，代号 LEGION-OPS）

### 目标：一个页面看清「谁在干活、干什么、干得怎么样」

```
┌─────────────────────────────────────────────────────┐
│ 军团作战大屏（8080/legion.html，30s 自动刷新）         │
├──────────────┬──────────────────────────────────────┤
│ 左：编制墙    │ 右：实时活动流 + 工单看板              │
│ 42 员卡片网格 │ · 活动流：谁·何时·干了什么（账本驱动）  │
│ 状态灯：      │ · 工单：doing/review 泳道              │
│ 🟢在岗(1h内有 │ · 今日军团简报（田小皮判读）            │
│   账本活动)   │ · LCS-1 最新报告入口                   │
│ 🟡待命(24h)   │                                       │
│ 🔴失联(运行体 │                                       │
│   探针失败)   │                                       │
│ 💤影子期成员  │                                       │
└──────────────┴──────────────────────────────────────┘
```

### 数据源（全部现成，零新建）

| 区块 | 数据源 | 刷新 |
|---|---|---|
| 状态灯 | observe 账本 + tasks.json + 运行体探针 | 30s |
| 活动流 | observe 账本尾 50 条 | 30s |
| 工单泳道 | tasks.json（doing/review） | 30s |
| 军团简报 | 田小皮判读缓存 | 5min |
