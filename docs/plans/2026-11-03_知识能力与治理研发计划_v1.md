## 二、目标与非目标
### 目标（本期）
1. **治理修复**：元数据行过滤、重复单元 cohort 合并、多源交叉验证、冲突仲裁流程落地；
2. **能力产品化**：能力图谱可视化/接口稳定、军团通知与调用约定；
3. **因子工程**：8 个日线级细化因子实现 + 因子日报可视化 + IC/分层初筛；
4. **数据仓补齐**：分钟K线接入排期（缠论）、数据质量遗留项修复；
5. **策略研究入口**：把「治理后结论 + 因子」作为假设输入给司马微团队（过四关才进策略池）。

### 非目标
- 不新增「自动交易/实盘上线」；策略线仍以四关+影子盘为门；
- 不做 LLM 微调（RAG+Prompt 足够）；
- 不在本期做盘口/Level2 短线战法（数据缺口，明确放弃）。

## 六、风险与应对
| 风险 | 应对 |
|---|---|
| 元数据过滤影响既有单元/卡 | 备份+dry-run+仅新流程生效；历史数据只标记不删除 |
| 多源验证样本不足（各博主内容独立） | 跨书/研报/新闻多源；无多源标「单源-低置信」，不夸大结论 |
| 因子过拟合 | 四关+样本外+成本；不达标不进策略池 |
| 分钟数据成本/许可 | W3 先评估；未批准不采购 |
| 并发会话写冲突 | 显式 pathspec 提交；共享文件单一 owner；WIP ≤2 |
| 任务队列/电池策略类故障 | 已修；纳入健康监控 |
