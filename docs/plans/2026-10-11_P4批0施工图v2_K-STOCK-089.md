## 二、⚠️ 头号施工陷阱：`import *` 不导出下划线名

三份预演沙盘用的是 `from api_common import *`——它**只保语法（py_compile 不解析名字）**，而批 0 清单几乎全是 `_xxx` 下划线名，`import *` **不会带入**，正式施工若照抄会在运行时 NameError。

**铁律：批 0 装配必须显式导入**：
```python
from api_common import (_read_json, _env_market_key, pill_nav, _tabs_html,
    _back_link_html, log_exc, _portal_token, _load_cainiao_env, _log_rotate,
    data_freshness_bg, data_sync_start, DATA_SYNC_CMDS,
    _FRESH_BG_LOCK, _FRESH_BG_ERROR, _DATA_LOCK, DATA_SYNC_JOBS,
    ROOT, REPORTS_DIR, QBT_DIR, STATION)
```
（以施工时实点清单为准；Mixin 侧同理显式导入。）
