## 1. 判定口径（与 `portal/api_d1_handoff.py` API 口径对齐）

| 对象 | 判定 |
|---|---|
| **watch_engine status.json** | 路径：`--status` > env `WATCH_ENGINE_STATUS_PATH` > 建议只读默认 `agent_platform/data/watch_engine/status.json`（缺失 → error，不伪造） |
| 心跳 | `last_tick_at` / `heartbeat_at` / `last_heartbeat_at` / `updated_at` / `generated_at` / `started_at` 首个可解析者（ISO8601；无时区按本地） |
| **stale** | `age_s = now - heartbeat > stale_after_s`（默认 **180s**，同 API `ENGINE_STALE_AFTER_S`）；边界 `==180` 不算 stale |
| **error（fail-visible）** | `engine_state=error`；status 缺失/超 256KB/坏 JSON/顶层非 object/无心跳/心跳在未来 >60s（时钟异常）/`paper_only=false`/`executes=true` |
| **8789** | `GET http://127.0.0.1:8789/watch-admin`，期望 200；非 200/网络错 → error（记录 status/延迟） |
| **8091** | `GET http://127.0.0.1:8091/api/d1/watch-plans`，期望 200；同上 |
| **W4 expire_due** | `--expire-due` + 显式 `--plan-ledger`（或 env `D1_WATCH_PLAN_LEDGER`）才调用 `watch_plan_consumer.expire_due()`；无显式路径 → **退出码 2 拒绝**（不隐式写生产默认账本）；`--dry-run` 只列到期（`due`/`plan_ids`）不写 |
| **alert-file** | 显式 `--alert-file PATH` 且 `overall != ok` 时 append `watch_guard_alert/v1` JSONL；healthy 不写；未给路径零写；**不接 Feishu/不推送** |
| **overall / 退出码** | 任一 error → `error`；否则心跳 stale → `stale`；否则 `ok`。exit 0=ok / 1=异常（stale/error）/ 2=参数/用法错误 |
