## 1. 目标接口口径（acad1-legion）

来源：`compositions/acad1-legion/manifest.yaml`、`docs/standards/INTERFACE_REGISTRY_v1.yaml`、
WO-ACAD1-LIVE-ACCEPT-20261104 只读验收（2026-11-04 05:29 实测）。

| # | 探针名 | URL（本机） | 未登录期望 | 角色 | 语义 |
|---|---|---|---|---|---|
| 1 | `pool` | `http://127.0.0.1:8091/api/acad1/pool` | 200 | public | 8091 portal-api 官方池（PG full 30） |
| 2 | `zhice-health` | `http://127.0.0.1:8105/api/v1/health` | 200 | public | 智策 OS v2（uvicorn）健康 |
| 3 | `shuijing-page` | `http://127.0.0.1:8734/academy/shuijing` | 200 | public | 司马徽研究台页面（text/html 200，公开族 C） |
| 4 | `hermes-acad1-comparison` | `http://127.0.0.1:8734/quant-api/api/v1/hermes/acad1-comparison` | 200 | public | Hermes 只读 BFF（公开，un-authed 200） |
| 5-10 | `acad1-research-{pool,stats,reviews,decisions,evidence,calendar}` | `http://127.0.0.1:8734/quant-api/api/v1/acad1-research/*` | **401** | **auth_required** | 8105 JWT auth（`get_current_user`）；未带 Bearer → `401 {"detail":"missing token"}`，**预期鉴权语义，不判失败** |

> 401 归属（WO-ACAD1-LIVE-ACCEPT 实证）：nginx `/quant-api/` 仅 rewrite 反代（`portal/nginx.conf`
> L1161-1163），无 auth_request；直连 8105 同路径同为 401 且 body 一致 → 401 来自 8105 服务内鉴权。
> 探针因此把 401 当「预期」：`expected_status=401`、check 标 `auth_required=True`；若返回 2xx
> （鉴权门缺失/回退）或 5xx/网络错，则 ok=False（不掩盖）。

## 2. `tools/q2_probe.py` 实现（新增 acad1-legion）

- `TARGETS["acad1-legion"]` = 上述 4 个公开端点；`AUTH_TARGETS["acad1-legion"]` = 6 个预期 401 端点；
  `AUTH_EXPECTED_STATUS = 401`。
- `_get()` 增强：捕获 `urllib.error.HTTPError` 并把 HTTP 状态码本身当证据（不再吞成 status=0）；
  `expected_status` 给定时按预期状态判 ok，不符则带 `unexpected_status` 明确原因。
- `_aggregate()`/`probe()`：公开端点按 2xx、预期鉴权端点按 `status==401` 判定；check 增
  `auth_required`/`expected_status`；报告增 `public_targets`/`auth_required_targets`。
- 兼容：`--target acad1` 别名、`--json`/`--markdown`/`--out` 保留；D1/data-warehouse 行为不变；
  Markdown 增「鉴权」列；公开端点仍按旧 `_get(url)` 签名调用（不破坏既有 monkeypatch/调用）。
- **不发送 Cookie/Authorization**（单测锁定：请求头仅 `Accept`）。

## 3. `tools/q2_slo_alert.py` 实现（新增 acad1 评估）

口径：**只对未登录应 200 的公开端点算样本；401/需登录显式 `auth_required/not_measured`，不伪造 200。**

| 端点组 | 判定 |
|---|---|
| `pool`（有 registry SLO：`acad1.pool.get` p95≤300ms / error≤1% / avail≥99.5%，slo_class=read_fast，status=draft） | 样本 < `MIN_SLO_SAMPLES`(20) → `not_measured`；≥20 才按 p95/error/availability 判 `ok`/`alert`；探针失败样本 → `alert`（不因样本少降级掩盖） |
| `zhice-health` / `shuijing-page` / `hermes-acad1-comparison`（registry **无 SLO 目标**） | 显式 `not_measured` + `reason="no registry SLO target; observation only"`（不自行发明目标）；失败样本仍 `alert` |
| 6 个 `acad1-research-*`（预期 401） | 全 401 → `status="auth_required"`, `ok=None`，计入 `not_measured`；**2xx → `alert auth_gate_missing`**；其它状态 → `alert probe_unexpected_status`；目标缺失/无样本 → `alert` |
| 数据 SLA 观测（`freshness_days<=1` / `stale=false` / `pool_total<=30` / `data_date` 存在） | 保留为 `interface_checks` / `interface_alerts`：**独立于 SLO 窗口判定**（`slo_status` 不受其影响），但显式上报，不掩盖数据新鲜度问题 |

- `evaluate()` 增加 acad1 分支（读 `q2_probe.probe("acad1-legion")` 样本；`probe_report`/`probe_fn` 可注入，
  测试不联网）；`--samples` 传给 acad1 公开端点采样；`main` summary 增 `auth_required`/`interface_alerts`；
  退出码仍按 SLO `alerts`（数据 SLA 观测不改变 rc，避免混淆 SLO 与数据质量口径）。
- D1（lusu-d1-flow）/ data-warehouse 分支保持原行为（既有 43 项测试全绿）。

## 7. SLO 缺口与残余（需后续单/负责人）

1. **SLO 窗口仍未实测**：默认 1 样本 < `MIN_SLO_SAMPLES=20` → 正确输出 `not_measured`；`--samples 20` 已验证窗口路径可判
   （pool ok）。**每日/定时采样与告警通道（scheduler/通知）尚未接线**——本单只交付工具与测试，接调度属运维/L2 另单。
2. **3 个公开端点无 registry SLO 目标**：`8105 /api/v1/health`、`8734 /academy/shuijing`、
   `8734 /quant-api/api/v1/hermes/acad1-comparison` 在 `INTERFACE_REGISTRY_v1.yaml` 无 SLO/SLO class 条目
   → 工具显式 `not_measured(observation only)`，**不自行发明目标**。建议 AR/ACAD1 决定登记目标或明确不纳入 SLO（另单）。
3. **6 个 acad1-research 端点登录后 200 数据未验证**：本工具只验「未登录 401 预期语义」；
   登录态 body 验收仍属 WO-ACAD1-LIVE-ACCEPT 的「待登录验证项」（需合法门户 zb_session，另单执行）。
4. **数据 SLA 缺口（已显式上报，非 SLO alert）**：pool `freshness_days=5 > manifest SLA 1`、`stale=true`
   （US/HK/CRYPTO 池日 10-29/10-30/10-31 滞后），`interface_alerts` 2 条；需 ACAD1/数据线复核日管线与 30 只 pending 复盘。
5. **registry 文档债**：`INTERFACE_REGISTRY` L1099 等 notes 仍写「8734 反代走 auth_request」（实测 401 来自 8105 JWT auth，
   nginx 仅 rewrite 反代）→ 建议文档线另单修订（本单不改 standards/）。
6. **新测试未进 fast gate 冻结清单**（tools_key 列表在 `tools/test_gate.ps1` + 冻结守卫）：当前随全量 tools pytest 执行；
   如需入 fast gate 需另单同步清单（避免本单写域外改动）。
