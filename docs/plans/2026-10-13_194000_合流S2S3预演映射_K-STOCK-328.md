## 一、S2 数据源切换（注入点设计）

### 现状
- `agent_platform/engine/tools.py`：`make_context(code)` / `kline_daily(code, n=30)` /
  `quote_snapshot(code)`——**腾讯免费行情 API**，interpreter 的数据源。
- `k_stock/kstock/datafeed.py`：`build_context(code)->dict[str,str]` /
  `load_bars(code, days=60)->DataFrame` / `tech_context` / `news_context` /
  `funda_context`——**特征湖 parquet（5596 只·tushare 千元口径）+ news.db 真数据**。

### 注入点（设计稿拍板：构造函数注入，不 import 死）
`Interpreter.__init__(self, team, llm, memory, checkpointer)` → 增加 `datafeed=None`：

1. 新参 `datafeed=None`；`None` = 维持现 tools.py 行为（**零破坏**，interpreter 其余调用方不动）。
2. 注入对象鸭子类型，需实现与 tools.py **同签名**两个方法：
   - `make_context(code) -> dict` ← 实现为薄壳转调 `kstock.datafeed.build_context`
   - `kline_daily(code, n=30)` ← 薄壳转调 `load_bars`（列名对齐：date/open/high/low/close/vol/amount）
3. interpreter 内部数据调用点改为 `df = self.datafeed or tools_mod`（单点分流）。
4. **降级兜底**（设计稿：腾讯 API 降级为 datafeed 异常兜底）：
   `try: ctx = self.datafeed.make_context(code) except Exception: ctx = tools_mod.make_context(code)`
   ——特征湖缺片/新票无 parquet 时自动回退腾讯，eval 现价快照 `quote_snapshot` 保留共用。
