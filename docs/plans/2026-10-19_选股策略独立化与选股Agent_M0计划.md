**一句话**：选股能力散落在三条线上，缺一个把它们合成“选股 Agent”的产品化工程。

## 二、产品定义：选股 Agent 是什么

```
选股 Agent = 可注册的策略产品线 × 无人值守流水线 × 军团人格外壳
```

- **身体（无人值守）**：策略以 Adapter 注册进 strategy_layer → 每日 07:30 融合裁决（组合分/action/confidence/分歧）→ 与 15:10 picks 链并轨为唯一事实源 → 证据链落库 → 股票池输出
- **大脑（军团人格）**：STRAT1（策略研究员）负责假设与台账；BACK1 负责回测证伪；选股参谋角色负责每日读池、出选股日报、推送飞书——**只提议不交易**（底线 1）
- **外壳（产品）**：picks 看板从“六源聚合展示”升级为“Agent 工作台”：每只票可见 组合分/贡献策略/分歧标记/证据链/后验

## 四、方案架构（目标态数据流）

```
六策略扫描（各自保持独立节奏）
   │  包 Adapter（G1）→ 标准 Signal
   ▼
strategy_layer Registry（注册/权重/启停）
   │  SignalAggregator：组合分 = Σ wᵢ·scoreᵢ；action 多数决；
   │  confidence = max(源)×1/n；divergence 检测
   ▼
signals_combined（PG）──┬─→ 唯一股票池（G2：picks 链改为消费它）
                       ├─→ 证据链库（决策/授权/结果，路线图 P0）
                       └─→ 后验引擎（G6：按策略×权重分层）
                            │
   ┌────────────────────────┼────────────────────────┐
   ▼                        ▼                        ▼
picks 看板（G8）       选股日报（飞书）         STRAT1/BACK1 研究台账
（组合分/分歧/证据链）  （选股参谋每日读池）    （假设→回测→合龙建议）
```

样板策略独立化五步（每步都有确认门）：适配 → 注册（影子权重 0）→ 回测锚报告 → 影子 2-4 周 → 合龙确认门（显式拍板）→ 权重生效。
