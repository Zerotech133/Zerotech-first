## 一、T1 规则分层体系（本轮 10-15~17，最高价值）

**改什么**：把散在主控 memory 里的组织铁律（K 编号纪律、pathspec 提交、回收站删除、三源同步、验 pandas 页用系统 3.11……）机器化进岗，不再靠主控人脑带。

**三层结构**：
1. `agent_platform/rules/org_rules.md` —— 全局铁律，**上限 50 行**，所有岗注入；
2. BUNDLE 岗卡新增可选 `rules` 字段（字符串数组）—— 岗级规则（如 QA1 加「fail-closed 只读」细则、DEV 线加「AST gate 四步」）；
3. 部门层暂用现有 `prompts/*.md`，不新建（避免第四层冗余）。

**注入链**：`_persona()` 尾部追加第 6 通道——模块级一次性读 org_rules.md（`__file__` 锚定，沿 079 判例），拼接格式 `## 组织铁律（org_rules·违反即事故）\n...` + 岗卡 `rules` 数组逐条。加载失败 fail-open（缺文件只告警不阻断产码）。

**体检**：`org_supervision.py` 新增 `check_rules()`：① org_rules.md 在位且 ≤50 行；② 29 岗 rules 字段类型合法（list[str] 或缺省）；③ 抽验 3 岗 persona 拼接结果含铁律锚行。黄级告警（规则缺失不阻断体检总分）。

**验收判据**：
- DEV1/QA1 探针问「提交纪律是什么」，能复述 pathspec 规则（086 拍板判据）；
- 29 岗 sys_prompt 增量 ≤300 tokens/岗（QA1 挂账观察②红线）；
- `python -c` 冒烟：_persona('QA1') 输出含「组织铁律」段；
- org_supervision 体检 check_rules 三项全绿。

**回退**：删 org_rules.md + _persona() 里 6 行拼接 + 岗卡 rules 字段留空——三处独立，任一可单独撤。

## 二、T2 证据引用协议（二轮 10-17~24，随 N5 EARS 化同批）

**改什么**：SEC2/QA1 证据包从散文升级为结构化引用：`#ev:commit:<sha>` / `#ev:file:<path>@<sha>` / `#ev:trace:<工单号>`。

**实现**：`tools/agent_coder.py` prompt 组装前加 `_resolve_evidence(text)`——正则扫引用语法，`#ev:commit` → `git show --stat <sha>` 原文附尾，`#ev:file` → 该 sha 版本文件切片（上限 80 行），解析不到的原样保留并标 `[未解析]`（fail-visible）。spec 模板同步加证据引用段。

**验收**：构造含 3 类引用的测试 prompt，解析输出含 git show 原文；坏 sha 不炸、标注未解析；072 金样本回归零差异（新工单才启用）。

## 三、T3 QA-RUN 验证闭环（二轮，=080-N4）

**对标**：SOLO Coder 收尾五步「起服务→探活→行为断言→日志扫描→结论入轨迹」。我们 QA 止步 smoke，这是与 Trae 最大的工作流差距。

**实现**：`tools/qa_run.py` 新模块——输入工单号+服务端口，五步各产出结构化行落 `portal/qa_runs/<工单>.json`；探活沿 8093 判例（`build_opener(ProxyHandler({}))` 直连，netstat 不可信）；行为断言从工单验收判据字段读取。结论行由 QA1 prompt 消费。

**验收**：对 8093 实跑一轮五步全绿；对假端口正确报 FAIL；json 轨迹含五步时间戳。

## 四、T4 工具权限二维矩阵（二轮，=080-N9 提前有参照）

**对标升级**：Trae 一维黑名单 → 我们 **岗×操作级二维**。配置 `agent_platform/rules/tool_matrix.json`：`{岗: {read: auto, write: [白名单], danger: deny}}`，默认 deny、白名单放行；QA1 只读白名单（已在跑）迁移为矩阵首条。**危险操作=全局禁**（回收站例外沿铁律）。

**验收**：矩阵加载器单测（缺岗默认 deny）；QA1 尝试写操作被矩阵拦截并落审计行；宿主执行链在岗侧 prompt 注入矩阵摘要（≤10 行）。

## 五、T5 门户多工单并行视图（三轮，正验站稳后）

e2e 单线串行期间只做**设计**不做工：门户看板加「生产线并行区」线框（各工单阶段：开单/产码/质检/merge，worktree 隔离已支持并行）。开闸条件=正验链路 7 天全绿。

## 六、T6 知识文档集批量挂载（三轮，轻量半天）

`/api/agent/learn` 支持 `docs:[批量列表]`；learn 端点循环挂载 + 逐部结果行返回。挂载上限 10 部/次防超时。验收：一次挂 8 部工程文档到 DEV 线三岗，org_supervision 投影体检复验 22/22 一致。

## 八、风险与边界

1. **规则膨胀**：org_rules 硬上限 50 行，超了进 knowledge_docs 走学习通道（086 边界重申）；每季度蒸馏一次。
