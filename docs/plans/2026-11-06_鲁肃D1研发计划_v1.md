#### D1-P0-02 SLO 7d 窗口

**测量窗口：** 2026-11-07 00:00:00 → 2026-11-14 00:00:00（Asia/Shanghai）。

**口径：**
- 以真实 HTTP 请求为准：优先 8091/nginx access log，辅以每分钟 `/api/d1/*` 探针；
- 按接口 SLO class 取目标，不拿全局统一阈值：
  - `read_fast`：p95 ≤ 300ms，错误率 ≤ 1%，可用性 ≥ 99.5%；
  - `read_heavy`：p95 ≤ 1500ms，错误率 ≤ 2%，可用性 ≥ 99%；
  - `write_ledger`：p95 ≤ 500ms，错误率 ≤ 0.5%，可用性 ≥ 99.9%；
  - `write_gate`：p95 ≤ 800ms，错误率 ≤ 0.5%，可用性 ≥ 99.9%；
  - `internal_contract`：p95 ≤ 100ms，错误率 ≤ 0.1%，可用性 = 100%。
- 7d 内允许计划内维护，但必须单列，不得把停机时间藏进分母；
- 出报告：`deliverables/d1_q2_slo_7d_20261114.json` + `.md`，含每接口 p50/p95/p99、错误率、可用性、样本量、窗口起止、原始日志引用。

**验收：** 每接口有明确“达/未达”；任一关键接口未达 → Q2 NO_GO，不调低阈值。
