# 身份拓扑决策 v1（2026-10-31）

## 决策

**当前采用“显式双层登录”，SSO 推迟到 M4 后单独 L2 窗口。**

```text
第一层：8734 portal（zb_session）
第二层：8787 Hermes 密码（hermes_session）
```

不把 SSO 硬塞进本期；理由：

```text
M4 有明确黄忠验收节点，SSO 是跨服务改造（反代可信头/OIDC/token 桥）
当前更缺的是发布/任务/证据收口，不是再加一个认证改造
```

## 允许的凭证入口（恰好 5 个）

见 `config/auth_surfaces.json`：

```text
1. zb_session       portal 登录态
2. hermes_session   Hermes 密码登录态
3. X-ZB-Cap/zbcap   OH 能力令牌
4. ide_session      LDE 会话
5. X-DSH-Token      8796 本机同源写守卫
```

## 禁止第 6 个

```text
新增任何 cookie/header/token 身份入口
前端持有模型 key / vault secret
绕过 8734 的直连写入口
```

新增必须：

```text
L2 批准 + 更新 config/auth_surfaces.json + tools/check_auth_surfaces.py
+ 变更说明 + 回滚方案
```
