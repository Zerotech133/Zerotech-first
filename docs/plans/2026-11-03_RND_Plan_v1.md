# 零界研发计划 v1（2026-11-03 ~ 2027-03-31）

- 性质：**执行计划**，服从 `ROADMAP_v4`（唯一战略源）；不新增第二平台/第二入口
- 当前基线（2026-11-03 06:35）：L1 18/18；HQ Q2 12/12；route 292；6 组合 0/0；Q2 = 1 PASS + 1 条件 + 4 Q1；8091 单点/内存 session；W3 未启动；页面当前 95 HTML（W3 基线以启动包为准）
- 总原则：**先稳定、再闭环、后扩展；证据优先；一次只跑一条主链**

## 一、目标（本计划结束时）

1. **一个人可治理的情报队伍**：五角色→Directive→军团→LegionReport 闭环跑通；
2. **Q2 全量**：6 军团 Q2，data-warehouse 登录验收；
3. **两旗舰**：每日情报决策、软件交付；
4. **商业 OS 主链**：商业信号→影响→通知→IP/行程/材料/PPT 的基础能力；
5. **W3/W4 出口**：页面 manifest/契约强制、Kernel v1.0/账本 100%/替换演练。
