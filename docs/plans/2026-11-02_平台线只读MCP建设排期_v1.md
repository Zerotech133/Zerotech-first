## 二、统一实现规范（4 个服务器共用）

- 形式：Python stdio JSON-RPC（照 `dw_governance_mcp.py` 模式），`--selftest` 必备；
- **只读**：不写数据仓、不触发任务、不执行清洗；所有工具带 `dry_run/meta` 标记；
- 输出：`content:[{type:text,text:json}]`，错误 `isError=true`，fail-visible；
- 依赖：`tools/datawarehouse` 现有模块（subprocess 调 `--json` 或直接 import）；
- 测试：每个服务器 ≥2 条 stdio 用例（initialize/tools-list/call/错误路径）；
- 注册：Hermes `~/.hermes/config.yaml` mcp_servers + `/reload-mcp`（**L2 审批**，一次批 4 个）；
- 安全：路径白名单、无 execute 能力、无凭据读取。

## 三、验收标准

| 服务器 | 验收 |
|---|---|
| dw-quality | Hermes 问「数据仓今天质量怎么样」→ 返回 5 项状态+资质分布；hard_ok 字段正确 |
| dw-catalog | Hermes 问「登记率/unknown 多少/某表登记信息」→ 真实值 |
| factor-tools | Hermes 问「今日因子日报/某因子 IC」→ 真实日报字段 |
| kb-corpus | Hermes 问「知识库统计/搜索某主题」→ 真实检索结果 |

## 五、风险

| 风险 | 对策 |
|---|---|
| 4 个服务器同时注册导致 Hermes 启动变慢/失败 | 先单服务器注册验证，再批量；保留 `--reload-mcp` 回滚（不注册即可） |
| subprocess 调 CLI 慢 | 优先 import 模块函数；timeout 60s；缓存只读结果 |
| 权限越界 | 只读白名单；无写工具；L2 审批时附工具清单 |
