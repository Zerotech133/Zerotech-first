## 2. 开源社区调研结论（2026-10 现势）

| 框架 | 启发点 | 对我们的动作 |
|---|---|---|
| **CrewAI** | 层级 Process（manager 委派+内置重试+human-in-the-loop）最成熟；2026-08 维护度雷达编排灵活性 5/5 | **吸收范式**：田小皮=manager delegate 位；派单走既有 devtask 不引其运行时 |
| **LangGraph** | 状态图+checkpoint 崩溃恢复+人工介入节点 | 我们的 checkpoint/任务单已覆盖同类能力；参考其「节点级恢复」细化 devtask 断点续跑 |
| **AutoGen** | ⚠️ 微软 2025-10 宣布进入维护模式（冻结） | **不引入**。多 Agent 对话式协作范式可用「双 Agent 对练」自研实现 |
| **MetaGPT** | 软件公司角色 SOP（PM→架构师→工程师→QA 流水线） | 与我们 charter 纪律同构；吸收其「角色产出物即交接物」的验收口径 |
| **Dify/n8n** | 可视化编排/外部系统集成 | 不引入；我们门户+IDE 即可视化层 |

**总路线：自研 agent_platform 为骨（已实证 63 工单/多部门并行），开源只吸收范式不引入运行时**——避免框架绑架，保持注册制零代码扩编优势。
