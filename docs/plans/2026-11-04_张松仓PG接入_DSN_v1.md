## 一、口径（连接解析优先级）

`dataset_registry.resolve_pg_connection()`：

| 优先级 | 来源 | 行为 |
|---|---|---|
| 1 | 显式参数 `pg_dsn` | `DatasetRegistry(pg_dsn=...)` 注入（测试/运维）；`""` = **显式禁用，不回退**（保持旧 `missing_dsn` 语义） |
| 2 | 环境变量 `ZHICE_V2_DSN` | 既有口径（libpq / SQLAlchemy 风格 URL 归一化） |
| 3 | `jev_common.DB_DSN` fallback | 与 `portal/api_acad1_pool._pg_connect_kwargs()` 同源：读 `C:\项目\老田的AI助手\jev-eval` 的 `DB_DSN`（host/port/user/password/dbname → psycopg2 kwargs，**密码仅内存**） |
| 4 | 全部不可用 | `connector_status=missing_dsn`（fail-visible、不假绿），`connector_error` 记录原因 |

- 开关：`DW_PG_DSN_FALLBACK=0` 可显式关闭 fallback（测试/应急回滚到"仅 env"旧口径）。
- 连接：`_pg_connect_default` 现同时接受 **libpq DSN 字符串** 与 **psycopg2 kwargs dict**；连接建立后强制 `set_session(readonly=True, autocommit=True)`（psycopg3 退化 autocommit）。
- 暴露：行/`stats_v2()` 新增 `connector_source`（explicit/env/jev_common/none），便于审计；`path/connector` 仍是逻辑标签 `pg@127.0.0.1:5446/zhice_os_v2`（不含凭据）。

## 三、影响面

1. **`/api/dw/get` / `stats-v2` / `get` / `sample`**：`ZHICE_V2_DSN` 未设时 pg 条目由 `missing_dsn` 变为 `active/available`（84 张 wave2 表可读），API 返回中 `connector_source=jev_common` 可审计。
2. **默认 `DatasetRegistry()` 初始化**：会尝试经 fallback 连接 PG（本机 ~毫秒级元数据查询）；DB 不可用时仍优雅返回 `missing_dsn/connector_unavailable`（不阻断文件级 `stats/list`，不假绿）。
3. **消费方**：`api_dw_registry`、`dataset_registry_cli`、数据仓页面统计（pg 可用数从 0→84）会受影响；依赖 `missing_dsn` 作为"未接 PG"信号的脚本需改判 `connector_status/connector_source`（已有行为取值为 ok/active）。
4. **测试**：缺 DSN 语义的既有测试已显式关闭 fallback；新增 mock 用例不依赖真实 PG/jev_common。

## 四、凭据安全边界

- `resolve_pg_connection` 返回结构只含 `label=pg@host:port/db`；**密码只在 `kwargs` 内存结构**中传给 psycopg2，不写入文件、不打印、不进 JSON 输出（`stats_v2/get/sample/CLI/API` 均有测试断言）。
- fallback 不可用原因只记录异常**类型名**（`jev_common_unavailable:ModuleNotFoundError` 等），不拼接可能含路径/凭据的异常消息。
- 连接建立后强制 `readonly=True`；`sample` 固定 `SELECT * ... LIMIT n`；不执行任何写操作；未改 PG/凭据/服务。
- 风险提示：`jev_common.DB_DSN` 当前为平台通用只读连接口径（与 portal 同源）；若后续需要更小权限，应申请**专用只读账号**并切到 `ZHICE_V2_DSN`，本单不改凭据。
