# 五角色晨会运行卡 v1（C2）

- 用途：每日 15 分钟、A0 主持、田丰执行编排；产出纪要 + 五角色意见 + 决议/派单。
- 原则：无证据不 verified；意见不替代签字；决议必须 owner/due。

## 会前（田丰，2 分钟）

1. 打开 `/hq` 五角色/议程/军团；
2. 选今日 1–3 个议题（研发/挖掘/分析/商业）；
3. 给每个议题挂 `topic_id`、owner、期望产出、证据来源。

## 会中（15 分钟）

| 角色 | 固定输出 | 禁止 |
|---|---|---|
| 田丰 | 今日三优先 + DAG + 派单 | 不代替 A0 终裁 |
| 诸葛亮 | 3 条反向质询：前提/反例/失败模式 | 不拍板、不写生产代码 |
| 赵云 | 证据缺口/审计风险/经验归档 | 不做业务决策 |
| 关羽 | 研发/技术债/门禁风险 | 不自行合并 |
| 黄忠 | 验收闸口/抽样结论/放行或拒收建议 | 不代签 |

## 会后（田丰，5 分钟）

1. 纪要落 `agent_platform/data/meetings/hq/`；
2. 决议 → Directive（owner/legion/acceptance/due）；
3. 未派单决议在 `/hq` 议程红标；
4. 次日晨会第一项：昨日决议跟进。

## 今日议题模板

```yaml
topic_id: HQ-YYYYMMDD-01
kind: 研发|挖掘|分析|商业
title: 一句话
owner: A0|ARCH1|D1|DATA1|ACAD1|STRAT1
evidence: [source_id/data_date/lineage]
desired_output: 决策|方案|代码|报告|内容|行程
due: YYYY-MM-DD
```

## 验收（连续 5 个工作日）

- 5 份会议纪要（morning）；
- 25 条 RoleOpinion（5 角色 ×5 天）；
- 至少 5 条 Directive，其中 ≥3 条有 task/order；
- 未派单决议 0；
- 每次会议 ≤15 分钟。
