## 一、双方向客户动线

| | 轻量玩家 | 高级玩家 |
|---|---|---|
| 进入方式 | 看到一个策略 → 模拟建仓 → 交易 | 组建投研团队：策略 + 经理 + 操盘手 |
| 复盘/会议 | **不需要**，无任何仪式感负担 | 经理组织盘前会议 + 盘后复盘 |
| 收费档 | 免费/低价档（单策略直订） | 按组合构成计价（成员×模型） |
| 本质 | 组合退化为「N=1 策略、M=0 操盘手、0 经理」 | 完整三层可组合 |

**关键认知：轻量不是另一个产品，是同一组合模型的最简退化态。** 这样一套引擎服务两档客户。

## 二、三层角色模型（均可雇佣/解聘/下钻）

1. **策略**：12 策略库，经理可挂荐语（MANAGER_INTRO 已有）✅ 已可下钻看详情
2. **操盘手**：分等级（正式/实习/储备/运营台已有），可组合——稳健+激进+实习生混编；下钻看记分卡/净值/成交 ✅ 大部分已有
3. **投资部经理**：AI 赋能（角色 prompt + 能力边界），职责=荐策略、开盘前会、管盘后复盘、面向（AI 或直接向操盘手）汇报

## 三、模型计价层（新，本次梳理核心增量）

- ⚠️ **硬约束（老田 23:28 拍板）：模型目录只能使用 https://client.gaorta.com/ 上的模型。**
  - Gaorta = One-API 型聚合网关：OpenAI SDK 兼容、按量付费、300+ 模型 / 60+ 供应商（OpenAI/Anthropic/DeepSeek/Qwen/Kimi/MoonShot 等全覆盖）
  - 架构红利：一个 base_url + 一个 key 通吃全部模型，模型目录直接从 gaorta 模型列表生成，**无需逐家接入**；计价系数直接锚定 gaorta 倍率
  - S-a 落地形态：`models.json` 生成器从 gaorta 拉模型清单（名称/倍率/供应商），本机 Ollama 作为离线兜底项单独标注（不进对外计价目录）
- 经理/操盘手背后是**可选择的模型**，模型消耗不同 → 聘请价格不同（Claude 经理 > DeepSeek 实习生）
- 角色与模型解耦：同一个「稳健操盘手」角色可以由不同模型驱动，客户按预算选模型
- 计价动线：`聘请价 = 角色基价 × 模型系数`，按月/按动线计

## 四、会议线（经理面向，松耦合投递）

- 盘前会议（已有雏形：作战计划/晨报）、盘后复盘（已有：review_minutes/judge 评审/周报 W40）
- **松耦合关键**：会议纪要不是绑死某个通道——经理产出纪要后，投递到飞书/站内/直接下发操盘手，通道可插拔
- 轻量玩家无此层（不产生会议，不收会议相关费）

## 五、松耦合可组合原则（架构约束）

1. 角色间只经**接口契约**通信：纪要（manager→anyone）、记分卡（trader→portfolio）、荐语（manager→strategy）、订阅关系（customer→组合）
2. 每个角色可独立：雇佣 / 解聘 / 升级模型 / 换风格，不牵连其他成员
3. 组合 = N 策略 × M 操盘手 × 0/1 经理，任意裁剪都合法
4. 收费按动线后置设计：引擎先跑通组合语义，计价层只读组合构成，不侵入引擎
