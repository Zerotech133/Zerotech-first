## 二、AgentSpec v1：增量协议（不推倒，只加三个字段族）

对现有 agent 条目**只增不改**（旧字段全部保留，interpreter 校验向后兼容）：

```jsonc
{
  // ---- 编制属性（已有，不动）----
  "agent_id": "ST1", "role_profile": "chanlun_analyst", "level": 2,
  "grade": "E2", "attributes": { ... }, "memory_grants": { ... },

  // ---- 模型调配（已有，UI 化即可）----
  "llm_binding": "glm/glm-5.3", "binding_note": "判读类上浮强模型；轻量调度走 5.3-flash",

  // ---- ★新增 1：技能挂载（引用不内嵌——Skill 是插件，Agent 是编制）----
  "skills": [
    { "id": "chanlun_9dim",  "kind": "algo",       "ref": "portal/algo_market.json#chanlun_9dim", "enabled": true },
    { "id": "devtask",       "kind": "tool",       "ref": "agent_platform/tools#devtask",          "enabled": true },
    { "id": "xq_data_review","kind": "automation", "ref": "automation#xq_data_review",             "enabled": false },
    { "id": "st1_persona",   "kind": "prompt",     "ref": "registry/claude_agents.json#STRAT1",    "enabled": true }
  ],

  // ---- ★新增 2：心跳口径（探针判例平移：三态不假绿）----
  "heartbeat": { "expect": "daily 17:35", "probe": "agent_platform/chief_last_run.log", "stale_after": "26h" },

  // ---- ★新增 3：启停（编制状态已有 status，补运行开关）----
  "runtime": { "enabled": true, "degraded_fallback": "qwen3.5:9b" }
}
```

**Skill 注册表（新文件 agent_platform/registry/skill_registry.json）**：kind 五类——`tool`（内置工具）/ `algo`（算法商品，外键 portal/algo_market.json 6 款）/ `automation`（计划任务与 automation）/ `prompt`（人设包，外键 claude_agents.json）/ `external`（外部 skill，预留）。**Agent 的 skills 数组只存引用 + enabled 开关，实体永不内嵌**——加 Skill 不改 Agent，加 Agent 不改平台（K-ORG-019 原则的 Skill 版）。

**两套口径归一**：ai_market.json 的 skills/algos 字段改为 AgentSpec.skills 的对外投影（货架=指挥台数据的只读营销视图），消灭第二本账。

## 三、指挥台：org.html 升级（不新建页面）

org.html 已有树图 + 编辑区雏形，升级为**全量指挥台**：

1. **全量视图**：/api/org 扩展为聚合投影（org.json + 14 个 team_*.json + 人设引用 + skill 解析），按部门/职级/模型/技能多维过滤。
2. **三区编辑**（对单个 Agent）：属性区（编制/职级/人设引用）/ 技能区（挂载/卸载/开关，选项来自 skill_registry）/ 模型区（llm_binding 下拉：glm-5.3 / glm-5.3-flash / qwen3.5:9b 本地 / claude…+ 一键降级档）。
3. **写回安全链**（判例平移）：改绑定 → 自动备份进 binding_backups/（已有判例）→ 写前跑 interpreter 校验（校验关口从"启动时"前移到"写回时"，不把错误配置拖到重启才爆）→ prompt 修改走 prompt_versions.json 版本化（已有）。
4. **心跳灯三态**：按 heartbeat 口径探活，绿=按时/黄=过期/灰=无账本，**绝不假绿**。
5. **加 Agent 表单**：填 agent_id/部门/职级/人设/模型/技能 → 生成注册表增量 → interpreter 校验 → 测试钩 → 生效。加一个 Agent 从"手改 JSON+祈祷"变成"一张表单+一道闸门"。
