## 三、影响面

1. **API 默认响应变化**：`/api/acad1/pool` 无 query 时由 12（CN 单日）变为 30（跨市场最新聚合），`pool_id/pool_date` 变为聚合语义（`ACAD1-POOL-PG-FULL-*`）。依赖固定 `count=12`、`pool_id=...PG-<date>` 或单市场 `by_market={CN:12}` 的**旧消费方**需显式加 `?view=single`。
2. **页面**：默认显示 30；`stale=true/freshness_days=5` 会显式展示（跨市场池日不一致，审计既成事实，不伪装 fresh）。
3. **D1/下游**：D1 消费方若沿用默认 URL 将看到 30（聚合口径）；建议：
   - 展示/研究默认可用 `view=full`；
   - **冻结/审计证据**需固定口径——在 ACAD1 统一池日修复前，冻结证据请显式使用 `?view=single`（或等 ACAD1/DATA1 统一池日后以单日 30 为准），避免 `pool_id` 聚合语义混入正式证据（见审计文档 §5.4 与 FULLVIEW 文档 §四）。
4. **缓存/CDN**：nginx 若对 API 有缓存需关注 `view` query 参与缓存键（默认同源反代，按 URL 缓存；本单未改 nginx）。

## 四、风险与回滚

风险：
- 聚合视图的 `pool_id/pool_date` **不是**统一池日语义（根因仍在 ACAD1 写入口径 + DATA1 契约）；默认切 full 是把过渡视图前置为默认，需与审计 A 方案修复时间线对齐（避免下游误把聚合 30 当正式单日 30）。
- PG 直连不可用/降级时默认展示单日（12）并显式 degraded，不失败不伪造；若 PG 长时间不可用，页面会显示降级说明。
- `stale=true`（跨市场数据日不同）可能被误读为数据过期，页面已展示 `pool_dates` 与说明；建议 ACAD1 补数后显式更新。

回滚（按优先级）：
1. **不改代码**：消费方/浏览器显式 `?view=single`（或页面点「单日视图」）即回到 12；
2. **代码 revert**：回退本提交（`DEFAULT_VIEW` 回 `single`、页面默认回单日），重启 8091 生效；无数据影响；
3. 环境级：`ACAD1_POOL_PG_DISABLE=1` 可使 full 降级单日并显式标注（应急观察用，不是正式回滚）。
