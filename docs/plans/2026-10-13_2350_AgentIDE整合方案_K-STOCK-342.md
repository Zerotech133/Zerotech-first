# Agent IDE 整合方案：仿 Trae/VS Code 五区开发台（K-STOCK-342）

> 2026-10-13 深夜 · 老田拿 Trae 截图点单：「借鉴这样的 IDE 开发模式，把每个板块整合整合」
> 现状基线：341（e6169c8）——三栏布局（树+档案+调试台）+ 可拖分隔条 + 代码预览 + 折叠块

## 〇、一句话方案

把 ide.html 从「三栏平铺」升级为**五区仿 IDE 布局**：新增**活动栏**（视图切换）与**底部面板**（日志/日报/控制台），中栏改**多 Tab 编辑器**（档案/代码/工单并存），右侧调试台增强 **@引用 + 模型选择 + 证据表渲染**——全部 bundle 内嵌静态数据，**零后端、零重启、nginx 即改即生效**。

## 二、五区定义

1. **① 活动栏**（48px 竖条）：5 个视图图标切换②的内容；当前视图高亮蓝。
2. **② 资源侧栏**（220px，可拖）：随①切换——组织树（现状）/ 代码文件 / 工单列表（doing 绿 · review 黄）/ 记忆（agent→namespace）。
3. **③ 编辑器区**（中栏，**多 Tab**）：Tab 可并存可关——档案 Tab（341 版整页内容）/ 代码 Tab（每文件一个）/ 工单 Tab。选中侧栏条目**新增 Tab 而非替换**，这是与现状最大的行为差异（Trae 核心体验）。
4. **④ 底部面板**（高 180px，可折叠）：三个 Tab——**调试日志**（send 推理耗时/eval token/失败原因，现状只在气泡尾部的信息沉到这里）/ **A0 日报**（最近一期判读只读投影）/ **控制台**（bundle 生成时间、agent 数、调度心跳）。
5. **⑤ AI 调试台**（400px，可拖，341 保留）：现有 chat 全保留；新增——**@引用**（输入 `@` 弹 Agent/文件选择，@file 把代码片段拼进上下文）/ **模型选择器**（qwen3.5:9b ↔ 4b 下拉，调试台本就直连 Ollama 零成本）/ **证据表渲染**（回复里的「证据|结果」表用表格样式出）。

## 三、数据通道（维持零后端纪律）

- 组织/代码/工单/记忆/轨迹：**全部 bundle 已有**（341 版 code_files、workorders、memory、coder_traces）——一期不需要动 build_agent_ide_bundle.py 之外的东西。
- A0 日报底板：二期从 `agent_platform/data/` 最近日报文件**烘入 bundle**（只读快照，随 bundle 重建刷新）；不为此加 API 端点。
- @file 上下文：前端直接取 bundle.code_files[i].content 截段拼 prompt，不发新请求。

## 五、风险与回滚

- 纯前端单文件（ide.html）+ bundle 生成器小改，nginx 静态即改即生效；出问题 `git revert` 单提交即回 341 版。
- 多 Tab 状态管理是唯一复杂点：用 `{id, kind, title, render}` 数组 + innerHTML 重绘（页面本身无框架，不上前端框架）。
- 窄屏（<1180px）：侧栏与调试台叠层策略沿用 341 的 media query，底部面板窄屏默认折叠。
- 已知判例回看：**深层内容断言**（341 的 `||''` 截断 BUG 教训）——施工后 playwright 必须断言每个 Tab 的深层块存在性，不能只断布局宽度。
