## 三、影子期与拍板衔接

1. **影子期内（~10-15）零动作**：两线样本各自干净跑完，双判据才有对照价值。
2. **k_stock 16:30 automation 时段矛盾**（K-STOCK-011 发现）：合流前先解决——建议改 **18:05**（错开 16:30-17:00 负载高峰与 17:10 影子线）；合流后随 S2-5 退役。待老田一句话确认即代改。
3. **合流触发条件**：10-15 双判据评估完成且无 P0 级失败（若某线判据不合格，先修再合流）。
4. **回退设计**：每步独立提交（K-STOCK 编号连续），任何一步验收不过即 revert 该步不前滚。

## 四、双实现首日对照（2026-10-08 Day0，S2-4 基线）

同票同日（600519 茅台）、不同实现的产出分歧——**合流必须量化的第一个事实**：

| 维度 | k_stock（D0 实跑 14:xx） | agent_platform（Day0 影子 15:22） |
|---|---|---|
| D1 结论 | **BUY 0.73**（五档+目标价+风险等级） | **HOLD 0.55**（降档纪律：conf<0.5 才 BUY） |
| 数据源 | 特征湖 parquet+news.db | 腾讯免费行情 API |
| 辩论 | 2 轮 → 多头占优 | 2 轮 sim 0.39 → 保守权衡 |
| 相似度度量 | 词面 Jaccard | 字符 bigram 余弦 |
| LLM | qwen3.5:9b | qwen3.5:9b |

判读：同模型同票下 BUY 0.73 vs HOLD 0.55 的分歧主要来自**数据源差异**（特征湖因子更丰富 vs 腾讯量价）+ **D1 评分契约差异**。S2-4 合流后须重跑对照，以「同数据源同契约」消除方差后再评估两编排器等价性。

附注：k_stock 晚间 19:38 的 PoC 为 **mock 模式**（mock=true，T1/T2 输出同文本致 sim=1.0 一轮即「收敛」——与我方 K-STOCK-004 B3 教训同现象），不作对照素材。
