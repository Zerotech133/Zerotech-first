# K-STOCK-346 · Agent IDE 多 IDE 团队工作区方案（多项目并行）
> STATUS: unspecified（owner: TBD；2026-11-07 前补状态或标 superseded）



> 2026-10-14 00:52 · 老田需求：一个 IDE 里一个团队 3-4 人各开一个项目/子项目，同时开展各项工作互不混乱
> 前置：342~345 五区 IDE 已全量交付（活动栏/多 Tab/底部面板/调试台/Ctrl+P）

## 一、问题定性（老田「混乱」疑问的两层回答）

| 层 | 结论 |
|---|---|
| 多人**同时访问**页面 | ❌ 不冲突——Tab/视图状态存各浏览器 localStorage，天然按人隔离 |
| 单页面内**多工作并行** | ⚠️ 确实混乱——①调试台单会话（切 Agent 即清空聊天记录）②27 Agent×代码×工单 Tab 混流一条栏无边界 ③工单平铺不分公司 ④无「工作现场」概念，切走再回来全部重找 |

**根因**：现有 IDE 是「单人单项目」信息架构，缺「工作区（Workbench）」抽象层。

## 二、方案：工作区 × 身份双维度隔离

### 数据源（零后端·bundle 已有）
- **工作区 = 项目部门**：🅰 回测开发部（DEV3/DEV4/QA1）、🅱 数据治理部（DATA1/DEV1）、🅲 下版本设计推理部（PM1/ARCH1/DEV2）——`departments[type=project]`
- **身份 = Agent**：27 在编，工单带 owner 字段可过滤
- 外加「全部」聚合视图（现状默认）

### 五区改造映射
| 区 | 改造 |
|---|---|
| 顶栏 | **工作区切换器**（🅰/🅱/🅲/全部）+ **身份切换器**（默认视角/以某 Agent 视角） |
| ① 活动栏 | 不变（5 视图） |
| ② 侧栏 | 按**当前工作区过滤**：组织树只见本部门成员、工单只见本项目 owner 单、记忆/轨迹只列本部门 Agent |
| ③ 编辑器 | **Tab 集按工作区隔离**（切工作区=整套 Tab 现场切换；localStorage 键 `tabs@<ws>`）；二期加**分屏**（左档案右代码同屏） |
| ④ 底部面板 | 日志面板按工作区分流（`logs@<ws>`）；A0 日报/点评全局共享 |
| ⑤ 调试台 | **多会话 Tab**：每个 Agent 一个会话（`chat@<ws>@<agent>`），切换保留历史、可同时与多人对话 |

### 状态存储键位规划（345 判例：重写页面先盘点持久化键）
```
ide-view@<ws>      视图          ide-tabs@<ws>     Tab 集序列化
ide-dbg@<ws>       调试目标      ide-chat@<ws>@<id> 会话历史
ide-ws             当前工作区    ide-me            当前身份
旧键 ide-view / --w-* / panel-closed 保留兼容（首次迁移读旧值）
```

## 三、分期施工

| 期 | 内容 | 量级 |
|---|---|---|
| **一期（骨架）** | 工作区切换器 + 侧栏过滤 + Tab 集按工作区隔离 + **调试台多会话**（三个混乱点根治） | 半天 |
| **二期（体验）** | 分屏编辑器 + 身份视角（工单 owner 过滤强化）+ 工单按项目分组看板 | 半天 |

每期独立 commit 可 revert。验收沿用 playwright 深层断言 + 新增「跨工作区隔离断言」（切工作区后 Tab 集确实不同、调试会话历史保留）。

## 四、风险与边界

- 纯前端 + bundle 微改（departments 已内嵌·零后端），nginx 静态即改即生效。
- 调试会话历史存 localStorage 有体积上限（每会话 50 条封顶，超则裁最旧）。
- 「全部」聚合视图=现状行为，老数据无感迁移（首次进入读旧键）。
