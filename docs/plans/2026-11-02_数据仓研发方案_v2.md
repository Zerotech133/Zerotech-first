## 一、第一性原则（最高约束）

> **数仓 = 一切可结构化、未来可用、能调取的数据的统一管理者。**

1. **结构化即可入仓**：接口数据 / 开源情报抽取数据 / 学习研究派生数据，一律纳入统一管理；
2. **未来可用即可调取**：每个数据集必须有取数入口（MCP/HTTP/CLI），否则不算入仓；
3. **统一登记/口径/治理**：唯一数据集目录、统一新鲜度/质量/权限/保留/敏感级；
4. **派生数据带血缘**：学习结论→报告/KB/因子/策略可追溯到源数据。
