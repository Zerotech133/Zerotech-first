## 二、本地回落方案（推荐案：F1 情绪判定本地化）

**模型选择**：qwen3.5:9b（本机实测在位 /api/tags；4b 太弱易全中性，35b 本机显存不足溢出 CPU 慢）。判断任务只输出 4 字段 JSON，9b 单条推理预估 3~8s（num_predict≤60），与 typesafe 超时 15s 同量级。

**实现形状**（约 40 行，动 news_ai.py 一处）：

```python
def jev_judge_one_local(title, stocks, timeout=30):
    """451 回落：本地 9b 出 {"bias","scope","conf"} JSON；失败返回 None。"""
    tag = ("（关联标的：%s）" % "/".join(stocks)) if stocks else ""
    prompt = (
        "财经快讯：%s%s\n判断市场影响，只输出 JSON："
        '{"bias":"bullish|bearish|neutral","scope":"bond|stock|fx|commodity|macro",'
        '"conf":0.0~1.0}，不要输出其他内容。' % (title[:80], tag))
    r = requests.post(OLLAMA, json={
        "model": os.environ.get("OLLAMA_MODEL", "qwen3.5:9b"),
        "messages": [{"role": "user", "content": prompt}],
        "stream": False, "think": False, "format": "json",
        "options": {"temperature": 0.1, "num_predict": 60},
    }, timeout=timeout)
    j = json.loads(r.json()["message"]["content"])
    if j.get("bias") not in _BIAS_CN:
        return None
    return {"bias": j["bias"], "bias_cn": _BIAS_CN[j["bias"]],
            "conf": round(float(j.get("conf") or 0.5), 2),
            "scope": j.get("scope", ""), "scope_cn": _SCOPE_CN.get(j.get("scope", ""), ""),
            "reason": "local-fallback(9b)"}
```

- `jev_judge_one` 头部接一级回落：typesafe 失败（含 451/超时）→ `jev_judge_one_local`；回落命中在返回 dict 加 `"src": "local"` 供账本统计。
- Ollama `format:"json"` 强制合法 JSON（9b 下实测可靠性远高于自由文本+正则）。
- scope 是 9b 弱项：接受空/错，scope_cn 允许 ""（下游 scope 语义仅展示，不进判据）。
