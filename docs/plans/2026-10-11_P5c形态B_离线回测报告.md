## 3. 三组证据

### 3.1 池级残余分层（形态 B 的池内背景）

| 1买 | 1479 | +1.13 / +0.30 / 52.2 | +1.77 / **+0.42** / 51.4 |
| 3买 bei=True | 1060 | -0.64 / -1.71 / 43.8 | -1.63 / -2.41 / 42.2 |
| 2买残余（非range） | 486 | +0.61 / -0.37 / 47.7 | -0.68 / -2.35 / 39.8 |
| 毒层（P5b 对照） | 366 | — | -2.9 / -3.5~-10.2 / — |

结论：P5b 砍毒层后，**2买/3买残余层仍为负 alpha（T+10 中位 ≈ -2.4）**，1买 是唯一正中位层——池级支持 1买 优先。

### 3.2 T1 通道内直接证据（形态 B 的真实场景：当日领涨∩cl_buy 残余）

| 层 | n | T+5 均值/中位/胜率% | T+10 均值/中位/胜率% |
|---|---|---|---|
| 领涨∩1买 | 118 | +1.15 / -1.02 / 42.1 | **+2.90** / -1.50 / 41.0 |
| 领涨∩2/3买残余 | 386 | -0.18 / -1.36 / 44.7 | -0.88 / -2.54 / 41.7 |
| 领涨∩毒层（对照） | 55 | -3.99 / -5.75 / 31.9 | -7.95 / -6.30 / 34.0 |

要点：
- 通道内 1买 仍占优（T+10 中位差 +1.04pp、均值差 +3.78pp），**但优势比池级缩窄**（池级差 +2.8pp → 通道内 +1.04pp），且**两层绝对中位均为负**。
- 领涨∩1买 呈「负中位（-1.50）+ 强右尾（均值 +2.90）」——其价值在尾部弹性而非胜率，与 T1 高风险共振层定位契合，但也意味着收益分布依赖少数大赢。

要点：

- 结论：优势非全天候，regime 依赖明确——**强化「暂缓启用、滚动复验」的现行建议**（§1），且 11-02 复验应加看月度表防「均值掩盖反转」。

## 5. 风险与局限

1. **样本期单周期**：2025-09~2026-10 未跨牛熊；1买 样本集中在 2026-04 后（检测器上线顺序 + 反弹期），右尾优势（均值 +2.90）可能部分是环境赐予。
2. **通道内样本偏小**：n=118/386，中位差 +1.04pp 恰好压线门槛 +1——不够厚的安全边际。
3. **qpzm 通道无历史留档**：供给与收益测算仅覆盖 strong∩chanlun 通道；qpzm∩chanlun 通道（2/3买残余参与）的表现未验证，形态 B 对该通道无动作属保守留白。~~历史不可重建~~ → **逐日留档已建**（K-STOCK-121，2026-10-11）：`picks_history/qpzm_YYYY-MM-DD.json` 全量快照随 TodaysPicks 自然积累，历史自 2026-10-09 起可回放；本报告存量结论仍是 strong∩chanlun 单通道口径。
4. **形态 B 与 D4 结论的呼应**：通道内两层中位均为负，与 D4「领涨后回调=动量衰减」一致——形态 B 是在该弱通道内**择优**，不是把通道变强。

## 6. 建议与预案

**建议暂缓启用**，按以下节奏：

1. 现行组合（P5b 毒层过滤 + 形态 C 排序 + P4 环境豁免）先运行 2-4 周；
2. 双工具滚动：`python quant_backtest/t1_channel_verdicts.py`（离线全量，随池增长）+ `python quant_backtest/pick_layer_verdicts.py`（归档实盘 T1 后验）；扩角度模式 `--by-month` / `--supply-q`（§3.4/§3.5，11-02 复验日同跑）；

**近月切片初验（2026-09-11 起，2026-10-11 跑）**：T+5 满窗侧 1买 中位 -1.91 vs 残余 -13.56（有效 n=17/11），相对优势放大至 +11.65pp（方向与全期一致且更强）；T+10 满窗仅 3/2 个——不可读，全期 T+10 结论（+1.04pp）待 10 月下旬窗口自然补满后复验（`t1_channel_verdicts.py --since 2026-09-11`）。供给：通道 5.46/日→1.62/日（30%）。工具已加固：分层表显示有效 n/事件数，门槛①改用 T+10 满窗计数（防窗口未满的幸存者偏差）。

**30 交易日模拟演练（2026-08-21~10-09，2026-10-11 跑）**：用历史数据预演复验 SOP——仅 strong∩chanlun 通道可历史重建（qpzm/cross 无留档；重放无板块前20截断，T1 日均 5.3 vs 生产 2.5，口径偏高）。模拟归档 30 份（picks_history_sim/，与生产隔离）→ `pick_layer_verdicts.py --hist` 全链路走通。结果：基准 1436 事件 T+5 中位 +0.20 / T+10 -0.23；**q_toxic n=68 T+10 中位 -4.57（差 -4.3pp）→ P5b 毒层过滤近期验证成立**；q_first_buy n=943 T+10 差 +0.2pp（微优不显著，形态 B 门槛②近期数据不达）；**panic_buy n=260 T+10 差 -0.6pp 与全期调研（reg=down 最优）相反——标记为 11-02 复验关注点**（P4 豁免人群≠panic 层全体，暂不动，跟踪）。演练暴露并修复 pick_layer_verdicts DataFrame 真值 bug（生产档尚未触发，提前消灭）。

3. 复评条件：通道内中位差持续 ≥+1pp（含新样本）且 T1 实盘归档中 q_first_buy 层验证占优 → 连同供给代价（23%）一并提交拍板；
4. 启用预案（已预置设计，改动小）：`tier_of` 内 cl_buy 计票拆两档（1买 全票；2/3买残余仅在 qpzm/cross 通道计票）+ `FIRST_BUY_STRONG_ONLY` 开关 + load_cross 同步 + 金测 4 例；回退=开关一行。
