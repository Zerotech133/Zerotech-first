## 降级行为

- **机器通道**：`X-Portal-Token` 常量比对原语义原样保留（Agent/自动化脚本非人，不登录），优先级最高。
- **本机回环**（127.0.0.1/::1）：无条件放行——与现有 P0-1b「本机可信域」口径一致，产线保底。
- **菜鸟不可达**（超时/连接失败/5xx）：
  - `CAINIAO_AUTH_MODE=degraded`（默认）→ 按「本机可信域」放行，量化产线不被登录系统故障连带；
  - `CAINIAO_AUTH_MODE=enabled` → 一律拒绝（fail-closed），供彻底切换后使用。
- 降级结论**不进缓存**，下次请求重试，菜鸟恢复即回正常路径。

## 安全注意

- token 只在内存比对与缓存，**不写日志、不落盘**；缓存随进程重启清空（TTL 60s）。
- 缓存为进程内 dict + `threading.Lock`，不含任何持久化。
- `CAINIAO_CLIENT_SECRET` 走环境变量注入，禁止写进 portal/ 下任何文件（该目录挂为 nginx web root）。
- 校验失败返回 401 语义（`reason=invalid_token`），前端 P2 做 refresh-token 自动续期 + 重登引导。
