# 零界版面架构宪法 v1（K-STOCK-169 · 2026-10-12）

> 治理依据：`2026-10-12_PRODUCT_ROADMAP_v1.md`。本文件定义零界站内的**版面总排布**与**页面准入/清理判据**；改版面先改这里。

## 一、五层版面（全站只有这五层，不再加第六层）

| 层 | 载体 | 职责 | 原则 |
|---|---|---|---|
| L1 门面 | `index.html`（8080 根路径） | 品牌门面「零界 · 一个人的 AI 公司」+ 此刻区（该看什么/我的钱/公司在跑/裁决窗/组织）+ 今日要务四域态势 + 领域卡板 | **唯一门面**；不再造任何「首页/驾驶舱」变体（home.html 已退役为判例） |
| L2 功能总目 | `/portal`（动态） | 67 个入口的完整目录页 | 门面的下钻层，不承担首屏叙事 |
| L3 五域导航 | nav.js（真源 `api_common.DOMAIN_NAV_GROUPS`） | 量化 / 情报 / 创作 / 开发（含零界学院）/ 系统 五个下拉域 + 顶栏动线 | 改导航只改真源后重跑 `tools/export_nav.py`，禁手改 nav.js |
| L4 动线 FLOW | nav.js 顶栏金色药丸 | 晨报→盘前→信号→大屏→盘后→模拟仓→**绩效**（产线闭环，断一环即修复） | 新产线上线必须接进动线 |
| L5 领域专项页 | 15 页静态 + 60+ 动态端点 | 具体作业面 | 每页必须有 L3/L4/门面卡 三者之一的入口 |

## 二、页面准入五条（新页面/新端点过五关才能上线）

1. **入口关**：nav 登记（改 DOMAIN_NAV_GROUPS）或门面卡或动线——**无入口的页面不许上线**（六孤儿端点判例）；
2. **短屏关**：动态报告页走 `_html_file`（自动注入 shortscreen.js 锚点+折叠）；静态页直接引 shortscreen.js；首屏必须是结论，明细一律折叠；
3. **品牌关**：标题含「零界」，样式用 tokens.css 令牌（fallback 允许）；
4. **AI 关**：引 cainiao.js（全站标准 AI 入口，不自造对话窗——home.html 判例）；
5. **路由关**：新端点落九段对应域文件 + portal_api 分发 + `p4_ast_gate.py snapshot` 登记。

## 三、清理判据（判定「删 vs 留」的架构口径）

| 特征 | 判定 | 动作 |
|---|---|---|
| 零入口 + 零引用 + 无任务生成 | **死功能** | 摘路由 + 删函数（/bt/analysts、/bt-weak-md 判例） |
| 一次性事故/验证报告 | **归档件** | 报告 html 归档 docs/ops/，摘路由（/bt-stock-incident、/fut-strat 判例） |
| 活跃计划任务在生成、只是缺入口 | **活产线** | **不删**，补入口或挂快照页（/bt-tbe=TbeStats、/col-audit=AIColAudit 判例） |
| 同职能多入口 | **重复** | 保留主入口，其余降级或合并（四驾驶舱→门面+总目判例） |
| 运行日志/构建备份 | **不入库** | 回收站 + %TEMP% 备份（backups/*.bak、*.log 判例；git 历史兜底） |
| webroot 上的运行时数据 | **待治理** | 登记风险（B-06 json 泄露面），批量动 nginx 前先 `nginx -t` |
