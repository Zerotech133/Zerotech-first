## 二、信封结构（所有响应统一）

```json
{
  "schema_version": "1.0",
  "ok": true,
  "kind": "llm_chat",
  "data": { },
  "error": { },
  "degraded": false,
  "latency_ms": 123,
  "ts": "2026-10-21T12:30:00+08:00"
}
```

- `ok=true`：`data` 必有；`error` 必空
- `ok=false`：`error={code, message}`；HTTP 状态仍 200（400/404 仅限协议层错误）
- `degraded=true`：LLM 走了降级路径（如云端 glm 故障自动落本地 9b）——**结果仍可用**，但调用方应知晓质量档位变化

## 三、端点明细

### 3.1 POST /llm/chat —— LLM 调用（智能体化方案 L1/L3 底座）

请求：`{"binding": "ollama/qwen3.5:9b", "system": "你是意图分类器…", "user": "用户消息"}`

binding 词表（缺省 `ollama/qwen3.5:9b`）：

| binding | 用途 | 备注 |
|---|---|---|
| `ollama/qwen3.5:9b` | 主力/意图分类/摘要 | 全本地零成本 |
| `ollama/qwen3.6:35b-a3b` | 判读重档 | 慢（600s 档） |
| `glm/glm-5.3` | 参谋长云端判读 | 包年通道；故障自动降级本地 9b（degraded=true） |
| `openai/gpt-6.0` | 诸葛亮异族 | 运行时经 OpenClaw agent-config 载体（2026-10-26 实测可用；当前 DeepSeek 中转·非GPT6，GPT6 真身待跨境网络；env key 非前置，密钥在 OpenClaw secret store） |

响应 data：`{"binding_resolved", "text", "status"}`（status: normal/degraded）。
错误：`{"code": "llm_error", "message": "…"}` —— **调用方必须自备兜底**（如飞书侧回落正则/模板），军团不替外部做业务降级。

### 3.2 POST /inbox/submit —— 任务投递（智能体化方案 L4 派单通道）

请求：`{"kind": "task_request", "payload": {"q": "…"}, "source": "feishu"}`

kind 词表 v1：`task_request`（派单）/ `question`（咨询，含诸葛亮位路由预留）/ `feedback`（反馈投诉）。

响应 data：`{"id": "lg-xxxxxxxxxxxx", "replayed": false, "state": "inbox"}`

**幂等**：同 payload+source+kind 重复投递返回同 id（`replayed:true`），不重复落盘。要强制新单须显式换 payload 或自带 idempotency_key（`^[A-Za-z0-9_-]{1,64}$`）。

### 3.3 GET /inbox/receipt/{id} —— 回执查询

data：`{"id", "state": "inbox|processed|not_found", "record": {…原始记录}}`

军团消费侧把消息从 inbox 移到 processed 后，state 即变 processed——飞书侧轮询此端点即可拿到「工位已执行」回执。

## 四、错误码汇总

| code | 场景 | 调用方动作 |
|---|---|---|
| `llm_error` | LLM 通道不可用/重试耗尽 | 回落自身兜底（模板/正则） |
| `bad_kind` | inbox kind 不在词表 | 修词表后重投 |
| `bad_payload` | payload 非 dict | 修格式 |
| `bad_idempotency_key` | 幂等键非法 | 修格式 |
| `bad_request` | HTTP body 非 UTF-8 JSON | 修编码 |
| `not_found` | 路由不存在 | 检查端点拼写 |

## 五、纪律边界（对接方必读）

1. 本门面**只增不改**：字段只加不减不改语义；破坏性变更须升 schema_version 并保留 v1 兼容期。
2. 军团内部（engine/bridge_inbox/adapters）重构不通知外部——只要本契约不变，外部零感知。
3. 账本/勾稽/enforce 判定**不经本门面**（纯工程红线）；审批签准不经本门面（approval_gate 本人闭环）。
4. 挂常驻服务、开鉴权、扩 kind 词表 = 变更，走工单。
5. 最小 curl 例：
```bash
curl http://127.0.0.1:8795/health
curl -X POST http://127.0.0.1:8795/llm/chat -H "Content-Type: application/json" \
  -d '{"system":"意图分类","user":"帮我看下今天亏最多的票"}'
curl -X POST http://127.0.0.1:8795/inbox/submit -H "Content-Type: application/json" \
  -d '{"kind":"question","payload":{"q":"客户咨询"},"source":"feishu"}'
```
