## 一、数据能力的依据（每个数源的血统书）

**原则：分析结论的可信度 = 数据血统的可信度。无血统数据不进分析。**

| 数据能力 | 源 | 血统依据（2026-10-16 实测审计） | 可信级 |
|---|---|---|---|
| **K线图形** | Tushare 日线 → parquet | 600337 实测：845 日零空值、**OHLC 逻辑违例 0**、日期连续（1 个长缺口=春节）、每日 17:00 机械入库（无人工干预） | ★★★ 机器级 |
| **市场事件**（形态/量能/跳空） | KG 算子对 K 线的计算 | **派生数据**——由 K 线经固定公式算出（K266/KgDailySync 链），不是别人给的结论；判据公开可复算 | ★★★ 可复算 |
| **龙虎榜席位** | Tushare ts_top_inst → KG | **交易所法定披露**（沪深交易所公开数据），滞后 T+1，只覆盖涨跌幅/换手达标日——**庄游分析的法定证据，但只见到冰山一角**（大宗/北向/分单不在内） | ★★★ 法定 |
| **公告事件** | 财联社/新浪/东财 采集 | 多源交叉（news.db：sina 23065 + eastmoney 8837 + 公告 4957 条），公告为交易所强制披露 | ★★☆ 需去噪 |
| **新闻舆情** | 同上多源 | 传闻与事实混杂——**N1 人设的「传闻降权」纪律由此而来** | ★★ 需降权 |
| **知识图谱关联** | Neo4j 147 万节点 | 上述数据的组织层（谁连谁），血统=各源血统的交集 | 随源 |

**结论一句话：图形数据是全体系里唯一「机器级+法定级」双保险的硬数据——这就是为什么方法论必须图先行。**

## 二、「图先行·事佐证」漏斗范式（本档核心）

```
┌─────────────────────────────────────────────────┐
│ 第一层【图形推演】（唯一主线，硬数据）              │
│  K线结构：缠论中枢/笔/分型 + 量价关系 + 缺口        │
│  推演出"假设"：疑似有人在运作（吸筹/洗盘/出货/无为）│
└───────────────────┬─────────────────────────────┘
                    ▼ 带着假设去找证据（不再是漫捞数据）
┌─────────────────────────────────────────────────┐
│ 第二层【事件佐证】（证伪/证实假设）                 │
│  公告时间点 vs 图形异动点的耦合（先于公告=内幕特征） │
│  例：600337 的 9-21/22 放量拉抬 领先 9-28 公告 4 日 │
└───────────────────┬─────────────────────────────┘
                    ▼
┌─────────────────────────────────────────────────┐
│ 第三层【资金佐证】（法定证据）                      │
│  龙虎榜席位身份（游资🔥/机构/拉萨散户团）            │
│  买卖方向与图形阶段的匹配度                         │
│  例：10-09 天量长阴日=成都北一环卖 2720 万（出货实锤）│
└───────────────────┴─────────────────────────────┘
                    ▼
┌─────────────────────────────────────────────────┐
│ 第四层【庄游定性】（结论输出）                      │
│  三层同向 → 定性成立（如 600337=游资主导重整博弈）  │
│  三层矛盾 → 降级为"存疑"，只观察不定性              │
└─────────────────────────────────────────────────┘
```

**与旧范式的本质区别**：
- 旧（今晚群辩用的）：三线并列 → 各说各话 → D1 加权。**图形只是三票之一**
- 新（本档）：图形推演出**假设** → 事件/资金只做**佐证或证伪** → 结论的因果链完整
- **比喻**：旧范式是三个证人各自作证；新范式是法医验伤（图形）在先，人证物证（事件/资金）只回答"是否支持验伤结论"

### 图形推演层的关键算子（军团工具化清单）

| 算子 | 判据 | 佐证指向 |
|---|---|---|
| **放量吸筹** | 低位箱体 + 间歇性放量（量比 3-5x）+ 收盘不破箱底 | 有资金在建仓 → 查席位是否机构/游资 |
| **缩量洗盘** | 拉升后缩量回踩（量比<0.5）+ 关键位不破 | 庄家控盘度高 → 查是否无龙虎榜（分单隐藏） |
| **对倒出货** | 高位放巨量 + 长上影/阴线 + 次日不修复 | 疑似出货 → 查席位卖方身份 |
| **抢跑异动** | 无公告日的异常放量拉抬 | 内幕特征 → 事后核对公告日期耦合 |
| **无为自然** | 量价随大盘、无独立结构 | 散手票 → 不浪费事件/资金查证成本 |

## 三、落地改造（三处）

1. **xsec_profile v2**：输出从三线并列改为漏斗四层——图形层先出「运作假设」，事件/资金层输出「佐证/证伪/无关」三态结论
2. **五虎人设升级**：T1/T2 的辩论锚点改为"针对图形假设的攻防"（多头证吸筹、空头证出货），N1/F1 退居佐证席
3. **D1 裁决规则增补**：三层矛盾时必须输出"存疑"而非强行加权（宁可弃单不可硬判）

## 四、与「庄家识别」的关系（老田问题的直接回答）

**庄家是否在操作，永远不能靠单一数据断言**——法定席位数据只覆盖达标日（冰山一角），新闻有噪，只有图形是全时段硬数据。所以：
- 图形给出"运作嫌疑"（第一性判断）
- 事件耦合给出"内幕嫌疑"（时间证据）
- 席位给出"身份实锤"（法定证据，只在可观测日）
- **三层齐 → 定性；缺任一 → 存疑观察**。600337 是完整案例：图形（9-21 抢跑）+ 事件（9-28 公告耦合）+ 席位（开源西大街等 6 游资）三层齐 → "游资主导"定性成立。
