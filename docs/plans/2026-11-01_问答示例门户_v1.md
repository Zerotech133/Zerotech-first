# 问答示例门户展示 v1（2026-11-01）

> 任务单：task-26（wave9 · Z 问答示例门户展示）。上游：wave7 `tools/kb_corpus/kb_qa.py` 生成的门户静态样本 `portal/static/kb_qa_samples.json`。
> 本文档记录 `portal/kb_reports.html` 新增「💬 问答示例（静态）」区块的数据源、渲染字段、降级路径与验证。

## 1. 背景与目标

wave7 交付的问答示例只落在 `portal/static/kb_qa_samples.json`，门户未展示。本任务在研报知识库页 `portal/kb_reports.html`
**新增**一个静态展示区块，让用户不跑 CLI 也能看到「问答示例 + 引用（unit_id/页码）+ 置信标注」，同时明确
**HTTP 问答接口尚未接线**（待 8091 L2 审批，见 `docs/plans/2026-11-01_问答HTTP接线L2提案_v1.md`）。

约束：**不改动**既有「检索 v2 区块 / 学习卡 / 今日简报 / H18 观察 / 搜索框 / 使用提示」等结构，只做新增；
不改 `portal/static/kb_qa_samples.json`（只读消费）。

## 2. 数据流

```
tools/kb_corpus/kb_qa.py samples
        └─► portal/static/kb_qa_samples.json   （wave7 已生成，5 个示例，含 fallback/无依据演示）
                    │
                    │ fetch('/static/kb_qa_samples.json?ts=...')   （kb_reports.html 新区块，静态文件直读）
                    ▼
portal/kb_reports.html · 「💬 问答示例（静态）」区块
   ├─ 标题 + meta（模型/生成时间/示例数）
   ├─ 示例卡：问题、答案摘要（≤180 字）、引用（[unit_id] p.X）、置信标注（高/中/低/拒答）
   └─ 降级：fetch 失败或 samples 为空 → 文案；不影响本页其他区块
```

静态文件写盘即生效，无需重启 8091（nginx 直读 `portal/static`，fetch 带 `?ts=` 防缓存）。

## 3. 页面区块结构（新增部分）

```html
<div class="panel" id="qa-sample-panel">
  <div class="panel-head"><b>💬 问答示例（静态）</b><span class="sub" id="qa-meta">加载中…</span></div>
  <div id="qa-body"><div class="empty">加载中…</div></div>
  <div class="qa-note" id="qa-note">HTTP 问答接口待 8091 审批，当前为静态示例；…不构成投资建议。</div>
</div>
```

- 位置：插入在「📡 H18 业绩预告修订观察」之后、页脚之前，与既有面板并列（不改动原面板）；
- 样式：仅新增 `.qa-card/.qa-q/.qa-a/.qa-cites/.qa-cite/.qa-conf/.qa-note` 七条轻量 CSS，复用页面既有 CSS 变量与 `.panel/.card/.badge` 体系；
- 脚本：独立 `<script>` IIFE（自包含，不依赖既有 `$`/全局函数），`fetch` 失败 `catch` 降级。

## 4. 渲染字段（来自 `kb_qa_samples.json`）

| 展示项 | 字段 | 说明 |
|---|---|---|
| 问题 | `samples[].question` | 转义后展示 |
| 答案摘要 | `samples[].answer` | 截断 180 字（`slice(0,180)+'…'`），无答案显示「（无答案）」 |
| 引用 | `samples[].citations[]` 的 `unit_id` + `page` | 渲染为 `[unit_id] p.X`；无引用显示「无引用」 |
| 置信 | `samples[].confidence.level/reasons` | high→高置信（绿）/ medium→中置信（黄）/ low→低置信（红）/ none→拒答/无依据（蓝）；并显示首条置信说明 |
| 降级标记 | `samples[].fallback` | 为 true 显示「规则降级」红标 |
| 演示标记 | `samples[].category` 含 `simulated` | 显示「演示」灰标（无依据/失败模拟样本） |
| 顶部 meta | `model / generated_at / samples.length` | 模型 · 生成时间 · 示例数 |

## 5. 降级路径

| 场景 | 表现 |
|---|---|
| `fetch` 非 200 / JSON 解析失败 | meta「加载失败（降级）」；正文「问答示例暂不可用：<原因>。HTTP 问答接口待 8091 审批，当前为静态示例。」 |
| `samples` 为空数组 | meta「无数据（降级）」；正文「暂无问答示例数据（/static/kb_qa_samples.json 为空）。…」 |
| 本页其他区块 | 完全不受影响（脚本独立 IIFE + try/catch，不修改既有 DOM/全局） |

## 6. 能力边界

1. **静态示例，非实时问答**：页面只展示 wave7 生成的 5 个样本（3 个真实 LLM 回答 + 1 无依据拒答演示 + 1 失败降级演示），不支持页面内提问；
2. **HTTP 接口未接线**：`/api/kb/qa` handler 已预接线（`portal/api_kb_qa.py`，`WIRED=False`），待 8091 重启审批（L2 五要素提案）批准后才可用；页面已注明；
3. **数据新鲜度**：依赖 `kb_qa.py samples` 重新生成 JSON；本次**未修改** static JSON；
4. **准确性**：回答为 LLM 依据知识库材料生成，引用经 unit_id 校验，但仅供参考、不构成投资建议；候选/回答需人工复核。
