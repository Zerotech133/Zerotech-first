# 课程语料采集与评论舆情方案（2026-10-18）
> STATUS: pending_approval（owner: TBD；2026-11-07 前拍板）



## 0. 背景与目标

- 现状：`res-downloader-py` 已收敛为全球金融数据目标（327 条规则，聚焦行情/交易所/链上），捕获维度为 video/audio/image/m3u8 媒体文件。
- 意图转变（用户 2026-10-18 指令）：
  1. **弱化行情涨跌/亏损类数据的扩增**，转向「讲理论、讲知识的课程视频 + 图片 + 推文」的采集与整理，为训练模型沉淀语料，形成新方案。
  2. **评论用于舆论走向与热点分析**，以 X(Twitter) 为主，接入现有 JEV 舆情链路（`news_collector/jev_feed.py`、`news_ai.py`、`jev-eval/jev_drift.py`）。
- 已确认口径：交付物 = 完整方案文档（确认后再落地）；课程 = 海外为主（YouTube/X 交易金融理论课）；推文/评论 = X(Twitter) 为主；评论分析 = 接入现有 JEV 链路。

## 1. 资源整理：课程/知识视频、图片、推文

### 1.1 现有能力与局限（res-downloader）

- 命中域名的 HTTPS 请求才做 MITM；`classify_response()` 按 Content-Type 分为 video/audio/image/m3u8，资源入池去重（`md5(url)`）。
- **局限**：只能捕获媒体文件；网页文本（课程讲义、推文文本、评论回复）不在当前分类内，需新增通道（见 §2）。

### 1.2 规则整理建议

- **保留**：现有 327 条行情/宏观/链上基础规则原样保留（作为市场上下文），**仅停止扩增**行情涨跌/亏损预警类站点。
- **新增「海外课程与理论内容」类别**（候选域名，落地时逐条去重验证）：
  - YouTube 系：`youtube.com`、`youtu.be`（交易/金融理论视频主阵地）
  - X/Twitter 媒体：`x.com`、`twitter.com`（推文配图与视频，经 MITM 捕获媒体文件）
  - 垂直教育/理论站：`investopedia.com`、`coursera.org`、`udemy.com`、`khanacademy.org`
  - 财经理论博主/机构：`econlib.org`、`nber.org`、`stlouisfed.org`（FRED 已在），及主流财经媒体视频（wsj.com/bloomberg.com 已在）
- 落地方式：`app/config.py` 追加（带类别注释）→ config.json 同步 → POST /api/config 热更新 → `should_intercept` 断言 → README 同步 → 提交（沿用现流水线）。

### 1.3 语料整理与目录规范（设计）

- 语料根目录建议：`C:\项目\老田的AI助手\quant_backtest\data\corpus\`（**待拍板**，见 §5）。
- 分桶：`courses_video/`（课程视频）、`theory_audio/`（音频）、`charts_image/`（图表/图片）、`tweets_text/`（推文）、`comments_text/`（评论）。
- 去重：沿用 `md5(url)`；文本类升级为 simhash 近似去重（对齐 K-ORG-159 计划，解决同题异源转载）。
- 溯源：每个桶配 manifest（JSONL：url/来源/抓取时间/内容 hash/分类），对齐 K-ORG-161 报告引用溯源规则，保证训练数据可溯源可回滚。
- 视频字幕/音频转写（whisper 类）：**设计期仅预留，落地排 P4**。

## 2. X(Twitter) 推文与评论采集方案

### 2.1 通道选型

| 通道 | 能力 | 结论 |
| --- | --- | --- |
| A. MITM 代理（res-downloader 现有） | 只能捕获 X 媒体文件（图片/视频） | 媒体走此通道 |
| B. X API v2（search recent / replies） | 推文文本、回复评论、话题标签 | **文本/评论走此通道**，需 API Key（待拍板） |
| C. 网页解析 + 登录态 | 可行性低（X 强反爬） | 不采用 |

结论：**媒体经 res-downloader MITM，推文/评论文本经独立 X 采集器**（命名遵循 atom 规范候选：`atom-x-collector`）。

### 2.2 评论/推文入链设计（接入现有 JEV 链路）

复用 `jev_feed.py` 接入模式，新增数据源 kind：

- 采集器输出对齐 news 行格式：`title / url / pub_time / stocks(自选股命中) / content(文本)`
- 写入 `news.db` news 表：幂等 ID `xd:<kind>:md5(url)`（kind 候选 `xd_x_post` / `xd_x_reply`，source=`xd_x`）
- 逐条过 JEV 本地模型判定写回 `jev` 列 → 复用下游 pushed/digested/摘要管线，无需改动
- 水位/回退窗口：对齐 `jev_feed` runs 表水位机制，单轮截断水位不动

### 2.3 舆论走向与热点分析

- **情感极性时间序列**：按小时/日聚合 JEV 判定结果 + 置信度加权（沿用低置信过滤阈值 0.7、时效衰减半衰期 6h，对齐 K-ORG-158 定案口径）。
- **热点识别**：标题/正文关键词、实体、话题标签聚合；候选方案 = 复用 KG 社区聚类经验（SIMILAR_K Leiden 397 社区先例）或先上 TF-IDF 话题桶。
- **漂移监控**：复用 `jev-eval/jev_drift.py`（周窗口 JS 散度），扩展按话题/情感维度监控。

## 3. 训练模型语料方案

### 3.1 语料构成

| 分桶 | 来源 | 用途 |
| --- | --- | --- |
| courses_video / theory_audio | YouTube 等海外课程 | 理论/知识注入（字幕/讲义文本） |
| charts_image | 课程图表/媒体配图 | 图表理解 |
| tweets_text | X 推文 | 观点/信号语料 |
| comments_text | X 回复评论 | 舆论走向/热点识别模型训练 |

### 3.2 整理与标注

- 清洗：simhash 去重、去广告/无意义回复噪声、语言分桶（英文为主 + 中文评论分桶）。
- 标注：三轴标注「内容类型 + 主题 + 方向（对市场/事件）」，规则预标 + 人工抽查。
- 存储：JSONL + 分桶目录 + manifest（§1.3）。

### 3.3 训练用法（设计）

- 课程语料 → 理论理解知识注入；推文+评论语料 → 舆论走向与热点识别（对接 JEV 判读升级）。
- **本期只沉淀数据与管道，模型训练另立工单**。
