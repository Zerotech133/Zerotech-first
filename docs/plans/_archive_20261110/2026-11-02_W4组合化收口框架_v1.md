#### 2.1.3 变更流程（冻结后）

1. **分类**：四形态判定（`PLATFORM_FRAMEWORK_v1:131-138`）；内核变更 = 改 schema/状态机/信封/口径/门禁；
2. **ADR**：一变更一 ADR（问题/方案/替代/回滚/兼容矩阵）；紧急 hotfix 可先合、24h 内补 ADR（门禁记 emergency 标记）；
3. **审批**：ARCH1 预审 + A0 批准；major（不兼容）A0+ARCH1 双签；例外走 ADR-017 流程（ADR + A0 + 临时 adapter + 90 天回归）；
4. **门禁**：`kernel_guard.py --files <changed> --commit-msg "<ADR 号>"`，无 ADR 拒收（`devtask merge`/`merge_preflight` 已接线 fail-closed）；
5. **同批**：版本 bump（patch/minor/major）+ sha256 更新 + 组合兼容矩阵回归，同一提交完成；禁止"先改后补 hash"。

#### 2.1.4 兼容策略

- **版本语义**：`kernel_version` = MAJOR.MINOR.PATCH；patch=文档/口径澄清（无 artifact 语义变化）；minor=向后兼容新增 artifact/字段；major=不兼容变更（双版本并存 ≥90 天 deprecation，`kernel_v1.yaml:18`）。
- **组合兼容矩阵**：冻结时逐组合执行 `validate` + 组合专属测试群（见 §2.2.4），记录"组合 × kernel v1.0 = PASS/条件/WARN"；组合 `spec.kernel` 区间必须命中 `1.0.0`（当前 6/6 为 `>=0.9 <2.0`，命中）。
- **实现可替换**：模型/数据源/通道/运行器/前端壳不在内核（`kernel_v1.yaml:19` forbidden），替换走 adapter/manifest 引用 + 契约测试（T3）。
- **冻结边界**：kind=schema/contract/gate/baseline 全冻；registry 类按登记格式冻结（内容可更新，格式不可变）；store/impl-ref 不冻结但变更须回归测试（`kernel_v1.yaml:260`）。
- **降级/回滚**：v1.0 冻结回执保存 kernel_v1.yaml 与逐 artifact sha256；回滚 = 恢复 frozen 基线文件 + `kernel_guard.py --verify` 确认 + 通知组合 owner；重大缺陷可 `status: degraded`（不删历史，ADR 记录）。
