# 知识采集与提炼功能 · 采集方案（2026-10-18）
> STATUS: declared



## 0. 功能定义

一个功能（候选名 `atom-knowledge`）：**知识采集与提炼**。两个入口、一条管道：

```
入口1 自主发现（规则域名 MITM 嗅探，课程类规则自动捕获）
入口2 批量链接（控制台/API 批量提交 URL 清单）
        │  合并为统一任务队列（md5(url) 去重 + 幂等）
        ▼
采集层：MITM 媒体捕获（res-downloader 现有）＋ 页面正文抓取（新增）
        ▼
提炼层：文本 → 知识条目（标题/正文/摘要/关键词/知识点）
        ▼
产出：语料桶 corpus/ 分桶 ＋ manifest.jsonl（可溯源）
```

- **入口统一**：自主发现与批量提交汇入同一任务队列，共用去重/幂等逻辑。
- **采集与提炼解耦**：采集层只管拿原始资源，提炼层只管出知识条目，以目录 + manifest 衔接。
- **落点（已确认）**：扩展现有 res-downloader-py（已有 MITM 捕获/下载器/Web 控制台/热更新，最快闭环），不新起服务。
- **MVP 范围（已确认）**：文本提炼先行（标题/正文/摘要/关键词）＋ 媒体原始文件归桶；字幕转录/OCR、X API 采集、JEV 入链、模型训练全部后置。

## 2. 数据格式

- 任务队列条目：`{url, source: "user"|"discover", ts, status}`
- manifest 行（JSONL）：`{url, source, ts, bucket, hash, title, summary, keywords, media_type}`
- 分桶：`courses_video/` `theory_audio/` `charts_image/` `page_text/`
