## 0. 一句话

给缠论引擎装一个**只看不动手的脑子**：每天把影子买卖点记进缠论分析师自己的记忆，
T+N 天后用真实行情对账打分，按「买卖点类型 × 级别 × 市场状态 × 结构指纹」归因出
*哪类信号在哪种环境下可信*，把结论写成灰度权重草案与署名理论笔记——
草案永远只是建议（draft），采纳（adopt）永远人工凭据，交易永远不碰（影子铁律）。

## 2. 设计原则（红线先行）

1. **影子铁律**：学习环全链只读行情、只写记忆与草案，**不产生任何交易指令**；
   权重草案不直接进生产参数（perf_ledger 判例平移：draft 建议权 / adopt 人工凭据）。
2. **append-only 时态记忆**：当时的判断永远保留原始版本（memory.py 既有语义），
   学习=追加修正记录，不覆盖历史。
3. **完整分布落盘**：每条信号判定带 conf 分解（背驰/共振/多枢三项）与灰度置信度，
   对账行带 T+5/10/20 三档后验——单一置信度不留盘（JEV K-ORG-176 判据平移）。
4. **小样本不凭据**：任何归因结论、降置信建议须样本 n≥30；权重调整单次幅度
   ≤±0.05，影子对照 ≥20 交易日才可提请 adopt。
5. **判例循先例**：账本幂等=perf_ledger perf_key 范式；评价=evaluate_incremental
   范式；归因读侧=tgraph/signal_precedents 既有接口，不新建平行统计。

## 3. 四阶段学习环架构

```
        ┌────────────────────────────────────────────────────┐
        │   缠论分析师（Hermes 智能体，席位号建议 ST1）          │
        │                                                    │
        │  L4 修正 ←── L3 归因 ←── L2 验证对账 ←── L1 观察     │
        │   │                                  ▲             │
        │   │ 权重草案(draft)                    │ 影子信号流    │
        │   ▼                                  │             │
        │  [人工 adopt→灰度参数]    chanlun_daily_ledger       │
        │  [署名理论笔记→知识库]    chanlun_gray conf 分解     │
        └────────────────────────────────────────────────────┘
```

### L1 观察（每日收盘后，append-only）

- **入参**：当日影子账本信号流（chanlun_daily_ledger 的 sig_buy/sig_sell，
  seen-ever 口径、hfq）+ 灰度 enrich 字段 + 当日 regime 档位（池指数 MA20/MA60）。
- **落盘**：两条腿
  - 学习环账本 `quant_backtest/data/chanlun_learn/ledger.jsonl`——一行一信号：
    `{sig_id, dt, code, type(1买/2买/3买/1卖/2卖/3卖), level, regime,
    fingerprint{bis6,amp,pv,npv}, conf, conf_parts{beichi,vv,multi_hub},
    entry_px, declared_at}`；sig_id = sha1(code|type|dt)[:16]（perf_key 同范式幂等）。
  - 智能体记忆 `agent/ST1/observation`（MemoryStore 追加）——同数据的
    自述版，附一句当日观察语（如「三买 600xxx：多枢第 4 枢，conf 0.53 偏低」）。
- **不写**：任何持仓/交易表。

### L2 验证对账（T+5/10/20 三档，随行情入库触发）

- 对每条 L1 行按 horizon 补后验：`ret_pct`（信号日收盘→T+N 收盘，hfq），
  卖点信号记反向口径（看跌是否兑现）。
- 账本 `chanlun_learn/verify.jsonl`，键 = sha1(sig_id|horizon)[:16]，
  **同键同值重放零副作用、同键异值拒绝**（perf_ledger M0 契约平移）。
- 同时落**分布摘要**：分档命中率、均值、左尾 p10/worst、样本 n——
  供 L3 与人读日报，避免只有单一均值。
- 调度：挂现有日链（影子链 17:10 窗口后追加一步），行情未入库自动顺延，
  不重试轰炸。

### L3 结构归因（每周聚合 + 触发式）

- **维度矩阵**（全部复用既有统计位，不新造）：
  买卖点类型（6 类）× 级别（笔/段，由 tgraph bis6 取值）× regime（high/mid/low）
  × 结构指纹（tgraph_fps 精确分组）× conf 分档。
- **读侧接口**：tgraph_slots（槽位边际战绩）、tgraph_fps（指纹分组）、
  tgraph_left_tail（左尾深度）、signal_precedents（同型先例 topk）——
  学习环只做「组合这些接口 + 写结论」，不重复造统计。
- **产出**：`chanlun_learn/attribution.jsonl`（append-only），每条形如：
  `{as_of, cell="3买 × low_regime × npv≤2", n, win, avg, p10,
  verdict="失效观察", evidence=[tgraph 行引用]}`。
- **判读规则（可回放、显式阈值）**：
  - n<30 → 只记 observation，不出 verdict（小样本不凭据）；
  - n≥30 且 avg<0 且 p10≤-10% → verdict="降置信候选"；
  - n≥30 且 win 较全域基线 +10pp 以上 → verdict="升置信候选"。

### L4 修正（两个出口，都是建议权）

**出口 A · 灰度权重草案（draft）**
- 可学习权重位 = chanlun_gray `_conf` 三参数：背驰加分（现 0.15）、
  共振加分（现 0.10）、多枢衰减（现 0.85）。
- L3 的降/升置信候选触发草案：`chanlun_learn/drafts/<ts>_<sig指纹>.json`，
  含 `{param, from, to, cell, n, rationale, shadow_until}`；单次幅度 ≤±0.05。
- 草案生效路径：**影子对照跑 ≥20 交易日**（草案参数 vs 现役参数双跑，
  council_sim 对照打分范式）→ 对照报告呈老田 → **人工 adopt** → 才改
  chanlun_gray 正式参数（同一工单提交，注明采纳依据工单号）。
- 学习环代码层**不提供**任何直改生产参数的函数。

**出口 B · 理论输出（署名口）**
- 每日：L1/L2 显著事件（conf 与先例背离、左尾触发、同型信号连败/连胜）
  写 `agent/ST1/thesis` 记忆 + 短评（缠论分析师本人名义，带证据引用）。
- 每周：聚合周记《缠论结构观察》——结构演化、哪类买卖点在本周市场状态下
  可信/失效、下周关注，落 `docs/` 或经既有推送链（卡片走 v3 规范）。
- 理论演进档案：对缠论规则本身的修正观察（如「三买在 low regime 失效率」）
  单独入 `dept/invest/thesis`，供 DEV3/STRAT1 与 council 复盘归因引用
  （K70 来源标签全链贯穿）。

  全部带 evidence 引用与 n 值；L4 草案文件必须含 shadow_until。
