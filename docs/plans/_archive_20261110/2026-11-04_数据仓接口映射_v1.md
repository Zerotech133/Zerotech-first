## 三、`tools/composition.py` 解析改造（ADR-019 D5/P5）

### 3.1 改动

- **原**（启发式）：`kind == "pg"` → `return token.startswith("v2_")`（按命名约定软过，无证据）。
- **新**（registry 证据）：`load_registries()` 增加 `pg_registered` 证据索引（只读、不 import 注册模块、不连 PG）：
  1. `tools/datawarehouse/dataset_registry.py` 的 `PG_WAVE1_TABLES`（**AST 静态读取**，避免 99KB 模块重依赖/副作用）；
  2. `tools/datawarehouse/dataset_refs_declared.json` 的 `canonical_ref=dataset/pg/*`（如 recommendation_pool→v2_acad1_pool）。
  - `resolve_ref`：`dataset/pg/*` 命中 registry → 解析；未命中 → **soft warning**（`dataset/pg 未在 registry 登记（soft warning；ADR-019 P5 过渡期，严格化后 block）`），**不 error**、不 strict block。
  - `_dataset_exists` 的 pg 分支改为 registry 命中判定；file/dir/registry 分支行为不变。
- **wave2 动态发现**（`public.v2_%` 全量）：依赖 `ZHICE_V2_DSN`，由 `tools/datawarehouse/dataset_registry_cli.py resolve-ref` 解析；composition.py **不连 PG**，故 wave2 表在登记/DSN 就绪前保持 soft warning（严格化时机见 §六）。
- 未改：planned_refs 优先逻辑、strict 语义（strict 仍把 warning 计 error）、validate/plan 退出码、`--json` 输出结构。

### 3.2 对账命令（只读）

```text

  -> dataset_id=pg_public_v2_acad1_pool（命中）
```
