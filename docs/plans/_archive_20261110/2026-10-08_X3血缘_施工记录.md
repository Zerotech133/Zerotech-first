## 2. 助手模块 linreg.py（新文件，148 行）

`quant_backtest/linreg.py`，`py_compile` 通过（Python 3.11 产线解释器，`C:\Program Files\Python311\python.exe`，psycopg2 2.9.13 沿既有依赖，**未引入任何新 pip 包**）。

- `JobRun(job, step)` 上下文管理器：`__enter__` INSERT job_run(status='running') 取回 id；`edge()` INSERT lineage_edge；`schema()` 列清单 sha1 变更才出新 version；`__exit__` UPDATE status/ended_at/rows_written。
- best-effort 纪律：所有 DB 调用经 `_silent` 包裹，任何异常吞掉落 `logs/lineage_err.log`，`__exit__` 返回 False 不吞业务异常；连接惰性建立（`import linreg` 零副作用，实测确认）。
- 连接：环境变量 `LINEAGE_DSN` 优先；缺省 `host=127.0.0.1 port=5442 user=quant_user dbname=quant_system` + `LINEAGE_PASSWORD` 补充。git_sha 取 quant_backtest 目录 `git rev-parse --short HEAD`。
- 插桩调用模式：**纯插入行，不重缩进、不改任何既有逻辑行**——入口 `_jr = linreg.JobRun(...).__enter__()`，出口 `_jr.__exit__(None, None, None)`，dryrun 提前 return 处补一次 exit（该次运行 status='ok' 不产边）。
- 施工期间修复一处自身 bug（`_q` 的 sql/args 参数误打包为单 tuple，冒烟首轮捕获，已修复并复测）。
