## 三、研发原则（执行纪律）

1. **历史数据前移**：可回放的数据类验收、查询、回测、快照对照，立即用历史数据验证并前移开发；实时任务（首跑/看门狗/调度）不替代。
2. **只读优先**：数据仓对业务/智能体一律只读；写回仅通过 staging+审核（L2）。
3. **证据包**：每项任务 = 命令 + rc + 产物 + 验收勾选 + 回滚 + owner。
4. **车道与 WIP**：标准道/治理道/L2 道分离；单人并行写 ≤2；共享文件单一 owner。
5. **窗口保护**：09:00 终验、11-05 窗口前后冻结主链；优化只动旁路/只读。
6. **小白天条**：用户界面零英文、中文优先；技术标识不进页面。
7. **智能体底座**：Hermes 只拿「嘴和手」（会话/编排/工具面），判定权留在仓内确定性工具。
