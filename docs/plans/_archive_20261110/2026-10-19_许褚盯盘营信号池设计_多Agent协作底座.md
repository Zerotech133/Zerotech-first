## 1. 信号池是什么（定位）

**营级共享账本**，插在"盯盘 Agent 产生信号"与"QUANT_UPSTREAM_REPORT 上行司马懿"之间：

```
盯盘 Agent ×N（许褚 + 未来营员）
     │  各自产生 ANOMALY / HEALTH 信号（必须绑冻结证据）
     ▼
┌─────────────────────────────┐
│  信号池（盯盘营共享，append-only）   │  ← 去重 / 生产者署名 / 状态机 / epoch 撤销
└─────────────────────────────┘
     │  营部上行官从池中按事件逐一取号
     ▼
QUANT_UPSTREAM_REPORT（单一上行路，RouteOutbox 不变）
     ▼
司马懿侧受理（W-Q1 UpstreamInbox，QS1 席）
```

要点：
1. **池不替代上行路**——它聚合信号、管去重与状态；上行仍逐事件走既有 `RouteOutbox`，语义（凭证时间窗/UNKNOWN 终态/epoch）零改动。
2. **池是营的资产**（盯盘侧），不是司马懿侧的——司马懿侧只有受理台账（W-Q1）。三层账各归其主：证据账+影子账（既有）+信号池（新增）归盯盘营；受理账+三路分发账归量化板块。
3. **信号必须绑冻结证据**：入池前置校验 `evidence_ref`（envelope_hash + version）在 EvidenceStore 中已冻结且未撤销，否则 `EVIDENCE_NOT_FROZEN` 拒收——池里不许有裸信号。

## 2. 契约草案

```
SignalPoolEntry := {
  signal_id,                     # 营内唯一
  producer_agent_id,             # WATCH 角色 AgentIdentity（W-Q0 已有校验件）
  report_kind,                   # ANOMALY | HEALTH（沿用 _KINDS）
  event_id, evidence_hash, evidence_version,
  created_at,                    # UTC 带时区
  status,                        # OPEN → CLAIMED → ACCEPTED；任一态可 REVOKED
  epoch                          # 撤销只进不退（对齐 RouteOutbox 语义）
}
```

不变量：
1. **append-only + 状态机单向**：OPEN→CLAIMED→ACCEPTED；REVOKED 可从任何态进入且不可逆；epoch 只进不退。
2. **去重**：同 `(event_id, evidence_hash)` 重复入池返回既有条目（幂等）；同 `event_id` 异证据 → `SIGNAL_CONFLICT` fail-closed。
3. **多 Agent 同事件**：第二个 Agent 报同一事件 → 新条目标 `co_signed=<首报 signal_id>`，**不合并、不覆盖**——保留各自视角与贡献明细（对齐选股线"贡献保留明细"判例）；是否视为同一信号由司马懿侧受理时裁决，池不裁决。
4. **取号租约**：上行官 `claim(signal_id, lease_until)`；租约过期自动回 OPEN（不产生 UNKNOWN——那是上行路 outbox 的事，池只管营内）。
5. **上行闭环回写**：outbox 回执 ACCEPTED_VERIFIED → 池内条目 ACCEPTED；UNKNOWN/DEFINITELY_REJECTED → 条目回 OPEN 待重试（重试上限仍由 outbox 管）。
6. 恒离线：无网络、无执行语义；条目无 order/fill/pnl/authorization 字段（与影子账同款洁癖）。

## 3. 多 Agent 协作（未来扩展，现在只留缝）

1. **编制**：盯盘营 N 席，每席一个 WATCH AgentIdentity，独立注册（registry 多条目）、独立 `resolve()`；池按 `producer_agent_id` 署名。
2. **分工**（分区盯守/分主题/分时段）属营内调度策略，**不进池契约**——池只保证"谁报的、报的什么、重复怎么办"，分工方案未来另立工单。
3. **N=1 与 N>1 行为完全一致**：今天许褚一营，契约按多生产者设计；扩编只是注册表加条目，池代码零改动。
4. **身份有效期**：沿用 AgentIdentity `valid_until`；过期生产者入池被拒（`AGENT_NOT_CURRENT`）。
