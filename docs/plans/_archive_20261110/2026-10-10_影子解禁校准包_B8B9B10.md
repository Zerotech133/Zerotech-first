## B10 — 收敛双条件（假收敛：立场塌缩被误判共识）

**根因**：`agent_platform/engine/interpreter.py` L194/207 `converged = sim > SIM_CONVERGE(0.8)` 单条件——倒戈→立场词趋同→sim 飙升，601318 末轮 0.78 已贴阈值，塌缩会被提前终止辩论。

**改法**（解禁日实施）：

```python
_STANCE_BULL = ("看多", "看涨", "做多", "买入")
_STANCE_BEAR = ("看空", "看跌", "做空", "卖出")

def _stance(text: str) -> str:
    """first-match 立场词（对齐 N3 修后 a0_chief 口径）。"""
    for w in _STANCE_BULL:
        if w in text[:60]:
            return "bull"
    for w in _STANCE_BEAR:
        if w in text[:60]:
            return "bear"
    return "neutral"

def _converged(a_text: str, b_text: str, sim: float) -> tuple[bool, bool]:
    """双条件：sim>0.8 且 双方立场仍对立。返回 (converged, collapsed)。"""
    if sim <= SIM_CONVERGE:
        return False, False
    sa, sb = _stance(a_text), _stance(b_text)
    if {sa, sb} == {"bull", "bear"}:
        return True, False
    return False, True   # 塌缩：不放行收敛，trace 标记
```

- interpreter 辩论循环两处 `converged = sim > SIM_CONVERGE` 改用 `_converged`；collapsed=True 时 trace 的 status 记 `collapsed`（照常跑满轮次，不提前终止）。
- `a0_chief.py` 相似度警戒（sim≥0.7）保留；日报追加「塌缩检出 N 次」行。

**验收门**：重放 601318 历史样本，期望末轮 sim≥0.8 但 collapsed=True、辩论跑满轮次；sim 真收敛（立场对立）样本提前终止行为不变。
