## 2. H37 银行政策脉冲

### 2.1 事件（事实，PDF1 原文要点）

- 来源：《银行行业简评》东海证券 2026-09-30（p1「投资要点」），行业评级 **标配**。
- 2026-09-29 央行调整完善若干货币政策工具（原文）：
  - 一年期 **PSL 利率下调 25bp 至 1.50%**，支持范围扩大至水网、新型电网、算力网、新一代通信网、城市地下管网、物流网等**「六张网」**；
  - **科技创新和技术改造再贷款额度增加 2,000 亿元至 1.4 万亿元**，资金支持比例由 **60% 提高至 100%**；
  - **支农支小再贷款额度增加 5,000 亿元**，其中民营企业再贷款额度增加 3,000 亿元至 1.3 万亿元；
- 同日财政部/央行/金融监管总局发布**居民购房贷款贴息**：自 10-01 起，对符合条件的新发首套商业性个人住房贷款给予**年化 1 个百分点、最长 5 年**的财政贴息，**单户贴息贷款规模上限 100 万元**；聚焦总价 150 万元以内、面积 120 平方米以内住房（p1）。
- 报告判断（事实层）：政策着力点由「降低资金价格」延伸至「改善银行投放积极性」；信贷边际改善值得期待，对公中长期贷款确定性相对更高；房贷贴息对银行按揭业务比直接降息更友好；对银行经营整体偏正面，息差影响以结构性缓冲为主（p1–2，表 1 于 p2）。

### 2.3 传导链（三段，逐段可证伪）

```
[政策包：价↓（PSL/再贷款利率）、量↑（再贷款额度）、财政分担（贴息）]
  │ ① 对公链
  ▼
六张网项目（水网/新型电网/算力网/新一代通信网/城市地下管网/物流网）
  → 政策性金融+项目资本金+配套融资 → 施工/设备企业流动资金需求
  → 科创技改再贷款支持比例 60%→100%（降低资本占用成本）→ 已有授信/项目加快提款
  → 银行对公中长期贷款投放条件改善（量）；优质项目定价被 PSL 降息压低（价）
  │ ② 零售链
  ▼
首套商业房贷贴息（年化 1%×最长 5 年、单户≤100 万、总价≤150 万/120㎡）
  → 居民实际付息下降 → 按揭申请与新发放改善（量）
  → 但二手房交易伴随卖方结清存量按揭 + 正常还本/提前还款 → 按揭余额净增量待观察
  │ ③ 银行量价质 → 板块预期
  ▼
投放条件改善 + 财政分担降低「压合同利率刺激需求」的必要 → 息差结构性缓冲
  → 板块对「信贷需求/盈利稳定性」的预期修复（估值/相对收益），而非当期 EPS 兑现
```

**关键区分（供 STRAT1 复核）**：本假设赚的是「预期修复」而非「业绩兑现」；若把政策解读成当期息差改善，即为错误口径（PDF1 明确「低成本资金红利仍可能在同业竞争中向客户让渡」）。

### 2.6 证伪条件（预注册，任一触发即降级/撤回）

- **F1（主判据证伪）**：T0+20 日板块 CAR[0,20] ≤ 0，或 CAR[0,20] > 0 但成交额占比 < 1.1×——「预期修复」不成立。
- **F2（对公段证伪）**：T0+60 日内，月度新增企业中长贷同比**连续 2 个月为负**，或 PSL 余额继续缩量 → 传导①不成立。
- **F3（零售段证伪）**：月度新增居民中长贷同比连续 2 个月为负，且 30 城成交面积（代理）未改善 → 传导②不成立。
- **F4（归因证伪）**：板块相对收益为正，但（a）对红利因子回归后 alpha≈0，或（b）同窗口非银行行业等权组同样上涨且幅度相当（>80% 由全市场 beta 解释）→ 仅登记为「beta/红利拥挤」，不登记为政策假设的 alpha。
- **F5（事件类型证伪）**：政策被后续收紧对冲（再贷款额度回收、贴息提前退出、PSL 再缩量并伴随项目暂停），或出现监管转向 → 事件类型失效。

### 4.6 证伪条件（预注册）
