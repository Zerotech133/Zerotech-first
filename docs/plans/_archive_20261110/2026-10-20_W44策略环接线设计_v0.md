## 一、目标与边界

策略环（W44）产生的 signal 需要进入 OS：落决策账、并按需触发 8097 通知链。本设计稿定义**批准后的接线点位与阻断点**，回答三个问题：

1. signal 从产生到通知，依次经过哪些点位；
2. 每个点位依赖什么、被什么阻断；
3. 如何保证"影子比对通过才正式"。

**边界**：本文档不涉及策略环内部逻辑（signal 怎么产生是军团/策略侧的事），只定义 signal 出策略环之后的 OS 侧接线。

## 二、接线链路总览

```
[策略环 W44]                    [OS 侧]                          [出口]
signal 产生 ──(点位①)──► W43 唯一入口 ──(点位②)──► 决策账落账 ──(点位③)──► 8097 通知链
   │                      （意图识别/                  （影子模式先     （按域模板/
   │                       白名单校验/                  行，比对通过     分域闸门）
   │                       订阅校验）                   再切正式通知）
```

四个点位，串行依赖：①不通②不启，②不通③不启。

## 三、点位明细与阻断点

### 点位①：signal 产生 → W43 入向

| 项 | 内容 |
|---|---|
| 做法 | 策略环按受控回写契约信封（见 `2026-10-20_I5军团受控回写契约设计_v0.md`）封装 signal，投递 W43 唯一入口，`domain` 一级路由至策略域 |
| 依赖 | 受控回写契约议定（信封 schema + 席位白名单）；W43 受理器扩展策略域意图类别 |
| **阻断点 A：门②口径** | signal 的**格式与语义口径**（字段、粒度、去重键、时效性）须经荀攸 M0 门②批准。门②未批 → 信封格式冻结不接线，策略环 signal 仅在军团侧自持留痕，不投递 |
| 失败语义 | W43 拒收显式回执（原因码），策略环侧有界重试；closed on failure，不造数 |

### 点位②：W43 受理 → 决策账落账

| 项 | 内容 |
|---|---|
| 做法 | W43 受理通过后，signal 连同审计五元组（actor/source/action/target/reason）落决策账；裁决口径按受控回写契约 §五 |
| 依赖 | 决策账表结构与 DD-5 OS 入口口径；受控回写契约审计段落点议定 |
| **阻断点 B：门③** | 门③（决策账落账口径：哪些 signal 级别落账、影子期数据是否入正式账）未经荀攸 M0 批准 → signal 只记 W43 受理日志，**不入决策账正式表**（可入影子表） |
| 不建第二账 | 决策账是唯一落点，W43 受理日志只是受理证据，不替代决策账 |

### 点位③：决策账 → 8097 通知链

| 项 | 内容 |
|---|---|
| 做法 | 影子比对通过、正式切换后，命中通知条件的决策账记录触发 8097 出向（分域闸门+按 kind 卡片模板），通知相关方 |
| 依赖 | 8097 唯一出口既有设施（计量/静默/blocked/分域闸）；P1 卡片差异化模板 |
| 阻断点 | 继承门②③；另有：影子比对未通过 → 通知永远不触发；客户域信号受订阅闸约束（P2 FC-C 口径，enforce 待批） |

## 四、影子比对（P3 验证口径）

- **影子模式**：门②③批准后先跑影子——signal 全链走①②，但③的通知触发关闭，落账进影子表；
- **比对内容**：signal 触发率、误报率、与既有预警通道的重合度、W43 受理拒绝率、限频命中数；
- **切正式条件**：比对结果经荀攸确认后另批切换，切换动作本身也是一次审批，不自动切；
- **影子期纪律**：影子数据显式标注 shadow=true，不进正式决策账、不触发任何对人的通知（避免影子期误扰）。

## 五、依赖与阻断点汇总

| 阻断点 | 内容 | 批准方 | 未批时的状态 |
|---|---|---|---|
| 门② | signal 格式与语义口径 | 荀攸 M0 | 点位①冻结，signal 不投递 |
| 门③ | 决策账落账口径（级别/影子数据去向） | 荀攸 M0 | 点位②只记受理日志，不入正式账 |
| 影子比对确认 | 影子期结果认可+切正式 | 荀攸/老田 | 点位③永不触发 |
| 受控回写契约议定 | 信封/白名单/限频 | 军团侧协同 | 点位①依赖项缺位，同冻结 |
| 订阅闸 enforce | 客户域信号通知的闸门模式 | 老田（另批） | observe 模式下客户域通知行为按 observe 口径 |
