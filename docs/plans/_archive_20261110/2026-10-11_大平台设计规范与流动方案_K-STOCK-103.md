## 二、导航形态规范（减胶囊·多下拉·不长图）

1. **全站只允许两层导航**：sticky 顶栏（动线+域下拉）+ 页内面包屑。**禁止平铺胶囊长条**——现存页里散落的胶囊排（quant.html 等静态页旧导航区）在 10-20 体验窗统一摘除，由顶栏接管；
2. **域内一律下拉**：任何「多于 7 个并列入口」必须收进下拉 details，不横排；
3. **长页准入闸**：新页 h2≥6 必须过 shortscreen.js（自动锚点+分区折叠）；投屏大屏例外但移动端 @media 切简版；
4. **新页面准入三件**：tokens.css + nav.js + 短屏化——缺一不收（守卫：unify_nav --check 已覆盖静态页，动态页走 pill_nav 模板天然合规）；
5. **每屏一个主任务**：首屏=结论/信号，明细下钻展开。

## 四、链路规范（治"链路错"）

1. **数据流单向**：采集/引擎 → DB/JSON → portal_api 读 → 页面渲染。**页面禁止直连他模块 DB**（先例：/paper 只读 URI 模式）；
2. **唯一链路登记**=K-STOCK-098 总登记文档第二节，新链路先登记后上线；
3. **禁止跨端口私调**：页面 JS 只调本域 API 与注册表内服务的展示端点；脚本互调走 subprocess+注册表端口，不许硬编码他人内部接口；
4. **断链自愈口径**：依赖服务挂→页面显示「降级+入口」，不许白屏或 500 裸栈。

## 五、板块流动方案（用户怎么在平台里流动）

```
⚡ 动线（每日必经）: 晨报→盘前→信号→大屏→盘后→模拟仓
        │ 域下拉（5 域全入口）          │ 统一卡下钻（任一代码）
        ▼                              ▼
   L1 量化域(34页)  L2 情报域(15页)  →  /kg/stock 五区卡（唯一终点）
        │ 商业化入口                    │ 个人入口
        ▼                              ▼
   /algo 算法市场 → /market 门面    Hermes(个人) / 菜鸟驾驶舱(公司)
```

流动三原则：**动线优先**（高频路径一步直达）、**下钻一致**（任何代码同一张卡）、**双 AI 分流**（公司事菜鸟/个人事 Hermes，K-STOCK-102 定案）。
