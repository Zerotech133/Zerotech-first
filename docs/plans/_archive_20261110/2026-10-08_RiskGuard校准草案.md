## 三、校准建议（逐规则：已做 / 待验证 / 剩余动作）

### R1 市场质量
- **已完成**：旧口径废弃 → 分位动态闸（LB125/P10），重放过 |t|≥3 门，两键入 calibrated_keys。
- **影子验证方案**：health0 序列已回填 223 天（health0.jsonl，20251021~20261008），
  分位闸每日自动出数。观察指标：block 日 vs pass 日的市场等权 ret5/ret10 差
  （沿 r1b 重放口径），连续 10 个有效采样日方向不翻 + |t|≥2 维持，即视为影子通过。
- **剩余动作**：无新调参；LB=250 档 2027 年数据攒够后复核（r1b findings）。

### R2 流动性冲击
- **已完成**：2.0→2.5 毕业（09-30），拦截量 -44%（60525→33676）、误杀率降 3.4pp。
- **影子验证方案**：账本 121 个 2.5 档 shadow_block 的真实前向收益 10-14 起陆续成熟，
  用 `python kg_riskguard_recon.py stats` 直接复算（结算口径已冻结：T0+5/10 交易日收盘）。
- **剩余动作**：3.0 档作保守对照（更准但更稀，block 样本 -38%）；**不建议再动**，
  该键已毕业，改动需新证据。

### R3 事件风险
- **已完成**：min_event_base 10→3（唤醒休眠：0 个可评 → asof 0914 有 88 标的可评）、
  bear_min_n 2→5（脱离方向反档，向重放最优档靠拢）。
- **影子验证方案**：降阈后每周重跑 `python kg_riskguard_calib.py --r3`，重点盯
  **3 档误杀率**（min_base=3 是降阈换样本，本身有放松风险）；bear_min_n=5 档
  需攒 n≥30 block 再判显著（当前 n=11 仅粗显著）。数据成熟前该规则实质低频触发，
  风险有限。
- **剩余动作**：`riskguard_bear_density`（0.5）仍无数据可校——密度从未达 0.3，
  建议维持占位并保持其"未校准"状态（客观上维持 enforce 降级，宁严）。

### R4 仓位集中度（归因最重，重点盯）
- **已完成**：0.30→0.35（脱离误杀区：0.35 档差 -1.84pp 方向转负，虽不显著但至少
  不再系统性拦盈利持仓；0.40 档强显著危险但 n=33 偏小不采）。
- **影子验证方案**：生产语义差是主要残留风险——重放是"账户已持仓集中度"，
  生产拦截对象是"新信号买入后权重"。建议影子期**双口径并行记账**：
  ①账本正常记 R4 shadow_block（触发新阈值 0.35）；②同时按 0.30 / 0.40 两档
  影子补记对照分数（score 字段已存权重值，**无需改代码**——重放脚本按权重分桶
  即可事后还原任意档位）。攒 ≥40 个 0.35+ 样本后复算 0.35/0.40 两档分离度。
- **剩余动作**：0.40 档 n 攒厚后重议上调；若影子期 0.35 档仍现"block 组更赚"
  （动量混杂坐实），考虑 R4 降级为"预警不拦截"（只入账本不进 verdict）。

### 通用（四规则共用）
- **重跑脚本设计（213 明细若定位）**：明细需含 `ts / security / rule_id / score /
  reason / action` 六字段，直接构造 ledger 行格式（`kg_riskguard.py:46-48`）追加为
  独立历史账本文件，喂 `kg_riskguard_recon.py settle_row`（`kg_riskguard_recon.py:53-81`，
  接口已支持任意账本路径）即可出逐规则后验收益表——**零新代码**。若明细无 rule_id，
  用 reason 文本关键词映射四规则（"健康占比"→R1、"vol/vol_ma20"→R2、"事件/矛盾"→R3、
  "仓位占比"→R4）。
- **enforce 解锁路径**（`kg_riskguard.py:39-44` 三重门）：剩余三键中，
  min_market_samples / min_vol_days 属数据量守卫（非定值阈值，建议按"守卫键不入
  calibrated_keys"原议保持未校准，或老田拍板特批）；bear_density 待 R3 数据。
  **在 enforce 解锁前，一切拦截均为影子留痕，生产交易链路零影响**——这与"先影子
  攒 2 周对照数据再切硬拦截"的验证路径天然一致。
