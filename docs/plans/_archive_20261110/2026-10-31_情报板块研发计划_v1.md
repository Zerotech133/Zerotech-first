## 0. 一页结论

情报板块未来四周只做三件事：

```text
1. 把情报链修通：路由、认证、排序、新鲜度
2. 把 JEV 判断变成可复核证据：抽样复习 + Reviewed Evidence
3. 把复核后的情报接进 N1/D1：先 A/B，不直接改生产
```

**P0 必须先于任何新功能。**  
当前 `/intel/stream` 502、情报 API 未认证、JEV 10,525 pending，任何新面板都只会放大问题。

## 6. 测试与门禁

### 必测

```text
1) route_table 16 组参数化 smoke：每路径 200/302，不得 502
2) 认证矩阵：未登录/登录/角色 3×3
3) 排序：注入 3 条不同 ts，断言 items 降序 + latest_ts
4) 复核：pending→resolved/reject；未授权 401；审计落账
5) 覆盖：stale 快照 age>24h 标黄；2020 日期过滤
6) N1：flag off 同旧行为；flag on reviewed/price_proxy 两态
7) E2E：一条真实事件采集→JEV→复核→N1→D1 回放
```

### 门禁

- `test_gate -Suite fast` 新增测试 0 失败；
- 路由/auth smoke 入 fast gate；
- N1 接线必须过 `change_gate`，不得以“测试绿”代替质量证据；
- 不新增 L2 动作；不改生产 prompt 默认路径。
