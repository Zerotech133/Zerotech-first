## 二、链路与模块（全部真实调用，非 mock）

```text
live /api/acad1/pool?view=full（只读 PG，set_session(readonly=True)）
  └─ portal/api_acad1_pool.load_pool_snapshot(view="full")   pool_id / 1 code
→ agent_platform/d1_decision.append_decision                 decision_id（d1_record，paper_only）
→ agent_platform/d1_handoff.append_handoff（d1_handoff/v2）  handoff_id(+receipt_id 别名) + watch_plans[]
→ agent_platform/watch_plan_consumer.consume_handoff         watch_plan_id（status=armed）
→ agent_platform/watch_plan_consumer.trigger_plan            confirmation_id（pending，四 ID 传递）
→ agent_platform/trading_bot_flow.decide(approve)            trade_id（paper ledger + trade receipt，幂等复跑同 ID）
→ agent_platform/training/outcome_chain.generate_outcomes    outcome_id（六 ID，complete）
→ agent_platform/training/outcome_chain.build_training_episode  training_episode_id（ids/metrics/errors，validate=[]）
```

所有写操作显式指向 `--tmp-root`（默认系统 temp `ifs_e2e_*`）；未调用任何 HTTP 写接口；未启停服务。

## 八、隔离 / 只读 / 回滚边界

- **不写生产**：所有写操作显式路径均在 `--tmp-root` 下；运行前后对 7 个生产 artifact +
  `agent_platform/data/confirmations/` 做 stat/sha 快照，`production_untouched.unchanged=true`；
  `isolation_tmp_only` 检查保证证据文件全部位于 tmp 根内。
- **不实盘/不训练**：链路终点到 training_episode（read_only=true / auto_training=false）；
  无 order/qty/broker/fill/account 等执行字段（扫描证据文件，`no_execution_fields` PASS）。
- **不启停服务/不调 HTTP**：池通过 `load_pool_snapshot` 只读 PG（`set_session(readonly=True)` + 只读 SQL），
  其余步骤直接调用模块；未访问 8091/8734。
- **回滚**：本单为**新增工具+测试+文档**（无数据迁移/无服务变更）——
  `git revert <本单 commit>` 即可；tmp 证据目录为运行产物，可保留审计或按回收站规则清理。
