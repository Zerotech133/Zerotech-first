## 1. 背景

wave16 评估 17 条问答样本时发现两个问题：

1. **无引用样本未区分标注**：q4「无依据模拟」与 2 条 expanded 拒答样本没有 citations，评估把
   「无引用」记为质量问题，但它们其实是**预期拒答**——需要字段区分「预期拒答」与「有引用答案」；
2. **幻觉启发式误报**：答案中的列表序号（`1. **技术升级**`、`2.`）、小整数（「3 条引用」）被当成
   未在引用中出现的「数字幻觉」→ 需要数字白名单/序数过滤。

## 2. schema v2 字段定义（每个 sample）

| 字段 | 类型 | 定义 |
|---|---|---|
| `expected_refusal` | bool | 该样本**预期**是拒答/无依据回答（无引用 + 拒答语义 / category 无证据模拟） |
| `citations_required` | bool | 该样本是否要求引用：非拒答=True；拒答=False |
| `answer_type` | enum | `fact`（有引用事实陈述）/ `inference`（有引用且含推断措辞）/ `refusal`（拒答） |
| `schema_version` | int | 样本级 schema 版本 = 2 |

顶层同时更新：`schema_version: 1 → 2`，新增 `schema_migration`（from/to/migrated_at/rules/backup），
便于追溯迁移规则与备份路径。

## 3. 迁移规则（按旧样本推断，不改 answer/citations 原文）

优先级：拒答判定 → 推断判定 → fact。

1. **refusal**：`citations == []` 且满足任一：
   - `no_evidence is True`；
   - `category ∈ {no_evidence_simulated, no_evidence, refusal}`；
   - 答案含拒答语义（没有足够依据/无法回答/未包含/没有找到/拒答…）；
   - `confidence.level == "none"`。
   → `expected_refusal=True`、`citations_required=False`、`answer_type="refusal"`。
2. **inference**：有 citations 且答案含推断措辞（预计/推断/推测/意味着/可能/或将/有望/测算/假设/
   综合来看/因此/判断/认为/预期/趋势上）→ `expected_refusal=False`、`citations_required=True`。
3. **fact**：有 citations 且不含推断措辞 → 其余同上。
4. 其它字段（answer/citations/confidence/note/category…）**原样保留**。

迁移结果（本次 17 条）：fact 13 / inference 1 / refusal 3；expected_refusal=3、
citations_required=14；备份文件生成于迁移前。

## 4. 幻觉检测 v2 规则（kb_qa_eval_v2.py）

| 规则 | v1（wave16） | v2（本次） |
|---|---|---|
| 数字候选 | 所有数字（≥7 位除外） | **白名单 1~10 过滤**；先剔除列表序号 `^N.`/`N、`/`N)` 与「第N」；≥7 位、12 位 hex、`rp_` 研报号继续过滤 |
| 英文 token | 任意英文词（≥2 字符） | **仅 ≥3 个字母**且未在引用文本出现才算候选（"AI" 等 2 字母不检测） |
| 引用上下文 | 数字/英文在引用文本出现则不标记 | 同（保留） |
| 前后对比 | — | 同批样本 v1 vs v2 候选数/样本数/被消除 token 清单 |

实测（17 条）：v1 幻觉候选 **5 项 / 4 样本** → v2 **2 项 / 2 样本**，**消除误报 3 项（降幅 60%）**；
剩余候选 q3「2030」、q5「LLM」需人工复核（2030 为真实年份但引用文本未含，LLM 为答案引入术语）。

## 5. 下游兼容

- 样本文件（`portal/static/kb_qa_samples.json`）字段**只增不改**：旧消费方读取 answer/citations/
  category 等字段不受影响；新增字段可被前端/评估忽略；
- `kb_qa_eval.py`（v1 评估器）仍可按旧字段运行；`kb_qa_eval_v2.py` 读取 v2 字段做区分评估；
- 切换评估器：评测报告需标注使用 v1 或 v2 规则（v2 报告见 `kb_qa_eval_v2_20261101.{json,md}`）；
- 回滚：`research/reports/kb_qa_samples_backup2_20261101.json` 为迁移前完整备份，可字节级恢复。

## 6. 局限

- schema v2 字段是**规则推断**（非人工逐条标注）：拒答/推断边界可能误判，建议后续人工抽检确认；
- 数字白名单会**漏检**真实小数字幻觉（如编造「3 条引用」），英文 ≥3 字母会漏检「AI」类缩写专名；
- 支撑度仍为字符 bigram 覆盖率启发式（改写/同义会被低估），需人工复核；
- 样本量 17 条，规则调优结论为冒烟级，不构成统计性结论；未调用 LLM。
