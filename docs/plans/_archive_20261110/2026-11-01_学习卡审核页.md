# 学习卡审核页 v1（点选 → 导出 decisions）

> STATUS: pending_approval

> 2026-11-01 · 目标：把「60 张学习卡候选的人工审核」从 JSON/MD 勾选搬到**可点选页面**，导出与
> `tools/kb_corpus/card_review.py decide` 完全兼容的 decisions JSON，形成闭环：
> **页面点选 → 导出 decisions.json → decide dry-run 预览 → 人工确认 --apply →（可选）--merge 合并**。
>
> 页面：`portal/card_review.html` · 数据：`portal/static/card_review_data.json`（60 条精简审核数据）

## 一、页面能力

| 能力 | 说明 |
|---|---|
| 候选展示 | 60 条（AE 20 + AV 40）：来源/主题/角度/问题/答案摘要（可展开完整答案）/出处/原文证据/机器预审建议（pass·revise + 置信/分数/理由） |
| 逐卡单选 | **☐通过 / ☐需修改 / ☐驳回 / ○未决**（默认未决；选中后卡片描边标记已处理） |
| 备注 | 每卡 textarea（修改点/驳回原因），随草稿保存 |
| 筛选 | 来源（AE/AV）、主题（动态）、预审建议（pass/revise/reject）、状态（未决/已处理）、关键词搜索 |
| 进度统计 | 总数/通过/需修改/驳回/未决 + 进度条 + 百分比 |
| 本地暂存 | 浏览器 `localStorage`（key=`card_review_decisions_20261101`），改动 250ms 防抖自动保存，刷新不丢 |
| 导出 | 「⬇ 导出 decisions JSON」下载 `card_review_decisions_20261101.json`（未决卡不导出，保持 pending_review） |
| 重置 | 清空本地草稿（不影响已导出文件/真实数据） |
| 三件套 | `/static/tokens.css` + `/static/nav.js`（自动注入统一顶栏/深浅色/移动端 shell），页面响应式适配 |
| 降级 | 数据加载失败时显示降级文案（提示检查 `/static/card_review_data.json`），不空白 |

```json

  "date": "20261101",
  "generated_at": "…",
  "source": {"checklist": "...", "checklist_sha256": "...", "precheck": "...", "precheck_sha256": "..."},
  "stats": {"total": 60, "by_source": {"AE": 20, "AV": 40}, "by_theme": [...],
            "precheck": {"pass": 36, "revise": 24, "reject": 0}},
  "options": {"verdicts": [{"key": "pass", "label": "通过"}, ...],
              "localStorage_key": "card_review_decisions_20261101",
              "export_filename": "card_review_decisions_20261101.json"},
  "items": [{"review_id": "REV-20261101-001", "source": "AE", "theme": "...", "angle_cn": "—",
             "question": "...", "answer_summary": "...", "answer": "...",
             "source_ref": "...", "evidence_summary": "...", "unit_id": "...",
             "precheck": {"suggested_verdict": "pass", "confidence": "high", "score": 100, "reasons": [...]},
             "checkboxes": {"pass": false, "modify": false, "reject": false}, "notes": ""}],
  "disclaimer": "..."
}
```

- 来源为 wave20 `card_review_checklist_20261101.json`（清单）+ wave18 `card_precheck_20261101.json`（预审建议），
  并记录两者 sha256 便于追溯；**页面只读，不写清单/学习卡**。

## 三、导出的 decisions JSON（与 decide 兼容）

```json
{
  "schema_version": 1,
  "reviewer": "card_review.html（人工审核页）",
  "decided_at": "2026-11-01T…+00:00",
  "source_data": "/static/card_review_data.json",
  "decisions": {
    "REV-20261101-001": {"verdict": "pass", "notes": ""},
    "REV-20261101-002": {"verdict": "revise", "notes": "答案需补数据来源"}
  }
}
```

- `verdict ∈ pass|revise|reject`；**未决卡不导出**（保持 `pending_review`）。
- `tools/kb_corpus/card_review.py decide --decisions <文件>` 支持该结构（`decisions` 包装 + review_id 键 + `{verdict,notes}` 值），
  与 wave19 建议 decisions 文件同一契约；也兼容源 card_id（`PROP-*`/`CP2-*`）键。

## 四、使用流程（页面 → decide → apply → merge）

```powershell
# 1) 打开审核页（统一入口 8734）
start http://127.0.0.1:8734/card_review.html
#    → 点选 通过/需修改/驳回 + 备注，进度条实时更新（localStorage 自动暂存）
#    → 点「导出 decisions JSON」得到 card_review_decisions_20261101.json（放到任意路径，如 research/reports/）

cd C:\项目\老田的AI助手
# 2) dry-run 预览（不写盘；显示将更新卡数/预计合并新增/跳过冲突）
C:\项目\py312\python.exe -X utf8 tools/kb_corpus/card_review.py decide --decisions research/reports/card_review_decisions_20261101.json

# 3) 人工确认后写清单状态（--apply；仍不动学习卡）
C:\项目\py312\python.exe -X utf8 tools/kb_corpus/card_review.py decide --decisions ... --apply

# 4) 需合并进学习卡时（备份 + 写后校验）
C:\项目\py312\python.exe -X utf8 tools/kb_corpus/card_review.py decide --decisions ... --apply --merge
```

> `--apply`/`--merge` 属数据变更：需人工确认 + 按仓库纪律审批；页面本身**不 apply**。

## 八、一键预填机器建议（v1.1 · wave22 CG）

| 控件 | 行为 |

| **⚡ 一键采用机器预审建议** | 按 `card_review_data.json` 的 `precheck.suggested_verdict` 预填：**pass→通过、revise→需修改、reject→驳回**；**仅预填「未决」卡**，已决卡一律不覆盖（有确认弹窗） |

- 预填后仍可逐卡改选/写备注，改动照常写入 localStorage（key=`card_review_decisions_20261101`），刷新不丢；

- 机器预审仅辅助：一键预填后可继续人工修正，最终以导出的 decisions 为准；
