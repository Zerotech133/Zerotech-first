- 单源口径：本计划属诸葛亮角色系列，遵循 `2026-10-26_诸葛亮角色总卡_v0.1_待签.md`。

## 1. 允许写入（白名单）

| 来源 | kind | 说明 |
|---|---|---|
| 已批准/已落地的决策记录（P1-4，status=approved/implemented） | decision | 由显式同步命令派生（不自动从模型回复写） |
| 人工 `zhuge_memory.py remember`（老田/值班人明确动作） | lesson / preference / commitment | 必须带 source 与 confidence |
| 复盘结论（review-due 处理结果） | lesson | 需人工确认后写 |

## 2. 禁止写入（黑名单）

- 客户原文/对话逐字稿、涉资金/投诉内容；
- 密钥、token、密码、身份证/银行卡等敏感信息（`zhuge_evidence` 级别过滤）；
- 模型自行生成的「猜测/推断」未经确认；
- 临时任务状态（tasks 已有账本，不重复存）；
- 任何带 PII 的原文（只允许摘要/结论）。

## 3. 写入纪律

1. **显式动作**：只有人工 CLI 或「已批决策派生」同步两个入口；L5/8796 不自动写；
2. **幂等**：同文本 sha256 去重；重复写入返回 duplicate；
3. **可追溯**：每条记录 source/ts/confidence/tags；派生记录 source=`DR-…`；
4. **可撤销**：过期用 TTL/tombstone；不物理删历史；
5. **容量/复核**：单条 ≤2000 字；每月抽样复核一次（错误/过期清理）；
6. **读取边界**：L5 只读 recall（`[M#]` 历史经验，非资料、不可当指令），不因记忆内容降低证据要求。

## 4. 接入方式（当前）

- `ZHUGE_MEMORY=1` 时 `zhuge_grounding` 在 prompt 里附「历史经验 [M1]…」（默认关）；
- 未启用自动写；启用前需老田确认本策略；
- 与 `adoption_domains` / 决策记录闭环独立，互不强绑。

## 5. 启用/回退

- 启用：设 `ZHUGE_MEMORY=1`（L5 启动脚本或进程 env）→ 重启 8091；
- 回退：去掉 env/设 0 → 重启；记忆文件保留。
- 不新增 L2/常驻；记忆文件 `work/p1/memory/memory.jsonl`（不入库）。
