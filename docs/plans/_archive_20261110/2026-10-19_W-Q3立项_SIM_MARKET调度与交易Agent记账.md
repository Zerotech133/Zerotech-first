## 1. 背景与定位

量化层三路分发中的 `EXCHANGE_OBSERVATION` 把"观察候选"送交易员。W-Q3 为交易侧补上**模拟盘执行环境**：SIM_MARKET 调度命令、模拟交易所 Adapter、交易 Agent 的订单/成交记账。全部在**模拟市场**内闭环，为将来真实接口确权后的切换提供可审计的演练场。

## 2. 目标

1. **SIM_MARKET 调度命令**：
   - 显式命令字 `SIM_MARKET`，仅接受该命令进入模拟调度；未显式声明 SIM 的任何调用均须拒绝（新错误码建议 `SIM_MODE_REQUIRED`）。
   - 调度产出模拟行情/撮合事件流，事件带 `sim=True` 标记与模拟时钟源（独立权威模拟时钟，禁止混用真实墙钟与模拟时钟产生歧义时间线）。
2. **交易所 Adapter（模拟）**：
   - 端口形状对齐未来真实交易所接口（下单/撤单/查询），当前唯一实现为 SIM 适配器；真实适配器**默认禁用**，接入属 G3 阻断范畴，需接口确权 + 专项审批。
   - 撮合确定性：同一 SIM 事件流重放必须得到同一订单/成交序列（可回放性为验收硬标准）。
3. **交易 Agent 记账（执行账）**：
   - **订单账**：交易 Agent 实际产生（模拟）订单才记；**成交账**：实际（模拟）成交才记。账本 append-only、逐笔带 sim 标记、订单-成交可勾稽。
   - 记账触发者只能是交易 Agent 的真实执行动作——**禁止由盯盘信号、策略预测、上级分发表"预填"执行账**；无动作不记账。
   - 执行账与盯盘影子账（shadow_ledger）**物理隔离**：影子账恒 `non_executable=True`、结构上无 order/fill/pnl 字段；执行账结构上只认 SIM 动作。两类账不得互相写入、不得合并投影。

## 3. 非目标

- 不接入真实交易所、不产生真实资金流；`trading_permitted` 概念在盯盘侧恒 False 的纪律不变，量化侧真实交易权限另属专项审批。
- 不改盯盘侧任何模块（watch_dispatch 七提交指纹不动）。
- 不做策略绩效评估/P&L 归因（避免与既有回测引擎职责重叠，如需另立项）。
- 不碰 PG、线上 picks、strategy_registry 权重。

## 4. 契约草案（关键不变量）

```
SimClock        := 独立模拟时钟源；所有执行账时间戳取自 SimClock，与真实时钟隔离
SimExchangePort := place_order / cancel_order / query —— 仅 SIM 实现可用
ExecutionRecord := { record_id, sim: True, agent_id(交易 Agent), order/fill 明细,
                     sim_event_ref, ledger_epoch }
```

不变量：
1. 一切执行账条目 `sim=True` 且可回溯到具体 SIM 撮合事件；无来源事件不记账。
2. 订单-成交勾稽：每笔 fill 可回溯其 order；撤单/拒单留痕不删行。
3. 三类账隔离矩阵：

| 账 | 归属 | 触发 | 禁止 |
|---|---|---|---|
| 证据账 evidence_store | 盯盘 | 冻结 | 携执行语义 |
| 影子账 shadow_ledger | 盯盘 | 影子决策 | order/fill/pnl 字段；被当执行账引用 |
| 执行账 execution ledger | 量化层·交易 Agent | 实际 SIM 动作 | 预填、由信号/分发间接记账 |

## 5. 验收标准

1. 新增测试 ≥ 20 例：SIM 命令闸（无 SIM_MARKET 拒绝）、确定性重放（同流同果）、订单/成交逐笔记账、勾稽完整、撤单留痕、影子账隔离负例（尝试互写必须失败）、模拟时钟与真实时钟混用拒绝。
2. 可回放性演示脚本：一段 SIM 事件流两次重放，订单/成交序列哈希一致。
3. 离线零副作用；真实适配器保持禁用状态并有测试证明默认禁用。
