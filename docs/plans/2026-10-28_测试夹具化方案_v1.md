# 测试夹具化 / 时间注入方案 v1（P0 #3，2026-10-28 · 关羽）
> STATUS: unspecified（owner: TBD；2026-11-07 前补状态或标 superseded）



> 问题（30 年诊断 #3）：k_stock/portal 大量测试直接吃"真实行情湖 + 当日日期"，日期一翻或湖未更新就变红 → 回归网在时间边界失效（今日已实证：行情湖 20261027 vs 市场目标日 20261028，2 个 paper_cli 测试误报"新增失败"）。
> 目标：核心测试**不依赖真实日期与真实数据**，任何时刻可跑、结果确定。

## 一、现状（已定位的注入点）

| 位置 | 现状 | 影响 |
|---|---|---|
| `k_stock/paper/cli.py:388` | `now = datetime.now(bj)` | 目标日随时间变 |
| `k_stock/paper/cli.py:423-453` | 市场目标日 vs 湖日历校验（fail-visible 拒写） | 湖未更新到当日 → 测试红 |
| `k_stock/paper/cli.py:688` | `asof or date.today()` | 快照日期随真实日期 |
| `k_stock/paper/hk_market.py` | 目标日/日历同类逻辑 | HK 测试同样受影响 |
| `k_stock/paper/market.py` | ParquetMarket 读真实湖目录 | 测试依赖真实数据 |
| `tools/test_baseline.json` env_failures | 5 条数据/环境依赖（含 paper_cli ×2） | 只是"登记"，不是解决 |

## 二、方案（两步，不改业务语义）

### 步骤 1：时间注入（代码级，1 天）

1. `k_stock/paper/cli.py` 顶部加纯函数：
   ```python
   def _today(fmt="%Y%m%d"):
       """测试可注入：KSTOCK_PAPER_TODAY=YYYYMMDD 优先；否则真实日期。"""
       v = os.environ.get("KSTOCK_PAPER_TODAY", "").strip()
       return v if len(v) == 8 and v.isdigit() else datetime.now(ZoneInfo("Asia/Shanghai")).strftime(fmt)
   ```
   替换 `now = datetime.now(bj)` / `date.today()` 为 `_today()` 或 `_now()`；
2. `hk_market.py` 同样加 `_today()`（env 同名，HK 可复用或 `HK_PAPER_TODAY` 覆盖）；
3. **零行为变化**：未设 env 时与现在完全一致；设 env 时仅影响"今天"判定。

### 步骤 2：数据夹具（测试级，1 天）

1. `k_stock/tests/conftest.py`（新增）：
   - fixture `frozen_lake(tmp_path)`：从 `k_stock/tests/fixtures/parquet/` 复制 3~5 个票的**小 parquet 夹具**到 tmp，返回目录；
   - fixture `frozen_today()`：`monkeypatch.setenv("KSTOCK_PAPER_TODAY", "20261027")`（与夹具数据同日）；
   - fixture 自动把 `ParquetMarket` 的 data root 指向夹具目录（若 market 支持参数化；不支持则 monkeypatch 常量）；
2. 改造优先级（先 3 个高价值用例）：
   - `test_paper_cli.py::test_mark_default_us_failure_is_nonzero_and_no_false_us_row`
   - `test_paper_cli.py::test_mark_all_real_engine_cash_only_accounts`
   - `test_hk_market.py` 的日历/目标日相关用例
3. 转换后从 `tools/test_baseline.json` 的 `env_failures` 中**移除**对应条目（不得靠基线掩盖）。

## 三、验收

1. 在"行情湖未更新到当日"的条件下跑 `python -m pytest k_stock/tests -q` → **0 新增失败**（当前环境即为该场景，可直接验证）；
2. 设置 `KSTOCK_PAPER_TODAY` 前后，业务逻辑分支一致（单测：未设 env 时 `_today()` == 真实日期；设 env 时返回注入值）；
3. `test_baseline.json` env_failures 条目减少（目标：5 → 0）；
4. 全量 k_stock 套件绿（2 条 known 除外）。

## 四、风险与回滚

| 风险 | 缓解 |
|---|---|
| 注入后测试"假绿"（真实日期路径未覆盖） | 保留 1 个"真实日期 smoke"用例（不注入），只做浅断言 |
| 夹具数据陈旧导致行为漂移 | 夹具只覆盖估值/对账算术，不测行情质量；季度刷新 |
| ParquetMarket 不可参数化 | 优先 monkeypatch 常量；不行则改 market 加可注入 root 参数（独立小单） |
| 影响产线 | 未设 env 时行为完全不变；产线绝不设该 env |
