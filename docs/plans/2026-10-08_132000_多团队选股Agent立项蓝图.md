## 二、修正后架构（K-STOCK 线）

```
日终调度（16:30 后，沿用 quant_backtest 骨架 + deadline 护栏）
  └─ 团队编排器（Python 重实现 ai_team_role DSL：拓扑排序/并行屏障/辩论/降级）
       ├─ T1 技术面分析师（人设：激进多头）  ← TDX 因子库 + qpzm 技术指标
       ├─ T2 技术面分析师（人设：保守空头）  ← 同上（人设相反）
       │    └─ bull/bear 辩论 ×2 轮（相似度>0.8 提前收敛）
       ├─ N1 新闻事件/情绪面分析师 ← jev 新闻判断流 + TDX sentiment 因子（龙虎榜）
       ├─ F1 基本面分析师 ← 元子图谱 + Tushare
       ├─ A1 投资建议（汇总 T1/T2/N1/F1 结构化输出）
       └─ D1 最终决策（五档 STRONG_BUY~STRONG_SELL + 置信度 + 目标价区间 + 风险等级）
            └─ 六维评分过滤（24 因子 WEIGHT/PENALTY，从 DB 快照 DDL 重建）
                 └─ 选股清单落库（stock_trade_strategy_pool 契约：score/weight/rank/factor_detail/reason）
                      └─ 次日对照评估（秩相关+分组收益，lineage 对齐 X3）
```
