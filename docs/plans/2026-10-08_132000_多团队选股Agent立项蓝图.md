## 一、项目定位

**一句话**：用多 Agent 团队协同产出「每日选股清单」，先影子运行（只出清单+次日对照，不下单），评估达标后再议模拟盘/实盘。

与既有系统的边界：
- 不替代盯盘机器人（那是持仓监控+风控线）；本项目是**选股生产线**，产出物喂给盯盘/回测消费。
- 不重建数据层——一切复用现有资产（见 §二）。

## 四、影子启动阶段与里程碑

### S0 立项蓝图（今天，D0）✅ 本文档
### S1 单 Agent PoC（D0 → D+5 个交易日）

**最小闭环日终任务**（每日一批，一日一跑）：
```
Tushare 行情 → A6 打分 top N → jev 情绪标注 → 元子情报标签 → 合成清单落库
→ 次日收盘对照（打分 vs 实际涨跌，秩相关+分组收益）
```

**PoC 通过判据（三条全过才进 S2）**：
1. 连续 **5 个交易日**无人干预跑通（失败自动告警，走飞书通道）；
2. 打分与次日收益**秩相关 > 0**（至少不劣于随机；分组单调性作参考项）；
3. 每环节 lineage 可追溯（对齐 X3 血缘三表设计，事件入图走 P1-4 口径）。

### S2 多团队扩编（PoC 过后 D+2 周内）
M1-M5 五角色并行接入 + A4 仲裁器扩展为合成底座 + 冲突仲裁规则（宏观与板块冲突时以风控优先）。

### S3 影子评估 → 上桌决策（D+4 周）
模拟盘对照跑 2 周，输出评估报告（胜率/回撤/换手/与盯盘线信号重合度），**报老田决定**是否进模拟盘正式运行；实盘不在本蓝图范围。
