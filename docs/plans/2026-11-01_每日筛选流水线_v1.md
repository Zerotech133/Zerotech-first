# 每日筛选流水线 v1（可手动运行，dry-run 安全）

- 日期：2026-11-01
- 支线：task-98（每日筛选流水线；**不注册定时任务**）
- 脚本：`tools/research/daily_screening.py`
- 测试：`tools/tests/test_daily_screening.py`（**6 passed**）
- 定位：研究输出，不构成投资建议；不调用 LLM、不重跑已有研究。

## 1. 用法

```bash
# 默认：最新交易日自动探测 + RS off + 写 research/reports/daily_screening_<date>.{json,md}
python tools/research/daily_screening.py

# dry-run：只打印摘要，不写文件（安全试跑）
python tools/research/daily_screening.py --dry-run

# 指定数据日 + RS overlay 模式 C，RS 交集清单最多 30 条
python tools/research/daily_screening.py --date 20261030 --rs-mode C --rs-top 30

# 输出到指定目录（不污染正式报告）
python tools/research/daily_screening.py --date 20261030 --rs-mode C --out-dir tmp/daily_screening
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--date` | 最新交易日（自动探测 `quant_backtest/data/tushare/daily/d_*.parquet` 最大日期） | 数据日 YYYYMMDD |
| `--rs-mode` | `off` | `off` / `A` / `B` / `C`（板块=行业等权当日涨幅；A 个股≥板块；B 超额≥1.0pp；C 板块≥1% 且个股≥1%） |
| `--rs-top` | 50 | RS 交集清单展示条数（0=不限，JSON 保留全量计数） |
| `--out-dir` | `research/reports` | 输出目录 |
| `--dry-run` | 关 | 不写任何文件，只打印摘要 |

## 2. 串联链路

```
最新交易日探测
  → S01 过滤（selection_engine.build）
  → S02 研究排序 top30（⚠️ 已暂停，仅参考）
  → S03 H18 业绩预告修订事件（selection_daily_<date>.json）
  → 量学四因子信号并集（LX20/LX06/LX12/LX22，等权全市场研究口径）
  → 可选 RS overlay（行业等权板块强度 + A/B/C 判定）
  → JSON/MD 报告
```

## 3. 输出

`research/reports/daily_screening_<date>.json`（schema `daily_screening.v1`）：

| 字段 | 内容 |
|---|---|
| `date` / `generated_at` / `dry_run` | 数据日/生成时间/是否 dry-run |
| `universe` | 输入数、S01 过滤后合格数、剔除明细 |
| `S02_ranking_research_only` | S02 暂停说明 + 研究排序 top30（代码/名称/行业/分数/reason） |
| `S03_H18_watch` | 规则、事件数、事件清单（报告期/公告日/类型/方向/Δ中值） |
| `pinxue_signals` | 四因子各自信号数+样例代码、并集数 |
| `RS_overlay` | off 时 `enabled=false`；启用时 全市场通过数/通过率/量学信号数/交集清单（code/name/industry/pct_chg/board_pct_chg/excess_pp/rs_flag/signals） |
| `boundary_notes` / `disclaimer` | 边界与免责 |

`daily_screening_<date>.md`：一、S01 过滤统计；二、S02 研究排序（暂停）；三、H18 事件；
四、量学四因子；五、量学信号 ∩ RS；六、边界与未来定时接入。
