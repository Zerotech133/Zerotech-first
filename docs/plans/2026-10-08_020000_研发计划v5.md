## 〇、把所有思想串起来（项目思想脉络一句话版）

1. **情报学总纲**（INTEL_RD_PLAN 〇章）：不造轮子，把"采集 → 证据 → 图谱 → 预警 → 决策 → 复盘进化"做成情报流水线。
2. **临界三层数据模型**：可信数据（数据城池 PG + parquet + 菜鸟）→ 可解释信号（缠论/九维/weak/strong 策略族 + 元子图谱归因）→ 可审计决策（门户 + 飞书 + 投委会 + 六本账）。
3. **命名宪章**（老田钦定）：项目=临界；图谱=元子；数据仓=数据城池；数据联动=数据血缘。所有文档统一口径。
4. **多 Agent 生产方式**：N-Agent 注册制（AGENT-PACT v1.1）——注册开工、写入窗口、版本化保护、金样本闸门、单一事实源、冲突上报。
5. **工作站多领域愿景**（README 六大卡）：量化股票与情报中枢已实，内容创作已起步，开发者/更多领域预留——未来向"集成超级助理"（Hermes 执行/记忆 + OpenClaw 网关 + CowAgent 记忆 + Khoj 检索）演进。
6. **临界 × 菜鸟整合愿景**（10-08 勘查定调）：登录用菜鸟 OAuth2，数据走"联邦 + 图中介"不合库，元子图谱成为两系统的共同语义层。

## 三、研发方向（一条主轴 + 三条主线 + 一条底座线）

**主轴：从"能看"到"能信"到"能赚钱"——可信数据已达成，下一程是可解释信号的后验闭环与可审计决策的价值验证。**

### 主线 A：决策闭环价值化（临界自身）
信号 → 回测闸门 → 影子账 → 模拟锦标赛 → 实盘影子 → 小资金。每一步都有后验数据闸门；RiskGuard 校准（P0-2）与缠论联立（P1-5）是当前两块拦路石。K70 的"策略来源全链贯穿"保证每笔结果可归因到策略/分析师，反哺 AI 再训练。

### 主线 B：数据一体化（临界 × 菜鸟）
登录整合（P1-1）→ 实体对齐（P1-2）→ 事件入图（P1-4）→ 联邦查询。原则：**不合库、不重写、图中介**——菜鸟业务事件挂到元子图谱已有节点，元子成为两系统共同语义层。顺序上登录先行（依赖最少、用户感知最强）。

### 主线 C：图谱智能化（元子）
血缘三表（P1-3）→ 语义边工程（K265/K266 汇合）→ nl_query 扩展（自然语言问图）→ 图谱直接支撑 AI 投研问答与再训练。原则：**本体管分类、图管关系、PG/parquet 管明细、预计算管速度**，不把一切塞进图数据库。

### 底座线 G：治理永续（不占研发排期，滚动执行）
AGENT-PACT 执行、当天入库纪律、金样本闸门、PytestWeekly、备份/膨胀/TTL 三件套巡检、每阶段末主控审计（沿 v4 §七模式）。
