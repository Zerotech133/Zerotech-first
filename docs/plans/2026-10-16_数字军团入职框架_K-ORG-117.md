## 一、核心思想：把 HR 五件事做成机器可读的入职流水线

```
入职意向 → ① 递简历 → ② 定级考试(分数) → ③ 部门分配 → ④ 职务任命 → ⑤ 授能宣誓
              resume      score→E1/E2/E3     dept        title      tools_allowed
                                      ↓
                              名册登记(org_registry) + 建档(HR档案) + 开记忆账户
```

**一句话纪律：无入职，不上线。** 未入册的智能体在账本里出现 = 黑户（org_supervision 点名），其产出不进任何账本。

## 二、档案四件套（每个成员一份，`agent_platform/hr/<agent_id>/`）

| 件 | 文件 | 性质 | 内容 |
|---|---|---|---|
| ① **简历** | `resume.yaml` | 静态（入职时定稿） | 身份/血统/教育/工作经历/技能自述 |
| ② **任职书** | `appointment.yaml` | 半静态（晋升时更新） | 部门/职务/职级/权限/入职日期/审批链 |
| ③ **工作经历** | `experience.jsonl` | 动态（自动追加） | 每日 decision log 摘要 = agent__X__decision 的索引层 |
| ④ **绩效考核** | `review.yaml` | 周期（月度） | 影子期转正/产出质量/KO 率/老田评语 |

## 三、定级考试（分数 → 职级）

不搞玄学评分，**用已有产线数据说话**——三个可量化维度：

| 维度 | 数据源 | 权重 | 计分 |
|---|---|---|---|
| **判读质量** | 影子期命中记录（如 A0 的三要点命中、Jev 的复核命中率） | 50% | 影子 N 单中命中/显错比 |
| **产出质量** | QA-RUN 通过率（K-ORG-087 T3）、一次通过 KO 率 | 30% | 近 30 单 rc=0 比例 |
| **纪律记录** | org_supervision 体检历史 + 越权/黑户告警次数 | 20% | 零事故=满分 |

**定级线**（新岗默认 E1 起，符合军团现状 DEV7/QA2/TR1 均为 E1 的渐进传统）：

- **E1 见习**（<60 分）：影子期强制，产出必须挂 review，无独立开单权
- **E2 正式**（60~80 分）：独立执行，产码走标准评审门
- **E3 骨干**（>80 分 + 影子期满）：可带项目、可审他人单、可入项目部

**特批通道**：老田可直接任命 E3（如田小皮 A0、LEG1——外脑引进的专家岗），但 appointment.yaml 的 approvals.human 字段必须留痕。

## 四、入职流水线（onboard_agent.py，已交付初版）

**用法一：全流程入职**（新智能体上线）
```
python agent_platform/onboard_agent.py --resume 新员工.yaml
# 自动：校验简历 → 定级（读影子数据，无数据则 E1）→ 建议部门（按 skills 匹配部门宪章）
#     → 生成任职书草稿 → 人审（田小皮+老田）→ 写入 org_registry v2 + 建 HR 档案 + 开记忆账户
```

**用法二：一句话入职**（对话式，老田提到思路时）
> 老田说"我们要一个管 OSINT 采集的 AI"→ 参谋长田小皮起草简历草稿 → 老田补关键信息 → 走同一流水线。**思路提及 = 入职意向登记**（116 §四"出生即入籍"的对话版）。

**用法三：存量补办**（K-ORG-116 六运行体）
```
python onboard_agent.py --backfill jev_gate,cowbridge,hermes_webui,...
# 从代码 docstring/守护任务/端口自动反推简历初稿，人只补 kpi 与自述
```

## 五、与现有体系的挂接（零重构）

| 现有件 | 挂接方式 |
|---|---|
| org.json / claude_agents.json | onboard 通过后自动追加（v2 schema，116 一批） |
| agent__X__{decision,knowledge}.jsonl | 入职即建空账户；experience.jsonl 每周从 decision 摘要 |
| org_supervision.py | 新增 check_hr()：① 名册成员 100% 有档案 ② 账本黑户=档案缺失告警 |
| devtask 工单 | E1 岗开单自动挂 review 标签；dispatch 权限按 rank 矩阵 |
| Hermes 军团面板 | 成员卡片显示简历摘要+职级+最近经历（只读转调） |

## 六、生命周期全景（本框架覆盖的完整闭环）

```
入职(本档) → 试用/影子(既有影子纪律) → 转正(月度review) → 晋升(分数达标+开单)
     ↘ 兼职项目部(既有虚编制) ↘ 轮岗(dept变更留痕) ↘ 离退(档案封存，记忆归档)
```
