- 状态：**已定稿执行（2026-11-02）**
- 定位：**平台技术框架的唯一完整计划**；服从 `ROADMAP v4`（唯一战略源）与 `AGENTS.md`（宪法）；详细契约见 ADR-015/016/017、ADGS v1.1、ZBF v1 总纲
- 依据：老田 2026-11-02 拍板（唯一宿主、ZBF v1、ADGS v1.1、W0 收编、五件事执行、不再逐项选择）
- 执行状态：P0 立法、框架总纲、ADGS v1.1、W0 收编（安全回收）、P1 组合运行时 MVP 已完成；本方案覆盖剩余全部工作

## 〇、一页结论

**一套宿主、一套内核、一套组合、一条黄金路径、一道门禁、一张排期。**

- 宿主：零界（8734 唯一入口）；智策收敛为 `quant-domain`（内部 API + 页面包 + PG + 日管线）。
- 内核：K0–K8 契约冻结（schema/注册表/门禁），实现可替换。
- 组合：C1–C8 用 `compositions/<id>/manifest.yaml` 声明，只引用不内嵌。
- 路径：所有开发只允许组合变更 / 实现替换 / 内核变更（ADR）三种形态。
- 门禁：composition validate + kernel_guard + devtask 九门 + Q1–Q4 + ADGS 证据包。
- 排期：W0 收编 → W1 组合纳管 → W2 单栈（L1）→ W3 解耦 → W4 组合化；三个硬节点 **11-04 / 11-08 / 12-02**。

## 一、统一目标（可验收）

1. **单宿主**：运维上只操作零界 8734；5175/8102 在 12-02 前关停。
2. **单入口/单身份/单库/单调度/单账本**（ADR-016 "一套" 7 项）。
3. **组合化**：新增/删除军团、产品、策略、页面、数据包、工作流 = 只改 `compositions/**`，内核 diff=0。
4. **可治理**：质量分级 Q1–Q4；内核改动 100% ADR；证据包 DOD 100%。
5. **可演进**：技术实现（模型/数据源/运行器/前端壳）可替换，调用方零改动。

## 三、统一架构（分层）

```text
唯一宿主：零界 8734
  ├─ 控制面：portal-api 8091（stdlib，保留）
  ├─ 业务面：quant-api 8105（FastAPI，内部）
  ├─ 页面：portal 静态壳 + /quant/* React 页面包
  ├─ 调度：job manifest + runner（Windows 任务仅触发器）
  └─ 组合层：compositions/*（C1–C8）+ registry + CLI
内核 K0–K8：契约/schema/注册表/门禁（不冻结实现）
适配器：LLM / Agent 运行时 / 数据源 / 通道 / 外部产品
```
