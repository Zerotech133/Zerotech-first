## 1. 用法

```bash
# 默认：最新交易日自动探测 + RS off（与原筛选行为一致）
python tools/research/screening_20261101.py

# 指定数据日 + 量学信号 ∩ 板块 RS 模式 C，清单最多 30 条
python tools/research/screening_20261101.py --date 20261030 --rs-mode C --rs-top 30

# 输出到指定目录（默认 research/reports）
python tools/research/screening_20261101.py --date 20261030 --rs-mode B --out-dir tmp/screening_rs
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--date` | 最新交易日（自动探测 `quant_backtest/data/tushare/daily/d_*.parquet` 最大日期） | 数据日 YYYYMMDD |
| `--rs-mode` | `off` | `off`（保持原样）/ `A` / `B` / `C` |
| `--rs-top` | 50 | RS 交集清单展示条数上限（0=不限；JSON 额外给 `intersection_count` 全量计数） |
| `--out-dir` | `research/reports` | 输出目录（JSON/MD 同名 `screening_<date>.*`） |

## 2. 口径

- **板块强度 = 行业等权当日涨幅**：读 `d_<date>.parquet` 的 `pct_chg`（百分比数值，如 `2.5` = +2.5%），
  按 `stock_basic.industry` 分组取**等权平均**（行业缺失的股票不参与 RS 判定）。
- **RS 判定**（个股涨幅 vs 板块等权涨幅，pct_chg 均为百分比数值）：

| 模式 | 条件 | 含义 |
|---|---|---|
| A | 个股涨幅 ≥ 板块涨幅 | 跑赢板块（相对强度） |
| B | 个股涨幅 ≥ 板块涨幅 + 1.0 | 超额 ≥1.0pp（强相对强度） |
| C | 板块涨幅 ≥ 1.0 **且** 个股涨幅 ≥ 1.0 | 板块与个股同步走强（动量共振） |

- **量学信号 ∩ RS**：量学四个研究因子（LX20 牛股三绝 / LX06 长阴短柱 / LX12 双阴出货 / LX22 凹口淘金）
  在当日非零信号的**并集**，与 RS 通过名单取交集；清单字段：
  `rs_flag / ts_code / name / industry / pct_chg / board_pct_chg / excess_pp / signals[]`。

## 5. 边界与局限

- **C 模式不要求超额**：只要板块与个股均 ≥1% 即通过，故清单可能含「跑输板块但个股仍强」的标的
  （如五粮液 +3.35% vs 白酒板块 +5.27%，超额 -1.93pp 但仍属 C）；如需强相对强度应选 B 模式；
- RS 为**当日**相对强度，不含趋势/持续性/量能确认，需与量学信号、S01/H14 风控组合使用；
- 行业等权口径对行业内大市值不敏感；行业分类来自 `stock_basic`（可能滞后于最新调整）；
- 量学信号为**反向/规避研究线索**（S05 已关闭），交集只表示「当日同时出现」，不构成买入信号；
- 停牌/涨跌停、ST 等未额外过滤（沿用原数据口径）；研究输出，不构成投资建议。
