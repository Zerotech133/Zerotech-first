## 一、背景

055 计划 F6b 验收口径：复核结论落 events + 只读面验证（无写工具）。
现状 review_one 走 chat_auto（纯补全对话，模型看不到仓库，只能信截断 diff+附证）。
agent_coder.chat_claude（Claude Code CLI headless）带工具环但默认降级链 blocked。

## 二、方案条目（SEC2 走查对照基准）

- **P-1**：review_one 主路径改为 chat_claude("QA1")，`allowed_tools="Read,Grep,Glob"`
  （只读三件套，无 Edit/Bash/Write 写面），max_turns=15，timeout=600。
- **P-2**：prompt 追加 READ_ONLY_ADDENDUM 只读纪律附言：可直读仓库核现状
  （根治 K-ORG-042 判例「diff - 行非现状」），附证计数可用 Grep 抽查复核。
- **P-3**：异常（CLI 缺失/超时/rc 非零）降级 chat_auto 并 stderr 留痕，质检不中断。
- **P-4**：验收=实测真实 sha（5792cc0）复核出结论 + review_verdict 落账 + 只读面
  静态断言（allowed_tools 串不含 Edit/Bash/Write）。

## 三、已知环境限制（非缺陷）

沙箱会话内 claude.cmd 子进程 spawn EPERM + reg.exe 黑名单拦截——主路径在沙箱内
不可用属环境限制；降级链实测工作（结论+落账全通）。非沙箱环境（老田终端/CI）
chat_claude 主路径可用（052 起既有实测）。
