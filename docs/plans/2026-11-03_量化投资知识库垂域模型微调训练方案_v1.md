## 1. 一句话结论
**不做 CPT，走「QLoRA SFT + DPO」两段式**：Qwen2.5-14B-Instruct（7B 先行冒烟）+ LLaMA-Factory，AutoDL 租 1×4090 24G，全流程 **5.5~10 卡时、总成本中位 ~¥50（上限 ¥240 < ¥300 红线）**。
理由：域内语料仅 ~52 万 token（距 CPT 门槛差 3 个数量级），但治理质量极高（人工双签、审计 0 问题、决策链完整），是 SFT+偏好对齐的优质小数据；本机/生产服务器均无 N 卡，训练必须云租。

## 3. 数据资产勘查（石语澄）
### 3.1 四个硬事实
1. **05 表同 concept 通过/驳回共存 = 0 对** → DPO 主体必须走拒绝采样；
2. **指标说明书.md 整文件是目录/图片引用**（871 单元，占 01 表 39.5%，清洗后仅 32 条目录行存活）→ 整文件剔除；
3. 治理「去重 0」仅覆盖视频号 800 单元；**全量实测精确冗余 161 条 + KEEP 集近重复 168 对（Jaccard≥0.7）** → SFT 前必须重跑去重；
4. **02↔05 有 188 条 a 列全文重复** → 按 concept 去重合并 → **唯一 QA 541 条**。
其他：样板话术污染 171 条（7.8%）；占位符噪声 155 条；超长单元 4 条（max 50669 字需切分）；PII 命中 0；q 模板 339/400 都是「什么是「X」？」（需变体改写稀释）。

### 3.2 清洗管线（7 步，2204 → ~1000-1100 干净单元）
规范化 → 占位符剔除（-155）→ 长度过滤（<30 剔除 + 指标说明书整文件剔除，2204→1148）→ 超长切分（>1500 按段落 ≤800 块）→ 样板话术句级剔除（黑名单正则，免责声明移入 system prompt）→ 精确+MinHash 去重 → 质量打标（cjk_ratio/来源/长度桶）。字符留存 ≥80%。

### 3.3 SFT 构造（~2600-3100 条）
| 类 | 来源 | 条数 | 要点 |
|---|---|---|---|
| A 概念 QA | 02 ∪ 05通过 去重 | 541 | 05 通过 329 中 141 新增 |
| B 结论改写 | 03 表 | 100 | 低置信 71 带不确定性后缀；事实型 11 q 注入 as_of |
| C 阅读理解 | 01 清洗产物 | ~950-1050 | output 强模型生成要点 + 人工抽检 10% |
| D 多源交叉卡 | 04 表 | 27 | 质量最高，末段退火 ×2 加权 |
| E 变体增强 | A/B 改写 | +1000-1400 | 口语化/场景化/对比式；embedding 0.7-0.95 过滤 |
| F 通用回混 | BELLE/Firefly/COIG | 800-1200 | 取 10%，防垂域腔 |

配比：战法 42% / 量化工程 20% / 研报事实 15% / 概念卡 15% / 多源卡 3%；来源 token 比 8博主 45% / 研报+Ace 32% / 老木 8% / 通用 15%；同源上限：同一 evidence_file ≤120 条。Held-out **105 条**（概念 55 + 笔记 50，同 concept 变体同侧）永不入训练。

### 3.4 DPO 构造（~850-1250 对）
① 需修改自我配对 25 对（rejected=含「点个小关小助」元信息污染原版）；② 驳回+重生成 10-13 对（人工确认）；③ 拒绝采样主体 800-1200 对（k=8 temp=0.9，规则门控+裁判分差≥3）；④ 句式鲁棒对 30-50 对（rejected=复读原文）。quality_score 无区分度（7 分占 377/400），不作信号。

## 4. 训练方案（唐炼之·终版）
- CPT 排除；QLoRA（NF4+double quant，bf16 计算）r=32/α=64/lora_target=all 起步；r=64 条件触发（格式回放 100% + 命中差>10pt + train loss 平台三条同时成立，epoch 降 2）。
- 7B 先行三职（冒烟/LR sweep/数据质检探针）→ 14B 正式（LR=7B 赢家×0.8 再×0.7，不重扫）。
- SFT：cosine、warmup_steps 10-15、mb2×ga8（抖动大→ga16）、packing false、cutoff 2048、3 epoch 封顶、dropout 0.05、NEFTune 第一轮不开。
- LR sweep：7B [5e-5,1e-4,2e-4] × 10% 子集 ~57 step，取「降得快不 spike」最大值×0.8。
- 防遗忘：通用 10% 单阶段联合训练（末 20% step 域内高置信 ×2 退火）。
- DPO：sigmoid β0.1、LR 5e-7、1 epoch、mb1×ga16（→32）；监控 rewards/accuracies、margins、logps/chosen、logps/rejected；rpo_alpha 触发=logps/chosen 降>15% 且连续≥15 点。

## 5. 对齐方案（齐衡之）
- 范式：**DPO sigmoid**；拒绝采样天然产出多样本排序。IPO 备胎（裁判自洽<70% 才切）；KTO 降级（<600 对先挤水 3→2.5+自洽复检）；SimPO/ORPO/PPO/GRPO 排除。
- 奖励管线：规则分是门不是分；裁判 rubric 四维（知识正确性 40% 一票否决/结构 20%/简洁 20%/边界 20%），长度零权重+冗余>30% 扣半+高置信带保留语扣分；temperature=0、双向位置交换取平均、结构化 JSON。
- k=8 簇四形态：正常构对；全好→best-of-8 回流 SFT；全坏→RAG-only 或补 SFT（>15% 停线）；半坏降 k。
- **[必须] DPO adapter 起点=加载 SFT 终验收 adapter（同 target/rank/alpha），ref=SFT 权重非基座**。
- Reward hacking 六模式防线（长而空洞/公式堆砌/免责刷分/过度拒答/logprob 双向压低/模板腔）；总闸门：margins 涨但 held-out 胜率不涨=确诊→回滚修数据。
- 发布闸门：胜率≥60%（<50% 弃 DPO）+ 拒答双组（误拒≤5%）+ 风险提示 100% + 高置信误触发≤5% + 格式不回退 + 通用退化≤2pt（>3pt 回滚）。

## 6. 工程与预算（柏容通）
- 硬件：本机/生产服务器无 N 卡 → **AutoDL 1×4090 24G**（¥1.5-2.5/h），恒源云/仙宫云备选。
- 显存：14B QLoRA SFT 14-19GB；14B QLoRA-DPO ~14-18GB（单 4bit base + policy/ref 双 adapter；**DPO OOM 点在 eval**）；7B 富余。
- OOM 降级：eval batch=1 → max_length 768 → 7B DPO → 预计算 ref logps → ref offload。
- 必须修订：①DPO eval_steps 50→10、save_steps 20→10（总 step 仅 ~19-31）；②per_device_eval_batch_size=1；③磁盘时序管理（峰值 70-90GB > 50GB 免费盘：先 7B 训完删原件再下 14B、merge 完删 bf16，或扩盘 +50GB ~¥10）；④warmup_steps 5→10-15、抖动先 ga8→16；⑤采样/评测统一 merge→AWQ-int4→vLLM。
- 成本：卡时 5.5-10h / 纯卡费 ¥11-25；裁判 API ¥10-45；胜率+校准 ¥3-8；**总计中位 ~¥50（¥25-90）**，旗舰裁判路线 ¥80-240。
- 不可砍：公式可执行率评测、held-out 105、DPO dev 64、人工校准 50 对、SFT 格式回放。

## 9. 风险与回退
| 风险 | 触发 | 回退 |
|---|---|---|
| SFT 过拟合 | train loss<0.1 / eval 升 / held-out 回落 | dropout→0.1；epoch 3→2；通用→15%；回滚 ckpt |
| 知识注入不足 | 格式 100% + 命中差>10pt + loss 平台 | 查知识密度 → r=64+epoch2 → LR+30% |
| 灾难性遗忘 | 通用退化>3pt | 通用 15% 重跑；DPO 后 β 0.3 |
| DPO 崩坏 | 四曲线异常 | LR 减半→β0.3→rpo_alpha 1.0→弃 DPO |
| 偏好对不足 | <600 对 | 阈值 2.5+自洽复检挤水→KTO |
| reward hacking | margins 涨胜率不涨 | 回滚+修构造侧，不调参硬扛 |
| 14B DPO OOM | CUDA OOM | eval batch1→max_len768→7B DPO→预计算 logps |
| 磁盘打满 | >50GB | 时序删权重；或扩盘 ¥10 |
| 版权合规 | 对外商用 | 研报直引样本（147+11）替换自研改写版；不出现原文长段 |
| 时效污染 | 把 2026.09-10 行情当现状 | as_of 双侧注入；事实类走 RAG 不靠参数记忆 |
