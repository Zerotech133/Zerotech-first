## 0. 一句话结论

**采用「轻首页 + 深工作台」双层结构：根首页只负责“今天去哪”，5 个领域负责分流，少量专业工作台承担深任务，89 个长尾入口收进命令面板/直达链接；不搞 69 页全量重做，也不把长尾页面全部塞进首页。**

最优路径：**先壳（首页/导航/搜索）→ 再主链（量化、情报、研发/运维）→ 最后长尾收编**；每步可验收、可回滚。

## 2. 三条候选路径与选择

| 路径 | 做法 | 优点 | 风险 | 结论 |
|---|---|---|---|---|
| A. 全量重做 | 69 页逐页重设计 | 一次到位 | 工期长、回归面大、老功能易丢 | ❌ |
| B. **壳先行 + 主链优先 + 长尾收编** | 先把首页/导航/搜索/组件做好，按任务链迁移 | 快、风险低、可验收 | 中途存在新旧混用 | ✅ **最优** |
| C. 双皮肤/iframe | 旧页套 iframe/双皮肤 | 改动小 | 双层滚动、链接断、技术债 | ❌ |

**选择 B**：页面改造按“用户每天必经链路”排序，而不是按目录/模块排序。

          ▼

### 三个硬规则

1. **一个首页只答一个问题**：今天去哪；不堆指标、不依赖 8798。
2. **每页一个主操作**：模拟仓=看计划/风控；策略=选策略；选股=看 T1/T2；深屏=看今日/大屏。
3. **功能不删除，默认收起**：长尾、机制、全量清单、旧页通过折叠/抽屉/命令面板可达。

## 4. 最优路径（用户动线，不是开发顺序）

| 场景 | 最优路径 | 目标 |
|---|---|---|
| 每日开盘 | 首页 → `/paper` → 今日计划/风控 → 持仓/复盘 | **2 次点击内**进入执行 |
| 选股 | 首页 → `/picks` → 默认 T1/T2 20 条 → 个股/模拟仓 | 首屏 30 秒内有结论 |
| 选策略 | 首页 → `/strategies` → 实盘 6 条 → 策略详情 | 默认不被影子/支撑干扰 |
| 看系统 | 首页 → `/os-entry` | 专业深屏独立 |
| 找旧页 | ⌘K/命令面板 → 89 入口 | 不靠记 URL |
| 驾驶舱 | 首页标注「需桥」→ `/zero_proto.html` | 桥恢复后启用 |

## 5. 整体设计

### 5.1 双表面（不是两套产品）

| 表面 | 用在哪 | 视觉 |
|---|---|---|
| **浅色首页/驾驶舱** | `/`、`/zero_proto`、领域入口 | 白底、青蓝 #0e7490、卡片化、低密度 |
| **深色专业工作台** | `/paper`、`/picks`、`/os-entry` | 深海军蓝、青 #6bd7e5、表格/证据、高密度 |

共享：语义色、字体、间距、焦点/状态、A11y；不共享：背景/密度/导航形态。

### 5.2 页面模板

- L0 首页：Hero + 四主卡 + 低频入口 + 状态/边界。
- L1 领域：状态条 + 任务队列（≤5）+ 最近结果/异常。
- L2 工作台：页面头 + 主任务区 + 侧栏/抽屉 + 最近证据。
- L3 明细：实体头 + 证据链 + 历史/审计。

### 5.3 实体链（跨页联动）

`date → symbol/signal → task/trace → report → decision/card → adoption → review`

页面 URL 约定参数：`?date=&symbol=&signal_id=&task_id=&trace_id=&decision_id=&from=`；不执行，只做上下文。

### 5.4 导航与搜索

- 顶部固定 6 项：今日 / 量化 / 情报 / 创作 / 研发 / 运维；
- 页面级最多：面包屑 + 业务 Tab；删除重复快捷条；
- 89 入口进 **⌘K 命令面板**（已具备 W3 基础）；
- 旧页保留，逐步 301/直达，不一次性删。

## 8. 指标

- 首页到任一主页面 **≤1 次点击**；到任务 **≤3 次点击**；
- 首屏信息块 ≤6；首屏文字量较旧版减少 ≥40%；
- 默认列表 ≤20 条；长尾可达率 100%；
- 跨页实体上下文（date/symbol/task）保持率 ≥95%；
- UI 审计：无硬伤；A11y：skip/focus/reduced-motion 全过；
- 不出现「旧首页/数据 Failed to fetch/三层导航」。
