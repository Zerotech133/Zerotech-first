# 黄忠 × Hermes 底层结合方案 v1（2026-10-31）
> STATUS: declared



> 拍板背景：老田 2026-10-31 指示「（黄忠项目）和 Hermes 的底层结合」。
> 先例：`D1 ↔ Hermes A/B 落地 v1`（WO-D1-HERMES-BRIDGE-20261030，2026-10-30）——工具面 MCP + 身份面 profile + 控制面 Tile；本方案沿用同一模式，按「黄忠是确定性验收尺子、Hermes 是交互/编排/控制面」划界，**不把验收逻辑迁进 Hermes、不开放写操作**。

## 一、边界与定位

| 层 | 归属 | 说明 |
|---|---|---|
| 交互/会话/工具编排/提醒 | **Hermes 8787** | WebUI、profiles、MCP 工具面、cron、飞书通讯中枢 |
| 验收/守门判定（六条、证据门、拒收/漏放） | **黄忠（本仓 tools/）** | 确定性、可复算、可审计；不对 Hermes 让渡判定权 |
| 执行调度 | Windows Scheduler | `HuangzhongDaily`（30min）、`HuangzhongEvidenceRefresh`（20:00） |
| 观测/控制面 | 8091 执行健康总线 + Hermes console Tile | `portal/execution_manifest.json` 白名单（R1） |

一句话：**Hermes 当「嘴和手」，黄忠当「尺子」，验收证据链留在仓内、只读暴露给 Hermes。**

## 二、四个面（本次只落面 1 + 面 2 的只读部分，其余待批）

### 面 1：工具面（Tool Plane）— Hermes → 黄忠（本次落地）

新增 stdio MCP server：`agent_platform/tools/huangzhong_mcp.py`（纯 stdlib，Python311 可跑，只读）：

| 工具 | 返回 |
|---|---|
| `huangzhong_status` | 六条复核聚合（passed/total、各条 status/measured）、最新验收单、证据年龄、④满窗/跟踪 |
| `huangzhong_review_latest` | 最近一次 `review_*.json` 明细（items/kpi） |
| `huangzhong_evidence` | 基线/红队 `generated_at/age_hours/stale/≤48h` |
| `huangzhong_acceptance_latest` | 最新 `acceptance_*.json`（verdict/commit/reasons） |
| `huangzhong_weekly_kpi` | 7 天窗口 runs/merge_done/覆盖率（只读计算，不落盘） |
| `huangzhong_tasks_health` | 两个计划任务 LastRun/rc/NextRun（只读 PS 查询） |

Hermes config 注册（`~/.hermes/config.yaml` → `mcp_servers.huangzhong`）：

```yaml
huangzhong:
  command: "C:\\Program Files\\Python311\\python.exe"
  args:
    - "C:\\项目\\老田的AI助手\\agent_platform\\tools\\huangzhong_mcp.py"
```

> 与 D1 桥一致：注册后需**重启 Hermes 8787** 才加载；重启前为 `configured/active=false`。

### 面 2：控制面（Control Plane）— 执行健康总线 / Hermes Tile（本次落地）

在 `portal/execution_manifest.json` 白名单登记两个任务：

- `HuangzhongDaily`：cadence 30min / grace 30min（`cron :15/:45`）；
- `HuangzhongEvidenceRefresh`：cadence 1440min / grace 4320min（每日 20:00）。

效果：8091 `/api/execution/health` 与 Hermes console「任务执行」卡（R1/R3）可看到黄忠任务红绿；`manifest` 每次请求读取（30s TTL），**改完即生效、无需重启 8091**。

## 三、为什么不是「迁进 Hermes」

1. 黄忠判定必须可复算/可审计（六条 + 证据年龄门 + 拒收台账），Hermes 9B 会话不适合承载确定性裁决；
2. 验收证据链在仓内 gitignored `work/` + `docs/plans`，迁移会破坏审计；
3. D1 先例已验证「MCP 双向 + profile + tile」模式成本低（一个 stdio server + 一行 config + manifest 两行）。
