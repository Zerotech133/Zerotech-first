# 研报面板门户接入 v1（2026-11-01）

> STATUS: declared(active: 2026-11-02 补标；owner=原作者/待评审)

> 任务单：task-15（wave5 · O 研报面板接入门户）。上游：wave4 `task-12` 研报评审面板 v3（候选 1、精确页码校验、人工复核清单）。
> 本文档记录「v3 多智能体研报面板 → 门户静态 JSON → selection.html 区块」的数据流、字段、页面区块与限制。

## 1. 背景与目标

研报评审面板 v3 的产物只落在 `research/reports/`，未进入门户。本接入的目标：

1. 把 v3 面板结果压缩为门户可直接消费的静态 JSON，**带数据生成时间与免责声明**；
2. 在既有选股页 `portal/selection.html` 增加「研报候选（多智能体）」区块（候选表 + 被拦截/复核提示页签），
   不新增页面、不改 nav、不动其他页面；
3. 提供可重复执行的导出 CLI（`export` / `--check`），失败不阻塞门户（前端降级文本显示）。

## 2. 数据流

```
research/reports/report_panel_v3_20261101.json   ← v3 面板产物（3 篇 × 双模型 × 3 角色 + 人工复核清单）
        │
        │  python tools/research/panel_export.py export --check
        ▼
portal/static/report_panel.json                  ← 门户静态数据（含 disclaimer / generated_at / exported_at）
        │
        │  fetch('/static/report_panel.json?ts=...')（selection.html 内 JS）
        ▼
portal/selection.html · 研报候选（多智能体）区块
   ├─ 概览卡：评审研报 / 进候选 / 被拦截 / 页码越界 / 人工复核勾选位
   ├─ 页签：候选 ｜ 被拦截 ｜ 复核提示（含精确页码越界明细）
   └─ 降级：fetch 失败或 JSON 异常 → 文本提示「研报面板暂不可用」+ 离线文件路径（不影响本页其他区块）
```

导出器只读 v3 JSON，不触发 LLM、不修改 v3 产物；门户 JSON 每次导出覆盖，`exported_at` 记录导出时间。

## 3. 门户 JSON 字段（`portal/static/report_panel.json`，v1）

| 字段 | 说明 |
|---|---|
| `generated_at` | v3 面板生成时间（上游数据时间） |
| `exported_at` | 本次导出时间 |
| `source` / `panel_version` / `date_tag` | 上游文件、面板 schema 版本（3）、日期标签 |
| `models` | 主模型（qwen3.5:9b）/ 交叉模型（qwen3.6:35b-a3b）/ 降级模型（qwen3.5:4b） |
| `disclaimer` | 短声明：**仅供研究，不构成投资建议** |
| `disclaimer_full` | 完整声明（含「不构成任何投资建议」「候选需经人工复核」） |
| `summary` | 概览：reports/candidates/rejected/page_invalid_facts/rule_fallback_roles/retries/elapsed_seconds/conclusion |
| `candidates[]` | 候选池：report_id/title/date/pages/pass_models/primary_pass_roles/role_agreement_rate/page_issue_count/model_verdicts |
| `reports[]` | 逐篇：candidate 判定、`verdicts[]`（3 角色 × 2 模型的 verdict/来源/页码有效率/是否降权/是否重试）、model_verdicts、role_agreement_rate、verdict_agreement、key_facts_overlap、page_issue_count、conditions、reasons |
| `rejected[]` | 被拦截研报（`reports[]` 中 candidate=false 的子集，含拒绝原因） |
| `review` | 人工复核清单摘要：`file`（research/reports/report_panel_v3_review.md）、items[]（每篇 facts_total/facts_invalid/opinions_total/open_checkboxes/reject_reasons）、open_checkboxes 合计 |
| `page_issues[]` | 精确页码越界明细：report_id/model/role/fact/page/allowed_pages |

**候选判定口径（上游 v3 固定）**：≥2 模型 pass 且主模型 ≥2 角色 pass 且精确页码校验通过（key_facts.page ∈ 来源单元 `page_start ±1`）。
本次真实数据：3 篇评审、候选 1 篇、被拦截 2 篇、精确页码越界 1 处（v2 宽并集口径为 0）、规则降级 0/18、结论「达到」。

## 4. selection.html 区块

- 区块容器：`<div class="panel" id="report-panel">`，标题「研报候选（多智能体）」，插入在「今日候选（S01 过滤 + S02 复合排序）」面板之后。
- 概览卡 id：`rp-reports / rp-cands / rp-rej / rp-page / rp-check`；页签按钮 `data-rp-tab=cand|rej|review`；内容容器 `rp-body`；脚注 `rp-note`。
- 渲染：原生 JS + `textContent/innerHTML`（所有上游文本经 `esc()` 转义），页签切换只重渲染当前页签。
- 降级：`fetch` 非 200 或 JSON 解析失败 → `rp-sub` 显示「研报面板数据暂不可用（降级显示）」，`rp-body` 给出离线文件路径与免责声明；本页其他区块（策略库/选股/影子盘/观察）不受影响。
- 复用页面既有样式变量（`--panel/--bd/--acc/--ok/--warn/--bad`）与 `.badge` 类；新增 `.rp-tabs/.rp-tab` 两个轻量样式，不引入新视觉体系、不改 nav。

## 5. CLI

```bash
# 导出（默认读 research/reports/report_panel_v3_20261101.json，写 portal/static/report_panel.json）
python tools/research/panel_export.py export
# 导出并校验 schema/声明字段
python tools/research/panel_export.py export --check
# 仅校验已落盘门户 JSON（CI/巡检可用，exit 0/1）
python tools/research/panel_export.py check
```

校验项（`validate_portal_payload`）：必需顶层字段齐全、`disclaimer` 含「仅供研究」「不构成投资建议」、
`disclaimer_full` 含「不构成任何投资建议」、`generated_at` 非空、`reports[]` 每行有 report_id 与角色 verdict、
`review.items` 存在、`summary.candidates` 与 `candidates[]` 长度一致。校验失败时导出直接报错（不写坏 JSON）。

## 6. 限制与后续

1. 面板每篇只投喂知识单元摘要（claim+evidence 截断），非全文；候选仅为「值得进一步跟踪」的初筛。
2. 精确页码口径依赖入库知识单元的 `page_start` 粒度；本批同篇多条单元共享起始页，正文后段引用会被判越界 →
   需人工复核或改进入库页码锚定后再收紧门槛。
3. 门户 JSON 为**静态快照**，依赖上游手动/定时运行 v3 面板后再 `export`；未接入定时任务（后续可加 cron/计划任务 + check 告警）。
4. 前端只展示摘要，完整人工复核清单仍在 `research/reports/report_panel_v3_review.md`（Markdown，含 ☐ 勾选位）。
5. 免责声明：本面板由本地 LLM 多智能体评审自动生成，**仅供研究参考，不构成任何投资建议**；候选必须人工复核后方可使用。
