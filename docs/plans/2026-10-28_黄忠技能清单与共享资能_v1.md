- **不可写**：业务代码、org.json/bundle、计划任务、凭据、生产数据；

## 四、认证标准（观察期结束前）

1. 独立完成 **≥10 单**验收（PASS/REJECT/OBSERVE 均有）；
2. 误拒绝率 **<5%**、漏放（PASS 后 7 天事故）**=0**；
3. 每单证据链完整（基线/红队/回滚点/签字位）；
4. 赵云抽查 3 单一致；老田认可后进入"阻断模式"讨论。

> **v2 更新指引（2026-10-30 老田拍板 D4=A+B 并行）**：以上第 1~4 条为 **v1 原文（保留存档）**，自 2026-10-30 起**已被认证标准 v2 取代，不再作为认证依据**。v2 六条：①**≥10 单 PASS** 验收；②**≥1 次真实受控拒收演练**（版本回退/故障注入/历史失败证据构造，**禁造数据**，须记录证据链与回滚/复位）；③误拒绝率 **<5%**（人工复核 REJECT；自然 REJECT <20 单时按逐单复核判定）；④漏放 **=0**（以满 7 天窗口的 PASS 单为分母）；⑤证据链完整率 **100%**，且证据为 **commit 级或显式绑定、年龄 ≤48h**（工具默认门）；⑥赵云抽查 **3 单一致（3/3）**。
>
> - **取代关系**：v1 第 1 条「PASS/REJECT/OBSERVE 三类均有」在现行工具下无法自然达成（工具读全局最新证据，干净仓库任何 commit 均 PASS），v2 改为「≥10 单 PASS + ≥1 次受控拒收演练」的可执行口径。
> - **详见**：`docs/plans/2026-10-30_黄忠认证标准v2与验收工具证据口径拍板_v1.md`（六条判定细则、与 v1 差异对照表、11-04 复核口径、受控拒收演练操作口径）。
> - **工具配套**：A 单 `WO-HZ-ACCEPT-EVIDENCE-20261030` 提供 commit 级证据 / 证据年龄门（默认 48h）/ REJECT-OBSERVE 判定路径；本 B 单 `WO-HZ-CERT-V2-20261030` 落制度与指引。

## 五、与其它席位的协作接口

- **关羽**：交付修复+证据包 → 黄忠独立复跑（四眼原则）；
- **诸葛亮**：质询/红队用例 → 黄忠转成验收判据；
- **赵云**：平台质量门/审计数据 → 黄忠消费；漏放由赵云审计；
- **田丰**：验收结论进入日报与派单闭环；
- **老田**：最终准入签字，黄忠只给建议与拒绝。
