3. **fail-open 禁令**：任何异常必须落 `problems`/`warnings` 或影响退出码，禁止 `except: pass`、禁止把异常当成「空/到底/无问题」。
4. **不静默截断**：凡是「可能没取全」的地方必须显式报告（`has_more` / `truncated` / `complete`），调用方必须把这三态区分处理。
5. **add 即 commit**：只 add 自己独占的路径，禁用 `git add -A` / `git add .` / `git checkout` / `git reset --hard`。
6. **注释用语**：表达异常处理统一写 `closed on failure`。
7. 不重启服务、不真发消息、不接排程、不写真实库、不改计划任务。
