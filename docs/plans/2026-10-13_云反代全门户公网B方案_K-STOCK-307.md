# 云反代全门户公网发布（B 方案）· 拍板档 K-STOCK-307
> STATUS: unspecified（owner: TBD；2026-11-07 前补状态或标 superseded）



> 2026-10-13 老田拍板：上云反代，手机免 Tailscale、客户零安装看全门户。
> 判例链：K-STOCK-305（跨设备按钮一律公网域名）/ K-STOCK-306（WAF 拦 .SH 判例）/
> 本日新判例：iOS 中国区 App Store 已无任何主流组网 VPN（Tailscale 2023 下架），管理面手机化只能走公网。

## 1. 决策

| 项 | 定案 | 理由 |
|---|---|---|
| 客户面访问 | 公网域名零安装（305 既定），本单把「全门户动态页」也公网化 | 商业化不允许客户装工具 |
| 管理面（老田手机） | 同一条公网链（白名单外页 + 访问码） | iOS 国内装不了 Tailscale，双链维护成本高 |
| 隧道 | frp（frps 云端 / frpc 工作站主动外连） | 工作站无公网 IP，frp 最成熟；frpc 只出不进，不新开本机监听端口 |
| 云端反代 | nginx 白名单制，默认 deny | portal_api 是 23k 行巨石，全量暴露=灾难；只放商业化必需路由 |

## 2. 架构

```
手机/客户浏览器
   │ HTTPS 443（自建或 IP+访问码）
   ▼
腾讯云轻量 nginx（白名单反代 + 限流 + 访问码门禁）
   │ 127.0.0.1:8735（frps 本地隧道口）
   ▼ frp TCP 隧道（token 强随机）
工作站 frpc ──► 127.0.0.1:8734 portproxy ──► nginx 8080 ──► portal_api 8091
```

- 工作站侧零新监听端口（frpc 主动外连），不涉本机 REGISTRY 变更。
- 云端端口：frps bind 7000 / nginx 443、80 —— 均为云上资源，记本档备查。

## 3. 云服务器采购决策（老田已选「上云反代全门户」）

| 方案 | 适用 | 备注 |
|---|---|---|
| **推荐：香港轻量 2C2G** | 快速上线 | **免 ICP 备案**，当天可用；~30-60 元/月档；延迟 30-50ms 对看板/卡片场景无感 |
| 备选：广州轻量 + 自有域名 + ICP 备案 | 正规长期 | 域名 ~30-60 元/年 + 备案 1-3 周；商业化做大后迁移 |
| 过渡：IP + 非标端口 + 访问码 | 当天验证 | 无域名无备案也可先跑 M1 |

镜像：Debian 12 / Ubuntu 22.04 均可（nginx + frp 无差别）。

## 4. 安全铁则（云 nginx 白名单 —— 违者评审门拒收）

**默认 deny**（location / { return 404; }），只放行白名单：

| 放行 | 说明 |
|---|---|
| `/picks.html` + 静态资源 | 今日选股看板（含 K306 行内下钻） |
| `/kg/stock/<code>` | 个股只读详情（自有域名无 WorkBuddy WAF 的 .SH 403 问题） |
| `/bt`、`/bt-report` 只读 | 回测列表/报告（GET only） |
| 静态领域页 `/quant` 等 | 按需追加 |

**永久禁止出公网**：`/api/*`（系统探活泄内情）、`/devops`（开发指挥台）、
`/audit-ai`+`/api/audit_chat`（LLM 滥用）、`/ollama/*`（本地大模型）、
`/sa`、`/council`、`/debate`、一切 POST 写端点（portal_api 的 X-Portal-Token
机制仅护写口，读口仍要靠云端白名单挡）。

门禁：M1 全站访问码（复用 picks-xxxx 形态，云 nginx 层校验 query/header）；
M2 分客户访问码 + 限流（limit_req 5r/s burst 10）。

## 5. 分期

- **M1（本单）**：采购 → frps/frpc 隧道通 → 云 nginx 白名单 + 访问码 → 手机实测全门户
- **M2**：分客户访问码、限流、用量日志（后续单）
- **M3**：动态交互页（回测提交类）安全评估后再议（后续单）

## 6. 风险与教训预埋

- frp token 必须强随机（≥32 位），frps 的 7000 端口安全组只对工作站出口 IP 放不开则全开但强 token。
- 云 nginx 日志落盘 + logrotate（长跑输出落文件铁则）。
- 工作站 frpc 以 Windows 计划任务/服务托管，断线自动重连（frpc 自带 retry）。
- 商业化收费前必须过一轮安全审计（挂账，勿忘）。
