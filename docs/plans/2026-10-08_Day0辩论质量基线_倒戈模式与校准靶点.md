## 二、倒戈模式定性（两票同一剧本）

T1（多头）逐轮演变——**不是被说服，是没有多头信念**：

1. **r0 开场即看空**：根本没用多头视角陈述（601318 r0「看空。均线空头排列…」）——人设约束只在辩论中段起作用
2. **r1 被逼出多头论据**：反驳机制强迫下给出像样的多头论证（「空头陷阱特征」「低位承接意愿」）——证明模型有能力，是 prompt 没要求
3. **r2 缴械退回**：数据稍不支持就立刻放弃（601318 明写「数据不足，暂不给方向」），final 维持看空

对照坚守三票：r0 即看多且全程不动摇（sim 0.27-0.43，真分歧）。

## 三、连带风险

1. **假收敛链**：T1 倒戈 → 立场词趋同 → sim 飙升。601318 末轮 sim=0.78，距 0.8 收敛阈值仅 0.02——若触发，辩论以「立场塌缩」被误判为「达成共识」提前终止。**建议（影子后）：sim 收敛须叠加「T1/T2 立场对立仍在」双条件**。
2. **J2 判读注意**：倒戈票的 confidence 语义已变（T1 自弃 → D1 conf 被拉低），conf-vs-ret 秩相关里这两票的低 conf 不代表「决策质量信号」，10-15 评估需分「坚守票/倒戈票」两组解读。
3. **HOLD 集中度根源之一**：五票全 HOLD 不仅是 D1 保守（score 恒 0 的契约问题），两票多头自弃直接削弱多头证据。

## 四、10-15 后校准靶点（冻结期满执行）

1. **T1 prompt**：r0 强制「以本方（多头）视角开场陈述最有力的多头论据」；全程禁止宣布对立立场，担忧只能作为风险提示附加；明确「立场是角色职责，不是数据结论」。
2. **T2 对称检查**：本次两票 T2 全程看空无漂移（空头角色与弱势数据同向，未受考验）——若影子期出现强势数据票，需观察 T2 是否对称漂移。
3. **收敛判据**：sim>0.8 收敛 → 改为 sim>0.8 **且** 双方立场仍对立；立场趋同时以轮次上限收场并在 trace 标记 `collapsed`。
4. **D1 输入增强**（可选）：向 D1 明示「T1 是否倒戈」标签，倒戈票的多头缺席应影响而非消除多头视角。
