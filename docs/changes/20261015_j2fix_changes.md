# 20261015 J2 秩相关门禁修复（K-STOCK-397）

## 现象
10-14 正式跑（eval_shadow_2026-10-14_official.md）J2 rho=None、n=4，5 票后验%全部 +0.00（现价==决策价）。当时误诊为"价格源未刷新"。

## 根因（勘误：价格源没坏，是 J2 采样设计坏了）
1. 产线决策行在盘后 ~17:12 记账（账本 ts 实证：10-09~10-14 均为 17:11-17:14，10-08 为 14:59），`price_at_decision` 记的就是当日收盘价；
2. eval 同日 19:00 跑，`quote_snapshot` 盘后返回同一收盘价 → 持有期=0，后验恒 0；
3. 采样用 `per_symbol_latest`（每票只取最近一行）→ 永远落在零持有期行上，J2 结构性不可计算。

## 修复（eval_shadow.py，备份 .bak_20261015_j2fix）
- J2 改**逐行（交易日×票）后验**：基准=决策日 K 线收盘（kline_daily 权威价，账本快照价仅兜底），出场=最新收盘，`posterior_row()` 三分支（正常窗口/零持有期 pending/决策日不在K线兜底）；
- 零持有期行跳过并打印 `[pending] N 行`（下一评估日自动入样）；
- 新增价格源哨：全部后验=0 时打 `[warn] 全部后验收益=0`（防"失败不发声"复发）；
- [skip] 行补日期前缀；分组判读（坚守/倒戈）复用逐行明细，不再二次拉快照；
- 文档头补 K-STOCK-397 修复说明。

## 验证
- 新增 tests/test_eval_shadow.py 5 用例（spearman 性质/posterior_row 三分支/逐行采样+pending/全零告警/skip 可见），test_all() 入口范式，5/5 绿；
- agent_platform 全部测试 6/6 绿（1.76s）；
- 解除沙箱真实重跑：`eval_shadow_2026-10-15_official.md`——**J1 PASS / J2 PASS（score rho=+0.264, conf rho=+0.271, n=19）/ J3 PASS（25/25），结论 PASS**；
- 明细合理性：招行 10-09 决策 +3.02%（3日窗口）居首、宁德 10-12 -6.12% 垫底，K 线基准价与账本价差异 ≤0.8 元（快照 vs 收盘微差，权威价口径正确）。

## 样本口径注意
- n=19 中窗口 1~4 日不等（变长窗口"决策日→至今"），样本积累后建议改固定 T+5 窗口复核；
- 10-14 的 4 行 pending，下一评估日自动入样；
- rho=0.264 样本仍小（19 行、score 双值 0/1），只作方向门禁（>0），不作强度解读。

## 回退
`cp eval_shadow.py.bak_20261015_j2fix eval_shadow.py`（恢复后 J2 复原为 per-symbol-latest 采样，将回到 rho=None 状态）。
