# 20261014 HMM 软闸门离线对照研究

## 概述

- **性质**：研究线，不接产线、不注册任务、不改任何现有文件，数据只读。
- **动机**：产线环境闸门目前用市场宽度（breadth，湖口径）硬阈值；开源调研建议用 2-3 状态高斯 HMM 做软闸门（后验概率 + 迟滞）。本次离线对照 40/45/50 三档硬阈值，评估 HMM 是否有增量信息。

## 方法

- **特征**：`[breadth_t, breadth_t - breadth_{t-5}]`（宽度水平 + 5 日动量），标准化后拟合；对角协方差高斯 HMM；8 次随机重启（seed=42，可复现）取最高似然。
- **状态标注**：按各状态宽度均值从低到高重排，最低宽度 = 风险态（无收益信息参与标注）。
- **市场收益**：湖 `data/ashare` 抽样 400 只（4977 只全程在市中按均值成交额取前列），用 `pct_chg` 字段（tushare 口径，基于除权后 pre_close，等价后复权日收益）等权合成。注：`data/tushare/adj_factor` 日快照在样本区间内仅 79 天，过稀，close×adj_factor 插值会引入除权跳变，故弃用。
- **前向收益**：T+20 自 t+1 复利到 t+20（闸门 t 日收盘后计算、作用于 t+1 起）。
- **防未来函数**：主口径为 HMM 过滤后验（仅用截至 t 的数据），平滑口径单独列示。
- **迟滞软闸门**：风险后验 >0.6 进、<0.4 出。

## 结论

1. **BIC 选 K=3**，风险态（宽度极低+动量加速恶化，仅 19 天）T+20 均值 -3.845%/胜率 15.8%，与 mid/bull（约 +2.2~2.8%）区分度真实。
2. **HMM 有增量信息**：软闸门关闸日质量显著高于硬阈值档（-3.8% vs +3.0%），捕捉的是极端恐慌组合而非所有低宽度日。
3. **警示**：本样本期（2023-04~2026-10）为反转市，三档硬阈值关闸日前向收益反而高于放行日，按现方向硬闸门在样本内为负贡献——需跨周期验证后再下产线结论。
4. **重合度低**：软闸门是硬阈值45 关闸日的极小子集（recall 4.5%），不是同一信号的重参。
5. **成本**：迟滞软闸门 0.3 次/年 vs 硬阈值 26.6 次/年，但风险态过稀（单段 19 天），频次优势不能直接外推。
6. **建议**：研究线继续推进滚动拟合版本 + 更早行情外推；产线上优先考虑「硬阈值 + HMM 极端状态并联加险」而非替换。

## 局限

- EM 全样本拟合，模型参数含全样本信息（过滤后验本身无未来函数，但非严格可交易口径）；实盘需滚动拟合。
- 风险态仅 19 天、单一恐慌段，收益统计自由度极低。
- 市场收益为 400 只抽样等权，与 breadth（湖内全量）口径有差。
- 样本期不足四个牛熊循环；迟滞参数 0.6/0.4 未寻优。
