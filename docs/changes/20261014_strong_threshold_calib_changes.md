# 20261014 strong 250日超额阈值周度自校准研究（W5b / W1-3 挂账项）

## 一句话结论

**判定不通过：维持固定 ±10pp 阈值，不建议周度自校准。**
分位自适应（P85/P90）既压不进目标厚度带（判定 A 失败），又让名单 T+20
相对收益单调变差（判定 B 失败）；把分位拉到 P99 才接近目标带，但 T+20
恶化到 -2.05pp（固定版 -0.51pp）。厚度漂移的量化证据已留档，若未来要
控厚度，对症抓手是名单分层/限流，不是动阈值（见第六节备忘）。

## 判定（任务书标准）

- **判定 A（厚度稳定性，需 ≥+20pp 提升）：失败。**
  P85 命中率 0.0%（+0.0pp）、P90 2.9%（+2.9pp），远低于 +20pp 门槛。
  全量口径下名单厚度量级是数百只，P85/P90 分位（阈值中位 43/64pp）
  根本压不进 [5,20] 带；拉到 P99（阈值中位 244pp）才到 31.7%，但——
- **判定 B（名单调优，T+20 不差于固定）：失败。**
  fixed=-0.51pp vs P85=-0.67 / P90=-0.71；分位网格上 T+20 随阈值
  **单调恶化**（P99 达 -2.05pp）。机理：分位校准只改厚度、不改名单的
  动量属性——阈值越高，名单越集中在「250 日已涨上天」的尾部，
  后 20 日相对板块回吐越多。
- **结论：recommend = keep-fixed-threshold（维持固定 ±10pp）。**

附注：固定版自身 T+20 也是负的（-0.51pp）——strong 名单本质是拥挤
动量组合，短周期跑输板块是信号属性问题，与阈值高低无关；这进一步
说明「调阈值」救不了名单质量。
