## 二、网格设计

**回放口径（PIT）**：信号日 T 用 T-1 及以前可得的四源票聚合；候选 T+1 开盘买、持有 5/10 日收盘卖；成本单笔往返 15bps；每日按排序键降序取 TopN=10；宇宙=market_scan.market_stocks()（5036 只，剔 ST/北交所/指数）。

**四源票定义**：

| 源 | 权重 | 方向判据 | 历史口径 |
|---|---|---|---|
| qpzm | 1.0 | RPS mix(50:0.4/120:0.3/250:0.3)≥70 且 收盘>MA20 → long；mix<30 且 收盘<MA20 → short | 近端复刻（非产线口径） |
| sig4 | 1.0 | 逐股四策略持仓数 ≥3 → long（与 cross_poll._src_sig4 同判） | 近端复刻（仅 close，参数=PARAM_DEFAULTS） |
| chanlun | 1.0 | 近 20 交易日最新 fresh 事件，买→long 卖→short（冲突取更近者） | 精确 PIT（v3 seen-ever 事件缓存） |
| 9dim | 网格变量 | 最新锚（约周频）score≥75 且 cov≥0.75 | 回放锚 2024-09-02 起 |

**网格变量（3×2×3×2=36 组合）**：①9dim∈{反向计分, 降权0.5, 剔除} ②共振最少源数 k∈{2,3} ③买入阈值∈{P50中位, P60, P75}（当日过 k 门槛候选的排序键分位）④排序键∈{raw长票计数, net净向分}。

**判据**：升格信号层要求 PF5≥1.15 且平台（本组合达标 + ≥3 个相邻组合达标，相邻=9dim 线序邻档/k 翻转/阈值邻档/排序键翻转）。

阈值建议（供产线参数预留，非立即生效）：
- 共振最少源数：**3**（k=2 明确否决）
- 买入分级：过 k=3 且分数 ≥ 当日候选 P75，TopN=10
- 观望分级：过 k=3 且 P60~P75（P60 边缘正期望 +0.57%/5d）
- 排序键：净向分与长票计数在本样本无差异（short 票在 Top10 内占比低）；建议产线直接用净向分（理论更优、成本相同）
- 9dim：降权 0.5 引入；反向语义留给拥挤警报模块
- 排序/阈值必须与环境闸门联动（闸门贡献了约 +0.1 PF）

## 八、遗留风险

1. **口径差**：qpzm/sig4 为 close-only 近端复刻，缺产线的板块共振维、环境闸门一票否决与自选池定义；结论对复刻口径成立，对产线口径需复验。
2. **时间衰减**：信号质量随窗口后段明显衰减（H3 段带闸门仍亏），提示 regime 依赖，40% 宽度闸门不够紧。
3. **9dim 样本薄**：≥75 分锚均 0~10 只，"反向计分优于剔除"结论不显著，需 9dim 锚扩大样本后再验证。
4. **单宇宙**：CN A 股 only；cross_poll 聚合含 US/HK/CRYPTO，本次未覆盖。
5. TopN=10 使阈值变量区分度有限（P50/P60/P75 信号数 2357/2237/2043），若产线 TopN 更大需重验。
6. 单笔成本按往返 15bps 一次性扣除，未含开盘滑点冲击；TopN 小盘票实际滑点可能更高。
