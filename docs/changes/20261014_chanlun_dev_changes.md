## 一、v7 机制

- 新文件：`quant_backtest/chanlun_rotation_v7.py`（未改任何既有文件；config.json 零改动）
- 滚动池：每 R∈{5,10,20} 交易日，对最近 LOOKBACK=40 交易日内的三类买点信号打分
  `score = 类型权重(1买3/2买2/3买1) × 新鲜度 0.5^(年龄/半衰10日) × 背驰加成1.2`，取 TopN=20 重选持仓池；池外平仓、池内持有；regime 80/50/30、-8% 止损、卖点出场与 v6c2 C1 完全同款（单因子隔离）

- 口径：use_hfq=true 走 kfac=pct_chg 累乘后复权，日志确认 `[HFQ] use_hfq=true 生效路径已走到: kfac后复权 76/76 只, HFQ_FALLBACK=0`
- 基建复用：`chanlun_signal.analyze` import 复用；信号流一次计算落缓存 `_v7_stream_cache.json`，敏感性变体秒级复用。v6c 全顶层脚本无法安全 import（会重跑七臂覆写留痕），数据加载 15 行以同口径内聚，用 B0 对数校验兜底

## 三、结论（判据：年化改善 ≥2pp 且回撤不恶化）

**不通过，不建议进影子对账。** 最优档 R=20（3买优先）年化 -7.45%，较 baseline 恶化 8.17pp；回撤 -32.2% 恶化 14.96pp。两项判据双双 fail，且对买点权重方向不敏感（一买优先/三买优先同向恶化）。

**根因（信号稀疏）**：全窗 729 交易日、76 只池仅 219 个新鲜买点（日均 0.3 个），重选日 40 日窗口内候选覆盖均值仅 10.6（一买优先）/14.5（三买优先），远低于 TopN=20 —— 池长期填不满，持仓被迫集中于少量"接飞刀"标的，叠加 pool_out 强制换仓与 -8% 止损反复触发（止损出场仍占 40%+）。

**判断**：滚动池机制本身无罪，是缠论三类买点在本池的**信号密度不足以支撑 Top20 独立选池**。若后续要救，方向不是调 R/权重，而是：① 候选不足时以池内动量/指数成分补位（混合池）；② 把买点信号降级为"确认过滤器"而非"选股器"。当前证据下不建议投入。

## 四、遗留风险

- B0 复跑年化校验阈值 0.05pp 偏严（数据漂移即触发 FAIL），仅作口径告警用，不阻塞流程
