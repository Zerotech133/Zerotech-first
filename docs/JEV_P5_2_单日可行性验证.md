## 一、结论先行

按老田裁定「不等两项数据补齐，先做 ②」，本轮**只验证链路能不能跑通、
指标能不能算出来、有没有把假东西当成结论**，不评估判定闸 A/B。

- ✅ **链路跑通**：11-06 单日事件池 63 只（封板 33 / 触板未封 30），
  **63 只全部拿到 T+1 后验**（后验日 11-09，由目录扫描得到），
  收盘价交叉校验异常 0 例。
- ✅ **三个闸位指标都能算**：覆盖率 54.0%、分化度、分化节点密度；
  2 个 pattern 有足量样本算分化度，1 个有可计分化节点。
- ⚠️ **发现并修掉一个会污染闸位的伪分化节点**：`time_ready` 实为「该票有本地分钟数据」，
  分出来的是大/小盘覆盖偏倚而非信号分化。本轮共拦下 2 个这类节点。
- ⚠️ **两个看空 pattern 的实际主路径与假设相反**（详见 §五），属单日单期观察，
  **不是结论**；v2 的判定闸状态一个字都没改。

**`validate()` 输出恒带 `feasibility_only=True` / `gate_eligible=False` /
`calibrated=False`，并附 5 条拦截原因。本轮任何数字都不得用于 A/B 判定。**

## 二、边界（为什么这只能叫可行性验证）

| 约束 | 实况 | 后果 |
|---|---|---|
| 后验期数 | 目录里 11-06 之后只有 11-09 一个交易日 | 只算 T+1，P5.2 定义的 1/3/5/10 日无法计算 |
| 样本池 | 封板 + 触板票，且社交采集器本就按涨停选票 | 选择偏倚，与全市场不可比 |
| 阈值 | `Thresholds` / `CaseThresholds` 均为起点值 | 命中集合未经校准 |
| 时间维 | 仅 10 / 63 只可算 Δmin（53 只 unpriced） | 三维度实际靠资金 + 社交撑起 |
| 判定闸 | 条件① 口径待老田拍板、条件②③ 需全量案例库 | 本轮不评估 |

> **社交快照时序口径标注（2026-11-10，A 方案，仅标注、不改结论）**
> §四 的「社交被覆盖 42 / 63」及 `social_covered` 沿用的是页面展示层
> `jev_social.load_social(day)`（按文件名取数、零时序校验），而快照的 `day` 是【选票日】、
> `fetched_at` 才是【观测时刻】；11-06 那份实际采于 11-08，作为「T 日当日社交状态」
> 的解释变量是错配的。本案例库恒带 `feasibility_only=True / gate_eligible=False /
> calibrated=False`，**任何数字本就不得进闸，v2 判定闸状态未被污染，无需回滚或改结论**。
> **本轮未改任何数字与结论。** P5.3/P5.4 校准须改用
> `jev_snapshot_gate.require_compliant_social()` 取合规快照后重算。

拦截原因（由 `validate()` 原样输出）：

- 单交易日样本，非多日累积 5000+ 涨停样本
- 后验仅 T+1 单期，1/3/5/10 日演化无法计算
- 样本池按涨停/触板选票，与社交采集选票同源，存在选择偏倚
- Thresholds / CaseThresholds 均未校准
- 时间维度大面积 unpriced（双锚点数据缺口未补）

## 三、数据契约（三处防造假设计）

1. **后验交易日从 `daily/` 目录扫描**，不写死交易日历、不用最近一日顶替；
   缺期记 `path=missing`，不进分布、不算覆盖率分子。
2. **路径分类**取 T+1 的 `pct_chg`（其 `pre_close` 即 T 日收盘），
   ±3% 之外分别记回落 / 继续涨，区间内记横盘；
   另用 `close(T+1)/close(T)−1` 交叉校验，差异 > 0.5pp 只标 `suspect` 不篡改路径。
3. **样本不足不硬算**：pattern 少于 5 例、分化节点任一侧少于 5 例，
   一律 `insufficient` / `divergence_pp=None`，绝不拿 n=2 的 100pp 当分化度。

装配层沿用 P5.1 纪律：只读本地快照与 parquet，不联网、不采集；默认不写盘，
只有显式 `--out` 才落研究成果 JSON。

## 五、三个必须上报的发现

### 5.1 伪分化节点：数据覆盖偏倚冒充信号分化（已修）

修正前 `fork_nodes` 在 P1 检出 1 个、P7 检出 2 个分化节点，
全部/主要落在 `time_ready` 上（主路径概率差分别 30.0pp / 23.81pp）。但该标志的计算式是
`delta_kind != unpriced and delta_min is not None`，而 `unpriced` 的主因是 `no_minute`
——本地分钟只覆盖中证800 一线，所以它实际在把样本分成「大盘股 / 小盘题材股」，
**不是任何信号取值发生变化**。若把它计入 v2 §六 条件③ 的分化节点密度，
全量跑时会凭空造出一批假节点，直接污染闸位决策。

修法（`portal/jev_casebook.py`）：节点新增 `node_class`，
`time_ready` 归入 `AVAILABILITY_PROXY_SIGNALS`，**保留 `delta_pp` 供诊断但 `countable=False`**；
`n_fork` 只统计 `countable`。另加 `degenerate` 标记：某一侧为空的分叉
（本轮 `fund_divergence` 28/0、`social_covered` 28/0 全 True，本是 pattern 自身命中维度，天然无信息量）
不计可计节点。`validate()` 新增 `n_proxy_fork_total` 诊断字段（本轮 2）。
已写成回归测试锁死，数据补齐后重跑若该类节点消失，即可反证确系覆盖偏倚。

### 5.2 两个看空 pattern 的主路径与假设相反（不下结论）

- **P1 散户接盘型**：假设「短期回落」，实际 28 例主路径是 **继续涨**（5 / 13 / 10），回落仅 5 例。
- **P7 诱多炸板型**：假设「冲高回落 / 炸板」，实际 27 例主路径是 **继续涨**（3 / 14 / 10），回落仅 3 例。
- 对照：全池主路径是 横盘（10 / 24 / 29）。

**这是描述性观察，不是假设被证伪**。四种可能都无法用单日单期排除：
① T+1 太短，「短期回落」也许在 T+3/T+5 才出现；② 当日是普涨行情，市场 beta
压过 pattern 信号；③ 阈值未校准，命中集合里混进了非目标形态；④ 假设方向本身写反。
**按老田定的纪律，单看一个维度/单日不成立，必须多维度交叉、多日复现才算结论。**
P5.3 应在多日案例库上分层检验（尤其按 T 日是否真封板、`delta_min` 分档）。

### 5.3 小样本的诱人数字必须拦住

P2 价格先行型只有 3 例且 3 例全回落（方向与「无消息接续警惕兑现」一致），
若按旧口径会算出 100pp 的「完美分化」。本模块因 `min_pattern_n` 直接标
`insufficient`、`divergence_pp=None`——这正是可行性验证要验的护栏确实生效。

## 六、对真相源 / 判定闸的处理

- 本轮**未改** v2 §六 任何闸位结论；条件①「按双锚点口径重判」仍是待拍板建议（见 P5.1 实现说明 §七）。
- P5.2 在 v2 中记为「单日可行性验证通过 / 全量案例库待数据补齐」，不标全量完成。
- 条件②（覆盖率 ≥60%）本轮读数 54.0% 来自偏样本且阈值未校准，
  `calibrated=False`，**不得引用**。
