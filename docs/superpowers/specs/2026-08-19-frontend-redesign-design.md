# zhice-OS V2 前端重设计 · 设计文档

- 日期：2026-08-19
- 状态：已与用户逐项确认（布局/主题/导航/迁移策略均经原型验证）
- 原型：`docs/mockups/theme-variants.html`（5 主题 × 2 态可切换，视觉基准）

## 1. 目标

把现有「四工作区下拉导航 + 亮色主题」重构为**交易终端式双层结构**：
打开系统先见全局指挥大屏，按市场进入工作区（顶栏市场 Tab + 左侧 8 项菜单），全站暗色科技风、5 套主题可切换。

## 2. 信息架构

### 2.1 双层结构

```
/                        全屏指挥大屏（无侧栏/底栏，独立态）
  合计KPI(4) → 四市场卡片(4) → 闭环漏斗表 + 系统健康环
  点市场卡片/进入按钮 → /{market}/overview

/:market/...            市场工作区（顶栏 56px + 侧栏 216px + 底栏 30px）
  /cn /us /hk /crypto
```

### 2.2 左侧菜单（严格 8 项，用户指定）

| 菜单 | 路由 | 承载页面（现有 37 页归入） |
|------|------|--------------------------|
| 总览 | `/{m}/overview` | 市场工作台(简报条+KPI+漏斗+持仓Top+注意力) + 行情 + K线 + 市场概览（Tab 或区块） |
| 策略管理 | `/{m}/strategies` | 策略列表/详情(4Tab)/绩效/模型与实验/AI研究助手/回测/基本面/市场状态 |
| 候选池 | `/{m}/candidates` | 候选池（分策略Tab+抽屉） |
| 计划与信号 | `/{m}/signals` | 交易计划 + 授权中心 + 闭环流水线（三视图 Tab 化） |
| 风控与执行 | `/{m}/risk` | 风险审查 + 偏差分析 + 审计Trace + 熔断器 |
| 交易 | `/{m}/trading` | 持仓(账户选择器/成交/日历) + 账户 + 组合跨市场 + 工作流 |
| 复盘研究 | `/{m}/replay` | 复盘(案例/决策打分/错误统计) + 盈亏日历 + 知识库 + 学习报告 + 日报 |
| 系统与设置 | `/{m}/system` | 系统状态(4Tab) + 告警 + 自动化 + 治理看板 + 多策略 + 日历 + 设置 + 大屏入口 + 导出 |

### 2.3 旧路由兼容

旧路径（/positions、/candidates 等）全部 `<Navigate>` 重定向到 `/{market默认cn}/组?tab=x`，收藏链接不断。MarketContext 改为从 URL 市场段派生（/cn→CN），不再独立 localStorage 状态。

## 3. 主题系统

5 套 CSS 变量主题（原型已验证），`body[data-theme]` 切换，`localStorage['zhice_theme']` 记忆，设置页 + 顶栏快捷切换：

| key | 名称 | 主色 | 定位 |
|-----|------|------|------|
| carbon | 碳灰 | 银白高光/纯黑底 | **默认主题**（Bloomberg 专业范，盯盘最不疲劳） |
| aurora | 极光蓝 | #5B6CF0/#22D3EE | 科技感 |
| emerald | 翡翠 | #10B981 | 金融绿 |
| amber | 琥珀 | #F59E0B | 暖色复古 |
| cyber | 赛博紫 | #9333EA/#E879F9 | 展示酷炫 |

所有组件只消费 CSS 变量（--bg/--card/--line/--cyan/--red/--green/--gold/--txt 系列），禁止写死颜色。A股红涨绿跌语义色在所有主题下保持（红 #FF4D5E 系/绿 #00D68F 系按主题微调）。

## 4. 视觉规范（v3 原型基准）

- **材质**：玻璃拟态卡片（backdrop-blur + 顶部高光线 + HUD 四角标）、背景网格 + 3 层柔光晕
- **字体**：数字/代码 JetBrains Mono（tnum），品牌/区块标题 Orbitron，正文 PingFang SC
- **节奏**：页面边距 44/64（大屏）· 32/40（工作区）；栅格间距 20-22；卡片内距 24+；表格行距 13
- **光效**：Logo 流光、扫描线、呼吸灯（盘中/调度器）、盈亏数字发光、卡片 hover 上浮+扫光
- **信息色**：待授权金色 alert、regime 标签（多头红/空头绿/震荡金）、双语标签（中文+EN 注记）

## 5. 组件改造清单

1. **新 AppShell**（两态）：`BigscreenLayout`（全屏）+ `WorkspaceLayout`（顶栏/侧栏/底栏）
2. **ThemeSwitcher**：设置页 5 卡片预览 + 顶栏快捷循环切换
3. **侧栏 NavSide**：8 项 + 徽标（候选数/待授权数）+ 底部实时状态块（阶段/待办/调度器/刷新）
4. **底栏 StatusBar**：市场·阶段·候选·待授权·今日盈亏·质量分·时钟
5. **既有 37 页**：antd ConfigProvider 换暗色 algorithm + 主题 token 对接变量；归组进 8 菜单（多为原样嵌入，去各自标题条改用页头组件）
6. **SymbolLink/⌘K/Toast/useAutoRefresh**：保留，⌘K 增加主题切换命令

## 6. 实施顺序（供 writing-plans 细化）

1. 主题基建：CSS 变量文件 ×5 + ThemeProvider + 切换器 + antd 暗色对接
2. AppShell 两态 + 路由重构（/market 段 + 旧路径重定向）+ MarketContext URL 派生
3. 大屏页升级（v3 布局 + 真数据接线）
4. 8 菜单容器页（Tab 化聚合现有页面）逐组落地：总览→交易→计划与信号→风控→复盘→策略→候选→系统
5. 底栏/侧栏状态块实时数据接线 + 回归验证（91 后端测试不动，前端构建+手动走查）

## 7. 明确不做

- 移动端适配（暂缓）
- 亮色主题（只做暗色 5 变体）
- 后端 API 改动（全部复用现有 116 端点；大屏所需 cross-market/pipeline/regime/data-quality 均已有）

## 8. 验收标准

- 打开 `/` 即全屏大屏，四市场数据真实（cross-market/pipeline/regime）
- 顶栏切市场 → 左侧 8 菜单工作区，37 页全部可达且功能不回归（授权/审批/跳K线/自动刷新）
- 5 主题任意切换全站生效并记忆；A股红涨绿跌全主题正确
- 旧路径重定向有效；⌘K 可达全部页面+切主题
- 构建通过，视觉与 v3 原型一致（间距/光效/材质）
