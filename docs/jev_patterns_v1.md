# JEV · 组合 Pattern 枚举 v1（P4 交付）

> 阶段 P4 产出（2026-11-10，老田批准启动）。三维度口径已钉死：**资金 + 社交 + Δmin**（P3 已拍板放弃结构维度）。
> 素材来源：11-06 判例（真相源 §2.3）+ `docs/jev_deltamin_spec.md`（P1.4）+ event_type_tier 分层（§一 PROVEN）。
> **性质**：候选定义稿——每个 pattern 的命中条件与预期演化是**假设**，全部待 P5 案例库实测后修订；不预设结论。

## 〇、通用记号（P5 matcher 的输入契约）

| 记号 | 定义 | 来源 |
|---|---|---|
| `div` | 资金背离：`main_net > 0 & net_mf_amount < 0`（主力接、全档逃） | ts_moneyflow |
| `mf_dir` | 当日主力净流方向（in/out/flat，按 main_net 分位 ±20% 定界） | ts_moneyflow |
| `guba_hot` | 股吧人气排名当日陡升（排名升幅 ≥ 30% 或进 Top100） | social json |
| `xq_inst` | 雪球机构/大V 榜覆盖（0 = 无视，≥1 = 有覆盖） | social json |
| `Δmin` | T_news − T_limit_seal（分钟，带符号）；None = unpriced | jev_deltamin_spec |
| `tier` | event_type_tier：强类型 6 种（权重 1.0）/ 弱类型 3 种（0.4） | posterior 后验 |
| `seal_early` | T_limit_seal < 10:30（早盘锁板） | stk_mins |

## 一、候选 pattern（10 个）

### P-01 散户接盘型（11-06 判例原型）

| 维度 | 命中条件 |
|---|---|
| 资金 | `div == True`（主力净流入但全档净流出） |
| 社交 | `guba_hot == True` 且 `xq_inst == 0`（散户热、机构无视） |
| Δmin | `Δmin > 0`（消息追认）或当日为日级追认源公告 |
| 预期演化 | 1-5 日回落概率占优（判例实测回落）；分化节点：次日主力转为大幅流出 → 回落加速 |
| 样本预期 | 背离日全市场日均数十只，扣除社交/Δmin 条件后 P5 预计数百样本 |

### P-02 消息驱动真突破型

| 维度 | 命中条件 |
|---|---|
| 资金 | `mf_dir == in` 且 `seal_early == True` |
| 社交 | 不限（后验看双榜覆盖度是否加分） |
| Δmin | `Δmin < 0` 且 `|Δmin| ≥ 30`（消息先行至少半小时）且 `tier ∈ 强类型` |
| 预期演化 | 次日惯性高开/续涨概率占优；分化节点：`|Δmin|` 越大且换手温和 → 续涨概率越高 |
| 对立面 | 同结构但弱类型 tier → 归入 P-08 |

### P-03 机构先手型

| 维度 | 命中条件 |
|---|---|
| 资金 | `mf_dir == in`（连续 2 日为佳，P5 实测时加窗口变体） |
| 社交 | `xq_inst ≥ 1` 且 `guba_hot == False`（机构有动作、散户未醒） |
| Δmin | 不限；若当日有强类型新闻任一方向均记录 |
| 预期演化 | 缓涨/横盘后突破（3-10 日窗口）；分化节点：第 3 日 guba_hot 起来 → 进入主升观察 |

### P-04 价格先行无消息型

| 维度 | 命中条件 |
|---|---|
| 资金 | 涨停封板，`mf_dir == in` |
| 社交 | 不限 |
| Δmin | 当日域内无强类型分钟级新闻（消息真空），或 Δmin 域内新闻均为弱类型 |
| 预期演化 | 分化最大的 pattern——游资一日游 vs 趋势启动并存；**必须**用次日资金方向 + 连板高度做路径分化节点（这恰是新验证器「分化度」指标的主测样本） |

### P-05 快速追认共振型

| 维度 | 命中条件 |
|---|---|
| 资金 | `mf_dir == in` |
| 社交 | 双榜同热（`guba_hot` 且 `xq_inst ≥ 1`） |
| Δmin | `0 < Δmin ≤ 60`（快速追认）且 `tier ∈ 强类型` |
| 预期演化 | 趋势确认，2-5 日续涨概率占优；分化节点：追认新闻数量（≥2 条独立源 → 加分） |

### P-06 滞后追认出货型

| 维度 | 命中条件 |
|---|---|
| 资金 | 涨停当日 `mf_dir == in`，但次日起 main_net 转负（P5 需 T+1 数据） |
| 社交 | `guba_hot == True`（热度滞后于资金拐点） |
| Δmin | `Δmin > 60`（慢追认）或纯日级追认源 |
| 预期演化 | 高位出货，3-10 日回落；与 P-05 构成 Δmin 区间的正反对照（60min 阈值由 P5 校准，非预设） |

### P-07 日级公告驱动型（不进分钟 Δmin）

| 维度 | 命中条件 |
|---|---|
| 资金 | 公告次日 `mf_dir == in` 或 `out`（方向表态） |
| 社交 | 不限 |
| Δmin | 源 = `announcement/xd_notice/report`（日级），按 spec 记「日级追认」不硬算分钟 |
| 预期演化 | 公告次日资金方向 = 主路径判别器：in → 续涨；out → 见利好出货。这是日级 co-signal 的主样本池 |

### P-08 弱事件涨停型

| 维度 | 命中条件 |
|---|---|
| 资金 | 涨停封板 |
| 社交 | 不限 |
| Δmin | 域内新闻 `tier ∈ {price, supply, other}`（弱类型） |
| 预期演化 | 事件质量差 → 回落概率偏高（弱类型准确率仅 48.8-51.5%）；作为 P-02 的对照面 |

### P-09 多源密集追认型

| 维度 | 命中条件 |
|---|---|
| 资金 | `mf_dir == in` |
| 社交 | 不限 |
| Δmin | 同票同日 **≥2 条独立源**分钟级新闻追认（`Δmin > 0`） |
| 预期演化 | 信息浓度高 → 方向可信度上调；与 P-01 构成「追认数量」维度的对照（1 条 vs 多条） |

### P-10 静默吸筹型（观察池，负对照）

| 维度 | 命中条件 |
|---|---|
| 资金 | main_net 连续 ≥3 日净流入且未涨停 |
| 社交 | 双榜皆冷（`guba_hot == False` 且 `xq_inst == 0`） |
| Δmin | 无（消息真空） |
| 预期演化 | 启动前哨——P5 用它统计「吸筹后 N 日内涨停/大涨」的前置命中率，反推 P-02/P-04 的前置条件覆盖度 |

## 二、pattern 间的关系设计（P5 验证器用）

1. **互斥组**：P-01 vs P-05 vs P-06（同为「涨停 + 追认」域，按 Δmin 区间与社交结构切分）；P-02 vs P-08（按 tier 切分）。
2. **正反对照对**：P-05/P-06（60min 阈值）、P-01/P-09（追认条数）、P-02/P-08（事件质量）——每对给出「分化度」直接可比。
3. **前置-后验链**：P-10（前置）→ P-02/P-04（后验路径），用于验证「吸筹 → 突破」因果链是否真实存在。
4. 覆盖策略：10 个 pattern 按「涨停日样本 + 非涨停资金异动样本」两级池跑 P5.2 案例库，实测覆盖率（判定闸 A 条件② ≥60% 的对象）。

## 三、P5 实现注意事项（给 P5.1 matcher）

- 命中条件全部用 spec 的数据契约读取（stk_mins 活源 / news.db ts / social json），**禁止** curated 旧源。
- 每个 pattern 输出：命中布尔 + 各维度原始值（供案例库留痕与后期调参）。
- Δmin = None（unpriced）样本：不进分钟 Δmin 类 pattern 的主判定，但保留在 P-04/P-07/P-10 候选池。
- 60min/30min/排名升幅 30% 等阈值全部标记为「待 P5 校准」，实现时做成参数非硬编码。
