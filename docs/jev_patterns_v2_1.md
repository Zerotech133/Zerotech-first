## 二、方法学纪律（进 v2.1 正文，优先级高于阈值）

1. **episode 去重强制**：一切 pattern 统计/校准必须基于 `--dedup` 口径（同票同 pattern 信号日间隔 ≤5 交易日保留首个）。判例：301190 三天连续命中 P-08，ret3 +58.4%/+46.9%/+34.8% 为同一波行情，不去重则 Δmin 分桶均值被拉爆（30~120 桶 17.89% 虚高）。
2. **基线同窗口纪律**：涨停票基线随窗口漂移（21 日窗 T+10 -6.33% vs 60 日窗 -3.29%），**相对差必须在同窗口内计算**，禁止跨窗口引用基线数字。
3. **连板股混杂警示**：涨停相关 pattern 的强收益桶常被连板股驱动（600825、301190），解读分桶时必须看 top 明细而非只看均值。
