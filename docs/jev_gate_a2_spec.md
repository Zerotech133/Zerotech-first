## 一、条件②原文与它的问题

原文：**「三维度 + Δmin 组合后，pattern 覆盖率 ≥ 60%（5000+ 只中被至少一个 pattern 命中）」**

这句话在可执行层缺三个要件：**分子是谁、分母是谁、未命中怎么归因**。不补齐，同一份数据能读出 13.85% 到 69.23% 五个不同结论，闸位 A/B 随口径翻转。本文补的就是这三件。

## 四、为什么现在不能判（缺口分解）

涨停池 2,701 个 pair 的数据齐备度：

| 条件 | 齐备数 | 占比 |
|---|---|---|
| 社交有同日快照 | 68 | **2.5%** |
| Δmin 有值（分钟级时间戳可算） | 169 | **6.3%** |
| 两者都齐 | 26 | **1.0%** |

同一分子在数据可判子集里的读数是 **79.29%**（Δmin 有值池 134/169），与 D1 的 13.85% 差 5.7 倍。**这个落差全部来自数据缺口，不来自 pattern 设计。**

结论：**13.85% 是「数据可用性下限」，不是「pattern 覆盖能力」**。据它宣布闸 B（<30% 触发收敛）是错误归因——相当于用「93.7% 的样本连 Δmin 都算不出来」去证明「pattern 设计不行」。

## 五、判定规则（**建议，待批**）

1. **可判条件**：D1 分母的有效可判率（Δmin 有值占比）须 ≥ 50%，否则条件②判「**不可评估**」，既不判过也不判不过；
2. **过闸**：D1 ≥ 60%；
3. **触发闸 B**：D1 < 30% **且** 可判率 ≥ 50%（即缺口已排除后仍然低）；
4. **强制附报**：每次判定同时给出 D3 读数与缺口三个百分比，防止「分母缩水导致虚高」。

按此规则，**今天的状态是「不可评估」**（可判率 6.3% ≪ 50%），闸 A/闸 B 均不成立，条件②继续挂起。
