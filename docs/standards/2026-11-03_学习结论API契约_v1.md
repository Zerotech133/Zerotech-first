# 学习结论 API 契约 v1（W3-3 · 2026-11-03）

> 数据源：`research/reports/learning_conclusions_lib_20261103.json`（只读，730 结论 / Top100）
> 当前形态：**静态导出** `portal/static/learning_conclusions.json`
> 建议 API：`GET /api/learning/conclusions`（8091 接线；**本期契约先行，未改 portal_api.py、未新增路由**）
> schema：`learning_conclusions.v1`

## 一、数据契约（Top100 字段）

每条结论必须包含 `consumer_contract.required_fields` 的 12 个字段：

| 字段 | 类型 | 说明/示例 |
|---|---|---|
| `conclusion_id` | string | 结论 ID，如 `LC-0001` |
| `concept` | string | 结论概念（归一化主题概念） |
| `text` | string | 结论正文（含依据摘要；185 字级） |
| `confidence` | string | 置信：`高|中|低`（当前 Top100：高5/中24/低71） |
| `executability` | object | `{level:"A|B|C", label, reason}`；A 日线可算 / B 需分钟数据 / C 人工判断 |
| `tactic` | object | `{category, name, hits, keywords, confidence}`；分类：缠论/均线/指标/量价/形态/风控/心理/量化/未分类 |
| `claim_type` | string | `规律型（方法论/博主/书）` / `事实型（研报）` |
| `n_sources` | integer | 独立来源数（≥1；Top100 中多源 29 条） |
| `sources` | array | `[{source_type, source_key, source_label, raw}]`，引用时用 `source_label` |
| `pit` | object | `{verifiable, as_of, precision, date_kind, dates, note}`（PIT/时点可验证） |
| `review_status` | string | `published` / `multi_source_verified` 等 |
| `score` | number | 治理评分（Top100 范围 218–356） |

附加入口字段（消费者可用，可选）：

| 字段 | 说明 |
|---|---|
| `aliases` | 概念别名（同簇合并用） |
| `confidence_reason` | 置信依据（如「≥2 独立来源且答案一致（Jaccard≥0.45）」） |
| `consistency` | 一致性明细（max_similarity/pairs_compared/consistent/direction_conflicts/threshold） |
| `source_types` | 来源类型集合（research_report / blogger / book） |
| `bloggers` / `research_reports` / `books` | 分来源明细 |
| `text_length` / `topic` / `cluster` | 文本长度/主题/簇 |

静态导出文件顶层：

| 字段 | 说明 |
|---|---|
| `schema_version` | `learning_conclusions.v1` |
| `generated_at` / `date` | 数据生成时间/日期（取源库，确定性导出） |
| `source` | 源文件 path/sha256/task/title/read_only |
| `endpoint` | `{current:"/static/learning_conclusions.json", suggested_api:"/api/learning/conclusions", status:"static_only_contract_first"}` |
| `consumer_contract` | 原样透传（query_params/required_fields/legions） |
| `query_support` | 查询参数说明 + 示例（当前本地过滤） |
| `summary` | 库内总数 730、Top100、置信/可执行性/战法/claim_type 分布、冲突 0、仲裁队列 24、score 区间 |
| `legions` | 军团消费口径 + counts（quant 14 / research 5 / arbitration 24） |
| `arbitration_queue` | 待仲裁 24 条（DATA1 张松） |
| `conclusions` | Top100 数组 |
| `validation` | `{ok, errors, required_fields, checked}`（导出时校验 PASS） |

## 二、查询参数（建议 GET /api/learning/conclusions）

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `confidence` | `高|中|低` | 全部 | 按置信过滤 |
| `executability` | `A|B|C` | 全部 | 按可执行性过滤（`level`） |
| `tactic` | `缠论|均线|指标|量价|形态|风控|心理|量化|未分类` | 全部 | 按战法分类过滤（`tactic.category`） |
| `limit` | `1..100` | `100` | 返回条数上限 |
| `offset` | `≥0` | `0` | 分页偏移 |
| （扩展）`min_confidence` | `高|中|低` | — | 建议：≥指定置信等级过滤 |
| （扩展）`q` | string | — | 建议：概念/正文关键词搜索 |

> 当前静态阶段：客户端拉全量 Top100 后本地过滤（`query_support.server_side=false`）；8091 接线后由服务端过滤、支持分页。

## 四、错误码（建议）

| HTTP | error.code | 场景 |
|---|---|---|
| 200 | — | 正常（`ok=true`） |
| 400 | `invalid_parameter` | `confidence/executability/tactic` 不在枚举内 |
| 400 | `invalid_limit` | `limit` 非 1..100 或非整数 |
| 400 | `invalid_offset` | `offset` <0 或非整数 |
| 404 | `conclusions_unavailable` | 静态文件缺失/未导出（当前静态阶段） |
| 500 | `internal_error` | 数据加载/序列化异常 |

错误响应体建议：`{"ok": false, "error": {"code": "...", "message": "...", "param": "..."}}`。

## 五、军团消费口径（consumer_contract.legions）

| 军团 | 取数规则 | 当前 Top100 counts |
|---|---|---|
| quant（量化交易部） | `executability.level ∈ {A,B}` 且 `confidence ∈ {高,中}` → 战法/因子假设 → 四关 | **14** |
| research（研报/知识线） | `confidence=高` → RAG/研报问答（引用 `sources[].source_label`） | **5** |
| arbitration（数据智能部） | `arbitration_queue`/conflicts → DATA1 张松仲裁后回写 | **24** |
