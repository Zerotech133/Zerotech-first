## 四、通知内容四要素（派单卡同款）

1. **更新范围**：节点/关系类型 + 数量级（如「Seat +12，TRADED_ON +3,400」）
2. **影响查询**：对照 `kg_graph.query_recipe` 标注受影响的查询模式
3. **生效时间**：落库时间戳 + 可回滚窗口（配合 kg_neo4j_backup）
4. **回执要求（v1.3 收紧）**：L2/L3 必须逐席显式 ACK，回执含席位、时间、结论（同意／异议／附条件）与依据；例行 L1 可并入晨会台账。**禁止「N 个工作日未回执视为默认接受」**；「已送达」不等于「已同意」。
5. **结算时点约束**：结算动作只能在回执截止时刻之后执行，禁止提前自动结算；结算记录须逐席列出回执证据。到期仍有未回执席位 → INTEL0 催办一次并留痕 → 仍未回执则逐案上行 A0／老田书面裁决；裁决须写明理由、适用范围、有效期，且不得追溯既往事件、不得自动适用于后续事件。

## 五、与张松（DATA1）的每日对表

- **对表时点**：每日 06:20 KgDailySync 22 步链完成后（对齐张松 06:30 巡检窗口）
- **对表内容**：①上游五链路（接口/开源情报/学习派生/平台运行/语料）中图谱相关源的断流/漂移；②实体口径变更预告（如席位名录更新、概念板块调整）；③kg_dataroot 类数据根变更（数据册 v2 已注销旧 kg_dataroot，路径变更必须经数据册登记，不登记=黑户）
- **纪律**：张松给数据可信与口径，郑玄给图谱结构与影响面——**不替对方裁决业务口径**，分歧上行马超 INTEL0
