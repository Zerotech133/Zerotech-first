# 军团看股标准 LCS-1（Legion Chart Standard v1）

> 2026-10-16 立标 ｜ 上游：K-ORG-120（图先行·事佐证）｜ 对标调研：开源社区 + 知识库
> 性质：**军团正式看股标准**——此后任何 Agent/人的个股分析输出必须符合本标准格式；旧三线并列范式废止

---

## 〇、立标依据（为什么这个方法论配得上成为标准）

| 对标对象 | 它的做法 | 与 LCS-1 的差异 |
|---|---|---|
| A-Master 诊股系统（开源多Agent） | 五 Agent 并列出报告（技术/资金/筹码/舆情）→ CIO 仲裁加权 | 维度并列无因果链；LCS-1 是**假设驱动的因果漏斗** |
| czsc / chanlun-pro（缠论量化，1.1k star） | 缠论结构计算（分型/笔/中枢/背驰）+ 信号-因子-事件体系 | 只做层1图形计算，无事件耦合/席位佐证层；LCS-1 吸收其结构计算为层1算子 |
| 民间实战方法论（"三三制"） | 连续 3 交易日 + 3 维度（量价/资金/消息）共振才确认主力意图 | **与 LCS-1 四层漏斗同构**——民间智慧验证了方向；LCS-1 是其机器化、判据化版本 |
| 菜鸟遗产 | 盯盘六维评分 + 多空辩论 | 维度加权制；LCS-1 保留其辩论制但换装漏斗事实底座 |

**LCS-1 的三句差异化**：
1. **假设驱动**：图形先推演出"运作假设"，数据检索有靶心（不是指标堆砌式漫捞）
2. **血统分级**：每个数据源带可信级（机器级/法定级/需降噪），结论可信度=数据血统
3. **三态判定**：佐证/证伪/无关——宁可存疑观察，不可强行定性

## 一、标准分析流程（四层漏斗，必按序执行）

```
L1 图形推演（唯一主线）→ 输出「运作假设」五选一
   放量吸筹 | 缩量洗盘 | 对倒出货 | 抢跑异动 | 无为自然
   工具：tools/chart_hypothesis.py（五算子，纯代码可复算）
L2 事件佐证 → 三态
   核验：异动日 vs 公告日时间耦合（领先=内幕特征，如 9-22 抢跑→10-01 公告）
L3 资金佐证 → 三态
   核验：席位方向与图形阶段匹配（出货假设→卖方席位实锤？吸筹假设→买方席位实锤？）
   工具：KG 席位查询（ts_top_inst 法定数据）
L4 定性输出 → 三选一
   定性成立（L2+L3 至少一项佐证且无证伪）| 存疑观察（矛盾或缺证）| 散手票（idle）
```

**铁律**：L4 禁止在证据矛盾时强行加权（吸收今晚群辩教训：小模型会强行给 BUY）；存疑就是结论的一种。

## 二、标准输出格式（所有分析报告统一）

```yaml
标的: 600337
L1_主假设: 抢跑异动（9-22 量比2.5从地量骤放，+6.6%）
L2_事件: 佐证（9-22 → 10-01 重整协议公告，领先7个交易日）
L3_资金: 佐证（席位净额+12277万，开源西大街等6游资）
L4_定性: 游资主导·重整博弈·第一波已兑现（成立）
数据血统: K线=机器级 | 公告=法定级 | 席位=法定级(冰山)
审美判定: WATCH（中枢震荡缩量，非买点形态）
风险声明: 席位仅覆盖达标日；新闻未入本次定性
```
