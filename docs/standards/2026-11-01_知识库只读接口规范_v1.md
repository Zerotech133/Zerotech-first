# 知识库只读接口规范 v1（KB Read API）

> 编号：2026-11-01_知识库只读接口规范_v1 · 适用范围：研报知识库（498 知识单元）+ 书籍知识库 + RAG 索引
> 目的：**其他 Agent/系统按契约读知识，不再各写各的解析**。
> 原则：只读、引用必带出处、契约版本化、错误可判、零副作用。

## 二、统一响应信封（所有通道/命令）

```json
{
  "api_version": "1.0",
  "request_id": "a1b2c3d4e5f6a7b8",
  "ok": true,
  "data": { ... },
  "error": null,
  "generated_at": "2026-11-01T00:10:00+08:00"
}
```
失败：`ok=false`，`data=null`，`error={"code":"...","message":"..."}`；退出码非 0。

**错误码**：`INVALID_ARGUMENT(400)` / `NOT_FOUND(404)` / `NOT_READY(503)` / `UPSTREAM_UNAVAILABLE(502)`。

## 三、资源与字段

### 3.1 知识单元 Unit（核心资源）
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 稳定 id：`sha1(book|chapter|page_start|claim[:80])[:12]` |
| `source` | enum | `书籍` / `研报` |
| `book` / `chapter` | string | 出处 |
| `page_start` / `page_end` | int | 页码（必填，1-based） |
| `concept` | string | 概念/术语 |
| `claim` | string | 可检验论点（必填非空） |
| `evidence` | string | 原文依据（≤300 字） |
| `score` | number | 仅 search 返回 |

### 3.2 状态 Status
`{docs:int, units:int, rag:{documents,records,version}, spotcheck:{schema_rate,ground_rate,...}, sources:[...]}`

### 3.3 书目 Book
`{id, source, pages, chapters, units}`

### 3.4 检索 Search
`{q, total_hits, items:[Unit+score...]}`（默认 top=10，上限 50）

### 3.5 简报 Briefing
`{generated_at, date, docs:[...], file, feishu_ready}`

## 五、消费方规则（强制）

1. **引用必带出处**：任何使用 Unit 的输出（回答/报告/推送）必须携带 `book/chapter/page_start-page_end`；
2. **证据不足答未覆盖**：不得用常识替代知识库内容；
3. **只读**：本接口无写操作；需要更新走 `pdf_ingest.py all` 等入库流程；
4. **超时/重试**：CLI 建议 30s 超时；HTTP 建议 10s、失败重试 1 次（指数退避）；`UPSTREAM_UNAVAILABLE` 不重试；
5. **缓存**：静态快照以 `generated_at` 判断新鲜度；`kb_units_all.json` 变更后 SPA 需刷新（`?ts=` 已处理）；
6. **版本**：`api_version` 不兼容时拒绝消费；破坏性变更升主版本（v2）并保留 v1 一个周期。

## 八、安全与合规

- 仅 127.0.0.1/同源；无鉴权（本机个人 OS），**禁止对公网暴露**；
- 内容仅内部研究使用；版权归原作者；引用遵循「短摘录 + 出处」；
- PII：入库前按标准脱敏（PDF 标准 §5）；接口不返回 PII 字段。
