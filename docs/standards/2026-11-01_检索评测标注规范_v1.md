# 检索评测标注规范 v1（研报知识库 search_v2）

- 日期：2026-11-01
- 支线：wave11 / task-32（AF：检索标注规范 + 两阶段偏差审计）
- 适用范围：`tools/kb_corpus/search_v2.py` 及其评测（wave7 10 条 → wave9 41 条 → wave10 89 条）
- 关联审计：`research/reports/eval_audit_20261101.md`（两阶段偏差归因）

## 1. 相关度分级（graded relevance 2/1/0）

按「该知识单元对查询意图的回答程度」人工判定，写入查询集 `graded` 字段：

| 等级 | 定义 | 判定规则（可复核） |
|---|---|---|
| **2 直接相关** | 单元直接回答查询主题，命中单元的核心知识点 | 单元 concept/claim/evidence 含查询的 grade-2 关键词 |
| **1 部分相关** | 单元与查询主题相关但非直接答案（背景、相邻概念、同一主题的分支） | 含 grade-1 关键词、但不含任何 grade-2 关键词 |
| **0 不相关** | 与查询主题无关 | 以上皆不含 |

规则：单元最终等级 = 命中关键词的最高等级（2>1>0）。关键词一律在 `concept/claim/evidence`
三字段上做子串匹配（与检索器分词语义无关，避免用检索器结果反向定义标注）。

## 2. 期望单元规则

- 期望单元（expected units）= 等级 > 0 的全部单元，由上述关键词规则从数据中展开，不需逐条手写 unit id；
- 每条查询的期望单元数必须 **≥1** 且 **< 全库 80%**（过多说明关键词过泛，失去区分度；
  过少则易脱离真实意图）；超出视为标注不合格，需重标；
- 查询集入库前必须跑「零期望单元校验」（wave9/wave10 已实现，0 条零期望）；
- 关键词之间用 `、` 分隔；同一主题的多组关键词允许分属不同 grade。

## 3. 单主题 vs 多主题口径

| 查询形态 | 标注口径 | 指标解读 |
|---|---|---|
| 单主题（如「量柱分类」） | 围绕一个主题标 2/1 级 | P@5 直接反映该主题的检索精度 |
| OR 多主题（如「光伏\|钠电池」） | 各主题并集标注，任一主题命中即相关 | P@5 反映召回覆盖，不惩罚跨主题混合 |
| AND 约束（如「快递 盈利」） | 以主主题标注 2/1；**不**因缺少约束词而判 0 | 严格 AND 会减少结果数，P@5 固定分母会低估——报告须同时给「单主题口径」与「AND 意图口径」或注明该偏差 |
| 排除（`-词`） | 期望单元沿用正主题标注，排除词只影响检索集合 | 关注「排除后仍能保留相关单元」 |

**禁止**用「对某方法有利的口径」单独作为 headline（如只报 OR 类收益）。

## 4. 查询集抽样配额（v1 起强制执行）

| 维度 | 要求 |
|---|---|
| 总规模 | **≥60 条**（低于 60 条不得作显著性结论） |
| 主题类 | ≥40%（覆盖书籍 + 研报两大来源，各 ≥20%） |
| 同义词/别名类 | ≥8 条（复用 `tools/kb_corpus/synonyms_v2.json` 的词组） |
| AND / OR 类 | 各 ≥8 条 |
| 短语类 | ≥4 条 |
| 排除类 | ≥4 条 |
| 短查询（≤4 字）/ 长查询（≥12 字） | 各 ≥3 条 |
| 抽样独立性 | 按主题/语法配额**先声明后抽样**；同一主题不重复出 query；查询选择不得参考任一检索器的表现 |
| 版本管理 | 查询集以代码常量/JSON 入库（当前 `eval_search_v2_ext.py` / `_ext2.py`），追加只允许新增 id，不允许修改已发布查询关键词 |

## 5. 指标口径（P@5 / 覆盖率 / 命中率 / NDCG@5）

- **P@5** = top5 中等级>0 的单元数 / **5**（分母固定 5，结果不足 5 条按 0 计）；
- **覆盖率** = 该查询全部标注关键词（2+1）在 top5 单元文本中被命中的比例；
- **命中率** = top5 至少 1 条等级>0 的查询占比；
- **NDCG@5** = DCG@5 / IDCG@5，DCG = Σ (2^rel−1)/log2(rank+2)（rank 从 0 起），
  IDCG = 全部期望单元按等级降序的理论 top5；等级>0 贡献正增益；
- 报告必须同时给：n、topk、标注口径（g2-only / grade>0）、v1 基线定义（旧逻辑复刻 vs 线上）、
  以及分语法类型明细；不得只报汇总。

## 6. 显著性要求

1. **n ≥ 60** 才允许使用「显著」措辞；n<60 只能报效应量与 CI；
2. 必报：配对 t（正态近似，说明非严格 t 分布）+ **bootstrap 95% CI**（≥2000 次、固定种子）
   + 命中率 McNemar；CI 不含 0 才可称「统计显著」；
3. 多重比较：同一数据多轮检验时，显著性结论需下调置信或明示「未校正」；
4. 子集分析（按语法/主题/来源）一律标注为**探索性**，与总体结论冲突时以总体为准；
5. 报告须给出「若结论反转的最小样本量/效应量」说明（敏感性）。

## 7. 禁止事项（事后调参红线）

- ❌ 看过结果再改标注关键词/等级以提高某方法指标（如 wave9 曾从 concept-only 改为三字段口径，
  必须像该次一样**同时报告两种口径**并标为敏感性分析，不得只留显著结果）；
- ❌ 删除/替换表现不利的查询或只报有利语法子集；
- ❌ 一次评测内混用不同 topk 或不同相关度口径而不声明；
- ❌ 用检索器返回结果反向定义期望单元（循环论证）；
- ❌ 在 n<60 或 CI 含 0 时使用「显著优于/明显更好」等措辞。

## 8. 标准句式（对外表述）

**允许：**
- 「v2 提升覆盖率与命中率（89 条：覆盖率 +0.074、命中率 +0.045）」
- 「v2 在同义词/别名类查询上收益明显（P@5 0.275→0.850，n=8，子集探索性）」
- 「v2 的 NDCG@5 方向性更高（+0.050），95% CI 含 0，未达统计显著」
- 「v1 保留为回退；v2 默认上线属产品选择（召回/覆盖率收益）」

**禁止：**
- 「v2 精度显著优于 v1」（89 条 P@5 p=0.204、NDCG p=0.106）
- 「v2 P@5 +0.141」（wave9 41 条结果，扩样后不可复现，见审计报告）
- 只报 p 值不报 n/CI；只报显著子集；n<60 下宣称显著

## 9. 两阶段偏差证据（摘要，详见 eval_audit_20261101）

- 重叠 41 条标注逐条一致、指标可复现（最大绝对差 0）→ 两阶段差异只可能来自**标注口径**或**查询集**；
- 标注口径（g2→grade>0，同一 41 条）：ΔP@5 +0.1414→+0.1561（+0.0147，p 反而更小）；
- 查询集（41→89，固定 grade>0）：ΔP@5 +0.1561→+0.0450（**−0.1111 为主因**）；
- 结论：wave9 的显著结果主要是 **小样本 + 新增查询构成（含更多 AND/主题类）** 的乐观偏差，
  **以 wave10 89 条 + bootstrap CI 的结论为准**。
