# 学习项目标准化流程 v1（SOP）

> 版本：v1｜生效：待老田/张松签收｜制定：2026-11-02｜**流程 Owner：DATA1 张松（兰台令·数据智能部部长）**
> 适用：**一切学习/知识类项目**——PDF/书籍、笔记、课程、情报、会议纪要等（学习PDF、老木创业笔记均按此流程）。
> 原则：**学习项目由数据智能部（兰台）自动化流水线负责；A0（田丰）只做跨部门仲裁与升级，不承担日常处理；老田只做立项/结项/不可逆审批。**

## 1. 角色与责任（RACI）

| 角色 | Agent | 职责（对学习项目） | R/A/C/I |
|---|---|---|---|
| **流程 Owner** | **DATA1 张松** | 流程制定/排产/验收/归档审批；对老田汇报项目状态 | **A**（最终负责） |
| 清洗/ETL 执行 | DATA2 刘巴 | S1 源件归档、S2 OCR/清洗/转写、staging 落盘与回执 | R |
| 质量与标准 | DATA3 陈群 | S4 治理质检（断流/漂移/去重/口径）、质量日报与告警 | R |
| 元数据与资质 | DATA4 杨仪 | S6 标准化（命名/编码/schema/索引/元数据登记） | R |
| 语料与情报结构化 | DATA5 谯周 | S3 知识单元结构化、S5 提炼（概念/FAQ/学习卡候选） | R |
| 因子/研究 | FACTOR1 蒋琬（按需） | 研究类项目的假设筛选/证据整理（只出证据不裁决） | C |
| 参谋长 | A0 田丰 | **只做跨部门仲裁、资源协调、升级裁决；不处理学习项目日常** | C |
| 人类 | 老田（laotian） | 立项/结项/不可逆审批；抽查与最终验收 | I/A(人类) |

## 2. 流程（S0–S8，状态机）

```
intake_pending → registered → ingesting → cleaning → extracting → governing
      → distilling → standardizing → published → archived
失败任意阶段 → blocked（保留回滚点；DATA1 处置，必要时升级 A0）
```

| 阶段 | 名称 | 负责 | 输入 | 输出（标准位置） | 质量门 | SLA |
|---|---|---|---|---|---|---|
| S0 | 立项登记 | DATA1 | 老田指令/自动发现 | `learning_projects.json` 记录（id/owner=DATA1/状态/源路径） | 三问必答：为何学/产出什么/验收标准 | T+0 |
| S1 | 源件归档 | DATA2 | PDF/笔记/URL 导出 | `C:\项目\PDF\` 或 `C:\项目\知识库\<域>\`；sha256+manifest；raw 只读 | G1 源完整（页数/大小/hash） | T+0 |
| S2 | 清洗/OCR/转写 | DATA2 | 源件 | `PDF\_ocr` / `知识库\20_清洗`、`20_转写`；清洗回执 | G2 OCR 质检（置信/断页/乱码率） | T+1 |
| S3 | 结构化抽取 | DATA5+DATA2 | 清洗件 | 知识单元 JSONL（claim/evidence/book/chapter/page/unit_id） | G3 schema 校验通过 | T+2 |
| S4 | 治理 | DATA3 | 知识单元 | 质检报告（去重/口径/血缘/新鲜度/权限） | G4 可追溯 100%、重复 0 | T+2 |
| S5 | 提炼 | DATA5 | 知识单元 | 概念/FAQ/学习卡候选/简报（`card_proposal_*`、`learning_digest`） | G5 抽样人审通过、来源可核验 | T+3 |
| S6 | 标准化 | DATA4 | 提炼件 | 命名/编码/schema/索引/元数据登记；`kb_units_snapshot`、索引更新 | G6 schema/命名/索引一致 | T+4 |
| S7 | 发布 | DATA1 验收 | 标准化产物 | `portal/static/*`（KB/学习卡/样例）、RAG corpus、门户页 | G7 评测回归不漂移 + HTTP 200 | T+5 |
| S8 | 归档 | DATA1 | 全部产物 | `_archive/<日期>_<项目>/`：ENTRY.md + manifest.json；状态 archived | G8 归档清单齐、只读、禁止项写明 | T+7 |

## 6. 质量门与指标

- 门：G1 源完整 / G2 OCR 质检 / G3 schema / G4 可追溯 100%+重复 0 / G5 抽样人审 / G6 命名索引 / G7 评测回归 / G8 归档齐；
- 指标：登记率 100%、清洗成功率≥99%、可追溯 100%、重复 0、人审通过率、SLA（S2 T+1 / S5 T+3 / S7 T+5 / S8 T+7）、断流 0；
- 不达标处理：DATA1 标记 blocked 并排期修复；连续 2 天不达标升级 A0；影响发布/不可逆动作升级老田。

## 7. 升级与审批边界

- 日常（S1–S6）：DATA1 全权；
- 跨部门资源/排期冲突/风险：DATA1 → A0（仅仲裁）；
- 立项、结项、对外发布、不可逆/数据删除：老田审批；
- 学习项目**不再由 A0 直接处理/归档**（本次修正：此前 A0 为学习PDF归档 owner 的表述作废）。

## 8. 模板

- 项目目录：`_archive/<YYYY-MM-DD>_<项目名>/{ENTRY.md, manifest.json}`；
- 项目记录：`agent_platform/registry/learning_projects.json`（id/name/status/owner=DATA1/source/stage/artifacts/next_action）；
- 质量回执：每阶段 `research/reports/<project>_<stage>_<date>.{json,md}`；
- 验收单：DATA1 签「阶段通过/阻塞」；老田终验。
