## 三、数据契约（v1，统一版本号字段 `schema_version`）

| Schema | 必有字段（摘要） |
|---|---|
| `learning_source_manifest.v1` | project_id、generated_at、files[]（name/sha256/size/origin/copied/ingested_at） |
| `learning_unit.v1` | unit_id、project_id、claim、evidence{file,line}、status(draft/approved/rejected)、created_at |
| `learning_card_candidate.v1` | card_id、project_id、concept、q、a、source、evidence、theme、status(pending_review/pass/revise/reject)、traceable、precheck{action,issues} |
| `learning_decisions.v1` | project_id、generated_at、decisions[]（card_id、action、reviewer、decided_at、note）、summary |
| `learning_archive_manifest.v1` | project_id、name、status=archived、archived_at、owner_ai、artifacts[]（path/sha256）、conclusions、forbidden、continue_entry |

规则：**旧格式必须先经 `learning_schema_migrate.py` 映射**；新工具只产出 v1 契约；字段缺一即 GATE fail。

## 四、发布门（G7，硬清单）
1. schema 校验全过（候选/决策/单元）；
2. 知识单元**可追溯 100%**（evidence 文件存在于清洗目录）；
3. 概念重复 **0**（与现有学习卡及批内）；
4. 有**decisions.v1** 且 `pass` 卡片才允许合并（人工/预审 reviewer 留痕）；
5. 合并后 `learning_cards.json`：字段完整、无重复 concept；
6. `learning_digest` 刷新 rc=0 + 页面/JSON HTTP 200；
7. 评测回归（WeeklyEval）无漂移（±0.02）。

不满足任一条 → **禁止发布**；只允许留在候选/草稿状态。

## 五、门禁工具（GATE）用法

```powershell
# 阶段自检（默认只读打印）
C:\项目\py312\python.exe -X utf8 tools/kb_corpus/learning_gate.py check --stage all
# 严格模式（失败 exit 1，用于定时任务）
C:\项目\py312\python.exe -X utf8 tools/kb_corpus/learning_gate.py check --stage publish --strict --write
```

- 阶段：`intake|units|candidates|publish|archive|all`；`--write` 落 `research/reports/learning_gate_<date>.json/md`；
- 已归档项目只校验 archive 阶段（其余阶段 skip）；
- 定时任务接线：Intake 后跑 `--stage intake`、Pipeline 后 `--stage units`、Governance 后 `--stage candidates`、Standardize 后 `--stage all --strict`。
