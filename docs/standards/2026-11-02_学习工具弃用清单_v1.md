> 目的：学习卡「生成 → 预审 → 发布」只保留**唯一路径**，历史单点工具加 DEPRECATED 标记防误用。
> **本次仅加文件头注释与清单，未改任何工具行为**（语法门 PASS）。

## 一、统一路径（现行唯一）

```
知识单元草稿（30_知识单元/<pid>_units_draft.jsonl）
  │  tools/kb_corpus/card_from_units.py          ← 生成候选（pending_review）
  ▼
候选卡（portal/static/card_candidates_<pid>.json）
  │  tools/kb_corpus/card_precheck_laomu.py      ← 预审（规则可配置；pass/revise/reject）
  ▼
审核稿 / decisions（research/reports/card_proposals_<pid>_<date>.json 等）
  │  tools/kb_corpus/learning_release.py         ← 发布门强制（gate publish → approved → card_merge → digest → gate strict → 回执）
  ▼
学习卡（portal/static/kb_learning_cards.json）+ 发布回执（learning_release_*.json/md）
```

禁止绕过：不得直接 `card_merge.py --apply` 推进学习卡（发布统一走 `learning_release.py`，含前后置 gate）。
