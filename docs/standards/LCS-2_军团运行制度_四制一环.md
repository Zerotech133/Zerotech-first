# 军团运行制度（LCS-2 · 四制一环）

> 2026-10-17 立制 ｜ 上游：LCS-1 看股标准（个人分析纪律）→ 本档管**组织运行纪律**
> 终极目的：一切结构化沉淀（计划/职责/会议/复盘）最终反哺 AI——**每个循环让军团比昨天聪明一点**

---

## 一、四制一环总览

```
┌─ ① 职责制 ─── 部门宪章(charter) + 岗位职责(duty) + 技能标签(skills)
├─ ② 计划制 ─── 周计划(dept_plan) / 日任务(排程+派单) / 里程碑(项目)
├─ ③ 会议制 ─── 晨会(日) / 部务会(周) / 专题会(临时) —— 固定议程+结构化记录
├─ ④ 复盘制 ─── 成员三问(日) / 部长点评(日) / 部门日报(日) / 军团日报(日) / 周复盘
└─ ⭕ 知识环 ── 一切记录 → 提炼(教训/判例/心得) → knowledge.jsonl → 反哺人设/路由/知识库
                  ↑__________________ AI 变聪明的飞轮 __________________↓
```

## 二、职责制（已建成的补全）

| 层 | 载体 | 状态 |
|---|---|---|
| 部门宪章 | org.json departments[].charter | ✅ 已有 |
| 岗位职责 | hr/<ID>/appointment.yaml 增 `duty` 字段 | 本轮补 |
| 技能标签 | resume.yaml skills（指挥台可编辑） | ✅ 已有 |

duty 格式：一句话核心职责 + 3 条红线。例（庞统/T1）：
`duty: 技术面多头论证——每论点必可证伪；红线：不臆造数据/不越权交易/L4存疑禁止看多`

## 三、计划制

**周计划** `agent_platform/data/plans/YYYY-Www_<dept>.md`：
- 周一 09:00 部务会产出：本周目标(≤3) / 任务分解 / 依赖与风险
- 与排程打通：计划任务可直接 cron 化

**日任务**三来源：排程（定期）/ 派单（指挥）/ 领单（成员主动——复盘 q3 的"主动领单"落地点）

## 四、会议制（核心新增）

### 会议类型与固定议程

| 会 | 频率 | 时点 | 与会 | 固定议程（议而不离此框） |
|---|---|---|---|---|
| **晨会** | 每工作日 | 09:00 | 部门全员+部长 | ①昨日完成(读复盘卡) ②今日任务(读排程/派单) ③阻塞求助(超期单) — 每部门 ≤15 分钟 |
| **部务会** | 每周一 | 09:30 | 部门全员 | 周计划制定 + 上周复盘 + 知识分享(判例) |
| **军团例会** | 每周五 | 16:00 | 田小皮+九部长 | 各部周报(3分钟/部) + 军团周复盘 + 表彰/督办 |
| **专题会** | 临时 | — | 相关者 | 单一议题深钻（如 600337 全链分析复盘） |

### 会议记录结构（强制字段——结构化才能喂知识环）

```yaml
meeting: 晨会|部务会|军团例会|专题会
dept: invest    date: 2026-10-20   chair: 鲁肃(D1)
attendance: [庞统, 司马懿, 许劭, 荀彧, 鲁肃]
agenda_done: [昨日三线扫描完成, 600337群辩已跑]
todo: [{agent: 庞统, task: weak池扫描, due: 今日}, ...]
blockers: [{agent: 许劭, issue: 新闻源降级, need: DATA1支持}]
decisions: [L4存疑票不入池]           # 决议（可判例化）
lessons: [席位净流入不等于抢跑成立——需公告耦合佐证]   # 教训（必进知识环）
```

## 五、复盘制（已建成，见 daily_review 四段流）

新增：**周复盘**（周五军团例会输入）= 7 日复盘卡聚合 + 工单完成率 + 知识产出统计。

## 六、⭕ 知识环（AI 变聪明的飞轮——本制度的灵魂）

```
会议记录/复盘卡/工单小结
   ↓ knowledge_distill（提炼器）
教训(lesson) / 判例(precedent) / 心得(insight) 三类条目
   ↓ 结构化写入
agent__<ID>__knowledge.jsonl（个人长记性）
   ↓ 周期反哺（每周部务会的知识分享环节拍板）
① 人设 prompt 增补（该员从此带着教训上岗）
② 判例库 docs/precedents/（全军团共享）
③ 路由能力册 skills 更新（会了新技能）
   ↓
下一次任务更聪明 ←——————— 循环
```

**反哺判据**（不是所有话都值得记）：
- lesson 必须可证伪可复用（"要小心"不收，"席位流入≠抢跑，需公告耦合"收）
- 每人每周知识条目 ≤5（防膨胀）
- 部务会拍板才入 prompt（人审关口）

## 八、纪律

1. **无记录不开会**：会而不记=白开，记录必须落 meetings/ 目录
2. **无教训不复盘**：复盘卡 q3 空=敷衍，部长点评退回重写
3. **知识必过审**：入 prompt/判例库的条目需部务会拍板（防幻觉沉淀）
4. ID 永不改：中文名是皮肤，ID 是骨骼（账本/记忆/工单全靠 ID）
