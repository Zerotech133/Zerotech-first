## 三、envelope / error 适配器用法（不强制改造现有 API）

```python
from agent_platform.contracts import ifs

# 成功：包一层 IFS-03 信封（data 需通过对应单接口 schema 校验）
payload = ifs.wrap_ok(
    "confirm.create", "trading_bot_confirmation/v2", data,
    source_of_truth="agent_platform/data/confirmations/",
    source_mode="ledger",
    as_of="2026-11-03", freshness_s=0, stale=False,
    ids={"confirmation_id": data["confirmation_id"]},
    warnings=[], generated_at=ifs.now_iso(),
)
assert ifs.validate_envelope(payload) == []

# 失败：错误码 + retryable + details（HTTP 层由调用方发送）
err = ifs.wrap_error(
    "bad_target_action", "watch 只能交 WA1/WA2/WA3/WATCH_TOWER",
    details={"field": "target"},
)
assert ifs.validate_error(err) == []
http_status = ifs.error_http_status("bad_target_action")   # 400
```

要点：

1. `schema_version` 必须与 registry `interfaces[*].schema` 同族（如 `d1_handoff/v2`）；
2. `request_id` 格式 `req-<32 hex>`；服务端应回写 `X-Request-Id`（IFS-10）；
3. 失败不得 `ok=true` 包裹；`data=null` 仅限 `ok=true` + warnings 说明（fail-visible）；
4. 错误码 21 个与 registry `envelope.error_codes` **逐项一致**（契约测试锁定）；
5. 适配器为纯函数、stdlib only：不写盘/不联网/不读 registry（registry 由测试交叉校验）。
