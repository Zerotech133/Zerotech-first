## 一、P-09b → is_broken_board 标记

### 为什么不再当 pattern

| 事实 | 数值 |
|---|---|
| v2.2 定义下 P-09b 样本 | 6 个 / 60 交易日 ≈ **0.10 个/日** |
| 按 n≥50 累积所需 | 约 **440 个交易日** |
| 实际语义 | 100% 是「盘中封过板、收盘未封住」= **炸板**，不是「从没涨停的票」 |
| 形态 | T+1 已为负（−0.46%）→ 「一路阴跌」，v2.1 的「冲高回落」措辞低估 |

转正判据 C1（n≥50）永远走不完，C4（T+1>0 且 T+10<0）也不成立。继续占一个 pattern id 只会让每次汇总都要解释一次「这 6 个不算」。

### 改成什么

```python
def flags(m):                     # _p51_matcher.py
    return {"is_broken_board": bool((not m.get("limit_up")) and m.get("seal"))}
```

- `limit_up == False` 且 `seal` 非空（盘中封过板）→ `is_broken_board = True`
- 随每个样本输出（`_p52_caselib` 样本新增该字段）
- 无 pattern 命中的炸板票进 JSON 的 `broken_board` 池，**不进 `samples`、不进 `summary`**
- 不占 pattern id、不进判定闸分子、不参与转正判据；`MINUTE_PATTERNS` 与 `GATE_A2_EXCLUDE` 已移除 P-09b

### 标记展开后的实测（关键）

标记的口径比 P-09b 宽得多（不要求「主力进 + ≥2 独立分钟源追认」），样本从 6 涨到 697：

| 池 | n | T+1 | T+10 |
|---|---|---|---|
| 涨停池（收盘封住） | 2,671 | **+0.76%** / 48% | −3.20% / 32% |
| **炸板池（触板未封）** | **697** | **−1.01% / 35%** | **−4.96% / 27%** |
| 触板池（两者合并） | 3,368 | +0.40% / 45% | −3.61% / 31% |

**炸板相对涨停池：T+1 −1.77pct、T+10 −1.76pct，胜率低 13pct。**

月度稳定性（T+1 四个月全负，方向一致）：

| 月份 | n | T+1 | T+10 |
|---|---|---|---|
| 202608 | 247 | −0.74% / 38% | −2.22% / 36% |
| 202609 | 335 | −1.24% / 32% | −5.55% / 24% |
| 202610 | 81 | −0.85% / 36% | −11.38% / 8% |

> 口径声明：炸板池的票来自候选池（涨停 ∪ 主力净流出 ∪ 主力净流入前 20% ∪ T-1 公告票），
> **不是全市场炸板票**。因此这是「候选池里的炸板」读数，不能外推为「所有炸板票都跌」。

## 二、P-07 negative 面词表扩容

### 方法

对 3,510 个 P-07 episode 取 T−1 真公告标题，逐候选词做子集后验，四个轴分别对照 P-07 全体基线
（T+1 −0.39% / 胜率 43%；T+10 −6.03% / 胜率 25%）：

- **A** T+1 均值 ≤ 基线 −0.50pct
- **B** T+1 胜率 ≤ 基线 −8pct
- **C** T+10 均值 ≤ 基线 −2.00pct
- **D** T+10 胜率 ≤ 基线 −5pct

入选要求：**n ≥ 10，且 A/B 至少命中一条（短期要能区分），C/D 至少命中一条。**

| 问询 | 27 | −1.61% / 33% | −8.20% / 11% | ABCD | **新增** |

新增 6 个：`仲裁 / 问询 / 终止 / 减持计划 / 冻结 / 聘任`。

### 实测不达标但暂留（LEGACY，待裁定）

| 词 | n | T+1 | T+10 | 问题 |
|---|---|---|---|---|
| 并购 | 9 | **+1.05%** / 67% | **+8.24%** / 40% | 方向相反（样本少但为正） |
| 合同 | 32 | +0.10% / 50% | −3.38% / 29% | 无任何轴命中 |
| 重组 | 25 | −0.56% / 40% | −5.95% / 19% | 仅 D |
| 增资 | 33 | −0.48% / 42% | −8.85% / 14% | 仅 C、D（无 A/B 短期区分力） |
| 竞得 | 1 | +2.45% / 100% | −5.33% / 0% | n=1 |

**这三类处置**：v2.3 保留在 negative 面（不动已冻结口径），但代码里单列为 `P07_NEG_LEGACY`，与 VALID 分开。
删掉它们的方案（V2）实测更纯，见下节待裁定项。

### 三个方案对比

| 方案 | negative n | negative T+1 | negative T+10 | 条件②覆盖率 |
|---|---|---|---|---|
| V0 现状（8 词） | 198 | −0.39% / 40% | −7.10% / 16% | 52.94% |
| **V1 只加不删（v2.3 采纳）** | **317** | **−0.75% / 38%** | **−7.95% / 14%** | **53.50%** |
| V2 再加删 5 个 LEGACY | 233 | −1.11% / 33% | −8.71% / 12% | 53.31% |

**V1 让负向面更宽也更负**（T+1 −0.39%→−0.75%、T+10 胜率 16%→14%），代价是纯度略降。
V2 更纯但覆盖率反而低 0.19pct（删掉的词里有少数 pair 未被 P-08 覆盖）。

### ★ 一个必须说清的结论：扩容不是覆盖率的杠杆

| 项 | 前 | 后 |
|---|---|---|
| 条件②分子 | 568 | **573** |
| 覆盖率 | 53.03% | **53.50%（+0.47pct）** |
| 距 60% | 6.97pct | **6.50pct** |

原因：涨停票只要「有新闻且全是弱类型」就已经进 P-08 分子，P-07 再怎么扩，**新增的 negative pair
大多本来就在 P-08 里**。之前把「P-07 词表扩容」当作主杠杆，是估算错误，此处更正。

## 六、教训

1. **判据只看均值会误杀**：第一版判据只查 T+1 均值，把「减持」（胜率 31%、T+10 −8.69%）判成不达标。
   负向信号要看收益与胜率两条腿，至少两轴。
2. **同一池内的词对比不构成区分力**：P-07 全体 T+10 已经是 −6.03%，比它更差很容易，
   所以必须要求至少一条**短期**轴（A 或 B）命中，否则「发行」这类泛词也会入选。
3. **pattern id 是稀缺资源**：0.10 个/日的面占一个 id，每次汇总都要额外解释。
   标记（flag）完全可以承载同样的信息，且没有转正包袱。
4. **标记口径放宽会带来意外收获**：P-09b 收紧到 6 个样本时看不出方向，放宽成「所有炸板」后 697 个样本、
   四个月 T+1 全负——原来不是信号弱，是筛选条件把样本卡死了。
