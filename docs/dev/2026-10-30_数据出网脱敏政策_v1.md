# 数据出网脱敏政策 v1（IDE / A0 / 诸葛复核共用）2026-10-30

> 背景：A0 工单 desc 会随 prompt 发送至云端 Hermes（glm-5.3）；诸葛亮复核会把 diff 发送至 DeepSeek 云端。
> 本政策为 P0-2 前置；默认 **fail-closed**（扫描失败=不发送）。未改代码，待审批后实施。

## 一、数据分级

| 级别 | 定义 | 出网规则 |
|---|---|---|
| **L0 公开** | 已公开文档/公开行情 | 可出网 |
| **L1 内部** | 工单标题、普通代码 diff、非敏感日志 | 可出网，最小上下文 |
| **L2 敏感** | 客户数据、持仓/交易、内部路径、未公开策略、完整 repo 上下文 | **默认不出网**；需脱敏或本地模型；单次审批 |
| **L3 机密** | API key/token/cookie/私钥、密码、身份证/手机号、`.env`、secret store 内容 | **禁止出网**；扫描命中即拒绝 |

## 二、字段级规则

| 字段 | 处理 |
|---|---|
| 工单 `desc` | 先分类；L2/L3 内容脱敏（客户名/账号/路径/策略参数替换为占位符）后才可进 A0 prompt |
| `diff` | 发送前过 secret scan（key/token/private key/phone/ID）；命中 L3 → 拒绝复核；L2 → 摘要/脱敏或本地模型 |
| `test_result.output_tail` | 截断 + 去环境变量/路径/凭据 |
| `context` | 仅 goal/acceptance；不灌全仓 |
| 日志/审计 | 只记录 hash/长度/命中规则，不记录原文 |

## 三、执行机制

1. **共享 redactor**：`tools/redact_outbound.py`（P0-2 实现），输入 text → `{redacted, hits, level}`；
2. **接入点**：A0 orchestrate 前、诸葛 review 提交前、任何外部模型调用前；
3. **fail-closed**：扫描器异常 → 不发送，返回 degraded；
4. **审计**：`data_outbound_audit.jsonl` 记录 task/run_id/model/bytes/hits/decision（不含原文）；
5. **复核 agent 零工具**：禁 web_fetch/memory_search/docs_search 等外连工具（或 allowlist+审计）；
6. **审批**：L2 单次出网需人批；L3 永不。

## 四、验收（P0-2）

- 测试语料（API key、cookie、私钥、手机号、身份证、客户名）100% 拦截/脱敏；
- 误报可接受但需人可覆盖（记录理由）；
- A0/诸葛 两条链路均接入 audit；
- 复核 flag 默认关，启用前 shadow 样本通过；
- 政策与实现同步进 ADR。
