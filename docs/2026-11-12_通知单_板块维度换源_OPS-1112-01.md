---

## 1. 起因：不是我们漏跑，是上游不再供数

`factor_proto/data/sector_daily.parquet` 最新只到 **20261012**，落后 22 个交易日。三条实测证据：

1. **直连上游接口探测**：`?start_date=20261023` → `rows: []`、`total: 0`、`total_exact: true`
   （`total_exact: true` 表示上游确认「这个区间真的没有数据」，不是分页假象）
2. **不带过滤取首页**：第一条记录就是 `20261022`，其 `_fetched_at = 2026-10-22 17:00:33`
   —— 上游最后一次抓数是 10-22 收盘之后
3. **另一份落湖产物** `quant_backtest/data/tdx/tdx_sector_daily` 到 20261022，但 10-13 起
   每天只有 2~3 个板块（24 行/10 天），等于没有，不能当可用片

**结论：这是上游断供，不是本地采集漏跑，也不是架构停更。** 三类问题必须分开写，
不要混成一句「板块停了」。

### 附带发现的一个假成功

`TdxTailSync` 每天 04:30 跑，`exit=0`，日志写 `[tdx_sector_daily] incremental from 20261022
→ DONE rows=... parts=31 1s`。1 秒完成、parts 数没变、最大日期没动 —— **上游给空时它照样报 DONE**。
「上游给空」与「采到了但没新增」必须分成两种输出，这条已并入采集侧整改要求。

---

## 2. 处置：不换外部源，改为本地自合成

评估过换外部源（东财板块行情、tushare `sw_daily`），都需要额外积分或额外接口，
且仍然是「别人的接口」。**本机已有两份数据足够自给：**

| 数据 | 内容 | 实测 |
|---|---|---|
| `index_member_all` | 5922 只票 → 31 个申万一级行业 | `out_date` 全空 = 全在册，`in_date` 最早 19891101 |
| `daily` | 全市场日行情 | 8752 个交易日 |

二者一 join，行业等权日线即可**跟着 daily 一起日更**，彻底去掉对断供接口的依赖。

新产物：`portal/daily_report/lens/sector_daily_synth.parquet`（本地，不入库）
生产者：`portal/daily_report/sector_synth.py`（调度在 16:40 的 `sector` 阶段，排在 lens 之前）

## 3. 口径变了，必须一起签收（这是本单最要紧的一条）

| 维度 | 旧（TDX 板块快照） | 新（本地自合成） |
|---|---|---|
| 行业数 | 132 个段（industry_l1 + old_industry） | **31 个**申万一级行业 |
| 加权 | 上游口径（不可考） | **等权**（成分股 `pct_chg` 简单均值） |
| 更新 | 一次性全量快照，无日更 | **随 daily 日更** |
| 覆盖 | 未实测 | 5574/5574 只，**100%** |
| PIT | 无成分时点 | 按 `in_date ≤ 当日 < out_date` 取成分 |

**等权 ≠ 市值加权，这是系统性差异，不是噪声。** 因此：

- ✅ 可用于：行业之间谁强谁弱、上涨行业占比、行业间分化度（横截面与广度判断）
- ❌ 不可用于：与申万官方指数（市值加权）比绝对水平、与旧 TDX 数据接续做时间序列
- ❌ 不可用于：任何以「板块指数点位」为前提的指标（如板块 RPS 的历史接续）

若你要把新旧数据拼成一条长序列，**必须显式断开**，不能直接相接。

## 7. 验收与回滚

**验收口径（三项全过才算交付）**

```bash
python portal/daily_report/sector_synth.py --check          # rc=0，产物最新 == clock
python portal/daily_report/check_products.py --only sector_daily   # 判定 OK，落后 0
grep -c '板块轮动' portal/daily_report/multi_lens.html      # 页面含该维度
```

**回滚**：`product_registry.yaml` 的 `sector_daily.compose` 删掉自合成片即可回到原片。
但注意——**回滚等于回到「落后 22 个交易日」的过期状态**，因为原片上游已经不给数了。
所以回滚不是选项，只是「自合成出错时的止损位」。
