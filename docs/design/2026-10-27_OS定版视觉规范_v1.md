## 5. 页面骨架（PageShell）

```
┌─ 全局导航（nav.js / nav.css，sticky，z=99）
│  动线胶囊 + 5 域下拉 + 返回
├─ 页面头部
│  品牌（18/750） + 只读徽标（badge） + 视图 tabs（今日建议/工作平台/今日结果/指挥大屏）
├─ 内容主区
│  eyebrow（11 大写距）+ H1（40）+ 引导语（16 muted）
│  freshness strip（来源核对/刷新）
│  panels / cards / grids / rows
├─ 页脚：门槛说明/版本/只读标注
└─ 浮动：⌘K 命令入口、密度切换（ui_palette）
```

要求：

1. 页面头部必须有「当前视图」高亮（下边框 2px 青色）；
2. 只读徽标固定文案「独立评审 · 只读」或场景等价；
3. 异步区域必须有 skeleton/aria-live/错误重试（W2 模板）；
4. 详情/证据入口统一放右侧或页脚（后续 EvidenceDrawer）；
5. 面包屑 + 链路条在 L2/L3 页面启用（本轮规范先定义，后续实现）。

| 组件 | 规范 |
|---|---|
| 顶栏 | `nav.css` 的 `.wb-nav`；高度/胶囊/下拉沿用；当前项 `is-active`；不新增第三层 |
| 视图 tabs | 5px 圆角，激活态下边框 2px 青色、透明底 |

| 按钮 | 行动按钮暗底/亮青边/浅青字；hover `--os-action-bg-hover`；禁用 40% 透明 |
| 顶部条 | 暗条 `--os-strip-bg-dark`；按钮 `--os-strip-btn-bg-dark` |
| source/row | 分隔线 + 11/13px；来源/时点/状态三段 |
| empty | 虚线框 + `--os-empty-bg/bd`；提供下一步按钮 |
| skeleton | W2 灰块 + shimmer；reduced-motion 关闭 |
| error | 红边 + 具体错误；禁止只显示「失败」 |
| 命令面板 | W3 规范；`Ctrl/Cmd+K`；无执行动作、无 storage |
| 密度 | `[data-wb-density="compact"]`；表格/列表间距与字号 |
| skip link | 第 1 个 Tab 落点；`.wb-skip` |

**状态色**：ok=绿、err=红、warn=琥珀；不得用红/绿表达涨跌之外的状态（遵循全局语义）。

## 7. 交互与可访问性

- 键盘：Tab 顺序 = skip → 顶栏 → 视图 → 主区动作 → 页脚；focus 可见；
- 命令面板：Ctrl/Cmd+K，↑↓ 选择，Enter 执行，Esc 关闭并归还焦点；
- 动效：180ms 标准缓动；尊重 `prefers-reduced-motion`；
- 异步：loading→skeleton，空→empty+下一步，错误→error+重试；
- 不自动刷新整页；刷新只更新数据区，保留焦点/滚动；
- 移动端 375px：无横向溢出；点击目标 ≥44px；
- 禁止：自动播放、闪烁、只靠颜色表达状态、无标签图标按钮。

---

## 8. 内容语气

- 结论先行，说明依据；不堆指标；
- 明确边界：规则归集就写「规则归集，非模型推理」；未接日历/审批就写「未接，不能当正式日程/派单」；
- 状态词：待核 / 已核 / 降级 / 不可用 / 未接，不用「可能/大概」伪装确定；
- 时间、来源、ID 必须可追溯；没有数据就写「未取得」，不造样本；
- 动作文案行动化：「打开工作平台」「重新核对来源」，不用「点击这里」。
