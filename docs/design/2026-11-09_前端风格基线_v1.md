## 一、单一事实源

`portal/static/tokens.css`（GitHub Dark 基底）。所有页面颜色/字号/间距/圆角
只准引用 token，禁止新写裸 hex。

**自包含页**（离线交付的 H5 / 控制台）不外链 tokens.css，但必须：
1. 在 `<style>` 头部注释声明「Tokens 基准：portal/static/tokens.css，值同源」；
2. 值与基准逐一相同（对表见下），改动基准时同步改副本。

## 二、组件规范

- **卡片**：底 `gray-2`、边 `gray-4`、圆角 10–14px、内距 12–16px；
- **按钮**：主=blu-600 实底白字，次=灰边透明底，危险=红边描线（不红底），
  禁止各页自造 .btn-red/.btndis 之类平行体系；
- **表格**：表头 dim 色、行分隔 `gray-3`、数字右对齐、涨跌色只上数字；
- **警示**：左缘 3px 状态色 + 浅底（同 H5 `.note`）；
- **涨跌语义**：颜色只做视觉辅助，**正负语义必须由汉字承担**（「赚/亏」「高/低」）；
- **每个数字必须有参照物**（基准/总数/满分是什么）。

## 三、中文文案规范

1. 正文禁止裸英文术语；下表术语出现时用中文，原词放抽屉/证据层：

| 英文 | 对外中文 |
|---|---|
| OOS | 样本外验证 |
| IS | 样本内 |
| provenance | 证据链 |
| gate / gating | 闸门 |
| escalate / escalation | 升级（超时转人工） |
| WF | 滚动前推验证 |
| confluence | 多条件共振 |
| tenant | 租户（保留，行业通用） |

2. 品牌语统一「零界 · <页名>」，禁止一页一个叫法；
3. 禁止 emoji 当标题图标（`<title>` 与一级标题）；
4. 时间一律 `MM-DD HH:MM`；金额 `¥`；百分比保留两位。

## 四、代码规范

1. **类名/ID 一律 ASCII**（禁 `class="k发现"` 这类中文类名；中文值→ASCII 映射表放脚本区）；
2. 全部文件 UTF-8（BOM 可），**禁止 GBK**；
3. **凭据不进代码**：DSN/token/密码走环境变量或 `.secrets/`（git 必须忽略）；
4. 端口/路径可被 env 覆盖，写死只许出现在一处（服务入口）；
5. 单函数 ≤120 行，超过必须拆；`do_GET` 式巨型分发器禁止新增分支，新功能走注册表；
6. `.bak*` 一律进 `_attic/`，不得留在 webroot/源码目录；
7. 死代码即删，不留注释掉的代码块。
