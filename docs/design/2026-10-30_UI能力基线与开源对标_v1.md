## 2. 开源对标（2026-10 现状）

| 项目 | 学什么 | 不照搬什么 |
|---|---|---|
| [shadcn/ui](https://ui.shadcn.com/) | 组件源码可复制、可改；组合优于封装 | React/Tailwind 依赖 |
| [Radix Primitives](https://www.radix-ui.com/primitives) | Dialog/Tabs/Dropdown 的可访问性状态机 | React 运行时 |
| [Ant Design](https://ant.design/) | 企业级密度、表格/表单/空态规范 | 重主题、强品牌默认样式 |
| [MUI](https://mui.com/) | 主题令牌与组件变体体系 | 全量组件库/运行时 |
| [Shoelace](https://shoelace.style/) | Web Components、框架无关、渐进增强 | 直接引入整套组件包 |
| [Tailwind CSS](https://tailwindcss.com/) | utility 与设计令牌的映射 | 引入构建链 |
| [Grafana](https://grafana.com/) | 大屏/告警/面板密度与状态色 | 重型图表栈 |
| [Open WebUI](https://github.com/open-webui/open-webui) | 对话/工作台信息架构 | 后端/模型栈 |

## 3. 零界选择

1. **无框架**：继续 vanilla HTML/CSS/JS + 渐进增强，避免为 UI 引入 React/构建链；
2. **组件源码化**：像 shadcn 一样把组件放在 `portal/static/ui/`，页面可读可改；
3. **可访问性借 Radix**：Dialog/Tabs 的键盘/焦点/ARIA 规则自己实现；
4. **组件边界**：Button/Badge/Card/Panel/KPI/Toolbar/Search/Tabs/Table/Empty/Loading/Error/Drawer/Toast；
5. **页面壳**：`PageShell` 统一 head/nav/page-head/footer，业务页只填内容；
6. **验收**：组件页 1440/390 截图 + `ui_ux_audit` 无新增 warn + 键盘可达。

## 4. 组件清单 v0.1

- 基础：`.ui-btn`（primary/ghost/danger/sm）、`.ui-badge`（ok/warn/err/info）
- 容器：`.ui-card`、`.ui-panel`、`.ui-grid`、`.ui-kpi`
- 交互：`.ui-toolbar`、`.ui-search`、`.ui-tabs`、`.ui-drawer`、`.ui-toast`
- 状态：`.ui-loading`、`.ui-empty`、`.ui-error`、`.ui-skeleton`
- 数据：`.ui-table`（等宽数字 `.num`）

页面见 `portal/ui_kit.html`。
