## 2. 页面清单（按族，active/legacy/review 三态）

### 2.1 active 主入口（必须保持三件套+壳）
- `/`（home_v3）、`/zero_proto.html`、`/os-entry`（os_entry_v9_prod）、`/os-board`（os）、`/hq`、`/portal`、`/login`
- 移动：`/m/` + 16 路由（entry/picks/chan/position/notify/subscription/daily/ledger/lineage/ticket/ops/analysis/brief/push/feed/strategy）+ `/m/strategy/<id>`、`/m/feed/<ticket>`
- 域入口：`/quant/*`（adapter）、`/sa`、`/intel`、`/dev`、`/ops`（按 nav 域）

### 2.2 legacy（保留入口，不再作为视觉基准；迁移/重定向）
| 页面 | 说明 | 处置建议 |
|---|---|---|
| `/home.html` | 旧首页 | 重定向 `/` 或保留 legacy 标注 |
| `/index.html` | 旧 index（40KB） | 核对是否仍被引用；无引用则归档/重定向 |
| `/portal` 动态页 | 旧总入口 | 保留运维入口，标注 legacy |
| `picks_public/*` | 生成页（4 HTML） | 由发布链路生成；清单标注"生成物" |
| `static/comm_ticket.html`、`static/dw_v2*.html` | 静态模板/原型 | 移出生产清单或标注 review |

### 2.3 review（评审稿/原型，不得作为生产入口）
- `os_entry_v4.html`、`os_entry_v5.html`（标题已注明"评审稿·非生产页"）——nginx 已 302 到 `/os-entry`（保留归档，不开放直达）
- `os_entry_v1..v8`、`zero_proto` 旧版本、`os_map.html`、`zero_home.html`、`protos/`、`work/unpublished/`、`work/publish_rollback_*` 副本
- 处置：统一 `status: review/archived`；需要保留演示的加 `noindex` + 明确入口标注；不进入页面清单导航。

### 2.4 生成物/备份（不属于 UI 生产清单）
- `picks_public/`（发布生成）、`work/publish_rollback_*`（回滚备份）、`data/os_goals/*/workspace`（任务工作区）
- 规则：**不得被当作生产页面维护**；构建/发布产物与备份目录不参与 UI 三件套检查，但在清单中登记"生成物/备份"状态，避免误判。

## 3. 页面清单（page manifest）schema v0

```yaml
schema: lingjie/page-manifest/v0
id: page/<slug>          # 全局唯一
path: /path              # 或 /m/path/<param>
family: cockpit|os|portal|h5|adapter|legacy|review
title: 页面标题
theme: light-cockpit|dark-os|h5|adapter:hermes|adapter:quant|legacy-dark
shell: cockpit-shell|os-shell|h5-shell|none
nav: nav-js|own-6|m-shell|none
auth: none|oidc|portal-token
status: active|legacy|review|archived
owner: A0|ARCH1|...
apis: [/api/...]
visual_baseline: docs/visual_baseline/<file>.png
note: 说明
```

校验规则（W3 门）：
1. `path` 必须能映射到 `route_baseline` 或静态文件；
2. `active` 页面必须 `theme/shell/nav` 三者非空且与实测依赖一致（tokens/nav/m.js 存在）；
3. `review/archived` 不得出现在导航；`legacy` 必须有迁移/退役备注；
4. 新增/删除页面必须同批次更新清单 + 路由基线（`portal_route_inventory --write-baseline`）。
