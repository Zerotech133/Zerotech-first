# 零界 A11y 检查清单 v1（2026-10-27）

> 适用：门户静态页/仪表盘/命令面板。目标不是「满分」，而是**键盘可用、语义清楚、状态可感知、动效不伤人**。
> 配套工具：`tools/ui_ux_audit.py`、`tools/ui_keyboard_audit.py`、`tools/ui_visual_baseline.py`（CDP）。

## 0. 每个页面必过（静态）

- [ ] `<html lang="zh-CN">`、viewport meta
- [ ] 引用 `tokens.css`（视觉唯一源）；无新增硬编码 hex/内联 style
- [ ] 统一顶栏/导航（`nav.js` 或定型页自身导航）
- [ ] 375px 短屏可用（无横向溢出/文字截断）
- [ ] `python tools/ui_ux_audit.py <files> --markdown`：无 warn（info 可解释）

## 1. 可感知（Perceivable）

- [ ] 文字对比度：正文 ≥4.5:1，大字/图形 ≥3:1（深色底尤其检查弱文字）
- [ ] 状态不能只靠颜色：涨跌/成功失败同时有文字或图标
- [ ] 图片/图标有替代文本；纯装饰 `aria-hidden`
- [ ] 表格有表头 `<th scope>`；复杂表有 caption/说明
- [ ] 空/加载/错误状态有文案，不只转圈

## 2. 可操作（Operable）

- [ ] 全部功能键盘可达（Tab/Enter/Space/Esc/方向键）
- [ ] **skip link 第 1 个 Tab 落点**（`tools/ui_keyboard_audit.py` + CDP 实测）
- [ ] `:focus-visible` 明显（tokens 全局焦点环；不得 `outline:none` 无替代）
- [ ] 无键盘陷阱；弹层/命令面板 Esc 关闭且焦点归还
- [ ] 点击目标 ≥24×24px（移动端 ≥44px 优先）
- [ ] 动效尊重 `prefers-reduced-motion`；无自动闪烁/循环干扰
- [ ] 命令面板等浮层：`role=dialog`、`aria-modal`、焦点进入输入框、方向键选项

## 3. 可理解（Understandable）

- [ ] 导航/按钮文案行动化，避免只有图标无 label
- [ ] 表单有 `<label>`；错误提示具体、可被读屏读出
- [ ] 导航一致：顶栏 + 面包屑两层，当前页有 active/aria-current
- [ ] 时间/单位/口径写清，避免歧义

## 4. 健壮（Robust）

- [ ] 原生语义优先（button/a/summary/table），ARIA 只补缺口
- [ ] `aria-live=polite` 用于异步状态播报，不滥用 assertive
- [ ] 弹层关闭后 `aria-expanded`（如适用）同步
- [ ] 无 `tabindex>0`（`ui_keyboard_audit` 会告警）

## 5. 测试方法（按成本从低到高）

1. 静态：`ui_ux_audit --markdown`（hex/a11y/状态/动效指标）
2. 焦点顺序：`ui_keyboard_audit --markdown`（源码顺序 + skip/tabindex 检查）
3. 真机 CDP（推荐）：
   - Edge `--headless=new --remote-debugging-port=9335`
   - `Input.dispatchKeyEvent` 实测 Tab/Shift+Tab/Ctrl+K/Esc
   - 断言 `document.activeElement`；Palette Esc 后焦点应返回打开前元素
4. 视觉基线：`ui_visual_baseline.py`（桌面 1440 + 移动 375 + sha256 manifest）
5. 人工 3 分钟：键盘走一遍、375px 看一下、读屏听关键状态（可选）

## 6. 已知基线（2026-10-27 OS 入口）

- Tab 第 1 项 = skip link「跳到主要内容」；
- 命令面板 Ctrl+K 打开、Esc 关闭后焦点回到触发前按钮；
- 375px 截图可滚动，卡片纵向堆叠；
- 无 `tabindex>0`，无硬编码 hex（页面级）。

## 7. 验收标准

- 新增/修改页面的 PR：清单 0-2 全过、UI 审计无 warn；A11y 有回归（工具或人工）记录；
- 命令面板/密度等新组件：先在 OS 入口灰度，再推广到其他页面。
