### 6.2 事实状态词法标注（M2/M3，FS 判据机械部分）

- **标注附命中词与原句 quote，必须人工复核后才可引用**；词法≠事实裁定。
- 工具：`news_collector/fact_type_annotate.py`（只读源 → `data/fact_type/{src}/{code6}.jsonl`，标注粒度 = ref_id × field）。

### 6.6 独立性判据（结合方案 C3，三角验证真伪）
- **底线**：≥2 独立源印证；单源仅作线索，不支撑结论。
- **独立性定义**：来源渠道相互独立、且非同一原始通稿的链式转引——**同一篇通稿被 N 家媒体转引 ≠ N 个独立源**。
- **结构性独立（A 股可用）**：官方渠道（irm/sse 公司回复）与民间渠道（淘股吧/雪球帖）讲同一事实，属渠道结构性独立，可信度≥2；两源文案雷同 / 明显同稿 = 转引嫌疑，不计印证。
- **强独立范式**：公司自述（互动易）与第三方数据（龙虎榜、机构研报、交易所公告）互证，属强独立——引用时优先采用此组合。
- 落点：对账底表 `codes[*].official/rumor` 两端齐备时，引用前须先判两端是否结构性独立，再决定是否计印证。

### 6.7 激励字段定义（结合方案 C4，CRAAP Purpose 维度）
- 评级对象为**源的倾向性**（在哪类说法上有偏），非整体可信度——识别"该源在哪类说法上有偏"，不整体否定该源。
- 六源激励基线：

| 源 | 倾向性（基线，待 track record 校准） |
|---|---|
| 交易所公告 / irm·sse 公司回复 | 利好 / 中性锚定（自述自身，乐观偏向） |
| 带货 KOL（雪球 / 淘股吧） | 持仓相关偏向（多持多吹 / 空仓踩） |
| 空方账号 | 利空偏向 |
| 新闻流 / 机构研报 | 机构立场（买方研报买入评级占比系统性偏差） |
| 互动易无回复提问 | 多为散户关切，中性偏疑 |

- 用法：引用任何源的说法时**双向披露其倾向**（"据公司互动易回复，偏利好自述"），不隐去不夸大。track record 校准档案属 L3 待批。

### 6.8 回音室须知（结合方案 C5，SOCMINT 偏差）
- **单一伪影不支撑结论**：一条帖 / 一个账号的说法不足以成立任何判断。
- **回音室偏差**：社区内共识 ≠ 整体市场情绪——公开社区用户存在自我选择偏差，散户情绪指数使用时须注明"样本来自公开社区，不代表全市场"。
- **协调 / 水军嫌疑标记**：多账号同时段同文案 = 协调行为异常标记（仅标异常，不裁事实）；本席在采集侧记录发帖量异常，不判定动机。
- 要求：任何散户情绪读数须带"样本来源 + 偏差声明"两列，否则不对外。

### 6.9 评级基线表（结合方案 C2，NATO Admiralty Code）
- **二维独立评估**：信源可靠性（A–F）× 信息可信度（1–6），两者**独立**评估——高可靠源（A）也会出错，低可靠源（F）也可能报对，**不可由源可靠性直接推断信息真假**。
- 六源**信源可靠性基线**（本席预置，待 L3 track record 校准）：

| 源 | 可靠性 | 理由 |
|---|---|---|
| 交易所公告 | A（完全可靠） | 交易所背书，法定披露 |
| irm / sse 公司回复 | A（完全可靠） | 公司在交易所平台官方背书 |
| 新闻流（权威媒体） | B（通常可靠） | 通常可靠，偶发转引失真 |
| 机构研报原文 | B/C | 通常可靠，带买方立场 |
| 雪球认证 / 大 V | C/D | 可能可靠，激励需标 |
| 淘股吧 / 股吧普通帖 | E/F | 无法可靠评估 |
| 投资者无回复提问 | F（无法评估） | 仅作参照，不计印证 |

- 信息可信度（1=已确认…6=无法评估）由分析岗在对账底表 `admiralty_code` 栏按格式填（如 `B2` = 源可靠 B、信息很可能真）；**本席预留占位，保持 null，不填任何结论**（见 6.3 边界）。

### 6.10 PIR 登记机制（结合方案 C1，情报周期/优先情报需求）
- **PIR（优先情报需求）先于采集**：决定"采什么、从哪采、看什么指示器"；PIR 内容（情报需求本身）归情报主管（马超）/ 老田定义，本席只登记与维护**覆盖状态**，不越界定义需求。
- 登记表：`docs/PIR_register.md`（字段：PIR编号 / 情报需求 / 关联标的 / 对应源 / 指示器关键词 / 覆盖状态 / 责任人 / 登记日）。
- 覆盖状态三档：未覆盖 / 部分覆盖 / 已覆盖（依据现有 OSINT 桥与采集队列判定）；标"未覆盖"即上报，**不擅自扩源**（扩源归上级裁定）。
