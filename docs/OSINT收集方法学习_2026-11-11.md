## 二、提炼一：情报周期与收集的方向性（PIR / 收集矩阵）

六阶段：Direction（PIR/RFI）→ Collection → Processing → Analysis → Dissemination → Feedback。核心洞见：

1. **PIR 把 OSINT 宇宙过滤为可行动信源**——先有问题，再收集；「没有方向的收集最终囤积无人使用的指标」。
2. **收集管理框架（CMF）**：PIR ↔ 源 ↔ 指示器 ↔ 覆盖状态的映射，缺口显式管理。
3. **好的 PIR = 具体问题 + 责任人 + 关联决策**；宽泛问题稀释收集力并引入确认偏误。
4. **Feedback 闭环**：情报使用效果回流，修订 PIR。

**本席映射（C1）**：现有采集是「标的驱动」（策略出票→队列→采集），方向被动跟随策略产出；COLLECT_REGISTER 管「谁在采」（确权），target_queue 管「采哪些」（覆盖），**缺 PIR↔源↔指示器映射层**。PIR 内容归上级定义（角色边界），本席可建登记表结构并维护覆盖状态。

## 三、提炼二：Admiralty Code（信源×信息二维动态评级）

NATO 标准（始于二战英国海军部）：每条情报标两个**独立**评级——

| 信源可靠性（A-F） | 信息可信度（1-6） |
|---|---|
| A 完全可靠（无假称性/可信度/胜任力疑点，有完全可靠历史） | 1 经其他独立来源证实 |
| B 通常可靠（偶有疑点，多数时候有效） | 2 大概率为真（未证实但逻辑自洽、与他源一致） |
| C 较可靠（有疑点，过去提供过有效信息） | 3 可能为真（合理，与部分他源一致） |
| D 通常不可靠（疑点大，但有过有效信息） | 4 存疑（可能但不合逻辑，无他源） |
| E 不可靠（历史无效信息） | 5 不太可能（与他源矛盾） |
| F 无法评级（无历史依据） | 6 无法判断 |

三条元判据（源自条令与实证研究）：
1. **两维独立评估**——高可靠源也会报错（报「可靠源 E5」）；不可靠源也可能报对。禁用源可靠性影响可信度判断。
2. **评级是分析性判断，非精确测量**（与 R12 自省模板同源）。
3. 实证：评估者常把六档压缩成三组使用（好/中/坏），语义模糊是固有缺陷——**评级必须附理由**。

**本席映射（C2，最直接接口）**：R12 的三层信源是**源类型静态分层**；Admiralty 是**源+单条信息动态评级**，正好填上 rumor_verification.py 核验结论栏「留空」的格式缺口——**留空≠无格式**：核验岗填写时按 Admiralty 码（如 `B2`），本席预置源可靠性基线（irm/sse 官方回复=A、新闻=B/C、xq/tgb=C-F 按作者历史）。

## 四、提炼三：三角验证与独立性

1. **≥2 个独立来源**；独立性 = 真正不同 origin，**同一篇通稿被 N 家转引 ≠ N 个独立源**。
2. **跨语言/跨市场印证强于同语言转引**。
3. **Provenance 追溯**：引用前追到最初报道者及其证据基础。

**本席映射（C3）**：rumor_verification 目前「两端齐备」只数条数，未判独立性。升级判据：互动易回复（官方渠道）与淘股吧帖（民间渠道）讲同一事实 → 结构性独立，可信度≥2；若两源文案高度雷同 → 转引嫌疑，不计独立印证。同文检测是词法可做项。

## 五、提炼四：信源档案与激励分析

CRAAP 五维（Currency 时效 / Relevance 相关 / Authority 权威 / Accuracy 准确 / Purpose 目的）中，**Purpose/激励分析**在 A 股语境最强：

- 公司自述（互动易回复中"订单饱满/供不发求"）→ 利好倾向
- 空方发帖 → 利空倾向；带货型 KOL → 持仓倾向
- 激励分析**不是**整体否定信源，而是识别「该源在哪类说法上可靠、哪类说法上有偏」

**本席映射（C4）**：六源建 source_profile 档案（track record 过往准确率、准入层级、利益相关类型三字段）。纯结构字段，个体研判归分析岗。

## 六、提炼五：SOCMINT 异动与协调行为识别

1. **异动信号**：发帖量异常激增、情感突变、关键词共现异常 = 事件前兆；**单一伪影（one post/one photo）不支撑结论**——最常见失败模式。
2. **协调不实行为（CIB）识别靠网络行为而非内容**：同时段多账号近同文案、账号新建聚集、发帖节奏非人类频率。
3. **认知偏差七类**（EU INTCEN）：确认偏误/近因偏误/可得性偏误/回音室（把社区内共识当整体情绪——**正是散户情绪指数的最大陷阱**）/机器人误判/文化误读等。

**本席映射（C5）**：情绪指数读数可加发帖量 z-score 异动字段（纯统计附原句）；tgb 多账号同时段同文案可做协调嫌疑标记（元数据级）。**止于标记，定性归分析岗**——「回音室」判据直接写入情绪数据的使用须知。

## 七、提炼六：存证纪律（provenance / 上下文保全）

范本要求：URL + 平台 + 账号 + 双时间戳（发布时/采集时）+ 周边对话；无溯源的截图 = 弱证据；先存证后分析（平台可能删帖抹证据）。

**本席映射（C6，本轮学习发现的实证缺口）**：抽查 `data/xq_timeline/000001.jsonl` 记录字段 = `{id, code, symbol, ts, title, text}`——**没有原文 URL**；tgb 有 link、irm/sse 有 id 可回查，xq 溯源链断。修复属采集器 schema 变更（需先确认雪球接口响应含 url 数据），列 L3 待批。

## 十、一句话总结

R12 解决「数据算什么」（证据分层+状态标注），本次收集方法解决「**往哪采、采到什么算数**」：**PIR 给方向、Admiralty 给评级、独立性判据给印证规则、存证纪律给溯源链**——四件拼上后，从「标的驱动的被动采集」升级为「需求驱动的收集管理」，且每一步都不越研判边界。
