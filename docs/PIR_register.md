# PIR 登记表（优先情报需求 / Priority Intelligence Requirements）

> 依据：`docs/OSINT收集方法学习_2026-11-11.md`（C1 情报周期/PIR、收集矩阵），L3 落地（2026-11-11 老田批准）。
> 本表由 OSINT1（马良）维护**覆盖状态**；PIR 内容（情报需求本身）由情报主管（马超）/ 老田定义。

## 机制
- **PIR = 需要持续用开源情报回答的优先问题**；先于采集，决定"采什么、从哪采、看什么指示器"。
- 本席职责：登记 PIR、映射其到源与采集队列、维护覆盖状态；**不定义 PIR 内容**（归情报主管 / 决策层，越界问题不碰）。
- 覆盖状态三档：**未覆盖 / 部分覆盖 / 已覆盖**（依据现有 OSINT 桥与采集队列判定）。
- 未来可扩展：PIR ↔ code 映射盘点（在 `strategy_picks_summary.py` 之上叠加，纯只读）。

- **irm/sse 公司回复**：覆盖"公司自述类"PIR（计划/投产措辞）→ 已有 OSINT 桥（k_stock / 侯风 / 两池 / 缠论队列驱动）
