## 四、可落码判据（机审表述，参照 m0/m3 drill 风格转写，本单零代码）

1. **断言式判据**：每场景判据写成断言形态，任一断言失败 → 演练进程非零退出（closed on failure）；全过 → 输出 DRILL PASS 摘要（场景×5、每场景一行关键计数）；
2. **计数器式判据**（全部显式可计数，沿 [M1单] W10 铁律）：
   - execute 调用计数 = 0；
   - 真实通道外发计数 = 0（HTTP/飞书/webhook 合并计）；
   - 账本写入差异数 = 0；data/ 写入差异数 = 0；预算流水新增科目数 = 0；新增跑批触发数 = 0；
   - 负样例：构造数 = 拒绝留痕数（零漏放、零多拦）；
   - 旗标：置 1 → 清 0 全程留痕对齐；
3. **快照对比式判据**：演练前后对执行面四项（跑批计划 / 推送配置 / 预算流水 / data/ 目录）各取快照，逐项 diff 为空方判 PASS；
4. **留痕式判据**：S1/S2/S3 产出留痕逐条含时间戳（动态）、场景号、输入引用、动作名、依据引用，机器可解析；
5. **隔离判据**：演练产出物只落演练专属临时目录，演练收口后目录清单与产出三件清单一一对应，零散落。
