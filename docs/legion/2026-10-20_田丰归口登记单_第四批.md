## 附六：错误码更正（2026-10-20，lead 权威核定）

- **更正**：本单附三中「winerror **183**」**记错**。权威核定：`ctypes.WinError(32)` = 「另一个程序正在使用此文件，进程无法访问」= `ERROR_SHARING_VIOLATION`；`WinError(183)` = 「当文件已存在时，无法创建该文件」= `ERROR_ALREADY_EXISTS`，**与本根因无关**。正确值为 **32**。
- **错因**：在 Python `except OSError` 块内调用 `ctypes.get_last_error()` —— CPython 异常展开过程中已多次调用 Win32 API，**线程 last-error 早已被覆盖**，读到的是残留值。
- **对结论的影响：无。** 32 与误记的 183 **同属「非 5」**，故「排除 ACL/目录只读（5 = ACCESS_DENIED）」的论证不受影响；「非并发、非只读、非 CWD」的排除结论均维持。
- **警示（工位自陈，已采纳）**：为核定此事，连写错三版脚本、前两版都**自信地输出「意外成功」**——若未顺手核对 Python 层明明抛了 `PermissionError`，就会把「无冲突」的反向结论写进文档。**这比不知道更危险：它看起来像个干净的实验结果。** 判据：**Win32 层与 Python 层表现矛盾时，先怀疑自己的比较逻辑，别先怀疑现象。**
