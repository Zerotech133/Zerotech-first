## W27 灰度定义与双轨对照机制

- **目标**：把 [M3单] W21 的「预演/灰度双轨对照、结论不一致即灰度异常信号」从概念种子落成可派工的机制定义——灰度期是什么、双轨各是什么、对照什么、异常信号怎么判定，并锁定「灰度期执行面行为与灰度前完全一致」的纯观测红线。
- **灰度定义**：**灰度 = 同一批 Verdict 决策点上，裁决规则集的新旧两版并行出裁决、只记录不阻塞**。同一决策点指同一输入件（同一 ResearchReport / 策略建议 id 的风控复评请求），A/B 两轨各自独立出裁决，互不读取对方结论。
- **双轨形态**：

```
同一 Verdict 决策点（同一输入件）
  ├─ A 轨（基线轨）：RiskGuard 预演版 = 军团侧纸面规则集 rule-set v1
  │    （[M3单] W17 版本化基线）→ 产出当前生效 Verdict（唯一生效件）
  └─ B 轨（灰度轨）：灰度版 = 目标规则集 rule-set v2 候选
       → 只出裁决记录，落灰度对照账本，零输出到生效链路
```

- **机制设计点**：
  1. **只记录不阻塞**：B 轨裁决不产 Verdict 件、不进五段链路任何生效环节（不开单、不改 stance、不改 risk_passed）——与铁律②影子语义同构：**B 轨只有观测权**；
  2. **对照粒度**：逐决策点 diff（判定维度与差异分级见 W29 统计口径），落灰度对照账本（格式沿用 [M3单] W21 预留的预演/灰度双轨对照表格式，机器可解析）；
  3. **「结论不一致即灰度异常信号」落地**：差异率按 W29 口径滚动统计，超熔断阈值即触发熔断回退（W29）——异常信号是**灰度机制的输出**，不是 B 轨对 A 轨的纠正输入，灰度期内 B 轨结论永不反灌 A 轨；
  4. **纯观测红线（本 W 核心验收面）**：灰度开关 on 期间，执行面行为与灰度前**逐项一致**——生效 Verdict 序列同输入同输出、工单状态机轨迹无新增分支、预算流水无新增科目。灰度不是「部分生效」，是「全生效照旧 + 影子全量对照」。
- **交付物**：灰度定义与双轨机制稿（本 W 段落即稿）+ A/B 轨责任方与权限锚点对照表（谁产出/谁消费/各自权限边界）+ 灰度对照账本 schema（字段表：决策点 id、输入件引用、A/B 裁决、diff 结果、时间戳）。
- **验收**：双轨定义逐条有权限锚点（B 轨观测权表述与铁律②原文无冲突）；「纯观测红线」四项逐项可机审表述；与 [M3单] W21 机制种子无语义漂移（以 W21 原文三点逐点对表）。
- **依赖**：[M3单] W17（rule-set v1 版本化基线）、W21（双轨对照概念与对照表格式）；[M0清单] 铁律②③。
- **风险**：A/B 两轨对同一输入件出裁决时可能因共享中间件产生写竞争——设计上 B 轨独立落账本文件（不写 A 轨任何存储），预研期两轨均纸面推演，无并发面。
- **规模**：0.5 天。

## W29 灰度开关与熔断

- **目标**：定灰度开关的配置形态、差异率统计口径（哪些差异算不一致）与熔断阈值/回退动作——使「异常信号→熔断→回退→零残留」成为一次可演练的闭环动作。
- **开关形态（两态单开关 + 无生效开关原则）**：
  1. **配置位**：灰度开关 `grayscale = off | on`，默认 off。off = 纯预演（M3 现状，仅 A 轨）；on = 双轨并行（A 轨生效照旧 + B 轨只记录）；
  2. **只读观测开关**：差异率统计与对照账本查询属只读观测面，随灰度开关 on 自动启用，独立于任何写路径，可随时只读巡检；
  3. **无生效开关原则**：**不存在**把 B 轨切为生效件的单开关——B 轨升级为生效（rule-set v2 转正）是**版本迁移过会事件**（走 W28 迁移单全条款），不是拨开关。此原则堵死「灰度期顺手切生效」的旁路。
- **差异率统计口径（三级分级）**：

| 级别 | 判定 | 计入熔断 |
|---|---|---|
| L1 事实级 | stance 不一致（approve / reject / hold 任互异） | **计入**（最重信号） |
| L2 结论级 | risk_passed 不一致（含显式 false vs 缺省拒口径差，对表 [M0清单] 第四项显式 bool 语义） | **计入** |
| L3 理由域级 | 结论同但命中规则集不同 / 理由域措辞差异 | 只观察留痕，**不计入**熔断（灰度期 L3 高发属预期，是迁移价值所在） |

  - **差异率** = 计入级（L1+L2）差异数 / 同期决策点总数，滚动窗口统计（窗口长度实装排期时拍板，预研建议 5 决策点起步小窗）。
- **熔断阈值与回退动作**：
  1. **触发条件（两选一即熔断）**：① 滚动窗口差异率 ≥ 熔断阈值（预研建议档：≥20% 或窗口内 ≥2 件计入级差异，孰先触发孰算；正式值实装排期过会拍板）；② **任一 L1 stance 反向对**（approve vs reject 互斥级不一致）无差别熔断——事实级反向不允许用比率稀释；
  2. **回退动作**：关灰度开关（on→off）→ 立即回纯预演态（B 轨停止出裁决）；A 轨全程未受灰度影响，回退即回到灰度前状态；
  3. **零残留定义（可机审）**：回退后 grep 生效侧（生效 Verdict 序列 / 工单状态机轨迹 / 预算流水）灰度期新增 B 轨痕迹 = 0；已落对照账本的 B 轨记录**保留不删**（append-only 审计件，熔断史即证据链）；
  4. **复位纪律**：熔断后重启灰度须过会授权（排期单另立），不复位不重启。
- **交付物**：灰度开关与熔断设计稿（本 W 段落即稿）+ 开关配置位声明（字段/默认值/权限：开关拨动权归风控部）+ 差异分级判定清单（L1/L2/L3 逐条可机审）+ 熔断动作卡（触发→关开关→验零残留→复位四步）。
- **验收**：三级分级对全部 diff 形态穷尽归类（无未分级态）；「无生效开关原则」表述与铁律②③无冲突；零残留四步逐项可机审；熔断阈值建议档与 L1 反向无差别条款自洽（后者不依赖前者即可触发）。
- **依赖**：W27（双轨机制与对照账本 schema）；[M0清单] 第四项（risk_passed 显式 bool 口径）。
