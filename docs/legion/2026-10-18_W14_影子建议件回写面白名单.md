### 5.2 流转状态机

```

    │                             └──(人工否决)──> rejected
    └──(人工直接否决)──────────────────────────────> rejected
```

| 迁移 | 允许 | 前置条件 | 落痕 |
|---|---|---|---|
| `candidate → reviewed` | 是 | 人工初审（完整性 + 来源可追溯） | `review_log.jsonl` 一行 |

| `reviewed → rejected` | 是 | 人工否决理由非空 | 同上 |
| `candidate → adopted` | **禁止（直跳即 FAIL）** | — | — |
| `adopted → candidate` | 禁止（重开须新 `cand_id`，旧件保号不动） | — | — |

### 5.3 人工审核闸（三道硬门，全部可机审）

1. **人是唯一写者**：`review_log.jsonl` 的 `reviewer` 必须是人工标识（`laotian` / 军师府人工 token），**无任何自动 approve 路径**；`reviewer` 缺失或为 agent 标识即 FAIL。
2. **对照期不可跳过**：`reviewed → adopted` 必须携带 `shadow_days >= 20` 与 `evidence_ref`，缺一即拒（承接 org.json `"权重草案 draft≠adopt（影子对照≥20交易日后人工凭据）"`）。
3. **流水只增不改**：两个 `.jsonl` 一律 append-only；W16 校验行数单调不减、历史行内容 hash 不变（改写历史 = FAIL）。
