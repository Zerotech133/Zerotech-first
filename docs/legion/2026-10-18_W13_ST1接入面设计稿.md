## 2. 映射表：ST1 判读件字段 → IntelItem 字段

### 2.1 构件与函数签名（预研稿，不落码）

| 项 | 设计 |
|---|---|
| 模块 | 复用 W12 适配层 `digital-legion/adapters/shadow_intel.py`，**新增 ST1 分支**，不新建第二个适配模块 |
| 常量 | `SOURCE_ST1 = "st1-chan-analysis"`；`ID_PREFIX_ST1 = "INTEL-SH-ST1-"`；`SCHEMA_ST1_UNFROZEN = "st1.v0-unfrozen"` |
| 入口 | `st1_observation_to_intel(row: dict, *, trade_date: str, seq: int) -> IntelItem` |
| 分派 | `shadow_row_to_intel()` 按 `row["schema_version"]` 前缀分派：`st1.*` → ST1 分支；`m5.*` → W12 分支。格式演进只加分支，不改既有分支 |
| 校验 | `validate_st1_intel(item: IntelItem) -> list[str]`，与 `validate_shadow_intel()` 并列；`validate_shadow_intel()` 内部按 `source` 二次分派（`st1-chan-analysis` → ST1 专项） |
| 输入路径 | `dept/invest/observation/<YYYY-MM-DD>/chan_<symbol>_<seq>.json`（ST1 写权限内，§4） |

### 2.2 宽进原则（本稿核心约定）

1. **映射函数永不抛异常**：任一字段缺失/类型不符，一律置空值或契约默认值，并追加一条 `mapping_warnings`（不阻断）。
2. **错误只在一处暴露**：全部错误由 `IntelItem.validate()` + `validate_st1_intel()` 返回的错误列表统一收口；调用侧据此判"入简报 / 入隔离区"，不做静默丢弃。
3. **别名多路命中**：同一语义允许多个候选键，按表内顺序取首个非空值。
4. **未知键透传**：判读件里本表未列的键，整体收进 `payload.chan["extras"]`（仅限标量/短列表），不丢信息也不污染契约字段。

## 3. 简报合流段 schema 增补稿（供 M1 W7 实装时引用）

### 3.1 与 W7 既有结构的共存规则

现有 `brief.json`（M1 已落盘形态）顶层键：`date` / `generated_at` / `source` / `status_counts` / `items`。本稿**不改动其中任何既有键的语义与取值方式**，只做两处追加：

| 增补点 | 位置 | 内容 | 与 W7 的关系 |
|---|---|---|---|
| A. 统计段 | 顶层新增 `stats` 对象，内含 `st1_item_count` | 四计数同容器、同为 `int`，机器解析口径一致 | W7 要求"头部三项统计可机器解析"，本稿把三项归口到 `stats`，并追加第四项；`status_counts` 保持原义不动（它统计心跳自产条目的校验状态，与 `stats.item_count` 不互相推导，验收脚本各读各的） |
| B. 观察段 | 总览条目 `items[0].payload.st1_observation` | ST1 段引用 + 要点摘录 | 与同层 `payload.legacy_shadow`（W12 段）**并列不嵌套**，两键互不引用、互不包含 |

**分列不混排的三条硬约束（可机审）**：

1. `payload.legacy_shadow` 内不得出现 ST1 的 `observation_ref` / `chan` / `st1_*` 任何键；`payload.st1_observation` 内不得出现影子链的 `run_id` / `shadow_status` / `degraded`（影子口径）任何键。
2. 两段各自计数、各自留空：当日无影子行 → `legacy_shadow.rows=0`；当日无 ST1 判读件 → `st1_observation.count=0`。**零条也是合法结构**（与 W15"零影子行不视为失败"同口径），不得用 `null` 代替空结构。
3. ST1 判读件本体只进 `items[]`（`source="st1-chan-analysis"`），**不得**再复制一份进 `legacy_shadow`；`payload.st1_observation` 只存 `st1_item_ids` 指针与 ≤5 条要点摘录。

### 3.3 字段口径表

| 字段 | 类型 | 口径 | 空值语义 |
|---|---|---|---|
| `stats.item_count` | int | `len(items)`（含影子件与心跳自产件） | `0` = 当日零条目（应视为异常，非降级） |
| `stats.degraded_count` | int | 影子链 + ST1 合计降级件数（`payload.degraded=true` 或影子行 degraded） | `0` = 无降级 |
| `stats.shadow_row_count` | int | 前日影子账本被引用行数，等于 `legacy_shadow.rows` | `0` = 当日无影子行，合法 |
| `stats.st1_item_count` | int | 本简报内 `source="st1-chan-analysis"` 条目数，等于 `st1_observation.count` | `0` = 当日无 ST1 判读件，合法 |

| `st1_observation.model` | str | 当日 ST1 主用档：`glm/glm-5.3` 或 `qwen3.5:9b`；混合时取降级档并置 `degraded≥1` | 无条目时 `""` |

| `st1_observation.points` | list[str] | ≤5 条要点摘录，单条 ≤120 字 | `[]` |

### 3.4 G1~G4 四闸门在 ST1 分支的落位（与 W12 共用机制，逐条对应）
