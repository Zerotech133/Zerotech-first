## 〇、一句话

第五辑把「全市场信息传导时钟」这条主线打掉了——**不是做不完，是数据不存在**。
所以这一期的动作不是"补时间维度"，而是**换维度**：席位（B）与沉睡表（D）转主攻，时间维度降级成窄口径的"媒体滞后时钟"，
并且所有关联结论从今天起必须带**同日同池对照**（判例 #38）。

## 三、任务分解（J-01 ~ J-06）

### J-01 媒体滞后时钟 v0（A 案降级版）

- **目标**：给出"媒体快讯相对价格异动的到达时延分布"，**明确不声称信息传导**。
- **输入**：`news.db`（只读）、本地 `stk_mins` / 分钟快照。
- **四道过滤（缺一不可）**：① `ts_kind == intraday`；② 剔除行情播报标题（正则已实测 23.7%）；③ 必须能映射到标的；④ 剔除与自身标的涨跌幅同句复述的行。
- **产出**：`docs/JEV_媒体滞后时钟_v0_实证.md` + 可复现脚本（落 `tools/`，只读、无网络）。
- **最小样本闸**：过滤后 **n < 200 → 直接判"不可建"**，出收口报告，不硬凑。
- **证伪条件**：n≥200 但分布无结构（p10–p90 跨度 < 5 分钟）→ 说明快讯与异动同步，时延无信息量，本项关闭。

### J-02 席位分层与族群观察 v1（B 案）

- **目标**：把"谁在买"做成可查询的三层结构，**下钻止于营业部**。
- **数据事实**（8 日实测）：1,487 行 / 128 个 `hm_orgs` / 54 个 `hm_name`；机构专用占 22.5%（334 行），深股通 130、沪股通 99；单席日均出现 **1.45 次**。
- **三层设计**：
  - **L0 身份三分**：机构（机构专用）/ 北向（沪深股通）/ 游资（其余）。这一层样本充足，可直接出统计。
  - **L1 系别**：地理系（温州帮 95、南京帮、苏南帮、佛山系、杭州帮…）与行为类（量化基金 215、量化打板 111、炒新一族、低位挖掘）。**这类是市场统称，不是自然人**，可用。
  - **L2 营业部**：`hm_orgs` 全名（如"开源证券西安西大街"78 次、"东方财富证券拉萨金融城南环路"68 次）。**这是下钻底线**。
- **自然人绰号处置**：`hm_name` 里 `章盟主`(67) / `作手新一`(12) / `方新侠`(7) / `赵老哥`(4) / `王海祥`(2) 等属自然人指向。
  默认方案：**映射为 `PSN_<hash6>`，参与计数、不展示原名**；映射表 `config/seat_alias.local.json` 本地保存、不入公开面。
- **产出**：`portal/jev_seat.py`（只读快照的纯编译器）+ `/api/jev/seat` 只读接口 + 一份 8 日回看报表。
- **证伪条件**：L2 层若 **80% 的营业部在 8 日内只出现 1 次**（长尾无重复），则"席位族群"不成立，只保留 L0/L1，不再投入图谱。

### J-03 涨停事件交叉卡 v1（原 T-191，本期主交付）

- **目标**：一个涨停事件 → 自动拼出一张卡，四维证据齐全，**无数据的维显式写 `unavailable`**，不许省略。
- **四维**：
  | 维 | 取数 | 时点精度 |
  |---|---|---|
  | 时间 | 分钟首次异动 / 首封时刻 / 打开次数 | 分钟级（`stk_mins`） |
  | 资金 | 主力净买（大单+特大单，万元）、divergence 标记 | 收盘终值 |
  | 席位 | L0 三分净买 + L1 系别 | **T+1 补齐**（龙虎榜次日早间才全） |
  | 叙事 | 当日公告（日期级）、研报评级、快讯条数（含"行情播报"标记） | 日期级 + 分钟级混装，必须标 |
- **硬设计**：**席位维天然滞后一天**。当日卡只有三维，卡面必须写 `seat: pending(T+1)`；次日回填后重算。不许用前一日席位冒充当日。
- **产出**：`portal/jev_cross.py` + `/api/jev/cross/<code>/<day>` + 单卡 HTML 片段。
- **不调 LLM**：卡面由规则拼装，不消耗云端额度；需要一句话摘要时走本地 9b，不落结论、不写"建议买入"类字样。
- **DoD**：对 11-11 全部涨停股批量出卡，**≥3 维有值率 ≥ 70%**；每维都带来源与精度标签。
- **证伪条件**：齐全率 < 40% → 退为"两维卡"（时间+资金），席位维单列为附表。

### J-04 EEI 反查沉睡表（D 案，本期只出需求单）

- **做法**：先列"研判要回答的问题"（EEI），再反查该用哪张表——不是先看 181 张表里有什么。
- **六条 EEI 与对应表**：
  | EEI | 问题 | 表 | 现状 |
  |---|---|---|---|
  | E1 | 谁在买 | `ts_hm_detail` / `ts_top_list` | 已接 8 日 |
  | E2 | 几进几（梯队位置） | `ts_limit_step`（6,761 行，现时到 11-12） | **未接**，可直接接 |
  | E3 | 属哪个题材、题材热度 | `ts_kpl_concept_cons`（主表停更 2024-11-17） | 部分接 |
  | E4 | 事件原文是什么 | `stock_news`（33 万条带全文）/ `ts_anns_d`（573 万） | 未接 |
  | E5 | 资金结构（谁在接） | `ts_moneyflow` | 已接 |
  | E6 | 公司行为（解禁/质押/分红） | 待探 | 未接 |
- **产出**：`docs/JEV_EEI需求单_v1.md` —— 每条写清字段、频率、用途、**归属采集工位**。
- **边界**：本项**不写采集器**。11-08 裁定：JEV 是数据使用方，"怎么拿到"是采集工位的事。

### J-05 叙事–资金背离（C 案，阻塞挂起）

- **阻塞原因**：叙事热度必须用 UGC 时间戳才成立，而 8 天只有 **12 条** UGC。
- **本期动作**：只出需求单一行（给采集工位：UGC 时间戳扩量），不排工、不做替代方案。
- **不许**：用快讯条数冒充叙事热度（那 23.7% 是行情播报，等于用价格解释价格）。

### J-06 案例库验证器 v1（P3 骨架）

- **目标**：把"lift 思维"换成 `pattern → 演化路径分布`，且**内置同日同池对照**。
- **最小可用形态**：给定 pattern（如"主力净买 + 全档净流出 + 龙虎榜散户席位净买"），输出 8 日样本内命中只数、后续 1/3/5 日收益分布、以及**随机同池对照的同一分布**。
- **证伪条件**：命中样本 < 30 → 只报"样本不足"，不出概率。

## 五、判定闸（11-20）

**通过（推演引擎仍在轨）**，四条同时满足：
1. 交叉卡在 ≥3 个真实交易日产出，**≥3 维有值率 ≥ 70%**；
2. 席位维覆盖当日涨停股 **≥ 50%**（11-11 实测 hm 74 / top 75，量级支持）；
3. 媒体滞后时钟出可复现分布（n / p50 / p90），且标题与正文均注明"仅媒体快讯，不含公告"；
4. EEI 需求单里**至少 1 张表**进入采集排期。

**不通过（必须承认，不许改口径抢救）**：
1. 齐全率 < 40% → 数据不足以支撑交叉，退两维；
2. 席位覆盖 < 20% → 席位维不成立；
3. 媒体滞后时钟过滤后 n < 200 → 判"不可建"，本项关闭并写进台账"测不了"（与"没发现"分开记，#38 同族）。
