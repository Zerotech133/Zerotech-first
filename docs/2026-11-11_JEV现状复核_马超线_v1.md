## 四、可用性实测（选股池 614 只，近 30 天）

```
已判 112,846 / 能落股票 46,384 (41.1%) / 落池内 7,799
池内 609 只有判读 = 99.2%
每票条数: 中位 11 / p75 19 / p90 31 / 最大 221
≥5 条 520 只(84.7%)  ≥10 条 343 只(55.9%)  ≥20 条 152 只(24.8%)
bias(池内): bull 47.7% / bear 15.3% / neutral 37.0%
有 bear 判读的票 423 只 (68.9%)
```

**覆盖不是问题，单票样本厚度才是问题。** bear 只占 15.3%，乘上中位 11 条 ≈ **每票 bear 中位
仅 1.7 条**。加上第二节的 conf 无区分度，**单条 bear 判读无法支撑「这只票要跌」的结论**。

## 五、结论：JEV 能进选股，但只能进两个位置

| 位置 | 能不能用 | 依据 |
|---|---|---|
| 单票方向信号 | **不能** | 每票 bear 中位 1.7 条；conf 无区分度 |
| 单票排除（一票否决） | **不能** | 误杀率 42%（bear 准确率 0.580 的反面） |
| **组级方向倾向**（联动组/板块） | **能** | 聚合后样本回到千级，JEV 自身的 54.2% 就是这个口径 |
| **池级风险温度** | **能** | bear 占比 15.3%，可作为「今天消息面偏空」的度量 |

即：JEV 与因子、图谱结合时，提供的是**组级的事件方向与事件类型**，
不是第 18 个逐股因子。这正好落在上一轮定的「联动组」产物上。

## 七、建议

1. 写 `jev_bridge.py`（与 `intel_bridge.py` 同构，只读），输出**组级**结构：
   `{group_key, n_judged, bear_share, event_mix, worst_type, as_of}`。
   明确不接受 `code` 单票查询，避免误用。
2. 接入点只在「联动组」判定里当一票，不给权重分。
3. 用 `policy` / `supply` 两类时一律丢弃（已标 low_signal），不要"折中降权"。
4. 报 JEV edge 必须带基线（现 0.501）。单独说 54.2% 会让人误以为对 50% 的胜率。
