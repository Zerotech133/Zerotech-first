# M0 事实源与适配器盘点

- 日期：2026-10-17
- 范围：老田个人 AI 组一次成型基座
- 目的：冻结 canonical writer、识别重复状态源，禁止迁移期双写
- 结论：当前可进入 M0 适配器阶段；暂不进入破坏式迁移或新增业务 Agent

## 一、总原则

```text
一个对象只能有一个事实写入口
旧账本先只读适配，不双写
事件账与状态快照分离
派生视图不可反写事实源
迁移必须可回放、可差异比对、可回滚
```

当前唯一任务编排权威仍为 `TaskStore / task.py`。`.worktrees/tasks.json`、门户项目 JSON、Academy、内容草稿和 flow 账本均不能升级为第二任务主控。

补充盘点：`.worktrees/tasks.json` 当前约 110,816 bytes、约 1,800 行，包含大量历史 `done/aborted/review/doing`，同一任务 ID 可能有重复或重试后缀且字段不稳定；`agent_platform/data/org/tasks/tasks_202610.jsonl` 当前仅 18 行，包含约 7 个早期开单及状态快照。两条线数量和覆盖范围不一致，因此 adapter 必须输出 `source`、`snapshot_freshness`、`coverage`，禁止按文件时间简单合并。

## 三、冲突与禁止映射

### 1. 任务状态不可直接合并

现有三套状态语义不同：

- TaskStore：`open/assigned/doing/blocked/done/rejected/cancelled`，带部门、severity、history 和闭环条件；
- `.worktrees/tasks.json`：`todo/doing/review/done/aborted`，偏研发 worktree 生命周期；
- `projects_registry.json` 子任务：`todo/doing/done`，只是项目展示进度。

禁止把 `review` 自动映射为 Task `done`，也禁止把项目进度覆盖执行状态。适配器必须同时输出 `canonical_status`、`source_status`、`mapping_confidence` 和冲突说明。

### 2. status 同名不代表同一状态机

Academy `status` 是研究阶段；项目 `phase` 是生命周期；gzh `status` 是内容审核；flow/heartbeat 的 `kind/action` 是事件。统一查询层必须保留 `source`、`source_id`、`object_type` 和 `semantic_type`。

### 3. 事件账不是任务快照

`portal.db.events`、heartbeat、push_flow、news.db runs 都是 append-only 事件或运行账。它们不能推断并覆盖 Task 当前态；`api_flow` 只能生成 read model。

## 四、Adapter 实施优先级

### P0：Task 只读统一适配器

1. 从 `agent_platform/data/org/tasks/tasks_*.jsonl` 读取当前快照。
2. 读取 `.worktrees/tasks.json`，标记 `source=devtask_registry`。
3. 建立 task_id、owner、project、source_status 映射。
4. 同一逻辑单冲突时输出告警，不静默覆盖。
5. 先做双读差异报告，禁止双写。

### P1：Academy 与 Project 适配器

1. Academy 复用 `academy_research.load_topics/summary`，保留阶段、decision、history、worker_refs。
2. 规范项目登记与门户 JSON 双读比对。
3. 选定 Project canonical 后，门户只消费投影。
4. Academy UI 仅展示，不拥有状态。

### P2：统一事件与内容适配器

事件外层最少包含：

```text
source / source_id / event_id / ts / kind / actor
object_id / object_type / trace_id / causation_id
idempotency_key / payload / provenance / event_hash
```

内容 adapter 以 `gzh/drafts/index.json` 状态为准；Markdown、HTML、图片、视频均注册为 Artifact；发布必须单独生成 Approval。

### P3：活性信号与索引

heartbeat 只进入 health/activity 视图；Qdrant、Neo4j、Portal UI 只读消费且可重建。任何索引丢失不能损坏事实源。
