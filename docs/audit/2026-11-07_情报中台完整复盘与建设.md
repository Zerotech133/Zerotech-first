## 1. 中台是什么（边界定义）

以 news.db 为数据面、runs 为流水面的**新闻/公告→JEV 判定→六域消费**流水线：

```
采集层    sina/eastmoney/wallstreetcn…（news_collector collect 5min 轮）
          xd_news/xd_notice（jev_feed 每日 21:00，v1 截断/v2 游标待切）
粗筛层    jev_prefilter（规则零算力，safe 模式，11-07 三重生效链打通）
判读层    feed 轮内 judge（夜窗让位）+ JevNight 夜批（21:50–07:05，Ollama 独占）
存储层    news.db（news 表 jev 列 JSON 判定）+ runs（5 kind 流水）
交付层    /api/jev/query（判定查询）、/api/jev/wordcloud（加权词云）、
          /api/jev/review/*（低置信复核）、MCP（tools/jev_mcp.py）、
          12 通道（见最终总结 §10）
观测层    preflight（夜窗前置校验）、cap_hit 告警、execution_watchdog、
          alert_push（飞书）——**缺漏跑哨兵（本轮补建）**
门户层    jev_wordcloud.html、jev_integration.html、review 页——
          **缺中台总览页（本轮补建）**
```
