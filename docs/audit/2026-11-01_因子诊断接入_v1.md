## 1. 结论

1. 新增只读因子准入 preflight `tools/research/factor_gate.py`：输入选股面板（CSV/JSON：
   `date,symbol,factor,forward_return`）+ 阈值，输出 **pass / warn / fail** 研究建议，
   并附 IC/ICIR/分位收益/覆盖率/多空差/换手/样本数。
2. 阈值分**硬闸（fail）**与**软闸（warn）**：硬闸不达标即 fail；软闸不达标只 warn；
   方向不一致/分位不单调等一致性检查只 warn。任何结论都是**建议**，`notes` 明示不自动晋升。
3. 缺列/空面板/坏文件 → **数据错误（CLI exit 3，stderr 说明）**，不静默 pass；
   坏行按比例计入硬闸（`max_bad_ratio`）并在 `diagnostics.bad_rows` 留样例（fail-visible）。
4. 本工具依赖 `tools/research/factor_diagnostics.py`（`WO-STRAT-FDIAG-20261101`）。该文件在本分支为
   **复制参考**（见 §7 来源与合并顺序），不重复实现诊断算法，保证与 FDIAG 口径一致。
5. 本次仅研究/准入建议；是否入池由人工按四关+影子盘+审批决定（本单不接生产）。

## 2. 调用方式

### 2.1 CLI

```powershell
# 默认阈值：pass→exit 0 / warn→1 / fail→2 / 数据错误→3
python tools/research/factor_gate.py --csv C:\Temp\fgate_demo\panel_pos.csv

# JSON 报告 + 落盘（研究报告建议放 research/reports/）
python tools/research/factor_gate.py --csv panel.csv --json --out research/reports/factor_gate_mom20_20261101.json

# 阈值 JSON 覆盖（研究口径可版本化）
python tools/research/factor_gate.py --csv panel.csv --thresholds tools/research/gate_thresholds.json --json

# JSON 面板输入（记录数组或 {"rows":[...]}）
python tools/research/factor_gate.py --panel-json panel.json --json

# CLI 单项阈值覆盖
python tools/research/factor_gate.py --csv panel.csv --min-rank-ic 0.03 --min-icir 0.3 --min-days 20
```

### 2.2 Python API

```python
from factor_gate import evaluate, load_panel, load_thresholds
df = load_panel("panel.csv")
th, warns = load_thresholds("thresholds.json")
report = evaluate(df, thresholds=th)
report["status"]   # pass | warn | fail
report["metrics"]  # rank_ic_mean/rank_icir/quantile_returns/coverage_names_mean/...
```

### 2.3 输入面板

| 列 | 要求 |
|---|---|
| `date` | 可解析日期（`YYYY-MM-DD` / Timestamp） |
| `symbol` | 证券唯一标识 |
| `factor` | 数值（工具不假设方向；负 IC 因子需调用方先取反或人工按负向因子复核） |
| `forward_return` | 数值小数（0.02=2%）；PIT/复权/停牌由调用方自备 |

CSV 用 `pd.read_csv`；JSON 支持记录数组或 `{"rows":[...]}` / `{"data":[...]}` / `{"panel":[...]}`。

## 3. 阈值语义

| 阈值键 | CLI flag | 默认 | 类型 | 语义 |
|---|---|---|---|---|
| `min_rank_ic_mean` | `--min-rank-ic` | 0.02 | **硬闸** | 日度 rank IC 均值下限（方向按输入因子原始值） |
| `min_icir` | `--min-icir` | 0.20 | **硬闸** | ICIR=IC 均值/标准差（ddof=1，不年化）下限；不可用（std=0/n<2）→ fail |
| `min_coverage` | `--min-coverage` | 20.0 | **硬闸** | 每日平均截面股票数下限（可运行最小闸） |
| `min_days` | `--min-days` | 5 | **硬闸** | 有效 IC 交易日数下限 |
| `max_bad_ratio` | `--max-bad-ratio` | 0.20 | **硬闸** | 坏行比例上限（bad_rows/rows_in） |
| `min_positive_rate` | `--min-positive-rate` | 0.55 | 软闸 | IC 正比例下限 |
| `min_quantile_spearman` | `--min-quantile-spearman` | 0.50 | 软闸 | 分位均值单调性（分位序号 vs 收益 Spearman）下限 |
| `min_long_short_ir` | `--min-long-short-ir` | 0.20 | 软闸 | 多空差 IR（mean/std）下限 |
| `max_turnover` | `--max-turnover` | 0.80 | 软闸 | top 分位成员换手率上限（交易成本风险提示） |

- 默认值是**可运行最小闸**（适合 5 日 × 30 只的研究样本冒烟）；生产复核建议用更严的
  `thresholds` JSON（例如 20 日 / 100 只 / IC≥0.03 / ICIR≥0.3），阈值版本化后随报告落盘。
- 额外**一致性检查**（仅 warn）：IC 方向与分位单调方向相反 → `direction_consistency`；
  分位收益不严格递增/递减 → `quantile_monotonic`。

## 4. 状态与退出码

| 状态 | 含义 | 退出码 |
|---|---|---|
| `pass` | 硬闸/软闸全部通过 | 0 |
| `warn` | 无硬闸失败，但软闸或一致性检查有告警 | 1 |
| `fail` | 任一硬闸失败（含指标不可用） | 2 |
| — 数据/用法错误 | 缺列/空面板/文件坏/阈值非法（fail-visible） | 3 |

> `warn`/`fail` 只是**研究建议**，不会触发任何自动动作（不写注册表、不产选股清单、不推飞书、不建单）。
> CI/研究流水线可据退出码决定是否继续人工复核，但不得把 exit 0 当「可上线」。

## 6. 不自动晋升边界（重要）

1. 本工具**只读**：输入面板/阈值文件，输出报告；除 `--out` 指定的报告外不写任何文件；
2. **不写策略注册表**（`strategy_registry` / `backtest_registry` / hypotheses.db），**不产选股清单**，
   不改 `selection_engine` / `bt_harness` / 计划任务；
3. **不新增 API/flag/常驻服务**；不联网（仅本地 pandas 读文件）；
4. `pass` 仅表示「按当前阈值未发现硬伤」，**不等于可上线**：仍需四关（PIT/统计/成本容量/影子盘）+ 人工批准；
5. 阈值是研究口径而非交易阈值：`warn`/`fail` 需人工复核（N1/QA1/策略线），不得用「调阈值到 pass」代替验证；
6. 报告可作 `research/reports/` 静态快照供门户/复盘引用，但接入 S5 监控/推送需另单审批。

## 9. 边界 / 未决

1. **阈值默认值需策略线/N1 拍板**：当前默认是「可运行最小闸」；生产复核建议用更严的版本化阈值（20 日/100 只等）。
2. 单周期、无行业中性/多周期衰减/显著性修正——沿用 `factor_diagnostics` 的口径边界（见其文档）；重叠样本修正可用 `tools/research/stat_utils.py`。
3. **方向语义**：阈值针对输入因子原始方向；若因子预期负向有效，调用方应反转因子或人工按负向复核（本工具不自动取反）。
4. `pass` 不代表可上线：仍需四关+影子盘+人工批准；本工具不写注册表/不产清单/不建单。
5. 新测试未纳入 `test_gate` 矩阵（`tools/test_gate.ps1` 不在本单允许文件）——若要进闸，另单把
   `tools/tests/test_factor_gate.py` 加入 tools_key/研究套件（+约 5s）。
6. 后续接入 S5 IC 跟踪/门户展示需另单（只读静态快照可先行）。
