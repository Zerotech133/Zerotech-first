## 二、路由修复（P0：`'str' object is not callable` → 502）

根因：B4a-lite 把 32 条 GET 精确路由表化成 16 个 `_GET_EXACT_*` 字典，表值是
**Handler 方法名字符串**；`portal_api.do_GET` 的 dispatch 写成 `table[path]()`，
把字符串当函数调用 → `TypeError` → 连接中断（浏览器表现 502/RemoteDisconnected）。
命中的包括 `/intel/stream`、`/bt-jev`、`/gzh`、`/fin`、`/kg/flow`、`/kg/battle` 等 32 条。

修复：16 组 dispatch 全部统一为 `getattr(self, route_table._GET_EXACT_N[path])()`；
`route_table.py` 增加契约说明与 `iter_routes()/unresolved(handler_cls)`，
新测试锁死三件事：

1. 表值必须是能解析到 `portal_api.Handler` 可调用方法的字符串（`unresolved()==[]`）；
2. 源码中不得再出现未绑定的 `table[path]()`，16 组必须全部 `getattr(...)`；
3. 真实 `do_GET` dispatch 路径（handler 级 stub）下 32 条全部命中对应 handler，
   参数化覆盖计划点名 6 条：`/intel/stream`、`/bt-jev`、`/gzh`、`/fin`、`/kg/flow`、`/kg/battle`。

语义保持不变：表键/方法映射/if-elif 顺序未动；`since_id` 等非表化分支未动。
未做真机渲染 smoke（页面 handler 依赖生产数据目录）；合并后按 §六 用真实 8091 验 200/302。

## 三、认证矩阵（拍板 1：情报默认全私有）

nginx 复用既有 `/_auth_guard`（internal → `8091 /api/auth/guard`，透传 Cookie）。

| 路径 | 未登录 | 登录后 |
|---|---|---|
| `/intel`、`/intel/stream` | 302 `/login?next=$uri` | 200（`/intel/stream` 不再 502） |
| `/xq_intel.html`、`/news_intel.html`（静态直链） | 302 `/login` | 200（`try_files` 正常出页） |

- API 位置不加 `error_page 401 = @login_required`：避免把登录页 HTML 当 JSON 交给前端；
- 静态直链与页面路由同受保护，堵住「绕过 auth_request 直接 GET .html 拿原文」的口子；
- 每个受保护路径只声明一次 location（测试断言 count==1，防复制出未加锁副本）。

### 公开白名单（保持不变）

- `/login`、`/s/<share_token>` 分享短链公开（规划「保留公开分享链接白名单」）；

- 直连 `127.0.0.1:8091` 属本机回环信任面（既有安全模型：局域网只经 8734 反代），
  本单不改变该边界；如需连本机低权进程也隔离，属后续独立拍板。

## 四、排序与新鲜度（P1 数据正确性）

旧口径：`news` 查询 `ORDER BY id DESC`（入库自增 id），补采/重判的旧闻会顶到第一屏
（实测 DB 最新 10-31，总线首条 10-29）。

新口径（两模块统一）：

```sql
ORDER BY ts DESC, created_at DESC, id DESC
```

- `api_intel_bus`：news/jev 窗口查询生效；`since_id` 水位模式保持
  `ORDER BY rowid ASC`（机器消费游标契约，不随展示排序改变）；
- `api_news_intel`：flash / policy / verdicts 三处 SQL 生效；
  verdicts 的 impact 权重 > conf 主排序不变，同分时按新基础序（ts 倒序）稳定保序；
- 总线信封新增字段（仅 news/jev 域）：

```json
{"as_of": "2026-10-31 12:00:00", "latest_ts": "2026-10-31 11:55", "age_s": 300}
```

  `as_of`=查询时刻；`latest_ts`=本域可见最新事件时间（无数据为 `null`，不拿 as_of 冒充）；
  `age_s`=滞后秒（无数据为 `null`）。页面可据此显示「数据截至」与 stale 告警（前端接入属后续）。

## 七、风险与影响

| 风险 | 说明 | 处置 |
