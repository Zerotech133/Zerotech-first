## 一、项目复盘

### 1.1 项目定位

「老田的AI助手」是一个以 MASS（Multi-Agent Stock System）三角体系为核心的**个人 OS 型多智能体平台**：

```
            工单治理（TaskStore + devtask 一单一线程）
                     │
   辩论引擎（interpreter） ←→ 判读席位（A0 agent，glm-5.3）
                     │
              A0 日报看板（a0_chief 聚合）
```

- **主人**：老田。**核心人物**：A0（田丰，参谋长/组织枢纽，2026-10-08 出生）。
- **宪法**：AGENTS.md 铁律（端口/入口/事件回流、前端准入三件套、多 Agent 并发隔离、git worktree 独立线程、完工必过评审门三守卫）。
- **工作纪律**：devtask 一单一线程（worktree + task/<TID> 分支 + merge 三守卫）、TaskStore 月度账本、判读席位成对重判、缺陷判读必带 [P0/P1/P2] 定级。
