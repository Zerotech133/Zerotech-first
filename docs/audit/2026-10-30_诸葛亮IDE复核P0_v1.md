## 一、接口

### `POST /api/zhuge/review`

```json
{
  "task_id": "WO-...",
  "diff": "unified diff ≤64KB",
  "changed_files": ["a.py"],
  "test_result": {"ok": true, "passed": 12, "failed": 0},
  "context": {"goal": "...", "acceptance": ["..."]}
}
```

返回 `202`：

```json
{"ok": true, "review_id": "zr-...", "status": "pending"}
```

### `GET /api/zhuge/review/<id>`

```json
{
  "ok": true, "status": "done", "read_only": true,
  "verdict": "pass|concerns|block",
  "findings": [{"severity":"P1","file":"a.py","line":42,
                "claim":"...","evidence":"...","fix":"..."}],
  "questions": [], "sources": [],
  "model": "deepseek/deepseek-chat", "mode": "openclaw_cloud",
  "elapsed_ms": 32000
}
```

### `GET /api/zhuge/review/status`

显示 `enabled`、OpenClaw ready、当前 model/carrier。

## 二、安全

- 默认关：`ZHUGE_IDE_REVIEW=1` 才启用；
- 需要门户 session cookie（`zb_session`）；
- 测试可用 `ZHUGE_IDE_REVIEW_ALLOW_ANONYMOUS=1`；
- 正文 ≤64KB；diff 不可信；只读，不写代码/不合并；
- 失败/超时返回 `degraded`，不伪造 `pass`；
- 缓存：`diff_hash + test_hash` 10 分钟。
