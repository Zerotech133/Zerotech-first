## 一、修复的 BUG

### BUG-1：`case_orchestrator` 锁泄漏（已修）

- 位置：`case_orchestrator.autorun()`
- 现象：case_id 不存在时，代码先把 ID 加入 `_RUNNING`，随后 `case_not_found` 直接 raise，**未释放锁**；之后同 ID 永远返回 `case_already_running`。
- 修复：case 不存在时显式 `_RUNNING.discard`；`orchestration` 初始化移入 try/finally 覆盖。
- 回归测试：`test_missing_case_does_not_leak_running`。

### BUG-2：已审批/已下发状态可被页面 save 降级（已修）

- 位置：`case_api.save_case()`
- 现象：服务端已 `APPROVED/DISPATCHED` 后，页面再 save 一个 `status=PROPOSED` 的旧状态，会覆盖服务端终态（approval 还在，但 status 错）。
- 修复：old status 为 APPROVED/DISPATCHED 时，客户端不能降级；DISPATCHED 优先保持。
- 回归测试：`test_save_does_not_downgrade_approved_or_dispatched`。
