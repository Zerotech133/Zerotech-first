## 1. H4：/api/ 从"公开基线"收敛为"显式白名单 + 默认拒绝"

**改动**（`portal/nginx.conf` 新增 H4-B 段，替换原通用 `location /api/` 公开 passthrough）：

1. **公开白名单（匿名）**：按一级路由名逐项登记（141 个 + intel 3 个只读子路径），
   以 3 条 regex location（系统/身份/首页告警、量化/回测/组合/策略/行情、治理/军团/情报/其他）
   收敛；明细逐项列在配置注释中，与测试双向校验。覆盖：`health`、`auth`、`bff`、`m`、
   `overview`、`home`、`brief`、匿名量化/组合/策略/行情、军团/情报页数据等。
2. **受保护（auth_request → 401）**：
   - 高敏子集（首轮已加，保持）：`/api/platform/`、`/api/org/`、`/api/analysis/`、
     `/api/os/`、`/api/jev/`（`error_page 401 = @api_unauthorized` → 401 JSON）；
   - 既有专项保护（保持）：`/api/news/intel`、`/api/xq/intel`、`/api/jev/query`、
     `/api/jev/review/`、`/api/intel/bus`、`/api/intel/evidence-targets`。
3. **未登记前缀：默认拒绝**——`location /api/ { default_type application/json;
   return 401 '{"ok":false,"error":"api_not_in_whitelist",...}' }`，不再有公开 passthrough；
   新增公开 API 必须显式加入白名单并同提交更新测试。
4. **news/xq/intel 三个一级族不整族公开**：intel 只放行 `brief`/`policy`/`sources` 三个只读
   子路径；`bus`/`evidence-targets` 仍走既有精确受保护 location；news/xq 保持受保护。

**影响面核对（静态证据）**：

- portal_api 服务端 `/api/` 路由 158 条：**140 条命中公开白名单、18 条命中受保护**
  （analysis/intel-bus/evidence-targets/jev/news/org/os/platform/xq），**0 条落空**；
- `portal/static`/`portal/*.html` 中 212 个 `/api` 引用：受保护页面的引用由受保护 location
  覆盖，其余全部命中白名单（测试 `test_public_whitelist_covers_static_page_references` 守护）；
- 仓库内非静态代码对 8734 `/api` 的引用（3 处）：`/api/auth/oidc/callback`、
  `/api/d1/research`、`/api/dev/legion` 均在一级白名单内；
- `/api/health`、`/api/auth/*`、`/api/bff/*`、`/api/m/*` 显式在白名单内，8734 公开页与
  健康探活不锁死（测试固定断言）。

**优先级核对**：白名单 regex 位于既有无修饰 `/api/` 之前；受保护 `^~` 前缀与精确 location
（audit_chat/regime/sixring/admission/state 等特殊上游）按 nginx 规则优先生效，未被 regex 劫持。

## 2. JEV 前端：reviewer 取会话身份（M3 收尾）

**问题**：M3 后端已改 `reviewer` 取 `zb_session` 的 sub（body 自报不一致 → 403
`reviewer_mismatch`），但 `portal/static/jev_review.html` 仍默认 `reviewer="老田"` 并提交，
会话 sub 不同即 403。

**改动**（`portal/static/jev_review.html`）：

- 删除 reviewer 输入框与固定默认值；新增 `#who` 展示位，从 `GET /api/auth/me` 读取
  `session.sub` 显示"复核人：<sub>（会话身份）"；
- resolve 提交 body 收敛为 `{id,decision,note}`，**不再带 reviewer**（后端取会话身份落库）；
- 未登录时显示"未登录：先登录 8734"链接，`load()` 不再请求受保护队列，裁决按钮 `disabled`；
- 保留队列筛选/分页/转义渲染；内联 JS 通过 `node --check` 语法检查（测试在 node 可用时执行）。
