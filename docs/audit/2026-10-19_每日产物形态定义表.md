## 二、统一风格规约（新增页面必须遵守）

1. 唯一色彩事实源：/static/tokens.css，禁止页内硬编码 hex（状态色/涨跌色一律读语义变量）。
2. 共享 chrome：/static/page_common.css（.wrap / h1+.sub / .panel / .metric / .pc-chip / footer）。
3. 导航：全部 portal/*.html 必须挂 /static/nav.js（nav.js 为生成物，改源 portal/api_common.py DOMAIN_NAV_GROUPS 后跑 tools/export_nav.py 再生，禁手改）。
4. 数据出口：只读 API 走 8091 mixin（fail-visible，不假绿）；静态页 8080 直出，正式入口 8734 portproxy。
5. 飞书卡片：v3 规范 build_v3；内网链接一律 markdown 超链接不做按钮（K43-c 判例）。

## 三、新闻域口径澄清

- 新闻源权威配置 = news_collector/news_config.json（watch_keywords/policy_keywords/policy_authority_sources/源显示名）+ news_collector.py SOURCES 注册表；sources.yaml 是 KG 采集域（zerobound-kg）权威，与新闻源无涉，本单未动。
- 政策分层规则：标题/正文命中 policy_keywords 即入政策栏；source ∈ policy_authority_sources 白名单 → 权威源（本单注册 govpolicy=中国政府网政策文件库、chinanews=中新社，均经实测 200 后入库）；命中但不在白名单 → 一般源（营养度待观察，白名单随实采质量迭代）。
