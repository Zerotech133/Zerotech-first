## 一、定位与数据流

JEV = 新闻结构化判读：把财经快讯转成 `bias / conf / scope / event_type / impact / companies / reason`，
供校准（方向准确率）、告警门、角色日报、Hermes/门户消费。

```
采集新闻 → news.db(102,723 已判/1,718 待判) → jev_backfill 判读（云 systemone 优先，9B 本地回落，safe 预筛）
        → JEV JSON → ① jev_audit 账本/后验/校准（jev_audit.db + posterior jsonl + latest.json）
                    ② 下游：Hermes 简报 / 门户 8091 / 三席服务 9101-9103 / MCP / 健康卡
                    ③ 运营：JevNight 夜间独占、小时轮、07:10 漂移日报、21:00 feed、22:30 verify
```
