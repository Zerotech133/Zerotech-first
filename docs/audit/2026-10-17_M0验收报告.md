## 四、关键设计判例（沉淀）

1. **v1 事件契约严格性**：ai_operator `validate_event` 顶层白名单外字段一律拒绝；扩展字段只能进 payload 或内部 v2，适配器不冒充 v1；
2. **naive 时间不补 UTC**：portal/heartbeat/push_flow 历史时间为 naive 本地时间，适配层显式标 `timezone_missing`，绝不伪造时区；
3. **无源 ID 不伪造**：缺失源 ID 保持 null + `identity_missing`，不用 line:n 或 hash 充当身份；
4. **Paper 旧幂等是 ref 不是 idempotency_key**：`ux_orders_ref` 全表非空唯一是真实防重判据，迁移期不动；统一账本走独立维度；
5. **死信语义**：claimed 超过 stale_seconds 未回写终态 → 自动标 failed 开新 attempt——进程崩溃恢复不依赖人工发现；
6. **fail-open 双轨**：新账本异常降级 unavailable 不阻断旧链；冒烟/测试强制旁路；
7. **同名 status 不跨域映射**：Task 状态机 / project phase / academy 阶段机 / gzh 审批态四者语义独立，投影原样保留。
