# JEV 低置信复核工作台

- 日期：2026-10-30
- 工单：`K-JEV-20261030-QUEUEUI`
- 入口：`http://127.0.0.1:8734/static/jev_review.html`

## 功能

- pending 列表（生产当前 10,523 条）
- 按 conf 升序（默认）/ conf 降序 / 最新入队排序
- bias 筛选：bull / bear / neutral / 全部
- 状态筛选：pending / resolved / all
- 每页 100 条，分页
- 逐条裁决：正确 / 错误 / 不确定
- 裁决写回：
  - `status=resolved`
  - `decision`
  - `reviewer`
  - `reviewed_at`
  - `note`

## API

```text
GET  /api/jev/review/queue?status=pending&bias=&sort=conf_asc&limit=100&offset=0
GET  /api/jev/review/summary
POST /api/jev/review/resolve
     {"id":"...","decision":"correct|wrong|uncertain","reviewer":"老田","note":""}
```

约束：

- 只读写 `jev_review_queue`，不覆盖 `news.jev`；
- 只能 resolve pending 行，重复/已完成返回 409；
- reviewer 必填，decision 枚举校验；
- 列表 SQL 参数化，排序白名单化。
