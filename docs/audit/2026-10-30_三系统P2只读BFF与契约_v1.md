### 只读/安全约束

- 只发 SELECT / 健康 GET，无写端点；
- SQL 守卫：非 `SELECT` 直接 `ValueError`；
- MySQL 用 `START TRANSACTION READ ONLY`，查询后 rollback；
- 密码只从本机 secret 文件/环境读，**不进入响应/日志**；
- 源不可达返回 `ok:false + reason`，不以 0 冒充正常；
- 智策业务 GET 无服务 token 时返回 `zhice_auth_required`，不伪造数据；
- BFF 只挂 GET；写方法由 portal_api 统一 404/405。
