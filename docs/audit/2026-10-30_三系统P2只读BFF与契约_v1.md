### IdentityContext

- `owner_scope`: own / strategy / tenant / global

- 明确禁止放 token/密钥

- Conversation + Message + Reference/WebPage/Attachment/ToolCall/Usage
- 对齐菜鸟 `AiChat*` 语义：RAG、联网、附件、MCP/工具、流式、token 成本

- `mode`: MODEL / AGENT / HYBRID

## 3. 零界只读 BFF

代码：`portal/api_zhice_bff.py`

### 端点

| 端点 | 内容 | 状态 |
|---|---|---|

| `GET /api/bff/health` | 两源健康 | 同上 |

| `GET /api/bff/zhice/market/regime` | 智策市场状态只读 | 同上 |

### CLI（无需重启，立即可用）

```bash
python tools/bff_readonly.py --view overview
python tools/bff_readonly.py --view cainiao
python tools/bff_readonly.py --view zhice
python tools/bff_readonly.py --view contracts
```

### 只读/安全约束

- 只发 SELECT / 健康 GET，无写端点；
- SQL 守卫：非 `SELECT` 直接 `ValueError`；
- MySQL 用 `START TRANSACTION READ ONLY`，查询后 rollback；
- 密码只从本机 secret 文件/环境读，**不进入响应/日志**；
- 源不可达返回 `ok:false + reason`，不以 0 冒充正常；
- 智策业务 GET 无服务 token 时返回 `zhice_auth_required`，不伪造数据；
- BFF 只挂 GET；写方法由 portal_api 统一 404/405。
