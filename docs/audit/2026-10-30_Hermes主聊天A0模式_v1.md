# Hermes 主聊天接入 A0 田丰（客户端模式）v1

- 日期：2026-10-30 21:20
- 工单：`K-QUANT-20261030-HERMESMAIN`
- 目标：让 Hermes 主聊天可以直接以 A0 田丰身份开发，而不是只走军团 IDE 面板。

## 实现

在 `Hermes/extensions/legion-ide/app.js` 末尾追加一个独立 IIFE：

- 在 Hermes 输入框左侧注入「A0 田丰」开关；
- 状态存 `localStorage["legion-a0-mainchat"]`；
- 开启后拦截主聊天发送：
  - 点击 `#btnSend`（捕获阶段）或 Enter；
  - 清空 `#msg`；
  - 调用 `/api/ide/orchestrate`：

```json
{"message":"...","task":"","agent":"A0"}
```

- 回复写回 `S.messages` 并 `renderMessages()`：
  - `mode=answer`：显示 A0 回答；
  - `mode=executed`：显示 A0 计划 + OH 会话 id；
- 关闭开关后完全走原 Hermes 发送链路，不改 Hermes 默认行为。

端点：

```text
8734 /hermes/ → /openhands/api/ide/orchestrate（受 nginx auth）
8787 直开     → http://127.0.0.1:8796/api/ide/orchestrate
```

## 验证

- `node --check app.js` 通过；
- `/extensions/app.js` 已包含「A0 田丰」；
- 页面存在 `#btnSend`、`.composer-left`、`#msg` 注入锚点。

## 使用

1. 打开 `http://127.0.0.1:8734/hermes/` 并登录；
2. `Ctrl+F5` 强刷；
3. 输入框左侧点「A0 田丰」；
4. 直接在主聊天输入任务。

## 边界（必须知道）

```text
这是客户端路由层，不是 Hermes 后端 agent 注册。
· 不写 Hermes 会话历史，刷新后主聊天不保留 A0 对话；
· task 为空，OH 使用默认工作区；要指定工单/worktree 仍走军团 IDE 面板；
· A0 的长期 memory 尚未注入；
· 本质是“主聊天壳 + Hermes/A0 orchestrator”，不是把 Hermes 核心换成 A0。
```
