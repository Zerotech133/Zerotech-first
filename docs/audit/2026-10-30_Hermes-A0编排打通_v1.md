- 工单：`K-QUANT-20261030-HERMESORCH`
- 目标：Hermes 做 orchestrator，A0 prompt + 席位路由；OH 只负责执行。

## 1. 之前的状态

```text
/hermes/ 选 A0
→ 直接 POST /api/ide/openhands/start
→ OH 只收到 message + model
→ agent="A0" 仅存进 _RUNS/session 元数据
```

A0 的 prompt、职责、席位绑定都没有进入运行时。

```text

```

新增：

- `agent_platform/legion_command/hermes_orchestrator.py`
- `POST /api/ide/orchestrate`
- 前端 `start()` 改走 orchestrator
- 单测 3 例：JSON 解析 / answer 不执行 / execute 把计划传给 OH

## 3. 实测

```json
{
  "message": "用两句话解释你作为A0田丰负责什么，不需要改代码或执行命令",
```

说明：

- A0 prompt 生效；
- Hermes 席位绑定 `glm/glm-5.3` 生效；
- 判定“不需要执行”，没有启动 OH；
- 耗时 5.4s。

## 4. 前端表现

- executed：显示 A0 计划 + binding，再进入 OH 事件流。
