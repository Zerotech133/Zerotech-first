## 交付

**`agent_platform/adapters/trace_link.py`** —— 影子(run_id) ↔ Paper(trace_id) ↔ 成交(order_id) ↔ 绩效(perf_key) 只读映射层：

- `link_key(segment, ref)`：环锚点规范化纯函数，缺必填/未知环节即抛（伪造/残缺锚点层内拒绝）。
- `link_id_of(chain)`：链幂等键=非空环节 link_key 排序 canonical hash[:16]，与环节次序无关。
- `LinkStore`：`data/trace_links.jsonl` append-only 账本——同链重放 status=replayed 零副作用；同键异链抛 ValueError（对齐 ApprovalStore M0 契约）；validate_chain 先行，结构非法不入账。
- `collect_shadow_anchors()`：影子账本只读逐行提取（done+run_id 过滤、坏行容忍跳过、failed/parse_ok=false 不产锚点——交影子环自身告警）。
- `replay_trace(store, target)`：任一环必填锚点值命中即整链时间线；partial 链正常回放、缺环显式 `missing_segments`；无命中 verdict=NOT_FOUND + finding（不伪造 ID）。
- CLI：stats / ls / replay（replay 未命中退出码 1）。

**`agent_platform/tests/test_trace_link.py`** 14 例：锚点规范化、链校验、link_id 确定性+次序无关、登记/幂等重放零追加、同键异链拒绝（篡改模拟）、残缺链拒绝、partial+missing_segments、NOT_FOUND、stats、影子收集（done 过滤/坏行容忍/缺账本空）、tmp 全隔离。

## 判例

1. **显式声明式关联**：环间关联只由 record_link 写入，映射层不做猜测匹配——无源 ID 不伪造判例在链场景的延伸。
2. **partial 链合法**：缺环不是错误，回放 missing_segments 显式化；NOT_FOUND 才是 finding。
3. **同键异链拒绝**：link_id 冲突但链内容不一致 → ValueError（M0 同键异参语义平移）。
4. **测试 bug 教训**：深拷贝链对象（bad）与账本行（含 chain 包装）是两层结构——`bad["chain"]` KeyError 教训：测试里模拟篡改应直接改 `_index[lid]["chain"]` 内层。
5. **收集器过滤职责分离**：failed/parse_ok=false 行不产锚点（影子环已告警），映射层只收可回放决策。
