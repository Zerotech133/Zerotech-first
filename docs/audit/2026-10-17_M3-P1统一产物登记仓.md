## 三、本刀判例

1. **登记不设门（观测≠承诺）**：record() 无任何状态/来源校验——登记是事实记录，发布/替换才设 Approval 门（M3-P3 绑 content_hash）。与 M2 判例「凭据不泛滥」同构。
2. **内容即身份**：产物幂等键=content_hash 本身（无参数五元组），同键异参语义不适用；IntegrityError → 读回既有行按重放处理（与 ApprovalStore 同构但语义不同源）。
3. **supersede 无源 ID 拒绝**：old_artifact_id 不存在 fail-visible 抛错——防伪造替代链（判例「无源 ID 不伪造」在产物域的落地）。
4. **同内容 supersede=重放**：内容没变时 supersede() 不产生 r2（去重索引兜底），revision 不虚增。
5. **payload 列为扩展槽**：Artifact 契约暂无 payload 字段，表列恒写 '{}'，读侧不映射——未来扩展只加列不动契约。
