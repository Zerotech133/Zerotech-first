# HZ 基线 7F 根因研究 v1

- 时间：2026-11-03 15:45｜性质：只读研究，不改测试/配置
- 结论：7 条失败**都不是运行时服务故障**，分三类：测试时间漂移、页面/测试契约漂移、模型绑定策略与 org 脱节。

| 组 | 测试 | 根因 | 性质 |

| A（3） | `test_attribution_gap_report` ×3 | 测试把 `TODAY=2026-10-27` 写死，`main()` 用真实当前时间 2026-11-03，7 天窗口切点变成 10-28，夹具事件全部落在窗口外 → `total=0` | **测试日期漂移** |

## 二、逐项证据

### A. attribution 3 条

- 测试固定：`NOW=2026-10-27`、`TODAY=2026-10-27`；
- 测试 `main(["--events", fixture, ...])` 未注入 `now`；
- 工具 `main()` 内部 `time.time()` 取真实 2026-11-03，cut=2026-10-28；
- fixture day=2026-10-27 < cut → `total=0`，`missing=0`，`strict` 不触发。
- **修法建议**：给 `attribution_gap_report.py` 增加 `--now`（复算/测试用）或测试改为动态日期；不改业务口径。

### B1. hq agenda marker

- 当前页面实际调用：`fetch('/api/hq/meeting/agenda')`；
- nginx 有 rewrite：`/api/hq/meeting/agenda` → `/api/hq/agenda`；
- 测试仍找 `/api/hq/agenda` 原始字符串 → 失败；
- 页面功能存在，属**测试契约滞后**，不是功能丢失。
- **修法建议**：测试接受 rewrite 前后两种路径，或页面统一写 `/api/hq/agenda`（需确认 nginx rewrite 保留）。

### B2. meeting browser harness

- 页面 `GROUPS` 增加 `dept:'pick-dept'`；
- 测试 harness `els` 初始化没有 `pick-dept`；
- `renderPicker()` 循环到 dept 时 `document.getElementById('pick-dept')` 为 undefined → `appendChild` 报错。
- **修法建议**：harness 补 `pick-dept`；属测试夹具维护，不是页面 bug。

### C. role_group DEV3 绑定

- org：`DEV3 llm_binding=glm/glm-5.3, grade=E2, discipline=quant`；
- `role_group_model.json`：`quant.E2.allowed=[ollama/qwen3.5:9b, deepseek/deepseek-flash]`；
- 失败：`DEV3 绑定 'glm/glm-5.3' 不在 quant/E2 allow`。
- **根因**：云端绑定任务改了 org，没同步 role_group 模型策略。
- **修法建议（二选一）**：
  - 若 13 负责人用 glm 是既定决策：把 `glm/glm-5.3` 加入 quant/E2 allowed（preferred 可保持本地）；
  - 若 DEV3 应回本地：改 org DEV3 binding 回 `ollama/qwen3.5:9b`（需确认云端绑定政策）。
