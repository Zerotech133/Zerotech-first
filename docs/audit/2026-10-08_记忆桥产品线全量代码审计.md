## 三、P1 发现（转正/收敛前必须处理）

### P1-1 【异常】生产写路径是「留痕换名」而非真实现——配置翻转承诺不成立

- 位置：`plugins\cowbridge\__init__.py` L186-200（on_memory_write）、L172-184（sync_turn）、L256-258（shutdown）
- 证据：
  ```python
  # on_memory_write「生产写路径（转正后启用）」——实际只是换文件名继续留痕：
  if self._bridge:
      self._shadow_append("to-cowagent", "memory_write_applied.jsonl", {...})
      # ↑ 没有任何写 CowAgent workspace 的代码
  # sync_turn 生产路径：入队后无人消费
  with self._lock:
      self._turn_queue.append({...})
  # shutdown：
  with self._lock:
      self._turn_queue.clear()   # ← 队列数据直接丢弃
  ```
- 矛盾：`DESIGN_v0.2_provider.md` L57「生产写只是配置翻转，不改代码」；`sync_turn` 注释 L181「shutdown 时批量小节化写 Cow daily 层」——实现不存在。
- 后果：转正时翻转 `cowbridge.json` → H→C 方向**假成功**（applied 留痕让运维误以为已写入）；turn 队列**静默积压**且进程退出即丢。
- 状态：**异常（承诺与实现不符）**。影子模式下无害。
- 处置：转正前二选一——①补真实现（写 Cow daily 层 + flush 消费者）+ 测试；②改 DESIGN/注释为如实描述（「生产写路径 v0.3 实现」），并在 cowbridge.json 翻转路径上加断言拦截（allow_write_* = true 且实现缺失时 initialize 直接 raise，防误翻转）。

### P1-2 【异常】测试盲区：v0.1.1 主路径（index.db + 根部 MEMORY.md）无 fixtures 单测

- 位置：`cowbridge.py` L252-265（selftest 只造 `fx/memory/MEMORY.md` + `daily/*.md`——旧契约路径）
- 现状：今晚真实链路由 `verify_provider_realdata.py` 补了集成验证（6/6 PASS），但它依赖真实 `~/cow` 环境，不可重放、不能进 CI。
- 后果：未来任何人改动 `_read_cow_indexdb`（如 index.db 结构升级、CowAgent 版本变更），selftest 依然全绿，回归只能靠 09:10 automation 的真实数据碰撞发现。
- 状态：**缺失（主路径单测）**。
- 处置：selftest 增加 fixture——用 `sqlite3.connect(":memory:")` 建 sessions/messages/chunks 表插两行，落盘临时 index.db，断言 dialog 候选与 sha1 幂等。

### P1-3 【异常】跨 Agent 注入链的残余风险（框架已有缓解，转正判据需补卫生检查）

- 链路：CowAgent web 9899 免认证（`channel/web/core/_common.py` L322-325 `_check_auth` 空密码直接放行）→ 任意本机进程可 POST /message 污染会话 → qwen 回复+用户输入入 index.db → `read_cow_memory` 读出 → 插件壳 prefetch/`cow_memory_search` 注入 Hermes 上下文。
- 框架缓解（Explore 取证）：注入点非裸拼——`memory_manager.py` L176-189 `build_memory_context_block` 包 `<memory-context>` 围栏+system note，L46-62 `sanitize_context` 剥离 provider 预包裹围栏（防嵌套逃逸）；注入只改 `api_msg` 副本（run_agent.py L10854-10865），不污染持久化。
- 残余：围栏内文本模型仍然可见（"忽略之前指令"类语义注入无免疫力）；`agent_permission_mode: full-access` 放大了 CowAgent 侧被诱导执行的后果。
- 状态：**存在缓解、残余风险需管理**。
- 处置：①CowAgent `config.json` 设 `web_password`（一行改动，堵住免认证入口）；②转正判据加一条「注入卫生抽查」——shadow/to-hermes 增量人审时抽查是否含指令性文本；③`agent_permission_mode` 视需要降级。
