## 二、设计裁决

1. **不建第二账本、不碰路由**：数据源 = 既有 `portal/data/llm_usage.jsonl`（agent_coder._log_usage 落账）+ `llm_tool_audit.jsonl`（API 审计）+ `registry/org.json`（agent→dept 权威映射）；Hermes/agent_coder 内部路由不动（红线）。
2. **域归因 fail-visible**：agent 经 org.json departments[].agents（含 lead）映射业务域；映射不到记 unmapped_agents 显式列出，不猜测（无源 ID 不伪造判例）。
3. **积分估算显式标注**：anthropic 通道单次 ≈4.5 积分（K-ORG-038 判例取中），字段名 credits_estimate；chars 兜底列保留（ollama/claude CLI 无 token 的通道）。
4. **与 tools/cost_report.py 分工**：cost_report = 工单维（K-ORG-080/N7 既有，e2e_report 消费）；usage_ledger = 平台域维（M2/M5 消费）。复用其 TID 归因正则口径与积分判例，零重复账本。
5. **缺源 WARN 不崩**：三源任一缺失 findings 显式记录、计 0（宁零勿造）。
