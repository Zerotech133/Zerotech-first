## 3. 设计

### 注册表

`agent_platform/identity/identity_registry.json`

每条 actor 包含：

- `sub`：统一主体 ID
- `actor_type`：admin / member / qmt_client / strategy_collaborator / agent
- `roles` / `permissions` / `owner_scope`：**统一描述**，不是授权
- `source_ids`：各系统 ID
- `source_claims`：分系统原始角色/权限，防止权限被拍平
- `links[]`：`verified` / `unconfirmed`，带证据
- `mapping_status`：verified / partial / unconfirmed

### 解析器

`portal/identity_registry.py`

- `list_actors()`：脱敏列表
- `resolve(sub)`：按统一主体解析
- `resolve_source(system, id)`：只认 **verified** 链接
- `build_context()`：生成符合 `identity_context.schema.json` 的上下文
- 只读：不写库、不读密钥、不发请求

### BFF / CLI

BFF（需重启 8091 生效）：

```text
GET /api/bff/identity/actors
GET /api/bff/identity/context?sub=zero_bound:owner
GET /api/bff/identity/context?source=zhice&id=u-96d51f4d9b7a2826
```

CLI（无需重启）：

```bash
python tools/identity_context.py --list
python tools/identity_context.py --resolve zero_bound:owner
python tools/identity_context.py --source zhice --id u-96d51f4d9b7a2826
```

## 4. 安全边界

- `roles/permissions` 只是上下文描述，**不替代任何系统的 RBAC**；
- `source_claims` 保存原始系统声明，消费方必须按来源分别判断；
- `unconfirmed` 链接不得用于登录、授权、交易、审批；
- 注册表不含密码、token、cookie、手机号；
- `resolve_source` 只匹配 verified；未确认链接显式返回 not found；
- 不合并智策/菜鸟数据库，也不复制用户表。
