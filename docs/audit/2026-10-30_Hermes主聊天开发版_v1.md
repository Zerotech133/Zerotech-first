## 4. run_id 事件链

每次编排生成：

```text
run-<12 hex>
```

事件落：

```text
C:\项目\_vault\legion_ide\runs\<run_id>.jsonl
```

实测 run `run-9ef4214a5766`：

```jsonl
{"type":"orchestrate_start","payload":{"agent":"A0","task":"WO-SUPERVISOR-20261030",...}}
{"type":"hermes_plan","payload":{"binding":"glm/glm-5.3","need_execute":false,...}}
{"type":"run_end","payload":{"mode":"answer"}}
```

`executed` 时额外有 `oh_start`（cid/worktree/error）。

## 5. 当前 Hermes 主聊天能力

```text
输入框左侧：
[A0 田丰] [工单下拉]
```

开启 A0 后：

```text
发送 → /api/ide/orchestrate
→ A0 prompt + 工单上下文
→ Hermes /api/chat（GLM-5.3）
→ need_execute 判断
→ OH 执行（task/worktree）
→ 回复 + run_id
```
