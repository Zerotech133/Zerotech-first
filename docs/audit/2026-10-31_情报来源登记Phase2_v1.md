### 1.1 为什么股吧优先

- 股吧落盘链路已存在（GubaCrawl，既有 jsonl 池），**登记与采样成本最低、可立即验证登记表是否失真**；
- 股吧帖子是短文本、结构稳定（`post_id/title/ts/click/comment/user/...`），适合做「采样≠发布」的只读工具首批验证；
- 现网实测：`quant_backtest/data/guba` 共 392 个 `*.jsonl`，其中 **188 个非空 / 204 个 0 字节**，最新非空文件 `002248.jsonl`（2026-10-30 17:50:30）。空文件正是「登记≠接入、接口可达≠数据可用」的活证据——采样必须跳过空文件并 fail-visible，不能拿"文件在"当"数据有"。

### 1.2 为什么视频后置

- `osint_video` 产线当前处于 T01/T03 PoC：`data/raw|work|store` 实测均为 **0 文件**（仅 `browser_profile/` 浏览器运行态 320 个文件，非情报样本）；
- 视频采集/转写受平台条款、版权与人工复核约束，Phase 2 没有授权边界内的现成样本可采；
- 因此登记为 `mode=sampling` 但 `enabled=false`、`full_ingest=deferred`：**登记先行、采样后置**，`--sample osint_video` 会显式拒绝（exit 4），而不是假装"已接入"。

说明：
- `last_sample` 由登记表维护者人工登记；**只读工具不回写**（避免采样动作产生写副作用），因此本轮登记后为 `null`；`--list` 会实时计算样本落点是否存在/最新非空时间，不依赖该字段；

## 三、口径红线：登记≠接入、采样≠发布

| 口径 | 含义 | 本单如何保证 | 禁止项 |
|---|---|---|---|
| **登记≠接入** | 写入 `sources.json` 只代表身份/授权/样本位置已登记；不代表已接入生产链路、不代表获准采集新数据 | 登记表 `policy` 明示；`--list` 只读；无采集任务/端口/服务改动 | 把"已登记"说成"已接入"；依据登记表启动采集或轮询 |
| **采样≠发布** | `--sample` 只读既有落盘样本、打印到本机 stdout，供核对结构与可用性 | 工具零写路径（AST 断言无网络/写盘依赖）；退出码显式；样本不落新文件 | 把样本当成品数据入库/发报告/推飞书/对外分发；拿采样结果当"数据已接入"证据 |

补充红线：
- **不联网**：工具仅 `argparse/json/sys/time/pathlib`，无 `requests/urllib/socket/sqlite3`（测试用 AST 静态断言 + 运行时行为验证）；
- **不写生产**：不写 `quant_backtest/data`、不写库、不回写 `sources.json`、不新增目录/服务；
- **fail-visible**：缺登记表/坏 JSON/缺字段/来源未知/未启用/路径缺失/空目录/全部坏行 → 非零退出 + `FAIL-VISIBLE:` stderr，绝不静默返回空样本；
- **内容时间戳优先**：采样只按文件 mtime 排序取文件，**不推断数据新鲜度**；股吧实测存在"文件新、内容 ts 旧"（如 `002248.jsonl` 首条 ts=2026-08-18），登记/采样均不能据此宣称"今日有产出"。

## 四、CLI 用法（只读）

```powershell
# 1) 只读展示登记表（含样本落点是否存在/最新非空时间）
python tools/intel_sources.py --list
python tools/intel_sources.py --list --json

# 2) 只读采样：股吧已有落盘，最多 2 条
python tools/intel_sources.py --sample guba --limit 2
python tools/intel_sources.py --sample guba --limit 2 --json

# 3) 后置/仅登记来源会被显式拒绝（不是静默空）
python tools/intel_sources.py --sample osint_video   # exit 4
python tools/intel_sources.py --sample tdx_market    # exit 4

# 4) 边界：limit 只允许 1..100（超界 exit 2）
python tools/intel_sources.py --sample guba --limit 999

# 5) 测试注入登记表路径（仍只读）
python tools/intel_sources.py --list --registry <path/to/sources.json>
```

退出码：`0` 成功；`2` 登记表/参数错误；`3` 无可用样本（缺文件/空数据/全坏行）；`4` 该来源在 Phase 2 不允许采样。
