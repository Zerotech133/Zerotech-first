# 人工复核批次校验/回填工具（WO-INTEL-HUMANAPPLY-20261031）

## 用途

把老田填好的 `intel_review_batch_20261031.csv` 校验后写回 `news.db`，
`review_type='human'`，与 AI 初筛的 `ai_first_pass` 严格分开。

## 安全默认

- 默认 dry-run，只校验不写库；
- `--apply` 前先做 sqlite 一致性备份；
- 只接受 `correct|wrong|uncertain`；
- 只更新 `status='pending'`，不覆盖已 resolved/legacy；
- 拒绝 `N1-AI`/含 `AI` 的 reviewer，防 AI 代签；
- 单事务，写后校验 pending 减少数 == 写入数；
- 不跑 A/B、不重启、不触发 JEV 重判。

## 用法

```powershell
# 1) 校验（不写库）
python tools/intel_human_batch_apply.py --csv C:\Temp\human_review_20261031\intel_review_batch_20261031.csv --json

# 2) 老田确认后写库
python tools/intel_human_batch_apply.py --csv C:\Temp\human_review_20261031\intel_review_batch_20261031.csv --apply
```

写后 summary 应出现：

```text
resolved_human = 50
resolved_ai_first_pass = 50
pending = 150
```

说明：具体 pending 数取决于写入时的实际队列；工具会输出前后值。

## 回滚

`--apply` 会打印 backup 路径；停写后用备份还原即可。
manifest 默认 `C:\Temp\intel_human_batch_apply_manifest.json`。
