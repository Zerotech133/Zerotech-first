## 1. 结论

1. 新增脱机因子诊断工具 `tools/research/factor_diagnostics.py`：输入一张已对齐的因子面板
   `DataFrame[date, symbol, factor, forward_return]`，输出 **rank IC / ICIR / 分位收益 / 多空差 /
   换手 / 覆盖率 / 样本数**，按交易日分组计算。
2. **纯 pandas/numpy**，无新依赖、无网络、不写生产数据；既可 import（`compute(df)`）也可 CLI
   （CSV → JSON/报告落盘）。
3. **fail-visible**：缺列/非 DataFrame/空数据/全部坏行 → `FactorDiagnosticsError`（CLI 退出码 2）；
   部分坏行/重复/截面不足/天数不足 → 不静默丢弃，进入 `samples`、`bad_rows` 样例与 `warnings`。
4. 口径与 Alphalens 对齐到「日度截面 rank IC + 分位收益 + 多空差 + 换手」，但**刻意收窄范围**：
   单周期、无行业中性/多周期衰减/绘图、ICIR 不年化、t 值仅描述（见 §6 差异表）。
5. 后续接入点见 §7：研究脚本批量因子筛查 → `bt_harness`/`selection_engine` 验证 → S5 IC 跟踪；
   均只读、不改变生产选股链路。

## 2. 输入契约

| 列 | 类型 | 说明 |
|---|---|---|
| `date` | 可解析日期（`YYYY-MM-DD` 字符串 / Timestamp） | 交易日；按日分组 |
| `symbol` | 字符串 | 证券唯一标识（代码/ts_code 均可，工具不解释含义） |
| `factor` | 数值 | 因子值；**不假设方向**（IC/多空差正负自会体现） |
| `forward_return` | 数值（**小数**，0.02=2%） | 前视收益；**由调用方按 PIT 口径自备**（本工具不做复权/停牌/对齐/前视校验） |

- 坏行处理：`date` 不可解析、`symbol` 空、`factor`/`forward_return` 非数值/NaN/inf → 剔除并记录样例；
  同一 `(date,symbol)` 重复 → 保留最后一条并告警。
- `forward_return` 大于 1 的数值（如百分数 2.0）不会被自动换算——文档已明确要求小数，避免静默改变口径。


字段口径：

| 指标 | 定义 |
|---|---|
| rank IC | 日度截面 `Spearman(factor_t, forward_return)`；统计量 = 有效交易日均值/标准差/正比例 |
| ICIR | `mean(IC) / std(IC, ddof=1)`，**不年化**；`n<2` 或 `std=0` 时为 `None`（不伪造成 0） |
| t_stat | `ICIR * sqrt(n_days)`，仅描述性参考（不做显著性/多重检验结论） |
| 分位收益 | 每日 `rank(method="first")` 后 `qcut(n)`：1=因子最低 … n=最高；分位内等权取 `forward_return` 均值，跨日等权平均 |
| 单调性 | 分位均值严格递增 `monotonic_up` / 严格递减 `monotonic_down`；另给 `quantile_spearman`（分位序号 vs 均值收益） |
| 多空差 | 每日 `top 分位均值 − bottom 分位均值`；跨日均值/std/IR/正比例 |
| 换手 | `top 分位`相邻两期 `|新集合−旧集合| / |新集合|`（0~1，单边成员替换率；全换=1） |
| 覆盖率 | 每日截面股票数的 mean/median/min/max + 低于 `min_names_per_day` 的日数 |
| 样本数 | 输入行/有效行/坏行/重复行/交易日数/IC 日数/分位日数/两类跳过日数 |

## 4. fail-visible 行为

| 情形 | 行为 |
|---|---|
| 输入非 `DataFrame` / 缺必需列 / 空 DataFrame | 抛 `FactorDiagnosticsError`（CLI 退出码 2，stderr 说明缺哪列） |
| 全部行都是坏行（有效行 0） | 抛 `FactorDiagnosticsError`（附带输入行数/坏行数） |
| 部分坏行 | 剔除；`samples.bad_rows` + `bad_rows` 样例（原因）+ warning；统计基于有效行 |
| 重复 `(date,symbol)` | 保留最后一条；`duplicate_rows` + warning |
| 单日截面 < `min_names_per_day`（默认 5） | 该日跳过 IC/分位；计入 `coverage.days_below_min` + warning |
| 有效 IC 日数 < `min_days`（默认 3） | 不抛错，统计量照算但 warning 提示不稳定 |
| 分位无法切分（截面/并列值不足） | 该日跳过分位；`days_skipped_quantile` + warning |
| 常数因子（无截面差异） | IC 为 `None` + warning（不把 0 当有效信号） |

## 6. 与 Alphalens / Qlib 的差异（刻意收窄）

| 维度 | Alphalens | Qlib | 本工具 |
|---|---|---|---|
| 输入 | prices + factor + group/sector，内部计算 forward returns（多周期） | 表达式引擎 + 数据 Handler（二进制数据仓） | **已对齐面板**：`date,symbol,factor,forward_return`（收益/PIT 由调用方负责） |
| 数据依赖 | pandas 生态（含 matplotlib 可视化） | 自带数据基础设施、模型/工作流 | 纯 pandas/numpy，**零新依赖、零网络** |
| 周期 | 多 period（1/5/10 day）forward return | 任务/模型配置 | **单周期**（由输入面板决定，多次调用可比较多周期） |
| 分组中性 | 支持 groupby sector/group 中性化 | 支持特征处理管线 | 不做行业中性（留作后续扩展） |
| IC/ICIR | IC、IC 均值/标准差、IC 衰减 | 有多类指标 | rank/Pearson IC、ICIR（不年化）、正比例、n_days；**无 IC 衰减/自相关** |
| 分位/多空 | quantile returns、long-short、turnover | 组合回测在引擎内 | 分位收益、多空差 IR、top 分位成员换手 |
| 统计严谨性 | 多种统计与可视化 | 内置评估 | **不做显著性/多重检验/重叠修正**（需要时可另用 `tools/research/stat_utils.py` 的 non_overlap/block bootstrap） |
| 用途 | 因子研究诊断 | 量化平台（数据+模型+回测） | **研究诊断只读**；不产出选股清单、不写策略注册、不接生产 |

> 设计取舍：先把「IC 口径 + 分位 + 多空 + 换手 + 覆盖」固定为**可复现、可嵌入研究脚本**的最小工具；
> 复杂能力（行业中性、多周期衰减、容量/成本、显著性）按需另立模块，避免把未验证口径带进生产。

## 9. 边界 / 未决

1. **单周期**：报告只反映输入面板的 `forward_return` 口径；多周期/IC 衰减需多次调用或后续扩展。
2. **不做行业中性/正交化**：因子与行业/市值暴露的混杂不在此工具内处理（研究侧需自行中性化后传入）。
3. **不做显著性检验/重叠修正**：ICIR、t 仅描述；重叠样本可另用 `tools/research/stat_utils.py`。
4. **不校验 PIT/复权/停牌**：`forward_return` 的 PIT 正确性由调用方负责（本工具只诊断，不充当前视守卫）。
5. **换手口径**为 top 分位成员替换率，与 `bt_harness` 的权重换手（含成本）不同；成本/容量评估仍走 bt_harness。
6. **不接生产**：不产出选股清单、不写策略注册表、不新增 flag/API/服务；接入 S5 监控需另单审批。
7. 新测试未纳入 `test_gate` 套件矩阵（`tools/test_gate.ps1` 不在本单允许文件）——若需进闸，另单把
   `tools/tests/test_factor_diagnostics.py` 加入 tools_key/研究套件（+约 2s）。
