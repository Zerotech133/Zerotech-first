## 1. 结论

1. 新增只读事件研究 harness：输入**事件表**（`date,anchor_symbol,event_id`）、**日线面板**
   （`date,symbol,close`）、**基准**（可选），输出**每事件 CAR[0,+N]**（默认 20 日，可
   `--horizons 5,20,60`）+ **路径/最大回撤/达峰日**，以及事件级汇总
   （`n_events/n_rows/mean/median/std/t/win_rate`）。
2. 事件级统计按 `event_id` 聚类（同事件多标的先取均值，不把 N 只股票当独立样本）；
   `n_events < min_events（默认 30）` → **`insufficient_sample=true` / `verdict=insufficient`**，
   只作「观察支持」上限，不出结论、不伪造显著。
3. **重叠提示**：不同事件 T0 距离 ≤ 最大窗口 → 报重叠对/`overlaps_with`；同事件多标的报
   `event_clusters`；提示需非重叠抽样 + block bootstrap（`stat_utils.py`）。
4. **PIT 纪律**：T0 = 事件日（非交易日顺延到之后第一个交易日）；窗口后数据一律不用，
   T0-1 收盘仅用于事件日收益基准；窗口不足 → 该窗口 `CAR=None` 并标 `insufficient_window`，
   不用未来数据补齐/外推。有专门测试：篡改窗口后数据、T0-1 之前数据后 CAR 不变。
5. 缺列/空表/坏行 **fail-visible**：结构性错误抛 `EventStudyError`（CLI exit 3）；坏行剔除并计数
   入 `warnings`/`event_bad_rows`；事件晚于数据/标的不存在/无前收盘均进 `excluded` 明细。

## 2. 输入契约

### 2.1 事件表 `events`（CSV/JSON 或 DataFrame）

| 列 | 说明 |
|---|---|
| `date` | 事件公告/发布日（可解析日期；非交易日自动顺延到之后第一个交易日 T0） |
| `anchor_symbol` | 锚标的（与面板 `symbol` 同口径；H37 为板块/锚池内个股代码） |
| `event_id` | 事件唯一标识（跨卡/跨锚池；同一事件多标的用同一 id → 事件聚类） |

- 重复 `(date,anchor_symbol,event_id)` 去重（保留首条）+ warning；坏行剔除并留样例。

### 2.2 日线面板 `prices`（CSV/JSON 或 DataFrame）

| 列 | 说明 |
|---|---|
| `date` | 交易日 |
| `symbol` | 证券代码（任意唯一标识） |
| `close` | 收盘价（**应使用复权价**；`daily` 未复权，BACK1 须先乘 `adj_factor`） |

- `close<=0`/NaN/非数值 → 坏行剔除 + 计数告警；重复 `(date,symbol)` 保留最后一条。

### 2.3 基准 `benchmark`（可选）

| 形式 | 说明 |
|---|---|
| 不传 | **全市场等权**：面板内全部标的日收益等权均值（与 `event_study.py` 市场调整法同口径；H37-H39 主基准） |
| `date,return` | 直接使用基准日收益（小数；最 PIT 友好，推荐 BACK1 用预计算基准） |
| `date,close` | 按 `close` 计算日收益（如沪深300 `index_daily`；注意本地仅 2023 起） |

## 3. 口径定义

- **T0**：`date` 当日为交易日则 T0=该日；否则 T0=之后第一个交易日（`t0_shifted=true`）。
- **日度异常收益** `AR_t = anchor_close_t / anchor_close_{t-1} − 1 − bench_return_t`。
- **CAR[0,+N]**：`Σ_{t=T0..T0+N} AR_t`，**含 T0**（用 T0-1 收盘计算事件日收益），
  默认 N=20（共 21 个日度 AR）；`--horizons` 可多窗口（5/20/60 对应预注册短/中/长窗）。
- **路径**：最大有效窗口的累计 AR 序列；`max_drawdown`=路径最大回撤（负值），
  `peak_day`=累计收益达峰日（T0 后第几天，从 1 起）。
- **事件级统计**：先按 `event_id` 对多锚取均值 → 再计算 mean/median/std(ddof=1)/t/win_rate；
  `t = mean/(std/√n)`（n≥2 且 std>0，否则 None）；`win_rate = P(CAR>0)`。
- **样本门禁**：`n_events < min_events（默认 30）` → `insufficient_sample=true`、
  `verdict="insufficient"`（H37-H39 预注册：n<30 一律最高「观察支持」）；达到则
  `verdict="observation"`——**仍不是 pass/可上线**（四关+影子盘+人工批准另说）。
- **重叠**：不同事件且 |T0 距离| ≤ 最大窗口 → 重叠对（观察窗不独立）；同 `event_id` 多锚 →
  `event_clusters`（统计已聚类）；提示用 `stat_utils.non_overlap_t / block_bootstrap_p`。
- **排除状态**（`excluded`）：`event_after_data`（事件晚于数据末日）、`anchor_missing`、
  `no_prior_close`（T0 为面板首日）、`insufficient_window`（窗口不足任何 horizon）、
  `data_gaps`（窗口内价格/基准缺失）。

假设卡要求「T0 信号 → T+1 收盘执行 → T+2 起算收益」时，BACK1 需在报告里单列滞后敏感性
（或先用本工具看 CAR[0,N]，再用 `bt_harness.py` 做执行/成本后口径），**不得把本工具的 CAR

## 10. 边界 / 未决

1. **n<30 不出结论**：当期三卡各仅 1 次真实事件（计划 §8.8）→ 只能「观察支持」；
   历史类比事件须 DATA1 双源核对后由 BACK1 建表（本工具不造事件日期）。
2. **不做统计修正**：重叠仅提示；非重叠抽样/block bootstrap 由 BACK1 用 `stat_utils.py`；
   本工具 t 值仅描述（n 小/重叠时不可作显著性依据）。
3. **不做执行价/成本/容量**：CAR 为收盘价环比口径；T+1 执行、30bp、滑点、涨跌停/停牌由
   `bt_harness.py` 或 BACK1 另做（本工具有严格的 PIT 窗口纪律，但不建模交易约束）。
4. **板块/行业基准需自建**：本地无申万行业指数；H37 板块/H38 传媒/H39 电子对照需成分合成
   （PIT 成员 + 复权），本工具只接受已完成基准序列。
5. **复权由调用方负责**：面板 close 必须是复权价；用未复权 `daily.close` 的 CAR 不可用。
6. **假设卡文档未合并**：`2026-11-01_H37_H39策略假设_v1.md` 在 `WO-STRAT-HYP` worktree；
   本工具不复制该文档，引用路径与 §引用（合并顺序不影响本工具代码）。
7. 新测试未纳入 `test_gate` 矩阵（`tools/test_gate.ps1` 不在本单允许文件）——如需进闸另单
   把 `tools/tests/test_hypothesis_event_study.py` 加入 tools_key/研究套件（+约 3s）。
