> 来源：全代码审计发现 `Hermes/`（745 条 ruff 问题）与 `AI/111111` 等实验目录混在自研仓库内，会污染门禁/健康度指标。
> 结论：**先定边界、后决定是否迁出**；边界内不动、不计入自研指标。

## 一、边界清单（2026-10-28 审计实测）

| 目录 | 性质 | 证据 | 处置 |

## 二、口径（生效）

1. **健康度指标**（F821/except-pass/ruff 基线）只统计**自研主线**：`agent_platform / portal / quant_backtest / k_stock / news_collector / jev-eval / osint_video / common / analysis / tools / ops / ollama_service / data_sources`；
2. `Hermes/`、`AI/111111/`、`zerobound-kg/`、`deliverables/` 等**不计入**；
3. 扫描/守卫脚本的 exclude 列表必须包含上述目录（本判例为权威口径，脚本与本表同批更新）；
4. 新代码**禁止**放进 `Hermes/` 与 `AI/111111/`；实验代码放 `experiments/` 或沙箱分支，不入主线门禁。
