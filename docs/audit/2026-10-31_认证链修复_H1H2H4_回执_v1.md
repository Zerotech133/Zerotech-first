## 1. H1：`/api/os/*` 认证可伪造 + 预览存储型 XSS

**修复**（`portal/api_os_goal.py`）
- `_os_goal_post` 认证收敛为**三选一**：`peer 回环直连`（本机进程）/ `_check_portal_token()`
  （X-Portal-Token）/ `有效 zb_session`（`auth_gateway.STORE` 校验，取会话 sub）。
- **删除** `X-OS-Page`、私网 `Origin`、`X-Real-IP` 信任分支（审计 PoC 可伪造即通过）。
  旧函数 `is_local_page_request`/`_origin_is_local_entry` 仅保留为 **DEPRECATED 恒 False**
  兼容函数（`_mixin_integrity` 函数基线要求不丢函数名；新代码禁止使用）。
- workspace 预览：**一律 `text/plain; charset=utf-8`** + 响应头
  `X-Content-Type-Options: nosniff`（`index.html` 不再以 HTML 执行 → 存储型 XSS 失效）。
- 新增 `_zb_session_sub(headers)`：Cookie= zb_session → 会话 sub（失效/异常一律 ""，fail-closed）；
  `handle_post(..., auth_sub=)` 把会话 sub 传入受控链（供 H2 signer 使用）。

**行为变化**：8734 上未登录且无 token 的 `/api/os/*` POST → **403**（旧：伪造头可通过）；
本机直连 8091 的 peer 回环仍放行；同机浏览器经 8734 仍自动带注入 token；LAN 浏览器需 SSO 登录。

## 2. H2：`sign_real_grant` 任意 nonce 伪造"真实签准"

**修复**（`portal/os_controlled.py`）
- 新增**服务端一次性 nonce**：`POST /api/os/item/<iid>/grant/nonce`
  （`issue_grant_nonce`）绑定 item/动作集合/签准方式/**会话 sub**，TTL 默认 **120s**（30–600 夹取），
  进程内字典 + 锁，最多 1024 条自动淘汰最旧；`_consume_grant_nonce` **先 pop 再校验**（重放必失败）。
- `sign_real_grant(..., signer_id=)`：必须由服务端签发且未消费的 nonce；signer **取登录会话 sub**
  （不再硬编码 `laotian`）；`len(nonce)>=8` 自造校验删除。
- 拒绝矩阵：重放 / 过期 / 自造 nonce / 错 item / 错动作 / 错方式 / 伪造 signer / 无会话 → ContractError（API 422）。
- `decide_l2_approval`（C1 审批）仍为旧 nonce 校验——**本单 H2 范围外，未改**（见 §5 未决项）。
