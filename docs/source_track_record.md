## 统计口径（未来脚本依据）
- **正确** = `admiralty_code` 可信度 1-2（已确认 / 很可能真）且与被核验事实一致
- **错误** = 可信度 4-5（可能假 / 很可能假）或被证伪
- **待定** = 可信度 3 或 6（无法评估）
- **正确率** = 正确 / (正确 + 错误)，待定不计入分母
- **样本数** = 该源在对账底表中被分析岗评估的 code 数

> 局限性：track record 仅在分析岗实际回填 `admiralty_code` 后才产生数据；本席职责是建好结构与采集链路，不替分析岗裁事实，亦不预填表现数字以免污染校准基准。
