# 扩展契约 v1（O3）

- **日期**：2026-10-27｜**依据**：O3 优化项；参考 Dify 插件独立仓、OpenHands extensions 仓库、Open WebUI 插件类型；边界遵循 ADR-013（不拆仓/不做插件市场）
- **落地**：`extensions/<name>/manifest.json` + `extensions/_schema/manifest.schema.json` + `tools/extension_lint.py`
- **性质**：声明契约（镜像）；**不改变运行配置**（`servers.json`/`tool_matrix` 仍为运行真源，O3-P2 再评估生成）

## 一、为什么

工具/MCP/skill 散落在 `servers.json`、`tool_matrix`、代码里，缺统一"这个扩展是什么、谁负责、能做什么、只读吗、怎么测"的声明。
统一 manifest 后：可 lint、可对照质量分级、可生成文档/工具矩阵（分阶段），也是 O5/O6 的基础。

## 二、manifest 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | kebab-case，与目录名一致 |
| `version` | ✅ | `x.y.z`；契约变更升 minor |
| `type` | ✅ | `tool` / `mcp` / `skill` / `filter` |
| `owner` | ✅ | 席位/责任人（需在 org 域内） |
| `description` | ✅ | ≥8 字，说明"做什么" |
| `risk` | ✅ | `read-only`（默认）/ `write`；写必须 `l2_approved=true` |
| `transport` | 视类型 | `stdio`/`http`/`cli`/`inprocess` |
| `entry` | stdio/cli 必填 | 仓库相对路径且存在 |
| `url` / `token_env` | http 必填 | https；token 仅 env（大写变量名），URL 禁 token 参数 |
| `allow_tools` | 建议 | 工具白名单数组；`"*"` 视为 scope 宽（质量分级 warn） |
| `docs` / `tests` | ✅ | 路径必须存在；≥1 |
| `compat` | 可选 | `min_platform` / `python` |
| `lifecycle` | 可选 | `active` / `deprecated` / `retired` |

## 三、规则（lint 自动检查）

1. 必填字段/类型/格式（name/version/type/risk/transport/token_env）；
2. 路径存在性（entry/docs/tests）；
3. http 安全（https、禁 URL token、必须 token_env）；
4. 写风险必须有 L2 标记；
5. 禁止明文 token 形态；
6. name 唯一（跨目录）；
7. name 与目录一致性（warn）。

```powershell
python -X utf8 tools/extension_lint.py           # 人读
python -X utf8 tools/extension_lint.py --strict  # 有 error rc=1
python -m pytest tools/test_extension_lint.py -q # 单测
```

## 四、生命周期

- `active`：在用；变更需更新 version + docs；
- `deprecated`：保留但不建议新用；须在 notes 写替代者与预计退役时间（≥90 天，参考 HA deprecation 纪律）；
- `retired`：声明保留、文件/入口迁移/删除（删除走回收站 + L2 若涉服务）。
- 不允许删除历史 manifest（与 ADR 一样保留决策痕迹）。

## 六、与其它项关系

- **O2 质量分级**：manifest 的 `risk/docs/tests/allow_tools` 可作为 tool 对象证据来源（P2 迁移）；
- **tool_matrix**：P2 可用 manifest 生成矩阵（先双写对比，再切）；
- **O5 E2E**：每个扩展至少 1 个场景（只读/失败路径）；
- **O6 Agent 运行契约**：扩展与 run/event 契约解耦（manifest 不定义协议）。
