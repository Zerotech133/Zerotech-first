# Agent 运行契约 v1 · 设计稿（O6）

- **状态**：Proposed（设计稿；实现前需 ARCH1/QA1 复核）
- **日期**：2026-10-27｜**性质**：纯文档，不改代码/服务
- **配套**：[ADR-014](../adr/ADR-014-agent-run-contract.md)

## 一、范围

定义 Agent 一次执行的统一数据契约：`Run` / `Event` / `Conversation`，以及版本兼容规则。
适用于：军团 8796、agent_platform engine、飞书 bot、后续评测/看板/diagnostics 消费。

**非目标**：不替换现有 trace/dev_events；不引入消息队列/分布式追踪后端；不在本单写实现代码。

## 二、对象定义

### 2.1 Run（一次执行）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `contract_version` | string | ✅ | 如 `1.0.0` |
| `run_id` | string | ✅ | 全局唯一（ULID/uuid4），入口生成、全链路透传 |
| `conversation_id` | string? | 否 | 多轮对话时关联 |
| `agent` | object | ✅ | `{name, runtime_id, seat?}` |
| `kind` | enum | ✅ | `chat` / `task` / `tool` / `eval` |
| `status` | enum | ✅ | `pending` / `running` / `succeeded` / `failed` / `cancelled` / `timeout` |
| `started_at` / `ended_at` | ISO8601 | ✅/否 | UTC，带时区 |
| `input` | object | ✅ | 摘要或脱敏引用（禁明文凭据/PII） |
| `output` | object? | 否 | 摘要/引用 |
| `error` | object? | 否 | `{code, message, retryable}` |
| `trace_id` | string? | 否 | 复用现有 trace 体系 |
| `usage` | object? | 否 | `{prompt_tokens, completion_tokens, cost_usd_est}` |
| `artifacts` | array | 否 | `[{kind, path/url, sha256?}]` |
| `meta` | object? | 否 | 扩展键值（只增不改语义） |

### 2.2 Event（run 内有序事件）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `contract_version` | string | ✅ | 同 Run |
| `event_id` | string | ✅ | 唯一 |
| `run_id` | string | ✅ | 所属 run |
| `seq` | int | ✅ | run 内单调递增 |
| `type` | enum | ✅ | `run.started` / `llm.request` / `llm.response` / `tool.call` / `tool.result` / `run.finished` / `error` |
| `ts` | ISO8601 | ✅ | UTC |
| `payload` | object | ✅ | 各类型自定，禁止凭据 |
| `trace_id` / `span_id` | string? | 否 | 与现有 trace 对齐 |

### 2.3 Conversation（可选，多轮容器）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `contract_version` | string | ✅ | 同 Run |
| `conversation_id` | string | ✅ | 唯一 |
| `participants` | array | ✅ | `[{type:human/agent, id, name?}]` |
| `messages` | array | 否 | `[{role, content_ref, ts}]`（内容引用/摘要，不存密钥） |
| `run_ids` | array | 否 | 关联 run |

## 四、兼容版本策略

- `contract_version` 语义化：`major.minor.patch`；
- **minor**：只增字段/枚举值（消费者必须忽略未知字段与未知事件类型）；
- **major**：删/改字段必须提供新版本并行输出 ≥90 天，并在 `docs/specs/` 记录迁移说明；
- 每个入口写契约时先跑 schema 校验（轻量 JSON Schema），失败按 `fail_visible` 记录，不阻断主链路；
- 兼容期结束后旧字段标记 deprecated（不立即删除）。

## 五、与现有系统的映射

| 现有 | 契约映射 | 说明 |
|---|---|---|
| `agent_platform/observability/trace.py` spans | `Run.trace_id` + `Event(ts/type)` 的细化 | 不改 trace 表；run 与 trace 可互查 |
| `tools/events.py` dev_events（15 类） | 独立保留（开发审计层） | 不混进 Agent run 契约；可用 run_id 关联 |
| `agent_platform/legion_command/serve.py` | P2 首批入口 | 生成 run_id/事件 |
| `agent_platform/engine` | P2 首批入口 | chat/工具调用打点 |
| `diagnostics.py`（O7） | P3 消费方 | 诊断包增加最近 run 摘要 |
| 评测/看板 | P3 消费方 | 统一统计成功率/时延/成本 |

## 六、落地阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| **P0（本单）** | ADR-014 + 本设计稿 + 字段表/示例 | ARCH1/QA1 评审通过 |

| P4（收敛） | 旧字段 deprecation | 90 天迁移记录 |

## 七、待评审问题

1. `agent` 标识：席位名 + runtime_id 双带（建议是）；
2. `status` 终态是否含 `cancelled`/`timeout`（建议含）；
3. `conversation` 是否作为必选（建议可选）；
4. P2 首批入口选 `legion_command/serve.py` + `agent_platform/engine`（建议是）；
5. 存储先用 append-only JSONL（建议是，不引新数据库）。

## 八、风险与回滚

- 设计不改运行代码，无风险；
- P2 若上线，契约写入失败 fail-visible、不影响主链路；可用开关关闭；
- 契约文件可回滚（git revert），历史数据保留。
