## 二、实现说明（首批）

- `tests/e2e/test_smoke_services.py`：E2E-01/02/03
- `tests/e2e/test_smoke_tools.py`：E2E-04/05/06/07
- `tests/e2e/test_smoke_bot.py`：E2E-08/09（心跳新鲜度 + `feishu_mock_harness.py` mock 回执；不发真实消息）
- `tests/e2e/test_smoke_failure.py`：E2E-10（离线端口可读清单、401 可读 JSON、strict 不因离线判负）
- 依赖：服务在线（8091/8734/8796）、bot 心跳/日志新鲜；**不依赖 LLM / 不发飞书消息**。
- 运行：
```powershell
python -X utf8 tools/e2e_run.py            # 全量首批 + artifact
python -X utf8 tools/e2e_run.py --list     # 列出场景
python -m pytest tests/e2e -q              # 直接跑测试
```
- artifact：`agent_platform/data/dev/e2e/<date>-<ts>.json`（passed/failed/duration/exit/场景清单）。

## 三、边界

- 首批是"**冒烟**"：HTTP 200 + 结构存在；E2E-09 用 mock `send_text` 验证命令→回执，不发真实飞书消息。
- 服务离线时测试失败是**预期行为**（E2E 的意义），不用 skip 掩盖；环境问题在测试输出里可判。
- 不写生产数据；8091/8796 只 GET；工具脚本用 `--print-only/--json` 只读模式。

## 四、规划场景的下一步
