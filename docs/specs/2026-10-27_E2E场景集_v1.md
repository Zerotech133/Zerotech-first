## 二、实现说明（首批）

- 运行：
```powershell

python -X utf8 tools/e2e_run.py --list     # 列出场景
python -m pytest tests/e2e -q              # 直接跑测试
```

## 三、边界

- 首批是"**冒烟**"：HTTP 200 + 结构存在；不做飞书真实消息（E2E-09 需测试应用/mock，另批）。
- 服务离线时测试失败是**预期行为**（E2E 的意义），不用 skip 掩盖；环境问题在测试输出里可判。
- 不写生产数据；8091/8796 只 GET；工具脚本用 `--print-only/--json` 只读模式。
