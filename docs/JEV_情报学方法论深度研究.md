## 一、把讲义放回学理坐标

### 1.1 讲义的原文出处（不是原创定义，是国内教材标准表述）

讲义「情报是指被传递的知识或事实，是知识的激活……知识性 / 传递性 / 效用性三属性」，与上列教材逐字对应：

- 清华大学出版社《信息与信息检索》§1.1.3：情报「为一定目的收集和传递的有特定效用的知识」，三属性为知识性、传递性、效用性；「情报就是流动的知识」。
- 清华大学出版社《文献检索概述》§1.1.3：逻辑关系「情报包含于知识，知识包含于信息」；情报具传递性、知识性、时效性、针对性、非公开性。
- 严怡民、马费成《情报学概论》(1983)：「情报就是作为人们交流对象的有用知识」；钱学森：「情报是人们的思维和行为所需要的、激活了的知识和信息」；肖自力 (1981)：知识中「动态的、有针对的、有时间性的、为未来服务」的部分。
- 国际关系学院《中国情报学论纲》：情报定义多达 **191 种**；1992 年第八次全国科技情报工作会议把「科技情报」改称「科技信息」后，情报/信息混用加剧。

### 1.2 最关键的一刀：Intelligence ≠ Information

《中国情报学论纲》的裁定比讲义更硬：

> 情报源于知识、高于知识，是对知识的激活；是对信息的解读、判断和分析；是人脑思维的产物，具有**对抗性、战略性、智能性、增值性和行动性（Actionable）**。
> 信息是原料，情报是产品；「Information 的 **Intelligence 化**」。情报的英文应对应 **Intelligence 而非 Information**。

西方口径同构：

- **DoD / ODNI（法源 PL 109-163）**：OSINT 是「由公开可得信息产生，并被及时收集、开发利用、分发给**适当受众**，以满足**特定情报需求**为目的的情报」。
- **Robert David Steele 四分法**：OSD（原始公开资料）→ OSIF（广泛分发的公开信息）→ OSINT（定向发掘、提炼、分发以回应特定问题）→ OSINT-V（经证实）。**信息是输入，情报是输出**。
- **ODNI 2025-12 国会证词**：切割 PAI / CAI / OSINT / GEOINT；OSINT 仅来自非涉密 PAI 或 CAI；OSINT 占《总统每日简报》来源 20–25%（特定口径，不可外推）。
- **NATOTerm**：OSINT 含「有限公开传播或获取范围的非秘密信息」（灰色文献）。

### 1.3 由此得到一条判定链

```
数据 / 原始记录  →  信息（OSD / OSIF）  →  按特定需求加工、核验、面向特定受众  →  情报（Intelligence）
                                                    ↑
                                      讲义说的「活化 / 效用性」就发生在这一步
```

**判据不是「数据多不多、算得深不深」，而是「有没有特定需求牵引 + 有没有面向特定受众的成品 + 有没有核验与分析」**。这条判据是下面所有结论的地基。

## 二、最深的一刀：JEV 现在生产的是「态势描述」，不是情报成品

### 2.1 用 Sherman Kent 的四类产品对位

Kent《Strategic Intelligence for American World Policy》(1949) 把情报生产分四类：basic descriptive（基础描述）、current reportorial（当前事实报道）、current evaluative（当前意义评估）、**estimative（估计性，长程投影与预警指标）**。CIA《Curing Analytic Pathologies》进一步区分：

> **warning 与 estimative intelligence 是人的「周边视觉」**：低分辨率、宽视野，对动态变化线索敏感，功能是**防突袭与预置反应**；而 situational awareness / current intelligence 必须 **evidence-based**。
> 估计性产品「不是对未来的预测，而是对事件可能走向的深思熟虑的判断（considered judgements as to the likely course of events）」，它**用证据硬度换前瞻性**，本质是推理与有根据的推测。

这直接给老田「JEV 不是预测器」的裁定提供了学理背书，并且指出它应该**细分为三类产品、三套验收标准**，而不是共用一个「准不准」：

| 产品类型 | 学理要求 | JEV 对应物 | 应有验收标准 | 状态 |
|---|---|---|---|---|
| 描述 / 当前事实 | 证据为本、可复核 | `graph_json` 整图、`boards`、`network`、`minute_read` 三档台账、三旗标 | 结构同构、字段无损、来源可追溯 | 【已具备】8091 只读比对 15/15、原型 SHA256 逐字节一致 |
| 当前意义评估 | 事实与判断分栏、置信度表达 | `jev_pattern.py` 命中、`summarize`、11-06 判例 | 概率与置信度分开表述、标明哪些是分析人员判断 | 【部分】三旗标只覆盖置信度侧，缺概率词表 |
| 估计 / 条件推演 | 允许以置信度换证据硬度，须列备选与证伪条件 | P1–P8「预期演化 / 分化节点假设」 | 竞争假设、诊断性证据、后验回流 | 【缺口】假设已显式登记，但无竞争假设、无证伪条件、无回流 |

### 2.2 缺口 S0（本轮新增，优先级最高）

JEV 当前产出是 `graph_json` 整图 + pattern 命中 + 覆盖率台账。按 Steele 链与 DoD 定义，这停在 **OSIF + 态势评估（JDL L2）**：数据齐、结构清、可追溯，但**没有 PIR（特定情报需求 / Priority Intelligence Requirement）**，也没有**面向特定受众的成品**，更没有「哪些是事实、哪些是判断、置信几何」的分栏。

**这不是算法缺陷，是产品定义缺口。** 补法不是加模型，而是给每个输出挂三件东西：

1. `requirement_id`：这次输出回答的是哪个具体问题（例如「新型电力的涨停是消息驱动还是价格先行」）；
2. `product_kind`：描述 / 评估 / 推演 三选一，决定验收标准；
3. `fact_vs_judgement`：事实字段与判断字段物理分栏，判断项带 Kent 式概率词 + 独立置信度标注（ICD 203 禁止「高置信度认为很可能」这类混写）。

**这与老田的三旗标口径完全不冲突**：`coverage_only / gate_eligible=False / calibrated=False` 是在说「置信度不够」，S0 是要把这份「不够」写得让受众能正确消费，而不是让全绿回执盖住它。

## 三、上一轮三个缺口的全网复核

### 3.1 缺口②「SNA 中心度量化」—— **撤回上一轮的实现建议**

上一轮我写「纯加字段、不重算」。全网证据表明这个建议**过于轻率**：

| 学理限制 | 出处 | JEV 是否踩中 |
|---|---|---|
| 中心度内嵌未声明的**过程假设**（最短路 / 转移式 / 流等权 / 边恒可用）；真实传播不匹配则结果**不可解释** | Borgatti (2005)；Springer《A systematic evaluation of assumptions in centrality measures by empirical flow data》 | **踩中**：板块联动是资金/情绪扩散，接近「并行复制（duplication）」而非「不可分割实体走最短路（transfer）」，介数中心度的前提根本不成立 |
| 数据**不完整性**：缺失会被算法读成「没有关系」 | Sparrow 链路分析三问题 | **踩中**：页面改造实测 `20261110` 的 39 条边里 **24 条 `cross` 边端点不在 `network.nodes`**（69 点只含板块与部分个股/消息节点）；在此图上算中心度会把「端点缺失」算成「该节点不重要」 |
| 小网络（节点 <20）指标不稳定，增删一条边可致排名剧变 | SNA 方法综述 | **踩中**：11 个板块的子网远低于阈值 |
| 中介中心度对扰动最不稳；采样下与全网结果相关性最差 | Bolland / Brandes | 踩中 |
| 「有联系 ≠ 有关系」；中心度是拓扑位置，**不是影响力、更不是因果** | 反恐情报 SNA 实务 | 踩中：`silent`（无消息同涨）边本身只是共现 |
| 中心度可被伪造（Sybil / 记录偏倚放大） | 对抗与偏差研究 | 部分：社交榜单本身有人为刷榜可能 |

**修正后的建议（按 S 级排序）**：

1. **不要先上中心度**。先做三前置：① 补全或显式标注 `cross` 边端点（可计数、不可绘图分开）；② 书面声明扩散过程模型（最短路 / 随机游走 / 并行复制）再选指标；③ 做增删边重算的稳健性检验，排名剧烈变化则结论只能作线索。
2. 更贴合的替代：用**不依赖过程假设**的入度/出度 + 时间领先计数——JEV 已有 `lead` 边、`Δmin` 带符号、`cross_summary`，天然是「谁先动、谁被跟随」，比套介数更诚实。
3. 若一定要算，中心度**只输出为线索字段**，不得进判定闸、不得写成「板块重要性」。

> 这一条是本轮「结合全网」最实在的价值：外部理论不是给原结论找背书，而是**推翻了其中一个建议**。

### 3.2 缺口③「隐含假设登记」—— **升级为 ACH 竞争假设矩阵**

**先订正事实**：`docs/jev_pattern_spec.md` §48–50 已明确写着匹配器采用「≥2 维度命中即记」的宽松策略，且「下列『预期演化』均为**待验证假设**，未经 P5 案例库检验前不得当作结论」；P1–P8 每个都带「分化节点假设」。**所以假设登记不是从零建，本仓早有，且比多数系统自觉。**

真正的问题在**推理方向**。Heuer《Psychology of Intelligence Analysis》(CIA, 1999) 与 IARPA 的归纳：

- 人脑默认 **satisficing**（接受第一个说得通的解释），需要 **SAT / ACH** 强制程序化考虑替代解释；
- ACH 核心是**诊断性（diagnosticity）**：与所有假设都一致的证据**诊断价值为零**；不是找证据支持首选假设，而是**找反证去排除**；「最可能的情景不是确认证据最多的，而是反证最少的」；
- 八步：假设集（含最坏情形与欺骗路径）→ 证据与论证（**含假设与逻辑演绎**）→ 按**证据逐行**扫矩阵（不是按假设逐列）→ 精炼 → 不一致性 → **敏感性分析**（关键证据若错/被误导/可另解，结论怎么变）→ 结论 + 被排除的备选及理由 → **里程碑作为未来指标**；
- 常见偏差：confirmation bias、anchoring、availability、mirror imaging、groupthink、motivated reasoning；制度化解法如以色列 Aman 的 **Ipcha Mistabra（魔鬼代言人）**。

**对 JEV 的锐利批评**：`≥2 维度命中即记` 是**数确认项**。三维度（资金 / 社交 / Δmin）里凑够两个就记一个 pattern，正是 ACH 要防的「用吻合度代替诊断力」。一个与 H1/H2/H3/H4 都不矛盾的证据（例如「当天有涨停」）不该贡献任何分数。

**落地映射（纯口径重构，零代码改动即可先写进规格）**：

| 竞争假设 | 预期看到的诊断性证据 | JEV 已有字段 |
|---|---|---|
| H1 消息驱动 | 新闻在前、封板在后，`echo_ratio` 高 | `delta_kind`、`echo_ratio`、`T_news_first` |
| H2 价格先行、消息追认 | Δmin 为正且大，消息 `ts_kind` 落在盘后 | `Δmin` 带符号、`ts_kind` |
| H3 散户接盘 | 主力大单买入但全档净流出，散户榜热、机构榜冷 | `divergence`、`guba_rank`、`xq` 人气榜 |
| **H4 采集覆盖伪影** | 锚点缺失、`minute_read=fail`、快照不合规、`unpriced` | `unpriced`、`minute_read` 三档、P2.3 三旗标、`AVAILABILITY_PROXY_SIGNALS` |

**H4 必须进矩阵**，这是 JEV 相对通用情报场景最特殊的一条：`JEV_P5_2_单日可行性验证.md` §5.1 已经抓出 `time_ready` 实为大盘/小盘覆盖偏倚冒充信号分化（标记 `AVAILABILITY_PROXY_SIGNALS` + `countable=False`）。把「数据没采到」列为与业务假设**平权的竞争解释**，才不会再出第二次伪分化节点。

**「不吠的狗」条款（本轮最硬的约束）**：IARPA 明确指出，**缺失指标 ≠ 事件不会发生的证据**；只有能证明「采集姿态足够稳健、若发生必被检出」时，`absence of evidence` 才能升格为 `evidence of absence`。这条应成为 JEV 的显式闸门，约束：

- `jev_deltamin_spec.md`：锚点缺失 → `unpriced`，「绝不硬算」【已对齐，且比多数系统严格】；
- `jev_gate_a2_spec.md` §五：**信号可达性天花板 51.8%**（OSINT 覆盖率天花板）——这是本仓对「采集覆盖充分性」给出的量化边界，正是把「无信号」解释为「无事件」之前必须出示的那张证明【已对齐】；
- 同文：**48.2% 涨停票三天内零新闻 → 问题域外**，任何 OSINT pattern 都不可能命中它们，不是引擎不行【已对齐】；
- `jev_gate_a2_spec.md` §十一：抽 1,500 条 `stocks` 空新闻，**99.7%（1,495/1,500）全文不出现任何 A 股简称** → 判定「可达率 69.9% 已近现实上限，过闸只能扩新闻源而非修抽取规则」【已对齐：这是目的性筛选，且「归一化会制造采集越差覆盖率越好看的反向激励」正是排除偏见】。

**ICD 203 补充要求**：产品须交代底层来源/数据/方法的质量与可信度，**区分「情报信息」与「分析人员假设/判断」**，用固定概率词表（Kent《Words of Estimative Probability》：almost certain ≈93%、probable ≈75%、chances about even 50%、improbable ≈30%、almost impossible ≈7%），且**概率（likelihood）与置信度（confidence）必须分开**，禁止混在一句。JEV 的三旗标只覆盖置信度侧；概率词表与事实/判断分栏是 S0 的一部分。

### 3.3 缺口①「回流闭环」—— 学理坐实，并给出台账数据模型

- **Hulnick (2006)《What's Wrong with the Intelligence Cycle》**（该刊阅读量最高论文之一）：搜集与分析**并行**而非串联；决策者常希望情报**支持**既有政策倾向而非告知（确认偏误）；模型缺消费与反馈、**stovepiping（烟囱化阻止跨手段交叉验证）**、无法定位错误来源。
- **Brunel《The Intelligence Cycle is Dead, Long Live the Intelligence Cycle》**：区分概念论/程序论；主流立场是「**作为启发式保留、作为操作模型废弃**」。
- **Shabtai (BESA, 2025)**：评估一旦交付就「像混凝土一样凝固」，因为要显得专业（不因客户互动而改、不频繁更新）；方案是把交付视为**过程的开始**，按三类参数持续复审：**(a) 验证与效度**（发展态势强化还是削弱评估）、**(b) 评估语境**（即使目标未变，周边因素变了）、**(c) 评估层级**（战略预警与战役战术预警的传导）。
- **贝叶斯增量更新**：`P(H|E) = P(E|H)·P(H)/P(E)`；**更新幅度应与证据的诊断性成比例**——弱证据微调、强证据显著调整、**缺失证据不更新**；Tetlock 超级预测者更新频繁但每次克制；**更新不足（锚定）比更新过度更常见**；须有可追溯日志、日终复盘被证伪假设。理论风险：分布式多源系统各自一致的独立更新可能产生逻辑不一致结论（SWC/WAC 修正）。
- 中文警务实证：「信息采集支撑情报研判、研判辅助参谋决策、**参谋决策倒逼信息采集**」闭合回环；「研、交、办、督、结」闭环；四色预警指令把成品推给执行单元并回收反馈。

**→ JEV 台账字段建议**（直接复用已验收的 `ingest_audit` append-only 形态）：

```
hypothesis_id       # 对应 P1–P8 或 ACH 矩阵行
product_kind        # 描述 / 评估 / 推演
prior               # 先验（Kent 概率词 + 数值区间）
evidence_id         # 指向 source_sig / 快照文件
diagnosticity       # 该证据对哪些假设有区分力（ACH 逐行）
likelihood_ratio    # 似然比；缺失证据恒为「不更新」
posterior           # 后验
falsified           # 被证伪标记
update_ts           # 更新时刻
review_params       # Shabtai 三参数：效度 / 语境 / 层级
```

**关键**：现在的 P5.2 只算了 T+1 后验收益，没有把它写回假设；台账要有 `falsified` 与 `posterior`，否则「回流」只是记账不是修订。

## 四、新增框架一：JDL L0–L5 能力坐标

上一轮只能说「多源融合要降一格」。全网给出精确坐标：

### 4.1 multi-source 与 multi-INT 不是一回事

| | 定义 | 难点 | JEV |
|---|---|---|---|
| **multi-source** | 合并**同类**报文（三部雷达看同一架飞机），语义一致 | 运动学关联、概率数据指派 | — |
| **multi-INT** | 跨门类（HUMINT/SIGINT/IMINT/OSINT/FININT…），语义不等价、置信度不可比 | 来源归属与内容同等重要 | — |
| **JEV 实际** | 资金、社交、时间**全是公开市场数据，同属 OSINT 一路** | 同一源内的**多模态交叉** | 【定性】学理上属 multi-source 的宽义，但**不是三类情报手段融合** |

写材料时必须说「同一源内多模态交叉」，不能写成「多源情报融合」。学理结论（单手段不可靠、须综合研判）依然成立，且 JEV 执行得更严（「结论必须多维度交叉」）。

### 4.2 JDL 六级对位（JDL/DFIG 修订版）

| 层 | 学理定义 | JEV 现状 | 状态 |
|---|---|---|---|
| **L0** 源预处理 | 信号/像素级、文本信息抽取；压缩数据保留有用信息 | 采集工位产出 parquet / JSON 快照，`tools/*_fetch.py` | 【存在】且物理隔离 |
| **L1** 对象提炼 | 时空配准、关联、聚类、身份融合、剔除虚假目标 | 6 位代码归一化、涨停自算（判例 #25）、`stock_basic.industry` 划板块 | 【存在】 |
| **L2** 态势评估 | 建立对象间关系、识别重要活动与事件模式 | `network.nodes/edges`、`boards`、`focus.timeline`、`lead/cross/silent` 传播链、`cross_summary` | 【存在·主战场最完整】 |
| **L3** 影响评估 | 评估影响、投影未来、风险与机会 | P1–P8「预期演化 / 分化节点假设」是雏形，但被三旗标压住 `gate_eligible=False` | 【部分·有雏形未兑现】 |
| **L4** 过程优化 | **按融合需求反向调配采集资源**、监控优化整体过程 | **无**。181 表 225GB 只消费 5 张（<4%） | 【缺口】 |
| **L5** 认知优化 | 人机交互、认知层优化、信任/负荷/注意 | 自包含查看器 + 三旗标常驻免责带 + `audit` 端点 | 【部分】 |

**L4 是本轮最有价值的新定位**：老田那条「数据利用率的账要定期算：181 张表只消费 5 张，真正该投入的是已付费/已接入但没用的那 175 张」，在 JDL 里的正式名字就是 **Level 4 Process Refinement**——不是「继续加采集源」，而是**由研判侧的空缺反向决定该采哪些表**。它与 §3.3 中文警务「决策倒逼信息采集」、与「回流闭环」是**同一个能力的三种说法**。三条线索在此汇合。

### 4.3 顺带一个反直觉结论：JEV 的融合层级低，但这是对的

三层融合（数据级 / 特征级 / **决策级**）里，JEV 是**决策级**：资金、社交、Δmin 各自判定，再合并结论。学理上决策级精度最低、信息损失最大，但**稳健性、抗单模态失效、灵活性最高**。这恰好与三旗标「不校准不进闸」的保守口径一致——**在 calibrated=False 的阶段，稳健比精度重要**。写材料时不必把「没做特征级融合」当缺陷。

## 五、新增框架二：Admiralty 双维信源分级

### 5.1 标准

NATO / AJP-2.1 / STANAG 2511 / 英 JDP 2-00 (2023) 的 **Admiralty Code**：**来源可靠性 A–F × 信息可信度 1–6，两维独立**，组成 `B2`、`F6` 这类编码。

- A–F：完全可靠 / 通常可靠 / 比较可靠 / 通常不可靠 / 不可靠 / **无法判断**；
- 1–6：已确认 / 很可能为真 / 可能为真 / 存疑 / 不可信 / **无法判断真伪**；
- **三条铁律**：两维独立（可靠来源可传错误信息 A4/A5，首用来源也可给出被证实信息 F1）；**F 与 6 不是「差」而是「无从判断」**，F6 也可能完全准确；评级**动态**，新证据可升可降。
- 中国 **GB/T 37228-2018** 附录 D 给出几乎同构的表 D.3 / D.4，并明确「两者相互独立」「级别划分并不存在渐进关系」，E1、A5 均为合法组合。
- **实证偏差**：美军一次野战演习中 **87% 的评分落在 A1/B2/C3 对角线，B2 占 74%**；受训分析员仍倾向把来源声誉当事实真伪的替代品。

### 5.2 JEV 的对位与缺口

| 本仓机制 | 覆盖什么 | 在 Admiralty 里属于 |
|---|---|---|
| `source_sig`（1159 个文件的 size/mtime/sha，含 `absent` 记账） | 输入快照完整性 | 采集过程可追溯性 |
| `minute_read` 三档台账（local / remote / fail） | 分钟层来源 | 采集过程可追溯性 |
| P2.3 三旗标 + `fetched_at` 同日盘后合规 | 快照准入 | 采集过程可追溯性 |
| `ingest_audit` append-only | 逐次输入留痕 | 采集过程可追溯性 |
| **单条信息的可信度评级** | — | **【缺失】** |

**活例**：P2.3 那次 `fetched_at` 与文件名日期错配（盘中 14:56 版被当同日盘后合规快照）——**采集器这个「来源」看似可靠，但「观测时刻」这条信息不可信**。这正是「来源可靠性 ≠ 信息可信度」；若当时只有一维评级，会直接漏过。

**建议（零风险、纯字段）**：给每类信号加两列独立字段 `source_reliability`（按源的历史表现，静态、可复用）与 `info_credibility`（按该条是否被独立佐证，逐条判），并在规格里写死**禁止由前者推导后者**；`F`/`6` 显示为「未评估」而非「不合格」。JEV 的多维交叉结论，本质上就是用另一维度去给这一维度做佐证——把这件事显式化，比新增任何算法都划算。

## 六、讲义里三处不能全盘接受（保持批判性思维）

### 6.1 「全数据模式 / 掌握大量数据可抵消错误数据」与情报学主线冲突

讲义称大数据「信息容错性提高……掌握有大量甚至全部数据，可以抵消掉错误数据所造成的影响」。这与两条权威口径直接张力：

- Heuer / IARPA：**缺失指标不等于事件不存在的证据**，除非先证明采集覆盖充分；
- Krohley：过度依赖技术、量化指标与「**完全态势感知的错觉**」，会侵蚀批判性思维与语境解读能力——恰在对手刻意伪造数据时最致命。

对 JEV：181 表 / 225GB 是 **Volume 有余，Value 未兑现**（方向准确率 52.5%、覆盖率 54.44% 挂起）。「数据多」不能替代「采集充分性证明」。**JEV 现有的 `unpriced` 硬纪律、48.2% 问题域外判定，恰恰站在正确的一边**，不该为追「全数据」而松口。

### 6.2 「收集即研判、应用即收集」vs「采集/渲染物理隔离」——分层成立，但有代价

上一轮判断「不在同一层」成立，全网进一步锐化：

- 讲义/Hulnick/Treverton/Clark 说的是**认识论与组织协作**（结论随新输入动态调整、搜集与分析并行、用户内嵌）；
- 老田钉的是**工程职责与代码边界**（「怎么拿到」交给采集工位，「拿到了说明什么」才是 JEV）。

**但要补一条代价**：Hulnick 明确把 **stovepiping（烟囱化阻止跨手段交叉验证）** 列为循环模型的结构缺陷。物理隔离在换来职责清晰与可替换采集器的同时，确实承担了这类风险。**缓解办法不是拆隔离**，而是在渲染/研判层保留跨维度联合判据与来源台账——本仓已有：三维度交叉裁定、`echo_ratio` 先验验证、`source_sig`、`ingest_audit`、`minute_read`。这些不是附属品，是隔离架构的**必要对冲**。

### 6.3 「空间关系」不适用，且不必补

讲义的地域/位置/现场，对应 JEV 的板块是行业分类。问题域不同，不是能力缺口。另：讲义十类可视化战法里「查找回路」在 JEV 无对应（无资金/信息回路检测），属【缺口】但优先级低。

## 八、必须写进任何对外材料的边界

1. **方法论可迁移，场景与授权逻辑不可迁移**。讲义语境是强力机构对**人**的目标追查、识别、定位、侦控与行动；JEV 是**公开市场信号**的 OSINT，对象是板块与证券，不涉及个人信息、定位或行动环节。
2. **关联不等于因果，结构位置不等于意图**。SNA 文献明确警告「牵连」风险；JEV 的 `lead` / `cross` / `silent` 边是共现与时序关系，不得据以推断主体意图。
3. **公开可得 ≠ 可无限关联与传播**。遵循最小化原则，保留来源标识、提取时间、原文与可信度评级，保证证据链可复核——这一条本仓已用 `source_sig` / `ingest_audit` 落实。
4. **「情报」一词对内可作方法论用语，对外避免与执法/国安语境混用**，建议统一表述为「公开市场信号的 OSINT 化推演」。
