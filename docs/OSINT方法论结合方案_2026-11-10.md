## 二、逐条结合映射（范本做法 → 本席业务落点）

### M1 三层信源结构 → 六源层级化【判据，零改动可执行】

范本：核验层（官方文件/国会报告）＞ 主干证据层（本地文献）＞ 参照层（中文编译）。

**A 股映射**——本席六源天然分三层，但落盘 schema 目前未标注层级：

| 层级 | 本席数据源 | 性质 |
|---|---|---|
| 核验层（一手） | 交易所公告原文、互动易/上证 e互动**公司官方回复**、sse 披露 | 可核验事实 |
| 主干证据层 | 新闻流、机构研报原文 | 报道与分析 |
| 参照层（二手） | 淘股吧、雪球发言、股吧、千股千评评分 | 情绪与传闻 |

**落点**：检索/盘点输出时按此层级引用；冲突时**上层覆盖下层**（官方回复 > 散户帖）。

### M2 事实状态标签 Checklist【判据，建议固化进台账】

范本 Checklist 逐条映射 A 股域（引用任何采集数据前检查）：

| 范本问句 | A 股对应判据 |
|---|---|
| 宣布 vs 已建成？ | 「公司计划扩产」≠「已投产」；互动易问答里"有规划"≠"已落地" |
| 申请 vs 已拨款？ | 「签订合作框架协议」≠「已确认订单收入」 |
| 已签约 vs 已投产？ | 中标公告 ≠ 收入确认（看计价与履行期） |
| 目标 vs 在途？ | 「预计年产能 X」是目标值，非已达产能 |
| 直陈 vs 报道词？ | 公告"公司拟/计划/预计/争取"均为计划措辞；"已经/完成/实现"才是事实措辞 |
| 财年口径？ | 业绩预告 vs 业绩快报 vs 正式财报，三种口径不可混比、不可加总 |
| 当事方自述？ | 公司互动回复中"订单饱满/供不应求"属当事方自述，需第三方数据互证 |
| 打印时间误当发布日期？ | 公告 PDF 页脚时间 ≠ 披露日期；以交易所披露时间为准 |

**判据编号建议：FS-1 ~ FS-8**（Fact Status），可作为质检规则与人工复核 checklist。

### M3 置信度三档判定【判据，与 M1 配套】

范本：高 = 官方文件 + 国会报告 + 评估文献同时支持；中高 = 官方节点 + 专题研究；中 = 仅构想 + 单一来源。单一作者群系列 = 方向性信号而非既定路线。

**A 股映射**：
- **高**：官方公告 + 互动易公司回复 + 财务数据三方互证
- **中高**：公告单源 + 机构研报佐证
- **中**：仅雪球/淘股吧单一热帖或同一作者系列发帖 → 只作"方向性信号"登记
- 「中」不等于不重要，代表**落地时间与形式不确定**

### M4 跨源核验表 → 「传闻-澄清」对账模板【结构类，小改动】

范本表 6 结构：`关键说法 | 本地依据（文献序号）| 外部核验来源 | 核验结论`。核验结论细分为：证实 / 证实并修正 / 方向证实金额待核验 / 否定 / 二手转述待核验。

**A 股映射**（可直接做成表模板）：

```
传闻/说法 | 采集来源与行号（如 tgb/000xxx.jsonl#L123）| 官方核验来源（公告号/互动易问答ID）| 核验结论
```

**价值**：淘股吧/雪球是传闻富矿，官方互动平台是澄清富矿，二者本就是本席在采的两端——这张表把"采集两端"接成闭环，且**纯数据治理动作，不越研判边界**。建议作为台账新登记项（裁定后实施）。

### M5 数据口径表 → 落盘与盘点强制口径列【结构类，零改动】

范本表 5：`指标 | 数值 | 口径与出处`，强制注明财年与性质。

**A 股映射**：本席所有盘点输出（如 strategy_picks_summary）中出现的数字，逐项标注**口径与出处**——例如覆盖数需标注"按队列 json 登记数 / 按实抓行数"两种口径不可混用（此坑本席已实际踩过：164 池 489 vs 593 的开关口径差）。

### M6 三类事件着色时间轴【结构类，可选】

范本图 4 用深/中/浅三色区分：已发生 / 官方设定节点 / 智库构想。

**A 股映射**：六源情绪卡与板块手册中的时间线，可区分：已披露事实（公告日） / 公司计划节点（预计投产/达产年） / 机构预测节点（研报预测 EPS 年份）。属输出美化，优先级低，归上级裁定是否采用。

### M7 逐篇解析模板 → 单条数据证据画像【结构类，登记即可】

范本：`类型 | 机构 | 时间 | 页数 | 论证结构 | 核心论点 | 可核查数据与原句 | 未来主张 | 证据性质 | 趋势关联`。

**A 股映射**：对**高价值单条数据**（如互动易关键回复）建立证据画像：`源类型 | 公司 | 问答ID/公告号 | 日期 | 关键原文（引用不转述） | 涉及的未来主张（计划/预计措辞） | 证据性质 | 关联板块/事件`。**关键纪律：引用原文不转述**——范本用原句+中文释义，本席用公告原文+行号定位。

### M8 制度性先行指标【指标类，已部分入册，补充操作化】

范本亮点：看"新 MOS 设立/预算科目重构/开放更新权"，不看"平台采购数量"。

**A 股映射的操作化补充**（此前 MEMORY 只记了方向，这里补具体观察对象）：
- 看公司**组织与流程信号**：新设子公司/事业部、招股书岗位扩张、定增募投科目变更
- 看供给链信号：上下游互证（上游扩产公告 ↔ 下游订单公告）
- 不看结果指标：单日股价、单日情绪绝对读数
- 本席内部运营同理：看**增量落盘行数与队列覆盖变化**，不看单日采集绝对量（已在册）

### M9 未采用项制度 + 局限性声明【流程类，已承诺，固化为模板】

范本把"已核查但未采用"的项目也列明（证明做过尽职调查）。本席已承诺：重大盘点输出附五项局限性自省。**固化为模板**：今后 strategy_picks_summary 类输出末尾固定附两节——「未采用项」+「局限性声明（五项模板）」。

### M10 语言纪律【流程类，零改动】

范本：所有量化结论用"据……记录/宣布/申请/引述"句式；拟议与目标明确标注。

**A 股映射**：本席输出涉及公司说法时，固定句式「据公司 20XX-XX-XX 公告（公告号 XXXX）」「据互动易问答（ID XXXX）」，计划类说法保留原措辞（"拟/预计/争取"），**不得压缩为已发生**。此条即中文编译偏差判据（已在册）的自查出口。

## 四、局限性声明（按范本五项自省模板，本方案自身适用）

1. **样本偏差**：范本仅一份军事领域报告，其判据向 A 股域迁移的有效性未经本席实证检验；
2. **映射推断**：M2/M3 的 A 股对应判据系本席类比推断，非原文内容；
3. **时效边界**：仅反映 2026-11-10 时点的体系状态；
4. **口径不可加总**：本文不用于直接推导采集扩容规模（R8/R10 仍按原判据独立裁定）；
5. **定性判断非精确测量**：L1-L4 分级为治理建议，非工作量精确估算。

## 五、一句话总结

范本的本质是**给每一条数据配三样东西：证据性质标签、口径出处、置信度**——本席现有台账管"数据在哪"，这套方法论管"数据算什么"，二者拼起来才是完整治理链。L1 四条零成本判据建议先批。
