## 〇、一句话结论

**能结合，但四条讲义不是同一个学理母体。** M1 / M3 / M4 出自 Heuer & Pherson 的结构化分析方法（SAT）体系；**M2「交叉影响分析法」出自上世纪六十年代技术预测 / 未来学的 Gordon 交叉影响法**，与 SAT 第五章·五「交叉影响矩阵法」只是同名。混同二者，会把「专家主观初始概率 + 蒙特卡罗概率传播」误当成可引入 JEV 的结构化分析技术 —— 而这与本仓 `calibrated=False`、不造假数据、校准前 `likelihood` 只允许 `unassessed` 三条硬纪律直接冲突。

全网复核带来的四个具体变化：

| 本轮讲义 | 坐实后 | 对 JEV 的净结论 | 性质 |
|---|---|---|---|
| M1 三法递进 | 排序式投票 → 成对比较 → 加权排序，递增的是**「权重标准的显式程度」**，不是计算量 | JEV 目前停在**排序式投票**；S0/S1 只把它推到加权排序的**契约层**，权重标准（PIR / 校准）仍无实体 | 定位纠偏 |
| M2 交叉影响 | 与 SAT「交叉影响矩阵法」**同名不同源**；讲义案例「A 国能源政策」即 Gordon 法经典例题 | 只可迁移第（1）步「确定影响关系」作假设生成器；**第（2）–（4）步定量部分全禁** | 新增辨析 / 禁用 |
| M3 事前分析 | Premortem（Klein），SAT 第九章·一 | 本仓已有等价机制且更硬；缺的是「整体信心」汇总，不是方法本身 | 加固 |
| M4 结构化自我批评 | SAT 第九章·二，十问 | **JEV 已把「靠人自觉」制度化成了「靠流程复核」**，从而绕开该方法固有局限 | 原创结论 |

**一句话边界**：这四条带来的增量仍然全在「态势描述 → 情报成品」这一段（第一辑 §七），而且**几乎全是口径与禁令，不是重计算**。M2 的定量部分恰好是「想跳过这一段、直接拿主观概率外推未来」的诱惑，禁掉它就是守住这条主线。

## 一、先把四条讲义放回学理坐标

### 1.1 中文版 SAT 目录对位

《情报分析：结构化分析方法》（小理查兹·J. 霍耶尔、伦道夫·弗森；金城出版社 2018 年中文版；在 CIA 谢尔曼·肯特学院内部教材基础上修订）收 **8 大类共 55 种**方法。两个独立书讯源的目录互相印证，四条讲义的对位如下：

| 讲义段落 | 中文版 SAT 落点 | 英文原名 / 学理别名 | 另一个母体 |
|---|---|---|---|
| ① 排序、评分、区分优先次序法 | **第四章·七**（分解与可视化） | Ranking / Paired Comparison / Weighted Ranking | 多准则决策 MCDM、**AHP**（Saaty）、孔多塞法 |
| ② 交叉影响分析法 | **不是** 第五章·五（Cross-Impact Matrix） | Cross-Impact Analysis / 交叉概率法 | **Gordon（1968，美国未来研究所）**、德尔菲法、主观概率、蒙特卡罗 |
| ③ 事前分析法 | **第九章·一**（质疑分析） | Premortem Analysis | Klein；prospective hindsight（Mitchell / Russo / Pennington） |
| ④ 结构化自我批评法 | **第九章·二**（质疑分析） | Structured Self-Critique | Heuer 关键假定检查、ICD 203 分栏要求 |

佐证：IALEIA 的 SAT 系列把 Heuer(1999) / Pherson(2019) 八类分类法列全；Kent School 的 *A Tradecraft Primer* 另用「诊断 / 反向 / 想象」三分法；SAT 读书笔记把 **Cross-Impact Matrix、ACH、Premortem Analysis and Structured Self-Critique、Key Assumptions Check** 并列为 Core SATs。中文版目录第九章·七恰是**德尔菲法** —— 这解释了讲义为何说 M2「弥补德尔菲法的不足」，但**同章不等于同源**。

### 1.2 关键辨析：M2 的两个同名方法

| | SAT 第五章·五 交叉影响矩阵法 | Gordon 交叉影响法（讲义所述） |
|---|---|---|
| 领域 | 情报分析 / 观点生成 | 技术预测 / 未来学 |
| 输入 | 事件清单 + 两两影响方向与强度（定性） | 各事件**初始概率** + **影响系数 KS**（专家打分） |
| 计算 | 矩阵，无概率传播 | 校正概率 + **随机数法反复模拟**（蒙特卡罗） |
| 输出 | 关系图 / 驱动因素识别 | 修正后的事件概率，用于预测与方案评价 |
| 经典例题 | 无特定 | 「某国今后 15 年能源政策」——与讲义「A 国能源政策」逐字对上 |
| 与 JEV | 定性关系可参照 | **定量部分禁用** |

讲义四步（确定影响关系 → 结合主观概率法与德尔菲法评定影响程度 → 引入经验公式确定影响值 → 蒙特卡罗模拟计算）与 MBA 智库 / 百度百科「交叉影响法」条目逐条一致；该条目明写「美国于上世纪 60 年代，在德尔菲法和主观概率法基础上发展」，另一条目明写「1968 年由美国未来研究所的戈登博士首先提出」。NOAA 收录的密歇根大学 Sea Grant 德尔菲方法评估亦记载：Gordon 法把德尔菲面板的估计当作 **initial estimates**，再用 Monte Carlo 与复杂矩阵多轮调整，并附条件概率合成公式。

### 1.3 由此得到一条判定链

```
SAT 传统（定性 · 外化思维 · 去认知偏误）   ──→  M1 / M3 / M4 可迁移到 JEV 口径层
技术预测传统（定量 · 主观初始概率 · 概率传播）──→  M2 定量部分不可迁移，只能取「关系定性」这一步
```

这条判定链是后面所有裁定的地基。**判据不是「方法看起来高不高级」，而是「它的输入在本仓有没有可回溯的实体」**：SAT 类方法的输入是证据行与假设，本仓有；Gordon 法的输入是专家主观概率与影响系数，本仓没有、也不允许臆造。

## 二、M1 · 排序、评分、区分优先次序法

### 2.1 三法递进：真正递增的是「标准的可审计性」

| 方法 | 产出 | 能回答 | 不能回答 | 权重标准 | JEV 对位 | 状态 |
|---|---|---|---|---|---|---|
| 排序式投票法 | 全序 | 哪个更重要 | 重要**多少** | 无 | 第一辑 §七 S0–S5 按优先级排列；`MIN_DIMS = 2` 三维度等权 | 【已具备·但仅此档】 |
| 成对比较法 | 全序 + 相对权重 | 重要程度 | **为什么**是这个权重 | 隐含于判断矩阵 | `Hit.confidence` = 命中维度权重和 / 全部权重和 | 【部分】字段在，标准不显式 |
| 加权排序法 | 全序 + 权重 + **显式标准** | 三者 | — | **可审计、可复核** | S0 `requirement_id` / `fact_vs_judgement`；S1 `diagnosticity` | 【契约层已写·实体缺】 |

讲义说「清单上项目太多」「排序结果事关重大」「整合团体意见」三条适用情形，在 JEV 里分别对应：181 张表只用 5 张的利用率账（第一辑 §七 S4）、能力账本优先级、以及并行工位 / 老田裁定构成的多方意见。但**适用情形成立不等于方法已到位**。

### 2.2 学理补注：AHP 补的是数学一致性，不是标准来源

维基「成对比较」条目指出：成对比较的重要应用是 **AHP 层次分析法**（Saaty），用比率量表把有形 / 无形因素的两两判断转为权重；同时列出传递性规则与孔多塞法（可能出现投票悖论、非传递）。

这恰好解释讲义那句「成对比较法……局限性在于赋予各项权重的标准是不明确的」：

- 判断矩阵的**一致性检验**只保证打分自洽，不保证标准客观；
- **孔多塞悖论**说明「两两比完」未必能合成合法全序；
- 因此从成对比较走到加权排序，关键动作不是「算得更细」，而是**把评分标准写成可被第三方复核的条文**。

### 2.3 JEV 裁定：停在排序式投票，不得声称已达加权排序

1. 第一辑 §七的 S0–S5 是**排序式投票**：给出优先级，未给「S0 比 S2 重要多少」的量化依据，也未写排序标准。
2. S1 §4.2 把「确认性累加」改述为「诊断性排除」，本质是把计分理由从「命中个数」换成「诊断性」，**朝加权排序走了一步**；第 4 条明写「与全部假设都一致的证据诊断价值 = 0，不得计分」，这正是「标准显式化」。
3. **但 S0/S1 规格 §6.2 D3 明写**：PIR 需求登记簿、概率词表的本仓校准**尚无实体**；校准前 `likelihood` 只允许 `unassessed`。**权重标准的实体缺失，故不能声称 JEV 已达到加权排序法。**
4. 一条零风险可补的：能力账本每条加一列「排序依据」纯文字，把「为什么这个优先级」显式化。属改第一辑文档，**需另批，本辑不改**。

> 与 S1 §4.2 第 2 条对齐：`Hit.confidence` 字段值不变，只解释为 `clue_weight`；它既不是结论置信度，也不是 Gordon 式概率。**本辑不重复订正，只登记一致性。**

## 三、M2 · 交叉影响分析法（本辑最重要的一条禁令）

### 3.1 强共鸣：它和 JEV 在问同一个问题

Gordon 法的立项动机是：德尔菲法**对各事件概率单独估计**，忽视事件之间的相互影响导致的概率变化。这与老田 2026-11-08 的硬结论——

> 单看时间（领先分钟）、单看资金（净额）、单看社交（名次）都不成立，三条指向同一方向才是结论。

——是**同一个问题陈述**。JEV 的 `lead` / `cross` / `silent` 边、分钟首次异动 / 封板传播链、跨板块边，其实就是一张**定性的交叉影响关系图**；`echo_ratio` 先验验证、三维度交叉裁定、`source_sig`、`ingest_audit` 是这张图的来源台账。第一辑 §6.2 已把这批东西定性为「采集 / 渲染物理隔离」的必要对冲（防 stovepiping），本辑从方法学上再确认一次：**关系定性这一层，JEV 不但有，而且是架构要求。**

### 3.2 三条硬冲突（【冲突】）

| # | Gordon 法的要求 | 本仓硬纪律 | 裁定 |
|---|---|---|---|
| C1 | 各事件**初始概率**由专家主观估计 | 三旗标 `calibrated=False`；无本仓校准概率词表；S0/S1 §6.2 D3 规定校准前 `likelihood` 只允许 `unassessed` | **没有可填的初始概率**，填了就是造假 |
| C2 | 影响程度 / KS 系数靠专家打分（无 / 弱 / 强 / 很强 × 升降方向） | `source_sig` / `ingest_audit` 要求输入逐次可回溯；不造假数据铁律禁止臆造参数 | **无可复核来源，禁用** |
| C3 | 蒙特卡罗输出**校正后的预测概率** | JEV 不是预测器，是条件推演 + 事后解释；S0 规定 `UNSPECIFIED` 时禁 `estimative`、`coverage_only=True` 时禁 `estimative` | **产品类型不允许** |

讲义自己给出的局限——「初始概率及影响程度均通过专家由主观估计得出，主观性和经验性较强，**仅适用于数据掌握不多的情形**」——在 JEV 语境里是反着的：JEV 有 181 表 / 225GB、有分钟级快照、有合规护栏，**恰恰不属于「数据掌握不多」**，因此连该方法自己声明的适用前提都不成立。这一条比 C1–C3 更干脆。

### 3.3 可迁移边界（三档写死）

- 【可取】**仅第（1）步「确定影响关系」**：作为**假设生成器**，产出类似 H1–H4 的候选关系，交 S1 ACH 矩阵受诊断性检验；**不产出任何概率数值、不产出影响系数**。
- 【不可取】第（2）–（4）步（专家评定影响程度、经验公式定影响值、蒙特卡罗模拟）：**明确禁用**，不得写进任何 JEV 分析产物、页面、台账或对外材料。
- 【不可混用】SAT 第五章·五「交叉影响矩阵法」是**定性**矩阵（观点生成），与 Gordon 的**概率传播**不是一回事。将来若要引入矩阵，只能引入定性版，且仍须过 S1 ACH 的诊断性排除，**不得把矩阵单元格直接当结论**。

### 3.4 与 S1 ACH 的分工（防止「都是矩阵」造成误用）

| | Gordon 交叉影响 | S1 ACH 竞争假设矩阵 |
|---|---|---|
| 推理方向 | 前向：概率如何被别的事件改变 | 反向：哪条证据排除了哪个假设 |
| 输入 | 主观初始概率 + 影响系数 | 可回溯证据行 + `diagnosticity` |
| 输出 | 校正后概率 | `excluded` 排除项 + 反证最少的假设 |
| 缺失证据 | 参与概率合成（危险） | `is_absence` 绑定 `absence_guard`，**缺失证据不更新、不得用于排除** |
| JEV | 【禁用】 | 【已写进规格】 |

**一句话**：ACH 是「用证据淘汰假设」，Gordon 是「用假设修正概率」；本仓只做前者。

## 四、M3 · 事前分析法

### 4.1 学理定位

Premortem（Klein）在 SAT 中文版列第九章·一；其心理机制是 **prospective hindsight**（Mitchell / Russo / Pennington）：假定结果已经发生，比假定「可能发生」能引出更丰富的因果解释。中文版实操案例把它展开为三步：假定一段时间后从可靠来源得知判断有误 → 头脑风暴导致错误的可能原因与替代假设 → 找出支撑主流判断的**关键假定**并评估其失效影响。第三、四步其实已溢出 premortem，接上了「关键假定检查」与 ACH —— 这与 S1 把 `sensitivity` / `falsification_conditions` 写进同一份 ACH 契约是同构的。

### 4.2 JEV 对位（【已具备·优于原方法】）

| premortem 要素 | 本仓落点 | 状态 |
|---|---|---|
| 假定未来发现判断错误 | 第一辑 §2.1 明定 JEV 是描述 / 评估 / 条件推演，非预测；无条件预测失败（lift≈0）已写进手册 | 【已具备】 |
| 想象导致错误的原因 | S1 §4.6 把 P1 / P7「主路径与假设相反」记为**未证伪、四种可能并列**；H4 采集覆盖伪影复用 `time_ready` 伪分化节点先例 | 【已具备】 |
| 关键假定检查 | S1 §4.4 `sensitivity` / `falsification_conditions`；§4.5「不吠的狗」硬闸门；`jev_deltamin_spec.md` 判例 #25「涨停档位先定死」 | 【已具备·写成硬表】 |
| 未来观测点 | S1 §4.4 `milestones`（T+1 / T+3 / T+5），与 S3 后验回流对接 | 【部分】S3 未实现 |
| 留痕 | `ingest_audit` append-only；上游 `stk_mins` 并行改写如实登记；可复现性判据改为「相同输入必得相同输出」而非抹平差异 | 【已具备】 |

### 4.3 局限的正确用法：不能停在「警示」

讲义说 premortem「仅对团体或个人起警示作用，而不涉及具体解决方法」。**JEV 不能停在这一层**，本仓的做法是给每条警示配一个可执行机制：

| 警示 | 配套机制 |
|---|---|
| 锚点可能缺失 | `unpriced` 绝不硬算，缺失不补值 |
| 覆盖偏倚会被当成信号分化 | `AVAILABILITY_PROXY_SIGNALS` + `countable=False` 拦下 |
| 上游输入在变，同日结论不可比 | 如实标 SKIP、不假绿，不追覆盖率 |
| 线上结构核对被判据降级掉 | 另批一次只读比对，把逐项结构核对补齐 |

**这是把 premortem 从「提醒」升格为「闸门」**；第一辑 §6.1 已用 `unpriced` 硬纪律站在同一边，本辑给它的学理名字就是 premortem 的闭环化。

### 4.4 建议增补（需另批，本辑不写）

`_product.premortem` 只读字段：记录「若此结论被证伪，最可能的三条原因 + 各自的可观测里程碑」。**只加文档口径，不改 S0/S1、不写入库、不入闸**；且不得引入主观概率（见 §3.3 禁令）。

### 5.2 核心结论：JEV 已把该方法从「靠人」搬到了「靠流程」

讲义给的局限是「从『支持者』到『批判者』，对团体内成员的积极意愿与智力的灵活性要求比较高」。**本仓的实际做法不是要求谁更愿意批判自己，而是把自我批评写成不执行就跑不过的流程**：

- 改前重读 v2；替换补丁前断言锚点 `count == 1`，替换后断言新串存在；
- 日期与编号一律码点复核，Write / Edit 通道同样不信任；多行补丁落盘成 `.py` 再执行；
- append-only 台账、只读扫描回执、输入逐次留痕 `source_sig`；
- 红因如实标注，**改判据不改实现、不抹平、不假绿**；
- 并行工位互斥协议；敏感保护超时**不重试、不绕过**；系统级动作「沉默≠同意」。

这些机制把「批判者」这个**角色**换成了「复核门」这个**工序**。因此 JEV 不是缺 M4，而是**已经用工程手段绕开了 M4 的固有局限** —— 这是本辑最值得写进对外材料的一条，也是第一辑 §八「证据链可复核」的学理命名。

### 5.3 仍存的三条缺口（诚实标注，不粉饰）

1. **无「整体信心」汇总字段**：十问回答完了，没有一个 `overall_confidence` 承接；S0 的 `confidence` 是产品级，不是十问汇总。
2. **无独立批判角色的留痕**：现有纪律全是同一流程自我复核，没有「谁、在何时、扮演了批判者」的记录。
3. **第 8 问未闭合**：若则分析 / 高影响低概率未进 S1。第一辑 §八 已警告低概率事件忌用模糊词、S0 有 `likelihood` / `confidence` 分栏（ICD 203），**补它需另批，且不得引入主观概率**。
