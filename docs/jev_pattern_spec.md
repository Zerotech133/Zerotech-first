## 1. 字段清单（命中条件唯一取值来源）

### 1.1 资金（jev_flow.load_flow）
- `main_net`：主力净流入（大单+特大单，万元）
- `net_mf`：全档净流入（万元）
- **divergence** = `main_net > 0 且 net_mf < 0`（主力接而全档逃）
- **一致性** = `main_net > 0 且 net_mf > 0`（主力接 + 全档流入）
- 中性 = 两者均不显著（绝对值低于阈值，阈值待 P5 校准）

### 1.2 社交（jev_social.load_social → by_code 字段）
- 雪球四榜：`xq_hot / xq_discuss / xq_trade / xq_follow`（值 + 对应 `_rank`）
- 股吧：`guba_rank`（人气榜排名）、`guba_rank_chg`（较上期变化，正负语义待 P5 校准）、
  `posts / reads / comments`（逐只票聚合）
- 顶层全局榜（xq 四榜全部、guba rank 全量）用于"机构 / 散户整体热度"口径
- **覆盖现状**：仅 `social_20261106.json` / `social_20261109.json` 两份同日快照 + 每日前向累积（见 v2 P2.2）

### 1.3 Δmin / 时间（P1.4 定义文档）
- `Δmin = T_news − T_limit`（分钟，带符号）
  - `Δmin > +5min`：**价格先行 / 消息追认**（新闻在涨停之后发布）
  - `Δmin < −5min`：**消息驱动**（新闻在价格之前发布）
  - `|Δmin| ≤ 5min`：同步，无区分
- 锚点：`T_limit_seal`（首次封板）、`T_limit_touch`（首次触板）；`T_news_first / T_news_last`
- 边界：任一锚点缺失 → `unpriced`，**绝不硬算**（判例 #25③）

## 2. 候选 pattern（8 个）

> 每个 pattern = 三维度软命中条件集合。匹配器（P5.1）采用"≥2 维度命中即记"的宽松策略，
> 不要求全中；单维度阈值带、置信度加权见 P5。下列"预期演化"均为**待验证假设**，
> 未经 P5 案例库检验前不得当作结论。

### P1 · 散户接盘型（retail-dumping）
- **资金**：divergence（main_net>0 & net_mf<0）
- **社交**：股吧热度飙升（posts/reads 高或 guba_rank 进入前列）+ 雪球机构沉默（xq 四榜无该股或 rank 靠后）
- **Δmin**：消息追认（Δmin > +5min，涨停后才有新闻追认）
- **预期演化**：短期回落（11-06 判例原型：新型电力 3 只涨停全背离 + 股吧散户追捧 + 雪球机构圈无视 + 消息追认 → 涨得不实）
- **分化节点假设**：Δmin 越大（追认越滞后）→ 回落概率越高

### P2 · 价格先行型（price-leads）
- **资金**：中性或见异常大单
- **社交**：中性
- **Δmin**：价格提前 ≥30min 启动 + 消息追认（Δmin 显著 > +5min）
- **预期演化**：有人提前知道 → 看后续有无持续消息确认；若无消息接续，警惕兑现
- **分化节点假设**：价格先行后 30min 内是否出现对应消息，是"有预谋拉升" vs "随机抢跑"的分化点

### P3 · 真突破型（real-breakout）
- **资金**：一致性（main_net>0 & net_mf>0）
- **社交**：雪球机构热榜（xq 四榜有该股且 rank 靠前）+ 股吧热度温和（不爆）
- **Δmin**：价格先行（先有资金动、再有新闻，Δmin 可正可负但资金在前）
- **预期演化**：继续涨 / 趋势延续
- **分化节点假设**：雪球机构榜 rank 越靠前 + 全档流入越持续 → 延续概率越高

### P4 · 消息驱动型（news-driven）
- **资金**：中性（消息落地前无明显资金异动）
- **社交**：消息发布后社交热度快速上升
- **Δmin**：消息提前 ≥30min 发布（Δmin < −5min，价格追认）
- **预期演化**：消息落地后延续一段时间（利好兑现 / 利空出尽视内容）
- **分化节点假设**：消息类型（event_type_tier 强类型 credit/trade/risk 等）决定延续方向

### P5 · 社交过热型（social-overheat）
- **资金**：net_mf 中性
- **社交**：股吧 Top3 + 雪球 Top3 同时高热（双榜共振）
- **Δmin**：同步（|Δmin| ≤ 5min）
- **预期演化**：分歧加大 → 震荡或回落（情绪赶顶特征）
- **分化节点假设**：双榜共振后 1 日内是否出现资金背离（转 P1）→ 决定回落

### P6 · 主力锁仓型（main-lock）
- **资金**：一致性（main_net>0 & net_mf>0）且持续
- **社交**：中性偏冷（无散户狂热）
- **Δmin**：价格先行温和（缓慢抬升，非突兀）
- **预期演化**：趋势平稳延续（慢牛）
- **分化节点假设**：全档流入能否持续；一旦 net_mf 转负 → 退化为 P1

### P7 · 诱多炸板型（fake-rally）
- **资金**：divergence（main_net>0 & net_mf<0）
- **社交**：雪球机构沉默 + 股吧散户追涨
- **Δmin**：价格先快速拉（触板 T_limit_touch）后消息追认，Δmin 大正
- **预期演化**：冲高回落 / 炸板（触板未封）
- **分化节点假设**：是否真正封板（T_limit_seal vs 仅 T_limit_touch）是核心分化点

### P8 · 机构埋伏型（institutional-accumulation）
- **资金**：资金温和流入（main_net>0，net_mf 小幅）
- **社交**：雪球机构热榜 + 股吧冷（机构圈关注、散户未察觉）
- **Δmin**：价格先行（缓慢建仓，新闻滞后）
- **预期演化**：慢牛延续，后期可能加速
- **分化节点假设**：股吧热度从冷转热的时间点 → 标志建仓完成、进入主升

## 4. 不预设结论

- 三维度组合覆盖率受**社交历史稀缺**限制（仅 2 份同日快照 + 前向累积日）。
  这恰是判定闸 A 条件②要实测的，本文**不在定义层预设覆盖率高低**。
- 每个 pattern 的"预期演化"是**待验证假设**，P5 用案例库演化路径分布检验；
  未经验证前，pattern 只是"信号组合标签"，不是结论。
- 8 个为初始候选，P5 跑完覆盖率 / 分化度后可能合并、拆分或新增。
