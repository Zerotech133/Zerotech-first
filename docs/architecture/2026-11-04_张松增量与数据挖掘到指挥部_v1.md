## 二、数据挖掘到指挥部的产品形态

### 2.1 统一对象 `hq/data_brief/v1`

```json
{
  "schema": "hq/data_brief/v1",
  "as_of": "...",
  "owner": {"agent_id": "DATA1", "name": "张松", "position": "数据资源主官（兰台令）"},
  "data_health": {
    "assets": {"all": 399, "registered": 350, "exposed": 80},
    "catalog": {"version": 38, "tables": 304},
    "registry": {"physical": 304, "display": 258},
    "freshness": {"data_date": "2026-11-02", "age_days": 2},
    "collectors": {"red": [], "today_zero": []},
    "contracts": {"mismatch": 3}
  },
  "alarms": [],
  "mining_signals": [],
  "questions": [],
  "boundaries": []

```

关键：**alarms/mining_signals/questions 都带证据和边界**，不含原始敏感路径。
