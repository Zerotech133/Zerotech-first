## 一、统一接口

新增 `agent_platform/gateway/internal_notify.py`：

```json
{
  "schema": "hq/internal_notify/v1",
  "target": "A0",
  "title": "[A0跑板] HUANGZHONG 中军帐·黄忠验收：需决策/卡点",
  "body": "需决策：... \n卡点：...",
  "link": "deliverables/daily_briefs/2026-11-04/rollup.json",
  "actor": "HUANGZHONG",
  "created_at": "..."
}
```

- 只调用 `inbox_gateway.submit`，不新增端口/队列/存储；
- kind 限定 `task_request/question/feedback`；
- 自动 dedupe：`daily-<date>-<lead>`（同一天同一席只一条，重跑 replay 不重复）；
- 目标/标题/长度校验；正文上限 4000。
