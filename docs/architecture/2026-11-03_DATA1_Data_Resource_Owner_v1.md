# DATA1 张松 · 数据资源主官 v1

- 日期：2026-11-03｜触发：A0 明确“张松掌管数据资源主要角色”
- 结论：DATA1 从“数据治理/数据工程师”升格为 **数据资源主官（兰台令）**；对数据资源全域负责，但不裁决业务口径。

## 一、职责（Owns）

| 职责 | 说明 |
|---|---|
| 数据资源目录 | 314 数据集 / 256 表的资产目录、分层、标签、新鲜度 |
| 数据接入 | 数据源接入、增量同步、断流/延迟监护 |
| 血缘与实体映射 | 表/字段/指标到源的血缘链，保证可追溯 |
| 权限与分级 | 数据分级、访问边界、敏感数据授权登记 |
| 生命周期 | 创建/归档/下线/删除审批链，保留证据 |
| 质量 | 完整性/一致性/及时性/空值/异常；质量报告 |
| 开放边界 | 对量化/研发/情报/客户输出数据的可用性与口径说明 |

## 二、不负责（Not Owns）

- 不裁决业务口径（由 D1/ACAD1/业务 owner 定）；
- 不代替 QA1 验收软件质量；
- 不代替 ZHAOYUN 做审计结论；
- 不直接改生产数据/不绕过审批。

## 三、会议角色

- 固定参加 **作战会**（operation）；
- 在会上输出：数据资源可用性、血缘/口径缺口、权限/生命周期风险、需谁裁决；
- 不参加晨会固定席（晨会仍为指挥五席）；专题可临时邀请。
