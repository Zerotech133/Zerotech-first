# 账号 tf 登录修复回执 v1（2026-11-03）

- 触发：A0 报“密码错误”，提供 `710555441@qq.com` / 密码
- 结论：**密码本身正确；登录名用错 + identity registry 缺映射**
- 现在可登录：用户名 **`tf`**，邮箱仅作账号联系方式

## 一、根因（三层）

1. **登录名用了邮箱**：零界登录表单把输入原样交给智策 `/api/v1/auth/login`，智策按 **username** 查库；`710555441@qq.com` 是 `email`，username 是 **`tf`** → `invalid_credentials`。
2. **缺 identity 映射**：即使改用 `tf`，智策验密通过后，零界还要 `identity_registry.resolve_source("zhice", user_id)`；registry 里只有 `zero_bound:owner` 等，`tf` 未映射 → `identity_not_mapped`（403）。
3. **重试触发限流**：连续失败触发 429 `too_many_attempts`（窗口 300s / 5 次），会掩盖真实原因。

## 二、账号只读核对（未打印哈希/密码）

- 智策 `v2_user`：`user_id=u-6195891e8668724c`，`username=tf`，`email=710555441@qq.com`，`is_active=t`，`role=USER`；
- 密码哈希算法：PBKDF2-HMAC-SHA256 / 260000 iter；离线校验 **12345678 匹配**；
- 未修改智策账号、密码、权限。

## 三、修复

1. `agent_platform/identity/identity_registry.json` 新增只读 actor：
   - `sub=zero_bound:tf`
   - `roles=["VIEWER"]`，`permissions=["view"]`
   - `source_ids.zhice_user_id=u-6195891e8668724c`
   - `links[zhice].status=verified`
2. `portal/login.html`：
   - 用户名标签改为“智策用户名，不是邮箱”，placeholder `例如 tf`
   - `invalid_credentials` 提示补充“智策用户名不是邮箱（例如 tf）”。

## 四、验证（真实会话）

## 五、权限说明

- 若 `tf` 就是 A0 本人需要管理权限，需另做身份合并评审（不能靠登录修复提权）。

## 六、使用

2. 用户名填 **`tf`**（不是邮箱）

4. 登录后进 `/hq` 或 `/meeting`
