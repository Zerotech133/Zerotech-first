## 三、登录链路（不绕鉴权，同源）

```text
浏览器（人类入口 8734）
  ├─ 已登录门户：Cookie zb_session（HttpOnly）
  ├─ 打开 /shuijing.html（8734 nginx 静态直出）
  └─ ACAD1Client.ensureToken()
        └─ POST /quant-api/api/v1/auth/portal-sso   （同源；credentials:'same-origin' 自动带 cookie）
             └─ nginx /quant-api 反代 → 8105 FastAPI portal_sso
                  └─ 用 zb_session 调 8734 门户 /api/bff/identity/me
                       └─ identity_registry 映射 zhice_user_id → 签发 JWT
        ← {ok:true, token, username, role, read_only}
  └─ token 存于客户端关包内存（可 getToken() 读取，仅本页生命周期）
  └─ GET 六接口，Header Authorization: Bearer <token>
```

失败语义（客户端 `ACAD1Error{kind,status,code,message,detail}`，全部显式）：
- SSO 401：`portal_sso.no_session`（无门户会话）/ `portal_sso.portal_unreachable`（门户不可达）/
  `portal_sso.not_mapped`（身份未映射）/ `portal_sso.user_inactive`（用户停用）；
- 数据 401：清空内存 token → 自动重换票 **一次** → 重试仍 401 则抛 `kind=unauthorized`（透传 8105 code，不静默、不假绿）；
- 其它：404（如证据包未生成）/ 400（bad date）/ 5xx 按 `kind` 显式返回，面板逐接口显示状态与 code。
