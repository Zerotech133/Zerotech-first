## 三、`portal/static/ifs_client.js`（新增，只读、零依赖）

API（挂 `window.IFSClient`，同时支持 CommonJS 便于 node 测试）：

| 函数 | 行为 |
|---|---|
| `unwrapEnvelope(payload)` | 返回 `{isEnvelope, ok, data, raw, warnings, requestId, schemaVersion, source, sourceMode, interfaceId, stale, error}`；**优先 `data`**（F1b 副本），无 data → `data = raw`（旧字段 fallback）；envelope 判定 = `data` 对象 / `request_id` / `warnings` / `source.interface_id` |
| `warningsOf` / `requestIdOf` / `sourceOf` | 取 warnings / request_id / source（source 对象优先，training 页 `source` 字符串时回退 `source_detail` 对象） |
| `errorInfo(payload)` | 优先 `error_detail{code,message,retryable,details}`；兼容旧 `error` 字符串/对象（`retryable=false`）；`errorText()` 生成只读错误文案 |
| `renderMeta(el, payload, opts)` | 只读元信息文本（interface/schema/request_id/source_mode/warnings/stale/error），`data-envelope` 标记 `envelope|legacy` |
| `renderWarnings(el, payload, opts)` | warnings 只读列表（HTML 全转义），无 warnings 自动隐藏 |
| `fetchJson(url, opts)` | 只读 fetch 包装（默认 `cache:no-store`，返回 `{ok,status,payload,env}`；不发起写操作） |
| `esc` | HTML 转义（与页面 `esc()` 同语义） |

兼容口径（F1b 兼容期）：envelope 保留旧顶层字段，故 **旧页面/旧测试零改动**；本迁移后新代码优先 `data`，
旧顶层字段仅作 fallback —— 为后续 F1c 完成、旧字段移除（IFS-09 破坏性变更走 v2 + 90 天双版本）预留。

## 四、页面改动（不改变现有 UI 结构）

1. `<head>` 增加 `<script src="/static/ifs_client.js"></script>`（同步加载，确保 inline 脚本可用；tokens/nav/shortscreen 三件套保留）；

3. 数据读取：`unwrapPayload()`（客户端存在→`IFSClient.unwrapEnvelope`；客户端缺失→本地旧字段兜底）；
4. 错误展示：`error_detail` 优先、旧 `error` 字符串兼容（research 的 decision 写入口仅错误文案变更，POST 逻辑/403 token 重试不变）；
5. training 页面 `data_unavailable=true` 诚实空态、research 水平来源/待研究口径等既有只读语义**全部不变**。

## 六、可达性说明（不重启验证）

- **`/static/ifs_client.js` 在人类入口 8734**：nginx（8080）对 `/static/` 为**磁盘直出**（实测 `/static/nav.css` 等非
  portal_api 白名单文件在 8734 返回 200，而 8091 返回 404）。合入后文件即从磁盘生效，**页面在 8734 可直接加载客户端，无需重启**；
- **8091 直连**：portal_api 的 `/static/` 有白名单 `_CT`（nav.js/tokens.css/shortscreen.js 等），
  `ifs_client.js` 不在其中 → 8091 直连会 404。页面已内置 **客户端缺失兜底**（旧顶层字段渲染），故 8091 直连页面不炸，
  只是不显示 envelope 元信息行；如需 8091 也提供该静态文件，需在 portal_api `_CT` 加一行（本单按边界未改 API 文件，列接线项）；
- **页面 HTML**：由 portal_api `_html_file` 每请求从磁盘读取，合入后立即生效（无需重启）；`/d1/training` 页面 dispatch
  属 F6b（已在 master，若 8091 尚未重启则页面本身 404，属 F6b 既有接线项，本单不重复处理）。
