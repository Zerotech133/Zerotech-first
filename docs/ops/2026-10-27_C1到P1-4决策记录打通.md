## 1. 映射规则

| C1 质询卡 | P1-4 决策记录 |
|---|---|
| created / open | 创建 `proposed`，`source_card=card_id`，标题「质询卡 <id> 处理决定」 |
| answered | 保持 `proposed`（等待结案；不自动代签） |
| closed **accepted** | `approved`，`decided_by`=响应/结案人；追加 outcome「C1 结案 accepted：…」 |
| closed **rejected** | `rejected`，`decided_by`=响应/结案人 |

- 证据：卡快照路径、`severity`、`questions=N` 写入 decision.evidence；
- `review_at` = 卡日期 +7 天；`confidence=unknown`（不冒充判断）；
- **幂等**：按 `source_card` 查找已有记录，不重复创建；已终态不重复决策；
- 只读 C1 账本、只写 P1-4 账本；**不改 C1 卡状态、不派单、不执行**。
