**结论**：两侧记忆均为 Markdown `## 小节` 形态 ⇒ 桥 = **小节级搬运 + sha1_12 内容哈希去重 + provenance 注释**，无需格式转换。

## 三、桥设计（v0.1 影子）

```
E:\老田的AI助手\Hermes\cowbridge\
├── cowbridge.py                    # 桥本体（约 270 行，纯标准库）
└── shadow\
    ├── to-cowagent\                # Hermes → CowAgent 候选
    │   ├── candidates.jsonl        # 逐行 {side,file,header,body,sha1,ts,action}
    │   └── daily-YYYY-MM-DD.sample.md
    ├── to-hermes\
    │   └── MEMORY.increment.md     # CowAgent → Hermes 增量候选（带 provenance）
    ├── review-*.md                 # 人审对照报告
    └── fixtures\cow-workspace\     # selftest 合成样本
```

- **去重**：`sha1(header + "\n" + body)` 前 12 位；对侧已有内容判 `dup` 跳过
- **provenance**：`<!-- provenance: cow:{file} sha1:{sha1} tier:{long|mid} -->` 写入 increment 每条目
- **结构噪音过滤**：纯标题 preamble（剔除 Markdown 标题行后无实质内容的 H1 块）不进候选——否则每个带 H1 的文件都产出一条 `### (preamble)` 噪音淹没人审；有实质内容的 preamble（如 USER.md 主题描述行）保留，人审可判
- **分层映射**：CowAgent `MEMORY.md` → tier:long；`daily/*.md` → tier:mid；Hermes 双文件 → CowAgent long 层候选
