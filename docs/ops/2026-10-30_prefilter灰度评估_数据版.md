# prefilter 灰度评估（数据版，2026-10-30）

> 工单：K-ORG-20261030-PREFILTEREVAL ｜ 只读评估（news.db mode=ro，零 GPU）
> 工具：`tools/jev_prefilter_eval.py`（--mode safe|aggressive）

## 一、方法（无人工标注集时的代理标注）

prefilter 一直默认关闭，开启前需量化"误杀率"（把有方向信号新闻 skip 成 neutral）。做法：
- 预筛决策：`jev_prefilter.decide(title, mode)`；
- 参照信号（代理标注）：现有 JEV 判定中 `bias∈(bull,bear)` 且 `conf>=0.75`；
- 误杀 = 预筛 skip 且参照为高置信方向信号；
- 样本 = 近 30 天已判新闻（Limit 20,000，命中上限）。

## 三、落地

### 已实现（默认仍关闭）
- `JEV_PREFILTER` 环境变量支持三种值：
  - `0`/未设 = **off（默认，行为不变）**
  - `1`/`safe` = **safe 模式（推荐）**
  - `aggressive`/`legacy` = 旧全量规则（仅用于对照/回滚验证）
- `jev_prefilter.decide(..., mode=)` / `prefilter_jev(..., mode=)`；
- safe 词表（9 条 routine 模板）：董事会/监事会决议、独董声明、章程修订、股东大会通知、月报表、定期报告披露提示、新股申购提示、休市安排；
- 个股代码守卫 + BATCH4 扩方向词仍生效（safe 模式下市场行情类一律 keep）。

### 开启方式（需老田批准）
在两个 wrapper 中加环境变量（或任务级 env）：
```
# jev-eval/start_jev_night.ps1 与 jev-eval/jev_backfill_task.ps1
$env:JEV_PREFILTER = 'safe'
```
预计收益：~1.6% 条目免 GPU 判定（routine 治理模板），年化省约 1-2 万次模型调用；误杀风险 ~0.015%。

### 回滚
1) 设 `JEV_PREFILTER=0`（停止未来 skip）；
2) 清已写 skip 行：`python -B tools/jev_prefilter_revert.py --days 30 --apply`（默认 dry-run，只清 `src=prefilter` 行）。

## 四、局限

- 代理标注 = 模型自身判定（模型高置信方向即"信号"）；若模型对 routine 公告判错，评估会低估/高估，但 100% 捕获率 + 3/312 误杀已足够支持灰度。
- 样本上限 20,000（近 30 天已判）；节假日/公告季分布变化需复测（建议开启后每周跑一次评估）。
- safe 词表只覆盖"模板化治理公告"，其余一律 keep（宁漏不误）。
