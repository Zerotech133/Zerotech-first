# ACAD1（司马徽）→ D1（鲁肃）池对接 v1

> 状态：**现行**（2026-11-16 WO-ACAD1-D1-BRIDGE）
> 脚本：`tools/acad1_pool_bridge.py` · 测试：`tools/test_acad1_pool_bridge.py`（7 例）
> 计划任务：`D1Acad1Bridge`（每日 10:00）

## 一、为什么需要

ACAD1 每天在 PG 产**官方推荐池**（`/api/acad1/pool`，`review_status=pool_reviewed`），
而 D1 侧的会审输入 `todays_picks.json` 数据日停在 11-13 —— 中间缺一条
「ACAD1 池 → D1 裁决 → 交棒」的桥。

2026-11-16 实测：

| 环节 | 状态 |
|---|---|
| ACAD1 PG 池 | `pool_date=2026-11-16`，**29 只**（CN 12 / HK 10 / US 6 / CRYPTO 1），`source_mode=pg_official_aggregated` |
| `todays_picks.json` | `scan_run_date=2026-11-13`（897 只，11-15 18:20 生成） |
| D1 `pool_v2_sessions` | 最后一场 11-13 |

PG 端口已监听（5432/5433），所以池走官方路径，**不是投影**。

## 二、边界（谁负责什么）

- **ACAD1 只选池/复核**：池条目里 `recommendation` / `confidence` / `tier` 全为 `null`；
- **D1 才裁决**：本桥按显式规则把池内标的落成五档，**不重算选股、不改池**；
- 默认只处理 **CN**（HK/US/CRYPTO 暂无行情源，交棒会跳过）；
- paper-only、不建单、不接实盘；幂等键绑定「池日 + 代码 + 来源」。

## 三、裁决规则（依据 ACAD1 既有证据，可追溯）

实测 29 只全部 `risk_flags=[]`、`selection_reason` 均以「基础信号：买点」开头、`status=selected`。

| 优先级 | 条件 | 结论 |
|---|---|---|
| 1 | `risk_flags` 非空 | **HOLD**（ACAD1 已标风险，D1 不硬顶） |
| 2 | `signal` 含「卖」/`SELL` | **SELL** |
| 3 | `selection_reason` 含「买点」或 `signal` 含「买」 | **BUY** |
| 4 | 其余 | **HOLD**（无可采信买点依据） |

**confidence 不另造数字**，由 ACAD1 `score` 归一：

```
confidence = clamp(0.45 + 0.25 × score/100, 0.45, 0.70)
带 risk_flags 再 −0.10；无买点依据 −0.05
```

## 四、交棒

BUY 且有收盘价才建（无价不造数）：

- `buy_zone = [close×0.98, close×1.01]`，`stop_loss = close×0.95`
- 两条 `watch_plans`：`wp-acad1-<池日>-<代码>-stop` / `-take`，7 天到期
- `target=WA1`（盯盘席），`paper_only/not_a_trade=true`

## 五、幂等与重跑

| 场景 | 行为 |
|---|---|
| 同日重跑 | 键相同 → 网关回放原记录，`already_judged` 计数，`todo=0` |
| 已裁决但要补交棒 | `--handoff-only`（裁决 POST 幂等返回原 ID，交棒缺失才新建） |
| 演练 | `--dry-run` 只打印映射，不发请求、不写账本 |

实测（10:15 重跑）：`already_judged=12 todo=0 processed=0`。

## 八、边界与已知限制

- **HK/US/CRYPTO 未接**：无行情源（腾讯接口仅 A 股），这些市场暂只裁决不交棒；需要港股/美股行情源后再扩；
- **tier 规则是我方映射**，不是 ACAD1 的结论——rationale 里写明「ACAD1 官方池复核产物 → D1 按规则裁 X」，可追溯也可被推翻；
- 池日为 `data_date`（11-13 数据日）与 `pool_date`（11-16 发布日）不同，去重键用 `pool_date`。
