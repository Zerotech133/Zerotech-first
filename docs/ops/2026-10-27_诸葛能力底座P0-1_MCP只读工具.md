## 2. 工具清单（全部只读）

| MCP tool | 数据源 | 说明 |
|---|---|---|
| `tasks_read` | `.worktrees/tasks.json` | 按 status/owner 过滤、limit≤100，返回任务摘要 |
| `org_read` | `agent_platform/registry/org.json` | 按 agent_id 过滤，返回席位/汇报线/LLM 绑定 |
| `docs_search` | `docs/**/*.md` | 关键词检索，返回 `path:line + snippet`（无来源不编造） |
| `health_read` | 8795 `/health`、8091 `/health` | 只读探活 + 延迟 |
| `brief_read` | 8091 `/api/zhuge/brief` | 只读读取规则建议面（可传 clock） |

**边界**：HTTP 仅允许 `127.0.0.1/localhost` 的 `http`；docs_search 只扫 `docs/`；无写文件、无 subprocess、无 eval/exec（AST 单测固化）；不派单、不执行。
