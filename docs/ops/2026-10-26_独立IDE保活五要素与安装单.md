## 一、命令全文（安装时执行）

```powershell
# 1) 每 5 分钟：8103 未监听则拉起（幂等）
schtasks /Create /TN "LegionIdeKeepalive" ^
  /TR "powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File \"C:\项目\老田的AI助手\ops\keepalive_legion_ide.ps1\"" ^
  /SC MINUTE /MO 5 /RL LIMITED /F
# 2) 登录触发：ONLOGON 任务需管理员；无权限则用 HKCU Run 兜底（本机治理时钟同款）
Set-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "LegionIdeOnLogon" ^
  -Value "powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File \"C:\项目\老田的AI助手\ops\keepalive_legion_ide.ps1\""
```

## 二、影响面

| 项 | 说明 |
|---|---|
| 新增 | 1 个计划任务（5min）+ 1 个 HKCU Run 项 |
| 每 5 分钟 | 启动一次 powershell（服务在跑时立即退出，<1s） |
| 日志 | `C:\Temp\legion_ide_keepalive.log`（只增） |
| 不碰 | 服务/网络/防火墙/系统代理/其他任务/数据；端口固定 127.0.0.1:8103（已入 REGISTRY） |

## 三、不可逆点

- 无数据破坏；任务/Run 项可随时删除。
- 注意：计划任务命令硬编码仓库路径，仓库迁移需同步改任务。

## 四、替代方案与已尝试

1. 不装：重启后手动 `-Action app`（现状，依赖人）；
2. 仅 HKCU Run：只覆盖登录，不覆盖进程意外退出；
3. 会话级后台：随会话退出，不适合常驻。

## 五、回滚预案

```powershell
schtasks /Delete /TN "LegionIdeKeepalive" /F
Remove-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "LegionIdeOnLogon" -ErrorAction SilentlyContinue
# 服务本体：powershell -ExecutionPolicy Bypass -File ops\start_legion_ide.ps1 -Action stop
```
