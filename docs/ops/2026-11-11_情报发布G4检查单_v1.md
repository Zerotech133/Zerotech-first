# 情报发布 G4 检查单（v1）

- 日期：2026-11-11｜适用：研判卡/情报成品**发布前**
- 定性：人工检查单（先人工执行，工具化另议）；**不替代** G0–G6 质量门、L2/L3 签批
- 对应：`deliverables/2026-11-11_情报研判方法选择与质量门_v1.md` 的 G4 挑战门
- 执行人：作者 + 独立复核人（作者自评不算挑战）

## 使用规则

1. 每张准备发布的研判卡，复制本表一份，逐项作答；空白=未过。
2. 五问中任一项无法回答 → **不得发布**；只能留作内部草稿。
3. 仅表达/置信度不足（G5）→ 可发“暂定版”，须带有效期、置信度依据、复核人。
4. 检查结果回填研判卡六个字段（可空字段，但发布时应尽量填）：
   `assumptions / alternatives / disconfirming_evidence / information_gaps /
   early_warning / feedback_due`。
5. 检查单与卡同留痕（deliverables 或工单附件），不进 `intel_briefs` 正文。

## 五问（必答）

| # | 问题 | 本卡回答 |
|---|---|---|
| 1 | **关键假设是什么？** 哪些假设一旦被推翻，结论就不成立？ | |
| 2 | **最强的替代解释/竞争性假设是什么？** 为什么排除它？ | |
| 3 | **反证与异常证据有哪些？信息空白在哪里？** 现有证据的诊断力够不够？ | |
| 4 | **如果 6–12 个月后回看是错的，最可能的前三个原因是什么？** 各自的预警指标/触发条件是什么？ | |
| 5 | **谁做的独立复核？** 复核人提出的异议是什么？复核后置信度如何调整？ | |

> 第 4 问即事前分析（premortem）的最小版：只写“可能失败”，不写缓解责任人，视为未完成。

## 回填字段对照

| 字段 | 来源问题 | 填写要求 |
|---|---|---|
| `assumptions` | 1 | 分号分隔，≤5 条，每条可证伪 |
| `alternatives` | 2 | 至少 1 条替代解释及排除理由 |
| `disconfirming_evidence` | 3 | 具体证据/来源，不写“暂无” |
| `information_gaps` | 3 | 缺什么、影响多大、能否补 |
| `early_warning` | 4 | 可观测指标 + 触发阈值 |
| `feedback_due` | 4/5 | 复盘日期 + 责任人 |
