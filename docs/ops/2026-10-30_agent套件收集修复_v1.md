# agent 套件收集错误修复 v1（2026-10-30 · 关羽 P78）

> 背景：agent_platform 测试套件长期无法完整运行（16 个模块收集错误），导致 P1-4 的 10 条 agent flaky 无法验证。
> 本单修复收集、完成失败分类入基线，并启动 flaky 复验。

## 一、根因

- 现象：`pytest agent_platform/tests` → `ModuleNotFoundError: No module named 'tools.safe_urlopen'; 'tools' is not a package`（16 errors）；
- 二分：`--import-mode=importlib` 或显式 `PYTHONPATH=<仓库根>` 后收集 **0 errors** → 根因是 **pytest prepend 模式下仓库根未在 sys.path 前部**，
  且 `agent_platform` / 测试目录被插到前面后，`tools` 被解析到错误位置（agent_platform/tools 无包标记）；
- 影响面：仅测试收集；生产进程通常带仓库根路径，未受影响。

## 二、修复（最小、集中）

新增 `agent_platform/tests/conftest.py`（仅测试期生效）：
1. 把仓库根插入 `sys.path[0]`；
2. 清理可能已误绑的 `tools` / `tools.*` sys.modules 条目。

效果：
- 收集：**2,457 tests collected / 0 errors**（修复前 2,324 + 16 errors）；
- 单文件 `test_a0_agent_p1.py`：10 passed（修复前收集即失败）；
- 全量套件：**2,444 passed / 8 failed / 4 skipped / 1 xfailed**（~305s）。

- 本轮：2 轮基线复验（结果附报告）；10 条 flaky 需累计 **7 轮 0 复现**方可淘汰（按 SOP）；
