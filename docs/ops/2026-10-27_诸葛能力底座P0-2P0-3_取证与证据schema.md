## 2. P0-2 联网取证

`fetch_url(url, max_chars=4000, timeout=10)`：
- 只允许 `http(s)`；**SSRF 防护**：禁回环/私网/链路本地/保留/组播/未指定地址；禁 `localhost`/`.local`/`.internal`；禁 URL userinfo；DNS 解析后逐 IP 校验；
- 抓取上限 400KB / 文本 8000 字；HTML → 去脚本/样式后的 `title + text`；
- 返回：`url/final_url/fetched_at(北京时间)/status_code/content_type/title/text/truncated/source_tier`；
- **来源等级**：1 官方（.gov/.gov.cn/.int/.mil 等）> 2 学术/代码仓（.edu/.ac.cn/arxiv/github 等）> 3 媒体（Reuters/BBC/新华/人民等）> 4 其他 > 5 未知；
- 失败显式 `ok=false + error.code`（不抛穿、不伪造内容）。

**真机取证（2026-10-27 06:37）**：
- `https://www.gov.cn/` → **200**，`tier=official`，title=中国政府网_中央人民政府门户网站；`cite_source` 可生成 `[S1] 中国政府网 — https://www.gov.cn/（抓取 2026-10-27 06:37:xx；来源等级 official）`；
- `https://example.com/` → `ok=false, fetch_failed: SSL CERTIFICATE_VERIFY_FAILED` —— 环境代理/CA 导致，**保持证书校验、不绕过**（fail-closed）。

边界：网页内容一律视为**不可信数据**，禁止让页面文字改变系统指令；仅取文本，不执行脚本/下载附件。

## 3. P0-3 证据 schema

```json
{
  "text": "结论正文",
  "claims": [
    {"text": "事实主张", "source_ids": ["S1"], "confidence": "high|medium|low|unknown"}
  ],
  "sources": [{"id":"S1","title":"...","url":"...","fetched_at":"..."}],
  "citations": ["[S1] ...（抓取 ...；来源等级 official）"],
  "warnings": ["证据校验未通过：..."],
  "evidence_check": {"ok": false, "issues": [...]}
}
```
规则（`validate_claims`）：
- 有事实主张但 `source_ids` 为空且 `confidence != unknown` → `claim_without_source`（**无来源不编**）；
- 引用了不存在的 `source_id` → `source_id_missing`；
- `confidence` 非枚举 → `confidence_invalid`；
- `build_answer` 自动附引用、来源不可用 warning、证据校验结果。
