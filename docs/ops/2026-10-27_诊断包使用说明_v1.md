# 诊断包使用说明（O7 Diagnostics）

- **工具**：`tools/diagnostics.py`（只读采集 + 脱敏，zip 输出）
- **用途**：故障/排障/夜跑失败时，一条命令拿到"系统现场"，避免逐项手查；也可用于交付/审计取证。
- **边界**：不改服务、不重启、不读 `_vault` 密文、不导出凭据值。

## 一、内容

| 文件 | 内容 |
|---|---|
| `meta.json` | 时间、git commit/分支/脏文件数、Python/OS、环境变量**是否存在**（不含值）、端口注册数 |
| `ports.json` | 关键端口探测（8091/8734/8796/8795/8787/8096/8094/8080/8101） |
| `health.json` | 关键 HTTP 端点状态/耗时 |
| `quality.json` | `quality_scale_check --json` 结果（24 对象分级） |
| `tests.json` | 最近 e2e artifact 摘要 + 最近夜跑 baseline 摘要 |
| `logs/*.log` | 允许清单日志尾部（每份 200 行、≤256KB，已脱敏） |
| `README.txt` | 包说明 |

**允许的日志清单**：`portal_api_task`、`legion_command_8796`、`legion_gateway_8795`、`feishu_bot`、`feishu_bot_heartbeat`（路径见脚本 `LOGS`）。

## 二、脱敏规则

- `token=/api_key=/secret=/password=/authorization:` 的值 → `<redacted>`；
- `sk-*`、`ghp_*`、`xox[baprs]-*`、`Bearer <token>` → `<redacted>`；
- 环境变量只记录"是否存在"（bool），不导出值；
- 包内不含 `_vault` 内容、不含 cookie/请求头。

## 三、用法

```powershell
python -X utf8 tools/diagnostics.py                 # 默认输出 agent_platform/data/dev/diagnostics/
python -X utf8 tools/diagnostics.py --out D:\diag   # 指定目录
python -X utf8 tools/diagnostics.py --no-logs       # 不含日志（最小包）
python -X utf8 tools/diagnostics.py --json          # 只打印摘要（zip 路径/健康）
```

- 单测：`python -m pytest tools/test_diagnostics.py -q -p no:cacheprovider`（7 项，不依赖在线服务）。
- 处置建议：先看 `health.json` → `ports.json` → `logs/` 对应服务尾部 → `tests.json` 是否夜跑新增失败。

## 四、保留

- zip 落 `agent_platform/data/dev/diagnostics/`（运行态数据，不入 git）；按需手工清理，不做自动删除。
- 与 O5 e2e、D2 夜跑配合：失败时先生成诊断包再排查，回执附包名。
