## 二、W0-3 执行方法（只读 → triage → 安全回收）

### 2.1 只读审计（不写）

```powershell
git -C C:\项目\老田的AI助手 worktree list --porcelain
git -C C:\项目\老田的AI助手 branch --list 'task/*'
python -X utf8 tools/devtask.py list --strict

```

输出：每个 worktree 的 owner/状态/是否有 commit/是否干净/是否已 merge。

### 2.2 triage 分类

| 类别 | 判定 | 动作 |
|---|---|---|
| A 已合并且干净 | status=done + 分支已 merge + clean | 回收（`devtask.py prune --apply`，先 dry-run） |
| B aborted 且干净 | status=aborted + clean | 回收（保留分支名/原因） |
| C parked/doing | 有未提交或待验收 | **保留**，owner 24h 内定性（续/停/归档） |
| D 无主/失联 | 无 owner 或超 7 天无活动 | 标黄进周报，owner 确认后再动 |

**红线**：不得对 C/D 执行删除/强推；回收只针对 A/B；prune 先 `--dry-run` 后 `--apply`。
