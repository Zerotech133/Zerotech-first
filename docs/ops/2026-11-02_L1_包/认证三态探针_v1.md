### 3.2 态二：已登录（门户会话，密码通道）

> 前置：本地管理员凭据在 `C:\项目\_vault\secrets\zb_admin.env`（`ZB_ADMIN_USERNAME`/`ZB_ADMIN_SALT`/`ZB_ADMIN_HASH`，只存 PBKDF2 哈希，**不得打印**）。
> **[验证·会建会话]** 以下为 L2 窗口内由执行人手工执行；执行前先确认 8091 在线，执行后关闭会话（logout）或等 TTL（3600s）自然过期。

```powershell
$B = "http://127.0.0.1:8734"
$jar = Join-Path $env:TEMP "zb_auth_probe.cookies"

# [验证·会建会话] 1) 本地管理员登录（用户名从 vault 读取，密码人工输入/读环境变量，不打印）
$user = (Select-String -Path 'C:\项目\_vault\secrets\zb_admin.env' -Pattern '^ZB_ADMIN_USERNAME=').Line.Split('=',2)[1]
curl.exe -s -i -c $jar -X POST "$B/api/auth/login" -H "Content-Type: application/json" `
  --data-binary ("{`"username`":`"$user`",`"password`":`"$env:ZB_ADMIN_PASSWORD`"}")
# 预期：HTTP 200；Set-Cookie: zb_session=<随机>; Path=/; HttpOnly; SameSite=Lax; Max-Age=3600
#       body: {"ok": true, "sub": "zero_bound:owner", "local_admin": true, "expires_in": 3600}
# 禁止：cookie/token 写日志或回显到交付物

# [验证] 2) 会话三连：me / guard / bff identity
curl.exe -s -b $jar "$B/api/auth/me"
# 预期：200；{"ok":true,"mode":"session","session":{"session_id":"...","sub":"zero_bound:owner","idp":"local-admin",
#   "auth_time":"...","issued_at":"...","expires_at":"...","amr":["pwd"],"read_only":true,
#   "identity_context":{...},"csrf_token_hash":"..."},"csrf_token":"<一次性>"}
#   ← csrf_token 只在响应出现，不落盘不打印；服务端 SessionStore 另有 capacity="readonly"（不下发，非授权字段）
curl.exe -s -o NUL -w "guard -> %{http_code}`n" -b $jar "$B/api/auth/guard"     # 预期 200
curl.exe -s -b $jar "$B/api/bff/identity/me"                                    # 预期 200，含 identity_context.display_name

# [验证] 3) 受保护面放行
curl.exe -s -o NUL -w "devops -> %{http_code}`n" -b $jar "$B/devops"            # 预期 200
curl.exe -s -o NUL -w "api/org/tasks -> %{http_code}`n" -b $jar "$B/api/org/tasks"  # 预期 200（会话放行）
curl.exe -s -o NUL -w "quant -> %{http_code}`n" -b $jar "$B/quant/"             # L2 后预期 200（quant/index.html）
curl.exe -s -b $jar "$B/quant-api/api/v1/health"                                 # L2 后预期 200 {"status":"ok",...}

# [验证] 4) 会话只读边界（不得越权写）
curl.exe -s -o NUL -w "POST /api/org/tasks -> %{http_code}`n" -b $jar -X POST "$B/api/org/tasks" -H "Content-Type: application/json" --data "{}"
# 预期：>=400（405/401/403 之一；8091 写端点仍需 X-Portal-Token 或具备写权限的会话）

# [验证] 5) 登出：csrf 从 me 响应取（脚本内变量，不落盘）
curl.exe -s -b $jar "$B/api/auth/me" | ConvertFrom-Json | ForEach-Object { $csrf = $_.csrf_token }
curl.exe -s -o NUL -w "logout -> %{http_code}`n" -b $jar -c $jar -X POST "$B/api/auth/logout" -H "X-CSRF-Token: $csrf"
# 预期：200 {"ok":true,"logged_out":true}；再执行 me/guard 预期 401
Remove-Item $jar -Force -ErrorAction SilentlyContinue

# [验证·会建会话] 6) 智策账号密码桥（L1 前置修完 #17 后才可用）
curl.exe -s -o NUL -w "login(zhice acct) -> %{http_code}`n" -c $jar -X POST "$B/api/auth/login" `
  -H "Content-Type: application/json" --data-binary '{"username":"<v2_user.username>","password":"<人工输入>"}'
# 预期：修前（8102 已停）=401 invalid_credentials（假失败）；
#       修后（ZHICE_BASE=8105）=200 且 sub 来自 identity_registry 映射；未映射账号=403 identity_not_mapped

# [只读] 7) 会话存储是内存：8091 重启即全体失效（L1 已知取舍，无需回滚动作）
# 验证方式：重启前后对同一 cookie 请求 /api/auth/me，预期 401。
```

### 3.3 态三：角色（身份映射 / 权限描述 / 强制面）

> 事实基线：**L1 没有 RBAC 强制点**。identity_registry 的 `roles/permissions` 是描述性契约（`identity_registry.py:9-12` 明文红线），session 固定 `capacity=readonly`（`auth_gateway.py:95`）。因此“角色态”当前验证三件事：①身份是否映射成功；②会话是否只读；③前端/接口是否有任何按角色放行的误实现。L1 验收不得把“描述性角色”误报为“已鉴权”。

# [只读] 5) 角色三态命令化（L2 目标形态，当前仅登记不执行）

| 要素 | 内容 |
|---|---|
| 命令全文 | 编辑 vault runtime env：`C:\项目\_vault\pocket-id\secrets\oidc_runtime.env` 中 `AUTH_OIDC_MODE=on`（其余键已存在则不动）；**不重启 8091、不重启容器**（下次 OIDC 请求即生效）。验证：`curl.exe -s $B/api/auth/oidc/status` 应 mode=on；`curl.exe -s -o NUL -w "%{http_code} %{redirect_url}" "$B/api/auth/oidc/start?next=/quant/"` 预期 302 → `http://localhost:1411/authorize?...` |
| 影响面 | 登录页出现 PocketID 入口；已映射 idp_sub（owner）可 passkey 登录；未映射 403；密码桥保留为回退 |
| 不可逆点 | 无数据/代码不可逆；但**凭据文件改动**须先备份原文件（`oidc_runtime.env.bak_<日期>`），且禁止把 secret 写入日志/交付物 |
| 替代方案 | 保持 shadow（不切 on），密码通道先行；或 PocketID 保持仅备用（L2） |
| 回滚预案 | 把 `AUTH_OIDC_MODE` 改回 `shadow`（或删除 runtime 文件 → auth_oidc_runtime 自动 mode=off），下一次 OIDC 请求即生效；已建 session 不受影响（TTL 到期自然失效） |

## 6. 边界与不做

- 本文不含任何密码/secret/token 值；`zb_admin.env`、`oidc_runtime.env`、`zero_bound_client.env` 只引用路径，不读取内容进交付物。
- 不新增认证旁路；不移除任何既有 `auth_request`；不把 `/api/` 整体加锁（H4-B 白名单契约不变）。
- 不执行登录/登出以外的写请求；§3.2 的 `POST` 仅登录/登出（建立与销毁会话），写拒绝探针为负例请求（预期失败，不产生业务写入）。
- 若执行时发现 OIDC `ready=false` 或 PocketID 容器非 healthy，**停止 L1 认证切换**，回退到密码通道并记录（不现场修凭据）。
