## 3. 状态机（强校验）

```
proposed → approved | rejected | deferred
deferred → proposed | approved | rejected
approved → implemented | superseded
implemented → superseded
rejected / superseded → 终态
```
- `approved`/`implemented` 必须记录 `--by`（决策人）；
- 非法迁移/缺决策人直接拒绝（不写账本）；
- 幂等：同 title+question+recommendation 重复 create 返回 duplicate。

## 4. CLI

```powershell

  --alternatives "A|B" --evidence "[S1]..." --risks "..." --confidence high \
  --tags rag --source-card ZQ-20261027-01 --review-at 2026-11-03
python tools/zhuge_decision_record.py decide DR-20261027-01 --status approved --by 老田 --note "批准"
python tools/zhuge_decision_record.py update DR-20261027-01 --outcome "已上线" --adoption-id "A-1"
python tools/zhuge_decision_record.py list --status approved
python tools/zhuge_decision_record.py show DR-20261027-01
python tools/zhuge_decision_record.py review-due --day 2026-11-03
```
