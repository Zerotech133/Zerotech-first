## 2. 方法

工具：`tools/datawarehouse/qualify_probe.py`（只读取证；`--apply` 仅写 registry 四个资格字段）。

1. **catalog 条目**：store/layout/date_col/files/rows/freshness/verification_status。
2. **磁盘实况**：store 存在性；递归 parquet 文件数（同时记顶层文件数与一级子目录名）；最多 5 个样本文件读 footer `num_rows`、`num_row_groups`、schema 前 30 列。
3. **最新业务日**：优先取样本文件末行组 footer statistics 的日期列 `max`（不读数据页）；取不到才回退文件名日期并标 `latest_degraded=true`。无日期列（静态表）标 `no_date_column`。
4. **manifest**：表名是否严格出现在 `tushare/_manifest.json` 顶层键。
5. **新鲜度**：`lag_days = today(20261027) - 最新业务日`；`lag<=7` 才允许 `evidence_ok`，未来日期单列 `future_date`。

抽样策略（总量上限 5 文件/表）：

- 文件名含日期（8 位日/6 位月）：按日期倒序取最近 4 个 + 最大 1 个；先按文件大小剔除明显 schema-only 空壳（同目录空 parquet 大小近似），避免“最近 4 个全是 0 行空壳”掩盖真实最新日。
- 文件名无日期：按 mtime 倒序取最近 4 个 + 最大 1 个。

verdict 判定：

- `evidence_bad`：store 缺失 / 无 parquet / 抽样 0 行。
- `evidence_partial`：manifest 缺，或最新日不可证/degraded，或无日期列，或 lag>7，或未来日期。
- `evidence_ok`：store 在 + ≥1 parquet + 抽样有行 + 最新日可证 + manifest 在 + lag≤7。

局限：行数是 5 个样本 footer 行数之和，不是全表行数；最新日来自样本 footer，若最新非空文件未被抽到会低估。文档表格中的“行数”均为抽样行数。

## 5. 关键发现与风险

1. **manifest 是共同缺口**：26 张全部不在 `tushare/_manifest.json`（38 键）。即使 anns_d/index_global/us_daily 等最新日仅 lag 1–4 天，也只能判 partial；批次 2 应补 manifest/采集回执，或明确“深表不走 manifest”的豁免规则。
2. **15 张 lag>7**：hk_balancesheet/hk_cashflow/hk_fina_indicator/hk_income（119）、us_balancesheet/us_cashflow/us_fina_indicator（119）、us_income（87）、top10_floatholders（57）、top10_holders（34）、index_weight（27）、irm_qa_sh/irm_qa_sz（13）、limit_list_d（13）、quarantine_prod_overwrite（295）。季度/静态表需按业务频率重设 lag 阈值，不能一律 7 天。
3. **stk_pledge 未来日期**：footer `end_date` 最大 20261231（lag=-65），属未来日期；需业务确认是质押到期日/计划日，不能直接当“最新数据日”。
4. **sw_l1_member 无日期列**：31 个 parquet（行业成员关系）静态表；按当前规则只能 partial，需在资格规则里增加“静态表无日期”分支。
5. **quarantine_prod_overwrite 是隔离区，不是独立源**：store 顶层 0 个 parquet；仅 `index_daily/`、`margin_detail/` 下 2 个 prod 覆盖隔离副本（14,284 行）。本工具按“磁盘实况”递归计数，判 partial；若按“顶层 0 文件”口径则为 bad。建议批次 2 决定注销/降级该资产，避免它被当成可查询数据源。
6. **limit_list_d 尾部空壳**：20261015–20261027 多个 parquet 为 0 行 schema 空壳，最近非空日为 20261014（与 catalog freshness 一致）；探针已按大小剔除空壳后取到 20261014，未误报 20261027。
7. **index_global 口径待定**：catalog `manifest_status=not_applicable`、`verification_status=verified`，但严格按“是否在 `_manifest.json`”判 missing。若确认 not_applicable 可豁免，它是本批唯一可能升 `evidence_ok` 的表（lag=1，20 文件，抽样 10,864 行）。
8. **catalog_snapshot 的 rc=1 是既有漂移**：`cyq_perf` catalog 273 / 磁盘 274；`guba_posts` 是 jsonl 但 snapshot 只数 `*.parquet`（0 vs 372）。与本批 registry 写回无关，写回前后均如此。
