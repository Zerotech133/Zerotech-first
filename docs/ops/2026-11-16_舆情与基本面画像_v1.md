# 舆情与基本面画像（F1 / N1 数据源）v1

> 状态：**现行**（2026-11-16 WO-FIN-PROFILE / WO-SENT-PROFILE）
> 脚本：`tools/finance_profile.py` · `tools/sentiment_profile.py`
> 测试：`tools/test_finance_profile.py`（7 例）· `tools/test_sentiment_profile.py`（6 例）

## 一、要解决的问题

投研四席里，T1/T2 靠 `xsec_profile`（量价/结构）能说话，而 **F1 与 N1 恒定输出 `unknown`**——
因为工单里只有技术信号，没有任何财务与舆情字段。四席里两席永远弃权，`BUY`（需 ≥2 席看多）也就永远出不来。

两个 profile 就是给这两席接上数据源。

## 二、数据源实测对照（2026-11-16，全部实跑过）

### 2.1 基本面：可用的

| 文件 | 规模 | 用途 |
|---|---|---|
| `fina_indicator.parquet` | 173 MB / 108 列 | 主料：roe、毛利率、净利率、负债率、流动比、营收/净利同比、单季营收同比、现金流指标 |
| `daily_basic.parquet` | 234 MB | 估值：pe_ttm / pb / ps_ttm / 换手率 |
| `stock_basic.parquet` | 1.9 MB | 名称 / 行业 / 市场 / 上市日 |

单只读取 **0.68 秒**（pyarrow 列过滤 + `ts_code` 过滤）。

### 2.2 舆情：可用与不可用（这一节比"用什么"更重要）

| 源 | 结论 | 原因 |
|---|---|---|
| `irm_qa_sz.parquet`（深交所互动易） | **可用** | 有 `ts_code`；`001228.SZ` 210 条，近 180 天 35 条**全部有公司答复** |
| `stk_holdernumber.parquet` | **可用** | 股东户数变化 → 筹码集中/分散 |
| `moneyflow.parquet` | 可用（可能全零） | 大单/特大单净额 → 资金情绪 |
| `margin_detail.parquet` | 视标的 | 非两融标的为 0 行 |
| `guba/`（股吧） | **不可用** | 每只股票的 jsonl **全是 0 字节** |
| `xueqiu/`（雪球） | **不可用** | 只有配置与结果文件，无行情/帖子快照 |
| `news.parquet` / `major_news.parquet` | **不用** | **没有 `ts_code`**，只能按股票名匹配标题，易误伤 |

后三项"不用"是实测结论，不是没找——写在这里是为了**下次不再重复试**。

## 三、两份画像各取什么

### `finance_profile.py`

```
report        end_date / ann_date / lag_days
profitability roe / roe_dt / gross_margin / net_margin
growth        revenue_yoy / profit_yoy / q_sales_yoy
solvency      debt_to_assets / current_ratio
cash          ocf_yoy / ocfps / cash_ratio
valuation     pe_ttm / pb / ps_ttm / turnover_rate
basic         name / industry / market / list_date
trend         最近 4 期的 roe / net_margin / revenue_yoy
warnings      滞后、估值缺失等
```

### `sentiment_profile.py`

```
qa         total_qa / window_qa(180天) / window_answered / last_date
           last_question / recent_questions(3) / risk_word_hits
holders    holder_num / prev_holder_num / change_pct / note(集中|分散)
moneyflow  main_net_wan(近5日) / daily[] / note(全零时)
warnings   无源、全零等
```

风险词表（固定 10 个，命中即报，**不做打分**）：诉讼 / 减持 / 亏损 / 问询 / 退市 / 质押 / 商誉 / 计提 / 停牌 / 违规。

## 四、四个语义陷阱（都显式处理了）

| 陷阱 | 错误做法 | 现在 |
|---|---|---|
| **全零 ≠ 平衡** | moneyflow 全 0 → 报"资金无异常" | 加 `note`「全零，不作为资金情绪依据」+ warning |
| **NaN ≠ 0** | 缺 roe 填 0 → 看起来"盈利为零" | NaN/None 一律剔除或置 `None` |
| **滞后 ≠ 缺失** | 报告期 139 天前 → 以为没数据 | 写 `lag_days` + `warnings`「可能是新报告期未入库」 |
| **非标的 ≠ 无情绪** | 非两融标的 0 行 → 以为没杠杆情绪 | 该字段整块不出现，不报 0 |

## 五、接入范围（只喂用得上的席位）

| 画像 | 喂给 | 理由 |
|---|---|---|
| `xsec_profile`（量价/结构） | 全部四席 | 都是技术/结构基础 |
| `finance_profile` | **F1 + T2** | F1 看基本面；T2 要估值/财报做反证 |
| `sentiment_profile` | **N1 + T2** | N1 看情绪；T2 也看资金/关注度 |

`--no-fin` / `--no-sent` 可单独关闭。

## 七、测试覆盖

`finance_profile`（7 例）：有数据 / 无记录 / 无文件 / **NaN 不填 0** / 滞后 warning / 估值缺失 / slim 白名单。

`sentiment_profile`（6 例）：180 天窗口 + 空答复不计 + **风险词命中** / 户数变化方向 / **全零告警** / 非零换算 / 无源 `available=false` / slim 白名单。

## 八、仍然出不来 BUY 的原因（重要）

四席都能表态后，`001228.SZ` 仍是 HOLD：

```
T1 bull    （有买点，但量能收缩、抢跑待核验）
T2 bear    （高估 + 减利 + 位置高）
N1 neutral （筹码集中，但无公告/资金配合）
F1 neutral （增收不增利、撑不住 37 倍 PE）
→ 辩论 2 轮 → 立场不变 → HOLD
```

**不是数据不够，是空头的反证成立。**只要 T2 能拿出「高估 + 减利 + 高位」，`BUY` 就不该出现——这是规则在正确工作，不是缺陷。

## 九、已知限制

- 财务数据最新到 **2026 中报**（lag 139 天），三季报未入库；
- 互动易只覆盖**深市**（`irm_qa_sz` 的 `_sz` 后缀），沪市标的 N1 会拿到「无记录」；
- 新闻类源无 `ts_code`，暂不接入；
- 不做情绪打分模型、不推断利好利空——只给计数与原文片段。
