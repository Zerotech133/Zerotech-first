# BFF 智策只读服务账号 · 月度轮换 Runbook v1

- 对象：`zero_bff`（智策 `v2_user`，角色 **VIEWER**）
- 用途：零界只读 BFF 登录智策 8102，仅 GET 行情/策略
- 凭据：`C:\项目\_vault\secrets\zhice\bff_service.env`（**不入库、不回显、不进日志**）
- 建议频率：**每月最后一个工作日 09:00**，由 A0/值班执行
- 影响面：只影响 `/api/bff/zhice/*`；`/api/bff/cainiao/stats` 与页面其他部分不受影响

## 轮换步骤

1. **先建新账号**（不停旧账号）：
   - 用 `POST http://127.0.0.1:8102/api/v1/auth/register` 创建 `zero_bff_YYYYMM`；
   - 生成随机强密码（≥24 字符），只在安全终端/密码管理器中出现；
   - 用管理员或 DB 将角色置为 `VIEWER`（最小权限）。
2. **验证新账号只读**：
   - `POST /api/v1/auth/login` 拿 token；
   - `GET /api/v1/market/overview`、`GET /api/v1/strategies` 应 200；
   - `POST /api/v1/positions` 应 403/401（确认 VIEWER 只读）。
3. **原子替换 vault 凭据**：
   - 写入临时文件 → 校验非空 → 原子替换 `bff_service.env`；
   - 旧文件保留一份加密备份，24h 后销毁。
4. **重启 8091 清缓存**（BFF 内存 token 缓存 50 分钟）：
   - 创建 `C:\Temp\PORTAL_API_RESTART.flag`；
   - `Start-ScheduledTask -TaskName 'AI工作站门户API'`；
   - 验证 `/health` 200。
5. **验收**：
   - `/api/bff/zhice/health` 200；
   - `/api/bff/zhice/market/overview` 200；
   - `/api/bff/zhice/strategies` 200（条数 >0）；
   - `/api/bff/overview` 200；
   - 页面 `/os-entry` 工作平台「三系统只读」面板显示智策在线。
6. **收尾**：
   - 停用/删除旧 `zero_bff_*` 账号（`v2_user` 置 `is_active=false` 或删除）；
   - 在工单/STATUS 记录轮换日期与验证结果，**不记录密码**。

## 回滚

- 恢复上一份 vault 凭据 → 重启 8091 → 验证四个端点；
- 若新账号登录失败，先恢复旧凭据保可用，再排查。

## 安全红线

- 不把凭据写进仓库、脚本、URL、聊天记录；
- 不用 ADMIN 账号做 BFF 服务账号；
- 不做写操作测试（BFF 只读；VIEWER 写保护是第二道门）；
- 轮换属配置变更，按 L2 记录；重启 8091 需显式批准。
