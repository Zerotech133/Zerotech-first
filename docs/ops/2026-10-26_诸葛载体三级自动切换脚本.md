# 诸葛载体三级自动切换脚本（2026-10-26）

- 脚本：`ops/zhuge_carrier_switch.ps1`（工单 `WO-LEGION-ZHUGE-SWITCH-20261026`）
- 用途：网络条件变化时，把 OpenClaw `zhuge` agent 的载体切到**当前可达的最高优先档**，并自检、失败自动回滚。
- 背景：诸葛亮真身 = GPT-6.0（`itokengate/gpt-6-sol`），跨境网络不可达期间用 `deepseek/deepseek-chat` 中转；内网 ms1max 双机（`.156/.155`）作为另一档可达时的替代。**标签由调用侧按 agent-config 实读，切换后自动变（openclaw_gpt / openclaw_cloud+carrier），无需重启 8091/8796。**

## 档位（从高到低）

| 档位 | 模型 | 探测 |
|---|---|---|
| `gpt6` | `itokengate/gpt-6-sol` | `itokengate.com:443` |
| `ms1max35` | `ms1max-35b/qwen36-35b-fast` | `192.168.5.156:8080` |
| `ms1max177` | `ms1max-177b/qwen38-flash` | `192.168.5.155:8080` |
| `deepseek` | `deepseek/deepseek-chat` | `api.deepseek.com:443`（兜底） |

## 用法

```powershell
# 1) 默认 dry-run：探测 + 打印目标，不改配置（推荐先跑）
powershell -NoProfile -ExecutionPolicy Bypass -File ops\zhuge_carrier_switch.ps1 -DryRun

# 2) JSON 输出（供监控/日报采集）
powershell -NoProfile -ExecutionPolicy Bypass -File ops\zhuge_carrier_switch.ps1 -DryRun -Json

# 3) 执行切换（备份 → openclaw config patch → validate → 真实推理自检；失败自动回滚）
powershell -NoProfile -ExecutionPolicy Bypass -File ops\zhuge_carrier_switch.ps1 -Apply

# 4) 强制指定档位（测试/运维手工切回）
powershell -NoProfile -ExecutionPolicy Bypass -File ops\zhuge_carrier_switch.ps1 -Apply -ForceTier deepseek
```

- 备份：`C:\Temp\oc_cfg_backups\openclaw-<stamp>.json`（每次 Apply 前自动）。
- 日志：`C:\Temp\zhuge_carrier_switch.log`。
- 退出码：`0` = 成功/无需变更；`1` = 失败或已回滚。
- 只读探测超时默认 2s（`-ProbeTimeoutMs`），自检推理超时 150s（`-InferTimeoutSec`）。

## 纪律

- 默认**只读 dry-run**；`-Apply` 才写，写前备份、写后 `openclaw config validate` + 一次真实推理自检，任一失败即回滚。
- 不落盘密钥：key 始终由 OpenClaw secret store（write-only）解析。
- **挂计划任务属 L2**（计划任务增删需老田批准），脚本本身不注册任何任务；如需「网络恢复自动切」再按 L2 五要素审批后配置触发。
- 自检通过不代表席位语义变化：L5/会议厅标签仍按 agent-config 实际值诚实展示（GPT6 / 中转替代），不冒充。
