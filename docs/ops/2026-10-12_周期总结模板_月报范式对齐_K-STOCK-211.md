## 一、范本解剖（七件套 + 风格三律）

范本仅 2 页，数据密度极高。结构逐件：

| # | 模块 | 内容 | 特点 |
|---|------|------|------|
| 1 | 页眉识别区 | 产品名 + 期号（2026年9月）+ 免责声明 | 每页重复，合规固定件 |
| 2 | **历史业绩表** | 基准 vs 本产品，6 指标：累计回报率 / 年化收益率 / 年化超额 / 最大回撤(日) / 夏普比率 / 卡玛比率 | 两列对照，一眼见分晓 |
| 3 | **逐期表现表** | 发行以来每期三行：SOXX / 本基金 / 超额 | 12 个月全量，无隐藏亏损期 |
| 4 | 当期表现段 | 截至日、累计收益、当期基准涨幅、当期产品收益 | 100 字内，只给数字 |
| 5 | **下期投研重心** | 3 条 bullet：模型迭代 / 组合动态精进 / 交易执行改进 | 每条=动作+目的，不超 3 条 |
| 6 | **月度点评** | 行情回顾 → 策略运作 → 归因 | 跑输 10.57pp 不回避，归因到「主动降 Beta、增配防御」的决策逻辑 |
| 7 | 页脚信息卡 | 投资目标 / 币种 / 注册地 / 成立日期 / 基金结构 / 收费（管理费 1.5% + 表现费 20% hurdle 8%）/ 开放日 / 锁定期 | 固定件，月月不变 |

**风格三律**（学的是气质不是数字）：
1. **凡业绩必有对照**——没有一行收益是孤立的，全部对着基准讲；
2. **跑输不遮掩，归因到主动决策**——「落后源于对尾部风险的主动管理」是范本最值钱的一句；
3. **展望 ≤3 条且可执行**——「改进订单拆分与择时逻辑，降低交易成本」这种颗粒度，不是「继续努力」。

## 三、周报（反推：月报的周粒度收缩，每周五收盘会后生成）

1. **本周一行表**：本周收益 / 周超额 / 周内最大回撤（基准列同月报基准）；
2. **近 8 周滚动小表**：三行（基准/组合/超额）×8 列——月报逐期表的周粒度版；
3. **本周运作要点**：成交/拒单/RiskGuard 拦截 top1 归因 + trainee routine 执行情况（chaser/taishan 撮合笔数）；
4. **下周重心**：≤3 条，来源同月报（拍板项+复盘）；
5. **需拍板项**：直接复用 `period_summary._decisions` 的三问格式（订阅/低分/回撤阈值）。

载体：周五 15:15 收盘会（调度已修 15:15:00）后自动汇编，推飞书速览同通道。

## 四、日报（反推：日报不是月报缩写，是盯盘口径，不新增调度）

对齐现有链路，只补「汇编」一步（16:00 撮合验收之后）：

1. **当日权益快照**：收盘权益 + 较昨变动 + 当日回撤（equity_marks 当日行）；
2. **当日执行流水**：07:20 pf_002 落单 n 笔 / 撮合成交 n 笔 / 拒单 n 笔（含原因分布）/ 挂起 pending；
3. **值班经理一句话点评**（对标月度点评的日粒度）：今天为什么赚/亏/不动，一句讲完；
4. **明日计划**：≤3 条（对标投研重心）。

承载：现有 09:00 晨检简报（盘前）已成型；本档=**盘后日报**，素材在 15:15 收盘会 + 16:00 撮合验收后已齐，可挂 16:30 游资画像同批次或独立 16:45，**开闸后定**。
