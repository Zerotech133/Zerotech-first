## 2. 状态模板

新增 `portal/static/ui_states.css`：

| 模板 | 用法 |
|---|---|
| `.wb-skeleton` + `.wb-skeleton-line(.short)` | 异步首屏/刷新骨架，带 shimmer；`prefers-reduced-motion` 关闭动画 |
| `.wb-empty` | 空状态（虚线框、弱化文字） |
| `.wb-error` | 错误状态（红色边框 + ⚠） |
| `.wb-state` | 行内状态容器 |
| `.wb-skip` | 键盘跳转链接（focus 时显现） |

OS 页建议区初始内容由文字改 skeleton；JS 渲染后原逻辑 `replaceChildren()` 覆盖，行为不变。
