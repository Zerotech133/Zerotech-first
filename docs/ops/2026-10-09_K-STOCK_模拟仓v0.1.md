## 定位

补上 K-STOCK 线「决策之后无执行层」的缺口：五节点辩论产出 D1（BUY/SELL/HOLD + confidence）后，
由模拟仓承接——AI 决策自动落单撮合、人为可 CLI 手动测试，同一账本、不碰真钱。

老田拍板四项：k_stock 线内模块 / 信号单当日开盘价成交 / 决策后自动落单 / CLI 全套。

## 关键口径

- **AI 信号单两步制**：exec 盘前落 pending（plan_date=决策当日，工作日顺延预测）→ settle 按
  ≥plan_date 第一个真实交易日**开盘价**撮合。防未来函数；湖盘后更新导致账面确认延迟次日晨，日线级可接受。
- **手动单即时成交**：湖内最近收盘价或指定价（须在 bar [low,high] 内）。
- **费率**：佣金 max(5, 0.025%) 双向 + 卖出印花税 0.05%；零滑点（挂账）。
- **风控两条**：单票 ≤20% 总资产、总仓 ≤95%（--force 跳过）。**无独立单笔限**——一手最低额
  （茅台 ≈12.5 万=12.5%）与 10% 单笔限自相矛盾，开发中实测暴露后论证删除。
- **AI 仓位公式**：目标 = 20% × min(1, conf/0.75)；差额不足一手 → cancelled 留痕。
- **幂等**：AI 单 ref=`{run文件名}#{股票}` 唯一部分索引；cancelled 不复活（次日产新 run 自然重判）。

## 设计中发现并修掉的问题

1. **时序缺陷（冒烟抓出）**：07:05 决策时湖最新=昨日，next_trading_day 纯查湖序列会
   「无之后交易日」全部 skip → 改为湖外工作日顺延预测 + settle 用 first_bar_on_or_after 纠偏（节假日同样解决）。
2. **契约细节**：决策产物 stock 字段是「600519.SH 贵州茅台」带名称 → `_norm_stock()` 正则归一化。
3. **风控自洽**：单笔限与一手最低额矛盾 → 删单笔限（见上）。
