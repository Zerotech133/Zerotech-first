## 2. 设计（为什么先 v0 再 Mem0）

- **零依赖**：主环境此前已因 Phoenix/NeMo 安装出现依赖冲突，记忆先用 stdlib v0 稳定接口；
- **追加式**：`work/p1/memory/memory.jsonl`，不改历史；过期用 tombstone（`event=expired`）；
- **五类**：decision / lesson / preference / commitment / fact；字段含 ts / tags / source / confidence / expires_at / sha256；
- **去重**：同文本 sha256 重复直接返回 duplicate；
- **召回**：复用 `zhuge_rag.tokenize`（CJK bigram/trigram）+ 近期衰减 + confidence 高加权；
- **隐私**：只存经验/决策文本，不存客户原文；单条 ≤2000 字；文件在 `work/`（不入库）。

## 3. 用法

```powershell
python tools/zhuge_memory.py remember --kind lesson --text "BM25 需同义词扩展" --tags rag,bm25 --confidence high
python tools/zhuge_memory.py recall --query "BM25 召回" --k 5
python tools/zhuge_memory.py list --limit 20
python tools/zhuge_memory.py prune
```
