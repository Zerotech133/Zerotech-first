## 一、可行性矩阵

| 方式 | 持续性 | 需要批准 | 适用 |

| **A. 手动有界循环**（`tools/test_loop.ps1`，本轮交付） | 在指定轮数/时长内持续 | 无（只读测试+写日志/事件） | 立即：回归窗口、夜间巡检 |

**边界（诚实说明）**：现在不是"席位完全自主调度"——自主调度需要 DSH 会话载体/8796 派单（P2c 正在接入）。当前是**关羽线执行 + 事件留痕**，等价于"关羽技能包里的测试循环"；接入 8796 后可升级为席位自动领单执行。

## 二、A 方式用法（已交付）

```powershell
# 2 轮 fast（portal+k_stock），轮间隔 30s
powershell -NoProfile -ExecutionPolicy Bypass -File tools\test_loop.ps1 -SuiteSet fast -Rounds 2 -IntervalSec 30
# 单轮 agent（约 7 分钟）
powershell -File tools\test_loop.ps1 -SuiteSet agent -Rounds 1
# 出现新增失败即停
powershell -File tools\test_loop.ps1 -SuiteSet fast -Rounds 6 -StopOnNewFail
```

- 底层调用 `tools/test_gate.ps1`（三分类基线：known/env/flaky；新增失败=0 才 PASS）；
- 产物：`_reviews_20261026/test_loop_<ts>.jsonl`（每轮每套房 rc/新增失败/日志路径）+ 终端摘要；
- 事件层：启动发 `task_start`，出现新增失败发 `guard_fail`（`DEVTOOL_AGENT=GUANYU`，归因到关羽/DSH）；
- 回滚：脚本只读+写日志，无副作用；删日志即可。

## 四、判据与告警

1. **唯一放行判据**：test_gate 新增失败 = 0（既存 known/env/flaky 不判负）；
2. 新增失败 → 循环立即告警（终端 + `guard_fail` 事件 + JSONL 记录），可选 `-StopOnNewFail` 停止；
3. 每轮结果保留日志路径，便于复盘定位。
