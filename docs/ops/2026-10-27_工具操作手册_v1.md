# 工具操作手册 v1（2026-10-27）

> 面向"用工具的人/Agent"的 how-to：每个工具的用途、命令、退出码、只读边界与关联测试。
> 配套参考：`docs/testing.md`（测试基线）、`docs/standards/2026-10-27_质量分级_v1.md`（Silver 证据）。
> 本文件不含凭据；token 类工具只说明"从环境变量读取"。

## 1. `tools/mcp_ro_filesystem.py`（MCP 只读文件）

- 用途：给 Agent 的 MCP filesystem server（root 白名单）。
- 调用：由 MCP 客户端按 `agent_platform/legion_mcp/servers.json` 拉起，非人工直接跑。
- 边界：只实现 list_dir/read_file/stat；root 由 `args --root` 限定（仓库 + deliverables）。
- 证据：`servers.json` risk=read-only；`tools/test_mcp_security_check.py`。

## 2. `tools/mcp_ro_git.py`（MCP 只读 Git）

- 用途：MCP git server（status/log/diff），只读。
- 调用：MCP 客户端拉起；`--repo` 指定仓库根。
- 边界：禁止写/checkout/push；输出截断由 server 控制。
- 证据：同 §1。

## 3. `tools/mcp_ro_zhaoyun.py`（MCP 只读赵云数据）

- 用途：tasks/org/docs/health 只读查询（MCP）。
- 调用：MCP 客户端拉起；`allow_tools=tasks_read/org_read/docs_search/health_read`。
- 边界：只读账本/文档，不写任务板。
- 证据：同 §1。

## 4. `tushare-http`（MCP 外部 HTTP）

- 用途：外部 Tushare MCP（258 tools，行情/基本面等）。
- 配置：`agent_platform/legion_mcp/servers.json`；token 仅 `token_env` 注入（不落仓/不写 URL）。
- 边界：risk=read-only；`allow_tools="*"` 目前宽（质量分级已标 warn，建议白名单化，改配置需重启 8796=L2）。
- 验证：`python -X utf8 tools/mcp_security_check.py`（0 error/1 warn 基线）。

## 5. `tools/seat_evidence_packet.py`

- 用途：田丰取数门面，生成确定性证据包（JSON+MD，含来源/时间戳/sha256）。
- 用法：`python -X utf8 tools/seat_evidence_packet.py [--out DIR]`。
- 输出：默认 `%LOCALAPPDATA%\\aios\\seat_brief`（env `SEAT_EVIDENCE_OUT` 覆盖）；缺源记 exists=False 不编造。
- 边界：只读源文件，不联网/不重启服务。证据：`docs/testing.md`。

## 6. `tools/c6_daily_kpi.py`

- 用途：C6 指标日报（dev 采集/归属率/吞吐/验收覆盖），只读 tasks.json+dev_events。
- 用法：`python -X utf8 tools/c6_daily_kpi.py [--date D --days 7 --json]`；输出 `agent_platform/data/dev/c6_daily/`。
- 边界：只出数不判负；口径见 `docs/testing.md`。

## 7. `tools/ruff_ratchet.py`

- 用途：ruff F/E9 棘轮，防 lint 债回潮。
- 用法：`--update` 生成基线；`--check` 检查；`--repo` 为主仓生成；基线 `tools/ruff_baseline.json`。
- 退出码：0=无新增；1=回归；2=基线缺失。
- 边界：只读扫描 + 写基线（仅 `--update`）。

## 8. `tools/night_test_baseline.py`

- 用途：夜跑基线：分套件跑 pytest、存 JSON、`--check` 对比新增失败。
- 用法：`--dry-run` / 直接跑（默认 portal+k_stock/tests）/ `--check` / `--suites`。
- 输出：`agent_platform/data/dev/test_baseline/<date>.json`；`--check` 新增失败 rc=1。
- 边界：会跑测试（耗时），不写生产数据。

## 9. `tools/mcp_security_check.py`

- 用途：MCP 白名单自查（read-only/token 仅 env/URL 无 token/明文/scope）。
- 用法：`python -X utf8 tools/mcp_security_check.py [--json]`；rc=1 有 error。
- 边界：只读配置；不改 servers.json。

## 10. `tools/devtask.py`

- 用途：任务单/worktree/合并调度（本平台核心开发工具）。
- 用法：`new <TID> "desc" [--project] [--dept dev --acceptance "..."]` / `merge <TID>` / `drop` / `prune --dry-run` / `list` / `port` / `board`。
- 边界：会写 `.worktrees/tasks.json`、建/删 worktree；合并过评审门；不触生产。
