## 三、判决与理由

**不转强制**（保持现状：默认关闭，按需 `DEVTOOL_OCR_GATE=1` warn）：

1. **非确定性**：同输入两次结果不同 → 阻断会造成"偶发拒收"，违反门禁可复现原则；
2. **成本**：25–36s/次、数十万 token/单（deepseek 便宜但不可忽略；全量代码单每日数十次则负担明显）；
3. **FP 率未达标**：策略要求"连续 2 周 FP<10% 才议 block"，当前样本远不足；
4. **价值确认**：OCR 适合**按需人工审查/复盘**（本次 2 个真 bug 已修），不适合当阻断门。

## 四、下一步（若将来要启用）

| 前置 | 标准 |
|---|---|
| 稳定 provider | 固定 model/effort 参数，记录版本（非确定性可接受但需记录） |
| 采样 | 开启 warn 跑 **≥20 个代码单/2 周**，人工分类 FP |
| 成本预算 | 单次 token 成本 × 日均合并数 ≤ 可接受阈值（建议先设月预算上限） |
| 启用形态 | 即使达标也**只 warn**（打印到合并输出）；block 仅对 `high` 且人工复核确认的类别另议 |
| 回退 | 环境变量即可关闭，无需回滚代码 |
