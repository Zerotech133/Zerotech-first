## 二、并行纪律（本轮硬约束）

1. **一单一 worktree**：每任务 `python tools/devtask.py new <TID> "<一句话>"` 建独立 worktree；只改 worktree 内文件；主区（master）一律不改。
2. **写域互斥**：三任务写域已登记；共享文件（`STATUS.md`/`ROADMAP`/`ADR`/`registry`/`portal_api.py`）本轮**不碰**；Lead 协调件与任务文件不同名。
3. **WIP**：worktree 12 → 15（ADGS 试点上限 ≤15）；合并后回收；不再开第 4 个写线。
4. **合并**：只在 16:30–17:00 主窗口（或 21:40–22:10 次窗口）；禁并期 09:15–15:05、17:10–18:40、20:00–20:20、21:20–21:40；窗口外只提交不合。
5. **提交**：显式 `git add <paths>`，禁 `git add -A` / `reset --hard` / `clean -fdx` / `merge` / `push`；提交信息带任务 ID。
6. **测试**：每分支定向测试全绿；Lead 合并前在 worktree 内复跑；新增失败=退回下一班。
7. **L2 不代执行**：服务重启/计划任务/nginx/凭据一律走 L2 五要素 + A0 批准（见合并申请单）。
