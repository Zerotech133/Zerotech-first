## 四、下一步研究方向（建议拍板）

### 方向 A：运维可靠性——「判断永远在线」（P0，本周可落地）

- **A1 回填护栏**：`jev_backfill.py` 加 `--deadline` 参数（单轮硬超时，如 20min 强制退出）；任务 XML 设 ExecutionTimeLimit=PT30M，杜绝实例悬挂连锁
- **A2 本地降级通道**：`jev_judge_one` 失败 N 次后自动切 Ollama（qwen3:8b-8k 输出同 schema JSON，标记 `"via":"local"`），云端恢复后 backfill 自动重判覆盖 → **判断永不空窗**
- **A3 gap 告警**：回填轮结束时 `left > 100` 即推送告警（复用现成 send_feishu）；N1Check 增加检查项「jev gap < 50」

### 方向 B：观测与数据中台——「看得见、接得上」（P1，1-2 周）

- **B1 观测修正**：`jev_judge_one` 成功打采样日志（1/10 sampled OK）；晨报新增「判断健康行」（24h 判断数/失败数/当前 left）
- **B2 jev_feed 复活**：注册计划任务（每日 1 次 + 断点续传已有），恢复中台增量；或评估与 backfill 合并为单任务降低复杂度
- **B3 判断回流量化**：news.db 的 bias/scope/conf 按标的/时间窗聚合写回 quant_backtest datamart——为方向 C 供料

### 方向 C：价值闭环——「判断值多少钱」（P2，研究方向，与 RiskGuard 重校准联动）

- **C1 判断 alpha 验证回测**：历史 jev bias（21,037 条）与后验 30min/日度行情对齐——「bull 判断后标的实际涨跌分布」；产出 conf 校准曲线 + bias 准确率分 scope 报告。**这是判断模块从「展示品」变「生产资料」的关键一步**，素材可直接喂给盯盘 RiskGuard 四规则重校准（拦截样本 +0.65% vs 放行 -0.25% 的误杀问题）
- **C2 采样升级**：晨报 50 条 → 分层采样（关键词命中 + 自选股 + scope 配额），把 98.9% 覆盖的存量判断真正用起来
- **C3 事实校验层**：判断 reason 中引用的标的/数字与新闻原文正则比对，校验失败打标 `unverified`——防编造从提示词约束升级为程序性校验

### 建议落地顺序

**今天**：A1 护栏（解除悬挂）→ 云端恢复后验证 gap 收敛 → A3 告警。
**本周**：A2 本地降级 + B1 观测。
**下周起**：B2/B3 → C1 回测研究（出首份 conf 校准报告）。
