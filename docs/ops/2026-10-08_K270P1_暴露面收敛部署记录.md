# P1-1 暴露面收敛部署记录（K270 整改，2026-10-08 11:2x）

- 编号：K270-P1（审查报告 `deliverables/comprehensive-review-2026-10-08.md` §五 P1-1 落地）
- 变更：两容器端口绑定 `0.0.0.0` → `127.0.0.1`，其余参数逐项保持一致

## 背景

K270 全面审查发现：ai-portal（门户全站无鉴权）与 dev-assistant（Open WebUI，**WEBUI_AUTH=false 免登录直用**）双双全网卡暴露，局域网内任何设备可访问门户全部页面并直接使用 LLM。

## 变更内容

| 容器 | 原绑定 | 新绑定 | 其余参数 |
|------|--------|--------|----------|
| ai-portal（nginx:alpine） | 0.0.0.0:8080→80, [::]:8080→80 | **127.0.0.1:8080→80** | 不变：restart=unless-stopped；ro 挂载 nginx.conf→conf.d、portal/→html |
| dev-assistant（open-webui v0.5.20） | 0.0.0.0:3000→8080, [::]:3000→8080 | **127.0.0.1:3000→8080** | 不变：WEBUI_AUTH=false / WEBUI_NAME=超级个体 / OLLAMA_BASE_URL=host.docker.internal:11434 / 三项 anti-track env；volume open-webui-data + bind D:\个人OS\assistant\tools |

重建命令（ai-portal 示例，dev-assistant 同法）：

```
docker stop ai-portal && docker rm ai-portal
MSYS_NO_PATHCONV=1 docker run -d --name ai-portal --restart unless-stopped \
  -p 127.0.0.1:8080:80 \
  -v "E:/老田的AI助手/portal/nginx.conf:/etc/nginx/conf.d/default.conf:ro" \
  -v "E:/老田的AI助手/portal:/usr/share/nginx/html:ro" nginx:alpine
```

## 决策记录：WEBUI_AUTH=false 保留不动

- 原报告假设风险为「Open WebUI 默认开放注册」；inspect 实核实为**整个鉴权关闭**（免登录直用），比假设更暴露。
- 处置选择**只收敛绑定不动鉴权**：127.0.0.1 绑定后攻击面=本机进程，与 portal_api(8091) 无鉴权同等的「本机信任模型」，且保留老田免登录使用习惯。
- **拍板项（挂账）**：若日后需手机/局域网访问 3000，须同步改 WEBUI_AUTH=true 并注册管理员后再放行绑定。

## 验证（11:2x 全通）

- `127.0.0.1:8080/audit` 200、`/api/audit_status` 反代 200（M6 接线链路完好，portal_api 8091 不受影响）
- `127.0.0.1:3000/` 200、`/health` 200（Open WebUI 冷启动约 40s，volume 数据完整保留）
- netstat：8080/3000 仅剩 127.0.0.1 监听，0.0.0.0/[::] 零残留
- docker ps 全景：除 tm_lin（无端口映射）外全部容器 127.0.0.1 绑定

## 回滚

按上表原绑定重建即可（`-p 8080:80` / `-p 3000:8080`），数据无变化（volume/bind 未动）。
