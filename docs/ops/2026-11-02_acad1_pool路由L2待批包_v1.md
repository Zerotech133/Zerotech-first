### 2.2 主方案理由（写进 L2 结论）

1. **事实一致性**：同页 `/acad1_pool.html` 已匿名 **200**，数据 API `/api/acad1/pool` 属 2026-11-01 H4-B **公开族 C**（`acad1` 明确列入，见 nginx.conf:225/268）→ 本页数据面/页面面本就是**公开只读研究**定位；把 clean URL 登录墙化（B）既造成页面组内语义不一致，也挡不住 raw URL 旁路（除非再门禁一处）。

### 3.5 关于任务文中的 `location ^~ /acad1/pool` 形式

- 本包主方案用 **`location = /acad1/pool`（精确匹配）**：与既有 clean 页式路由习惯一致（`= /academy/shuijing`、`= /hall`、`= /stack`、`= /ide`…），且不会把未来 `/acad1/pool/<x>` 未知子路径误映射到页面。
- 若 A0 坚持前缀形式，等价替换为 `location ^~ /acad1/pool { … }`（**`^~` 不可省略**：line 69 有后缀正则，虽 `.html` 不在名单，但前缀形式会被普通前缀处理；`^~` 抑制正则检查并吞含 `/acad1/pool*` 全后缀）。语义差异：`/acad1/pool/xxx` 会返回页面而非 404。
