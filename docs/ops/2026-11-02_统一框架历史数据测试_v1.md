2. 把当前 `tools/composition.py` 复制进临时根（验证"当前框架校验器"对历史清单的检出能力）；
3. 临时根用 junction 挂当前 `agent_platform/`、`portal/`、`research/`、`quant_backtest/`（支持注册表/页面/数据集上下文）；
4. 跑 `composition.py validate --all` 与 `plan --strict --json`，记录 errors/warnings/findings/rc；
5. 全部在 `C:\Temp\zbf_hist_replay\` 完成，不修改仓库。

## 三、解读

1. **门禁有效**：W1 起点 28 个引用 warning 被当前校验器完整检出；试点阶段新增 manifest 后 warnings 从 14 变为 15，说明新增声明若未登记会被门禁记录（不是静默通过）。
2. **收敛可验证**：`215b11eb`（planned refs registry + manifest 校正）后 warnings 0，并保持到 W1 关闭提交；与当前工作区 0 一致。
3. **无 schema/漂移误报**：7 个历史快照 `errors=0` 且 `plan --strict` findings=0、rc=0，说明"历史清单 + 当前门禁"没有产生结构性误报；W1 关闭的引用 100% 可由 git 历史复现。
4. **限制**：使用当前支持注册表（agent/page/dataset/job）作为上下文，不是提交时点的完整快照；因此 warnings 绝对数可能因支持面变化略有差异，但趋势与收敛结论稳定。
