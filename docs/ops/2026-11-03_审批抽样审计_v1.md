## 二、发现

1. **100% approved、无 rejected**：审批可能过宽，或只记录通过项；
2. **pending=0 不能推断无待办**：飞书待办未同步本地库；
3. **决策人集中**：抽样中 7/10 为老田，符合 M4 owner 单签政策，但需防止“形式审批”；
4. L2 例外类（devtask_l2_exemption）8 条，全部 approved，需核对五要素证据。

## 三、建议

1. W3 起审批审计每周 1 次，样本 ≥10；
2. 对 L2 例外逐条核对五要素/回滚；
3. 飞书待办与本地审批库做只读对账（后续 MCP/API）；
4. 不把“pending=0”当作“无待办”的结论。
