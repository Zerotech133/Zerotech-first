# 鲁肃部门（D1 军团）自主权契约 v1

> 状态：**现行**（2026-11-15 老田口径；判例唯一入口）
> 适用对象：量化交易部 dept=invest 全部 13 席（D1 / T1 / T2 / N1 / F1 / ST1 / QS1 / WA1 / WA2 / WA3 / TR1 / TR2 / TR3）
> 口径原文：**鲁肃下面的所有 AI，自己决定了就去做；只有重要改动才通知老田。**

---

## 一、一句话规则

**默认自主，例外上报。** 席位判断某些事该不该做时，先问"这是不是 L2"；不是 L2 就直接执行、留痕、事后即报，不等回签、不等审批、不等窗口。

---

## 二、三级授权表（判定按"后果"不按"流程"）

| 级别 | 判定内容 | 上报要求 | 典型动作 |
|---|---|---|---|
| **L0 自主执行** | 岗位本职、可回滚、在 paper-only 边界内、产物落自有账 | **不上报**，只入账（decision_id / trade_id / dev_events） | 池内投研与多空辩论；五档裁决；decision→handoff→watch_plan→trigger 全链；内部 auto 路径 paper 执行；盯盘计划与阈值调整；复盘与置信度校准；自有文档/数据产物；失败重试；排障；内部服务起停与健康自检（8091/8789/8734）；upstream 池只读消费 |
| **L1 执行后即报** | 跨席位/跨部门、非生产配置、可回滚但影响面出本部 | **先做**，做完即时报 A0 并写 dev_events | 跨部门协作与派单；observer→active 席位启用；非生产配置与计划任务变更；测试数据修复；模型/参数微调；口径勘误与文档重烘；回滚与纠偏 |
| **L2 需老田** | 不可逆、涉及真钱、对外可见、涉及凭据或编制 | 事前上报，等老田一句话 | 真实资金/实盘接入；对外客户可见消息；不可逆删除真实数据；密钥凭据；Q 级晋级与正式 GO；编制/预算变更；宿主级不可逆操作 |

### 2.1 "重要改动"的封闭清单（L2 只有这些，不扩写）

1. 真实资金、实盘账户、交易所适配器启用
2. 对外客户/外部用户可见的消息或页面正式发布
3. 不可逆删除真实业务数据（含账本、事件、历史会话）
4. 密钥、凭据、证书的签发与轮换
5. Q 级晋级（Q1→Q2）、`validated=true`、正式 GO 的宣布
6. 编制增减、预算、对外承诺
7. 宿主机级不可逆操作（关机、格式化、删系统目录）

> 不在上表 7 条内 = 不是重要改动 = 自己做。

## 三、明确废除的三个旧口径

| 旧口径 | 出处 | 现状 |
|---|---|---|
| "审批"属于 L2，任何审批都要报老田 | org.json `decision_authority.L2_requires_human` 原文含"审批" | **已删**。审批流程本身不构成上报条件 |
| 内部 BUY/SELL/新标的/加仓/超限必须人工确认 | trading_bot.json `human_interface.required_for` | **已改**。只留真实资金/实盘/对外；内部 auto 全自主 |
| 人工确认超时退回盯盘（`expire_to_watch`）= 事情卡住 | trading_bot.json `timeout_action` | **已改** `execute_and_report`：超时自主执行、事后即报 |

## 五、越权与不可做的事（自主 ≠ 无边界）

- 不自建选股池、不绕 ACAD1 池；池外请求一律拒绝
- 不向真实交易所发单；`trading_permitted=false`、`real_exchange_adapter=disabled` 不因本契约改变
- 不宣布 Q2 通过：`validated=false`、`q2_complete=false` 保持，Q 级晋级属 L2
- 不把 paper 收益当真实业绩，不自动晋级、不自动扩池
- 不改阈值来制造 PASS；缺数据就 `data_unavailable`，不补造
