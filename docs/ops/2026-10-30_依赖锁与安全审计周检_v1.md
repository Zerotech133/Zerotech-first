## 三、周检 SOP

1. **每周一 09:00**（或任何静态门变更后）跑 `python tools\dep_audit.py --check`；
2. `pip_audit` 报漏洞：
   - 有修复版本 → 升依赖（改 pyproject/requirements-dev → `uv lock` → 提交 lock 与升版单）；
   - 无修复版本 → 登记豁免（原因/影响面/到期日）进 `docs/ops/`，不得默默忽略；
3. `uv_lock` 不一致 → 立即 `uv lock` 并提交（锁漂移=可复现性丢失）；
4. bandit 启用后：HIGH>0 当周处置；MEDIUM 月度评审。

## 五、依赖锁策略

- **工具链锁**：`uv.lock`（dev group）是唯一权威；新增 dev 依赖必须同批提交 lock；
- **运行依赖**：各线 venv 现状管理（quant/portal/agent 分线），P2 再统一收编（避免一次动全仓环境）；
- **禁止**：无锁新增依赖、`requirements-*.txt` 与 pyproject 不一致、跳过 `uv lock`。
