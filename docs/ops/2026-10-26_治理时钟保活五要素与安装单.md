# 治理时钟保活 · L2 五要素批准单（待老田批准后安装）

> 目的：让治理时钟（08:46/17:50/18:05/18:10 四锚点）在**重启机器后自动恢复**，不再依赖会话手动拉起。
> 现状（2026-10-26 13:10 实测）：时钟 pid 9448 在跑；**无**任何治理保活计划任务；HKCU Run 无治理项。
> 幂等脚本：`ops/keepalive_governance_clock.ps1`（缺失则拉起，已在跑 no-op；日志 `C:\Temp\governance_keepalive.log`）。

## 一、命令全文（安装时执行，两种机制任选其一）

### 方案 A（推荐）：任务计划程序，两个触发器
```powershell
# 1) 每 5 分钟：缺失则拉起（幂等）
$ps = 'powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\项目\老田的AI助手\ops\keepalive_governance_clock.ps1"'
schtasks /Create /TN "GovernanceClockKeepalive" /TR $ps /SC MINUTE /MO 5 /RL LIMITED /F
# 2) 登录时立即拉起（覆盖开机后首个 5 分钟窗口）
schtasks /Create /TN "GovernanceClockOnLogon" /TR $ps /SC ONLOGON /RL LIMITED /F
```
（如当前用户无计划任务权限，改用 HKCU Run：）
```powershell
$run = "powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File ""C:\项目\老田的AI助手\ops\keepalive_governance_clock.ps1"""
Set-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "GovernanceClockKeepalive" -Value $run
```

### 方案 B：仅 HKCU Run（只在登录时拉一次，5 分钟韧性靠脚本自身）
```powershell
Set-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "GovernanceClockKeepalive" -Value $run
```

## 二、影响面

| 项 | 说明 |
|---|---|
| 新增 | 1–2 个计划任务（或 1 个 HKCU Run 项） |
| 每 5 分钟 | 启动一次 powershell（常驻时钟在跑时立即退出，开销 <1s） |
| 日志 | 追加 `C:\Temp\governance_keepalive.log`（只增不删，可手工清理） |
| 不碰 | 服务/网络/防火墙/系统代理/其他计划任务/数据目录；不起额外端口 |
| 完成度 | 机器重启后无需人工介入，08:46 扫描/17:50 预扫/18:05 收口/18:10 AI 建议自动恢复 |

## 三、不可逆点

- 无数据破坏性操作；任务/注册表项可随时删除。
- 唯一注意：若仓库路径变更（`C:\项目\老田的AI助手`），任务里硬编码路径会失效 → 需同步改任务命令（已在脚本中参数化 Repo，但计划任务命令行写死）。

## 四、替代方案与已尝试

1. **不安装**：重启后手动 `python ops\governance_clock.py --loop`（现状，已验证可用但依赖人）；
2. **HKCU Run 单点**：只覆盖登录，不覆盖进程意外退出（5min 韧性不足）；
3. **PowerShell 后台作业**：随会话/终端退出，不适合作为常驻。
→ 推荐方案 A（5min + ONLOGON 双触发器）。

## 五、回滚预案

```powershell
schtasks /Delete /TN "GovernanceClockKeepalive" /F
schtasks /Delete /TN "GovernanceClockOnLogon" /F
Remove-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "GovernanceClockKeepalive" -ErrorAction SilentlyContinue
# 时钟本体不受影响；如需停：Stop-Process -Id (lock 里的 pid)
```
