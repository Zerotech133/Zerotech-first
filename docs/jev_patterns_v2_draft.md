## 二、新增通用纪律（进 v2 正文）

1. **基线意识**：每份案例库报告必须附全体涨停票基线表；pattern 有效性 = 相对基线差，禁止绝对收益下结论。
2. **xd_notice 剥离**：异动推送不是「公告」——凡以「公告/追认」为语义的 pattern（P-01 confirm 分支、P-06、P-07），confirm 信号排除 `xd_notice` 或单独降权（P 表加 `CONF_WEIGHT_XD_NOTICE`）。同义反复警告：xd_notice 对涨停票覆盖近 100%，把它当追认等于拿结论证明结论。
3. **数据缺口清单**（P5.3 前置）：①news.stocks 回填（分钟白名单源 20-50%）；②announcement/report/survey 票映射 1.9-23%；③社交快照扩票池或历史回补；④stk_mins 当月只覆盖中证800 → 每日盘后自动补摸板票（`jev_mins_fetch --source tushare`，xtcloud 源不稳）。
4. **格式坑**：`news.stocks` 是 JSON 数组字符串或逗号分隔两种格式并存，解析必须双格式兼容（`_p52_caselib._stock_codes`）。

## 三、对 P5.3 校准的影响

- 阈值校准的样本池变化：P-04 退出 signal 校准；P-08 升级为主样本池（n=283，后验完整度最高）；P-07 待池重构后重跑。
- 校准目标从「10 pattern 全覆盖」改为「**7 个可判 pattern + 1 个实验田（P-04）**」，判定闸 A 条件②（覆盖率 ≥60%）的分子分母同步改口径。
- v1 的互斥组与正反对照对设计不变；P-04 退出后，「分化度」指标改在 P-08（弱事件）与 P-02（强事件）之间测。
