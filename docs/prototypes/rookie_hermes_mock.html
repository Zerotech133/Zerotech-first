三、联动三通道（机制定案）

① 下行 · 派单转执行

菜鸟建任务单（tasks 七态）→ 可执行项自动路由 Hermes 工具链 → Hermes 干活。凡写库/下单/发推送，单据先行。

② 上行 · 结果回写

Hermes 完成后回写任务单（done/failed + 证据链接）→ 菜鸟汇总进 A0 日报 → 老田一份汇总看全部。

③ 平行 · 分流与升级

判据：是否涉及部门/审批/数据写入。是 → 升级菜鸟建单；否 → Hermes 直答。双向可转让，不留死角。
