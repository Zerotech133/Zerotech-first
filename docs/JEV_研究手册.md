## 一、JEV 是什么（定位先钉死）

- **是**：**OSINT 多维信号收集 + pattern 识别 + 演化推演引擎**。
  输入 = 多维实时/历史信号（资金流、社交热度、结构、Δmin 时间维度）；
  第一步识别异常 pattern（如：资金背离 + 散户热度飙升 + 机构沉默 + 消息追认）；
  第二步查历史案例库（该 pattern 出现时，过去 N 次演化路径分布）；
  第三步输出推演 + 策略建议（各路径概率、分化节点）。
- **不是**：无条件预测器（"这只 3 天后必回落"）、荐股、实时盯盘告警、爬虫。
- **红线（不可动）**：采集是下属工位，JEV **只读快照、不联网、不爬**；
  JEV **不做无条件单点涨跌预测、不荐股、不实时告警**——但"给定 pattern 的条件推演"是核心职责。
- **结论判定原则**：任何"推演结论"必须**多维交叉**（时间 / 资金 / 社交三维 + Δmin 指向同一方向才算成立），单看一条不算。

## 四、已验证：语义层（后验硬证据）

口径（`jev_posterior_poc.py`）：信号日 = 新闻 ts 日期，持有 = 其后首个交易日 T+1 收盘；
标的收益 = 关联 A 股 T+1 pct_chg 等权均值；超额 = 标的 − 沪深300 同日；
方向命中 = sign(超额) 与 bias 一致；中性命中 = |超额| ≤ ±1%。

**样本**：140741 已判新闻 → 29910 带标的 → **28502 可评估**（方向类 14102 / 中性 14400），覆盖 19 个交易日。

| 指标 | 值 | 对照 |
|---|---|---|
| 方向类准确率 | **52.5%**（n=14102，95%CI 51.7–53.3%） | 全判 bull 49.2% / 全判 bear 50.7% → 仅 +1.8~3.3%，**显著但微弱** |
| 平均超额（bull / bear / neutral） | **+0.203% / −0.408% / +0.099%** | **sign 正确**：bull 跑赢、bear 跑输，组合层方向 tilt 真实存在 |
| 中性带命中（|超额|≤1%） | 30.3% | 中性类≈无信息量（均值超额≈0） |

**按事件类型（n≥20，真实边）**：credit 64.7% / trade 62.9% / risk 58.1% / policy 54.6% / equity 53.8% / earnings 53.9% 有边；
**无/反向**：price 48.8% / supply 49.1% / other 51.5%。

**结论**：新闻 bias 的**方向**在组合层是真实弱信号（bull 跑赢 0.2%、bear 跑输 0.4%）。
单点命中率仅 52.5%（接近抛硬币），**不可作单只标的买卖信号**，只可作组合层微弱方向因子。

## 五、已弃用：`conf`（反相关，比随机还差）

`tools/jev_calibrate.py` 复用后验标注（right=1 当且仅当 bias 判读正确），28506 样本按 ts 时间切分 70:30。

| 方法 | AUC | ECE | Brier |
|---|---|---|---|
| raw_conf | **0.414** | 0.431 | 0.447 |
| temperature（T=20，保序） | 0.414 | 0.096 | 0.255 |
| platt（反转，保序） | 0.586 | 0.030 | 0.240 |
| isotonic | 0.499 | 0.022 | 0.245 |

- 分位可靠性查表（测试集）：conf [0,0.75)→右率 **0.557**；[0.90,0.95)→0.352；[0.95,1.00)→**0.375**。**高 conf 段右率反而最低** → 确认反相关。
- **结论**：单调校准器保序、AUC 不变（零判别增益）；即便反转 Platt 也仅 0.586，仍弱。
  **conf 救不回来 → 正式弃用**（不修不换，直接从下游摘除）。
- **替代**：`tools/jev_signal.py` 的 `jev_signal_score`（事件类型分层加权方向分）。
  下游 4 个**决策驱动**点已改：避雷池（弱类型 price/supply 不进）、词云（强弱权重 1.0/0.4）、要闻榜（分层分布替代 conf 排序）、判读区（按 tier 排序）；
  `portal/m_score.py` 的 `jev_conf` 5 核心评分指标也换成 `jev_signal`（活 `/api/m/score/core` 已验证，值 -0.0064）。
  残余 `conf` 仅留作**显示字段**，不再驱动任何决策。

## 六、策略推演引擎（条件推演，非无条件预测）

> 关键纠偏（2026-11-10）：此前把"**无条件预测**失败"外推成了"**条件推演**也不可能"——这是逻辑跳跃，二者完全不同。

- **无条件预测**（"这票 3 天后必回落"）：单点对错，资金背离 lift +1.1% ≈ 0 → 确实不行。
- **条件推演**（"当 pattern X 出现，历史上这条因果链走到了哪步、接下来会冒什么信号"）：OSINT 式情报分析，11-06 是一次完整推演，只是大规模未验证。
- **事后解释**（"回头看为啥涨不实"）：能做，但**不是 JEV 的收敛方向**。

此前用 lift（3 日回落率）考核 JEV，等于用预测指标去砍一个情报分析器——**尺子用错**。
725 只 lift≈0 不代表推演不行，是测试方法和数据都不对：

| 问题 | 说明 |
|---|---|
| pattern 定义太粗 | 只测了"资金背离"单维；11-06 是三维度同时命中的**组合** pattern |
| 结构维度几乎没数据 | 725 只仅 52 只有结构字段、全挤 10-30 一日 → 三维度退化成单维 |
| 缺 Δmin 时间维度 | 判例 #25③"价格先行 vs 消息追认"是推演因果链最关键一环，此前完全没量化 |
| 验证器指标错 | 用"3 天后回落率"当指标；推演关心的是 pattern 出现后**演化路径的多样性和各自概率** |

**11-06 判例再定性（修正）**：股吧散户追捧 + 雪球机构无视 + 主力接而全档逃 = 典型"散户接盘"**组合 pattern**，是一次**有效推演**；
此前把它当"涨停后 N 日回落"前瞻信号去测 lift，是测试错配，不是推演失效。

**下一步（P 阶段）**：Δmin 时间维度（已钉死可用性，见 `JEV_DeltaMin_可用性扫描.md`）→ 社交历史回补 → 重写验证器为 `pattern→演化路径` 案例库 → 三维度+Δmin 组合 pattern 回测（≥5000 样本）。

## 九、一句话给研究者

JEV 的**事实层（新闻/披露/资金/社交的结构化解读）可用但弱**（方向对、量级 0.2~0.4%、单点≈抛硬币）；
它的**无条件预测野心已被数据证伪**（conf 反相关、资金背离 lift≈0）→ 但这是"尺子用错"，不是能力归零。
正确定位是 **OSINT 多维信号 + pattern 识别 + 演化推演引擎**：给一个异常 pattern，推演出因果链的多种可能演化、各自概率、分化节点。
当前最急的是 **Δmin 时间维度**（已钉死可用性）+ **社交历史回补**——补上这两块，推演引擎才跑得起来。
