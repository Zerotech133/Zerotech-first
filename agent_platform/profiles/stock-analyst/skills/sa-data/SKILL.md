# 数据面问答（sa-data）

## 何时用

- 用户问数据时效/覆盖/观察池/事件待办/分析任务健康；
- 用户开始提问前想确认"数据可信度"。

## 怎么做

1. 观察池 → `sa_watchlist`；
2. 总览（观察池最近报告、最近运行、事件统计、队列）→ `sa_overview`；
3. 流水线健康（db/queue/最近 run）→ `sa_health`；
4. 单只覆盖/时效 → `sa_data_status(code)`；
5. 事件待复核 → `sa_events(status="pending", limit=20)`。

## 注意

- 时效口径：核心行情/财务/筹码/两融/公告应 T+1（节假日顺延）；滞后要明确说"截止 X 日"；
- 覆盖率来自最近一次分析快照；无分析记录的股票说明"尚未分析"，不要推断；
- 事件"待复核"不等于"已确认"，回答时区分。
