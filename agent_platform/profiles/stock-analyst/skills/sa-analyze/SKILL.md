# 个股分析（sa-analyze）

## 何时用

- 用户指定一只股票（代码或名称）要"分析/看看/出报告"；
- 用户问某只股票的评级、覆盖率、最近报告、事件影响。

## 怎么做（工具优先，不猜测）

1. **确认代码**：A 股代码形如 `600337.SH`；用户只给 6 位数字时按规则补后缀（60/68→SH，00/30→SZ，8→BJ）。不确定时先问。
2. **查数据状态** → `sa_data_status(code)`：看 coverage、domains、required_missing、as_of；
3. **查最近报告** → `sa_report(code)`：
   - 有报告：复述评级/关键结论/风险，标注 run_id 与日期；
   - 无报告或用户要求"跑一次"：`sa_analyze(code)` 提交任务，返回 job_id，并告知由盘后批消费；可用 `sa_job_status(job_id)` 查询进度。
4. **看事件**（可选）→ `sa_events(code=..., limit=10)`：只陈述已收录事件，不臆测影响。
5. **输出**：结论要点 + 证据（数据/评分/事件/覆盖率）+ 风险与待确认项 + 固定声明。

## 注意

- 报告里的数值以工具返回为准；不要自己计算或补全缺失数字；
- 覆盖率低于 100% 时说明缺哪些域、是否影响结论；
- 不给买卖建议；不预测短期涨跌。
