# 测试全局可变状态泄漏盘点（K-ORG-190）

- 日期：2026-10-19
- 执行工位：a-results（A路）
- 范围：`agent_platform/tests/`（97 个测试文件）中"模块级全局可变状态在测试中被写、不清理/不恢复"的泄漏点
- 性质：**只登记不修**，各条目归各 owner

## 背景

判例：`tests/test_monday_checkpoint_log.py` 的 `check("样例检查")` 曾向 `monday_checkpoint.RESULTS`
全局列表塞条目且不清理，导致"单跑绿、全量红"的字母序污染（本日已由提交 c161c6ee
以 setUp/tearDown 快照-恢复修复，正序/逆序均验证通过）。

本盘点将同类模式在全测试目录扫一遍，防止下一个同型判例。

## 扫描方法

1. grep 模块级容器初始化：`^[A-Za-z_]\w* = [] / {} / set() / dict() / list()`
2. grep 测试内对导入模块属性的写操作：`alias.ATTR = ...`、`alias.RESULTS.append/extend/clear`、`.setdefault(`
3. grep 环境变量 / 进程级标志写入：`os.environ[...] =`、`sys.dont_write_bytecode`
4. 对每处命中人工核验是否带快照-恢复（setUp/tearDown、try/finally、addCleanup、pytest monkeypatch、_load 动态模块隔离）
