## 六、红线段（现场四条）

1. **不手动跑 AgentShadowDaily**——无交易日判断，手动重跑会污染账本；90s 重试等待属设计内。
2. **PENDING ≠ 通过**——周末 7/7 = PENDING 中性，首跑前全 PENDING 是预期形态，不是 PASS。
3. **不修第三会话在途件**（strategy_runtime 等）——观察点前冻结不动已预演路径（总裁决清单 #01/#02）。
4. **演示永不落真仓**——任何演练/复现一律走 `--root <隔离目录>` 或 `SHADOW_DATA_ROOT` 隔离阀；真仓 data/ 现场只观察不试写。
