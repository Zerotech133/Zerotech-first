# 九维量化选股体系 P1 实施计划（纯门户影子版）

## Context

用户提供「九维量化选股体系（升级版）」完整规格：A股、9因子群、总分100、买入阈值≥90分、动态调权三档。工作区无「原85分模型」对应实现，确认为**新建策略**，采用策略市场模式（青萍之末 /bt-qpzm 为模板）落地为独立工作台。

**已确认口径决策**（用户拍板）：
1. 机构调研接口 research DENY → 机构行为分值重分配：龙虎榜10 + 大宗5 = 15分
2. 情绪因子降级为「新闻热度代理」：个股新闻量周环比（news_collector）+ JEV负面占比（news_ai）+ 券商覆盖篇数（research_report）
3. 先纯门户影子：不推飞书，门户展示 + r5/r20 前向收益战绩积累，验证胜率后经确认再接推送

**数据权限实测**（已验证 ✅）：fina_indicator / top_list / block_trade / moneyflow_hsgt / margin / moneyflow / daily_basic / index_daily(科创50) / research_report；本地 parquet（5593只 OHLCV+amount）；news_collector+JEV 现成。

**规格内无源项的降级口径**（实施时在页面口径说明中明确标注）：
- VIX≤15：A股无真源，premarket 现为模拟源 → 降级为「科创50 20日已实现波动率分位≤30%」计3分（本地真源，防模拟值恒过阈值给虚分）
- Q业绩超预期概率≥80%：无直接源 → 用 tushare forecast 业绩预告「预增/略增」近似，forecast 不可用则该项 cov 不可判
- 行业归属：首选申万 index_classify/index_member_all（启动时探权限），DENY 回退 stock_basic.industry 免费字段（已验证可用）
- EV/EBITDA：总市值(daily_basic total_mv)+有息负债(fina_indicator)近似，缺失则用「PE≤行业中位」近似并标注

## 新文件（quant_backtest\）

### 1. nine_dim.py（核心引擎）
- `FACTORS`：声明式九维表 `{id, name, max, items:[{id,label,cond,pts,penalty}]}`（借鉴 chanlun_composite.RULES 模式）；判定函数返回 True/False/None，**None=未覆盖 → 不计分不扣分**，榜单按已判项归一化展示真实得分+覆盖度 cov
- `_ts()`：复用 rps_resonance.py L199 的 POST 封装
- `coarse_filter()`：零API本地粗筛——(量≥120日均量1.5倍 或 站上布林(20,2)上轨) + RPS50>80（复用 batch_rps）+ 当日成交额>2亿 + 剔ST/停牌。理由：技术8+动量12共20分是≥90分票的必拿项，粗筛只滤掉拿不到这20分的票
- `fetch_api(codes)`：两段式第二段。moneyflow/daily_basic/top_list/block_trade 按 trade_date 全市场一次拉再过滤候选；fina_indicator 按 (ts_code,end_date) 季更缓存 data/nine_dim_fina_cache.json；news 周环比+JEV+research_report 篇数
- `industry_map()`：申万优先、stock_basic.industry 回退；行业RPS=成分股RPS等权中位
- `market_env()`：科创50 MA20（index_daily 本地缓存）、两市成交额（本地 parquet amount 求和）、波动率分位；输出调权状态
- `dynamic_weight(env)`：三档调权状态机（科技牛市/高波动/财报期），输出各因子分差
- `score_one()`：逐项判定→调权→归一化→总分+九维分项+cov+徽标明细
- `run_scan()`：编排；入池幂等键 (ts_code,trade_date)；原子写 data/nine_dim_scores.json + 追加 data/nine_dim_history.jsonl
- `update_perf()`：入池日收盘价基准跟踪 r5/r20；pre_close 缺口>0.5% 标 adj_flag 剔除（借鉴 chanlun_scan 模式）；聚合战绩缓存 data/nine_dim_pool_eval_cache.json
- `main()`：`--dryrun` 打印 Top20 核对
